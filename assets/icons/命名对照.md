# 图标命名对照（中文 ↔ 英文）

> SVG 文件统一使用英文 kebab-case 命名（见 `docs/02_样式与布局/00_写法说明.md` 第 7 条）。新增图标用中文命名丢进来，由我批量转换并更新本表。
>
> 颜色约定（2026-08-07 新 token 体系，spike/icon-migrate/migrate.py 批处理）：线条层 = 文字四档（常态 #F7FFFC/69.41%、标签 #EAFFF7/34.12%、高亮 #FEFFFF/92.94%、极淡 #EEFFF8/23.53%）统一转 `currentColor`、**不烘透明度**（CSS color 档位表达明暗，AppIcon 内联使用）；结构色（品牌 #0A8079、状态色、边框 #E6FBE8/14.12%、控件底色 C4 等）与软件品牌彩色（AE/Animate/PS/chrome/edge/火狐）保留原值不随 color。
>
> 2026-08-07 新图标入库（143 + 3 + 19），旧默认图标 79 个全部删除；新图标常用尺寸 18px（旧体系 16px 作废，尺寸档见 token 第 6 节）。
