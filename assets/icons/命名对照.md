# 图标命名对照（中文 ↔ 英文）

> 阶段七新图标体系（2026-08-28 入库 130 个）。源文件在 `docs/UI 重构/图标/`（保留中文原名，作设计侧底稿）；本目录文件名为英文 kebab-case。
>
> 旧 MVP 图标全部归档于 `assets/icons/旧版/`（旧对照表同在其中）。**2026-08-30（7.1 十七轮）起改为回退层机制（用户定）**：`icons.ts` 新库查无时落旧版同名 + console.warn 打标（过渡期限定——此前"负向排除不注册不打包、引用旧名即报图标不存在"的口径已解除）；面板轮逐件按稿接线、回退命中清零后回退层整层删除退役，届时旧版重回不注册不打包终态。**新写组件禁止引用旧图标名**（依赖回退层 = 错误信号）。
>
> 颜色约定（2026-08-28 定稿执行，用户确认规则）：**单灰线条图标**（#4D4D4D / #808080 等线条层）文件级批处理转 `currentColor`（明暗由 CSS color 档位表达）——首批已转 18 个（item 组件族所用：expand / chevron-small / close-small / more-small / more-large / add-small / add-large / link-small / play / pause / open-in-explorer / import / trash / uncategorized / recent / auto-import / library / thumbnail），二批 6 个（2026-08-29 按钮组件族所用：collapse-sidebar / set-cover / copy / set-prompt-file / workspace / ai-chat——set-prompt-file 原为 #BFBFBF 二级单灰，同一图标在 solid 稿二级 / 图标+文字稿三级两档复用，故一并转），三批 5 个（2026-08-29 卡片组件族所用：card-hover-play / card-hover-pause / card-hover-volume / card-hover-mute / linked-file-badge——04_卡片 单灰 #BFBFBF，常态二级 / hover 一级由 CSS color 驱动；original-file-badge 品牌色保留原值、folder-large 双色调走 TwoToneIcon 通道），四批 29 个（2026-08-29 悬浮栏组件族所用：search / filter / heading-1~6 / body-text / quote / list-unordered / list-ordered / task-list / table / code-block / code-inline / insert-link / divider / bold / italic / strikethrough / seek / step-frame / volume / mute / loop / note / fullscreen / angle-bracket——filter 原为 #F2F2F2@14% 半透明-2 烘焙值，转后由 CSS color 给 --n-l-a2 档），五批 1 个（2026-08-29 通知栏所用：check-small——原为 #F2F2F2 一级烘焙值，转后状态圆点内由 CSS color 给 --n-l1 档），其余随用随转；**双色调结构图标**（folder-closed / folder-open / archive / image / warning-small 等的 #BFBFBF 亮层 + #666666 暗层）**文件保留原值**，组件内用 `getTwoToneIcon()` 换 `--tone-1 / --tone-2` 变量通道（默认 自定义/常态-1/-2，文件夹九色自定义对覆盖）；**品牌彩色与状态色**（original-file-badge #0F89EC、waveform-deco #F2F2F2@14% 等）保留原值不动。
>
> 引用方式：`lib/icons.ts` 按**文件名干**注册（目录名不参与引用，同名干会互相覆盖，入库前查重），AppIcon / getIcon 按名引用；内联 SVG，不用 `<img>`。
