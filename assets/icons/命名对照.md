# 图标命名对照（中文 ↔ 英文）

> SVG 文件统一使用英文 kebab-case 命名（见 `docs/02_样式与布局/00_写法说明.md` 第 7 条）。新增图标用中文命名丢进来，由我批量转换并更新本表。
>
> 颜色约定：通用部分统一 `currentColor`（CSS 控制 color 变量），透明度烘在 SVG 属性里；文件夹卡片结构色用 CSS 变量 `var(--folder-card-back/front/file)`（换配色只改三个变量，**必须内联使用 SVG**，`<img>` 引入读不到页面变量）；品牌色（#1E83B5）为硬编码。
