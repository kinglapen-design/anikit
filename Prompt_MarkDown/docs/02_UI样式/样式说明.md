## 组件口径

- 无序列表：蓝色实心圆点（6px），不用默认 disc。
- 代码块：圆角 8 + 1px 描边；标题栏（▾ + 名称，13px 次要色）；行号右对齐、次要色 60% 透明。
- 引用块：左竖条 3px，整体次要色，不加底色。
- 表格：圆角 8 + 1px 外描边，表头浅底，单元格间 1px 内描边。
- 分割线：1px，上下 18px。
- 块级间距整体口径：段/列表 8px、引用/代码块/表格 12px、标题段后 8-10px（2026-10-18 用户反馈「空隙太大」后收紧一档）。
- 链接：强调色无下划线，hover 加深 + 下划线。
- 主题切换过渡 200ms；亮暗同构，仅换 token 值。
