## 踩坑（本轮三个，均自复）

1. **pnpm install 被父目录吞掉**：Prompt_MarkDown 位于 anikit_tauri 仓库内，pnpm 向上找到父 pnpm-workspace.yaml 后"已完成"不装本地依赖（vue-tsc 借父 node_modules 假绿）。立本地 `pnpm-workspace.yaml`（`packages: []`）为根标记后正常。
2. **规则链 select 后面板消失**：selectItem 先 dispatch 插文本、后 push 段落记录，dispatch 同步触发会话存活校验（期望光标 = 末段尾）必败 → 自杀。改为**先记段后 dispatch**；back() 同病（先 splice 后 dispatch）。
3. **自动化数字键假象**：CDP press_key 的 char 事件绕过 DOM preventDefault，数字选定后多插一个字面数字——自动化假象非应用 bug；数字键与鼠标同一 selectItem 入口，鼠标路径已验证。
