# P4_AI

> △逼仄简陋的厨房里，抽油烟机嗡嗡作响。
> △李静系着褪色的围裙，正握着铁勺小心翼翼地熬着稀粥；姜建军揉着酸痛的腰，在破餐桌旁帮姜玥整理书包。
> △雪牧推开卧室门走出，手里捏着一张抄着分数的便签纸。
> 李静（转头擦擦额汗，语气疼惜）：小牧起来啦？手腕怎么缠着纱布？是不是昨晚碰伤了？
> 姜建军（放下书包，神色紧张）：今天高考放榜吧？小牧，考得怎么样？钱这一块不用担心，姨父就算去工地多搬几车砖，也给你凑够学费！

# P4_用户

``` text
资产清单
角色清单：雪牧=@；季明谦=@、季明谦音频=@。
场景清单：雪牧卧室_正打=@；雪牧卧室_反打=@；季明谦的办公室=@。
道具清单：手机=@、手机来电显示=@。

空间关系
空间站位参考图=@（仅作为人物站位参考使用）；雪牧在自己的卧室里，坐在自己的书桌前。
季明谦再自己的办公室，坐在自己的办公桌前，背后是书柜。

剧情
清晨，今天是高考放榜日，季明谦得知雪牧拿了全省第一，兴奋的打电话来祝贺。

画风约束
皮克斯式高品质风格化3D卡通动画；御兽奇幻动画，色彩明亮且柔和，亮暗冷暖对比，亮部暖黄，暗部蓝紫；高斯镜头，高光柔和晕染，通过局部过曝来增强光感，柔和阴影；人物表演夸张且充满弹性，是动画表演逻辑。

光影设定
清晨的日光从窗外斜射入房间内。

时间线：8秒/3个镜头，镜头切换快。

镜头 1：[0-1.5秒]
- 景别：特写。
- 机位与运镜：手机正上方，俯拍手机；云台稳定，慢推镜头。
- 构图与景深：画面中央手机，手机屏幕上显示来电显示季明谦；背景是桌面。
- 表演和台词：手机铃声响起，屏幕弹出来电显示，手机震动位移，雪牧的左手入画抓起手机。
- 音效：来电铃声。

镜头 2：[1.5-4.5秒]
- 景别：近景→中景。
- 机位与运镜：雪牧左前方，平视，手持摄影晃动，固定→急拉镜头。
- 构图与景深：画面右侧近景是雪牧，面朝左侧；左手拿着手机将手机放在耳边，显示手机背面；中景是书柜和衣柜，远景是卧室房门。
- 表演和台词：一开始近景，固定镜头，雪牧左手抬起将手机放在耳边，季明谦兴奋的几乎咆哮的哭腔大喊（画外音）：“雪牧！市教育署、省御兽总会把学校门槛都踏破了！”，同时急拉镜头至中景，突如其来的巨大音量让雪牧下意识把手机从耳边挪开半米远，用夸张演出进步一强调声音的冲击力：手机旁边放漫画声音放射特效，听筒里传来的气浪仿佛一阵狂风，将雪牧的嘴唇被吹的外翻，漏出牙龈，嘴唇呈现波浪运动，头发被吹的往画面左侧一侧，呈现胡乱飞舞的感觉。

镜头 3：[4.5-7.5秒]
- 景别：特写→近景。
- 机位与运镜：季明谦右前方，平视，手持摄影晃动，固定→升镜头。
- 构图与景深：一开始是季明谦特写的左手，背景是办公桌桌面，随后升镜头为近景，画面左侧近景是季明谦，面朝画面右侧；右手拿着手机将手机放在耳边，显示手机背面；远景是书柜。
- 表演和台词：季明谦左手重重的砸在办公桌桌面，桌面上的钢笔被震动弹起，同时，季明谦依旧兴奋的近乎咆哮的哭腔继续大喊：“七百分！全省断层第一！”；随后，升镜头，拍摄季明谦面部近景，他眼角含泪，左手抬起擦了擦眼角的眼泪，右手拿着手机将手机放在耳边，继续兴奋到无以复加的大喊：“咱们一中这辈子没这么长脸过啊！”

镜头 4：[7.5-10秒]
- 景别：中景。
- 机位与运镜：雪牧左前方，平视，云台稳定，慢推镜头。
- 构图与景深：画面右侧近景是雪牧，面朝左侧；左手拿着手机；中景是书柜和衣柜，远景是卧室房门。
- 表演和台词：一开始，雪牧左手拿着手机，胳膊抬起伸直，将手机远离自己的耳朵半米远，雪牧抬起自己的右手揉了揉自己的左耳朵，然后放下右手搁在书桌桌面上，同时，左手重新将手机贴回自己的耳边，表情哭笑不得，额头一滴漫画汗珠特效流下，然后消失，雪牧哭笑不得的说：“王老师，淡定淡定，正常发挥而已！”

镜头 5：[10-12秒]
- 景别：近景。
- 机位与运镜：雪牧左前方，平视，云台稳定，慢推镜头。
- 构图与景深：画面右侧近景是雪牧，面朝左侧；左手拿着手机贴在耳边；中景是书柜和衣柜，远景是卧室房门。
- 表演和台词：雪牧右手抬起扶额，一副哭笑不得的表情，随后眼神左右躲闪，顾左右而言他的继续说：“先挂了哈，我给我小姨报个喜去！”

镜头 6：[12-14秒]
- 景别：特写。
- 机位与运镜：雪牧左前方，仰视，云台稳定，慢推镜头。
- 构图与景深：画面右侧近景是特写的雪牧左手拿着手机，手机背面面对镜头；中景是雪牧的胸腔。
- 表演和台词：雪牧放下左胳膊至胸腔高度，左手拿着手机上至下入画，随后挂断了电话。
- 音效：电话挂断音。

仅音效设计，禁止背景音乐，禁止出现字幕，台词完整，人声清晰。保持画面的表演与光影持续变化，禁止画面完全静止。
```
