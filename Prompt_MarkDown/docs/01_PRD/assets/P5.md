剧情
清晨，李静在厨房熬粥，姜建军在帮李玥整理书包，姜玥拿着勺子在喝粥。

画风约束
皮克斯式高品质风格化3D卡通动画；御兽奇幻动画，色彩明亮且柔和，亮暗冷暖对比，亮部暖黄，暗部蓝紫；高斯镜头，高光柔和晕染，通过局部过曝来增强光感，柔和阴影；人物表演夸张且充满弹性，是动画表演逻辑。

光影设定
清晨的自然光从东侧的窗户斜射入客厅。

时间线：4秒/2个镜头，镜头切换快。

镜头 1：[0-1.5秒]
- 景别：特写。
- 机位与运镜：铝锅正上方，俯拍，云台稳定，慢推镜头。
- 构图与景深：画面偏左是铝锅，铝锅里熬着粥，画面右侧是李静的右手拿着锅铲，背景是燃气灶。
- 表演和台词：李静拿着锅铲在轻轻的搅动着铝锅里熬的粥。
- 音效：锅里的粥翻滚的咕噜声。

镜头 2：[1.5-4秒]
- 景别：全景。
- 机位与运镜：摄影机位于餐桌一侧、姜建军的正对侧处，平视，云台稳定，慢右移镜头。
- 构图与景深：画面前景是餐桌桌面，右侧中近景是姜玥的左正侧面，李玥面前的餐桌放着碗；画面左侧中景是姜建军的正面，书包放在他面前的餐桌上；越肩穿过姜建军和姜玥，画面中间远景处是位于厨房的李静，她背对着镜头站在灶台前。
- 表演和台词：江玥拿着勺子在喝粥，姜建军将桌面上的小学课本整理放进书包，远处的李静还在熬粥。
- 音效：窗外清晨鸟儿的声音。

仅音效设计，禁止背景音乐，禁止出现字幕，台词完整，人声清晰。保持画面的表演与光影持续变化，禁止画面完全静止。
