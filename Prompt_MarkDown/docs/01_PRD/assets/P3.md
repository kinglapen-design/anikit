角色清单：雪牧=@、雪牧音频=@；

空间站位参考图=@（仅作为人物站位参考使用）；雪牧在自己的卧室里，坐在自己的书桌前，平板电脑放在书桌上，屏幕正对雪牧。

剧情
清晨，今天是高考放榜日，雪牧将平板电脑拉到自己面前，挂断同学电话后，开始查询自己的成绩。

画风约束
皮克斯式高品质风格化3D卡通动画；御兽奇幻动画，色彩明亮且柔和，亮暗冷暖对比，亮部暖黄，暗部蓝紫；高斯镜头，高光柔和晕染，通过局部过曝来增强光感，柔和阴影；人物表演夸张且充满弹性，是动画表演逻辑。

光影设定
清晨的日光从窗外斜射入房间内。

时间线：11秒/[待填]个镜头，镜头切换快。

镜头 1：[0-1秒]
- 景别：特写。
- 机位与运镜：平板电脑，向左倾斜构图，俯拍，手持摄影，跟镜头。
- 构图与景深：画面右侧是平板电脑，背景是书桌桌面。
- 表演和台词：雪牧的右手从画面左侧如画，抓住平板电脑的边缘，朝画面左侧拉动。

镜头 2：[1-3秒]
- 景别：中景。
- 机位与运镜：雪牧左前方，仰拍，云台稳定，慢右移镜头。
- 构图与景深：画面左侧前景是平板电脑的背面和书桌桌面，画面偏右侧中景是雪牧，远景是书桌和卧室大门；焦点先锁定平板电脑，在变焦至雪牧。
- 表演和台词：雪牧的右手从画面左侧将平板电脑右拉至自己的面前，同时，他拿手机的左手从耳边放下，同时挂断了电话，放在画面右侧的桌面上，然后右手在平板电脑上快速的点击。
- 音效：挂断电话音效。

镜头 3：[3-5秒]
- 景别：特写。
- 机位与运镜：平板电脑右前方，俯拍，云台稳定，慢推镜头。
- 构图与景深：画面中央是平板电脑，平板电脑屏幕上显示的文字=@，背景是书桌桌面。
- 表演和台词：一张成绩单在平板电脑里弹出，雪牧的略微惊讶的画外音响起：“嚯~，文武总分七百，”。
- 音效：弹出成绩单的音效。

镜头 4：[5-7秒]
- 景别：近景。
- 机位与运镜：雪牧左前方，微俯拍，云台稳定，慢右移镜头。
- 构图与景深：画面偏右侧近景是雪牧，他面朝画面左侧，远景是书桌和卧室大门。
- 表演和台词：雪牧耸了耸肩，然后双手抱在胸前，嘴角歪向一侧，同时笑着继续说：“老师还真就多一分不叩呀。”

仅音效设计，禁止背景音乐，禁止出现字幕，台词完整，人声清晰。保持画面的表演与光影持续变化，禁止画面完全静止。
