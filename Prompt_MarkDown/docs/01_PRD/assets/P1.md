
# P1_AI

> △破旧窗台上，手机屏幕疯狂闪烁，星辰激动的声音几乎穿透听筒。
> 星辰（电话音，尖叫失声）：雪牧！别睡了！快去查分！你看没看全省大榜？！
> 雪牧（揉着太阳穴打哈欠，懒洋洋笑道）：大小姐，一大早拆迁呢？高考大榜又不长腿，还能跑了不成？

``` text
资产清单
角色清单：雪牧=@、雪牧音频=@；星辰=@、星辰音频=@。
场景清单：雪牧卧室_正打=@；雪牧卧室_反打=@；星辰卧室=@。
道具清单：雪牧的老旧手机=@、雪牧手机的来电提醒=@；星辰的兔耳朵手机壳装饰手机=@。

空间关系
雪牧卧室空间站位参考图=@（仅作为人物站位参考使用）；雪牧在自己的卧室里，坐在自己的书桌前，书桌上放着手机和平板电脑。
星辰卧室空间站位参考图=@（仅作为人物站位参考使用）；星辰在自己的卧室内，坐在床沿，面朝书桌方向。

剧情
清晨，今天是高考放榜，雪牧的手机响起铃声，他接起电话，是星辰的来电，星辰兴奋的尖叫声传来，提醒雪牧快点去高考大榜。

画风约束
皮克斯式高品质风格化3D卡通动画；御兽奇幻动画，色彩明亮且柔和，亮暗冷暖对比，亮部暖黄，暗部蓝紫；高斯镜头，高光柔和晕染，通过局部过曝来增强光感，柔和阴影；人物表演夸张且充满弹性，是动画表演逻辑。

光影设定
清晨的日光从窗外斜射入房间内。

时间线：11秒/5个镜头，镜头切换快。

镜头 1：[0-1.5秒]
- 景别：近景。
- 机位与运镜：雪牧左前方，微仰拍，云台稳定，慢推镜头。
- 构图与景深：画面右侧近景是雪牧，面朝左侧；手机在雪牧手上，显示手机背面；中景是书柜和衣柜，远景是卧室房门。
- 表演和台词：雪牧双手拿着手机在打字，突然铃声响起，雪牧身体微弹，被突入起来的铃声弄得微微一愣，眼睛微略睁大，嘴巴微张。
- 音效：打字音效和来电铃声。

硬切至下一镜；

镜头 2：[1.5-2.5秒]
- 景别：特写。
- 机位与运镜：主观视角，俯拍手机；云台稳定，慢推镜头。
- 构图与景深：画面中央是雪牧双手握着手机，手机屏幕上显示来电显示星辰；背景是桌面。
- 表演和台词：手机屏幕上的接听键在跳动，雪牧右手大拇指按下接听。
- 音效：来电铃声。

镜头 3：[2.5-4.5秒]
- 景别：近景→中景。
- 机位与运镜：雪牧左前方，平视，手持摄影晃动，固定→急拉镜头。
- 构图与景深：画面右侧近景是雪牧，面朝左侧；左手拿着手机将手机放在耳边，显示手机背面；中景是书柜和衣柜，远景是卧室房门。
- 表演和台词：一开始近景，固定镜头，雪牧左手抬起将手机放在耳边，星辰的尖锐且极度高亢的声音从手机里传来（画外音）：“雪牧！别睡了！”，同时急拉镜头至中景，突如其来的巨大音量让雪牧下意识把手机挪远了半米，用夸张演出进步一强调声音的冲击力：手机旁边放漫画声音放射特效，听筒里传来的气浪仿佛一阵狂风，将雪牧的嘴唇被吹的外翻，漏出牙龈，嘴唇呈现波浪运动，头发被吹的往画面左侧一侧，呈现胡乱飞舞的感觉。
- 音效：来电铃声。

镜头 4：[4.5-6.5秒]
- 景别：中景。
- 机位与运镜：星辰右前方，平视，手持摄影晃动，跟随跳动；
- 构图与景深：画面左侧近景是星辰，面朝右侧；右手拿着手机将手机放在耳边，显示手的背面，远景是衣柜、房门和梳妆台。
- 表演和台词：星辰左手握拳放在胸前，激动的上下颠了两下，头发跟随运动，表情十分的开心且俏皮，星辰继续兴奋的高喊：“快去查分！你看没看全省大榜？！”

镜头 5：[6.5-8秒]
- 景别：特写。
- 机位与运镜：雪牧左前方，微仰拍，云台稳定，慢推镜头。
- 构图与景深：画面右侧近景是雪牧，面朝左侧；左手拿着手机将手机放在耳边，显示手机背面；中景是书柜和衣柜，远景是卧室房门。
- 表演和台词：雪牧汗颜的右手扶额，轻轻摇了摇头，雪牧苦笑道：“大小姐，一大早拆迁呢？”

镜头 5：[8-11秒]
- 景别：中景。
- 机位与运镜：雪牧左前方，微仰拍，云台稳定，慢推镜头。
- 构图与景深：画面右侧近景是雪牧，面朝左侧；左手拿着手机将手机放在耳边，显示手机背面；中景是书柜和衣柜，远景是卧室房门。
- 表演和台词：雪牧耷拉着眉毛苦笑，耸了耸肩，右手摊了摊，雪牧继续苦笑道：“高考大榜又不长腿，还能跑了不成？”

仅音效设计，禁止背景音乐，禁止出现字幕，台词完整，人声清晰。保持画面的表演与光影持续变化，禁止画面完全静止。
```
