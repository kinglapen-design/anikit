剧情
清晨，今天高考放榜日，雪牧拿着成绩便签走出房门，李静和姜建军关心的询问雪牧，雪牧笑嘻的走到餐桌前桌下，将成绩单放在餐桌上。

画风约束
皮克斯式高品质风格化3D卡通动画；御兽奇幻动画，色彩明亮且柔和，亮暗冷暖对比，亮部暖黄，暗部蓝紫；高斯镜头，高光柔和晕染，通过局部过曝来增强光感，柔和阴影；人物表演夸张且充满弹性，是动画表演逻辑。

光影设定
清晨的自然光从东侧的窗户斜射入客厅。

时间线：8秒/[待填]个镜头，镜头切换快。

- 景别：中远景。
- 机位与运镜：摄影机位于过道，拍摄厨房入口一侧，平时，云台稳定，慢推镜头。
- 构图与景深：画面左侧是纵深的墙壁和储物柜，画面中景厨房入口处的李静，背景是窗户。
- 表演和台词：李静从画面左侧墙壁后看不见的厨房里朝右侧走出来，看向镜头，手里还拿着锅铲，眯起眼睛，慈祥的微笑，李静慈祥的说：“小牧起来啦？”；

镜头 3：[2.5-3.8秒]
- 景别：近景。
- 机位与运镜：雪牧正前方，平视，云台稳定，降镜头。
- 构图与景深：一开始是雪牧胸腔近景，降镜头至雪牧包着纱布的右胳膊近景，画面远景右侧是玄关雪柜和挂钩，远景左侧是大门。
- 表演和台词：雪牧表情开心，李静心疼的画外音响起：“手腕怎么缠着纱布？”

镜头 4：[3.8-5秒]
- 景别：近景。
- 机位与运镜：李静左前方，平视，云台稳定，慢推镜头。
- 构图与景深：画面右侧近景是李静，她面朝画面左侧，远景是厨房柜台。
- 表演和台词：李静眉头耷拉，满脸的关心，心疼的继续说：“是不是昨晚碰伤了？”

镜头 5：[5-7秒]
- 景别：中景。
- 机位与运镜：姜建军正前方，平视，云台稳定，慢推镜头。

- 表演和台词：姜建军放下手里的书包，随后靠在椅子后背上，看向画面左侧，神色紧张，姜建军舔了舔干涉的嘴唇，紧张的试探询问：“今天高考放榜吧？小牧，考得怎么样？”

- 构图与景深：画面中央近景是雪牧，画面远景右侧是玄关雪柜和挂钩，远景左侧是大门；焦点锁点雪牧，浅景深。

镜头 8：[10-11秒]
- 景别：近景。
