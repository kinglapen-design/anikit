# UI 重构工作规范（阶段七 · 样式定稿）

## 1. 设计稿入口（路口）

设计源只有一处：`docs/UI 重构/`

- `Design Token/Token.md` —— 总 token（颜色 / 字体 / 效果 / 圆角 / 间距 / 动画），一切数值的唯一源头；`src/styles/tokens.css` 随重构以它为准逐步重建
- `Design Token/布局/` —— 窗口 / 面板的容器结构与数值
- `Design Token/组件/` —— 零件级样式（常态写全、状态只写差异）
- `图标/` —— 新图标中文名源文件，待入库
- 各稿子目录内的 `assets/` —— 设计截图，还原质量的比对基准

配套约束（新设计稿未覆盖时照旧有效）：

- `docs/02_样式与布局/03_新面板口径速查.md` —— 弹窗 / 滚轮 / 列表 item / 重命名 / 透明度的已定口径，动手前通读
- `docs/02_样式与布局/00_写法说明.md` —— 写法约定与术语词典
- `assets/icons/命名对照.md` —— 图标中英文对照表

## 3. 会话开始流程（缺样式先问，齐了才动手）

1. 读本次任务相关的设计稿 md + `Token.md` 对应章节；
2. 对照 `src/styles/tokens.css`、`src/components/` 现状；
3. 缺什么列清单，一次列全找用户提供：
   - 设计稿没写的数值 / 状态（hover、选中、禁用、焦点……）
   - 缺 token（新颜色档、新字档、新圆角……）
   - 缺组件（设计稿有、代码没有）
   - 缺图标（对照表查无此项）
4. 拿不准的一律停下来问用户，**一次只问一个**；没有 token 或设计参照的部分禁止凭感觉自创样式（红线）。

## 4. 已定口径（跨会话通用）

- 1px 线：一律 border 或零模糊 box-shadow（同渲染路径、吸附设备像素），**禁止 `height:1px` 背景块当线**（走抗锯齿路径必糊）。
- 菜单 / 列表的分割：消灭独立分割线元素——组容器挂 `box-shadow: 0 1px 0`，父容器 `gap:1px` 让阴影有落点。
- 间距一律 padding + gap，不用 margin（`00_写法说明.md` 第 6 节）。
- 描边一律 inside、不占空间，工程用 inset box-shadow / `::after`（`00_写法说明.md` 第 8 节）。
- **动画要主动做，不等用户提醒**（2026-08-31 用户原话「为啥每次都不主动去做动画效果」）：稿 prose 提到展开 / 切换 / 滑入 / 伸缩等动效字样的必须同轮落地；稿未给数值时优先套既有范例与 token 档（侧栏分段切换 = 退 150ms 缓出 + 入 250ms 缓入 delay 100ms 位移 48px；树节点展开 = `lib/expandAnim.ts` 150ms；分段滑块 300ms；hover 150ms），稿有 prose 无数值可就近套用后标注，拿不准再问——**禁止静默省略动画直接交付瞬时切换**。
- **图标入库必转 currentColor 时核对线条层色值**（同日走查坑：basic-info / link-relations / prompt 漏转，figma 烘焙稿中状态色 → 选中态 CSS color 驱动失效；错误信号 = 选中/未选中图标色不随态变）。

## 5. 图标入库

- 流向：`docs/UI 重构/图标/`（中文命名，保留作设计底稿）→ 复制入 `assets/icons/`，文件名英文 kebab-case；
- 每入库一个，同步登记 `assets/icons/命名对照.md`（中文 ↔ 文件名）；
- `assets/icons/旧版/` = MVP 旧图标归档，`src/lib/icons.ts` glob 已负向排除（不注册不打包），勿往其中加新图；
- 引用按**文件名干**（目录名不参与），同名干互相覆盖——入库前全库查重（旧版除外）；
- 线条层转 `currentColor`、结构色与品牌彩色保留原值（约定见 `00_写法说明.md` 第 7 节与命名对照.md 头部）；图标内联使用，不用 `<img>`。

## 6. 组件复用（优先级从高到低）

1. 已有组件直接用（先 Glob / Grep 查 `src/components/` 再动手）；
2. 差点意思 → 扩展（props / 插槽 / 变体），不新建相似组件；
3. 实在满足不了才新建，并同次更新设计系统预览页。

禁令：

- 页面里不重复堆叠样式——同样式出现第二次就要抽象成组件或通用类；
- 不硬编码：颜色 / 字号 / 行高 / 间距 / 圆角 / 阴影 / 动画时长一律走 token 变量；`Token.md` 里没有的数值先问用户补 token，不自创；
- UI 文件不写业务逻辑，功能一律抽象为命令接口（`docs/01_开发规范.md` 第 1 条）。

## 7. 设计系统预览页

- 仅开发环境可见（`import.meta.env.DEV` 门控），不进生产构建；纯前端渲染，不调后端命令；
- 位置约定：`src/preview/`，入口组件 `DesignSystemPreview.vue`；
- 内容：`Token.md` 全部 token（色板 / 字阶 / 效果 / 圆角 / 间距 / 动画）+ 所有已封装组件及其状态（常态 / hover / 选中 / 禁用），能放尽放；
- 任何组件新增 / 扩展 / 改样式，同次提交内更新预览页——它是复用效果与还原质量的验收面。
