## 007 无边框窗口装饰四轮探索，终局为不透明 + 原生 DWM

- **现象：** 无边框窗口要阴影 / 圆角 / 1px 线框 / resize 判定，四轮方案全部翻过车：① window-shadows crate（1px 直角线框 + rwh 版本分裂）；② tauri `shadow: true` + DWM 抑制（主题边框 / DWM 圆角 / 顶边线 / 圆角外底色块，抑制不尽）；③ 全透明 + CSS 圆角阴影（当时判为终局）；④ 原生方案。
- **方案③ 同样翻车（用户实测四宗罪）：** inset 线框被三栏贴边背景遮住看不见；resize 判定双区域（阴影边缘 + 窗口边缘）；blur 40 超出 20px 阴影带被物理边缘裁成硬边；阴影带 20px 无法穿透点击到下层软件。
- **终局解法：** `transparent: false` + `shadow: true`（tao undecorated shadow）——Win11 DWM 圆角 8px 恰与设计一致、DWM 原生阴影（无硬边无阴影带）、resize 判定统一在物理 = 可视边缘（tao 只给顶边，四边用 `startResizeDragging` 热区补足）；mac 系统圆角 + 系统阴影；Win10 直角接受；线框用 `DWMWA_BORDER_COLOR` ≈ C4-15 合成色（Win11+）。
- **预防：** 桌面应用的窗口装饰（圆角 / 阴影 / 边框）优先用系统原生能力并按平台接受差异（Win11 8px / mac 系统 / Win10 直角），不要为追求跨平台像素一致去自绘——透明分层窗口与 DWM 的交互全是边角问题。
