## 022 窗口几何持久化把"最小化态"写回：启动恢复成一小块

- **现象：** 软件窗口只剩一小块（422×313 甚至更小），重启也恢复不回去。
- **原因：** Windows 最小化窗口报告坐标 (-32000,-32000) 与退化尺寸（实测 237×39）；窗口几何持久化（resize/move 防抖写回 config settings.window）未做任何守卫，最小化 / 隐藏托盘途中的 onMoved/onResized 把坏值写进配置，启动恢复即成小窗（恢复侧下限 400×300 形同虚设）。
- **解法：** 写回三道守卫——isMinimized 不写、尺寸 <800×500 不写、坐标 <-10000 不写；恢复下限提为 800×500；用户 config 里的坏几何直接移除（恢复默认尺寸居中）。
- **预防：** 一切持久化"系统可能给出退化值"的状态（窗口几何 / 显示器拓扑 / 输入设备），写入前必须校验合理性（最小尺寸 / 坐标域 / 枚举白名单），恢复侧再兜一层 clamp——写、读两端都不可信。
