## 030 状态切换用 v-if 摘挂内容：空 flex 容器基线漂移，弹窗整体跳 1px

- **现象：** 复选框勾选 / 取消时，所在弹窗全部内容（标题、按钮）微微上移 / 下移 1px，像窗口抖了一下；删除资源库确认窗的"同时删除素材文件"复选框必现。
- **原因：** 对勾图标用 `v-if` 摘挂——未选中时 `.box` 从"有内容的 flex 容器"变"空 flex 容器"，CSS 基线推导规则不同（空 flex 容器基线 = 底缘，有内容 = 内容基线），按钮在 `.desc` 行盒中的占位高度差出 1px，模态框垂直居中重排，全内容跟着跳。视频帧逐像素比对实证：未选中帧 = 选中帧整体上移 1px（dy=-1 完全重合）。讽刺的是组件注释本就写着"对勾透明度过渡"，`v-if` 让这条 transition 从未生效。
- **解法：** 对勾常驻 DOM，`:class="{ off: !model }"` 切 opacity——两态 DOM 结构完全一致，布局与基线零变化。
- **预防：** **状态切换只改样式、不摘挂 DOM**——凡 `v-if` 用在"纯显隐、占位固定"的装饰性元素上（图标 / 角标 / 对勾），都要警惕它同时改变了父容器的基线 / 尺寸推导；显隐用 opacity / visibility / transform。检查方法：切换状态前后各取一次 `getBoundingClientRect()` 比对，任何像素差都是布局抖动。
