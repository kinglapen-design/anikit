## 065 伪元素当背景层必须沉底：absolute 无 z-index = 层叠第 6 层盖正常流内容（2026-08-31）

- **现象：** 7.1 二十三轮走查——右栏 g1 底色改 `::before` 只画顶行以下后，用户实机报封面编辑「更换封面 / 取消 / 确认」与底部「信息查看管理」钮**看不到但能盲点**（点「更换封面」位置菜单能弹出）。
- **根因：** `::before { position: absolute }` 无 z-index → CSS 层叠第 6 层（z-index auto 定位元素档），绘制在正常流内容（第 3/5 层）之上 → 右栏所有无定位元素被 g1 伪元素盖住；`pointer-events: none` 让 hit 测试穿透 → 「能点不能看」。带 position 的元素（relative 的封面框 / 输入框 / 分段控制器 / tab 滚动区）同第 6 层且 DOM 序在后，侥幸可见——现象呈「部分元素消失」，极具迷惑性。
- **修法：** aside 加 `isolation: isolate`（自建层叠上下文，不依赖外层上下文状态）+ `::before` 加 `z-index: -1`（沉到正常流之下）。
- **预防：** ① 伪元素当背景层 = `isolation: isolate` + `z-index: -1` 配套写，别只写 absolute；② **computed 样式与几何断言测不出层叠遮挡**——元素在、尺寸对、就是被盖；改背景层/层叠结构后必须截图目验关键交互件（按钮！），探针 R13c 封面编辑态截图 + R4c2 沉底断言钉死。
