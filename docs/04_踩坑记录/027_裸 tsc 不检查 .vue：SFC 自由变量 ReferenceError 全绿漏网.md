## 027 裸 tsc 不检查 .vue：SFC 自由变量 ReferenceError 全绿漏网

- **现象：** 给 AssetGrid 加激活闸时引用了只存在于 ContentArea 的 `active` 变量，`pnpm tsc --noEmit` 与 `pnpm build` 双双全绿；运行时空格预览彻底失效（每次按键监听器内抛 ReferenceError）。
- **原因：** `pnpm tsc` 调的是裸 `tsc`——只检查 `.ts/.tsx`，**`.vue` 文件的 script setup 完全不查**；vite/rolldown 编译 SFC 只做转译不做类型检查。于是 .vue 里的未定义变量、类型错误在"tsc / build 全绿"下全部漏网，只能运行时暴露。
- **解法：** 本例修复 = 激活态由 ContentArea 以 `panelActive` prop 显式传给 AssetGrid（AssetGrid 拿不到 panelApi / panel id）。
- **预防：** ① 跨组件搬代码时警惕"目标文件没有该变量"——.vue 没有编译器兜底；② **"tsc/build 全绿"不等于 .vue 无类型错**，SFC 关键改动（尤其新引用变量）要在 dev 里实际点一遍对应交互；③ 待评估引入 `vue-tsc` 补盲（记 09 待办，涉及依赖与脚本变更）。
