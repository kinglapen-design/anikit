## 015 视觉类目检用合成样本：口径缺陷被掩盖

- **现象：** 音频波形渲染迭代十几轮，用 ffmpeg 合成的 8 秒噪声样本目检一直"通过"，用户真实 3 秒配音文件却整体发淡、峰值无辨识度。
- **原因：** 渐变叠加机制的效果强依赖"文件时长 / 窗口数"比例——长文件每窗口样本多、纵线长且重叠，合成样本看着正常；用户短文件每窗口仅 ~2 样本，纵线短且散，叠不出实心主体。合成样本的统计特性与真实素材完全不同。
- **解法：** 取用户参考版音频本体跑候选算法**逐像素比对**（`tools/waveform-match.py`），匹配度 95%+ 才定稿；不再凭合成样本目检下结论。
- **预防：** 视觉 / 渲染类功能验收，样本必须用用户真实文件（覆盖最短 / 最长 / 最静 / 最响两端），合成样本只能做逻辑单测，不能做观感目检（呼应 012 "新格式接入先用用户真实样本验证"）。
