# 085 CSS :has() 里写组件类名——组件类名一改选择器静默失联，展开钮「DOM 在但不可见」（2026-09-23）

## 现象

用户实机报「展开侧边栏的按钮怎么没了」：左栏收起后，标签行首的展开钮（SidebarExpandButton）不出现。DOM 里按钮实际已渲染（`ic-btn plain lg flip-h` 在 `.dv-pre-actions-container` 内），颜色 computed 正常（亮色/三级 + svg stroke=currentColor），但整格零宽零高不可见。

## 原因

`src/styles/dockview-theme.css` 的显隐规则 `:not(:has(.icon-btn)) { display: none }` 写的是 **1.2 时代的组件类名** `icon-btn`；阶段七 7.1 七轮按钮族封装（aa35652a）把 IconButton 根类改成 `ic-btn` 后，`:has(.icon-btn)` 永远不匹配 → 容器恒 `display:none` → 按钮在 DOM 里渲染但不可见。断链无声无息：样式表不报错、组件不报错、DOM 断言（按钮存在）还能 PASS，只有几何 / 截图能抓到。

## 解法

- 显隐探测改元素选择器：`:not(:has(button))` / `:has(button)`——pre-actions 容器只驻留展开钮一个组件，元素级探测免疫类名漂移。
- 同文件另两条 `.icon-btn` 残留（左 actions + 钮色档）与 PreviewTitleBar 的 `:deep(.icon-btn)` 一并清/改——色档已由 IconButton plain 自带（l3 / hover l2 + l-a3），规则属冗余死代码。
- 探针钉回归：`tools/cdp-sidebar-expand-probe.py`（E1-E4：无钮不占位 / 收起 / **展开钮 display:flex + 钮 30×30 + svg 18 几何断言** / 点展开钮还原）+ 截图目验。

## 预防

- **CSS 选择器跨文件引用组件类名是高危写法**——组件改类名时样式表零报错静默失效。容器「有内容才显」类探测优先用元素选择器（`button` / `svg` / `img`）或容器自有数据属性，不引用组件内部类名。
- 「DOM 在但不可见」排查顺序：先 `getComputedStyle` 的 **display / visibility / opacity**，再几何（getBoundingClientRect），最后才查颜色——本坑颜色全程正常，病根在 display。
- SVGElement 没有 `offsetWidth/offsetHeight`（HTMLElement 才有），探针量 svg 几何必须走 `getBoundingClientRect()`。
- 过程附坑：文档文件名含 ASCII 冒号（`:has()`）→ NTFS 把冒号后当 ADS 流名，落盘真名截断成 `085_CSS `（带尾空格），git add 直接炸（error 123/2 连环）；**文档文件名禁用 ASCII 冒号与空格**（本库惯例：分隔用「-」，括注用中文（））。尾空格文件删除链：cmd del / PowerShell Remove-Item / .NET File.Delete / ctypes DeleteFileW·MoveFileW 全被拒（路径 normalize 或非法字符），**Git Bash `rm` 直删成功**（MSYS 运行时不吃尾空格）。
