# 094 Win11 25H2 窗口双杀：DWM 默认边框停画 + 浅色主题云母变白——显式染边框 + 锁窗口深色主题（2026-09-29）

- **现象：** 用户实机两连报。①主窗口边框线没了（Win11 25H2 26200 深色主题下圆角在、四边无线）；②朋友同版 25H2 机器整个窗口「回退成白色」而非保底深灰，但朋友的 Codex 云母正常——用户随后自测：切 Windows 浅色主题，本机同样变白。
- **原因：**
  - **边框**：25H2 起 DWM 默认边框（`DWMWA_COLOR_NONE`，2026-09-06 六轮定的「交 DWM 默认半透明」口径）**不再绘制**——实机剖线实证：默认态窗外→窗内像素直接突变无过渡列，而 `DwmSetWindowAttribute(DWMWA_BORDER_COLOR, 红)` 立即画出 2 物理 px 红线（150% 缩放），机制完好、只是默认色不画。063 当时「COLOR_NONE 抑制在本机 25H2 未达预期观感」的伏笔即此。
  - **变白**：并非 Mica 调用失败（`SYSTEMBACKDROP_TYPE=2` 设上了），而是**窗口主题默认跟随系统**——浅色主题下 tao 把窗口 `USE_IMMERSIVE_DARK_MODE` 置 0 → Mica 浅色变体 ≈ 白底，经 `fx-mica` 全透明的 `.window` 透出；应用无浅色 UI 适配，深色文字 token 浮在白底上观感崩塌。「保底深灰 --n-g-a1-solid」只在后端 build<22621 / set_effects 失败时报 solid 才画，浅色云母这条路径够不着。
- **解法：**
  - 边框 = 回到显式染色（同 0830 方案）：新增 `window_fx::paint_border`（`BORDER_COLOR = 0x00333333` = --n-g6 #333，与实色模式前端自绘同色），主窗口启动染一次（lib.rs，`extend_frame` 旁）、预览/插件子窗口建窗同染；`set_main_border_picking` 常态恢复分支从 `COLOR_NONE` 改染回 #333。
  - 主题 = 锁深色：主窗口 `tauri.conf` `theme:"Dark"` + 子窗口 `WebviewWindowBuilder.theme(Some(Theme::Dark))`。tao `update_theme` 对 `preferred_theme.is_some()` 的窗口在 `WM_SETTINGCHANGE` 直接 return 不跟随（tao-0.35.3 源码实证），Mica 恒深色变体、DWM 退化实底也恒深色。
- **预防：** ①DWM「默认」行为（默认边框、默认主题跟随）随 Windows 版本漂移，窗口装饰关键项一律**显式设置、不依赖默认**；②排障 DWM 层问题先分「机制坏 / 默认色变」——显式染色试出红线即可证明画框机制完好，锁定默认值失效；③云母/实色之外还有「Mica 浅色变体」第三态，接云母的窗口必须显式声明主题。
