# 降级吞错与跨空间视口重放——幽灵目录冒充空目录（2026-10-02）

## 现象

空工作空间里「添加链接文件夹…」选中一个明明存在的外部目录，toast 报「目标目录不存在」；标签页标题还停在库式浏览过的文件夹名（05_分镜），视口空空如也看似正常空目录。链接功能实机走查首日即报（2026-10-02，录屏）。

## 原因

双因合璧，缺一不可：

1. **持久化视口跨空间未校验重放**：`ui.lastWsView` 是全局停留视口记忆（2026-09-19 定，App.vue 按 `ws:` 前缀归桶持续记录），但它**跨空间共享**——甲空间浏览过的 ws 目录被记下，`SidebarLeft onModeChange` 切 workspace 时不校验存活直接 `openView(lastWsView)` 重放，在乙空间（空工作空间）即成「幽灵视口」：一个根本不存在的目录视图。标签恢复、运行期外部删除当前目录同病。
2. **接口降级吞错**：`list_workspace_dir` 彼时把列举失败（目录缺失 / 越界）一律降级成 `Ok([])`——「目录没了」与「空目录」对前端不可分，幽灵得以冒充空目录长久存活：空视口看似正常、标题停在幽灵名、右键写操作全部落在幽灵路径上。

报错文案再补一刀：落点缺失报「目标目录不存在」，而用户刚选完链接**目标**——「目标」一词在多对象流程里必被误读。

## 解法

三件套：`list_workspace_dir` 列举失败 **Err 原样上抛**（仅未开空间 / 根缺失保留暂态降级）→ 前端 ws store `loadDir` catch 置 `missing[rel]`（成功清除）→ App.vue watch 当前视口 missing 即 `tabs.openView` 回退父级，连环回退直至根（根缺失时 `openView` 同视口早退不成环，`root.exists` 空态接管）。落点报错改「挂载落点目录不存在：{rel}」写明「落点」。

## 预防

- **持久化的视口 / 路径类配置，重放前必须校验存活**——尤其跨空间 / 跨项目共享的记忆位（lastWsView 教训）；校验不了的，消费端要有自愈回退路（missing → 回退祖先）。
- **接口降级吞错要分「暂态」与「状态」**：启动未就绪（未开空间 / 根缺失）可降级；缺失 / 越界这类**状态事实**必须上抛——「没了」冒充「空」必然养出幽灵态，且越藏越深。
- **多对象流程的错误文案禁用裸「目标」一词**——落点 / 选中目标 / 源 必须带定语（本次用户即把落点缺失读成链接目标缺失）。
