# alt+` 呼出改最上层判定（2026-09-08，feat/new-ui，实机走查第一批第 19 条）

：alt+` 呼出逻辑仍有洞——最小化场景 2026-09-02 已修，但多数时候窗口没最小化、只是被其他 APP 遮挡在后，按键未按预期呼出。**根因** = 旧判定 `visible && focused && !minimized` 用 `is_focused()` 近似"在前台"——被遮挡但未失焦（focused 仍 true）时误走 hide 把窗口收进托盘，与呼出预期相反。**修法**（`lib.rs`）：新 `is_main_foreground()` = Win32 `GetForegroundWindow()` 比对主窗口 HWND（windows crate 已在依赖，零新依赖；非 Windows / 取句柄失败回退 is_focused）。判定改：可见 && 最上层 && 未最小化 → hide（toggle 语义不变），其余一律 `show_main_window` 呼出到最上层。托盘 / 单实例唤醒路径不受影响。cargo test 446 绿 / clippy 净。**交实机复验：被遮挡未最小化时按 alt+` 直接提到最上层，不再误收托盘**。接口文档 17_预览/12_主窗口显隐事件 同步。
