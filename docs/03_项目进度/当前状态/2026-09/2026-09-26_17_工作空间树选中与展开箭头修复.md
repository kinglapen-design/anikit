- **选中链（问题 1，查实非 _12~_16 回归）**：ws 文件夹卡片自 2026-09-17 进网格轮（020e6fd2）起就没接选择体系——FolderStrip `isWs` 早退闸是步骤 2 写操作未落地期的暂缓，当日落地后遗留成缺口。用户说的「蓝色边框」= 卡片族 `.kc-sel` 2px 品牌选中环（树选中无描边 = 速查 §41 已定口径，树行当前目录灰底本就正常）。修法 = ws 文件夹进**素材选择域**（clickItem，键形 `ws:{rel}|ws:{所在目录rel}` 同文件卡；ws 写操作全按路径混合受理，不进库文件夹域免得逐处加守卫）：卡片点击蓝框 + Ctrl/Shift 三态（clickItem 补可选 order 参）+ 右键未选中先单选 + wsFolderSpec 批量分流（复制/剪切/删除 N 项、重命名单项）+ F2 文件夹键路由 namingFolderCardId（仅当前视口条带内）+ 树行 plain click 入域（FolderTree 同口径 nextTick + 守卫）+ 行 domain-selected 联动 + 详情面板文件夹形态（WsDetail：类型 = 文件夹、名称不去后缀、size/日期恒 0 不出行）；selection store = selectedRefs 对 ws: 文件夹键兜底合成 + prune 存活键补目录条目。偏离库侧一处记档：ws 文件 + 文件夹可混选（单域 Explorer 式），库侧两域互斥。
