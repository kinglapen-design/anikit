# 窗口双杀修复：25H2 边框停画 + 浅色主题云母变白（2026-09-29，feat/new-ui）

用户实机两连报：①主窗口边框线没了；②朋友（同 Win11 25H2）窗口回退成白色而非保底深灰，朋友机器 Codex 云母正常——用户自测补刀：本机切浅色主题同样变白。

- **根因一（边框）**：25H2（26200）起 DWM 默认边框 `COLOR_NONE` 不再绘制——实机剖线实证默认态窗外→窗内直接突变无过渡列，显式染红则正常画 2 物理 px 线（画框机制完好、默认色失效；063「COLOR_NONE 在 25H2 未达预期观感」伏笔坐实）。
- **根因二（变白）**：非 Mica 调用失败（SYSTEMBACKDROP_TYPE=2 设上了）——窗口主题默认跟随系统，浅色主题下 `USE_IMMERSIVE_DARK_MODE` 置 0 → Mica 浅色变体 ≈ 白底，经 `fx-mica` 全透明 `.window` 透出；保底 `--n-g-a1-solid` 只在后端报 solid 时画，此路径够不着。
- **修法一**：显式染边框回 0830 方案——新 `window_fx::paint_border`（`BORDER_COLOR_NORMAL = 0x00333333` = --n-g6 #333，与实色模式前端自绘同色），主窗口启动染（lib.rs extend_frame 旁）+ 预览/插件子窗口建窗染；`set_main_border_picking` 常态恢复分支 COLOR_NONE → #333。
- **修法二**：窗口主题锁深色——主窗口 `tauri.conf theme:"Dark"` + 子窗口 `WebviewWindowBuilder.theme(Dark)`；tao 0.35.3 源码实证 `update_theme` 对 `preferred_theme.is_some()` 的窗口在 WM_SETTINGCHANGE 直接 return 不跟随 → Mica 恒深色变体、DWM 退化实底也恒深色。

验证：cargo check / clippy 净、lib **548 测绿**；debug 实例实机剖线顶边 2 物理 px #333 线精确出现、角部沿圆角（截图目验）。踩坑 094 新立、口径速查 §19 边框段与 fx 段修订、探针 `tools/win-dwm-inspect.py` 留存（只读 DWM 体检：样式/EXTENDED_FRAME_BOUNDS/SYSTEMBACKDROP_TYPE/IMMERSIVE_DARK + 四边剖线）。**待用户实机复验**：切浅色主题云母应保持深色 + 边框可见；预览/插件子窗口边框；picking 进出切染与恢复。
