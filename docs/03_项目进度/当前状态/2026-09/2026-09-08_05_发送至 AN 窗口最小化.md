# 发送至 AN 点击即最小化主窗口（2026-09-08，feat/new-ui，实机走查第一批第 20 条）

：点「发送至 AN」时 APP 挡住 Animate——用户要看的是有没有导入 AN；曾有一次 AN 弹重复元件选择框被 APP 挡住未发现，APP 侧只显示超时。**修法**（前端一处三入口全覆盖）：`placementOps.sendToAnimate()`（素材卡右键 / 回收站右键 / Ctrl+E 唯一汇聚口）函数首行即 `getCurrentWindow().minimize()`——点击即最小化、不等发送结果（发送是 await 长链路：剪贴板载荷转换 + WS 回执最长 20s，等结果再让位则 AN 弹窗早被挡）；结果 toast 仍窗内发出，回窗可见。后端命令与链路不动。vue-tsc 0 错。**交实机复验：发送后 APP 立即让位，AN 侧弹窗（重复元件选择框等）可见可点**。接口文档 16_右键菜单配套/07_CEP插件命令 send_to_animate 条同步。
