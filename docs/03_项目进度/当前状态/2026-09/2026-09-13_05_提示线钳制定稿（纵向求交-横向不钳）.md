# 提示线钳制定稿：纵向求交、横向不钳（2026-09-13，feat/new-ui，实机复验一条）

：用户复验"左侧插入提示覆盖在卡片上，之前和右侧一样在边距处"。**根因** = 左边距由宿主「列表容器」`padding: 12 0 0 12`（ContentArea）承担，行首间隙 g.left=-12 恰落该留白带（设计内区域）；二轮求交钳制把它判空、三轮平移钳制把它盖上首卡，均误判。**定稿 = 纵向求交、横向不钳**（gapClient / gapBar 同）：纵向防 Teleport 无裁剪画出工具栏；横向行首落宿主留白与右侧 PAD.right 对称即设计位置；出盒（窗口左上）由 panelActive 门控保证。typecheck 绿；口径速查 07 同步。**行为变化交实机走查：行首提示线回首卡左侧留白带，不盖卡片不丢**。
