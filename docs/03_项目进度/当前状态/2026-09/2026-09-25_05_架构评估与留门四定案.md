# 当前状态 · 2026-09-25_05

## 架构包容性评估与留门四定案（2026-09-25，feat/new-ui）

用户三问（未来未知功能包容性 / 大版本与 UI 换代伤筋动骨否 / 视频向量动静），三路实证探查后定案：

- **包容性**：素材域内扩展已注册表级（previewSpecs / cardSpecs / barSpecs / menuSpecs 实证，MCP 工具 25 行一个，新数据文件备份/迁移/撤销自动生效）；**全新功能域的缺口在挂载点**（dock 面板仅 ContentArea 一种、左栏三段 / 详情三 tab 硬编码联合类型）与 **AppState 库中心化**（非库功能域无状态落点、无撤销）。死代码面小（休眠 2 件 + 死命令 2 个，台账在册）。
- **换代减震**：UI 换代不伤筋动骨——token 单源 + 台账（149 件：新 72 / 业务 75 / legacy 0 / 休眠 2）+ preview 展区把换代降为台账驱动；legacy 块只剩向导 `--space-48` ×8 一个定案解锁。真实风险在验证网（探针 ≥6 枚腐烂 / clippy 48 / vite HMR 失真四咬）。
- **留门四定案（用户定）**：① 详情第三 tab = 自定义卡片容器（提示词挪基础信息下；detailTabSpecs 注册表）② 中间面板自定义页面（pageSpecs：viewKey 前缀 → 页面组件；启动页负一屏 / widget；3D·电子书走 previewSpecs 现成门）③ 悬浮栏按钮 show 数组 + PlayGroup 单点够用不提前泛化 ④ 左栏 Obsidian 式自定义（分段注册表 + 快速访问 pin 泛化 + 图标网格复用）。
- **7.3 阶段表 v2**（按包容性收益排）：T0 验证网修复 → T1 WS 协议泛化（09-04 条并入）→ T2 pageSpecs → T3 detailTabSpecs → T4 左栏分段注册表 → T5 迁移正名（MIGRATIONS 启用 + 自检链 9 段收编）→ T6 AppState 解库 → T7 五查新一轮。功能轮不挡：筛选 → 提示词照常先排。
- **视频向量预研定案**：动得整齐、零侵入现有分层，唯一新大件 = 推理引擎收 adapter 可换。V1 SQLite 派生存储 + 暴力 topK → V2 provider adapter → V3 导入挂接（视频 = 抽帧 + 图像模型帧平均）→ V4 搜索栏语义模式 → V5 MCP 暴露。
