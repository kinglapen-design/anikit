# 预览模式导航不退出修复（2026-09-08，feat/new-ui，用户实机报）

：预览模式下点侧栏切文件夹 / 快速访问，视口已切但中栏仍是预览画面，用户不知文件夹已换。**根因** = 预览是全局单例（`preview.assetKey && active` 整栏切换），导航统一入口 `tabs.openView` 只改 viewKey 从不碰 preview store。**修法**（tabs.ts 命令层一处收口）：`exitPreview()` 幂等关预览，`openView` 两分支 / `openInNewTab` / `goHistory` 视口切换前各调一次；同视口点击早退不算导航保持预览，点标签页切激活（预览跟随激活 panel 的 4.3 既有设计）不动。vue-tsc 0 错、build 通过。**行为变化交实机走查：预览中导航立即退出预览落在目标视口**。
