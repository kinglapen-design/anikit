# 阶段八 8.1 二轮 2a 复验二修 · WebP 黑底（透明丢失）修复（2026-09-01，feat/new-ui，用户实机报）

：根因两环——① **组包丢 ALPH**：webp crate 有损编码对含 alpha 输入自动产 ALPH 伴随块（libwebp use_argb=1），初版 `extract_vp8_chunk` 只提 VP8/VP8L 把 ALPH 丢了 → 帧无 alpha、透明区 RGB(0,0,0) 落黑底；修法 = `extract_image_chunks` 按序保留全部图像 chunk（webp 0.3.1 自带 AnimEncoder 评估弃用——它自动差分裁剪，与全帧组包路线冲突）。② **缩略图管线对动图丢 alpha**：image crate 0.25 的 webp 解码器对 VP8X 动画容器把透明像素落成黑——`thumbnail::generate` 对 gif/webp 改走 anim 首帧解码（新 `decode_origin_image` 选路），静态 webp 不受影响。**验证**：cargo test **422** 全绿（+1 黑底回归钉 `webp_anim_thumbnail_keeps_alpha`）。**存量**：库里三个黑底 webp = 丢 ALPH 旧组包，刷新缩略图救不回（原图无 alpha），重导即可。**下一步：用户实机复验（重导 → fla 卡片透明底 + 自动/悬停播放 + 无重影）；其后 2b = CEP 正式面板 + 一键安装 + 设置页**。
