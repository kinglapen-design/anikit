## 区块标题分割（前端，typecheck 0 错）

WorkspaceTree 根层两个 SectionTitle block 标题：「常用 / N」（pin 数，无 pin 不渲染）+「文件夹 / N」（根直接子目录数）；间距 = 标题 padding-top 8（首个不吃双份），items gap 2 不变；hover 出展开钮、点击折叠区块（FolderStrip / ArchiveStrip 同先例，ref 默认开）；空态不随折叠隐藏；子层递归无标题。改 04 轮「无区块标题直接列表」初判（沿用库快速访问先例的自作主张），PRD 常用固定交互段同步改定。

## exe 文件级图标缓存（后端，cargo test 绿 +1 测）

根因：不可解码类型按扩展名缓存 `.anikit/thumbs/{ext}.webp`——exe 同扩展名各程序图标不同，首个提取的图标被所有 exe 复用（用户实机「缓存了第一个 exe，之后所有软件图标一模一样」）。修：exe 走 `{url-safe(rel)}-{mtime}-{size}.icon.webp`（内容缩略图键 + .icon 中缀，purge_stale 同源顺清），现场 shell 提取该文件自身图标，源变化即失效重提；其余类型维持按扩展名缓存；thumbKind 仍 = FormatIcon，前端零改动。测试 exe_icons_cache_per_file（两 exe 缓存互异 + 源变化旧缓存清、邻文件不受影响）。
