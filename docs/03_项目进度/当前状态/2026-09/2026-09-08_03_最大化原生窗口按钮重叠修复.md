# 最大化时原生窗口按钮压自定义按钮修复（2026-09-08，feat/new-ui，实机走查第一批第 17 条，同日翻车两轮后终局）

：最大化 / 全屏时右上角出现一组系统默认窗口控制按钮压自定义按钮（常态 hover 顶边也露原生关闭钮红色细条，用户视频实机报）。**根因**（读 tao 0.35.3 源码坐实） = tao 建窗无条件保留 `WS_CAPTION | WS_SYSMENU | MIN/MAXIMIZEBOX`，无边框靠 WM_NCCALCSIZE 返 0；063 六轮终态的 `DwmExtendFrameIntoClientArea(-1)` 整窗玻璃延伸 = 云母 backdrop 载体——带 caption 样式 + 整窗玻璃，DWM 遂把原生按钮画进玻璃（最大化画在 rcWork 让出的 caption 条带，常态画在 Win11 顶边 inset 2px 细条）。**翻车两轮（实机连报，当日回滚）**：① 最大化态切延伸 0 → 云母载体被抽整窗纯黑；② 摘 WS_CAPTION → caption 扛着的阴影/圆角/边框体系塌了，全窗白边环。**终局**（三处配合）= ① `window_fx::extend_frame` **只在最大化/全屏态撤玻璃**（margins 0 杀按钮，还原回 -1，常态不动）；② 前端 `.window.fx-mica.maximized` 回落实色 `--n-g-a1-solid`（DWM 最大化本关 backdrop，微软自家同惯例；不补裸奔纯黑）；③ 失焦欺骗 subclass 扩 `main_window_guard` 拦 `WM_WINDOWPOSCHANGING` **动画前预撤玻璃**（复验报"动画里闪按钮"——Resized 在动画结束后才到；还原不预撤，完成后回 -1），`FRAME_GLASS_OFF` AtomicBool 防重复调用。cargo test 446 绿 / clippy 净 / vue-tsc 0 错；探针五轮（063 手法 + 前台断言——无断言截到上层窗口，前两轮结论作废）。**交实机复验：最大化无原生按钮且动画不闪、实色底非纯黑 / 还原云母边框圆角如常 / 进出全屏 / 失焦云母不退化**。已知取舍：最大化云母换实色（保云母则按钮回来，二选一）。踩坑 071 重写。
