# 拖进度偶发「转码中…」修复：error 回退分错误码，瞬时错误先直读重试（2026-09-24，feat/new-ui，用户实机报）

：用户实机——预览普通 MP4 拖进度到开头偶发「转码中…」白等几十秒。**根因 = 直读优先链（踩坑 075）的 error 回退不读 MediaError.code**：seek / 硬解管线瞬时错误（DECODE/NETWORK，Chromium 硬解已知脆点）与「格式真不支持」（SRC_NOT_SUPPORTED）一刀切全送 ffmpeg 整段软编码（踩坑 086）。**修法 = 回退分两级**：非 SRC_NOT_SUPPORTED 先同源 `load()` 直读重试一次（loadedmetadata 恢复原位置续播，全程不出「转码中…」），仍 error 才落转码；SRC_NOT_SUPPORTED 直落转码不白试。四播放点（previewMedia `retryDirect()` / HoverVideoLayer / HoverAudioLayer / TabLinks）同口径。typecheck / build 绿；实机复验点 = 同片反复拖到开头不再出「转码中…」，mov 等真不可播格式照旧兜底可播。踩坑 086、接口 18、PRD 04 同步。
