# 拖拽僵尸会话修复（2026-08-13，feat/new-ui，用户实机"树/快速访问点不动、双选中，重启解决"）

：根因 = 拖拽引擎 begin() 无 pointer capture——item 按下后鼠标划出窗口松手 pointerup 丢失，sess 变僵尸（blur 兜底只在失焦触发），后续按下被 `if (sess) return` 静默复用 → 移动超阈值误 startDrag：suppressClick 吞 click（点不动、双击才行）+ clickFolder 误入域（双选中残留）+ 严重时静默 drop 移动文件。**三道防线**：begin 对卡片/树 item 根元素 setPointerCapture（治本，勿 capture 到 documentElement——会吞纯 click）+ onMove 首行 buttons 活性检查立即自清 + begin 先取消旧 sess 再建新；次要路径 FolderTree nextTick 入域加 sidebarSelected 守卫。踩坑 032；CDP 回归探针 9 项全 PASS（tools/cdp-drag-zombie-probe.py 含真实拖拽不误伤），vue-tsc 零错误。
