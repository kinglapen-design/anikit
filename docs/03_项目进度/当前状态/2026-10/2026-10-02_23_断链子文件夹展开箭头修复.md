# 当前状态：断链子文件夹展开箭头修复（2026-10-02 二十三轮）

链接走查四连报：断链子文件夹在树里连展开箭头都没有（误判「没有子文件夹」）——根因 = `has_visible_sub_dir` 用跟随式 `is_dir()`，断链 junction 穿透失败不计入子级，**只含断链门的父目录被误判无子级丢箭头**（条目列举本身正常，唯独箭头没了）。修复 = 与 `list_dir` 目录判定对齐：**reparse 目录（含断链）计入子目录**（`DirEntry::file_type` 零 syscall，仅疑似候选补一次 reparse 检测）。测试补「只含断链门的父目录 has_sub_dir = true」断言。563 测绿 + clippy 净；接口 20 `hasSubDir` 口径同步。**待实机走查：断链父目录箭头回归 / 展开后断链子夹 warning + 置灰 / 有效链接目录箭头照常**。详见 [开发日志 2026-10-02_23](../../02_开发日志/2026-10/2026-10-02_23_断链子文件夹展开箭头修复.md)。
