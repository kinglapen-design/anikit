# 工作空间右键菜单移植与系统菜单（2026-10-01，feat/new-ui）

用户要求：库式右键菜单能移植到工作空间的移植过去（快捷键 / 分组分割线，文件夹与文件都查），并落地「Windows 原生右键菜单」（压缩解压 / Git 等）。

- **四 spec 重组**（`menuSpecs/workspace.ts`）：分组 / 分割线 / 快捷键标注全面对齐库菜单。文件 = 打开预览 / 新标签页打开 / 默认应用打开 / 打开方式 / 发送至 Animate（fla）/ 资源管理器 / **系统菜单** │ 复制·剪切·粘贴（条件出现）·重命名·创建副本 │ 复制数据 ▸（路径 / 名称 / base64）│ 删除 │ 刷新；文件夹 = 新标签页 / 新建（同级+子级）│ 固定 │ 剪贴板组 │ 复制数据 │ 资源管理器 / 系统菜单 │ 删除 │ 刷新；树行减「重命名」；空白 = 新建 / 粘贴 │ 资源管理器 │ 刷新。「打开」冗余项不列（同库口径）；批量分流同库 3.4；新建 = 库「先建后命名」移植（当前视口即父目录时进行内命名态）。
- **快捷键 ws 分支新绑三键**：Ctrl+D 副本 / Shift+Enter 默认应用打开 / Ctrl+E 发送至 Animate；Enter / Ctrl+Enter / 新建两键仅标注（库同）。
- **系统菜单 = Windows 原生 IContextMenu**（`adapters/shell_menu.rs`）：桌面 IShellFolder + 全 PIDL 取菜单对象，自建消息窗转发五消息给 IContextMenu2/3（扩展子菜单 / 自绘项靠它），光标处模态弹出（spawn_blocking STA，主线程不冻结），选中 InvokeCommand。边界：Win11 新样式 IExplorerCommand 扩展不在其中。windows crate 补 `Win32_UI_Shell_Common` + `Win32_System_LibraryLoader`。
- **新命令**（`commands/workspace.rs`）：`open_path_with_default_app` / `open_path_with_dialog` / `ws_file_base64` / `ws_duplicate` / `ws_shell_menu` / `send_path_to_animate`（cep 抽 `send_fla` 共享）；统一 `validated_ws_path` 校验。
- **顺手修正**：ws 新建文件夹避让名 ` (n)` 括号式 → `-n`（09-23 序号定案 ws 侧残留）。
