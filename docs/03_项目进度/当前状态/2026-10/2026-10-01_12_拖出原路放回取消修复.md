# 拖出原路放回取消修复（2026-10-01，feat/new-ui）

走查再报：拖出未松手原路放回 UI 触发回导（库导入流 / ws `_n` 副本），库式与 ws 式拖出同病。

- **根因**：OLE DoDragDrop 存续期间本窗仍是合法放置目标，拖回来时 `enter / over / drop` 照发，落盘逻辑分不清是自己的拖。
- **修法**：`osDragOutActive` 窗口期标记（发起 OLE 拖放置位、resolve 清位），`onDragDropEvent` 入口早退——不高亮、不落盘，OLE 报无放置 = 拖取消；两条拖出路径一处标记同愈。
- 文档：PRD 02_打开素材 补「原路放回 = 取消」口径。

验证：typecheck 0 错（纯前端）；待实机走查（原路放回零动作 / 正常拖出落盘 / 取消后再拖入外部文件正常）。
