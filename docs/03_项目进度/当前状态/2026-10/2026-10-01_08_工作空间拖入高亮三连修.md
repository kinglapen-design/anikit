# 工作空间拖入高亮三连修（2026-10-01，feat/new-ui）

_07 互通轮实机走查两连报（pane 高亮下半视口消失 + 同目录空拖也亮 / OS 拖入无提示），高亮口径统一为「只回答松手会不会落到这」。

- **pane 命中层错位修复**：落点命中原用卡片层 rect（只到内容高），下半视口判不中——注册项 `layer` 改传视口根（该字段仅 pane 命中消费，间隙解析卡片层坐标系不受影响）；库侧跨分屏并入在目标 pane 空白下半区同步生效。
- **ws 同目录禁止高亮**（用户定）：补库分支同款「被拖项全已在目标目录不出落点」守卫。
- **OS 拖入悬停高亮**：`onDragDropEvent` 的 enter / over 驱动 `osFileDragHover`（`dragOperation` 新导出）——树行 / 文件夹卡 = 并入、可导入视口 = pane 级整片、虚拟视图 / 回收站 = 拒入不高亮；视觉槽与内部拖拽共用，leave / drop 清槽；PRD 02 联动节补高亮口径。

验证：typecheck 0 错（纯前端）；待实机走查（整片视口恒亮 / 同目录不亮 / OS 拖入各落点高亮 / 松手落盘不回归）。
