# 当前状态：链接目标拒挂储存空间整树（2026-10-02 二十轮）

用户问「选文件夹时选了储存空间自身怎么办」——拆解：空间根本就被防循环祖先校验拒掉，**但空间兄弟目录有洞**（`assets` 素材池 / `自动导入` / 库数据与 `workspace` 平级，两条旧校验都不沾）——素材池挂进工作空间 = 绕过库封闭语义直接改库文件，元数据必脱钩。修复 = `check_link_target` 首道闸**拒挂储存空间整树**（`root.parent()` = 空间根，canonicalize 前缀命中即拒，「储存空间内的目录不能挂载（素材池 / 自动导入 / 库数据是 AniKit 自留地）」），`ws_add_link` / `ws_retarget_link` 同闸；原 root 内 / 祖先两校验保留（防御）。测试补两断言 + 合法目标移出空间根独立 tempdir（夹具踩线 = 校验生效证明）。563 测绿 + clippy 净。边界：空间外库目录（仅元数据无素材内容）不在本批拒绝范围。PRD 02 落地口径与接口 20 同步；详见 [开发日志 2026-10-02_20](../../02_开发日志/2026-10/2026-10-02_20_链接目标拒挂储存空间整树.md)。
