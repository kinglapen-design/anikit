# 命中片段与范围播放

`create_semantic_segment` 已接通应用菜单、命令、MCP 写入闸、撤销与热刷新。创建前校验模型 / 分析版本和源指纹，禁止嵌套。虚拟片段只保存 metadata 和区间缩略图，不复制媒体；视频按真实 PTS、动图 / 序列帧按原始帧索引限界。物理片段经 ffmpeg 生成独立普通资产，视频为 MP4，序列帧为 GIF，动态 WebP / APNG 保留格式与逐帧 delay。

真实后端验证覆盖视频 / GIF / 序列帧的虚拟与物理输出、动态 WebP / APNG 逐帧导出和封面写入隔离。真实界面验证右键创建虚拟视频，MCP 创建虚拟 GIF / 序列帧与物理 GIF，三类虚拟范围播放和物理单帧独立显示均通过。完整 S0–S9 脚本通过，MCP 32 工具可用，最终全量后端 703 项通过。

`get_media_source`、序列帧清单、动图帧流、来源路径和详情均携带或解析片段信息。设置虚拟封面不会改写来源 metadata。时间角标与完整任务面板未供稿，没有新增样式。详见[开发日志](../../02_开发日志/2026-10/2026-10-31_03_命中片段与范围播放.md)。
