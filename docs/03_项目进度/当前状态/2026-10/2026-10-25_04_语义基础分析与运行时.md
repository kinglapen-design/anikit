# 语义基础分析与运行时

本地基础语义分析已经真实落地，但 1.0 向量分析整项尚未完成。当前进入外部 provider、前端交互验证和 MCP 阶段，暂不打包宣称发布。

## 已验证

独立 worker 的 CPU / DirectML 推理均返回 512 维，支持回退复用、超时取消和文本塔空闲卸载。真实 MP4、GIF、WebP、APNG、三帧序列包已完成分析 → 分段入库 → 中文检索；末帧使用真实 PTS，序列帧命中 0 / 42 / 83ms，APNG 与 PNG 序列帧不混淆。

全量后端 675 项通过，语义专项与 Clippy 通过。Windows 库单测 manifest 问题已修复并记录为踩坑 114。搜索模式、相关度结果源、预览时间/原始帧跳转和任务进度入口已接入，TypeScript 检查通过。

## 继续推进

外部 provider 使用 OpenAI 兼容或 Ollama 多帧理解，密钥只进 Windows 钥匙串，外部文本仍由本地 CLIP 编码。事件必须引用证据帧，候选因果标 hypothesis，不把 CLIP 场景偏置当稳定动作识别。

还需完成 provider 回环与详细分析闭环、前端真实交互探针、MCP、片段导出、1000 帧耐久、完整便携包和发布文档。正式模型发布下载源尚未确定，目前只支持受管目录或离线模型包，路线图向量分析不勾。
