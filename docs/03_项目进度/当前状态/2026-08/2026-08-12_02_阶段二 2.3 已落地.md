# 阶段二 2.3 已落地（2026-08-12，feat/new-ui）

：**导入预览性能优化**——用户实测痛点：自动播放 GIF + 卡片缩小密度变大 → 全局 UI 延迟（hover 目录树滞后）。根因：① 自动播放无数量闸（小卡片时虚拟窗口 200+ 卡片同时解码）；② 卡片动图 = `<img>` 播原尺寸 GIF。**方案（用户定）**：数量闸 + info 小动画缓存，自研解码器仍归阶段四（闸门 = 调度层与其互补、小动画 = 缓存层转移解码成本到导入期，均不浪费）。**数量闸**：`lib/autoplayGate.ts`（上限 16，满员 FIFO 排队唤醒；悬停直通），AssetCard 动图/视频/序列帧三处自动播放统一接入。**小动画缓存**：ffmpeg sidecar 转短边 320 animated webp → `info/{stem}_anim.webp`（导入后异步 + 存量懒生成，`-fps_mode passthrough` 保时长、`-f webp` 显式封装）；`get_asset_file_path` 返回加 `animPreview`，前端播放源 `animPreview ?? path`。CDP 探针实证（cdp-autoplay-gate-probe.py）：40 动图卡两态（初始/滚底）均 21 挂载 16 播放 0 源文件泄漏。vue-tsc / build / cargo test 259 全绿。PRD 04 性能口径 / PRD 01 info 内容 / 07 接口文档同步。
