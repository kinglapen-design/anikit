# 2026-10-03

## 立项候选（0.2.0 时代，2026-10-03 咨询定）：命令面板（Command Palette）

用户问「有没有接入的必要」（Obsidian 式 Ctrl+P 模糊搜命令）。当日评估结论：**1.0 不做，0.2.0 插件化后自然成立**——

- 命令面板解决的问题 = 命令数量爆炸后的可达性 + 插件命令的泄洪口；AniKit 现状命令层级浅（菜单四钮 + 右键全覆盖，editMenu 即全命令菜单面）、目标用户（动画师）是鼠标 + 快捷键党（Eagle 无此物），无痛点。
- 0.2.0 插件市场后插件注册命令需要统一入口，命令面板 = 现成答案；且命令已收敛 `menuSpecs` 注册表体系（appMenu / editMenu / 右键全族），可直接作数据源，彼时接入成本低。
- 开工要点（届时细化）：模糊搜索 + 键盘导航 + 快捷键标注列（菜单稿既有口径）；命令注册表从 menuSpecs 提炼「全命令面」单源（消除菜单/面板双份维护）。
