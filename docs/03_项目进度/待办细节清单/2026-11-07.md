## 背景与分工

用户希望漫剧等生产任务能跨 Codex、Kimi 等助手交接，不靠人工复制粘贴当传声筒。登记方向见 [PRD 08-07](../../01_项目-PRD/08_AI%20功能/07_工作台转型.md)「跨 Agent 任务调度」。核心不是让助手互相聊天，而是任务、产物和完成通知有统一归属。

AniKit 保存任务状态、事件编号和产物索引；Markdown / 文件承载输入与结果；本地调度器启动代理并持有运行上下文。AniKit 不承诺直接唤醒已有交互会话，不能续接时由调度器携带原任务上下文启动新运行。

## 最小验证范围

先使用模拟执行器，不接真实模型、不调用生成服务。创建 `EP50-P03` 测试任务，模拟代理写 `candidate.md` 并主动报告；AniKit 校验任务与产物后发出完成事件，调度器收到事件并执行下一步。过程中主动断线一次，按事件编号补领，确认不丢通知、不重复执行。

真实接入前逐家确认官方 CLI / API 的启动、退出、上下文恢复与错误语义。代理自报完成不等于验收通过，必须能核对 taskId、attemptId、产物路径和预期文件。
