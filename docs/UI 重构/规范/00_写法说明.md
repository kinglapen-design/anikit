# 00_写法说明（格式参考）

> 给写文档的人看的格式约定。照着写，我就能机械地转成 tokens.json + CSS 变量。

## 1. 分工（组件该不该写在这里）

- **01_样式 token.md**：颜色、文字、线框、间距、圆角、图标。
- **02_通用组件/**：通用组件的样式规则（按钮、item 这类到处复用的"零件"），目录见 `02_通用组件/00_组件目录.md`。
- **Figma 已画好的页面以 Figma 为准**（导出稿已归档至 `docs/归档/00_修改与需求/03_新样式/01_figma-css/`），md 里不用重画细节，只写 Figma 里没有的规则。

## 2. 基础 token（01_样式 token 各节）——照现在的写法就行

一行一个：`名称：值（用途）`，无需改动。

## 3. 组件写法：常态写全，状态只写差异（不要嵌套层级）

每个组件一段，**常态写完整，其他状态只写和常态不一样的属性**，一行一个状态：

``` text
#### 图标按钮（示例）

- 常态：图标 常态 / 底色 无 / 边框 无 / 圆角 6 / 内边距 6（大=30×30）或 4（小=20×20）
- 悬停：叠 暗-悬停
- 选中：叠 亮-选中
```

嵌套容器（如文件树 item）也只写每层的关键属性，状态同样只写差异：

``` text
#### 文件树 item（示例）

- 结构：展开按钮(图标 12px, 标签) + 内容容器(内边距 6 8, 圆角 6, 间距 6) → 图标 18 + 名称(正文, 常态) + 数量标签(标签, 标签)
- 悬停：内容容器叠 暗-悬停
- 选中：内容容器叠 亮-选中 + 边框 1.5px 常态（内阴影模拟）
```

## 4. 颜色速记（写 md 用左边，我转 JSON 用右边）

| 你的写法 | 代码变量 |
| --- | --- |
| 品牌色-常态 | `--brand` |
| 品牌色-边框线 | `--brand-border` |
| C1 ~ C5 / C5-底色 | `--c1` ~ `--c5` / `--c5-base` |

## 5. 布局文件写法

每个容器一段，属性一行写完：

``` text
## 左侧边栏
- 尺寸：260 × 填充拉伸（拆分条调宽）
- 圆角 6 / 内边距 4 / 子项间距 0 / 颜色 C3 / 边框 1px 亮-选中
- 结构备注：文件树展开图标竖向对齐，子项左边距统一留位
```

## 6. 间距约定（设计与工程一致）

**一律使用内边距 + 子项间距（gap），不使用外边距（margin）。** Figma 无外边距的设计方式与现代 CSS 工程实践一致：组件不带 margin，间距由父容器用 gap / 内边距统一控制，避免 margin 塌陷与组件间间距污染。

**四边边距的写法顺序：上、右、下、左**（从上面开始顺时针，与 CSS `padding: 上 右 下 左` 一致，转换零翻译）。能简写就简写：四边相同写一个数（`内边距 8`）；上下、左右分别相同写两个（`内边距 上下8 左右12`）；都不一样才写四个。

需要由我翻译的设计↔工程差异（会个案记录在开发日志）：填充可拉伸 → flex/grid 弹性、绝对定位元素（滚动条、角标）、文字行高的字体渲染差异。

## 7. 图标 SVG 约定（2026-08-07 现行，详见 `assets/icons/命名对照.md` 颜色约定）

- **Figma 导出时线条保持"描边"属性，不要轮廓化（Outline stroke）**——轮廓化后 SVG 全是 fill，CSS 无法区分线条与填充。
- **线条层 = 文字四档色（高亮/常态/标签/极淡），透明度照 Figma 导出即可**：入库时由我批处理统一转 `currentColor` 并删除透明度（明暗由 CSS color 档位表达），不要自己手改色值。
- **结构色（品牌色、状态色、边框、控件底色）与软件品牌彩色保留原值**，批处理不动。
- 图标**内联使用**（`<img>` 引入的 SVG 读不到 currentColor 与页面变量）。
- SVG 文件名可用中文命名，交付后由我统一改为英文 kebab-case，并维护中英文对照表。

## 8. 术语词典（防歧义，双方共同遵守）

> 尺寸相对词必须有唯一指向。拿不准时我会先问，不自行推断。

- **子项**：auto layout 容器的**直接子元素自身**。`width: 子项` = 紧邻注释所指子元素的自身宽度（例：展开按钮容器 `width: 子项` = 展开按钮图标 12px）。**不写"子项的高度 / 父级高度"这类推断**；有多个子元素时写全名，如"子项（展开按钮图标）"。
- **主容器 / 总容器 / 内容容器 / 按钮容器**：仅嵌套层级的命名，格式为"容器名：包含的子元素"。
- **填充父容器 / 填充可拉伸 / 自适应填充父级**：`flex-grow: 1`，充满父容器剩余空间。
- **margin: 0 auto**（Figma 标注原文）：在父容器主轴上居中。
- **order**：flex `order`；**Inside auto layout**：该元素在 auto layout 中的约束（`flex: none` / `flex-grow: 1` 直接对应 CSS）。
- **active**：**持久化选中态**（selected），不是 CSS `:active`；**checked**：单选 / 复选的勾选态。
- **图标尺寸**：`图标 18×18` 指 SVG 画布（viewBox）尺寸；**图标按钮大 = 30×30 / 小 = 20×20** 指按钮容器（分别 padding 6 / 4，图标 18 / 12）。
- **描边（border / stroke）**：一律 inside 对齐、不占空间；工程用 inset box-shadow 实现（01_开发规范 第 4 条）。
- **绝对定位坐标**（如角标 `left: 8px; top: 8px`）：相对最近的定位父容器（Figma 里即其直接父框架）。
- **尺寸：A x B**：宽 × 高；**全部数值单位为 CSS px（逻辑像素）**，设计稿 100% 与工程 1:1。
- **状态书写**：常态写全，`hover / active / checked` 只写与常态不同的属性（第 3 节）。
- **叠（罩层）**：在原背景上叠加一层透明度色（暗-悬停 / 亮-选中），不替换底色、不掺白（2026-08-07 用户定：掺白会发灰）；工程用 `linear-gradient(罩层, 罩层), 底色` 双层背景实现。
