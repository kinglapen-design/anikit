### 12.1 二轮修订（2026-08-24 用户定，覆盖 §12 部分口径）

- **关系模式 = 多选累积**：选一个 = 追加一条而非切换（用户场景：一次为发起方加父亲/儿子/母亲/专武多条）；备选区**整组竖排复制**（选中文件 item + 双称谓框 + 发起文件 item + 红删为一组，"把整个 item 复制就行了"），组间 8；确认批量写入（add_relations，单撤销步）带数量「确认 (N)」；空态 = 占位组双框 disabled。
- **发起文件自身卡片 = 剪切档半透明（--opacity-cut 0.5）+ cursor not-allowed**（picker-self 类，AssetCard / ArchiveCard）；视觉排除优先于点击拦截。
- **详情关系 item 点文件卡 = 跳转定位**（asset → origin Placement 所在文件夹视口 + 选中卡片；archive → 档案视口 + 选中档案卡；openView 入面包屑历史，后退即返回）；**换绑废除**（要换就删了重新添加），改称谓保留（点称谓框 C2 输入框）。
- **白名单收窄**（错误信号：模式内出现任何与选文件无关的入口）：只放行 树 / 快速访问导航、搜索、查看方式（滑块 / 递归显示 / 排序）、挑选文件（点选 + 双击预览）、面包屑后退前进；**汉堡含切库也禁**（跨库挑选后置）、收件箱条目与菜单禁、包内帧选择与编辑禁。**后续筛选（/）接入时进白名单**。
- 探针桩纪律补一条：**IconButton 的 title 是 v-tip 指令不落 title 属性**——探针按结构位置取钮（`.bar-title > .icon-btn` 第一个 = 汉堡 / `.add-btn-wrap .icon-btn` = 新增）。
