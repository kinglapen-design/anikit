# 26. 阶段七菜单栏主菜单轮（2026-09-05；稿 = 用户当场供稿截图，spec = src/lib/menuSpecs/appMenu.ts）


- **菜单栏「菜单」钮接业务**：点击 = 按钮下方弹出（左缘对齐 + 底 +4，旧汉堡同位口径）+ **同钮再点 toggle 关**；其余三钮（编辑 / 插件 / 视图）仍点亮不接业务随后续轮。选择模式（picker.active）禁开（白名单收窄：主菜单含切库，§12.1；视觉不改——稿无禁用态）。
- **ContextMenu 多级级联 flyout 栈（单级改多级）**：`flyouts[]` 栈（flyouts[i] = 第 i+2 级），hover 第 k 级项（根 = 0）= **截断到 k 层再按项推新层**（onItemHover(entry, e, level)）；key = `层级:父项top` 防跨层同 top 撞 key；各级独立 fixFlyoutX 左飞修正。**组外关闭 = 根与各级 AppMenu 的 group 传全部 flyout 根元素（AppMenu group 改收数组）**——点任一级菜单内不关；点组外任一级都会 closeAll（幂等）。**hover 必先于 pointerdown**：截断后深层已收，深层 AppMenu 的"点外关闭"不会误伤浅层项 click。
- **trigger 触发钮豁免须传全级**：menuState.trigger（openContextMenu opts.trigger）→ 根**与各级 flyout** AppMenu 都要传——漏传 = 深层菜单把触发钮 pointerdown 当组外先关、click 又开，toggle 失效（本轮探针 M7 实证）。
- **菜单库列表 = 纯对勾行（2026-09-05 用户定稿口径）**：MenuItem checkable + `library: true`（点击动态判定切换 + keepOpen 可切回），对勾随 currentLibrary 实时（flyout 渲染层 library 特判）；**旧 LibraryMenuItem（08 稿抓手排序 + 删除×，33 高旧 token）不进此菜单**——删除走同级「删除当前资源库」项。旧 libraryHamburger spec（hamburgerSpec / librarySwitchSpec）与根级库拖拽链退役评估记 09 待办。
- **spec 口径**：设计项全列、无业务 disabled 占位（§6 不变）；选中集依赖项（整理菜单 / 文件菜单链接组）按单选素材 / 单选档案解析（singleAsset / singleArchive / pickerTarget 助手在 appMenu.ts），回收站视口编辑类全 disabled（useGlobalKeys 同口径）；「打开文件/档案链接所在位置」三级 = linkList 面板（panel 字段任意层级通用）。
- **探针**：`cdp-app-menu-probe.py` 43 项全 PASS（M1 根级 8 项 4 组 + 弹出位 / M2 文件 L2 16 项 / M3 新建 L3 文档七项带图标 / M4 截断 / M5-M6 仓库·资源库 L3 对勾行 + keepOpen / M7 toggle / M8 Esc / M9-M10 整理选中依赖禁用态 + linkList L3 tip 壳）。**探针桩补启动重开链**（list_recent_libraries 非空 + open_space/open_library/get_current_library 有状态桩）——boot 首查 get_current_library 非 null 会跳过 reopenLastSession，currentSpace / currentLibrary 两单例不回填（主菜单 L3 对勾/禁用依赖）。
- **同日二轮（2026-09-05 用户实机反馈两条）**：① **「转换为缩略图链接并复制」条件出现**——格式不能作缩略图（后端 asset_menu.rs `is_thumb_capable` 口径 = 静态图 png/jpg/jpeg/bmp/webp + gif 动图；前端镜像 = formatBadge `isThumbCapableExt`）就不列该项（列了点了必报「不能用作缩略图」，误导人）；**卡片右键与主菜单「整理」同步**；主菜单无选中时保 disabled 占位（固定设计清单，无格式可判）。② **一级条目菜单 min-width 250**（用户定：纯内容自适应太窄显得轻）——AppMenu 加 `minW` prop，ContextMenu 根级条目菜单传 250；**flyout 与面板形态（iconPicker 等稿值定宽）不传**，保持内容自适应。探针 cdp-app-menu 补 M1-7 / M11 段（fla 负例两菜单不出现 + png 正例），51 项全 PASS；context-menu 84 / paste-link 15 回归绿。
