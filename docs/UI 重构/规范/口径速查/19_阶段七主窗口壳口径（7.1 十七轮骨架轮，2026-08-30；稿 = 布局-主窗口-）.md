# 19. 阶段七主窗口壳口径（7.1 十七轮骨架轮，2026-08-30；稿 = 布局/主窗口/）


- **窗口背景效果双态（fx 机制）**：`transparent:false + backgroundColor:#00000000`（tauri.conf；063 六轮方案一：tao `transparent:true` 的 blur-behind 空 region hack 会让"DWM 圆角描边曲线与方形客户区角"之间的月牙缝 alpha=0 成透底洞——用户实机角部钩形透出下层；Mica 由 DWM 在窗口表面底下合成，不需要 tao transparent，真正要透明的只有 WebView2 默认背景）+ `DwmExtendFrameIntoClientArea(-1)`（lib.rs，DWM 帧/backdrop 填充非客户区缝）+ Rust 运行时按系统版本判定——Win11 22H2+（注册表 CurrentBuildNumber ≥ 22621，`adapters/window_fx.rs`）= **云母 Mica**（`set_effects`，禁 CSS backdrop-filter 充当，稿注）；其余 = **实色回退 `--n-g-a1-solid`**（#1F1F1F，半透明-1 去透明度，2026-08-30 用户定，**不做 Acrylic**）。前端 = `get_window_fx_mode` 查询后 `.window` 加 `fx-mica` 类——**基态样式即 solid 实色**，查询返回 mica 才单向切换（防首帧闪；失败保持 solid）。**fx-mica 底 = 全透明**（2026-08-30 用户定稿：主窗口稿的 93% 半透明-1 是 figma 模拟云母的手法，工程里云母上不叠色，DWM 云母直接呈现；实色区 = 内容容器/右栏 g1 卡片各自画）。预览子窗口同口径（builder transparent + 各自 apply）。**`set_effects` 必须在 `show()` 之后调**（踩坑 057：show 前设置吞 WebView2 内容，只剩云母渐变无 UI）。
- **.window 壳**：基态底 `--n-g-a1-solid` / fx-mica 底全透明；大阴影 = DWM shadow（shadow:true，丢失再议 workaround）；**圆角分模式**：实色 = 前端自裁 `--n-radius-8`（最大化归零）；云母 = **DWM 系统圆角独裁、前端 radius 0 不裁**（CSS/DWM 双裁切 AA 差四角透缝，踩坑 063）；**窗口边框（2026-09-06 六轮用户改定 = DWM 默认半透明——「DWM 原生就是半透明就可以把边框直接交给 DWM，主窗口也是」，原 2026-08-30「通用/六级实心 #333 染色」撤销，lib.rs 不再染色；子窗口本就未染色同此口径）**：**云母 = DWM 画独存 + CSS 零绘制**（六轮定稿机制不变——CSS 线与 DWM 线并集左右不对称（左/上 3px vs 右/下 2px）、角弧异径分离出缝，任何 CSS 线逃不掉系统错位，win-border-measure.py）；**实色 = 前端 `::before` 自绘**（inset 0 / 1px `--n-g6` / radius 8 / pointer-events none / **z-54**——Win10 DWM 无默认边框可画，g6 档保留；最大化隐藏）；**picking 选择模式 = picker store enter/exit `invoke set_main_border_picking` 切染 DWM 品牌色 #0F89EC ↔ COLOR_NONE 恢复默认**（commands/settings.rs；Win10 忽略无害）+ 云母模式前端全零画（`::before`/`::after` 均 border 0，品牌框 = DWM 切染线独存）；实色模式 `::after` 1.5px `--brand-border` radius 8 自绘 + `::before` 让位（border 0）单层。**沿窗口圆角画线必须按同 radius 圆角路径**——直角线四角被 DWM 角弧（内陷 ≈2.3px > 线宽）整段吞断（063）。
- **三段底色结构（稿核心视觉）**：左栏（bar-title/rail/side-content）与标签栏（dv-tabs-and-actions-container）**透明透窗口底**；**内容容器 = g1 实底卡片 + 左上 16px 圆角 + 左缘 1px `--n-l-a2`**（dockview 定位链 = `.dv-grid-view > .dv-branch-node > split > .dv-sash-container + .dv-view-container` 紧邻——split 首子恒为 sash-container，`:first-child` 恒不匹配勿用；嵌套分屏左列内层同带左缘线 = 近似）；**右栏 = g1 + 左缘 1px `--n-g3` 通栏**（子块 border-left 收编容器统一）。标签栏下边框线废除（内容容器顶边即分界）。
- **图标旧版回退层（过渡期限定，2026-08-30 用户定）**：`icons.ts` 新库查无 → 落旧版同名 + console.warn 打标（一次/名）。**面板轮逐件按稿接线，回退命中清零后整层删除退役**——新写组件禁止依赖回退层（引旧图标名 = 错误信号）。
- **transparent 窗口已知 trade-off**：WebView2 文本子像素抗锯齿失效（灰阶抗锯齿）——实机观感待用户确认。Win10 solid 路径无实机条件，逻辑走查 + 单测覆盖。
