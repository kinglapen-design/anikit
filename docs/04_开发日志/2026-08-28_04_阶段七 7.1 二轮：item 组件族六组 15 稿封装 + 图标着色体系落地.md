**图标着色（用户定案"按规则本批先转"）**：
- 单灰线条图标 17 个文件级转 `currentColor`（expand / chevron-small / close-small / more-small / more-large / add-small / add-large / link-small / play / pause / open-in-explorer / import / trash / uncategorized / recent / auto-import / library），状态变色（hover 二级 / 选中一级）由 CSS color 驱动；
- 双色调结构图标（folder-closed / archive / image / warning-small，亮层 #BFBFBF + 暗层 #666666）文件保留原值，`lib/icons.ts` 新增 `getTwoToneIcon()` 换 `--tone-1/-2` 变量通道（**fill 的 presentation attribute 不吃 var()，必须内联 style**）——默认 自定义/常态-1/-2，文件夹九色自定义对经 `TwoToneIcon` 的 `data-tint` 覆盖；
- 品牌徽章 / 波形装饰保留原值。规则已回补 `assets/icons/命名对照.md` 颜色约定节。

**组件**（`src/components/items/`，纯展示 + 事件 emit，无业务逻辑）：
- `items.css` 共享：`.ni-card` 卡片壳（g3+g5 1px / hover g4+g6，描边瞬时切换防踩坑 036）+ `.ni-slide` 滑入动作区（grid 0fr→1fr + opacity，常态零宽不占位）+ `.ni-close`；
- `TreeRowItem`（folder/archive/quick 三型）：230×26，hover 半透明-3 / 选中 半透明-2 + 立体感-通用 + 提亮一级；文件夹双色调九色（树稿实证图标着色而非旧体系行底 tint）；档案提示装饰 = 圆点（稿 CSS 写 8×8 方块、图为圆点，以图为准，待用户确认）；
- `SectionTitle`（block/group）：**常态只显标题（/数量），展开钮 + 动作组 hover 才现身**（稿 prose 明确"常态都不显示"，一轮漏看已修），hover 行抓手指针；gap 稿值 10 不在间距 token 档，暂用 8 兜底（space-between 下仅最小间距、视觉无差，待用户定是否补档）；
- `TabItem`：选中 = g1 底 + 圆角 8 8 0 0 + **反弧肩膀**（::before/::after 8px radial-gradient 反圆角，与 g1 面板无缝）；未选中 hover = 四周 4px 间距的 6px 圆角罩（半透明-3，用户定）；关闭钮仅选中/hover 显示；
- `NoteItem`：时间码数字档 + 摘要单行省略 + 关闭滑入；
- 详情面板五件：`LinkFileItem`（路径加粗分段色档 + 关闭绝对右上滑入 + origin 品牌星右下）/ `LinkThumbItem` / `LinkAudioItem`（22 圆播放钮品牌底 hover 提亮，播放三角光学左偏 2px）/ `LinkRelationItem`（关系标签 chip = g6 + 立体感 + 加粗三级，用户当日补稿；输入态去立体感 + g2 + 半透明-1 描边 + flex 展开）/ `PollutionFileItem`（三钮按钮组滑入）；
- 选择模式两件：`PickFileItem`（输入态 = g2 + 半透明-1 描边）/ `PickRelationItem`（三行：选中文件框 + 关系双框（chevron-small 源图形朝上，左框转 180=↓ 右框原样=↑）+ 原始文件只读框 g4/g6，聚焦框描边 半透明-1）。
