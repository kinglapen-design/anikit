## 阶段七 7.1 十六轮：悬浮栏族补稿——通知栏两枚 + 悬停 tip 三件落地（既有四件贴稿重构）

**范围**：用户当日新补 `组件/悬浮栏/` 下两组稿——通知栏（通知栏 / 通知栏-选择模式）+ 悬停-tip（悬停 tip / 悬停-卡片名称 / 悬停-链接列表）。全部是**既有件的贴稿重构**（ToastStack / PickerBanner / v-tip / LinkListPopover），非新建。

**开工两问定案（一次一问）**：① 通知栏稿第二张图成功✓+失败✗同框 = 一图陈列两种状态，**每条通知单图标按需**（toast store 契约不变）；② 选择模式横幅挂点 **统一锚点**——从 App 层整窗居中（top 60）迁入 DockHost，与通知条同列同锚点（旧双锚点同现重叠作废）。

**落地**：

- **统一锚点 `.notice-anchor`**（base.css 全局类）：top 64 列表容器顶部居中不挡工具栏、z-1600、竖列 gap 8、pointer-events none 穿透空隙；挂点 = 主窗口 DockHost（横幅在上 + 通知条在下）/ 预览子窗口 App 层（仅通知条）。
- **ToastStack 贴稿**：壳 = 通用/半透明-2 + 立体感-背景模糊-大阴影 + blur 小 + 圆角 99 稿值（高 46 / padding 12 16 12 12 / gap 12，宽随内容）；状态圆点 22 = 成功/禁止底 + 立体感-主要按钮 + 内图标 14 一级（成功 = check-small——**图标五批 1 个转 currentColor**，命名对照登记；失败 = close-small）；行为文字 = 正文 一级；动作（撤销）= 按钮文字-大 一级；关闭 ✕ 二级裸钮（hover 稿未画记 09）。出入场 = 上→下位移 8 + 透明度 **250ms 小位移 缓入缓出**（稿 prose「上→下位移出现」，时长走 token；旧 150ms 废除）。
- **PickerBanner 贴稿 + 文字抖动修复**：壳 = 品牌/半透明 + 大阴影 + blur + 圆角 99（稿无 border，旧 1px 亮-选中边框废除）；结构 = 标题「选择模式」（按钮文字-大 一级）+ 目的文案（正文 一级）+「ESC 退出」（次要文字-加粗 二级，旧「Esc 取消」废除）；**bannerText 格式贴稿** = 「选择文件/档案，为 [雪牧.fla] 添加关系」式（逗号 + 名称方括号），cdp-relation-picker / cdp-link-manage 两探针期望串同步。**稿备注「循环动画字体抖动」修复** = 滑入（300ms）与 2.6s ±6px 循环浮动**分挂两层**，浮动层恒 composited（will-change: transform + translate3d 关键帧）——同一元素叠两个动画会在交接时切换合成层致文字重栅格化（抖动根因），分层后文字只栅格化一次随层位移；实机复验待用户（09 待办）。
- **v-tip 贴稿**（tip.ts + base.css .app-tip）：壳 = 通用/半透明-1 + 1px 半透明-3 真 border + 小阴影（无 inset 高光）+ blur 小 + 圆角 6（padding 4 8）；标题 = 次要文字-加粗 二级；**keys（快捷键 / 卡片简介副行）= 数字档 Fira Mono 三级原文直显——kbd 徽章形态废除**（稿为纯文字；2026-08-11「与菜单 KbdBadge 一致」口径作废，菜单 KbdBadge 本身不动）；行为全保留（400ms 延迟 / 下方居中不足翻上 / 水平钳制 / 点击即隐藏 / 透明度 120ms）。
