## 十八轮十四轮 · 窗口边框五轮定稿（用户供 Codex 思路：同色遮罩环淹没圆角 AA 过渡带）

- 四轮「前端零线条」实机复验仍败：100%/125%/150% 缩放四角都有缺口（Windows 搜索面板同病）——纯 DWM 画边时角弧 AA 过渡带直接咬内容色，深内容/浅壁纸对比把 AA 半透像素暴露成缺口。用户观察到 Codex 无此问题，推断其「加了一层外圈遮罩与边框线颜色一致」，问可行性 → 可行，本轮落地。
- 修法（五轮定稿）：`.window.fx-mica::before` 遮罩环 = **1px 边框线 + 1.5px 零模糊外扩阴影，同为边框色**——过渡带整圈淹没成边框色，内容边缘退入弧内不再直接暴露给 DWM 角弧 AA；与 DWM 染色线同色重叠合一，无双层。与四轮的本质区别：四轮「不画线让 AA 带裸奔」，五轮「把 AA 带涂成边框色」——弧线对齐问题不复存在（整个分叉带都是自己人）。
- 几何：环圆角 `calc(--n-radius-8 - 1px)` = 7 = DWM 裁切弧（~7 逻辑 px @150%）内缩 1 贴其内缘；外扩阴影 1.5px（= --border-strong 档）兜底各 DPI 裁切弧 ≤9 分叉；最大化 DWM 不裁角不画边 → 环同隐（`.window.maximized.fx-mica::before` 后置，与 picking 环同 0,3,0 优先级拼顺序压）。picking = 遮罩环换品牌色（与 DWM 切染 #3DDDD2 同色合一；`::after` 云母仍零画）。实色模式全不变。
- 探针 cdp-window-shell-probe.py：W2/W2c/W2d 改写（mica 遮罩环 1px rgb(51,51,51) + 阴影 1.5px + radius 7 / picking 环换品牌色 / ::after 零画），复跑全 19 项 PASS；vue-tsc 绿；curl 拉 vite 编译产物直验六条 ::before 规则齐全、层叠序正确（踩坑 064 流程 touch 先行）。
- 注释同步：App.vue 壳注释簇 + settings.rs set_main_border_picking 头注；踩坑 063 补五轮终版；速查表 §19 .window 壳口径四改。
- 实机四角观感（常态 + 选择模式 × 100%/125%/150%）留用户复验——headless 探针截不到 DWM 层，本轮与四轮同样只能验 CSS 侧结构。
