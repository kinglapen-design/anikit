# 修复：拖拽时整窗黑屏（用户实测，松手即恢复）

**修复：拖拽时整窗黑屏（用户实测，松手即恢复）**。根因 = 二轮 ⑤ 的 CSS 闸写在 AssetCard scoped 块内用 `:global(body.dragging) .thumb .actions`——**SFC scoped 编译把 `:global()` 后的后代选择器吞掉**，产物只剩 `body.dragging{opacity:0;pointer-events:none}`（dist CSS 实证），拖拽开始 body 加 dragging 类 → 整个 body 透明度归零、只剩窗口底色 = 全黑，松手移除类即恢复。修法 = 规则改非 scoped 全局块（`body.dragging .asset-card .thumb .actions`，类名原样保留可匹配 scoped 产物，特异性 (0,4,1) 压 hover 规则），构建后 dist CSS 验证产物正确。**教训：scoped 块内 `:global(x)` 只能整包选择器，不能带后代；全局规则老老实实写非 scoped 块或全局样式表**。tsc / build 全绿。
