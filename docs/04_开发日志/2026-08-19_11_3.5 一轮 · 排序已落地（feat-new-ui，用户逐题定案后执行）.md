# 3.5 一轮 · 排序已落地（feat/new-ui，用户逐题定案后执行）

**3.5 一轮 · 排序已落地（feat/new-ui，用户逐题定案后执行）**：
  - **定案口径**（用户逐问逐答）：轮次 = 先排序后分组；范围 = **全局统一**（应用级 settings.ui 现成字段 ui.sortBy/sortAsc）；键 **8 项** = 自定义 / 名称 / 文件大小 / 时长 / 扩展名 / 创建时间 / 修改时间 / 导入时间（00 总览与 04 预览 06 节出入——含时长）；作用 = **素材区全视图**（含快速访问），文件夹/档案卡片不参与；**修改时间 = 现有库内变更时刻**（非源文件 mtime 冻结值）；**创建时间 = 源文件磁盘创建时间**（导入时记，存量无值排尾）；名称排序用户补充**中文数字（一~万）与天干（甲乙丙…）按序**（不处理会按字符码乱序）。
  - **后端**：`AssetMeta.created_at: Option<String>`（serde default + skip_none 不升 DATA_VERSION）——导入管线 `source_created_at` 入库前读源文件 birth time（池内复制会刷新文件时间）；剪贴板临时文件 / 新建文档 = 建档时刻；副本 / 克隆继承源资产不刷新；序列帧 = 首帧源文件（Move 会删源，循环前读）。`PlacementView` 补 `size / createdAt / modifiedAt / importedAt` 四字段（views.rs 自 metadata 带出）。
  - **前端排序库 `lib/sortPlacements.ts`**：显示层排序不动存储序；**自然排序** = chunk 化（阿拉伯数字串 / 中文数字串解析数值 / 天干单字 / 文本段 localeCompare zh）逐段比，异类退化文本比；空值（无时长 / 无创建时间）**恒排尾**不随升降反转；平局恒名称自然排序 + assetId 兜底（不反转）。`placementsFor` 出口统一接排序（泛型保持 RecentAssetView/RecycleEntryView 扩展字段）。
  - **新增区（用户定"跟 window 一样但置顶"）**：排序状态下新增 / 导入 / 粘贴 / 副本的项不按排序键分散、**集中置顶**（先来在前）——找到新建文件 + 确认导入数量；**切视图再回来即归位**（sidebarSelected watch 清空），切库（afterOpen）/ 物化同清。content store `newArrivals: Map<key, 到达序号>`；登记点 = 导入 flush / linkPlacements / duplicatePlacements（后端已返回新 id 清单）/ createDocument。
  - **物化素材侧落地**（02 整理口径延伸）：显示排序下素材拖拽排序 = 该层可见序（新增区 + 排序流）物化为存储序、拖拽组按落点并入，`reorder_placements` 整层序列 + 段尾锚点一次重写（reorder_folders 物化同模式），切回自定义 + 清新增区；粘贴 / 新建不物化（无相对落点语义，用户定）。
  - **28 稿排序方式行点亮**：下拉 8 项（MenuItem checkable 对勾，同显示简介下拉）+ 升/降 segmented（**自定义时禁用**——AppSegmented 补 disabled 形态）；占位 disabled 行 / seg-disabled 死样式清除。
