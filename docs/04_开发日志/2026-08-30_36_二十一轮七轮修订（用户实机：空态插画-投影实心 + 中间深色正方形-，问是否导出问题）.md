## 二十一轮七轮修订（用户实机：空态插画"投影实心 + 中间深色正方形"，问是否导出问题）

- **诊断（非导出缺陷）**：folder-empty.svg 与 figma 稿逐字节一致——背板渐变 #333→#1C1C1C + 内阴影 filter + 1px 6% 描边 + 前板 fill #292929 50% 全在。"中间深色正方形" = **稿设计的前板**（半透明-2 压渐变背板下半，稿图同款暗区）。
- **真根因 = 双重 opacity**：figma 导出把节点 0.6 透明度烘进 SVG `<g opacity="0.6">`，EmptyFolderState CSS 又按稿文本叠 `opacity: 0.6` → 实际 0.36——图标过淡、前板暗区对比失真（像"实心投影/深色方块"），CSS drop-shadow 源 alpha 同步打折（40%→14% 黑，#171717 底上亮度差 ≈1 不可见，"没有模糊"的体感）。像素实证：图标顶缘亮度 33-38 ≈ 23+(51-23)×0.36 坐实 0.36。
- **修法**：删 CSS 叠的 opacity（SVG 自带），filter drop-shadow 保留（figma 外阴影不随 SVG 导出，本就靠 CSS 补）。导出约定记入速查 §22：装饰插画类稿 css 的 opacity = 节点自身属性导出已含，CSS 不重复叠。
- 探针：T17a 补「CSS 不叠 opacity（=1）+ filter 含 drop-shadow」断言；复跑 ALL PASS + 空态截图目验；vue-tsc 绿。
