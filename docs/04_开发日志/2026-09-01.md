## 阶段七 7.1 二十三轮走查续：封面设置两 BUG 修复（用户实机两报）

**① 封面确认后「又裁了一次」**——根因 = 前后端取景长宽比脱节：7.1 新稿取景框方形 240×240（CoverSettings `.cs-frame` aspect-ratio 1），后端 `bake_cover` 输出仍沿旧 43 稿 416×320（13:10，`COVER_OUT_W/H` 参与窗口数学）。cover 铺满窗口前后端不同 → 后端竖向多裁 ~23%，烘出 13:10 图再被方形展示框 `object-fit: cover` 左右裁一刀，合计放大 ~1.3×。修法 = 烘培输出改 **416×416 方形**（与框同比例，前后端公式恒等；像素档沿旧长边 416；存量 13:10 封面重设即更新，不做迁移）。踩坑 067。

**② 角标改名后中间面板卡片角标消失**——根因 = `set_archive_cover_settings` 懒建条件误写 `iter().all(|a| a.folder_id == folder_id)`：空表 / 全表皆本档记录时 all 成立 → 每次确认追加同 folderId 空壳副本。读侧不对称伪装成「改名丢失」：详情 `get_archive_data` 用 find（首条 = 真数据，右栏正常）；卡片 `list_archives` 全量返回、前端 map 后写覆盖 → 空壳赢。修法 = 条件改 `all(!=)`（custom_data.rs 同口径，编辑路径懒建不写 created_at）+ 开库自检 `fix_archives` 加**同 folderId 去重保留首条**（存量坏数据开库自愈，备份门禁既有）。附愈：旧条件在「他档有记录本档无」时懒建跳过 → expect panic。踩坑 066。

**验证**：cargo test **407** 全绿——新增 `cover_settings_lazy_create_never_duplicates`（他档有记录不 panic / 唯一记录反复设置零副本 / 三角语义不串）+ `open_dedups_archive_records`（重复记录去重留首条 + 落盘）；`cover_bake_crops_by_crop_params` 断言改 416×416 + 中心采样点同步。前端零逻辑改动（CoverSettings 头注同步方形口径）。

**文档**：07 接口文档烘培规格改 416×416；00_当前状态新条目 + 6.1 一轮旧条注记；踩坑 066/067 新立。
