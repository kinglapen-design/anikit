**新 PRD 三份定稿并落入正式 PRD（用户草稿 `00_修改与需求/01_新PRD/`，逐模块讨论迭代后由主代理统一转写）**：
	- **01_储存空间**：相比草稿增补讨论定案——多储存空间完全独立 + `.anikit` 素材包导入合并（用户修订，取代"仅一个空间"）；多库允许合并；workspace 经 junction 映射至其他路径（不考虑散落各处的项目文件夹）；四步向导每步可下一步跳过；**工作空间链接落盘**——素材链接 = NTFS 硬链接（同卷免权限、fileIndex 识别、hover 全部链接），档案/文件夹不整体物化（防双向同步高耦合），需要时提供"物化到磁盘"动作。
	- **02_文件整理（新体系，章节重排）**：区块（自定义分区、默认区块「目录」不可删 = 保留层级导入落点、删除区块内容去未分类、导出物化为顶层平行文件夹）；目录树视觉（区块根父级底色默认灰 / 拖入自动灰 / 父级色子项 10% / 图标可勾选影响全部子级）；**档案文件夹**（文件夹右键转换 / 无子文件夹约束 / 树内无箭头专属图标品牌紫圆圈 / 档案不作拖拽父级仅排序、纯文件可拖入 / 中间面板文件夹·档案·文件三区 / 回收站保持封装=当单文件看待、序列帧同 / 固定长宽比卡片、头像=封面同步 / 档案内二级侧边栏）；**分组**（档案与普通文件夹通用；未分组默认；规则 = 扩展名/类型/名称 AND/添加日期/修改日期）。
	- **分组规则冲突三条（用户草稿 + 讨论微调）**：完全相同禁存；单规则组互斥——自动转移 + toast 明确告知（取代草稿"静默自动取消"，防用户困惑）；多规则组合最具体优先（命中条件多者胜，平局按定义顺序）。**日期分组定案**：默认导入日期（稳定）可切修改日期（fla 活文件场景），创建日期不做；分档互斥（今天/昨天/本周早些时候/上周/本月早些时候/更早），一个文件只出现一次，"看本周全部"归筛选而非分组。
	- **03_数据链接**：文件详情 = 颜色/名称/链接/基础信息/链接区块（最多三段路径：区块/根父级/所在目录）/归属档案/提示词/关系/音色；档案差异 = 头像（取景框编辑、伴生缩略图与 PSD 可作来源）/徽标（可隐藏）/属性（短文本 `|` 分隔）/描述（标题+长文本超行展开）。**属性/描述命名定案**（用户问，采纳——通用且不撞已砍"标签"概念）。**提示词流程**：分析不主动建文档，三动作 = 创建 MD（自动放源文件同目录）/ 编辑器（须先存 MD）/ 复制；指定文本 = 引用 + 快照（源 MD 删不断链）。**关系双向**：正向标签 + 自动中性反向称谓可手动精化（儿女→儿子）；音色 = 关系预定义 kind。
	- **资产选择器（统一"选另一个文件"操作逻辑，用户三连问归一）**：拖拽为主（同屏拖卡片进详情目标区块）+ 选择器弹窗为辅（不平铺全部——搜索 + 区块/目录树导航 + 当前档案/最近使用置顶）+ 头像专属入口（档案内右键"设为档案头像"）。
	- **数据落地规划（草稿授权主代理规划）**：关系/音色统一 relation 模型 `{from,to,kind,label,reverseLabel?}` 存空间级 relations.json（关系可跨库）单一写点；头像 = {源资产 ID, 取景框参数}；内部链接统一 `anikit://item/{ID}`。
	- **分词搜索命中范围扩展（用户讨论定案）**：纳入 = 资源名/Placement 显示名/扩展名/链接/所在路径（区块·文件夹·档案名）/属性/描述/提示词/关系与音色对象名及关系名/徽标文本；度量类（颜色/尺寸/大小/时长/日期/比例）走筛选不进分词。**匹配规则**：子串包含、不区分大小写、空格 AND；**链接字段匹配前 URL decode**（用户问"pinterest 长链接"场景——`q=%E6%A1%A3%E6%A1%88` 解码后输"档案"可命中）。实现备注：短文本内存索引扫描即可，提示词为唯一大文本源，量大后上倒排接口不变。
