# 3.4 九轮 · 删除位置级模型（feat/new-ui，用户定"护栏拆干净"——链接当真实文件对待，origin 不主动转移）

**3.4 九轮 · 删除位置级模型（feat/new-ui，用户定"护栏拆干净"——链接当真实文件对待，origin 不主动转移）**：
  - **delete.rs 重写（位置级）**：「从文件夹中移除」（Shift+Del / uncategorized）= 任何 Placement 挪未分类（不删记录、名称与 origin 标记不动）；「丢到回收站」（Del / recycle）= 该位置从 folders.json 移除 + recycle.json **按资产聚合**记录（同资产条目追加 placements）。**"最后一条"判定、两段式 needConfirm、origin 自动转移三机制整体废除**（DeleteReport 退役，命令返回 void）；origin 进回收站后链接可以活着挂目录树，资产可以暂时没有 origin（物理实体由 info 承载）。
  - **recycle.rs 分级彻底删除**：快照含 origin = 资产本体在回收站 → 物理删 info + **库内活链接随清** + 四同步；纯链接位置记录 = 只删条目，物理不动、无需确认。`linkRefs` 语义从"快照内"改为**库内活链接计数**（物理删本体才拦确认）。还原撞名放开（restore_recycle 不唯一化，名称原样写回）。
  - **purge.rs 跟随**：删除文件夹子树 origin+链接**全部回未分类**（"链接随文件夹删"废除）+ 删文件夹重名唯一化摘除；permanent 彻底删除文件夹补清**他处指向子树资产的链接**（本体死链接必死）。
  - **测试重写 7 份**：delete.rs 全新 2 用例（挪 root 原样 / 位置级回收站+聚合+不转移）；recycle.rs 还原撞名放开 + 活链接警示 + 纯位置记录只删记录 2 新；purge.rs 链接回 root 改写 2 + 批量断言 1。cargo test **333 全绿零警告** / typecheck / build 全绿。
  - 文档同步：PRD 01 边界规则 2（删除语义位置级重写）+ 规则 8（origin 不主动转移，取代自动转移）/ PRD 02-13 删除条重写 + 02-15 链接去向（删文件夹全回未分类）+ 链接区块（回收站资产活链接照常反查）/ 07 接口文档（delete_placements / restore_recycle / delete_recycle·clear_recycle 分级 / delete_folder）/ 09 待办（⑪显示名放开全闭环；阶段六「设为原始文件」条目按新模型修订——本体在回收站时活链接可设为原始文件，彻底清除即降级为只删记录）。
