# 文件夹卡片走查再修（2026-08-10 用户截图反馈二轮）

**文件夹卡片走查再修（2026-08-10 用户截图反馈二轮）**：① **角部尖刺**——outline 负 offset + border-radius 在 Chromium 下角部渲染 artifact（偶尔卡片角外露品牌色小尖角）；1.5px 状态边框三轮定案 = `::after` 伪元素 border（inset 0 / border 1.5px / 圆角跟随 / 不占布局，同旧 icon-wrap::after 机制），inset box-shadow 1.5px（渗线）与 outline 负 offset（尖刺）两案均弃；② **文件夹卡片重命名点素材卡片区不确认**——根因：素材区 pointerdown 走框选回调 `useMarquee.onPointerDown` 的 `e.preventDefault()` 阻断焦点转移、input 永不 blur；修法 = `gridPointerDown` 分发入口统一 blur 活跃 input/textarea（其 @blur 提交逻辑随之触发；重命名 input 自身 pointerdown 已 stop 不到此），覆盖点素材卡片 / 文件夹卡片 / 空白全部路径。tsc / build 全绿。
