# 收件箱"文件被占用"搁浅修复（用户实测：Animate 保存 fla 后仍持有文件）

**收件箱"文件被占用"搁浅修复（用户实测：Animate 保存 fla 后仍持有文件）**：就绪探针原为只读打开——持有方允许读共享时探测通过，但导入 move（rename）需 delete 共享必败，条目已出队再无事件触发，文件搁浅 inbox（仅下次启动清点补入）。探针改"可移走"口径：Windows 以 GENERIC_READ | DELETE 访问 CreateFileW 探测（与 store_file 的 rename 判定同源，自身放开全部共享即开即关；CreateFileW 需 windows crate 补 Win32_Security 特性），未放手就留队列每拍重试，放手后下一拍自动入库；非 Windows 以读写打开近似（POSIX rename 不受持有影响）。新增持锁判定单测（只读共享持有 → 不可移走，释放 → 可移走），cargo test 60 过零警告。残留竞态（探测到移动间隙被锁）由启动清点兜底。
