# 复验三需求（文件夹卡片进入 / 名称双击改名 / 新建先建后命名）

**复验三需求（文件夹卡片进入 / 名称双击改名 / 新建先建后命名）**：① **后端新命令 `rename_folder`**（trim 校验非空 + Windows 非法字符 + 保留名，同名幂等，索引重建 + 落盘，撤销标签"重命名文件夹为 xx"；3 用例含撤销回滚）。② **文件夹卡片**：双击非名称区 = 进入该文件夹（FolderStrip onEnter → sidebarSelected）；名称加 .folder-name（hover cursor:text）双击就地改名（Enter/失焦/Esc 一律保存，非空且变了才调 renameFolder）。③ **素材卡片名称退出框选空白**：.title / ListRowCard .name 移出 card-info（meta 尺寸行保持框选起点），hover cursor:text、双击就地重命名（selection.renamingKey 既有机制）、pointerdown 回卡片本体分支（可拖拽/单击选中）。④ **新建文件夹"先建后命名"**：三入口直接 createFolder（前端算同级唯一默认名"新建文件夹/-2"…）→ 新节点命名态（namingFolderId，祖先链强制展开）→ 失焦/Esc/Enter 一律保存退出（不再取消新建；空或不变保留默认名）；FolderTree 临时节点逻辑整体删除。顺手修：三处重命名输入框补 @dblclick.stop（双击选词曾冒泡触发预览/进入）。cargo test 206 过、clippy 清零、tsc / build 全绿；07 接口已同步。
