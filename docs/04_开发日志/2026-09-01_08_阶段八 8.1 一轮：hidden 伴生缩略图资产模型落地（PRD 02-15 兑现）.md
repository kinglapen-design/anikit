## 阶段八 8.1 一轮：hidden 伴生缩略图资产模型落地（PRD 02-15 兑现）

**范围**：hidden 数据模型 + 视图过滤 + 工程卡片代理显示 + 绑定/还原命令——CEP 导出链路的入库语义底座，独立于插件可先行（WS 服务 / CEP 正式版归二轮）。

**后端**：

- `models.rs`：AssetMeta 加 `hidden` / `thumb_asset_id`（serde default+skip_none，不升 DATA_VERSION）——PRD 02-15 的 thumbAssetId 模型落盘形态。
- `views.rs`：PlacementView 加 `hidden`；**缩略图代理** = thumb_asset_id 有效（目标存在且 hidden）时 thumbPath/thumbKind/thumbW/thumbH 取目标 hidden 资产——fla 卡片直接显示伴生 WebP 的图；目标未 hidden 不代理（半态护栏）。经 `lib.index.assets` 解析零签名改动，五处调用方（import_task / recycle / recent / import / document）天然生效。
- `asset_menu.rs`：`set_thumb_asset`（绑定/换绑：护栏 = 自绑 / hidden 再绑套娃 / 非图片动图格式拦截；重复幂等；多工程共绑；换绑不动旧 hidden 等用户处理；写序先引用后 hidden 防有害半态）+ `restore_thumb_asset`（还原为素材：解 hidden + 联动清全部工程引用，返回引用数）。不接撤销（同缩略图三件套口径）。
- `library.rs` 开库自检 `fix_thumb_refs`：剔除指向不存在资产的 thumb_asset_id（两段式——改内存 → 备份门禁 → 逐资产 metadata.json 落盘；反向不查：hidden 无引用 = 换绑遗留合法态）。
- `recycle.rs sync_after_purge`：彻底删除 hidden 资产时他处 thumb_asset_id 引用联动清除（purge / 回收站两路径共用此收尾）。
- `search.rs`：hidden 资产全范围搜索不命中（非用户管理对象；回收站快照范围不过滤，管理语义保留）。

**前端**：content.ts placementsFor 普通视图统一过滤 hidden（folder 直陈 + 递归两分支 / quick:all / uncategorized / inbox / recent——**递归分支首版漏改探针 H3 逮住**）；`quick:thumbnail` 点亮 = hidden 集按资产去重显示一次；allCount / uncategorizedCount / inboxCount 过滤 + 新 thumbnailCount（去重同口径）；LibraryView 缩略图项计数接入（UI 本已渲染，零改动）。

**验证**：cargo test **417** 全绿（+7：绑定落盘 / 换绑与共绑 / 护栏三则 / 还原联动 / 视图代理与半态 / 开库自检端到端 / purge 引用清理）；vue-tsc 0 错 + build 绿；新探针 `tools/cdp-hidden-thumb-probe.py` **8 项全 PASS**（H1 全部视图过滤 + 计数 / H2 未分类 / H3 文件夹链接位置 / H4 缩略图视图去重 + 计数 / H5 fla 卡代理图 / H6 搜索不命中）。

**文档**：07 接口（PlacementView.hidden + 两命令条）/ PRD 02-15 落地标注 / 00 状态同步。

**遗留（09 待办 / 二轮）**：缩略图视图「标注绑定的工程」展示与详情「缩略图」区块反查；fla 卡片动图播放代理（播放源 assetId 代理给 hidden 资产，本轮只代理静态图）；手动「将 xx 设为缩略图」菜单入口（CEP 自动绑定先行）。
