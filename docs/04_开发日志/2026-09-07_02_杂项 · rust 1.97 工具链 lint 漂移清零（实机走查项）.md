## 杂项 · rust 1.97 工具链 lint 漂移清零（实机走查项）

1.97.0 语言变更「`Result<T, !>` / `ControlFlow<!, T>` 的 must_use 视同 `T」+ clippy 新 lint（needless_match / doc_overindented_list_items 等）叠加，全仓 47+49 黄。按类收口：

- **doc 注释列表**（doc_lazy_continuation / doc_overindented_list_items，9 个文件）：列表后的模块级注记补空 `//!`/`///` 行分段（search / recycle / library / clone / delete / operations-sequence）；行首 `+` 被 markdown 误当列表标记的换行重排（services/font、commands/font）；plugin_ws 过深缩进改 2 空格对齐。
- **unused_must_use**（font.rs ×6）：Win32 清理调用显式丢弃——`let _ =` RegCloseKey ×5 / RemoveFontResourceW ×1（结果本就无意消费，let _ 表意）。
- **needless_match + manual_map**（commands/preview.rs:63，仅测试构建）：`#[cfg(not(test))]` 抽空 None 臂后 match 退化为恒等映射——重构为 `let hit` + cfg 门控 `if hit.is_none()` 提交懒生成，两构建语义不变。
- **plugin_ws 死代码墙**（测试构建）：lib.rs 的 `server::init` 调用点本就 cfg(not(test)) 门控（踩坑 014），但模块内服务器路径未门控——对齐 frame_stream 手法：init / serve / handle_conn / write_port_file / welcome_payload / tree_payload / handle_exported / handle_thumb_only / resolve_paste / fail_pending_of + 6 行仅服务器路径使用的导入全部 `#[cfg(not(test))]`；server/mod.rs 再导出同步门控 init、摘掉全仓未命名的 PastePermit；type_complexity 提 `PendingMap` 别名；pump 去多余 mut。
- **decoder.rs 5.3 视频/音频引擎**（2026-08-22 随视频播放回滚 `<video>` 直读拆除，仅测试在用）：**用户当场定案全删**（视频播放定线 `<video>`；方案与代码存档见 git 历史）——VideoDecoder / Pull / AudioChunk / VideoOpts / decode_video_once / 音频三件套（resample_into / f32_plane / emit_chunk）+ AUDIO_RATE/CHUNK + 6 个专用测试全删，decoder.rs 收编为纯 GIF 单趟解码（decode_once 生产在用，其 3 个 GIF 测试保留）；孤儿样本 tools/test-assets/sample.mp4 同删（仅视频测试引用，README 同步）。
- **其余零散**：color sort_by_key(Reverse) / custom_data 去同型 .into() / import 去多余 & / inbox 改 std::slice::from_ref / cep_export within_limit 改 `#[cfg(test)]`（仅测试断言用）+ assert! 替 assert_eq!(.., false) / import_task 两函数补 `#[allow(clippy::too_many_arguments)]`（同既有 5 处口径）/ frame_stream serve_ws 补 `#[allow(clippy::result_large_err)]`（tungstenite 握手回调 Err 变体签名既定无法装箱）/ anim_preview_queue `&PathBuf`→`&Path`（Path 导入随 emit  cfg(not(test)) 门控）/ operations/mod 摘掉 3 个全仓未命名的 Outcome 再导出 / operations-sequence `target_folder` 字段 allow（生产侧不读，测试 440 行钉落点语义）+ paths 导入 cfg(test) 门控 + manual_contains。
- **顺带修既有红**（与本项无关）：cep_install `BUNDLED_VERSION` 0.2.0→0.3.0——09-06 三轮走查 bump manifest 0.3.0 时漏同步常量（测试钉的同步不变量）。
