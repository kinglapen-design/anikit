- **右键菜单体系讨论定案（用户 UI 重构设计期逐条确认，PRD 已同步 02-13/14/15、03 链接区块）**：
	- **Eagle 操作哲学分析**（用户问 Eagle 为何文件无剪切、文件夹仅克隆）：素材库 = 实体与组织分离，复制/剪切在库语义下歧义（引用还是实体？悬空焦虑）；我们的对策——文件夹对齐 Eagle（无复制剪切、仅拖拽 + 克隆弹窗），剪切保留（语义明确 = 移动 Placement + 6.0 撤销兜底危险感），复制 = 关联弹窗比 Eagle 隐式链接更明确。
	- **档案剪切/复制/粘贴**：剪切允许（"当单文件看待"一致性）；复制不叫复制——给克隆（链接克隆/复制克隆弹窗，复用 6.2 克隆文件夹）；档案仅作粘贴接收方（仅纯文件，同拖拽规则）。
	- **文件夹剪切放开**：三种实体剪切全通（剪切=移动，护栏复用 move_folders 循环校验 + 失效 toast + --opacity-cut 半透明）；"复制"在树节点不存在，统一走显式命名操作（关联/克隆）。
	- **粘贴三键（用户 mockup 定键位）**：Ctrl+V 链接（静默）/ Ctrl+Shift+V 链接并重命名（选择性粘贴弹窗，原关联弹窗降级为显式入口）/ Ctrl+Alt+V 副本——键位语义：V=链接族、+Shift=同族加强、+Alt=换族副本；与现有实现键位互换（6.1 的 Ctrl+Shift+V=副本），记入 05 待办开发对齐。Ctrl+拖拽同步改直接链接不弹窗。
	- **高级重命名**：单弹窗多模式（重命名并编号 / 查找替换 MVP 纯文本无正则），不单设"查找替换"入口；必备实时预览（旧名→新名全列表）。

	- **删除菜单分流**：多条 Placement 仅显示「从文件夹中移除」（可撤销，不进回收站），最后一条才显示「丢到回收站」。
	- **候车区规则（未分类/收件箱，用户定）**：资产级去重只显原始文件；可移出分类摘标、禁拖入、禁链接（发起与落点都禁——用户论证：允许未分类建链接会导致"分好类的全是链接、原始文件滞留未分类"语义倒挂）；副本例外（新 ID 独立资产）。
