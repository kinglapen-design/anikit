# 6.2 三轮：文件链接（17 稿链接管理）+ 链接音频（voice 关系 + 音频区块）


**背景**：继续 6.2（用户："选择模式已做，继续接入音频，文件链接。文件链接的 UI 为链接管理"）。开工五问定案：① 范围 = 链接音频 + 文件链接两块（副本 / 工程恢复文件 / 头像「从资源库中选择」后置；工具栏按钮也接入，**工具栏与新增菜单的链接管理钮删除**——"这个是针对某个文件的，右键菜单和详情面板有入口就行"）；② 弹窗语义 = 管理**一个文件**的链接分布（左列 = 侧栏文件树照搬——红底只是文件夹自定义色按实际设置、数量 = 文件树递归数据、组头纯显示 + 钮不接线、文件不能脱离文件夹放根目录；同文件夹重复链接**平铺多行**，"后面版本迭代重构 UI 时再重新设计这个面板的逻辑——批量选择文件管理做不到"）；③ 备选区文件行 = 名称输入框（"稿的名称框本身就是输入框"——PRD 03-04 与 02 稿不冲突）；④ 链接音频 = 多选累积；⑤ 档案多位置（角色档案整体链接到其他项目不散落）= 数据模型级改动，**立项后续做**。

**后端**：
- `add_relations` 加 `kind?` 参数：`voice` = 无称谓（label 恒空串、reverseLabel 恒 None），**to 必须音频 asset**（mp3/wav/wma 小写比较），from 可 asset / archive（档案也能链音频）；free 口径不变。撤销标签分流"链接音频 / 链接 N 条音频"。
- 新命令 **`sync_asset_links`**（链接管理一次提交，单撤销步标签"链接管理"）：adds（链接前插 + 唯一化，空名回退资产名）/ removes（**直接删记录不进回收站**——用户定；陈旧跳过）/ renames（链接仅改显示名；origin 行 rename_placement 全语义同步磁盘 originName 段登记 DiskOp）；**name/oldName 可选精确到行**（Placement 无 ID，三元组只命中第一条——2026-08-13 重复链接放开后平铺多行必须）；**护栏：位置归 0 报错**（防孤儿资产）。测试 2 用例（增删改 + 重复行精确）cargo 400 绿。
