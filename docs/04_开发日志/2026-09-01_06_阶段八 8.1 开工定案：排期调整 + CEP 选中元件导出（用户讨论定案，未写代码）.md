## 阶段八 8.1 开工定案：排期调整 + CEP 选中元件导出（用户讨论定案，未写代码）

**起因**：用户报开发进度太慢、素材急需整理——真正痛点 = fla 工程文件无伴生缩略图，整理时全是格式图标盲盒。确认排期调整：阶段八拆分提前至阶段七 7.1 暂停处（二十六轮刚收尾待实机复验，干净暂停点）。缩略图主体（静态图/视频/序列帧/动图/音频波形/字体/shell 图标）阶段四五已完成，唯一缺口即 fla 伴生图。

**讨论定案过程**（逐项问定）：

- **起步路线**：用户要求先看接口设计——后续新增其他软件插件不能返工已写代码。回应：统一 WS 服务 + 适配器接口（PRD 07 §01 既定方向），jsfl 直启 = Animate 适配器的离线通道（同一指令接口换传输），非一次性凑合代码。
- **范围（用户定）**：先做 CEP 导出 WebP 动画或静图，只做元件选中导出对齐舞台中央；WebP 与新建 fla 导入 APP 自动创建链接；缩略图进快速访问、fla 进未分类；CEP 内识别 APP 树形结构选文件夹（可行：WS 双向通道下树数据本就是 JSON 传输）；本阶段完成后才做 APP 内批量导出。
- **「链接」语义**：按 PRD 02-15 hidden 资产绑定模型（thumbAssetId）——普通视图过滤 hidden、缩略图视图标注绑定工程、fla 卡片直接播 WebP 动图；用户无补充异议。
- **导出交互形态**：面板预设 + 一键导出（不弹确认窗）。
- **帧数/大小**：默认 10 秒上限；大小软上限 2M——用户疑虑"会不会太小"，给参考数据（静图 50-200KB 绰绰有余；10 秒 240 帧 1024px 有损 WebP 简单内容 0.5-2M、复杂 3-8M）后定**软上限 + 自动降级链**（降质量 80→60→40 → 缩尺寸 1024→768→512 → 减帧率，压不进也留产出并提示）；用户确认大小限制只作用于 ffmpeg 合成环节（PNG 无损中间产物合成完即删）。
- **设置共享（用户问 CEP 能否接收 APP 设置）**：APP 全局设置单写点 → WS 连接下发 + 变更推送，插件本地缓存兜底；8.2 批量导出读同一份天然一致。APP 设置页 UI 随 8.2。
- **面板样式**：纪律上无稿禁自创——用户定套用 APP 现有暗色 token 朴素功能版先跑通，正式稿后补。
- **用户补充两笔**：① 命名输入框默认填充元件名可改（工作中元件名多为"元件1"类默认值无参考意义）；② 树选择器默认未分类，懒得选可直接导出。

**文档**：PRD 07 新增 03 节「实施定案（2026-09-01）」全量收录；01 路线图阶段八条改写（8.1 CEP 导出 → 8.2 APP 批量导出 → 8.3 CEP 完整能力 → 8.4 Chrome）；00 当前状态同步。

**下一步**：spike 验证 CEP 环境（面板在本机 Animate 跑起 / WS 连通 / jsx 导出 PNG 序列 + 另存 fla），通过后正式开发。
