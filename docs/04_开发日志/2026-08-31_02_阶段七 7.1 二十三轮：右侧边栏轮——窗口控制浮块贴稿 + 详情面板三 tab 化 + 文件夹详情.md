## 阶段七 7.1 二十三轮：右侧边栏轮——窗口控制浮块贴稿 + 详情面板三 tab 化 + 文件夹详情形态 + 选择模式贴稿

**定案（八问用户）**：① 旧「pinned + 7 排序区块堆叠栈」三 tab 化——只有链接关系 tab 内区块（带标题行）可面板内拖拽排序，其他无标题不可拖；排序/显隐管理面板后续轮（「信息查看管理」底部钮本轮点亮不接业务）；② 窗口控制维持 App 浮块（2026-08-08 不参与收展定案不变），仅贴稿改样式；③ 右栏收展钮**恒显**中间面板工具栏最右侧（二十一轮做工具栏时用户忘说，本轮补）；④ 旧「副本」区块废除、笔记区块（DetailNotes）摘出等补稿接回；⑤ 链接 tab 缩略图/污染文件两区块 = UI 占位不接业务（「图片被用作缩略图次数」反查与 info 文件夹异物文件均后续立项——「这是 UI 重构，业务层面后面再说」）；⑥ **文件夹详情形态**——视口未选中文件时显示当前视口文件夹/档案信息；选中普通文件夹也显示该文件夹详情；快速访问简化版（无缩略图、名称框禁改名、文件数/占用空间两行）；⑦ **按钮序全局改「取消左 / 确认右」**（"确认放右边确实更顺手"——速查表 §1 旧「主左次右」口径废除，存量弹窗随轮翻转，09 待办⑥）；⑧ tab 默认「基础信息」+ 会话级记忆（换选中回 basic）；档案形态三 tab 同构按档案数据渲染；属性 chip 字档 figma「标签」12/17 未收录 Token.md——就近用次要文字 12/16 不补 token。

### 同日 · 二十三轮实机走查六条修复（用户反馈逐条落地）

用户实机走查提六条，全部当晚修复：

1. **tab 切换滑动动画**（用户原话「为啥每次都不主动去做动画效果」——流程级教训已写入 ui-refactor skill §4 已定口径：稿 prose 提到动效必须同轮落地，禁静默省略）：DetailSections tab 内容区加滑动切换——侧栏分段切换范例同款时序（退 150ms 缓出 / 入 250ms 缓入 delay 100ms / 位移 48px / 离场 absolute 不占位），**方向随 tab 序**（向右切 = 旧左出新右入，与分段滑块同向；向左反向）；切 tab 滚动回顶；`.tab-pane` 包层（Transition 单子元素——TabBasic 等多根组件）。
2. **分段图标着色失效**——根因 = basic-info / link-relations / prompt 三 svg 入库时漏转 currentColor（figma 烘焙稿中状态色：basic-info 恒一级 #F2F2F2、另两个恒三级 #808080），`.seg-item` 的 color 档驱动被绕过（选中不变一级、未选中反亮）。三图标转 currentColor + 命名对照八批登记；skill §4 同步加「入库必查线条层色值」。
3. **窗口控制区透窗口底**（用户：「不要底色，用主窗口的云母，菜单栏/标签/窗口控制连起来」）：`.sidebar-right` 根摘掉 background g1 + border-left g3，改 `::before` 只画顶行 46 以下；顶行透云母/实色-1 与菜单栏、标签栏同行连片。附效：border 不占布局后栏内容宽 263→264 与 detail-root 定宽齐平（原左缘 1px 隐性裁剪消）。
4. **封面编辑边距内收 24 修复 + 展开动画**：根因 = 双重 padding（二十三轮 CoverSettings 根自持 12 叠 pinned 12——6.1「防双重 padding」旧坑回潮）；修法 = CoverSettings 根不自持 padding（挂载点 pinned 恒 12，唯一挂载点）。**展开/收起动画 = pinned 根高度 FLIP 补间 250ms 缓入缓出**（稿 prose「向下展开设置」；翻转前后实测 + overflow 锁裁剪；transitionend + timer 290ms 双通道收尾，expandAnim 同款手法）。
5. **链接 tab 标题行常显**（用户：「没有内容标题也要在，标题上的添加按钮本身就是一个入口」）：SectionTitle 扩 `staticActions`——折叠钮 + 动作组不随 hover 常显（区块稿常态帧即画出按钮组；树容器/列表容器等其余调用方 hover 现身口径不变，速查表 §14 受控例外条）；五区块标题行本就恒渲染（探针断言加固）。
6. **描述收起态留一排截断**（用户：「只留标题完全不知道写的什么」）：标题行折叠钮收起 = 正文留一排 -webkit-line-clamp 1 截断（自带省略号），不再整段隐藏；3 行截断 + 展开/收起小字钮（6.1）只在非收起态出现；measure 对收起态保持旧判定。PRD 03_数据链接描述条同步。

**同日二轮修订（用户实机走查）**：tab 切换动画方向**改恒定旧左出 / 新右入**（与左侧边栏分段切换统一）——初版按 tab 序双向（fwd/back 与分段滑块同向）被否：「左侧边栏是恒定左出右入，这边统一一下，不然语义不统一，看起来挺迷糊的」。DetailSections 删方向计算（TAB_INDEX/tabShift），Transition 固定 `tab-x` 一套类；探针 R10e 断言同步，38 项全 PASS 复跑。

**同日三轮（用户实机报「封面展开看不到按钮但能盲点」）**：根因 = 二轮窗口控制区透底引入的 `.sidebar-right::before` 背景层——absolute 无 z-index 伪元素列 CSS 层叠第 6 层（z-index auto 定位元素档），**盖在正常流内容之上**：右栏所有无定位元素（ActionButton 更换封面/取消/确认/信息查看管理、cs-slider 等）被 g1 伪元素盖住，`pointer-events: none` 让 hit 穿透 → 「能点不能看」；带 position 的元素（封面框/输入框/分段控制器/tab 滚动区 relative）同层 DOM 序在后侥幸可见，现象呈「部分消失」极具迷惑性。修法 = aside `isolation: isolate` + `::before z-index: -1` 沉底。探针补 R4c2 沉底断言 + R13c 封面编辑态截图（r23c-cover-editing.png 目验五件 + 管理钮全可见）——**computed/几何断言测不出层叠遮挡**，踩坑 065 新立。排查弯路：无头复现全正常（断言只查存在性/几何），用户一句「能盲点」定位到遮挡方向。另：探针复用用户 5373 dev 实例拿旧样式一轮 FAIL（踩坑 064 同款，touch 后过）。
