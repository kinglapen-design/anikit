# 阶段四·预览窗口对接帧流（用户实机报"删掉解包逐帧序列后预览无法播放"）


用户走查发现：删掉某动图 `info/frames/` 解包产物后预览窗口播不了（播放条 1/0，走 list_sequence_frames 旧链），卡片却正常（帧流不碰 frames/）——预览还没对接。本轮对接，动图预览播放整体切帧流。

- **协议与播放控制（后端）**：帧头 16→20 字节加 `idx u32le`（源帧索引 0 起循环回绕——播放条帧号/进度用）。会话加三控制：暂停（publish 后阻塞轮询 5ms，stop/恢复/seek 可唤醒）、倍速（delay/rate，AtomicU32 存 f32 bits）、**seek**（GIF/WEBP 无索引只能顺序解码：目标在当前之后 = 快进——不推帧不睡眠纯解码；已过 = 中止本趟重开从头快进；到位按播放态继续或停住，暂停 + seek±1 = 逐帧步进）。新命令 `set_anim_stream_playing` / `set_anim_stream_rate` / `seek_anim_stream`；clamp 上限 1024→4096（预览视口×zoom，卡片前端自 clamp 1024 不变）。
- **前端 preview store**：动图播放从"rAF 引擎切 `<img>` src（吃 list_sequence_frames 帧图）"整体换帧流——loadAnim 起会话（视口短边×zoom 出帧、进入即播、倍速跨素材同步、封面帧 seek 定位），onFrame 驱动 frame/animTotal（max(frameCount, 已见 idx+1)，分母不依赖帧清单）/natural（尺寸热更新换算保视觉）；**seek 拖动期间忽略在途旧帧**（帧号不被拉回跳动）。setFrame/stepFrame/play/pause/setRate 按 kind 分流（sequence 引擎不动）。帧流失败回退原生 `<img>` 播源文件（无播放条）。
- **解包产物用途收窄**：list_sequence_frames 帧清单仍拉——已解包时设封面 / 帧条小图 / 逐帧笔记照常（PreviewFrameStrip 零改动）；未解包此三项禁用（PlayBarFrames 统一播放条 + disabled，"解析中…"分支退役），播放不受影响。anim-unpacked 事件到达重跑 loadAnim 解锁。frames/ 存废本身不动（待用户定案）。
- **画面**：新组件 PreviewAnimCanvas.vue（watch store.animFrame → putImageData，铺满 .img-wrap，缩放/平移/旋转/翻转随查看器体系；占位缩略图在下层，出帧盖住；img onload 在帧流活着时不喂 natural——防 320 缩略图抢尺寸）。出帧尺寸跟随：PreviewPanel watchEffect（viewW/H/zoom）→ syncAnimSize → setSize（放大看细节跟随清晰，4096 封顶）。
- **验证**：cargo test 351 绿（+3：暂停恢复 / seek 定位与回退 / 倍速）；typecheck / build 绿；卡片探针协议头升 20 字节复跑 PASS；新探针 `tools/cdp-preview-anim-probe.py`（用户场景回归：桩 list_sequence_frames 恒 unpacking 空清单）——预览照常出帧 / 帧号推进 / 暂停恢复命令序列 / 拖动 seek 合法 / 笔记+设封面禁用 2 钮，全项 PASS。07 接口 / PRD 04 同步。
