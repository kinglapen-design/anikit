# 阶段五 5.3：视频全面接入自研解码器（帧流 + 全自研 PCM 音频）

# 2026-08-22


用户指令"继续 5.3，全面接入新的自研解码器"。开工一问定案：**音频 = 后端 PCM 全自研**（后端 ffmpeg-next 解码音轨 → 48kHz 立体声 f32 PCM 经 WS 推前端 → WebAudio 播放；音量/静音 = 前端 GainNode 纯本地）——备选"隐藏 `<video>` 只出声"（同步漂移 + 浏览器编码限制仍在）与"本轮无声"（违 PRD 音量条文）均被否。

### 后端

- **`adapters/decoder.rs`**：`decode_video_once`——视频 AV 同趟解码：**真 seek**（`start_secs>0` → `ictx.seek`（AV_TIME_BASE 微秒，关键帧落点）+ 前向丢帧，帧区间 [pts, pts+delay) 整体在起点前才丢 = 跨点帧精确命中，任意方向同径）；帧 pts = best_effort_timestamp；音轨 best Audio → `resampling::Context` 重采样 48k 立体声 f32 packed → 攒 1024 帧/块回调（块 pts 锚定首样本、按块长累加）。`DecodedFrame` 加 `pts_ms`（gif 桥填趟内累计 delay）。缩放抽 `scale_frame` 共用（gif 老路不动）。坑两枚：`timestamp()` 不回落 pts（单测手造帧须 set_pts，生产解码器恒有 best_effort，代码已加 pts 回落兜底）；**`frame.plane::<f32>()` 长度 = samples() 不含声道数**（ffmpeg-next 语义）——立体声交错只拿到一半，改 `data(0)` + 手工切片（`f32_plane` 助手钉注释）。
- **`services/frame_stream.rs` 协议 v2**（破协议，前后端 + 三探针同步改）：二进制首字节 tag——`0` 视频帧 29B 头（+pts_ms f64）/ `1` 音频块（pts + frames + PCM）；文本控制消息 `flush`（seek 重推前发）/ `ended`（loop=false 到底）。**双通道**：视频帧仍 watch（latest-only，卡顿丢帧正确）；音频走 broadcast 容量 256（音频不可丢——watch 语义丢块出爆音）。**pace 改累计 deadline**（next_due += delay/rate，落后重置基准不追赶防爆发）+ init 调 `timeBeginPeriod(1)`（windows crate Win32_Media，踩坑 040 收口，09④ 闭环——音画同步前提）。会话上限 64→80（动图 50 + 视频 16 + 预览）。
- **视频会话**：`start_video`（fps 必需 = idx 推导 round(pts×fps)；has_audio = ffprobe 探测；start_secs = 首趟起播点；loop_enabled）；run_video_session 循环——seek_secs 待处理 = 中止本趟重开（先发 flush）；自然到底 loop 重开 / 非 loop 发 ended 转暂停停末帧（seek 唤醒 = 播放键回 0 语义）。`seek_video`（秒）/ `set_loop` 新公共函数。
- **命令组**：新 `commands/video_stream.rs`（start_video_stream / seek_video_stream / set_stream_loop）；播放/暂停/倍速/尺寸/停止复用 anim_stream 六命令（按 session id 无类型门槛）。**fps 自愈抽 `heal_video_fps`**（原 get_media_source 内联块抽出共用；start_video_stream 锁内自愈 + emit video-fps-healed 再启动）。
- **退役**：`get_media_source` 删视频分支收窄音频专用（route() 容器/编码判定、mp4 转码路径全删；MediaSource.fps 字段移除）；`get_asset_file_path` 删 animPreview 字段（09② 闭环）。
- **测试**：cargo test **363 全绿**（+9——decoder 6：resample 攒块/seek 丢帧/gif pts/sample.mp4 无音轨/真 seek 落点/sidecar 现生成 testsrc+sine 带音样本 AV+seek；frame_stream 3：视频会话出帧 idx·pts 递增 / seek 前进回退落点 ±100ms / loop=false ended+seek(0) 唤醒）。旧坑顺手：既有警告 3 条（sequence.rs 两处 + operations/mod.rs 再导出）均为 5.2 遗留非本轮引入，未动。

### 前端

- **`lib/streamClient.ts`**（animStream.ts 退役替换）：协议 v2 解析（tag 分流）；StreamSession = start（动图）/ startVideo（秒起播点 + loop）/ setSize / setPlaying / setRate / seek（动图帧）/ seekVideo（秒）/ setLoop / setMuted / setVolume / stop。**音画同步**：音频可闻（未静音 + 有音轨）时帧按 pts 排队等音频钟（rAF 驱动，队列上限 8 追帧丢旧）；静音/无音轨到达即渲。
- **`lib/streamAudio.ts`**（新）：共享 AudioContext 单例（单域上限）+ 每会话 GainNode；**静音 = 丢块不调度**（autoplay 策略：suspended 需手势，取消静音的点击即手势 resume）；块调度 = 锚定（首块 pts ↔ ctx.currentTime+150ms 预滚）+ 逐块拼接 + 迟到 80ms 重锚不追赶；`clockPts()` 供帧同步；flush = 停全部已排源。倍速 = playbackRate（**v1 音调随速变**，时间拉伸保调记 09）。
- **卡片 `VideoCanvasLayer.vue` 替代 `HoverVideoLayer.vue`**（旧 `<video>` 组件删除）：悬停完整循环 + 横向 scrub（rAF 合帧 + 66ms 门控沿用）+ 胶囊帧号/时间码 + 音量钮（hasAudio 才出）+ 3px 进度条；自动播放 = 封面帧 t 起 10s 封顶范围循环（**帧 pts 越界前端驱动 seekVideo 回起点，300ms 冷却防在途/失败洪泛**）+ 恒静音无控件；尺寸跟随/300ms 进入延迟/闸门池 16 全沿用。
- **预览**：preview store 视频分支接帧流（loadVideo；渲染复用 animFrame 通道 + PreviewAnimCanvas 改名 **PreviewStreamCanvas**）；新增 vSecs/vDuration/vFps/vHasAudio/vEnded/vStreamLive/vMuted/vVolume/vLoop 态；**真逐帧**（暂停 + seek((idx±1)/fps)，废除 ±1/24s 时间步进）；视频 seek 在途帧丢弃 = videoSeeking 标记（WS 有序，flush 前到达必为旧帧——比动图 seekTarget 更严）。PlayBarVideo 重写（数据源 preview store；转码中加载态随 `<video>` 链退役；vStreamLive 闸）；**VolumeControl 参数化**（props/emits；PlayBarAudio 同步适配）；PreviewPanel 删 `<video>` 元素挂载；previewNotes/DetailNotes 视频分支改 vSecs/videoSeek；previewMedia 收窄音频专用（删 video 分支/fps/setVideoThumb——setVideoThumb 移入 preview store 取 vSecs 精确到帧）。
- **协议 v2 动图侧零行为变化**（pts 忽略）；AnimCanvasLayer / preview store 动图分支换 import。
