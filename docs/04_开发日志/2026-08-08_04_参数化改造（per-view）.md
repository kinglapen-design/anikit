# 参数化改造（per-view）

**参数化改造（per-view）**：content store 新增 `placementsFor(viewKey)` / `stripFoldersFor(viewKey)` / `viewTitle(viewKey)`（原 getter 保留、委托激活视口——操作上下文不变：交互发生时所在 panel 必为激活）；ContentArea 改为 dockview panel 组件（props 接 params.viewKey；预览整栏切换仅激活 panel 生效——preview store 全局单例）；ContentTitleBar / AssetGrid / FolderStrip 加 `viewKey` prop（滚动位置存取、收件箱判定、子文件夹条带全部按本页 viewKey）。侧边栏/树/文件夹卡片/右键"打开"等 8 处导航写入点统一改 `tabs.openView()`。
