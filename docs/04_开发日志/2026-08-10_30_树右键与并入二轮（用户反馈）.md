# 树右键与并入二轮（2026-08-10 用户反馈）

**树右键与并入二轮（2026-08-10 用户反馈）**：① **右键菜单取消后选中态残留**——菜单框架加 `onClose(executed)` 回调（ContextMenu：点条目 = true，点外 / Esc = false）；FolderTree 右键未选中项先单选时快照选择域与锚点，菜单取消（未执行）即恢复。② **并入填充透明度 12%→30%**（新 token `--brand-1-30`；树 item 底色浅，12% 偏白）并统一两侧口径。**二轮根因**：树 drop-into 是"直接替换 item 底色"（30% 单层透明靠侧栏透色，还抹掉 tint 自定义色底），文件夹卡片 drop-cover 是"独立覆盖层叠加"——逻辑不同导致明暗不一；drop-into 改与 selected 同构的 linear-gradient 罩层 + 保留形态底色（root / child / archive 分行垫 tint/c5 底）。**`--brand-1-12` 剩余用途**（用户询问）：框选矩形填充、拖拽间隙竖块（素材卡片间距落点 + 文件夹同级排序竖块）；标签页拖拽不用它——dockview 主题是 brand 24% + brand-border。tsc / build 全绿。
