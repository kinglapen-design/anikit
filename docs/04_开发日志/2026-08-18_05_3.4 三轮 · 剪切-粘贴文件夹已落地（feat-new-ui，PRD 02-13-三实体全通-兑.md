# 3.4 三轮 · 剪切/粘贴文件夹已落地（feat/new-ui，PRD 02-13"三实体全通"兑现）

**3.4 三轮 · 剪切/粘贴文件夹已落地（feat/new-ui，PRD 02-13"三实体全通"兑现）**：**后端零新写**——复用 move_folders（护栏现成：禁入自身/子级、档案不作父级、陈旧 id 跳过；撤销标签"移动 N 个文件夹"）。
  - **剪贴板扩展**：`InternalClipboard.folders?: string[]`（与素材 items 互斥——选择域互斥，一次只剪切一类）；`selection.isFolderCut` + FolderCard / ArchiveCard / TreeItem 新 `cut` prop（--opacity-cut 0.5 档，速查表口径），FolderStrip / ArchiveStrip / FolderTree 三处绑定。
  - **流程**：`cutFolders`（写剪贴板 + toast）/ `pasteFoldersInto(target)`（源失效预检 toast"剪切的文件夹已不存在"并清剪贴板；move_folders 失败后端中文 toast 直出；成功清剪贴板一次性）；`pasteClipboard` 开头分流 folders 分支（Ctrl+V 落当前视口文件夹）。
  - **入口**：Ctrl+X 文件夹域分流（useGlobalKeys，Ctrl+C 对文件夹无语义——复制 = 克隆归四轮）；菜单点亮 folder「剪切文件夹 Ctrl+X」（`cutFoldersFlow` 批量分流同删除：触发项在多选域 → 整个选中集）+「粘贴文件夹 Ctrl+V」（落点 = 被右键文件夹本身，剪贴板无文件夹禁用）+ archiveCard「剪切档案」。「粘贴」在素材/档案菜单不新增（03/04 稿粘贴组本来就是素材语义）。
  - 验证：typecheck / build 全绿（纯前端轮）。cargo test 不涉及（后端零改动）。
