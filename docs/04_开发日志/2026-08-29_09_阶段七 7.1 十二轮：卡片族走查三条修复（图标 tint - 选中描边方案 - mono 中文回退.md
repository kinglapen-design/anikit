## 阶段七 7.1 十二轮：卡片族走查三条修复（图标 tint / 选中描边方案 / mono 中文回退）

**用户走查反馈（3 条）**：

1. **文件夹卡图标变色噪声大**——FolderCard 去 tint prop，文件夹-大恒默认双色调（自定义色只留树容器）；预览页撤 tint 演示列。
2. **选中边框不像 2px、粗细不均（文件夹卡正常）**——根因 = 首版媒体卡用**真 1px border + 选中环 inset -1px**：负偏移在分数物理像素下渗线粗细不匀，文件夹卡无真 border 所以正常。改回**旧统一线条方案**（速查表 §7 / 旧 AssetCard）：常态 1px = `.kc-bordered::after`、选中 2px 品牌 = `.kc-sel::before`，双层伪元素全 inset 0，禁真 border 禁负 inset；选中仍 opacity 过渡（踩坑 036）。FileCard / ArchiveCard / ListRowCard 换接线，FolderCard 随 cards.css 自动生效。
3. **数字档中文回退宋体**——`--n-font-mono` 链补 CJK 档：`"Fira Mono", Consolas, "Microsoft YaHei UI", "Microsoft YaHei", sans-serif`（原链末位裸 monospace 在 Windows 落宋体）。

**验证**：vue-tsc 绿；2x 截图复验（文件夹三态图标恒灰 / 选中环均匀贴缘 / 统计行中文 = 雅黑）留档 `tools/style-preview/r11-cards-2x-*.png`（覆盖更新）。速查表 §16 两条修订 + §13 补 mono 回退口径。
