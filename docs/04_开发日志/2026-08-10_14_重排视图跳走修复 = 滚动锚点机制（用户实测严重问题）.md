# 重排视图跳走修复 = 滚动锚点机制（2026-08-10 用户实测严重问题）

**重排视图跳走修复 = 滚动锚点机制（2026-08-10 用户实测严重问题）**：现象 = 列表滚到中部后，Ctrl+滚轮缩放卡片尺寸视图跳到别处；拖拆分条拉大容器滚轮上跑、缩窄下跑。根因 = relayout 后 pos 像素原样保留（`setTotal → scrollTo(pos)` 仅重夹），行数 / 行高全变后同像素对应完全不同内容。修法 = relayout 加**内容锚定**（Eagle 同款）：重排前记录视口顶所在行首张卡片 key + 行内偏移比例，重排后滚回该卡新位置（`box.height` 四种布局同构 = 行高，按比例还原）；`restorePos`（切视口 / 进出预览恢复）优先于锚点，视口顶在头部区块时不锚，锚点卡已消失退化重夹。覆盖：缩放 / 拆分条立即·停顿·收展逐帧重排 / 布局方式切换；顺带改善导入新项流入不再跳屏。tsc / build 全绿。
