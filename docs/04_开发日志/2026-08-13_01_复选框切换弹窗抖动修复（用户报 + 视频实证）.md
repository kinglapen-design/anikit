# 复选框切换弹窗抖动修复（用户报 + 视频实证）

**复选框切换弹窗抖动修复（用户报 + 视频实证）**。现象：勾选 / 取消"同时删除素材文件"复选框时弹窗全内容跳 1px。视频帧逐像素比对定位：未选中帧 = 选中帧整体上移 1px——根因 = 对勾 `v-if` 摘挂让 `.box` 变空 flex 容器，基线推导规则变化（空 = 底缘 / 有内容 = 内容基线），行盒高度差 1px，垂直居中的模态框整体重排。修 = 对勾常驻 DOM 切 opacity（组件注释本就写着"透明度过渡"，v-if 让 transition 从未生效）。记踩坑 030（状态切换只改样式不摘挂 DOM；装饰元素显隐用 opacity / visibility / transform）。vue-tsc / build 全绿。
