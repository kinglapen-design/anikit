## 阶段七 · 视图菜单「重置窗口」（用户当场定：窗口 1400×1100 + 左 254 / 中 880 / 右 266）

**实现**：

- capabilities 补 `core:window:allow-set-size` / `allow-unmaximize`（09-06 插件窗同族坑：缺权限 = 静默 deny）。

**验证**：`pnpm typecheck` 0 错；cdp-app-menu-probe **135 PASS**——V 段更新（V1 根级 9 项 4 组 + V12 新增四项全绿：菜单关 / 左 254 右 266 DOM 实测 / set_size IPC 参数 = Logical 1400×1100——桩环境无真窗口，真机尺寸与最大化还原归实机走查）；仅 V6-2 / V8-4 / V10-5-6 四项 FAIL = 09-06 起 headless CDP 不稳的已知未跑通段，与本轮改动无关。
