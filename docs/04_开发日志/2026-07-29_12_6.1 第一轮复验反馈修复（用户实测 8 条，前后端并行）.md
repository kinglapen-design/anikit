# 6.1 第一轮复验反馈修复（用户实测 8 条，前后端并行）

**6.1 第一轮复验反馈修复（用户实测 8 条，前后端并行）**：① **拖拽只出动画不执行（根因）**——`dragOperation.endDrag` 先 `sess = null` 再调 drop，而全部 drop 函数首行 `if (!sess) return` 从全局 sess 取数 → 落点静默无操作；修为落点动作在 pointermove 算出时即捕获入参、drop 函数全改显式参数；次生 bug：toast 计数 label 在 invoke 前拼好恒显"0 个"，改惰性求值。② **素材拖不到间距排序（根因）**——`.cards-layer` 子卡片全绝对定位致层高度塌缩为 0，`getBoundingClientRect()` 只剩一条线，容差判定恒不命中；修 = 层补显式 `height: gridTotal` + 容差改按 boxes 包围盒。③ **框选无法从卡片间距起**——同根因（层高度 0），层补高后间距 pointerdown 命中 cards-layer 正确落入框选分支。④ **文件夹卡片区空白点击不清选择**——useMarquee 新增 headerBlankClear（点在 .grid-header 内未中卡片/按钮 → selection.clear()）。⑤ **文件夹多选 + move_folders**——selection store 加文件夹选择域（selectedFolders + folderAnchor，三态同素材规则、与素材域互斥、全选/框选仍不涉及）；范围选顺序：卡片按条带、树按可见展开态 DOM 扁平化；多选整组拖拽：树中间 1/3 / 文件夹卡片并入 = 新命令 `move_folders`（后端并行补：循环护栏"不能移动到自身或其子文件夹内"、同父跳过、先全量验证后落点、撤销标签"移动 N 个文件夹"，5 用例），替换原"暂不支持移动文件夹层级"toast；树上/下 1/3 = 整组同级 reorder_folders。⑥ **ghost 美化**——新 `lib/dragGhost.ts`（缩略图短边 ≈96 / opacity 0.75 / 圆角 8 / --shadow-pop / 多选角标，无图给格式角标 + 名称纸片）+ 源项原地半透明 0.4（dragView 态，AssetCard/ListRowCard/FolderCard/TreeItem 四端）。⑦ **复制/剪切反馈**——Ctrl+C/X 写剪贴板后 toast「已复制/已剪切 N 个项目」。⑧ **被剪切项半透明**——selection.isCut + 卡片 fade-cut 态 opacity 0.5，粘贴/覆盖/清空自动恢复。新 token 三档：--opacity-drag-source(0.4) / --opacity-drag-ghost(0.75) / --opacity-cut(0.5)（01_样式 token.md 已同步）。另：content store 的 selectedFolderId 移除，文件夹选中态统一归 selection store。cargo test 199 过零警告、clippy -D warnings 清零、tsc / build 全绿；07 接口（move_folders）已同步。
