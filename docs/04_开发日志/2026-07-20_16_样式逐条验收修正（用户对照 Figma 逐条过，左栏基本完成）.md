**样式逐条验收修正（用户对照 Figma 逐条过，左栏基本完成）**：
  - 系统性根因：Figma 描边 inside 不占空间 vs CSS border 外扩——所有带边框容器差 1~2px，全局 border 改 inset box-shadow（踩坑 008 + 规范第 4 条红线）；主窗口圆角定 10。
  - 区块副标题按钮定稿：chevron-small / add-small 按 16×16 显示 + 图标按钮-小（24×24 / 圆角 4），图标常态 C4-40、hover C4-70（hover 提亮选择器须匹配 SVG 属性原值而非渲染值）；`00_写法说明.md` 补第 8 节术语词典（"子项"= 直接子元素自身、active=持久化选中等，防尺寸相对词歧义）。
  - 文件树对齐体系：两区块容器化（快速访问 / 文件树，间距 16）；item 组左 3 + 展开容器 9 + gap 2 = 14 与汉堡菜单、副标题按钮左缘对齐；副标题左 14、右 8；层级缩进定 20px（子项箭头尖角对齐父级装饰图标中心：9/2+2+6+16/2 = 20.5）。
  - 缩进线终版：容器级连续竖线（父级装饰图标中心起笔，父线穿子级展开区、子级的子级旁两条并存）、箭头容器铺 C3 底色遮线（视觉不穿过）、中间纯竖线、末子项 L 横线、颜色 = 装饰图标 fill 色 C4-7——规则已同步进 `02_左侧边栏.md`。
  - 侧栏滚动条：原生滚动条占位致右缘错位 → `overflow: overlay` 已被 Chromium 弃用 → **自绘悬浮 thumb**（`useSideThumb`，token 15：4px / 距右 4px / 不占布局），ResizeObserver 需同时观测内容元素高度（展开 / 视图切换后溢出才显示）。
  - 字体观感差异定性：Figma（Skia）与 Chromium（DirectWrite）渲染引擎差异，同字同号无法 CSS 级完全对齐，撤掉自加的 `-webkit-font-smoothing: antialiased` 后接受现状。
