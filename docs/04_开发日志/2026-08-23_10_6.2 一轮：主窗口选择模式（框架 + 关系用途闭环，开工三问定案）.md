# 6.2 一轮：主窗口选择模式（框架 + 关系用途闭环，开工三问定案）


**口径（开工三问定案）**：① 范围 = 选择模式框架 + 关系用途闭环（备区块两种模板都做，文件选择模板用途入口随后续轮）；② 反向称谓 = 备选区右框**手动填写**（用户原话"仔细看截图"，PRD"自动显示儿女"的词典推导不做），可留空回退同词；③ 拖拽到详情区块直接建关系本轮不做（拖拽路径称谓填写 UI 无稿）。

**后端**：
- `core/models.rs`：`Relation{ id, from, to, kind, label, reverseLabel? }` + `RelationRef{ lib, kind: asset|archive, id, name }`（携库名 + 显示名快照——关系可跨库，快照兜底显示）+ `RelationsFile` + `new_relation_id`（RL 前缀）。
- `core/relations.rs`（数据层）：空间根 relations.json 单一写点（load 缺文件按空表 / save 原子写）+ `prune_relations` 开库自检（剔除端点指向本库已失效目标的关系；跨库端点无法校验保留；有改动直接原子写回——空间级文件不在库备份清单）。
- `services/relations.rs`（业务层）：add（label trim 必填 / from≠to / 目标存在校验 + 显示名快照）/ update（改称谓 + 换绑端点 new_to/new_from 二选一，无改动 false）/ remove；reverse 空串规整 None。
- `commands/relations.rs`：4 命令接撤销三步（锁序 **library → space → undo**——三者同持唯一处；record_file 快照空间级文件天然支持）。

**前端**：
- `stores/picker.ts`（新）：选择模式会话态（active / purpose=relation-add|retarget / template=relation|file / origin / picked[] / 双框称谓 / confirming 防重入）；进入清全局选择 + 右栏收起强制展开；退出恢复发起目标选中（回到触发处，nextTick 入域同 FolderTree 口径）；确认按用途执行（add 幂等插入 / retarget 重拉）。
- 四重标识：`.window.picking::after` 整圈 1.5px `--brand-border`（token 注释既定预留）+ `PickerBanner`（品牌底胶囊，滑入 + 循环浮动，Esc 取消标注）+ SidebarRight 整体替换 `PickerPanel` 备选区 + 已选卡片压暗 30% 档 + 成功绿圆底 check 大勾（AssetCard / ArchiveCard picked 态）。
- 备选区两模板：relation（选中文件 item + 关系输入框×2 + 发起文件 item + 红删移出）/ file（名称 + 链接徽章 + 红删，多选累积框架就位）。item 左标 = 15px 缩略图 / 档案封面 / archive 图标 / 扩展名文字回退（图标库无通用文件图标，不猜造）。
- 交互变化：单击卡片 togglePick（AssetGrid / ArchiveStrip 分流；发起文件自身不可选；回收站不可选）；双击预览 / 档案双击导航保持；右键仅查看类精简集（assetCard / archiveCard / folder 三 spec picker 分支）；拖拽禁用（gridPointerDown + beginFolderDrag 双守卫）；树仅导航（FolderTree plain click 只 openView 不入域；新建 / 重命名 / 排序 / 新增菜单 / Ctrl+N / 区块管理禁用）；编辑类快捷键全禁（useGlobalKeys）；Esc = 取消全部放弃。
- `SectionRelations.vue`（新，03 数据 item §4 稿）：称谓框（点击 → C2 底输入框二次修改，写字段按目标端位分流 label/reverseLabel）+ 朝左箭头（chevron-large rotate 180）+ 对方文件卡（点击进选择模式换绑）+ × hover 滑入删除；添加钮点亮进选择模式；DetailSections 注册表 relations 从 SectionEmpty 切到 SectionRelations。

**坑（探针实证）**：桩 `list_relations` 返回 DB 数组原引用 → 前端 state 与桩共享数组（桩写 = 前端 push），add 后内容态 2 条同 id 记录——探针基建 artifact，非产品 bug；历史教训"多文件改动探针前批量 touch"再次应验（vite watcher 漏变更拿旧模块）。v-for 内模板 ref = 数组收集（`ref.value[0]`，直调 .select 抛 TypeError）。
