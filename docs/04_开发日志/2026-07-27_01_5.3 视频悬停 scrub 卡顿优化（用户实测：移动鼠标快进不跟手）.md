# 5.3 视频悬停 scrub 卡顿优化（用户实测：移动鼠标快进不跟手）

**5.3 视频悬停 scrub 卡顿优化（用户实测：移动鼠标快进不跟手）**：根因 = pointermove 高频（百次/秒级）每次直接设 `video.currentTime`，每次都是完整解码器 seek（找关键帧 / 清缓冲 / 重解码），上一次未解完下一次又来。改为 rAF 合帧应用 + 66ms 门控（seek 上限 15fps）+ 目标与上次差 <0.05s 跳过（手停微抖不触发解码）；pointermove 只记目标比例。卸载取消 rAF。tsc / build 全绿。
