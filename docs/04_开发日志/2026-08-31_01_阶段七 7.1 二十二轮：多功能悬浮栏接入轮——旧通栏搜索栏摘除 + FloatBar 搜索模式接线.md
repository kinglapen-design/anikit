# 2026-08-31

## 阶段七 7.1 二十二轮：多功能悬浮栏接入轮——旧通栏搜索栏摘除 + FloatBar 搜索模式接线

**定案（两问用户）**：① 搜索交互 = 新稿单行输入实时分词——tag 化 chips（`~` / `//` / `/` 前缀 tag、空格成 chip、kbd 提示组、失焦提交）随旧栏废除（用户：「筛选和搜索分开了，不需要 tag 化视觉化区分，正常空格分词就行了」）；`~` 手敲全局保留（后端前缀协议零改）。② 筛选按钮组 = **点亮不接业务**（点击仅切本地选中态 `.on`，不触发搜索；筛选弹窗 9 子稿 + 后端筛选条件另轮）。

**落地**：

1. **组件扩展**：FloatBarSearch 加 input ref + `defineExpose({ focus, blur })` + `@keydown.esc` emit escape；FloatBar 挂 `modeRef` + `defineExpose({ focusSearch, blurSearch })` 转发。
2. **业务壳 SearchFloatBar.vue（新）**：ContentArea 非预览态每 panel 一个；`.sf-anchor` absolute 底部居中距底 12、pointer-events 穿透空隙（栏体 auto）；draft ↔ store（setDraft 实时分词）；viewKey / showSubfolders 变化重搜；Ctrl+F requestFocus 聚焦；Esc 清空失焦；筛选 activeFilters 本地切换；mounted rerun / unmount removePanel（对仗旧 SearchBar 接线）。
3. **store 去 chips**：`PanelSearch` 删 chips 字段；query = `draft.trim()` 直传；`keywordsOf / effectiveGlobal` 保留剥前缀（与后端 parse_query 同规则，`~` 手敲全局链路不动）；`addChip / removeChip / popChip / chipsFor / clear` 删除（无调用方）。
4. **ContentArea**：删 SearchBar import + `footer.search-wrap`；SearchFloatBar 挂 v-else 分支末尾；`.content-area` 加 `position: relative` 作定位基准；旧 SearchBar.vue 删除。
5. **遮挡补偿**：`layouts.ts PAD.bottom` 0→**66**（悬浮栏距底 12 + 栏高 42 + 栏与末行卡片呼吸距 12 稿值组合——用户定：滚到最后一行时卡片与搜索框间距 12 留呼吸空间）——grid-viewport 是 JS translateY 滚动（overflow:hidden + canvas 位移），CSS padding 不产生可滚距离，留白必须计入布局总高，末行卡片才能滚出悬浮栏遮挡区。
6. **后端**：search.rs 注释 chip 表述清理（逻辑零改）。

**PRD 改写**：03_查找文件 01 节（指令式搜索 → 搜索：前缀指令与 tag 化废除条）/ 2 筛选节（悬浮栏按钮组 + 弹窗口径，条件呈现与交叉组合随筛选轮定）/ 02 快捷搜索框；00_功能总览 3.1/3.2/3.4；03_数据链接 04 白名单条（筛选（/）→ 筛选按钮组）；07 接口文档 search_assets 条 chip 表述；09 待办 3.6 二轮 tag 化遗留条作废（谈不上两口径并轨）。
