# 修复：文件夹拖入父级后拖不出来（用户实测）

**修复：文件夹拖入父级后拖不出来（用户实测）**。根因 = 文件树上/下 1/3 落点有"整组须与目标同父"的排序护栏，跨层级拖动落上/下沿被判无操作，而 move_folders 只绑在中间 1/3——拖得进拖不出。修法 = `move_folders` 加可选定位参数 `beforeFolderId`（锚点须 targetParent 直接子级，同级兄弟顺移插入，一次命令一步撤销）；前端 `dropFolderBeside` 放开：整组同父照旧 reorder_folders，跨父级 = move_folders 到目标父级插指示线位置（"after" 传目标下一兄弟，无则 null 末尾）。新增 4 用例（锚点插入顺移 / 锚点校验 / 嵌套拖回顶层复验场景 / 撤销回滚）。cargo test 203 过、clippy 清零、tsc / build 全绿；07 接口已同步。
