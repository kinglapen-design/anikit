# 6.1 复验反馈第二轮（用户实测 5 条）

**6.1 复验反馈第二轮（用户实测 5 条）**：① **ghost 无缩略图**——根因：startDrag 把 elementFromPoint 返回的最深元素（常是 `<img>` 自身）当锚点，dragGhost 只查后代 img 恒 miss 走文字纸片；修 = 先 closest 到卡片根（多选取首个选中项 data-key 卡片），读 `img.currentSrc || img.src`。② **排序指示错位（指针右侧、竖块跑行首）**——根因：makeGridResolver 间隙搜索 `y < top+height/2` 对同行所有 box 恒真，阅读序第一个同排 box 即 break → 指针在行上半部恒插行首；修 = 先定行（底+半行距在指针之下的 box）再按 x 中点定列，行内未命中 = 行末竖块（beforeKey 仍为下一行行首项，drop 语义不变）。③ **框选起点放宽到卡片信息区（Eagle 同语义，用户认可方案）**——AssetCard `.texts` / ListRowCard `.name`/`.details` 加 card-info class，gridPointerDown 命中即交框选分支；信息区单击 = 清空选择（不选中卡片，刻意对齐 Eagle）；右键 / 双击预览 / 重命名输入框不受影响；逐像素 alpha 穿透不做（成本与 Eagle 均未做）。④ **树多选排序只动一项**——根因：树 plain click 只设 sidebarSelected 导航不入文件夹选择域，导航高亮冒充选中态；拖"看着选中"的项被引擎判为组外 → 单选清空整组；修 = plain click 同步 clickFolder 单选入域（nextTick 让过 App.vue 的 sidebarSelected watch clear）。⑤ **拖拽期间禁悬停层**——body.dragging + AssetCard 单点 JS 闸（hoverActive = hovered && !dragView.active，视频/音频/序列帧/动图四层 + 放大镜全走既有退出路径：卸载停播 / 还原封面）+ CSS 闸（悬停按钮组隐藏禁点，特异性压 hover）；拖拽中起拖的视频切回 auto 静音范围循环。tsc / build 全绿（无后端改动）。
