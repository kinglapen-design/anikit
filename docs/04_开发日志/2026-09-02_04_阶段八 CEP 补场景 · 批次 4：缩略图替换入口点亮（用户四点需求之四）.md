## 阶段八 CEP 补场景 · 批次 4：缩略图替换入口点亮（用户四点需求之四）

**替换语义定案**（用户答"做保守点不会有错"）= **换绑**：CEP 重导 / 手动设置已绑定工程 = 新 WebP 独立资产 + 工程改指向（批次 2 thumb_commit 已天然兑现 CEP 路径），旧 hidden 留着用户手动处置。不做原位覆盖、不做分场景自动。

**答疑回扣**：替换不靠哈希——绑定 = 资产级 `thumb_asset_id` 引用；链接红利 = 资产的多 Placement 共享同一份绑定（换绑一次处处生效）+ 一个 hidden 资产可绑多个工程。

**落地**（APP 侧手动入口，PRD 04-03 缩略图组两 disabled 占位点亮）：

- `stores/selection.ts`：`thumbLink: { assetId, name } | null` 会话级（内部剪贴板同款口径，不落盘）。
- `placementOps.ts`：`copyThumbLink`（纯引用复制不动库数据，toast 反馈）/ `applyThumbLink`（set_thumb_asset 绑定，hidden 随绑定打）/ `restoreThumbAsset`（restore_thumb_asset：取消 hidden 链接位置恢复 + 清全部工程侧引用，toast 带清除数）。
- `menuSpecs/assetCard.ts`：「转换为缩略图链接并复制」点亮（单选可用）；「将『xx』设置为缩略图」动态 label 带链接资产名（无链接占位 disabled、自绑禁用）；**「还原为素材」新挂**（仅 `p.hidden` 资产显示——缩略图视图右键，旧图处置闭环）。
- 「打开 Animate 生成缩略图」仍 disabled（归 8.2 APP 内批量导出）。
