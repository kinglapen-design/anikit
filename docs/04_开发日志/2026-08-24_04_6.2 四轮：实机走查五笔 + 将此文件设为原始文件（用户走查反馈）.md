**背景**：三轮落地后用户实机走查，报五笔：① 添加音频联动泄漏到关系区块；② 链接区块 item 要能跳转、当前目录 item 恒第一行（多了难分辨）；③ 原始徽章全部摘掉——只有"有链接"的原始文件才上 ★、有链接的非原始文件上链接 icon，右键菜单「文件链接管理」下加「将此文件设为原始文件」；④ 右键「打开文件链接所在位置」接入；⑤ 悬停徽章弹出全部链接列表（用户给效果图）。

**改动**：
- **① voice 泄漏**（bug）：SectionRelations views 过滤 `kind === "free"`（audio 区块过滤 voice 已有，关系侧漏对称）。
- **② 链接区块**：items 排序 = 当前查看的这条 Placement（folderId + name 双键匹配，重复链接不错位）恒第一行；点 item = `jumpToAssetPlacement`（relationOps 新增公共：目标文件夹视口 + 选中卡片，openView 入面包屑历史）——关系 item / 音频 item / 链接区块 item / 徽章浮层行五处同跳转口径。
- **③ 徽章规则**：`content.placementCountByAsset` getter（活位置计数）——AssetCard 徽章改：**活位置 > 1 才上**（origin ★ original-file-badge / 链接 icon linked-file-badge），单位置无徽章（原"origin 恒显"作废）；徽章容器 `.card-badges` 带 `data-badge`（探针可断）。**「将此文件设为原始文件」**：后端新命令 `set_placement_origin`（目标置 origin、原 origin 摘标——库内 origin 恒 ≤ 1；仅标记不动磁盘；name 可选精确到行；已是 origin 幂等不进撤销栈；撤销标签"设为原始文件"）+ cargo 用例 1；菜单项挂「文件链接管理」下方（单选 + 仅链接卡可点，稿无此项不配图标）——**2026-08-19 待办（阶段六备用）闭环**。
