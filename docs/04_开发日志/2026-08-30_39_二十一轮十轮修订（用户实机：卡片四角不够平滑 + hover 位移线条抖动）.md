## 二十一轮十轮修订（用户实机：卡片四角不够平滑 + hover 位移线条抖动）

- **方案问答记录**：卡片边框 = 双层伪元素描边环（cards.css）——常态 `::after` inset 0 1px g3（hover 瞬时换 g6）、选中 `::before` inset 0 2px 品牌 opacity 过渡。伪元素 border 与真 border 同绘制路径（无"伪元素更不稳定"）；菜单分割线类孤立线条粗细不一根因 = 分数物理像素起点吸附位置，与载体无关。用户确认既有口径补记：**双层背景模拟线条严禁**（速查 §7）。
- **症状与根因**：① 常态亮图四角锯齿（视频卡最明显）= `.kc-clip` 蒙版裁剪弧 + `::after` 描边弧双线分数像素错位，亮图暗线对比强；② hover 位移期线条抖动 = 整卡 GPU 合成层逐帧亚像素重采样（固有特性，可减轻不可根除；稿值 -4px/250ms 未动，要动须用户定夺）。
- **修法（圆角平滑三件套）**：① `.kc-media` 删冗余 `overflow:hidden`（内容 `.kc-clip` 单层裁剪，壳背景走纯圆角填充路径）；② 铺满缩略图/封面自带 radius 8（FileCard `.fc-thumb` cover/contain、ArchiveCard `.ar-cover`——图片绘制路径平滑于容器蒙版，与描边弧同心同半径）；③ 选中/命名态常态环 `border-color: transparent` 让位（双环变单环；cards.css `.kc-sel.selected/force-selected::after` + FileCard/ArchiveCard/ListRowCard naming scoped 同款）。
- **验证**：vue-tsc 绿；r11 留档探针复跑全组截图目验（常态/hover/选中/naming/dropInto 无破版，选中成干净单环）；实机 GPU 路径精细观感待用户复验。
- **文档**：速查 §7 补双层背景严禁 + 伪元素路径问答 + 圆角平滑三件套；§16 媒体卡壳条同步。
