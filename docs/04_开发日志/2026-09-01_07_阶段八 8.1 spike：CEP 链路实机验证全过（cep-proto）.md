## 阶段八 8.1 spike：CEP 链路实机验证全过（cep-proto）

**验证结果**（`spike/cep-proto/`，用户实机逐项过）：面板加载 / WS 连通（端口文件发现 = server 写 `%APPDATA%\AniKit\cep-server.port` + 面板 node fs 读）/ jsx 读取选中（中文名无乱码）/ 静图导出（90% 居中正确）/ 动态导出 17 帧逐帧推进 / fla 坐标还原正确 / ffmpeg 合成 WebP 实测（17 帧@25fps：1080p q80=628KB、1024 q80=281KB、1024 q60=230KB；10 秒档估算 ~4MB → 2M 软上限 + 降级链定案成立）。

**关键技术结论**：

- ~~`exportPNGSeqToFile`~~ Animate 2024 已移除（TypeError: not a function）——逐帧导 = `tl.insertFrames(n)` + 循环 `tl.currentFrame=i` + `exportPNG(file, true, true)`。
- **movieclip 必须转 `graphic`+`loop='loop'` 才随主时间轴逐帧推进内部动画**（用户旧项目 `ref/cep-extension` 的踩坑结论直接复用，该旧项目即本机已装的 com.animator.assetmanager.export），导完还原 symbolType/loop。
- 坐标口径修正落地：缩放居中只作用于 PNG 画面，导出后还原坐标再保存 fla（PRD 03 原意，spike 初版误存居中坐标）。
- `insertFrames` 带 frameIndex 在单帧时间轴上越界报错——缺省参数（当前帧处追加）即可。

**新定案（用户实机后提）**：产物落点从系统临时目录改**库根 `cache/cep-out/`**（同盘剪切进库快、失败残留手动清理不翻 C 盘）；库根路径 WS 连接时下发插件。

**已知余项（正式版处理）**：① PNG 导出默认白底无透明通道（正式版发布设置带 alpha）；② **CEP 面板输入框打不了中文**（CEF IME 顽疾，用户实机卡此）——拟定 jsx ScriptUI 原生对话框辅助回填（用户旧项目 promptForName 同款）；③ jsx 中文报错消息乱码，正式版错误码化。
