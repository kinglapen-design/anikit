# 5.2 后端第二块：音视频播放源 + 逐帧笔记数据层（后端落地，前端未接）

**5.2 后端第二块：音视频播放源 + 逐帧笔记数据层（后端落地，前端未接）**。① **get_media_source**（commands/media.rs）：播放路由纯逻辑判定——WebView2 可直播（视频 mp4/m4v + h264 + aac/mp3/无音频流；音频 mp3/wav）直给源文件路径 `transcoded: false`，其余 ffmpeg 转码兜底；`adapters/ffmpeg.rs` 新增 `transcode_for_webview`（视频 libx264 veryfast crf23 + aac + faststart 出 mp4，无音频流不带 -c:a；音频 pcm_s16le 出 wav）与 `ffmpeg_available`（区分"组件缺失"与"转码失败"两种中文文案）。**幂等复用**：产物 `cache/tmp/media-{assetId}.mp4|.wav` 旁写 `.stamp` 记源文件 "大小:mtime秒"，一致直接复用，源变化重转；复用判定先于二进制检查（已有产物不依赖 ffmpeg）。② **notes.json 逐帧笔记**：`core/notes.rs` 单一写点（load / upsert / remove，复用 json_io 原子写 + version 门禁，文件不存在 = 空列表；单条 2000 字符截断，同 key 覆盖刷新 updatedAt RFC3339）；命令 `get_notes` / `set_note`（commands/notes.rs）统一返回按 key 排序的全量列表，set_note 空文本 = 删除，key 非空 ≤64 字符校验。③ **备份**：INFO_DATA_FILES 是枚举清单，加入 notes.json（备份与迁移共用 data_files，测试同步覆盖）。路由判定 / 笔记数据层 / 命令语义均纯逻辑单测，真 ffmpeg 转码归 #[ignore] smoke。cargo test 152 过零警告、clippy --all-targets -D warnings 清零。
