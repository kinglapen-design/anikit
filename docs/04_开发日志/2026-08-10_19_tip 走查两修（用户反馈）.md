# tip 走查两修（2026-08-10 用户反馈）

**tip 走查两修（2026-08-10 用户反馈）**：① **tip 靠右被压成一字一行**——根因：fixed 元素 shrink-to-fit 宽度受 left 位置约束（transform 不计），水平钳制把 left 推到右缘后可用宽不足，上一轮引入的 `word-break: break-all` 使 preferred-minimum 降到 1 字 → 竖排；修法 = `.app-tip` 显式 `width: max-content`（不被 available 压缩），靠右整体左移仍由钳制负责，仅超 max-width 的长名称换行。② **区块标题"添加"tip 原生 title 系统样式**——SectionHeader add-btn / group-menu-btn 改 v-tip；顺手全局扫尾同类：AppTag 删除 / AppSearchBar 清除 / ToastStack 关闭 / LinkDialog 名称四处一并 v-tip 化（IconButton 的 title prop 内部本就转 v-tip，无问题）。tsc / build 全绿。
