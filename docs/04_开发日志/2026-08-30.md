## 十七轮补 · 云母实机诊断与修复（同日，用户实机"没有云母效果"起）

**诊断链**（用户实机 + 本地自助 CDP/截屏/DWM 属性实证）：

1. 用户首测无云母 → 极端测试（50% 透明度）依然实色 → 后端日志确认 build=26200 判 mica、`set_effects` 成功，断点收窄到渲染层。
2. 本地起诊断实例（`WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` 加 `--remote-debugging-port=9223` 连 WebView2 CDP）：DOM 完整、`fx-mica` 类挂载、93% 底生效、invoke 返回 mica——**前端链路全对，内容被 Windows 合成层吞掉**。
3. 组合矩阵实测：① transparent+shadow+Mica 冷启动 = 云母渐变无 UI；② transparent+无 shadow+Mica = UI 正常但纯透明穿透（透出下方窗口文字）；③ 不透明窗+透明 webview 底 = 露 GDI 黑底（重定向表面无 alpha）。
4. **热切换实验定案**：运行中 `set_effects(Mica)`（临时 debug 命令）→ SYSTEMBACKDROP_TYPE=2 + UI 完整 + 云母透出——**冷启动时序是唯一病根**：`show()` 前 set_effects 吞 WebView2 内容。

**修复**：`apply_main` 移到 `show()` 之后（lib.rs）；50% 测试档恢复 93% 稿值；诊断件（CDP 端口 / ANIKIT_FX 开关 / debug_set_window_fx 命令）摘除。修复后实例实证：Mica 激活 + UI 完整 + 左栏/标签栏 7% 云母透出贴稿观感。

**环境坑（顺手清理）**：EBWebView 脏 profile（强杀实例后）致渲染进程崩溃（页面全透、DevTools 打不开）——删 `%LOCALAPPDATA%\com.anikit.dev\EBWebView` 重建；增量缓存错乱 LNK2019（踩坑 033 再现）清 `target/debug/incremental`；探针/诊断自起进程残留占端口（045/054 同族：vite 孤儿 5373、webview2 占 9223、杀 cargo 连带 tauri CLI 杀 vite 僵尸化）。踩坑 057 新立。
