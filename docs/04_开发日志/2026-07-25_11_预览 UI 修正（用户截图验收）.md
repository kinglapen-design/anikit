# 预览 UI 修正（用户截图验收）

**预览 UI 修正（用户截图验收）**：① 上/下一个图标方向上下 → 左右（chevron ±90°，与返回/前进同语言）；② 播放条/帧条图标补 80% 档（标题栏规则本来在位——dev 编译产物验证，用户所见 100% 为这两处遗漏）；③ 独立预览窗口宽度塌陷——.preview-window 缺 flex:1（App 根横向 flex 子项宽度按内容撑开），右侧大片空白、预览图被裁；④ open-new-window.svg 用户更新设计稿后 stroke 回到 #F8F5FA（100% 不吃档位），重转 currentColor——图标更新稿需重新批转（命名对照约定）。
