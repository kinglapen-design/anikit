# 6.1 三轮：颜色解析（pinned 颜色 bar 真色，用户点名 6.1 余项开工）


**口径（开工一问定案 + 用户指令）**：本轮**只上真色**——悬停色号 / 单击二级菜单（HSL·RGB·HSV、一键复制、搜同色）后置 09；**透明通道颜色不混入**（用户原话"透明通道的颜色不要弄进来"）——alpha < 16 像素不参与统计，半透明按原始 RGB 计入不做预乘；数量 = **存 10 显 7**（PRD 上限十个，01_主窗口稿 bar 槽位 7 个）。

**后端**：
- `services/color.rs`（新）：`extract` = 4-4-4 RGB 桶直方图（4096 桶、桶内均值抗相近色散席）→ 按像素数降序贪心选取，与已选色 RGB 距离² < 56² 视为同色跳过，上限 `COLOR_STORE_COUNT = 10`，输出 #RRGGBB 大写；`ensure_asset_colors` = **存量懒回填**（colors 空 + 有缩略图 → 解码 320px 缩略图提取落盘 + 索引同步；**不刷 modifiedAt** 防 3.5 排序键漂移、**不进撤销**——系统补数非用户写操作；best-effort 失败仅日志下回重试）。
- `ThumbOut` 加 colors 字段：`thumbnail::generate` 出图即提色（图已在内存，320px 小图亚毫秒级），五处生成点全接——导入 / 序列帧打包 / 删帧封面重建 / 设封面帧 / 剪贴板·自定义缩略图（重生成缩略图即同步刷新主色）。
- `AssetMeta.colors`（serde default 空数组，不升 DATA_VERSION）；`get_asset_detail` 输出 colors 并在返回前挂懒回填（读命令唯一维护性写副作用，注释留痕）。

**前端**：`AssetDetail.colors`；SectionPinned 颜色 bar 真色接入——有真色按实际数渲染（slice 0,7），空（非图片 / 无缩略图）= 7 个占位色块恒显（口径不变）；色块 1px 描边对真色保留（浅色色块靠描边出形）。

**验证**：cargo test **392**（+7：提取 6 项——纯色单席 / 透明像素跳过 / alpha 阈值边界 15 跳过 16 计入 / 占比降序 + 近似红合并 / 上限截断 / 全透明空；回填 1 项——落盘与索引一致 + 不刷 modifiedAt + 幂等）全绿；typecheck / build 绿；`cdp-custom-data-probe.py` 加 S10（A1 三色块按序 computed rgb 断言 / fla 无颜色 = 7 占位透明底恒显）**全项 PASS**。

**同步**：PRD 04_文件预览 05-1（实现口径）/ 03_数据链接 02 颜色条 / 07 接口（colors 输出 + 懒回填副作用 + 颜色解析服务条）/ 09 待办（悬停色号 + 二级菜单后置一笔）/ 速查表 §9 6.1 条 ⑤ / 05 进度。
