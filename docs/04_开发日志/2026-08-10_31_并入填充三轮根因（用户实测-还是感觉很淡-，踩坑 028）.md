# 并入填充三轮根因（2026-08-10 用户实测"还是感觉很淡"，踩坑 028）

**并入填充三轮根因（2026-08-10 用户实测"还是感觉很淡"，踩坑 028）**：二轮罩层写法本身没错但仍只见边框——真根因是 **hover 特异性压制**：`.tree-item.child:hover:not(.selected)` 中 `:hover` 与 `:not()`（按参数计）合计特异性 (0,4,0)，压过 `.tree-item.child.drop-into` (0,3,0)；拖拽时鼠标正悬停目标上，hover 暗罩把 30% 品牌罩层整个盖住。修法 = 三条 hover 规则补 `:not(.drop-into)`（状态类存在时 hover 罩层退让，同 `:not(.selected)` 思路）。tsc / build 全绿。
