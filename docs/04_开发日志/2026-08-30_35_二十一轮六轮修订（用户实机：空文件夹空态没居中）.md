## 二十一轮六轮修订（用户实机：空文件夹空态没居中）

- **根因**：ActionButton md/lg 档 `width: 100%`（稿 flex-grow 拉伸语境，宽由父容器定）+ 组件根 `flex: none` 不收缩——空态 `.ef-actions`（flex 行，声明宽 282）里两个按钮各撑满 282、双双不缩，向右溢出 282；容器声明宽照旧（T17b 旧断言 aw=282 全绿），视觉按钮组中心 = 容器中心 + 溢出/2 偏右。探针截图目验坐实（组中心 1207 vs 插画 905）。
- **修法**：`.ef-actions` 改 `display: grid; grid-template-columns: 1fr 1fr`——按钮 width:100% 填 grid 格各 137 精确稿值，组件零改（ActionButton "宽由父定"语义不动）。
- **探针**：T17b 补钮实宽断言（137）；**T17c 新增居中实证**——按钮组双钮 rect 中心 = root 水平中心 ±1、ef-body 盒中心 = root 垂直中心 ±1（实测 cx=0 cy=0）。插曲：首跑 T17c 误 FAIL——断言 `ef.get("cx") or 99` 把实测 0 当假值落 99，改 isinstance 数值直判；组件修复本身无回归。复跑 ALL PASS，vue-tsc 绿；速查 §22 空态条同步。
