## 阶段七 7.1 七轮：按钮族六件封装 + 预览页「组件 · 按钮」展区

**范围**：`组件/按钮/` 17 稿（主按钮×2 / 文字按钮×3 / 图标按钮×5 / 标签按钮×3 / 分段控制器×2 / 图标+文字 / 拉下按钮 / 字体安装按钮）封装进新组目录 `src/components/buttons/`（与旧根目录按钮件并存，业务接入随面板重构轮逐件替换）。

**落地**（六件，force-hover 静态验收 + 分段/拉下真实交互实例同次进预览页）：

1. **ActionButton**（主按钮大/小、文字按钮大/小-立体、文字按钮、图标+文字-立体 五稿合一）：variant primary（品牌底+立体感-主要按钮，hover 提亮）/ solid（g4+立体感-通用，hover g6）/ ghost（菜单钮，hover 半透明-3+二级）；size lg 38 / md 34 / sm 28；**lg/md = 填充式宽 100%**——figma padding-x 0 + flex-grow 是拉伸语境，宽度交父容器；前置图标恒 12 三级 hover 不变色。
2. **IconButton**（通用/大/小/立体/立体-半透明 五稿合一）：variant plain 30² / bare 裸 18·14 / solid 高 34 填充式（图标恒二级）/ float 半透明-2 浮钮（图标恒三级，hover g4）。
3. **TagButton**（标签按钮三稿）：solid md（g4 加粗）/ solid sm（g5 常规，选中 = 品牌底+一级+立体感-主要按钮）/ ghost sm（半透明-3 加粗，hover 半透明-2，选中 半透明-1+一级）。
4. **SegmentedControl**（分段控制器图标/文字）：容器 icon = 半透明-3 高 38 / text = g3 高 40；选中 = 半透明-1+立体感-通用 thumb 滑块位移 300ms 形态切换 token；段均分 flex 1 + min-width 0（沿旧 AppSegmented 防错位口径）。
5. **FontInstallButton**：18px 圆钮 g4+g6 描边，选中品牌底+半透明-1 描边；稿无 hover 不做。
6. **DropButton**（拉下按钮-横向）：g6+半透明-3 描边高 28；常态只显选中项 + chevron 朝右，点箭头 inline 展开全部项（朝左，250ms），点项选中并收起。

**待确认记 09**：① 按钮族禁用/按下态 17 稿均未画（不自创未实现）；② 字体安装钮 hover 稿无；③ 拉下展开形式 = inline（稿 CSS 并列容器内推定，若要 popover 需补稿）。

**验证**：vue-tsc 绿；无头 1x 全页 + 2x 局部截图目验贴稿（主按钮立体感/hover 提亮、solid hover g6、标签小排选中品牌底贴稿图「男主角」、分段 thumb 浮起滑动、拉下两态箭头方向）留档 `tools/style-preview/phase7/r7-buttons.png` + `r7-3x-*.png`。速查表 §15 新立按钮族口径。
