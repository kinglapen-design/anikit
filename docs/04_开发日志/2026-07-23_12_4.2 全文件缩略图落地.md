# 4.2 全文件缩略图落地

**4.2 全文件缩略图落地**（分支 feat/stage3-import，用户 2026-07-22 定案语义：shell 只作保底，PSD/AI/SVG 不走 shell 保证无 Adobe 可看；shell 产物一律按格式存 cache/thumbs、**不进 info**——info 内放 shell 图占空间且与后期补的伴生图并存污染；AI 本轮先保底）：
	- 新增 `adapters/shell_thumb.rs`（仅格式图标）：IShellItemImageFactory::GetImage（SIIGBF_ICONONLY|BIGGERSIZEOK，256 见方）→ HBITMAP 经 GetObjectW + GetDIBits（负高度顶向下 32bpp）转 BGRA→RGBA 并解除预乘；thread_local STA COM guard（S_OK 才配对 CoUninitialize，S_FALSE 借用，线程退出自动 uninit）——第三方 shell handler 对 STA 兼容性最好；非 Windows 存根保留 mac Quick Look 方案。windows crate 补 Win32_UI_Shell / Win32_Graphics_Gdi / Win32_System_Com 特性。
	- 新增 `services/thumb_formats.rs`：PSD = psd crate 解内嵌合成图（宽高不走整文件解码，手解固定头 "8BPS" 偏移 14=高/18=宽 大端；合成数据 alpha 全 0 = 未开"最大兼容性"保存 → 回退格式图标）；SVG = resvg（usvg 解析取 tree size 作宽高，pt/mm 单位换算自带；tiny-skia 按 320 短边渲染，输出预乘 alpha 解除后交 webp 编码）。
	- thumbnail 回退链：probe / generate 先 image crate 后 thumb_formats；新增 `ensure_format_icon`（cache/thumbs/{ext}.webp，幂等，空扩展名归 "file" 键）。
	- 视图层回退：Library 加 `format_icons` 内存集（open 扫 cache/thumbs 重建，免逐卡片 stat）；`thumb_path` 无 info 缩略图时查集合返回格式图标路径；建档两处（import_task build_one / resolve "保留两个"）锁外补图标、消费者锁内登记内存集；**前端零改动**（thumbPath 拿到即渲染）。
	- 依赖四问：psd 0.3.5（MIT/Apache，165KB 纯 Rust，PSD 解析无更优选项——image 0.25 已移除 psd feature，已核实本地源码）/ resvg 0.47（Linebender 维护，0.45 起 Apache-2.0 OR MIT，默认 features 含系统字体文本渲染；用 resvg::usvg / resvg::tiny_skia re-export 避免版本错配）。
	- 测试：shell_thumb 2（未知扩展名出图标 / 不存在文件 None）+ thumb_formats 4（PSD 假头 probe / 伪 PSD 解码 None / SVG probe+decode 含 320 短边缩放 / 其他扩展名忽略）+ thumbnail 图标缓存幂等 + 命令层集成（导入伪 fla 回退 cache/thumbs/fla.webp、重开库内存集扫描恢复）；cargo test 91 过零警告，tsc --noEmit 全绿。
	- 已知边界：PSD 未开最大兼容性保存 → 格式图标；AI 内容缩略图后置（候选：pdfium sidecar 体积 +10~15MB / hayro 纯 Rust 新库待 spike）；shell 图标随系统关联程序变化（zip 显示压缩软件图标）。
