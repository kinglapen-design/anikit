# 6.1 二轮：数据区块排序/显隐文件与档案独立设置（用户实机定）


**背景**：6.1 一轮落地后用户实机发现——22 稿「编辑数据区块」面板的排序/隐藏，档案和文件共用同一份应用级配置（`ui.detailSections`），档案里改序/隐藏会串到文件详情。要求独立设置。

**改动**（纯前端，无后端）：
- `stores/ui.ts`：新增 `detailSectionsArchive`（档案套；`detailSections` = 文件套，存量配置无缝保留）+ PERSIST_KEYS 注册 + 启动 mergeDetailSections 兜底两套同口径；`sectionsFor(host)` 取套；moveDetailSection / moveDetailSectionTo / toggleDetailSection 第三参 host（默认 "file" 兼容）。
- `DetailSections.vue`：按 `target.kind` 分流渲染与面板内拖拽落点（archive → 档案套）。
- `SectionEditPanel.vue`（22 稿面板）：编辑目标分流——档案侧栏入口（host=archive）恒档案套；右栏入口跟随当前选中（选中档案卡片 = 档案套，选中文件/无选中 = 文件套，与 DetailPanel 档案判定同逻辑）。

**验证**：typecheck 绿；`cdp-custom-data-probe.py` 加 S9 段（档案套隐藏音频 → detailSectionsArchive 持久化 + 文件套不动 + 档案详情联动消失 + 文件详情音频仍在 + 文件套面板行态独立）全项 PASS；`cdp-archive-probe.py` ⑦ 段持久化断言适配（其上下文 = 选中档案卡 → 档案套）复跑全过。

**同步**：PRD 03_数据链接 02 区块体系条（两套独立配置 + 面板编辑目标分流口径）/ 速查表 §9（host 分流口径 + 错误信号）/ 04 日志 / 05 进度。
