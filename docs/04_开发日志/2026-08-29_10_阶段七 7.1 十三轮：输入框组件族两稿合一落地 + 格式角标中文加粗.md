## 阶段七 7.1 十三轮：输入框组件族两稿合一落地 + 格式角标中文加粗

**稿源**：`组件/输入框/` 大 / 小两稿 → `src/components/inputs/TextInput.vue`（size：lg / sm）+ 预览页「组件 · 输入框」展区。

**顺手一笔**：格式角标中文加粗（用户截图指定）——FormatBadge 字重 500→700；Fira Mono 仅内嵌 Regular/Medium，拉丁/数字 700 仍落 Medium 视觉不变，CJK 回退雅黑（十二轮 mono 链修复后）正好吃 Bold。

**用户定案一笔**：占位符 = 亮色/四级（稿只画了文字二级色，未写占位符）。
**落地要点**：

- lg = 高 34 / padding 8/12 / 常态描边 通用三级；sm = 高 26 / padding 4/12 / 常态描边 亮色/半透明-3、**文字居中**（稿 justify-content center，年/月/日小框语境）；底 通用二级 + 圆角 8，宽 100% 随父容器。
- **聚焦描边 = 亮色/半透明-1，双层伪元素 inset 0**（卡片同款线条方案：::after 常态瞬时 / ::before 聚焦 opacity 150ms，禁真 border 禁负 inset、禁颜色过渡）；壳 + 内嵌透明 input（focus-within 驱动，expose focus/select）。
- hover 稿无不做；**禁用态稿未画 → 属性透传不改视觉**（同按钮族口径，记 09 待办）。
- 预览页每档附真实可点实例（v-model）+ force-focus 静态验收列。

**验证**：vue-tsc 绿；2x 截图目验贴稿（大/小 常态·占位·已填·聚焦四格全对；角标「序列帧 / 主角」加粗、拉丁数字不变）留档 `tools/style-preview/r13-inputs-2x-*.png` + `r12-badge-bold-2x.png`（探针 `tools/cdp-inputs-shot-probe.py` 新建）。速查表 §17 新立输入框族口径。
