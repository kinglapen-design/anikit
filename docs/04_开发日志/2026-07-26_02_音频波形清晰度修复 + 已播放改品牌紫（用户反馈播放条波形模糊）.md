# 音频波形清晰度修复 + 已播放改品牌紫（用户反馈播放条波形模糊）

**音频波形清晰度修复 + 已播放改品牌紫（用户反馈播放条波形模糊）**。根因：PlayBarAudio / PreviewPanel 直接拿 info 里 640×272 波形缩略图 object-fit 拉伸到 ~1200px 显示面，位图放大必糊。① **后端渲染参数化**：`services/media.rs` 抽 `waveform_image_sized(path, w, h)`（渲染口径与 5.1 定稿逐像素一致——满色纵线 / 竖向柔化 / 声道分绘 / 静音中线 / 60% alpha，仅宽高为参数），`waveform_image` 卡片缩略图 640×272 签名不变；新命令 `get_waveform(assetId, width, height) -> { path }`（commands/media.rs，async）——宽高钳制 32~7680 / 8~1080，产物缓存 `cache/waveforms/{assetId}_{w}x{h}.webp`（进开库会话级清空名单），命中直给；ffmpeg 缺失 / 提取失败中文报错。② **前端 `lib/useHiresWaveform.ts`**：ResizeObserver 观察轨道 / 画面区实际尺寸 × devicePixelRatio 取整，防抖 250ms 调 get_waveform，等图期间维持旧图、失败回退 thumbPath 拉伸旧行为；PlayBarAudio 与 PreviewPanel wave-large 共用。③ **播放条配色改版**（Eagle 蓝/灰对比的紫/灰版）：两层 div 以波形图作 CSS mask（alpha 通道，mask-size 100% 100%），底层 font-icon-3 = 未播放、上层 brand-1 clip-path 裁到进度 = 已播放，播放头 1px brand-1 不变；C1-40 罩层方案废弃。cargo test 162 过零失败、clippy --all-targets -D warnings 清零、tsc / build 全绿。
