# 导出失败清单 + 重试（用户定：导出也有失败弹窗，按钮重试）

**导出失败清单 + 重试（用户定：导出也有失败弹窗，按钮重试）**。原逐文件拷贝失败静默吞（只少计数，全失败还报"已导出 0 个文件"成功 toast）。**后端**：`ExportFailedItem{path, target, reason}`——target 记**首跑实际尝试的完整目标路径**（重名去重已计入），重试按 源→目标 原路覆盖（成功项不重导成 -1 副本、不撞开目标目录里无关同名文件）；`ExportOutcome{copied, failed}` 取代裸计数，`Finished` 事件带 failed；新命令 `export_retry(items, onEvent)`（不读库纯 IO，目标父目录补建，再失败原样回新清单）。**前端**：失败弹窗通用化 `ImportResultDialog → FailedListDialog`（title / failed / retry emit 参数化，App.vue 挂导入 / 导出两实例）；导出编排收敛 `content.runExportTask`（placementOps 两入口 + retryFailedExport 共用），finished 分级收尾——error → 失败 toast / failed 非空 → 弹窗 / 干净 → 成功 toast。新测试 1 用例（retry 原路拷出含父目录补建 + 再失败留清单）。CDP 探针全项 PASS（tools/cdp-export-failed-probe.py + export-failed.png：右键菜单实机链路触发 / "导出未完成" / 重投项 path+target 保留 / 全成关窗 + toast）。cargo test 285 / vue-tsc / build 全绿。PRD 05 §03 与 07 接口文档同步。
