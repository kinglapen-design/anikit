# 4.4 文件夹卡片缩略图落地（阶段 4.4 第一项）

**4.4 文件夹卡片缩略图落地（阶段 4.4 第一项）**：默认取文件夹直接子项中按 Placement 顺序的第一个静态图片作缩略图；口径与 formatBadge 静态图片对齐（PNG/JPG/JPEG/BMP/WEBP，排除序列帧 frameCount、GIF 与 PSD/SVG 等工程/矢量格式；右键自定义图片归 6.3）。前端零后端改动：`content.folderThumbMap` 由全量 placements O(N) 派生（首项命中即停，`FolderStrip` 按文件夹 id 查表）；`FolderCard` 接 06_卡片 02 有缩略图态——`folder-card-layer4` 背面 + 后层装饰纸（图层3，16,25 / 149×109 只露上沿）+ 缩略图放前层纸（图层2，8,29 / 165×113，object-fit contain 与网格缩略图同口径不裁切，底色保留 `--folder-card-file` 文件纸托住透明通道）+ `folder-card-thumb-layer1` 正面下沿（高 60 盖住照片下段，呈"照片探出文件夹"；分层 SVG 线条原被批成 currentColor 15%，组件内强制回 border-1 实线，与无缩略图态图层边框一致），无缩略图仍走 `folder-card`；`formatBadge.ts` 导出 `isStaticImageExt` 作唯一口径。06_卡片文档补落地注记（Figma 旧 CSS 的总容器 gap2/高200/padding4 已被 2026-07-23 定稿取代）。tsc / vite build 全绿。inbox 被占用文件可见性（4.4 第二项）方案待与用户讨论后实现。
