## 阶段七 7.1 十一轮：卡片组件族十稿封装落地

**稿源**：`docs/UI 重构/Design Token/组件/卡片/` 十稿（文件卡 通用/视频/音频/字体/txt-md + 列表卡片 + 列表表头 + 文件夹卡片 + 档案卡片 + 格式角标）→ `src/components/cards/` 6 件 + 共享 `cards.css` + 预览页「组件 · 卡片」展区。

**用户定案两笔（稿未写明，问过用户）**：

1. **音频波形进度扫过颜色 = 品牌色**（稿只有静态五级灰 + prose「走带颜色丝滑扫过」未给色；实现 = 品牌色同构波形层 `clip-path` 按进度裁，与波形根数解耦）；
2. **悬停控件 hover 才现**——视频/音频右上胶囊（视频 = 帧数 + 播放/暂停 + 音量/静音；音频 = 时长 + 播放/暂停）与视频底部 4px 播放条常态全隐；波形扫过 hover / 播放中才显。

**落地要点**：

- **FileCard 五稿合一**（kind：general / video / audio / font / text，同 ActionButton 五稿合一先例）：通用 = 缩略图 cover（沿用旧网格口径）+ square 变体（shell 缩略图 / 未导入 = 正方形 + 50% 居中，稿注）；字体 = 示例字块（标题档 四级）+ 复用 buttons/FontInstallButton；txt-md = 卡内文本滚动预览（滚动内容入渐变罩下）+ 6px 滚动胶囊贴右缘（g3，胶囊自身 hover 升五级——稿「hover-滚动条」节；溢出才显、跟随滚动）。
- **选中统一 = 品牌 2px `::after` 状态层 opacity 过渡（速查表 §7）**：`inset: -1px` 让 2px 环正好盖住常态 1px 描边；内容圆角裁切走 `.kc-clip` 内层（overflow hidden + radius inherit），选中环在裁剪层外防 overflow 切边。hover = 描边升六级瞬时（踩坑 036）+ 位移 Y -4px + 小阴影（250ms 小位移档）。
- **格式角标统一样式 = FormatBadge**（`.kc-float`：半透明-2 + 立体感-通用 + 背景模糊-小 + 圆角 4，数字档 12/16 二级）：文件卡左上 12/12、档案卡（属性文字「主角」）、列表行扩展名列全族复用。
- **FolderCard**：g3 底 + 立体感-通用（无描边），hover 仅底升六级（稿只给 background-color，无位移无阴影）；文件夹-大 24 双色调走 TwoToneIcon（tint 九色对）；简介统计两行数字档三级。
- **ArchiveCard**：正方形（aspect-ratio 1，稿注），封面 cover；渐变罩三行 = 名称 标题档一级 / 属性 " | " / 数量 " / "（数字档 二级）；右下 linked-file-badge 14 二级。
- **ListRowCard**：57 高 padding 6/12/6/6；hover = 底升 g3 + 描边升 g5（瞬时）；缩略图 80×45 图 contain（沿用旧 ListRowCard，与网格卡 cover 不同）；数据列各 123 宽 数字-大档 三级。
- **ListHeader**：g3 + 立体感-通用 高 34 padding 8/12；箭头 = chevron-small 单箭头旋转换向（朝上 = 升序原样、降序 rotate 180°，300ms 形态切换——稿注「上下箭头不同时出现」）；hover 列现箭头 / 当前排序列恒显；箭头常态 四级 / 自身 hover 三级。
- **图标三批 5 个转 currentColor**（card-hover-play / pause / volume / mute + linked-file-badge），original-file-badge 品牌色保留、folder-large 双色调保留原值走 TwoToneIcon；命名对照.md 登记。
- **尺寸模型**：组件宽高 100% 随父容器（稿值 = figma 画布语境），预览页按稿值演示；网格行列尺寸归列表容器布局轮。

**验证**：vue-tsc 绿；无头 1x 全展区 + 2x 分组截图目验贴稿（常态/hover/选中/方形变体/胶囊三控件/波形扫过/列表三行/文件夹 tint/档案正方形全对；滚动胶囊 DOM 实证：溢出才显、高 150.6 跟随滚动）留档 `tools/style-preview/r11-cards-*.png`（探针 `tools/cdp-cards-shot-probe.py` 新建）。速查表 §16 新立卡片族口径。
