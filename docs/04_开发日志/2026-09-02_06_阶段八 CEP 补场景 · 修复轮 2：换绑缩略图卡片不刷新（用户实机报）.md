## 阶段八 CEP 补场景 · 修复轮 2：换绑缩略图卡片不刷新（用户实机报）

**现象**：「将 xx 设置为缩略图」换绑后，卡片尺寸跟新缩略图走了（thumbW/H 已刷新），但画面还是旧动画——切视图或开关预览才恢复。

**根因**：`AnimCanvasLayer`（fla 卡动图播放层）`start()` 只在开流时读一次 `playAssetId`——自动播放开着时组件常驻挂载，换绑后 playAssetId 变了但旧帧流会话照跑，canvas（带 `--n-g2` 衬底）盖住下层**其实已经刷新**的静态封面 img。数据层（views 代理 / refresh 全量替换 / thumbUrl computed 含 ?v= 版本戳）与静态 img 链路均无滞留；详情面板 target 实时 find placements 无快照，同免疫。

**修复**：AnimCanvasLayer 加 watch（`playAssetId ?? assetId`）——源 id 变 = 停旧流 + hasFrame 回落（下层新封面先露出）+ 重开新流。

**同款滞留排查**：新窗口预览 loadAnim 同模式（预览窗口打开 + 主窗口换绑，边角）未修，记 09 待办④；HoverZoomOverlay 每次悬停重挂载不受影响。

**验证**：vue-tsc 0 错 + build 绿。**下一步：用户实机复验（换绑后卡片立即换脸，无需切视图）**。

**文档**：04 本日志；05 当前状态 + 09 待办④。
