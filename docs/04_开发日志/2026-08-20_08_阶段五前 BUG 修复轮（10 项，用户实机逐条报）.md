# 阶段五前 BUG 修复轮（10 项，用户实机逐条报）


进阶段五前用户实机走查报的 10 条 BUG 一轮修完；cargo test 347 / typecheck / build 全绿；新探针 `tools/cdp-bugfix-probe.py` **19 项断言全 PASS**（S1 树数量 / S2 树定位 / S3 组内拖拽 / S4 toast 图标 / S5 新建文档置顶 / S6 新建子文件夹展开 / S7 新标签页 / S8 面包屑；BUG1 由 cargo test 覆盖，BUG4 真实系统对话框待用户实机）。

1. **副本落点紧随原件**：原 `duplicate_placements` 走导入语义统一"段首前插"（+ 前端新增区置顶），克隆的副本顶到第一行第一列——列表底部克隆完还要回顶部找。后端改：源在目标文件夹内 = 恒插源后第一位（新副本贴原件、旧副本顺后移）；跨文件夹副本粘贴保持段首前插。前端 `duplicatePlacements` 摘除 markArrivals（副本不进新增区）。补后端用例 `duplicate_inserts_after_source`（紧随 / 再副本 / 跨文件夹三断言）。文件夹克隆（clone_folders）本就紧随源后，无改动。
2. **移动 / 新建后默认展开父级**：`moveFolders` 成功后展开目标父级（拖拽并入 / 剪切粘贴 / MovePanel 三入口同封装自动覆盖）；`createAndName` / `createArchiveAndName` 新建子级展开父级——原 forceOpenIds 只是命名期强制展开，命名完随父级折叠态收回。
3. **导航树定位**：LibraryView watch `sidebarSelected`（+ folders 就绪补位）——树外入口进文件夹视口时展开祖先链 + 所在区块并 scrollIntoView(nearest) 定位；原仅高亮，父级折叠时当前文件夹树上看不见。
4. **「在其他应用打开」错误码 31**：`ShellExecuteW "openas"` 对未注册 openas 动词的文件类型返回 SE_ERR_NOASSOC（31），系统对话框根本调不起。两级方案：openas 优先，失败回退 `rundll32 shell32.dll,OpenAs_RunDLL`（不依赖动词注册，同一对话框；rundll32 按 CommandLineToArgvW 正常解析，Command 可用——与 explorer 的踩坑不同）。
5. **文件夹 / 档案「新标签页打开」**：原误用 `openView`（未锁定页只替换视口，没开新页）。tabs store 加 `openInNewTab`（恒 addTab），folder / archiveCard 两 spec 接入。
6. **面包屑后退 / 前进**：ContentTitleBar 原 disabled 占位。tabs store per-panel 双栈历史（openView 替换入 back 清 fwd；goHistory 直接替换视口不走锁定新开语义；panel 关闭清栈；navCan 响应式镜像供按钮禁用态）；ContentArea 传 panelId 接线。
7. **树数量口径**：原"展开即隐藏"（用户实机：父级 80 个素材直接在父级下，展开后数量消失误以为显示异常）。改：折叠 = 递归总数；展开 = 直接子项文件数（content 新 getter `directCounts`），为 0 不显示。TreeItem 加 `directCount` prop，FolderTree 绑入。
8. **复制 / 剪切成功 toast 用失败图标**：`copySelection` 的 `icon:"fail"` 是 info 型废除时的误改，摘除（默认 success）。
9. **组内允许排序、跨组禁止**：原"分组模式整体禁排"（resolver isFolderView 直接排除）。makeGridResolver 加 `groupOfKey` 组约束——拖拽组与落点同组才出落点（多选跨组 / 落点跨组 = null）；显示排序物化分支可见序改网格注册的 displayItems（组拼接序，原 placementsFor 原序物化会错位）。
10. **新增区全排序模式置顶**：原仅 isDisplaySorted（非自定义）生效——"全部"视图自定义序下新导入沉底（存储序按文件夹段组织）。摘除排序模式条件，新增 / 导入 / 粘贴 / 新建文档恒置顶（切视图归位口径不变）。
