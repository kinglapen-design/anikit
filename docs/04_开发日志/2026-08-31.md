## 阶段七 7.1 二十二轮：多功能悬浮栏接入轮——旧通栏搜索栏摘除 + FloatBar 搜索模式接线

**落地**：

4. **ContentArea**：删 SearchBar import + `footer.search-wrap`；SearchFloatBar 挂 v-else 分支末尾；`.content-area` 加 `position: relative` 作定位基准；旧 SearchBar.vue 删除。

6. **后端**：search.rs 注释 chip 表述清理（逻辑零改）。

**PRD 改写**：03_查找文件 01 节（指令式搜索 → 搜索：前缀指令与 tag 化废除条）/ 2 筛选节（悬浮栏按钮组 + 弹窗口径，条件呈现与交叉组合随筛选轮定）/ 02 快捷搜索框；00_功能总览 3.1/3.2/3.4；03_数据链接 04 白名单条（筛选（/）→ 筛选按钮组）；07 接口文档 search_assets 条 chip 表述；09 待办 3.6 二轮 tag 化遗留条作废（谈不上两口径并轨）。
