# 5.2 前端：预览播放套三形态 + 逐帧笔记浮层（前端落地，文档同步收尾）

**5.2 前端：预览播放套三形态 + 逐帧笔记浮层（前端落地，文档同步收尾）**。① **kind 六态分派**（stores/preview.ts loadAsset）：frameCount&&!animated → sequence；animated → anim（list_anim_frames 占位清单 + preview-anim-frames-ready 渐进填 fullPath/stripPath/delayMs）；音频/视频扩展名 → audio/video（get_media_source）；其余维持 get_asset_file_path（image/other）。② **引擎统一**：FrameEntry 加 delayMs（序列帧 1000/fps 预填、动图事件推送准确值），tick 按"当前帧 delayMs/倍率"推进（下限 16ms 防占位 0 值死循环），未解码帧停住等就绪；序列帧 4.3 行为等价回归。③ **stores/previewMedia.ts**：模块级单例 `<video>` 元素（音频同用免双实现），元素事件同步 playing/currentTime/duration/volume/rate/loop；视频 loadedmetadata 把 videoWidth/Height 喂进同一套 fit/缩放数学；转码中 transcoding 加载态，源解析失败 kind 落 other + 中文文案；setVideoThumb 成功后 thumbPath 置空还原技巧刷新卡片。④ **播放条三形态**：PreviewPlayBar 改 16 行分发壳 + PlayBarFrames（sequence/anim 共用）/ PlayBarAudio / PlayBarVideo / VolumeControl（点击切静音、悬停出滑块浮层，4px 透明桥接防 hover 断开）；波形进度条 = 波形缩略图铺满 + C1-40 罩层压暗未播放（无 opacity token，用既有色档罩层实现）+ clip-path 全亮已播放 + 1px 品牌紫播放头，pointer capture 拖动 seek。⑤ **笔记浮层 PreviewNotes.vue**（用户定案浮层编辑器）：播放条上方 bottom:100% 锚定，当前帧/时间标识 + textarea（失焦/Ctrl+Enter 保存）+ 全部笔记列表（点击跳帧/跳时间、删除、当前项高亮）；**打开即暂停双引擎**——视频 currentKey 随播放每毫秒变会冲掉编辑目标帧；帧条有笔记帧块右上角品牌紫圆点；PreviewPanel 快捷键加 INPUT/TEXTAREA 焦点守卫（textarea 空格/方向键不被抢）。⑥ **TitleBar 按 kind**：anim/video 去默认应用打开，audio 无缩放组/旋转翻转/默认应用打开；全屏机制覆盖 anim/video；视频暂停时 ←/→ 逐帧 ±1/24s，音频 ←/→ 维持上/下一个素材（定案逐帧只给视频）。tsc / build 全绿。
