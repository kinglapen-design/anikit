## 1. 命令 API（Tauri commands，占位分组，实现后逐条补签名）

- **库管理：**
	- `create_library(path: string) -> LibraryInfo` —— 在选定空文件夹创建素材库（文件夹名即库名）；已是资源库 / 非空文件夹返回中文错误
	- `open_library(path: string) -> LibraryInfo` —— 校验结构（asstes/ + folders.json 可解析且版本合法）后打开；打开流程内含版本迁移检查（迁移前自动备份）与 24h 定时备份
	- `get_current_library() -> LibraryInfo | null` —— 当前打开的库；前端启动据此决定是否弹"创建/打开资源库"模态
	- `list_recent_libraries() -> LibraryEntry[]` —— 全局配置 config.json 的资源库最近列表（最近在前）
	- 类型：`LibraryInfo = { name, path, assetCount, folderCount }`；`LibraryEntry = { name, path, lastOpenedAt }`
	- 关闭 / 备份 / 版本回滚命令：待后续阶段
- **导入（阶段 3.1 落地，后台任务 + Channel 流式；4.1 序列帧打包）：**
	- `classify_paths(paths: string[]) -> { kind: "files" | "folder" | "mixed", fileCount }` —— 拖拽 / 菜单共用预判；fileCount 为递归展开后文件总数
	- `detect_sequences(paths: string[]) -> SequenceGroupInfo[]` —— 序列帧检测（后端为唯一事实来源，4.1）：递归展开后按"同目录 + 基础名 + 扩展名 + 序号位宽"分组（`标题001` / `标题 (1)` / `标题_001` / `标题-001`），序号连续（缺帧 ≤ max(2, 跨度/10)、同组同号不判）且 ≥3 且为图片格式（png/jpg/jpeg/gif/webp/bmp）才判定；`SequenceGroupInfo = { name, ext, frameCount }`（name = 基础名即资产标题）。09 导入弹窗确认后调用，命中则追加弹 12_序列帧弹窗
	- `import_paths(paths: string[], structure: "flatten" | "keep", source: "copy" | "move", targetFolder: string | null, sequenceMode: "pack" | "scatter", onEvent: Channel<ImportEvent>) -> taskId` —— **立即返回 taskId，导入在后台线程执行**（分段短锁：扫描 / hash / 复制 / 缩略图在锁外，索引与 folders 写盘在锁内毫秒级，UI 不阻塞）；keep 按原结构建文件夹节点（同级同名复用）并先发 folders 事件；move 跨盘回退 copy+删；hash 命中挂起待 resolve_conflicts 决策；单文件失败不阻塞整批。**sequenceMode = "pack"（4.1）：检测到的序列帧整组打包为一个 Asset**——`{ID}.info/frames/` 归一重命名 `标题-序号.扩展名`（序号补齐位宽），metadata 记 fps（默认 24）/ frameCount / thumbFrame（首帧文件名），缩略图复用图片管线取 thumbFrame；组 hash = 各帧 sha256 按序号升序串联后再 sha256；Placement 显示名 = `标题.扩展名`；复制/剪切对整组生效（剪切整组帧移走）；"scatter" = 逐文件导入（现状；剪贴板 / 收件箱恒 scatter）。started.total 按单元计（散文件数 + 组数）
	- `import_clipboard(targetFolder: string | null, onEvent: Channel<ImportEvent>) -> taskId` —— 剪贴板图片 → PNG 落 cache/ 后以 move + flatten 走同一管线；命名 剪贴板-yyyyMMdd-HHmm，重名 -序号；剪贴板无图片报中文错
	- `cancel_import(taskId: number)` —— 置位取消标志，管线在当前单元写完后中断（已导入部分保留）
	- `resolve_conflicts(items: ConflictResolution[], source: "copy" | "move") -> { resolved, failed }` —— 冲突决策（导入完成后统一处理）；`ConflictResolution = { sourcePath, existingAssetId, targetFolder, action: "useExisting" | "copy" | "link" | "skip", linkName?, sequence?, sourceThumbPath? }`；useExisting 把已有资源 origin Placement 移至 targetFolder（目标处链接去重），copy 继承 source 建档（**序列帧冲突按回传的 sequence 组信息重新打包**，4.1），link 建链接 Placement（linkName 或原名），skip 不动（源文件保留）；**sourceThumbPath 原样回传——决策成功（含 skip）即删除该预览缓存，且 cache/tmp 为会话级临时、打开库时整目录清空（4.2，2026-07-23 用户定）**
	- 事件流 `ImportEvent`（tag="type" camelCase）：`{type:"started",total}` → keep 模式 `{type:"folders"}`（层级已建，前端重拉文件树）→ 逐单元 `{type:"asset",placement:PlacementView}`（到一个显示一个）→ `{type:"finished",imported,conflicts:ConflictItem[],failed:{path,reason}[]}`
	- 冲突挂起项 `ConflictItem`（携双侧显示数据，供 10_重复添加提示）：`{ sourcePath, sourceName, sourceSize, sourceW, sourceH, sourceThumbPath, targetFolder, targetFolderName, existingAssetId, existingName, existingW, existingH, existingSize, existingExt, existingThumbPath, existingFolderName, sequence? }`——**sourceThumbPath（4.2 补）**：webview 直渲不了的格式（PSD/PSB/SVG 等）后端经解码管线生成的预览缓存绝对路径（cache/tmp/{路径+大小散列}.webp，幂等）；图片格式为 null，前端直读源文件。**不复用已有侧缩略图**：将来支持剪贴板自定义缩略图后 hash 相同缩略图也可能不同（2026-07-23 用户定）；**序列帧冲突（4.1）**：sourceName = `标题.扩展名`、sourcePath = 首帧路径（弹窗预览首帧）、sequence = `{ name, ext, width, frames: [{path, number}] }`（帧按序号升序，前端原样回传给 resolve_conflicts）
	- **根目录约定：Placement.folder 用保留 ID `"root"` 表示，Folder 列表不放 root 节点**
	- **新导入前插（2026-07-25 用户定）：新 Placement 插到目标文件夹段首（add_placement 锚点保批内到达序，新批次排旧批次前），显示顺序 = items 数组顺序；order 向负生长（仅相对键，7.1 排序落地时统一重排）；前端流式导入同语义前插（started 锚点清零，finished 后 refresh 全量对齐）**
- **内容浏览（阶段 3.1 落地）：**
	- `list_folder_tree() -> FolderNode[]` —— 文件夹树（按 order 排序）；`FolderNode = { id, name, count, children }`，count 为**递归 Placement 总数**（含全部子文件夹，2026-07-25 用户定：整洁层级下直接数会大面积为 0）
	- `list_placements(folder: string | null) -> PlacementView[]` —— folder=null 为"全部"；`PlacementView = { assetId, folderId, name, w, h, ext, thumbPath, thumbKind, origin, frameCount, animated, duration, bpm, importedFrom }`（`importedFrom`: "inbox" | null，2026-07-25 补；快速访问"已导入"按 importedFrom=inbox 且未摘标持久显示（不限 folderId=root：手动导入 Keep 生成的层级也算未分类；摘标=清 importedFrom，归 6.3））；thumbPath 为缩略图绝对路径——info 内缩略图优先，无则回退**系统格式图标缓存** `cache/thumbs/{ext}.webp`（4.2：PSD/SVG 由 psd/resvg 解码出内容缩略图进 info；fla/zip 等非素材与无伴生图工程文件走 shell 格式图标，按格式缓存一份、不进 info；皆无为 null）；**thumbKind = "asset" | "formatIcon" | null（2026-07-22 用户定）——格式图标为方形，卡片/列表行 contain 显示不裁切，无尺寸资产卡片容器按 1:1 布局**；w/h 无尺寸为 null；**frameCount 序列帧（4.1）与动图（5.1）皆非 null——前端按 animated（5.1 补：frameCount 非空且 ext 为 gif/webp）区分：序列帧把格式标签与名称后缀显示为"序列帧"（`标题.序列帧`，仅显示层，数据与磁盘文件不动，2026-07-22 用户定），动图显示紫角标**；**duration（秒，5.1）= 视频 / 音频 / 动图时长，卡片标签改时长属性（mm:ss）；bpm（5.1）= 音频内嵌标签 BPM（TBPM/bpm，只读标签不做自动检测，2026-07-26 用户定），无标签为 null**。5.1 缩略图口径补充：视频首帧（ffmpeg sidecar 抽 0s 帧）、音频波形图（min/max 多窗口低 alpha 叠加：稳态主体实心、瞬态尖峰半透明发丝，2 倍超采样 + Triangle 降采样 → 640×272，**上半左声道 / 下半右声道**立体声分绘，约 2.35:1 长方形 Eagle 同形态，柱 #F8F5FA 基色；音频 w/h 记波形图尺寸且与 ffprobe 探测解耦，卡片按宽比例布局）均走既有 webp 缩略图管线进 info；GIF / WEBP 动图取首帧（image crate / image-webp 纯 Rust 解码）；sidecar 二进制缺失时音视频退化为格式图标保底、导入不失败
- **收件箱 Inbox（阶段 3.2 落地；4.4 语义重定 2026-07-25：自动导入收窄白名单 + 磁盘实况手动导入）：** 随 `create_library` / `open_library` 自动启动（库切换重建、应用退出收尾）；库内 `inbox/` 挂载为盘符（DefineDosDeviceW 会话级映射，A / B 优先其后 Z→E 选空闲；托盘"收件箱盘符"开关手动挂 / 卸）；notify 增量监听（写入完成检测：静默 2s + 大小两轮一致 + 全部文件可移走——GENERIC_READ|DELETE 探测，与 move 同口径；逐条目独立判定：占用条目自己等放手不拖累其他条目；启动清点存量）→ 就绪批次**经白名单过滤**（`AUTO_IMPORT_EXTS` = png/jpg/jpeg/bmp/webp/gif/psd/psb/svg/ai/mp4/mov/avi/mpeg4/m4v 小写比较（视频 2026-07-25 用户补；音频待 5.1 再扩），不反向枚举工程格式；文件看扩展名，目录须递归文件非空且全部白名单）串行走 import 管线（keep + move 过境语义：导入后即移走、目录常态为空；白名单以外留在磁盘不自动导入）→ 事件 **`inbox-import`**（负载 = ImportEvent，与导入 Channel 同形状），前端复用 11_导入进度条与 10_重复添加提示（冲突决策走 `resolve_conflicts`，source 恒 "move"）；**自动合并**：撞 hash 且已有资产同为 inbox 渠道（`metadata.importedFrom`）时静默合并——已有资产改名为新文件真实名（磁盘 originName + 词干缩略图 + origin Placement）、新文件作为重复丢弃、发 asset 事件，正式资产（非 inbox）不受影响照常询问（PRD 01-2.3 注，2026-07-22 定案；只服务自动入库媒体，逻辑未动）
- **收件箱磁盘实况（4.4，"工程文件"区块；事实来源 = 磁盘，不建档不写库不建持久状态）：**
	- `list_inbox_snapshot() -> InboxEntry[]` —— **快层快照**（同步返回，必须快）：`InboxEntry = { name, isDir, size, modifiedAt, autoImportable, occupied, iconPath }`（modifiedAt Unix 毫秒；autoImportable 白名单判定——目录递归扩展名全白名单，只读目录项不算大小）。快层口径：文件 size 取元数据、occupied 单文件可移走探测（都便宜）；**目录 size 先给 0、occupied 先给 false 占位**（递归贵，由 details 事件补齐）；iconPath 只命中已缓存的 `cache/thumbs/{ext}.webp`（只判存在，不触发 shell），目录恒 null
	- `import_inbox_entry(name, onEvent: Channel<ImportEvent>) -> task_id` —— 手动导入 = **移走入库**（Move + Keep + imported_from "inbox" + Scatter，无复制入口）；占用条目中文拦截；复用 spawn_import 任务管线（进度条 / 重复提示流与常规导入一致）；失败不重投（用户显式动作，错误已回前端）
	- `open_inbox_entry(name)` / `rename_inbox_entry(name, newName)` / `delete_inbox_entry(name)` —— 磁盘操作仅 inbox 根下一级条目（拒 `..` 与 `\/:*?"<>|` + canonicalize 父目录校验防穿越）；删除 = 文件 remove_file / 目录 remove_dir_all，占用等系统错误原样透传中文
	- 事件 **`inbox-fs-changed`**（负载 = ()）：watcher 任何带路径事件触发（前端 150ms 去抖后重调 list_inbox_snapshot 全量替换——新增 / 删除 / 重命名不丢文件）；占用语义：被占用不自动入库、放手也不自动入库，仅更新实况展示
	- 事件 **`inbox-disk-details`**（负载 = InboxEntry[]，**慢层**）：detail worker（AtomicBool 防重入，延迟 200ms 合并连发）在 fs 变化 / 收件箱启动时后台算完整快照——目录递归 size、全文件 occupied 探测、文件条目 iconPath 经 `ensure_format_icon` 现场生成 / 命中（shell 调用只允许在该 worker，图标只写 cache/thumbs 不写 info，不递归触发 fs-changed）；前端收到后整体替换快层快照，目录大小与占用标记以本事件合并后为准
	- **failed 残留重投**：自动导入 run_import 返回 outcome 后，failed 项中源 path 仍存在且位于 inbox 根内的经 `requeue_failed` → `WatchHandle::requeue`（wake 通道发带路径 synthetic Event）重投监听等待队列，走常规就绪判定（静默 + 可移走 + 大小稳定）自动重试——覆盖"探测后软件又锁住、move 阶段失败"的竞态；conflicts 不重投（skip/useExisting/link 是用户决策，源保留属预期）
- **预览（阶段 4.3 落地）：**
	- `get_asset_file_path(assetId: string) -> { path: string | null, pending: boolean }` —— 预览显示路径解析：webview 可直渲格式（png/jpg/jpeg/bmp/gif/webp/svg）返回源文件绝对路径；psd/psb 缓存命中返回全尺寸缓存路径，**未命中则提交预览解析队列并返回 `pending: true`**（前端先显缩略图，事件 `preview-full-ready { assetId, path }` 到达后替换高清）；其余格式 path=null + pending=false（前端用格式图标大图兜底）
	- `list_sequence_frames(assetId: string) -> { fps, thumbFrame, frames: [{ name, fullPath, stripPath }] }` —— 序列帧帧清单，**立即返回（帧原图立即可播）**：扫 `{ID}.info/frames/` 按文件名排序（帧可缺号，不推导）；fps 缺省 24；stripPath 为帧条小图路径——已缓存直接填，未缓存为 null 并提交预览解析队列后台生成，每 8 帧（或收尾）发事件 `preview-strips-ready { assetId, items: [{ name, stripPath }] }` 渐进填充（2026-07-25 用户定：播放不被帧加载卡住）
	- **预览解析队列（services/preview_queue，2026-07-25 用户定）**：单 worker 线程 + 代际号——**提交新任务即清空 pending 并代际 +1**（预览只服务当前停留素材，过期任务作废）；PSD 单文件解码不可中断（完成落盘无害，已切走不发事件），帧条逐帧查代际可中断；lib.rs setup 初始化（AppHandle 发事件，cfg(test) 空实现，见踩坑 014）
	- `set_thumb_frame(assetId: string, frameName: string) -> { thumbPath }` —— 当前帧设为预览图（2026-07-25 用户定：重新生成缩略图 + 记封面帧）：对帧图重跑缩略图管线（词干同名直接覆盖），更新 metadata 的 thumbFrame/thumbnail/modifiedAt 并同步内存索引；返回新缩略图绝对路径（前端即时换卡片图）
	- `open_with_default_app(assetId: string)` —— 系统默认程序打开源文件（Windows ShellExecuteW "open"，adapters/shell_open；非 Windows 暂不支持）
	- `open_preview_window(assetKey: string) -> ()` —— 新窗口打开预览（4.3）：assetKey = `{assetId}|{folderId}`；窗口 label `preview-{assetId}`，同资产复用聚焦，否则开无边框预览窗（视觉参数同主窗口），URL `?preview={assetKey}` 进独立预览布局
- **Placement：** 移动 / 链接 / 副本 / 重命名（异步改 originName）/ 删除 / 排序 / 克隆文件夹
- **标签：** 增删改 / 合并 / 群组
- **搜索：** 分词搜索 / 筛选
- **缩略图：** 生成 / 重建 / 系统缩略图（按格式缓存）；封面帧设置已落地（见预览组 `set_thumb_frame`）
- **回收站：** 列表 / 还原 / 彻底删除 / 清空

## 2. 动画软件通信通道（WebSocket）

- 服务：`ws://127.0.0.1:{port}`，端口动态分配并写入全局配置；插件启动后连接并保持长连接。
- 请求：JSON `{ id, action, payload }`；响应：`{ id, ok, data | error }`。
- 事件（插件 → AniKit 主动上报）：`progress` / `done` / `error`。
- Animate 适配器起步动作：`sendToStage`（剪贴板载荷 + clipboardPaste 原位粘贴）/ `exportThumbnail` / `getState`。
- 协议细节待阶段 0 剪贴板格式验证后补充。

## 3. anikit:// 协议

- `anikit://item/{ID}` —— 软件内跳转；外部软件（如 Obsidian）点击调起 AniKit 并跳转（安装时向系统注册协议处理，Windows 注册表 / macOS Info.plist）。
