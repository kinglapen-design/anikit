- **重排交互升级（用户反馈防抖不丝滑）**：200ms 防抖改为 Eagle 式缩放过渡——拖动窗口/拆分条期间 canvas 按宽度差整体等比缩放（transform，卡片实时跟随），宽度差超 12% 立即重排，否则停顿 240ms 后精确重排。

## 2026-07-17

- PRD 九份文档（00-08）完成终审，迁入 `docs/03_项目-PRD/`，脱离 Obsidian 直接编辑，避免同步漂移（此前发生过两次内容丢失）。
- 技术栈拍板：**Tauri + Rust 后端 + 严格 TS 前端**。理由：原生集成密度高（剪贴板格式 / Shell COM / 全局热键 / 文件监听）Rust 一线全包；无 GC 停顿利于大列表滚动；Rust 编译器是 AI 生成代码的即时验收机，bug 出不了编译期。
- 选定 Tauri 而非 Electron 的补充依据：Eagle 本身即 Electron 开发，证明 Web 技术可达到性能线；Tauri 运行时更轻，但窗口拖出等能力需在阶段 0 验证。
- MVP 范围锁定：封闭库 + 文件树/标签/基础操作 + 分词搜索 + 四种布局预览 + 导入导出 + Animate 缩略图与发送。索引工作空间、标注、向量/AI 全部后置。
- 确立六阶段路线（见 [[05_项目进度]]），阶段 0 技术验证第一优先为 **Animate 剪贴板格式验证**。
