# 新面板口径速查

> **UI 任务（任何新面板 / 弹窗 / 卡片 / 列表 / 菜单）动手前必读。** 每条都是实机踩坑后的定案（带错误信号）。设计稿没有明确规定的部分，一律按本表；本表没有的，先问用户再写码（规范红线：禁止凭感觉自创样式）。定了新口径就回本表补条（规范第 4 条）。

## 1. 弹窗（一律 AppModal，禁手写壳）

- 外框 = 1.5px 亮-选中**真 border**（盒模型内缩）。**禁** inset box-shadow 画框（内容层画框 → 滚轮/内容压线）。
- 标题 = **常态色**（AppModal 默认已是 `--text-normal`，**勿覆盖**；高亮是错误信号）。
- 按钮组 = **主左次右**（确认/合并/开启/删除 在左，取消/上一步 在右），88×38 定宽；底部按钮栏 62 高、padding 12 12 12 24、顶部分隔线。
- **AppConfirm 按钮 min-width 88 已组件化（2026-08-15）**：`.app-confirm :deep(.actions) .app-btn { min-width: 88px; }`——各弹窗不必再局部补（错误信号：确认弹窗按钮随文案塌宽）。注意 `.text` max-width 372 是共享口径，描述超长会换行使弹窗实测宽度偏离稿值，改动须用户定夺。
- 遮罩点击一律不关闭；关闭只走 X / 取消按钮。
- 弹窗内 item 底色 = 窗口同色 C2（靠线条分层，不靠底色）；选中行描边 1.5px `--brand-border`。
- 定宽弹窗写内容宽（border 另占 3px），宽度链变化时全组重算（如卡片行 666 链）。

## 2. 滚轮（滚动条）

- **纵向 = `ScrollThumb` 悬浮件**（悬停显隐）：滚动容器挂 `.kit-scroll` + relative 包裹层 + `<ScrollThumb :body="ref" />`。**禁止**：原生恒显 / `scrollbar-gutter` 占位 / 容器 border 占位 / **"padding + gutter 凑边距"**（6+6=12、10+6=16 这种凑法就是错误信号——主窗口边距就是纯 padding 16）。
- **横向 = `.kit-scroll-x`** 原生 6px 实色胶囊（C4/C5），容器 `padding-bottom: 6` 容纳。
- 悬浮滚轮贴边不压弹窗框的前提 = 弹窗真 border（见 §1）；**内容区内的分隔线**被滚轮压时，包裹层 `::after` 上层补画（z-index 11、pointer-events none）。
- 滚轮 thumb 用**实色** C4/C5（透明色与线条交叉叠色，2026-08-10 定案作废）。

## 3. 列表 item（树 / 组列表 / 横条行）

- hover = 叠**暗-悬停**罩层（`--line-hover`）；选中 = **亮-选中**罩层（`--line-active`）+ **1.5px 文字常态**内阴影（与目录树 `TreeItem.selected` 同款，勿自创）。
- 选择域联动描边 = 1.5px `--brand-border`（`domain-selected`）。
- **选中态行 hover 不再变色**（`:not(.cur):hover`）；可点行 `cursor: pointer`；item 圆角 6。
- 复选/单选/开关一律 AppCheckbox / AppRadio / AppSwitch；红色圆减号 = IconButton `delete-red` 形态。
- **表单行标签冒号一律英文 `:`**（2026-08-19 用户定，全库统一——「规则:」「范围:」「分组名称:」等；句子/toast 正文里的标点不动）。
- **多值 chips 区换行向下排、行高自适应**（`min-height` 不用固定高）；左侧「× 规则 范围」标签组包 `.row-head` 恒 28 高居首行——chips 变两行时标签**保持首行垂直居中**，不随整体居中（33 稿规则行口径；错误信号：固定 44 高 + wrap → chips 溢出/标签跑两行中间）。
- 菜单项「上移/下移」类**跟在文字右侧的小图标 = MenuItem `trailingIcon`**（12px 标签档色，禁用随父色；`trailingIconClass: "rot-180"` 转向），不占左侧 18px icon 位（2026-08-19 12 稿对齐）。
- 分词输入 = **TermChipsInput**（chips + 回车/空格/+/失焦提交；IME isComposing 守卫——回车空格是选词键，不守卫会把中文输入确认误提交成 chip）。
- **主窗口搜索框 = tag 化 chips 形态（2026-08-19 用户定，3.6 二轮）**：前缀指令与关键字都成 chip——`~`→「~ 全局搜索」（范围 = tag，**无范围按钮**）、`//`→「// 搜索」、`/`→「/ 筛选」占位；连写剥落（`~人物` 空格 → 两个 chip）；交互同 TermChipsInput（空格/回车提交、空草稿 Backspace 删尾、× 删、失焦提交草稿），**草稿未提交也即时参与搜索**；右侧 kbd 徽章组（/ 筛选 // 搜索 ~ 全局）= **未聚焦且无内容时的提示**，聚焦或有内容隐藏、输入区贯穿；chips 换行搜索栏向上撑高（min-height 46，不固定死）。**chip 样式不用品牌色**——照分组管理未选中 tag 口径（C4 底 / 1px 暗-悬停线 / 常态字，2026-08-19 用户定）。

## 7. 线条与叠色

- 半透明线十字交叉会**双倍叠色**——横线端点不得与异色竖线在同一内容层重叠（弹窗真 border 后横线自然不碰竖框；新画通栏线时自查两端）。
- 双线重叠检查：相邻两条分隔线（如列表末行底线 × 按钮栏顶线）用 `:last-child` 判定去一。
- **1.5px 状态描边一律 `::after` 伪元素 border**——inset box-shadow 1.5px 在分数物理像素下边缘渗线、断出像素点（文件夹卡片 2026-08-10 / 区块头 drop-into 2026-08-14 两次实机踩坑）。
- **状态描边过渡一律 opacity，禁 border-color / box-shadow 颜色过渡**（2026-08-19 踩坑 036）：颜色过渡是**重绘型动画**——圆角 + 1.5px 分数像素下 GPU 合成损伤区偶发漏覆盖，取消状态（选中/聚焦/hover）后**品牌色像素点残留**（用户实机反复出现；headless 软渲染复现不了，探针须非 headless GPU 路径）。机制 = 常态层（无过渡）+ 状态层（border 恒定，opacity 0↔1 过渡；换色瞬时、透明度动画）——AssetCard / FolderCard / ArchiveCard / InboxDiskSection / PreviewFrameStrip / AppInput / AppSearchBar 已全部落地此结构；新写状态描边照抄。
- **落点指示线 / 竖块要画出容器留白区时，Teleport 到 body 按 client 坐标画（fixed）**——`grid-viewport` overflow 裁剪会把负 layer-x（首列前插间隙 = 容器 16 留白区）整条裁掉（2026-08-18 实机"首列前插提示线不可见"根因）；钳位回 0 又会盖住首卡。素材网格 .drop-gap（AssetGrid gapClient）与文件夹条带 .folder-drop-gap（FolderStrip gapBar）同此机制；拖拽中指针持续 move → 每次重取 rect 自愈滚动滞后。
