所有的区块都允许折叠和展开，收起时，内容往上滑出总容器，只保留区块副标题，展开时，内容从上之下滑入总容器。

详情面板的区块允许拖拽排序（颜色信息区块永久置顶除外）。鼠标移到区块副标题区域时，指针变成抓手（cursor: grab），展开箭头 + 标题提亮 font-icon-1，无底色；整行均为折叠判定区，添加按钮不参与抓手。可移动区块 hover 底色 C2（详情面板区块悬停底色，pinned 除外）。
