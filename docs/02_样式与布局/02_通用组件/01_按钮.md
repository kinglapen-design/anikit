## 05. 视图切换按钮

视图按钮有四个。

左侧边栏：资源库视图、工作空间视图、标签视图、快捷入口视图。

右侧边栏：详情视图、AI 对话框视图、AI会话视图、AI 生成视频视图。

视图切换按钮，也就是永远有一个按钮处于持久选中状态，切换时 background C4-15 平移动画，点击的瞬间，取消 hover 效果后执行平移。

``` css
/* 总容器：视图按钮 */
box-sizing: border-box;

/* Auto layout */
display: flex;
flex-direction: row;
align-items: center;
padding: 4px;
gap: 6px;

width: 填充父容器;
height: padding + 子项;

background: C1-50;

border: 1px solid C4-15;
border-radius: 8px;

/* Inside auto layout */
flex: none;
align-self: stretch;
flex-grow: 0;

/* 视图按钮：图标 */
/* Auto layout */
display: flex;
flex-direction: row;
justify-content: center;
align-items: center;
padding: 6px;

width: 撑满空余空间;
height: padding + 子项;

background: none;
border-radius: 6px;

hover: background C4-7;

active: background C4-15; /* 持久化选中 */

/* Inside auto layout */
flex: none;
flex-grow: 1;

/* 图标 */
width: 16px;
height: 16px;

color：C4-40;

active: C4; /* 持久化选中 */

/* Inside auto layout */
flex: none;
flex-grow: 0;
```
