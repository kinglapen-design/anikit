## 01. 滑块

可以选择是否要百分比，无百分比时，直接删除百分比。

``` css
/* 总容器：滑块组 + 百分比 */
/* Auto layout */
display: flex;
flex-direction: row;
align-items: center;
padding: 0px;
gap: 6px;

margin: 0 auto;
width: 120px;
height: 10px;

/* Inside auto layout */
flex: none;
flex-grow: 1;

/* 滑块组：滑轨 + 按钮 */
width: 120px;
height: 子项;

/* Inside auto layout */
flex: none;
order: 0;
flex-grow: 0;

/* 滑轨 */
position: absolute;
width: 120px;
height: 0px;
left: 0px;
top: 5px;

border: 3px solid C4-15;

/* 按钮 */
position: absolute;
width: 10px;
height: 10px;
left: 42px; /* 具体位置根据滑动位置 */
top: 0px;

background: C4;

/* 百分比 */
[[01_样式 token]] / 副文本

color: C4-70

order: 1;
```
