> 2026-07-23 用户定稿：图层色与边框见 [[01_样式 token#01. 颜色]] 第 7 节；

``` css
/* 标签（X 个文件 / Y 个子文件夹；无子文件夹仅 X 个文件） */
```


## 03. 素材卡片

> 2026-07-23 用户定稿（回退"图片 + 居中文字"方案——新设计窄图名称压缩严重已否决）：
> 角标保持实底彩色徽章（位置回图片左上）；按钮组回图片右下，但改图标按钮-小（图片干扰大，不裸 16 图标）。

``` css
/* 总容器：图片 + 文字组 */
display: flex;
flex-direction: column;
padding: 0px;
gap: 4px;

width: 按布局（justified 行高等比）;
height: 图片（按原图比例）+ 64;

/* 图片：高 = 总高 - 64 */
/* 无常态边框——::after 伪元素占位，hover/选中上色 */
border-radius: 8px;
/* 注：边框用真 border——inset box-shadow 会被铺满的图片盖住（同主窗口机制） */

hover: border 2px border-1;
active: border 2px 品牌色-1; /* 持久化选中 */

/* 格式角标：图片左上各 4px（静态图片格式不出角标） */
padding: 0px 4px;
border-radius: 4px;
background: 格式深色（token 01-6）;

font: [[01_样式 token#02. 文字]] / 角标文字（10/16 粗体）;
color: font-icon-3;

/* 按钮组：图片右下各 4px / 间距 4（发送至 + 放大镜） */
[[01_按钮#01. 图标按钮 - 无底色装饰]] / 小图标（24×24 / padding 4 / 圆角 4）;

background: C1-20%; /* 深色透明压图 */
color: font-icon-3; /* 图标 60% */

常态: 悬停卡片才显示;
hover: background C1-40% / 图标 font-icon-2（80%）;

/* 文字组：间距 2 / 居中 / 高 60 顶部对齐（一行时与图片间距恒为总容器 gap 4） */
display: flex;
flex-direction: column;
justify-content: center;
gap: 2px;

height: 60; /* 标题两行 40 + 间距 2 + 标签 18 */

/* 名称：最多两行，两行显示不完截断 */
[[01_样式 token#02. 文字]] / 正文;

color: font-icon-3; /* 图标 60% */
text-align: center;

hover: 输入指针
active: border 1px border-radius: 4px 品牌色-1; /* 双击进入输入聚焦 */

/* 标签（尺寸 / 格式） */
[[01_样式 token#02. 文字]] / 副文本;

color: font-icon-3;
text-align: center;
```
