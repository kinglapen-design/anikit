## 03. 素材卡片

> 2026-07-23 用户定稿（回退"图片 + 居中文字"方案——新设计窄图名称压缩严重已否决）：
> 角标保持实底彩色徽章（位置回图片左上）；按钮组回图片右下，但改图标按钮-小（图片干扰大，不裸 16 图标）。

``` css
/* 总容器：图片 + 文字组 */

flex-direction: column;
padding: 0px;
gap: 4px;

width: 按布局（justified 行高等比）;
height: 图片（按原图比例）+ 64;

/* 图片：高 = 总高 - 64 */
/* 无常态边框——::after 伪元素占位，hover/选中上色 */

/* 注：边框用真 border——inset box-shadow 会被铺满的图片盖住（同主窗口机制） */

/* shell 格式图标（thumbKind=formatIcon）：最大边 = 图片容器 50%（左右各留 1/4，
```

### 03-1. 悬停行为按类型分发（2026-07-27 用户定案，5.3）

> 悬停按钮按需出（不再全部"发送 + 放大镜"）；视频 / 音频 / 动图悬停直接播放、无按钮。
> 行为矩阵与交互细节见 [[04_文件预览]] "卡片悬停行为分发定案"，本节只记样式规格。

``` css
/* 悬停按钮分发（DOM 顺序固定：发送 → 默认应用打开 → 放大镜） */
静态图片: 放大镜;
图片工程（PSD/PSB/SVG/AI 有内容缩略图）: 默认应用打开 + 放大镜;
动画工程（fla/aep 有内容缩略图，8.2 后）: 发送 + 默认应用打开 + 放大镜;
动图 / 序列帧: 放大镜（浮层内播放，2026-07-28 用户定；序列帧归动图范围）;
视频 / 音频: 无按钮（播放层；放大无意义）;
格式图标（shell 图标）: 仅默认应用打开;

/* 放大镜触发（2026-07-28 用户定）：悬停到放大镜图标上 150ms 即出浮层（不点击），
   移出图标 / 滚出 / Esc 即关 */

/* 视频播放层（HoverVideoLayer，参考图 1）：视频铺满图片区（object-fit 同卡片图）；
   悬停 = 完整播放整段（scrub 走预生成预览帧切图，帧图层与卡片图同 object-fit，2026-07-28 Eagle 帧图方案）；
   自动播放（查看方式开关）= 封面帧起 10 秒循环、无控件恒静音 */
进度条: 贴底横贯 高 3 / 轨道 border-2 / 已播 fill 品牌紫-1;
右下胶囊: 右 4 下 7（进度条上方 4）/ padding 2 6 / 圆角 4 / C1-40 底;
胶囊内: 当前时间（副文本 / font-icon-1）+ 音量钮（16×16，图标 12）;

/* 音频悬停播放层（HoverAudioLayer，参考图 2）：卡片缩略图即波形图 */
已播放高亮: div 以同一波形图作 CSS mask（mask-size 同卡片 object-fit）/ 品牌紫-1 实底 /
  clip-path inset(0 X% 0 0) 裁到进度;
播放头: 1px 品牌紫-1 竖线全高;
右下胶囊: 右 4 下 4 / 同视频胶囊规格 / 当前时间 + 播放暂停钮;

/* 序列帧播放层（HoverSequenceLayer）：帧图铺满（object-fit 同卡片图），无控件 */

/* 悬停放大浮层（HoverZoomOverlay，参考图 3）：Teleport body，z-index 2000；
   悬停放大镜图标 150ms 即出（2026-07-28 用户定：悬停触发不点击），移出图标 / 滚出 / Esc 即关；
   动图浮层 = 源文件原生循环播放；序列帧浮层 = 按 fps 轮播帧图（从封面帧起） */
遮罩: 全屏透明（背景不变暗）+ pointer-events none（鼠标穿透：浮层出现时鼠标仍 hover 放大镜按钮，
  移出按钮自然关闭；双击穿透可直进预览）;
浮层壳: max 80vw × 80vh / padding 8 / C3 底 / inset 1px border-1 / 圆角 8 / --shadow-pop;
图: contain 完整显示;
```
