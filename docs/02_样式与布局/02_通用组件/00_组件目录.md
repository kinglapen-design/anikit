- 07 上下文规则：剪贴板无文件 → 三粘贴项不出现；**新建文档组 = 系统检测动态显隐**（`lib/docApps.ts` ← `detect_doc_apps` 命令，每次打开 UI 监测）：已安装 → 带系统 exe 图标（`CtxItem.iconData`，MenuItem img 16 居中 18 盒）显示，未安装 → 删除该项；**MarkDown（md.webp 图标）/ 文本文档已点亮**（`create_text_document` 纯文本直接建档，先建后命名），其余新建业务 3.1 接。

- 定宽：稿定宽经 opts.width 传入（03/04/05/07 = 320 / 08 = 300 / 14 = 220 / 13 = 148；二级经 `CtxItem.submenuWidth`，缺省均 175）。二级稿宽（02_布局稿实测）：链接位置 320 / 缩略图·导出文件·汉堡"文件"二级 213 / 添加至其他资源库·AI 工具集·复制数据 180 / 排序依据 184 / 扫描重复文件 96 / 更改封面 152（汉堡"查找"二级无稿值，213 与文件二级同宽）。
- 边界钳制：菜单不超出窗口边缘（03 稿注）——右/下缘溢出回收进窗口留 4 呼吸，高过窗口封顶 100vh-8 纵向滚动；二级 flyout 右缘溢出改向左飞出。尺寸用 offsetWidth/Height 量（getBoundingClientRect 会带上弹出动画 scale 初帧导致低估）；flyout 换父项按 key 重建（实例复用会位置滞留）且 pop=false 不回放动画。
- 菜单结构（03/04/05 稿）：容器 padding 0，**搜索区与 item 组是两个容器**——搜索区高 44 / padding 12 / 搜索图标 18 盒 svg 15 标签色 / 占位符"搜索..." 极淡 / 右侧清除钮 20 圆角 6 / border-bottom 暗-悬停随容器满宽；item 组独立容器 padding 12 / gap 2，**divider = 组内自然宽 296（稿值），不通栏不用负 margin**（2026-08-11 二轮走查）。`searchable: true` 开启搜索：打开自动聚焦，输入即扁平过滤（一级+二级 label 大小写不敏感，命中二级平铺直接执行，过滤时无 divider 无 flyout），Esc 先清空再关。
- 关闭语义：点条目 = 执行并关（onClose(true)），点组外 / Esc = 取消（onClose(false)，供"右键未选中项先单选、取消恢复选择"）；菜单项点击默认不自动关的口径仅限 AppMenu 单独使用场景。**keepOpen 例外（2026-08-12 用户定判定口径）**：一次性任务类（新建 / 重命名 / 删除 / 导入——执行后进入后续输入或任务流）必关；可逆状态翻转类（切库 / 排序依据 / 展开收起——用户可能立即再做一次，如切过去看一眼切回来）标 `keepOpen: true` 执行后菜单保持。
- item 视觉：高 33 / padding 6 8 / 圆角 6 / 图标 18 / hover 叠 `--line-hover` 罩层 / 禁用 = `--line-active` 色不响应 hover；快捷键按 "+" 拆 KbdBadge 组，**显示小写化（词键 ctrl/shift/alt/enter/delete 小写、单字母大写，稿口径）在 MenuItem 统一转换**，spec 里仍写 "Ctrl+R"；二级箭头 = tree-expand-arrow 12 旋转朝右。
