## 菜单（AppMenu / ContextMenu / MenuItem / MenuDivider）

> 组件文档待逐份补写；先记 figma 稿之外的规则（1.3 一轮 2026-08-11 落地）。

- 触发与宿主：任何组件 `openContextMenu(e, entries, onClose?, { width?, searchable? })`（`src/lib/contextMenus.ts`）→ App.vue 唯一 `<ContextMenu>` 渲染；菜单 spec 集中在 `src/lib/menuSpecs.ts`（数据驱动，设计项全列、无业务 disabled 占位）。
- 定宽：稿定宽经 opts.width 传入（03/04/05/07 = 320；二级经 `CtxItem.submenuWidth`，缺省均 175）。
- 边界钳制：菜单不超出窗口边缘（03 稿注）——右/下缘溢出回收进窗口留 4 呼吸，高过窗口封顶 100vh-8 纵向滚动；二级 flyout 右缘溢出改向左飞出。
- 搜索框（03/04/05 稿）：`searchable: true` 开启——高 44 / 占位"搜索" / 右侧清除钮 / 下边框分隔；输入即扁平过滤（一级+二级 label 大小写不敏感，命中二级平铺直接执行，过滤时无 divider 无 flyout），Esc 先清空再关。
- 关闭语义：点条目 = 执行并关（onClose(true)），点组外 / Esc = 取消（onClose(false)，供"右键未选中项先单选、取消恢复选择"）；菜单项点击默认不自动关的口径仅限 AppMenu 单独使用场景。
- item 视觉：高 33 / padding 6 8 / 圆角 6 / 图标 18 / hover 叠 `--line-hover` 罩层 / 禁用 = `--line-active` 色不响应 hover；快捷键按 "+" 拆 KbdBadge 组；二级箭头 = tree-expand-arrow 12 旋转朝右。
