## 01. 输入框 - 通用

``` css
/* 总容器：文本 or 占位符文本 */
box-sizing: border-box;

/* Auto layout */
display: flex;
flex-direction: row;
align-items: center;
padding: 6px 8px;

width: 填充父容器;
height: padding + 子项;

background: C1-15;

border: 1px solid C4-15;
border-radius: 8px;

hover: 输入指针
active: border 品牌色-1; /* 持久化选中 */
error: border 错误色（--error）；下方可配一行提示（副文本 / --error），输入即恢复正常 /* 2026-07-21 定，Eagle 式校验 */

/* Inside auto layout */
flex: none;
align-self: stretch;
flex-grow: 0;

/* 文本 */
font: [[01_样式 token#02. 文字]] / 正文;

color: C4;

/* 占位符文本 */
font: [[01_样式 token#02. 文字]] / 正文;

color: C4-40;
```
