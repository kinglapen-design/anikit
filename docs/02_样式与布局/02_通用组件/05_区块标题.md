# 05_区块标题 / 分组标题

> 视觉以 figma-css `05_区块标题 item` 与分组标题稿为准；本文记 figma 没有的布局与行为规则（2026-08-08 用户定）。组件 = `src/components/SectionHeader.vue`（group 变体 = 分组标题）。

## 间距与 padding（2026-08-08 定案）

- **padding**：统一 `0`；仅目录树区块标题 `padding-left: 8px`。
- **区块内 gap（标题 ↔ 内容）**：通用 **8**；中间面板卡片区块 **12**（卡片需要更多呼吸空间）。
- **高度**：区块标题恒 **20**（有无添加按钮都不变，防抖动）；分组标题恒 **30**。

## 分组标题布局规则（卡片容器内，随 1.4 / 3.5 落地）

- 分组标题只出现在卡片容器里；**区块标题 ↔ 第一个分组标题 ↔ 卡片内容容器，相邻间距都是 12**。
- **折叠层级**：折叠区块标题 = 其下所有素材卡片（含全部分组）折叠；折叠分组标题 = 仅该分组子项卡片折叠。
- **sticky 置顶**：分组标题滚到容器顶部时停留；该组子项全部滚出后，下一分组标题接替置顶——分组标题带下拉菜单（快速跳转分组），置顶是跳转入口的常驻保障。

## 分组标题 figma 规格（已封装于 SectionHeader group 变体）

- 30 高 / 圆角 6 / padding 0；标题 16/22 700 文字-常态 + 数量；折叠箭头 12×12（标签档）；分组菜单按钮 30×30（group-menu 图标 18，标签档）。

## tail 插槽（2026-08-10，figma-css 02_布局/42_中间面板）

- 标题行右侧（spacer 之后、添加/分组菜单按钮之前）可挂自定义内容：**`#tail` 插槽**。
- 首个用例 = 文件夹卡片区块的"递归显示"复选框（AppCheckbox，绑 `ui.showSubfolders`，2026-08-10 已接入 `placementsFor`：开 = 文件夹视口含全部后代文件夹内容）；label 按 42 稿覆盖为标签档 12/17（组件默认正文 14/20）。
