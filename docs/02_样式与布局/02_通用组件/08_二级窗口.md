#### 不带关闭按钮标题栏

标题容器分为带图标和不带图标。

**通用规则（2026-07-22 用户定案，新弹窗直接执行，不用再问）：**
1. **宽度**：`width: fit-content`（由最宽子项决定，窗口不预留大片右侧空白），**最大 368px**；提示文字超出 368 限制时**换行**（不设单行省略）。
2. **按钮组右对齐**（`justify-content: flex-end`）；按钮按 [[01_按钮#07. 大标题按钮-小按钮]]（宽按标题自适应、高 38、padding 8px 16px）。
3. 需要更大窗口的特例（如 10_重复添加提示 1052×732）由用户单独出设计，不适用本条。

``` css
/* 总容器：标题容器 + 内容 + 按钮组 */
box-sizing: border-box;

/* Auto layout */
display: flex;
flex-direction: column;
align-items: flex-start;
padding: 16px;
gap: 16px;

position: absolute;
width: fit-content; /* 由最宽子项决定 */
max-width: 368px;

background: C3;

border: 2px solid border-1;
border-radius: 8px;
box-shadow: 0 4px 40px rgba(0, 0, 0, 0.6); /* 统一悬浮投影，见 [[01_样式 token#07. 阴影]] */

/* 标题容器：图标 + 标题 */
/* Auto layout */
display: flex;
flex-direction: row;
align-items: center;
padding: 0px;
gap: 6px; /* 不带图标时只有标题一个子项，间距无影响 */

width: 94px; /* 根据实际情况 */
height: 24px; /* 根据实际情况 */

/* Inside auto layout */
flex: none;
order: 0;
flex-grow: 0;

/* 内容：提醒文字 + 实际内容 */
/* 提醒文字 */
[[01_样式 token#02. 文字]] / 副标题

color: font-icon-3;

/* Inside auto layout */
flex: none;
order: 1;
flex-grow: 0;

/* 实际内容：根据具体情况定 */

/* 按钮组：按钮（右对齐） */
/* Auto layout */
display: flex;
flex-direction: row;
justify-content: flex-end;
align-items: flex-start;
padding: 0px;
gap: 16px;

width: 100%;
height: 38px;

/* Inside auto layout */
flex: none;
order: 2;
flex-grow: 0;

/* 按钮 */
[[01_按钮#07. 大标题按钮-小按钮]]

background: 品牌色-1 / C5 /* 主次按钮用不同的颜色 */
```
