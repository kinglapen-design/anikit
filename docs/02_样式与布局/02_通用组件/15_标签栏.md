# 15_标签栏（多标签页）

> 视觉以 figma-css `15_标签栏.md` / `39_右键菜单-标签页.md` 为准；本文只记 figma 没有的实现规则。2026-08-08 随 1.2 落地（dockview 方案）。

## 实现（dockview）

- 轮子：`dockview-vue` + `dockview-core`——拖拽重排 / 拆分停靠 / 序列化全由库承担；floating groups 与 popout 禁用（样式未适配、popout 在 Tauri webview 不可用）。
- 主题：`src/lib/dockTheme.ts`（theme 对象，继承 themeDark）+ `src/styles/dockview-theme.css`（`anikit-dock-theme` 覆盖层，figma 尺寸色值全在此）。
- 组件：`DockHost.vue`（宿主）/ `TabLabel.vue`（自定义 tab，标题按 viewKey 实时派生——文件夹重命名跟随）/ `TabAddButton.vue`（rightHeaderActions，每个分屏 group 各一枚）；panel 内容 = `ContentArea.vue`。
- 选中态冲突裁量：`01_主窗口.md` 注释"选中标签与中间面板同色 C1"为旧稿，以 `15_标签栏.md`（更新）为准——选中 = C4 底 + 亮-选中 1px 边框。

## 行为约定（PRD [[03_数据链接]] 05 全量）

- 标签页 = 一个文件视口（viewKey）；侧边栏导航对**未锁定**标签页替换视口、**已锁定**新开标签页（Eagle 式）。
- 锁定：无关闭钮（显示 `window-pin-on` 图标）、右键"关闭标签页"禁用；可拖拽 / 可分屏。
- 右键"新窗口打开"仅预览视图可用，文件视口恒禁用色（预览标签页化后续轮次）。
- 关完最后一个标签页自动补"全部"（本轮约定不留空，空状态形态待定）。
- 每个标签页独立滚动位置（会话级）；切换标签页清空选择。

## 持久化

- `onDidLayoutChange` 防抖 500ms → `ui.tabLayout`（settings.ui 子树）→ 启动 `fromJSON` 恢复；params 缺 viewKey 兜底回默认"全部"，文件夹已删的标签页显示空视口 + "文件夹"标题（失效清理待办）。

## 缺口 / 待办

- 标签栏空白区未设窗口拖拽（与 dockview tab 拖拽冲突），窗口拖拽区在 panel 内工具栏行——是否补 drag-region 待评估。
- 分屏后每个 group 独立标签栏（VSCode 式），设计稿只有单栏形态——多 group 视觉走查随 1.2 后续轮次。
