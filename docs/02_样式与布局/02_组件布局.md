## 04. 左侧边栏

因为左侧边栏文件树有 item 的展开 / 折叠图标，所以左侧边栏子项的左边距统一要留出更多空间，让子项之间的图标竖向对齐，而不是和展开箭头对齐。

左侧边栏布局：竖向

1. 标题栏

	- 结构：内容容器（内边距 8 8 8 12 / 子项间距自适应）→ 汉堡菜单（图标按钮-无底色装饰 / 大 = 28 x 28）+ （按钮组（子项间距 4）→ 添加-大（图标按钮-无底色装饰 / 大 = 28 x 28）+ 展开收起侧边栏-左（图标按钮-无底色装饰 / 大 = 28 x 28））

2. 切换资源库
	- [[01_样式 token#11. 切换素材库]] → 图标（资源库装饰）

3. 快速访问

	 - 结构：内容容器（内边距 8 0 8 0 / 子项间距 4 / 宽度自适应填充父级）→ 区块副标题（[[01_样式 token#5. 区块副标题]] / 不带按钮 / 内边距 0 8 0 12 / 文本：快速访问）+（item 组（内边距 0 8 0 4 / 子项间距 2）→ 全部（[[01_样式 token#4. 文件树 item]] / 不显示展开按钮 / 文字：全部 ）+ 未分类（同全部 / 文字：未分类）+ 最近使用（同全部 / 文字：最近使用）+ 回收站（同全部 / 文字：回收站））

4. 文件树

	- 结构：在同快速访问基础上微调
		- 内容容器（内边距 8 0 0 0 / 宽度和高度自适应填充父级）
		- 展开按钮（根据父级下有没有子项决定）
		- 区块副标题（有添加按钮 / 文字：文件夹(文件夹数量递归统计值)）

5. 视图切换

	- 结构：内容容器（内边距 4 8 8 8）→ (视图切换按钮（[[01_样式 token#13. 视图切换按钮]]）→ 资源库视图 + 工作空间视图 + 标签视图 + 快捷入口视图)

## 05. 中间内容展示区

中间内容展示区布局：竖向

1. 标题栏

	- 结构：内容容器（内边距 8 / 子项间距自适应）→ （面包屑导航（子项间距 6）→ （按钮容器（子项间距 4）→ 返回按钮（图标按钮-无底色装饰 / 大 = 28 x 28 / 图标：展开收起箭头-大 顺时针旋转 90 度）+ 前进按钮（同返回按钮 / 逆时针旋转 90 度））+ 滑块（[[01_样式 token#10. 滑块]] / 无百分比）+ 显示子文件夹内容（[[01_样式 token#9. 单选框]] / 文字：显示子文件夹内容）+ （按钮组（子项间距 4）→ 插件（图标按钮-无底色装饰 / 大 = 28 x 28）+ 查看方式（图标按钮-无底色装饰 / 大 = 28 x 28）））

2. 卡片列表

	- 结构：内容容器（宽度 x 高度 自适应填充父级 / 子项间距 16）→ （文件夹卡片容器（内边距 8 / 子项间距 4）→ 区块副标题（[[01_样式 token#5. 区块副标题]] / 不带按钮 / 文本：文件夹(当前目录子文件夹数量)）+（文件夹列表（子项间距 6）→ 文件夹卡片（[[01_样式 token#16. 文件夹卡片]]））+（素材卡片容器（内边距 8 8 0 8 / 子项间距 4）→ 区块副标题（[[01_样式 token#5. 区块副标题]] / 不带按钮 / 文本：内容(当前目录文件数量)）+ （素材列表（子项间距 6）→ 素材卡片[[01_样式 token#17. 素材卡片]]）））

3. 搜索框

	- 结构：内容容器（内边距 4 8 8 8）→ 搜索框（[[01_样式 token#12. 搜索框]]）

## 06. 右侧边栏

右侧边栏布局：竖向，最后一个区块高度可以自适应填充，或者增加占位符，反正保证视图切换保持在底部。

1. 标题栏

	- 结构：内容容器（内边距 8 / 子项间距自适应）→ （按钮组（子项间距 4）→ 展开收起侧边栏-右（图标按钮-无底色装饰 / 大 = 28 x 28）+ 窗口置顶（图标按钮-无底色装饰 / 大 = 28 x 28））+ （按钮组（子项间距 4）→ 窗口控制-最小化（图标按钮-无底色装饰 / 大 = 28 x 28）+ 窗口控制-最大化（图标按钮-无底色装饰 / 大 = 28 x 28）+ 窗口控制-关闭（图标按钮-无底色装饰 / 大 = 28 x 28））

2. 颜色信息

	- 结构：内容容器（内边距 8 / 子项间距 4）→ 区块副标题（[[01_样式 token#5. 区块副标题]] / 不带按钮 / 内边距 0 8 0 12 / 文本：颜色信息）+ 颜色信息容器（[[01_样式 token#8. 颜色信息]]）

3. 基础信息

	- 结构：内容容器（内边距 8 / 子项间距 4）→ 区块副标题（[[01_样式 token#5. 区块副标题]] / 不带按钮 / 内边距 0 8 0 12 / 文本：基础信息）+ （内容容器（子项间距 8）→ 标题（[[01_样式 token#6. 输入框]]）/ 无链接按钮 / 占位文字：输入标题）+ 注释（[[01_样式 token#6. 输入框]]）/ 无链接按钮 / 占位文字：输入注释）+ 链接（[[01_样式 token#6. 输入框]]）/ 有链接按钮 / 占位文字：http://）+ (详情（[[01_样式 token#14. 详情]]）→ （标题容器文字 / 评分 + 尺寸 + 文件大小 + 格式 + 添加日期 + 创建日期 + 修改日期）+ 详情（就第一行评分需要特别强调 [[01_样式 token#20. 评分]]））

4. 链接文件夹

	- 结构：内容容器（内边距 8 / 子项间距 4）→ 区块副标题（[[01_样式 token#5. 区块副标题]] / 带添加按钮 / 内边距 0 8 0 12 / 文本：链接文件夹）+（item列表（子项间距 8）→ [[01_样式 token#7. 详情面板 item]] / 链接文件夹 / 基础 item （图标 文件夹-关闭.svg / 文字 文件夹名称） / 副文本 文件名）

5. 标签

	- 结构：内容容器（内边距 8 / 子项间距 4）→ 区块副标题（[[01_样式 token#5. 区块副标题]] / 带添加按钮 / 内边距 0 8 0 12 / 文本：标签）+ （item 列表（流式布局 宽度不够换行）→ [[01_样式 token#7. 详情面板 item]] / 标签带删除按钮 / 基础 item （图标 标签.svg / 文字 标签名称））

6. 提示词

	- 结构（有提示词）：内容容器（内边距 8 / 子项间距 4 ）→ 区块副标题（[[01_样式 token#5. 区块副标题]] / 不带按钮 / 内边距 0 8 0 12 / 文本：提示词）+（内容容器（子项间距 8）→ [[01_样式 token#6. 输入框]] / AI 提示词输入框 + （按钮组（子项间距 4）→ 复制提示词（图标按钮-有底色装饰）+ 打开提示词编辑器（图标按钮-有底色装饰）+ 删除提示词（图标按钮-有底色装饰）））

	- 结构（无提示词）：内容容器（内边距 8 / 子项间距 4 ）→ 区块副标题（[[01_样式 token#5. 区块副标题]] / 不带按钮 / 内边距 0 8 0 12 / 文本：提示词）+ 分析提示词（图标+标题按钮）
