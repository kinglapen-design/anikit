## 01. 颜色

1. 品牌色
	- 品牌色-1：#1E83B5（拆分条高亮，重要按钮）
	- 品牌色-2：#2B9FD9（重要按钮悬停 / 点击）

2. 专项使用
	- 文件夹卡片颜色：#202124（文件夹卡片背面颜色）
	- 文件夹卡片颜色：#262629（文件夹卡片正面颜色）
	- 文件夹卡片颜色：#C6C7CC（文件夹卡片文件颜色）

3. 通用色
	- C1：#09090A（窗口底色） - 作为深色区域衍生基础
	- C2：#1B1C1F（中间面板）
	- C3：#1F2023（左右侧边栏）
	- C4：#F2F4FA（文字高亮） - 作为浅色区域衍生基础

4. 透明度衍生（通过设置不同的透明度来衍生其他颜色，方便后期换配色只用改通用色变量）
	- C1-80：80% 透明度（素材卡片格式提示底色）
	- C1-50：50% 透明度（搜索框、视图切换）
	- C1-15：15% 透明度（详情面板区块底色）
	- C1-7：7% 透明度（详情面板区块悬停）
	- C4-70：70% 透明度（非高亮状态下的文字，图标）
	- C4-40：40% 透明度（提示文字，标签文字，副标题文字，展开 / 折叠箭头）
	- C4-15：15% 透明度（边框线亮，选中，滚动条）
	- C4-7：7% 透明度（边框线暗，悬停，图标填充色）
