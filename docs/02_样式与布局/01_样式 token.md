## 01. 颜色

1. 品牌色
	- 品牌色-1：#1E83B5（拆分条高亮，主要图标）
	- 品牌色-2：#2B9FD9（主要图标悬停）

2. 专项使用
	- 文件夹卡片颜色：#202124（文件夹卡片背面颜色）
	- 文件夹卡片颜色：#262629（文件夹卡片正面颜色）
	- 文件夹卡片颜色：#C6C7CC（文件夹卡片文件颜色）

3. 通用色
	- 通用色-1：#09090A（窗口底色） - 作为深色区域衍生基础
	- 通用色-2：#1B1C1F（中间面板）
	- 通用色-3：#1F2023（左右侧边栏）
	- 通用色-4：#F2F4FA（文字高亮） - 作为浅色区域衍生基础

4. 透明度衍生（通过设置不同的透明度来衍生其他颜色，方便后期换配色只用改通用色硬编码）
	- 通用色-1：80% 透明度（素材卡片格式提示底色）
	- 通用色-1：50% 透明度（搜索框、视图切换）
	- 通用色-1：15% 透明度（详情面板区块底色）
	- 通用色-4：70% 透明度（非高亮状态下的文字，图标）
	- 通用色-4：40% 透明度（提示文字，标签文字，副标题文字）
	- 通用色-4：15% 透明度（边框线亮，选中，滚动条）
	- 通用色-4：7% 透明度（边框线暗，悬停，图标填充色）

## 02. 文字

- 大标题：尺寸 16px，行高 22px，Microsoft YaHei UI，加粗
- 正文：尺寸 14px，行高 20px，Microsoft YaHei UI，regular
- 副文本：尺寸 12px，行高 18px，Microsoft YaHei UI，regular

## 03. 线框

- 粗线条：2px（主窗口外边框，拆分线悬停态，素材卡片悬停选中）
- 细线条：1px（三栏外边框，分割线，按钮边框线，输入框边框线）

## 04. 间距

- 2px（item 间距）
- 4px（主窗口间距，三栏内边距，item 内边距，图标按钮组间距，区块标题与区块内容间距）
- 6px（图标按钮内边距，搜索框内边距，视图切换栏内边距，输出口上下边距）
- 8px（区块内边距，主窗口内边距）
- 12px（左侧边栏区块左边距）
- 16px（文件夹卡片列表与素材卡片列表间距）
- 18px（左侧边栏切换资源库左边距）

## 05. 圆角

- 4px（单选框，复选框）
- 6px（图标按钮，其他按钮，三栏，item）
- 8px（搜索框，视图切换栏，输入框）
- 12px（主窗口）

## 06. 图标

- 图标大小：16px
	> 图标整体大小是 16px，一些小号的图标，我会在 SVG 里缩放大小，四周留出更多的空白。
- 图标颜色（常态）：
	- 菜单图标：通用色-4：70% 透明度
	- 切换按钮：通用色-4：40% 透明度
	- 单选框 / 复选框
		- 线条：通用色-4：15% 透明度
		- 填充：无
	- item 装饰图标
		- 线条：通用色-4：40% 透明度
		- 填充：通用色-4：7% 透明度
