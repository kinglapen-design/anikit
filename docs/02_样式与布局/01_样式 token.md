> **所有 token 禁止硬编码，目前处于 MVP 测试阶段，包括品牌色都有可以随时调整。**

## 01. 颜色

1. 品牌色

``` text
品牌色-1：#0C8CE9（拆分条高亮，重要按钮）
品牌色-2：#096CB2（重要按钮悬停 / 点击）
```

2. 专项使用

``` text
文件夹卡片-图层1：#262629
文件夹卡片-图层2：#C6C7CC
文件夹卡片-图层4：#202124
```

3. 
``` text
错误色：#D04833（窗口控制关闭）
警告色：#BF9325
成功色：#29A13D
```

4. 通用色

``` text
C1：#09090A（窗口底色） - 作为深色区域衍生基础
C2：#1B1C1F（中间面板）
C3：#1F2023（左右侧边栏）
C4：#F2F4FA（文字高亮） - 作为浅色区域衍生基础
C5：#18191C（二级窗口 / 模态窗口）
```

4. 透明度衍生（通过设置不同的透明度来衍生其他颜色，方便后期换配色只用改通用色变量）

``` text
C1-80：80% 透明度（素材卡片格式提示底色）
C1-50：50% 透明度（搜索框 / 视图切换）
C1-15：15% 透明度（详情面板区块底色）
C1-7：7% 透明度（详情面板区块悬停）
C4-70：70% 透明度（非高亮状态下的文字 / 图标）
C4-40：40% 透明度（提示文字 / 标签文字 / 副标题文字 / 展开箭头）
C4-20：20%透明度（禁用）
C4-15：15% 透明度（边框线亮 / 悬停 / 选中 / 滚动条）
C4-7：7% 透明度（边框线暗 / 卡片边框 / 图标填充色）
```

## 03. 线框

1. 粗线条

``` text
2px（主窗口外边框 / 拆分线悬停态 / 素材卡片悬停选中
```

2. 细线条

``` text
1px（三栏外边框 / 分割线 / 按钮边框线 / 输入框边框线）
```

## 04. 间距

``` text
2px（item 间距）
4px（主窗口间距，三栏内边距，item 内边距，图标按钮组间距，区块标题与区块内容间距）
6px（图标按钮内边距，搜索框内边距，视图切换栏内边距，输出口上下边距）
8px（区块内边距，主窗口内边距）
10px（区块副标题左右边距）
14px（左侧边栏区块左边距）
16px（文件夹卡片列表与素材卡片列表间距 / 左侧边栏区块副标题左边距）
20px（左侧边栏切换资源库左边距）
```

## 05. 圆角

``` text
4px（单选框，复选框）
6px（图标按钮，其他按钮，三栏，item）
8px（搜索框，视图切换栏，输入框，主窗口）
12px（文件夹卡片图标容器）
```

## 06. 图标

所有图标均为 16 x 16，只有文件树 item 的展开小箭头和二级菜单提示右箭头用 8 x 8。
