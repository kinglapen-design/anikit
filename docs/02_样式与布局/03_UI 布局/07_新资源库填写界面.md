输入框默认聚焦状态。

填写名称后，点击选择保存路径后打开软件开始使用。

点击取消后，回到创建资源库界面。

这个窗口可以复用，后期在汉堡菜单里还可以创建资源库，切换资源库按钮也可以创建资源库。

**名称校验（2026-07-21 定，Eagle 式）：** 提交按钮不做禁用；名称不合规时点击，输入框描边变错误色（--error），输入框下方出一行提示（副文本 / --error），输入即恢复正常。规则同 Windows 文件夹命名：不能留空、不能含 `\ / : * ? " < > |`、不能以空格或点结尾、不能用系统保留名（CON / PRN / AUX / NUL / COM1-9 / LPT1-9）。前后端同规则把关。

**图标实现（2026-07-21 定）：** 标题图标用"切换资源库"同款 CSS 实现——24×24 容器 / padding 4 / 圆角 6 / 底 品牌色-1，内放 16×16 资源库-装饰（library-badge）；不单独导出 24×24（品牌色走 CSS，换配色不用重导）。

**布局修正（2026-07-21）：** 输入框与按钮组均为撑满父容器（align-self: stretch，实际 376px），下方 CSS 标注的 336px 以撑满为准。
**按钮修正（2026-07-22）：** 两按钮不再等分——宽度按标题自适应、高 38、padding 8px 16px（01_按钮#07 修订）；按钮组容器仍撑满、**右对齐**（08_二级窗口通用规则）。
**宽度修正（2026-07-22）：** 总容器 408 → **368**（08_二级窗口通用规则：小弹窗最大宽度 368）；输入框随容器撑满（实际 336px）。
