整体窗口大小和样式和 [[07_新资源库填写界面]] 一致

导入一般会弹出三个模态窗口：导入文件、导入文件夹、导入文件 / 文件夹/

导入文件：只有复制一份文件、剪切原始文件的单选向，删除关于层级的提示文字和单选项。

导入文件夹：有剔除原始层级、保留原始层级的单选项，复制一份文件、剪切原始文件的单选项。

导入文件 / 文件夹：当用户混合了文件和文件夹拖入时，和导入文件夹的模态窗口一致。

打开时都默认为：剔除原始层级，复制一份文件。
