打开资源库不是什么文件夹都能打开的，必须要加一个判定，是我们的资源库结构才行，这个功能主要是给老用户重装后再次选择已有资源库使用。

## 创建 / 打开流程（2026-07-21 用户确认）

- **创建：** 点"创建资源库"→ 系统文件夹对话框选择 / 新建空文件夹（文件夹名即素材库名）→ 插画与按钮组之间显示一行选中路径（正文 C4-70）→ 按钮组变换："创建资源库"变"**确认路径**"、"打开资源库"变"**重新选择**"（纯文字无图标，按钮宽 200）→ 确认路径建库；重新选择回到初始两按钮界面。
- **打开：** 点"打开资源库"→ 系统文件夹对话框 → 选中即校验资源库结构，通过直接打开；不通过在同一位置显示错误行（语义色 --error），按钮保持初始态。
- 无"稍后"按钮（以本设计稿两按钮为准，PRD 01 的"稍后"选项不落此版本）。
