打开资源库不是什么文件夹都能打开的，必须要加一个判定，是我们的资源库结构才行，这个功能主要是给老用户重装后再次选择已有资源库使用。

## 创建 / 打开流程（2026-07-21 更新，替代原"确认路径"方案）

- **创建：** 点"创建资源库"→ 进入 [[07_新资源库填写界面]]（输入名称 → 点"选择保存路径"弹系统对话框选保存位置 → 在选中位置创建以名称命名的库文件夹并打开）；取消回本界面。
- **打开：** 点"打开资源库"→ 系统文件夹对话框 → 选中即校验资源库结构，通过直接打开；失败进入 [[08_选择路径错误]]（重新选择路径 / 取消回本界面）。
- 无"稍后"按钮（以本设计稿两按钮为准，PRD 01 的"稍后"选项不落此版本）。
- 按钮规格以 [[01_按钮#06. 大标题按钮-大按钮]] 为准（带图标 250 / 不带 200，高 52）；二级与模态窗口统一带投影（0 4px 16px rgba(0,0,0,.4)，同主窗口）。
