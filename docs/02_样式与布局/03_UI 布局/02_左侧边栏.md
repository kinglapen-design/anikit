## 04. 树形容器

滚动条作用整个容器，将所有内容框在一个容器里，方便执行滑动动画。

切换素材库被资源库视图、标签视图、快捷入口视图共用，如果切换到工作空间，再单独跟随树形容器一起执行滑动动画。

区块副标题的展开按钮可以展开收起对应区块的内容。

文件树的展开后图标为：文件夹-打开；折叠时：文件夹-关闭

文件树展开时，需要有缩进线，缩进线的绘制规则如下：

``` text
缩进线颜色：与装饰图标的 fill 颜色一致（C4-7）；后期自定义文件夹颜色时，两者同步更改。

展开后，从子项的文件夹图标前开始绘制，具体位置就是展开按钮所占位的空间，展开按钮所占的空间为 9px 宽，中间位置为 x5，缩进线 1px 宽度，左右各留 4px。

如果碰到子项里面还有子项，导致子项有展开按钮：竖线照常穿过（父级层级的缩进线保持延展，子级的子级旁会并存两条缩进线），视觉上由展开箭头（容器铺侧栏底色）遮住穿过的竖线，不穿帮。

缩进线都为竖线（中间子项纯竖线、不画横线），最后一个子项画 L 形，按展开按钮所占的 9px 宽度计算，L 的底部横线大概从 x5 画到 x9。

最后一个重要的问题，保证层级间的缩进线间距一致，你可能需要计算以下子项的缩进像素多少刚好能满足。
```
