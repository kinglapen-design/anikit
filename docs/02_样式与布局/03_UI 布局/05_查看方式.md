> 2026-07-23 用户定：级联菜单改**二级窗口模式**（设置面板形态）。

点击中间面板标题栏"查看方式"按钮，弹出二级窗口（08 浮层壳：C3 / 圆角 8 / 1px border-1 / --shadow-pop，锚定按钮、点组外或 Esc 关闭，内边距 16，宽 264）。

## 结构

``` text
行 item ×5（C4 底 / 1px border-1 / 圆角 8 / 内边距 4 4 4 8，间距 8）：
  左 = 名称（正文 font-icon-1）
  右 = 下拉选择器（1px border-1 / 圆角 6 / 内边距 4 8 / 最小宽 96，
       当前值 font-icon-2 + 下拉箭头 font-icon-3，hover 底色 font-icon-6；
       点击在行下方弹出选项菜单（AppMenu 复用，与主窗口同组，点组外一起关闭））

  1. 查看范围：全局 / 当前目录（ui.useGlobalView）
  2. 布局方式：自适应 / 瀑布流 / 网格 / 列表（ui.layoutMode，立即生效）
  3. 排序方式：自定义 / 标题 / 扩展名 / 文件大小 / 尺寸 / 评分 / 时长 /
     添加日期 / 创建日期 / 修改日期 + 分割线 + 升序 / 降序（7.1 接功能，先存状态）
  4. 显示简介：尺寸 / 文件大小 / 创建日期 / 修改日期 / 标签 / 无显示（隐藏）
     （ui.briefMode；"尺寸"与"无显示"已生效——无显示时卡片标签行隐藏，其余随 7.x 接线）
  5. 分组方式：自定义（占位，7.1 接）

分割线（border-2）
  自动播放动图：开关（ui.autoPlayGif，5.3 接功能）
  自动播放视频：开关（ui.autoPlayVideo，5.3 接功能）

分割线
  显示扩展名角标：开关（ui.showExtBadge，立即生效——关闭后卡片不显示格式徽章）
  显示子文件夹内容：开关（ui.showSubfolders，与标题栏复选框同状态双绑定）
```

> 开关统一用 AppSwitch 组件（[[01_按钮#08. 开关按钮]]：50×28 胶囊 / 圆钮 20，未选中 font-icon-5 / 选中品牌色-1）。
