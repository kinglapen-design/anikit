整体样式和 [[07_右键菜单]] 一致。

一级子菜单：单选框 使用全局设置（样式和显示子文件夹内容一致，只是 padding 需要调整至 4 6 4 6）、布局方式、排序方式、分组依据。

使用全局设置：意思是将所有父级下的内容全部统一设置，关闭则是每个父级可以单独记录下来。

布局方式二级子菜单：自适应、瀑布流、网格、列表。

排序方式二级子菜单：标题、扩展名、文件大小、尺寸、评分、时长、添加日期、创建日期、修改日期、分割线、升序、降序。

一级子菜单用的是正常的图标 + 标题 + 提示箭头。

二级子菜单不需要图标：将样式里原本属于 16 x 16 的图标空间，换成 8 x 8 的对勾，对勾用 1px 像素的线条绘制一下，圆头，拐角处圆润。被选中的二级子菜单前面打上对勾，没被选中的隐藏对勾，但是对勾占位的空间还是要保留，不然子菜单之间的标题列对齐就会出现问题。

``` css
/* 总容器：单选框 + 分割线 + 一级子菜单 */
box-sizing: border-box;

/* Auto layout */
display: flex;
flex-direction: column;
align-items: flex-start;
padding: 4px;
gap: 2px;

position: absolute;
width: 175px;
height: 132px;

background: C5;

border: 1px solid C4-15;
border-radius: 8px;
box-shadow: 0px 4px 16px rgba(0, 0, 0, 0.4);
```
