## 01. 模式切换

双击素材卡片 / 卡片"查看大图"按钮，中间面板整栏切换为预览模式（2026-07-25 定案）：标题栏换预览工具栏、内容区换预览画面、**搜索栏隐藏**（序列帧时播放条占其位）。返回按钮退出预览回卡片列表。

## 02. 预览标题栏

布局模式同 [[03_中间面板#02. 标题栏]]（space-between 等距、内边距 12、图标按钮 80%）：

- 左组：返回（chevron-large 顺时针 90°）+ 索引 `x / y`（正文 font-icon-1）。
- 中组：缩放滑块（04_滑块，2%~800%）+ 百分比文字（说明文字 font-icon-3，最小宽 38 右对齐）。
- 右按钮组（间距 4）：插件、旋转、水平翻转、适合窗口、原图大小、默认应用打开（源文件 PSD·AI·SVG / 其他格式）、新窗口打开、上一个（chevron-large 顺时针 90° 朝左）、下一个（chevron-large 逆时针 90° 朝右）。
- 带图片源文件（PSD·AI·SVG）：去旋转 / 翻转；其他格式（fla / zip 等）：仅返回、索引、插件、默认应用打开、上 / 下一个。
- 动图 / 视频（5.2）：去默认应用打开（缩放组、旋转、翻转、适合窗口、原图大小保留）；音频：仅返回、索引、插件、新窗口打开、上 / 下一个（无缩放组、无旋转翻转、无默认应用打开）。
- 独立预览窗口（新窗口打开）：返回 + 索引替换为文件名标题，末尾加窗口置顶 + 完整窗口控制按钮；窗口无边框圆角阴影同主窗口。

## 03. 预览画面

- 图片以容器中心为锚缩放平移：滚轮缩放瞄点跟随鼠标位置；滑块缩放瞄点在视图中心；左键拖动平移；双击切换 适合窗口 ⇄ 原图大小。
- 旋转 90° 步进 / 水平翻转只作用于图片自身，缩放平移数学不受影响。
- 快捷键（2026-07-26 用户定）：← / → = 上 / 下一个素材（全类型统一）；逐帧步进 = `,` / `.`（YouTube / mpv / Premiere / Animate 同约定；序列帧 / 动图步一帧，视频暂停后 ±1/24 秒，步进即暂停）；空格 = 播放暂停；Esc = 退出全屏 / 退出预览。

## 04. 视图导航器（Eagle 式）

图片放大超出可视范围时右下角出现，还原后消失；拖视口框移动画面、点击小图跳转该点居中。

``` css
/* 总容器：右下各 16 / 内边距 4 / C3 底 / inset 1px border-1 / 圆角 8 / 浮层阴影 --shadow-pop */
position: absolute;
right: 16px;
bottom: 16px;
padding: 4px;
background: C3;
box-shadow: inset 0 0 0 1px border-1, --shadow-pop;
border-radius: 8px;

/* 小图盒：按图片视觉比例缩进 160×120 内，圆角 4；视口框 1px font-icon-1（inset） */
```

## 05. 播放条（序列帧；动图 5.2 完全复用）

占搜索栏位置（同容器内边距 4 12 12 12），样式照搜索框（C3 底 / inset 1px border-1 / 圆角 8 / 内边距 4 / 间距 6）：

- 播放/暂停（**进入自动播放**）、当前帧/总帧数（正文 font-icon-1）、进度条（3px 轨道 border-1 底 + 品牌紫填充 + 10px 拖钮，拖动定位帧）、倍率文字按钮（**悬停出竖排档位弹窗**，2026-07-26 改版：YouTube 同款，上 8x → 下 0.25x 共 11 档 8/4/3/2/1.75/1.5/1.25/1/0.75/0.5/0.25，当前档位左侧 ✓ 标记，点击设置并关闭；容器 C3 / inset 1px border-1 / 圆角 8 / --shadow-pop / 内边距 4，item 高 28 圆角 4 悬停 font-icon-6 底，底部 4px 桥接防 hover 断开——与音量弹层同款）、笔记（5.2 已实现，见 09 笔记浮层）、当前画面设为预览图、全屏（显示器全屏，Esc 退出）。播放条 / 帧条图标按钮同中栏 80% 档。
- 动图播放驱动（2026-07-26 修订，用户定案）：动图导入后后台**异步解包持久化到 `info/frames/`**（与序列帧同构同归一命名，推翻 2026-07-25"cache 会话级"定案——逐帧播放需要高清帧图配合，既然要解就持久化一次解码永久可用）；逐帧时长清单存 `info/frames.json`，播放引擎按 delayMs/倍率 推进。未解包完成时预览用原生 `<img>` 播放源文件兜底（webview 自动循环，零等待），播放条显示"解析中…"，解包完成事件到达后无缝切帧驱动。帧条小图仍维持 `cache/frames/` 会话级按需生成（见 06）。

## 06. 帧条（序列帧；动图 5.2 完全复用）

播放条下方（间距 4），样式同播放条容器（C3 / inset border-1 / 圆角 8 / 内边距 8 / 间距 8）：

- 上 / 下一帧按钮（chevron-small 旋转 ±90°）+ 逐帧预览块横排（高 56 宽按比例 / 圆角 8 / 1px border-2；当前帧 2px 品牌紫——卡片选中语言）。
- 帧列表横向按需滑动不出滚动条：切换帧时高亮块先移至可见区两端，顶头后帧列表才滑动（2026-07-25 定案）。
- 帧预览块：帧清单命令立即返回（不阻塞播放），帧条小图（`cache/frames/{ID}/{帧名}.webp` 短边 128，不进 info；会话级——打开库时清空）由预览解析队列后台逐帧生成、每 8 帧事件渐进填充，未就绪帧块显示 C4 方形占位（2026-07-25 定案）。
- 有笔记的帧块右上角加品牌紫小圆点（5.2，见 09）。

## 07. 播放条·音频（5.2）

容器样式同 05（占搜索栏位、照搜索框）；无帧条、无笔记、无全屏：

- 播放/暂停、音量（音量图标点击切静音，**悬停出竖向滑块弹层**——容器同倍率弹窗（C3 / inset border-1 / 圆角 8 / --shadow-pop / **内边距上下 8 左右 4**——细长 item 上下留白为左右两倍，拖钮不出容器 / 4px 桥接），竖向轨道高 96：3px 轨道 border-1 底 + 品牌紫填充自底向上 + 10px 拖钮（播放进度条自绘口径转 90°）；拖/点设音量 0-1，静音时滑块归 0 联动、拖离 0 自动解除静音）、当前时间/总时长（mm:ss 分钟补零，同卡片时长口径）、**波形进度条**（2026-07-26 改版：波形按轨道实际像素 × dpr 后端重采样渲染——任意宽度 1px 级清晰，未就绪 / 失败回退 info 波形缩略图拉伸；两层 div 以波形图作 CSS mask——底层 **wave-pending 实色** = 未播放（font-icon-3 60% 与 C3 混合的实际色号，新增 token，不受 mask alpha 影响）、上层 brand-1 紫 clip-path 裁到进度 = 已播放（Eagle 蓝/灰对比的紫/灰版，用户定），播放头 1px 品牌紫竖线；点击 / 拖动 seek）、倍率文字按钮（同 05 悬停竖排弹窗）、循环（激活态品牌紫）。
- 画面区显示波形大图（同按实际像素后端重采样，contain；未就绪回退 info 波形缩略图）。转码中播放条显示"转码中…"（说明文字 font-icon-3）。

## 08. 播放条·视频（5.2）

容器样式同 05；无帧条：

- 播放/暂停、快退/快进（∓5 秒）、上/下一帧（step-frame 图标左右翻转使用，步进即暂停——快捷键 `,` `.` 的实体入口，2026-07-26 用户定）、音量（同音频竖向滑块弹层）、当前帧/总帧数（5.3 帧化：帧数模式且 fps 可用，回退 当前时间/总时长；**时间文本悬停出帧数 / 时间码切换弹窗**——同 05 倍率弹窗规格复用：容器 C3 / inset 1px border-1 / 圆角 8 / --shadow-pop / 内边距 4、底部 4px 桥接、未选中 font-icon-3 选中 font-icon-1，选中即切查看方式"时间显示"同一设置，2026-07-28 用户定）、进度条（3px 轨道 border-1 底 + 品牌紫填充 + 10px 拖钮，同 05 序列帧进度条）、倍率（同 05 悬停竖排弹窗）、循环、笔记（见 09）、当前帧设为预览图（ffmpeg 截当前时间点帧重生成缩略图，卡片即时换图）、全屏（同 10）。
- 逐帧走快捷键：`,` / `.` 步进一帧（fps 可用按素材自身 1/fps，缺失回退 ±1/24 秒——5.3 帧化；步进即暂停；← / → 已统一为切换素材，2026-07-26 用户定）。画面为 video 元素，缩放 / 平移 / 旋转 / 翻转与图片同一套数学。不可直播格式（wma / mov / HEVC 等）后端自动转码（cache/tmp，幂等复用），期间播放条显示"转码中…"。

## 09. 笔记浮层（5.2，用户定案：浮层编辑器）

点播放条笔记按钮（激活态品牌紫）在播放条上方弹浮层（bottom:100% + 间距 4，C3 底 / inset 1px border-1 / 圆角 8 / --shadow-pop）：

- 头部："笔记" + 当前帧标识（序列帧 / 动图 = 帧号 x/y，视频 = 当前时间 mm:ss）+ 关闭。
- 当前帧 / 当前时间点 textarea（C4 底输入框样式），失焦或 Ctrl+Enter 保存；浮层打开即暂停播放（编辑目标帧稳定）。
- 下方全部笔记列表：帧号或时间 + 摘要单行省略 + 删除；点击跳帧（序列帧 / 动图定位帧，视频 seek 该时间）；当前项高亮。
- 数据：info 内 `notes.json`（单一写点 core::notes，不动 metadata），key = 帧名（序列帧 / 动图）或 `t:{秒}`（视频）；空文本保存 = 删除该条。音频无笔记。

## 10. 全屏

显示器全屏（2026-07-25 定案，2026-07-27 实测修订）：预览区 fixed 铺满窗口（z-index 1500，C1 底）+ 窗口 fullscreen；隐藏预览标题栏；**播放条 / 帧条脱离文档流浮在画面底部**（不占位——画面按整个窗口铺满，挡住就挡住，用户定）；**fitZoom 全屏去 48 留白**；**fitMode 跟随**——处于"适合窗口"状态时容器尺寸变化（进 / 出全屏、窗口拉伸）自动重新 fit，手动缩放 / 拖动 / 原图大小退出跟随。Esc 或全屏按钮退出。5.2 起同适用于动图与视频。
