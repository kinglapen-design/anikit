窗口尺寸，是我按照 150% 缩放显示设计的最佳状态，不要改变。

![[Pasted image 20260720015128.png]]

``` css
box-sizing: border-box;

/* Auto layout */
display: flex;
flex-direction: row;
align-items: flex-start;
padding: 0px;
gap: 0px;
isolation: isolate;

position: relative;
width: 1298px;
height: 1150px;

background: C1;
/* 浅色（边框线，选中） */
border: 1px solid C4-15;
box-shadow: 0px 4px 40px rgba(0, 0, 0, 0.4);
border-radius: 8px;
```

> 三栏面板无圆角无边框，仅左侧边栏 border-right、右侧边栏 border-left（1px C4-15）作视觉分割线。
> 投影工程实现为 `0 4px 16px rgba(0,0,0,.4)`：窗口为透明 + 20px 阴影带，blur 40 超出阴影带会被窗口物理边缘裁成硬边；resize 判定用 startResizeDragging 做在可视边缘内 8px。
