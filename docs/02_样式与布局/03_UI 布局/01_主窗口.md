窗口尺寸，是我按照 150% 缩放显示设计的最佳状态，不要改变。

![[Pasted image 20260720015128.png]]

``` css
box-sizing: border-box;

/* Auto layout */
display: flex;
flex-direction: row;
align-items: flex-start;
padding: 0px;
gap: 0px;
isolation: isolate;

position: relative;
width: 1298px;
height: 1150px;

background: C1;
/* 浅色（边框线，选中） */
border: 1px solid C4-15;
box-shadow: 0px 4px 40px rgba(0, 0, 0, 0.4);
border-radius: 8px;
```

> 三栏面板无圆角无边框，仅左侧边栏 border-right、右侧边栏 border-left（1px C4-7）作视觉分割线。
> **窗口装饰为系统原生方案（2026-07-20 定案）**：不透明窗口 + DWM 圆角（Win11 8px 与设计一致 / mac 系统圆角 / Win10 直角接受）+ DWM 阴影；1px 线框 Windows 用 DWMWA_BORDER_COLOR（≈ C4-15 合成色 RGB(44,45,47)），mac 无边框 API、暂无。阴影 / 圆角 / resize 判定均不再自绘（曾用透明窗口 + CSS 阴影，因硬边、resize 双判定、阴影带点击穿透弃用，见 04 日志）。
