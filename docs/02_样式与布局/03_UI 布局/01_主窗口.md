窗口尺寸，是我按照 150% 缩放显示设计的最佳状态，不要改变。

![[Pasted image 20260720015128.png]]

``` css
box-sizing: border-box;

/* Auto layout */
display: flex;
flex-direction: row;
align-items: flex-start;
padding: 0px;
gap: 0px;
isolation: isolate;

position: relative;
width: 1298px;
height: 1150px;

background: C1;
/* 主窗口不自绘边框——DWM 默认 1px，颜色经 DWMWA_BORDER_COLOR 染为 border-1 */
box-shadow: 0px 4px 40px rgba(0, 0, 0, 0.4);
border-radius: 8px;
```

> 三栏面板无圆角无边框，仅左侧边栏 border-right、右侧边栏 border-left（1px border-1）作视觉分割线。
> **窗口装饰（2026-07-23 更新）**：不透明窗口 + DWM 阴影 + **DWM 默认 1px 边框（颜色经 DWMWA_BORDER_COLOR 染为 border-1 #3A3940，Win11 22000+ 生效，Win10 忽略）**；圆角 8 自绘（与 Win11 DWM 圆角一致，最大化时去除）；resize 判定在可视边缘内 8px。主窗口不自绘外边框——实测自绘 2px 与 DWM 1px 重叠成 3px、四角圆角错开有空余，放弃；边框一律 1px 不设粗细层级（用户定），2px 仅保留卡片悬停 / 选中描边与拆分条高亮。曾用透明窗口 + CSS 阴影，因硬边、resize 双判定、阴影带点击穿透弃用（见 04 日志）。
