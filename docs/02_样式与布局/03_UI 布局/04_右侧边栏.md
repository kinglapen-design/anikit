## 03. 详情容器（2026-07-23 重组，替代原 Figma 导出稿）

> 侧栏外层无 padding——通栏分割线横贯侧栏，间距由各区块自身 padding 撑开。
> 区块统一规则：padding 12 16 12 16 / gap 8 / 分割线 inset box-shadow border-2（绘制在背景之上，hover 盖不住）（首个区块不画）。
> 区块副标题 padding 0；hover 整行抓手（cursor: grab，为拖拽排序准备），展开箭头 + 标题提亮 font-icon-1，无底色。
> 各区块模块独立、可增删；颜色信息区块永久置顶（pinned），不参与拖拽排序。

``` text
颜色信息（pinned：padding 8 16 12 16 / gap 16，无副标题）
├─ 预览容器（gap 8）：预览图（高 120 / 圆角 6 / 1px border-1 + 格式角标）+ 颜色 item（胶囊圆角 14 / C4 / 1px border-1）
└─ 输入框组容器（gap 8 / padding 0）：标题输入框 + 注释输入框 + 链接输入框（带打开按钮）

基础信息（通用区块规则）
└─ 详情容器：两列网格，标题左对齐 font-icon-2 / 值右对齐 font-icon-3，行距 2（评分行为 5 星 12×12，选中警告色）

关联文件夹（通用区块规则，副标题带添加按钮）
└─ 关联文件夹 item（02_item 06）

标签（通用区块规则，副标题带添加按钮）
└─ 标签 item（02_item 07）

提示词（通用区块规则）
└─ 输入框（03_输入框 04）+ 按钮组（图标按钮-有底色装饰 ×3）
```
