## 02. 标题栏

汉堡菜单的标题不需要给下拉事件，标题显示的是当前所在父级的文件夹名称，标题右侧的 `/ 搜索结果(数量)` 只有在搜索后从左侧滑入 `搜索结果容器`，可以通过返回按钮撤销搜索结果，取消搜索后，`/ 搜索结果(数量)` 往左滑出容器。

滑块拉到最右边是最大尺寸，最大尺寸的判定是第一行第一列的第一张卡片，刚好撑满整个容器。最小尺寸你看看设置为多少？最小尺寸应该和中间面板的最小宽度联动，当中间面板拉到最小宽度时，还能刚好容纳一列，这个宽度应该就是卡片的最小尺寸参考。

ctrl + 滚轮，可以缩放卡片，和滑块联动。**滑块 / ctrl + 滚轮同时缩放素材卡片行高与文件夹卡片列宽（同比例，文件夹卡片列宽 = 181 × 行高 / 220（2026-07-24 修订：gap 16 + 左右间距后 189 一排仅 3 列，181 一排正好 4 列，且为文件夹 SVG 原生宽度））**——文件夹卡片可被缩小，窗口拉伸后不会一直占满素材的预览空间。

## 03. 卡片列表

滚动条作用整个容器，区块副标题可以展开和折叠收起内容。

文件夹卡片也采用响应式布局，支持自适应缩放，拖动窗口，拆分条时，整体缩放，到达阈值时换行。

文件夹一行满了之后自动换行，不要横向滚动。**文件夹卡片用基础网格布局、固定 181 列宽（2026-07-24 修订，一排 4 列）**（用户 2026-07-20 定：固定大小，不需要瀑布 / 自适应 / 列表），右侧留空。

**滚动条（2026-07-24 修订）**：文件夹区块与"内容"副标题随素材网格共用一个滚动；自绘悬浮滚动条定位里层 viewport 右缘（可见条右缘距中栏外边框 4px），常态 font-icon-5 / hover border-1 / 可拖拽；网格右缘预留 20（命中区 12 + 间距 8），卡片左右缘距中栏外边框均 24。

> 工程实现备注（2026-07-20）：头部（文件夹区块 + 内容副标题）与素材卡片层分离——头部 grid 自然流即时精确、不参与 transform 缩放；卡片层 translateY（实时头部高度 + 6）+ 宽度差 scale 过渡，拉伸窗口时不会重叠 / 拉远。

> 工程实现备注（2026-07-25，4.4 inbox 新语义）：收件箱视口（快速访问 · 收件箱）头部挂"工程文件"磁盘实况区块（InboxDiskSection，无设计稿、按文件夹区块同口径从既有 token 组装——待用户过稿）：SectionHeader + 固定提醒副文本（font-icon-3 / caption）"工程文件不支持自动导入，请手动导入"；卡片 grid auto-fill minmax(120px,1fr)，图标容器**正方形**（2026-07-25 用户定）；目录用 folder-closed 图标（40，font-icon-3）、文件用系统格式图标缓存（无缓存回退扩展名角标文本，formatBadge 色映射实底；图标最大边 = 正方形图标位 50%，与素材卡片 / 列表行同口径），占用条目右上"被占用"小标签（--warning）；常态 1px border-2 / hover 2px border-1 / 选中 2px 品牌色（与素材、文件夹卡片一致）；右键 AppMenu：打开 / 重命名 / 删除 / 导入（占用禁用，MenuItem 新增 disabled 态 font-icon-3）——**菜单必须 Teleport 出 AssetGrid 变换层**（grid-canvas/cards-layer 带 transform，fixed 会被捕获为相对变换祖先定位，菜单随滚动偏移）；重命名为名称位行内输入（C4 / border-1 / 圆角 6），Enter 提交 Esc 取消。该视口"内容"副标题改题"已导入"。
