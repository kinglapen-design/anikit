导入进度条的出现位置在中间面板工具栏和卡片容器之间插入。

这一栏不用写具体的 css，可以直接拼接一个。

构造：进度条 + 标签文字 + 预计时间 + 关闭按钮。

容器 padding：8px 16px（左右 16 与中间面板标题栏 / 网格对齐，2026-07-27 用户定）。

底色：无。

边框：无。

子项间距：6px

容器高度：关闭按钮。

容器宽度（填充父级）：padding + gap + 标签文字宽度 + 关闭按钮宽度 + 进度条占用其余剩余空间。

进度条：高度 6px 胶囊形状，宽度填充，color border-1，已加载 color 品牌色-1。

标题文字：正在导入文件(已导入数量 / 总数量)。

> 如果总数量全量扫描一次开销太大，可以异步任务扫描，随着扫描慢慢增加。

关闭按钮：[[01_按钮#01. 图标按钮 - 无底色装饰]] / 大图标，和窗口控制的关闭按钮一致，只是 hover 颜色不再用错误色，而是用 font-icon-6.

> 关闭后等于取消，为了避免文件数据写入一半被取消，导致文件损坏，或者我们的软件无法识别，产生垃圾，取消后，虽然进度条关闭了，但是我们还是要监测，目前是否有传输到一半的文件，后台继续写入，等这个文件写入完成后在真实关闭。
