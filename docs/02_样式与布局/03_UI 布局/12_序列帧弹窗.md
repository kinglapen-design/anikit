## 序列帧资产的卡片 / 列表显示约定（2026-07-22 用户定）

- 格式角标（[[02_通用组件/06_卡片]]）与列表行"格式"列：显示 **序列帧**（非真实扩展名）。
- 名称：显示为 `标题.序列帧`——取 Placement 名称去原扩展名后加 `.序列帧` 后缀。
- 仅显示层转换：Placement 名称仍为 `标题.扩展名`，frames/ 内真实帧文件名不动；判定依据 = PlacementView.frameCount 非 null（07_接口文档）。
