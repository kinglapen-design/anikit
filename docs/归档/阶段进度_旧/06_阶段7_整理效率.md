# 阶段 7 · 整理效率

- **7.1 排序与分组（待开工）：**
	- PlacementView 补 size / modifiedAt，列表模式"文件大小 / 修改日期"接真实值（消化 2026-07-21 待办）。
	- 排列：标题/大小/格式/时长/修改时间/创建时间/导入时间 + 递增递减，默认自定义（order）；排序箭头交互；卡片布局与排列支持全局设置与当前目录设置（PRD 04-08）。（评分排列随评分移出 MVP，2026-07-28 定）
	- 分组显示：首字母/格式/大小/时间分组，内容区副标题分割；点击副标题弹下拉展示全部分组快速跳转、滚动条联动；高级分组（自定义规则，规则存 folders.json 文件夹节点，按文件夹各自生效）。（标签 / 评分分组随标签最小骨架与评分砍除同步移除，2026-07-28 定）
- **7.2 分词搜索与筛选（待开工）：**
	- 命令 API：`search`——关键字空格分词 AND 命中，范围：资源名/各 Placement 显示名/扩展名/标签/链接/标注名（注释/描述随功能后置就位后纳入，2026-07-28 定）；范围参数（当前目录 ↔ 全局），当前目录遵循"显示子文件夹内容"开关语义。
	- 前端搜索框："/" 弹搜索模式下拉（MVP 仅分词，向量/AI 占位项）、"//" 弹筛选下拉、Tab 与范围 chip 切换当前目录/全局、Ctrl+F 聚焦。
	- 筛选 tag 体系：颜色/格式/标签/比例/文件夹/添加日期/修改日期/文件大小等（评分筛选随评分移出 MVP，2026-07-28 定），各子菜单弹二级窗口选择（复用 08 组件壳）；tag 带删除角标，退格选中（高亮）再按删除，单击进入编辑；筛选 tag 与分词关键字可交叉组合。
	- 时长/标注/注释/链接/描述等"有无"类筛选，随对应数据在后续阶段就位后补齐。
- **7.3 详情面板（待开工）：**
	- 模块化封装：颜色/基础信息/标签/关联文件夹/AI 提示词各为独立模块，预留统一接口可增删（PRD 04-05）。
	- 附属文件模块（2026-07-22 用户定案）：打开详情时实时扫 `{ID}.info`，列出已知文件（原始文件 / metadata.json / 缩略图 / annotation.json / frames/）之外的文件（AN 的 RECOVER_*、Blender 的 .blend1 等恢复/备份文件），显示名称/大小/修改时间 + "打开所在文件夹"（explorer /select）定位；不建档、不入索引、不动不删——挪出建 ID 会被软件重新生成（Blender 无休止造 .blend1），AN 崩溃恢复也要求 RECOVER 在原位置。
	- 颜色信息：缩略图 + 颜色提取色块（最多 10 个，悬停显色号），单击弹 08 二级窗口显示 HSL/RGB/HSV + 一键复制 + 一键搜索相同颜色。
	- 基础信息：标题输入框（直接改名，走 6.1 重命名规则）、链接输入框、尺寸、大小、创建/修改/导入时间（注释出入口随功能后置、评分模块随评分移出 MVP，2026-07-28 定）。
	- 标签模块：添加/删除标签（依赖 tags.json）；关联文件夹：列出同资源全部 Placement 所在文件夹及各自显示名。
	- AI 提示词模块：占位空态（AI 功能后置）。
- **7.4 标签最小骨架（待开工；2026-07-28 用户定案：标签价值在跨维度归类——动作/技法等横跨项目文件夹的维度，Eagle 重型体系不适用，MVP 只做最小骨架；标签视图/群组/重命名联动/合并/自定义颜色列为后续版本，AI 搜索就位后再评估）：**
	- tags.json：标签定义，单一写点；资源侧 metadata 只存标签名列表。
	- MVP 范围：详情面板标签模块添加/删除（7.3）+ 批量标签（6.2）+ 分词搜索与筛选命中（7.2）。
	- 后续版本：标签视图（全部标签/未标签文件/未分类标签 + 群组树）、重命名联动、合并、自定义颜色（标签树图标/缩进线/详情面板三处同步，色值存 tags.json）。
