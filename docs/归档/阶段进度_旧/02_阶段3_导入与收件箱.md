- **任务 1 · 核心导入闭环（✅ 验收通过 2026-07-26）：**
	- 后端：导入管线 `services/import.rs`——扫描源（文件/文件夹递归）→ sha256 查重 → 复制/剪切进 `{ID}.info` → 写 metadata → 写 folders.json（剔除层级平铺进目标文件夹；保留层级按原结构建文件夹节点与 Placement，PRD 05-01 注）→ 更新内存索引；图片宽高提取入 `metadata.width/height`；缩略图 `services/thumbnail.rs`（图片格式 → webp，存 `{ID}.info`，登记 `metadata.thumbnail`）。
	- 命令 API：`import_paths`（混合列表 + 结构/来源选项）/ `import_clipboard`（剪贴板图片 → PNG，时间戳命名 剪贴板-yyyyMMdd-HHmm，重名追加 -序号）/ hash 冲突决策回传 / 内容浏览查询命令（全部 / 按文件夹）。
	- 前端：导入菜单（左侧边栏添加按钮弹出，样式同右键菜单，图标 import-file / import-folder 已入库）→ 系统对话框 → 导入弹窗（`03_UI 布局/09_导入弹窗.md` 三态：导入文件 / 导入文件夹 / 混合，默认剔除层级 + 复制）；webview 拖拽导入复用同一弹窗（拖至文件树文件夹上则导入至该文件夹）；hash 冲突询问弹窗（逐个询问 / 全部建立链接 / 全部跳过，**无设计参照，待用户补**）；内容区接真实数据替换假数据。
	- 依赖新增：`sha2`、`image`（四问记录与选型理由记 04_开发日志）。
- **任务 2 · 收件箱 Inbox（✅ 验收通过 2026-07-26，PRD 05-01）：**
	- subst 盘符挂载/卸载：启动时挂载、退出卸载，托盘提供开关（用户可手动卸，启动时重挂）。
	- notify 监听管线：ReadDirectoryChangesW 增量事件（非轮询）→ 写入完成检测（大小连续 N 秒稳定且可打开）→ 占用延迟重试 → 复用任务 1 导入管线。
	- 过境语义：导入后即移走、目录常态为空；重名与 hash 冲突走"导入即建档"既有规则（冲突挂起收集、完成后逐个弹"重复添加提示"）；**自动合并**：撞 hash 且已有资产同为 inbox 渠道（metadata.importedFrom）时静默改名为真实名 + 丢弃重复源，正式资产照常弹窗（2026-07-22 定案 A，解决 AN RECOVER 快照与真实文件 hash 相同）。
	- 图标决策（2026-07-22 用户定）：盘符图标暂用系统默认，待用户设计整套图标（盘符 / 资源库文件夹 / 工作空间文件夹 / 托盘 / 任务栏等）后统一替换。
