## 选择
- 单选
- 加选
- 范围选
- 框选
- ctrl + a 全选
- esc 反选，点击空白处反选。
> 文件夹卡片不参与全选。

## 移动方式
- 拖拽移动（拖拽移动、Ctrl+X+Ctrl+V）
- 拖拽排序
    - 文件树item：将 item 高度平分为三份，上下 1/3 的判定为排序，视觉效果显示插入线（品牌色-1），item 显示 hover 背景色，中间 1/3 的判定为并入，视觉效果：item 底色为 品牌色-1 12% 透明度（需要新建 token），边框 1px 品牌色-1。
    - 卡片：拖动到每个卡片的间距处排序，用底色为 品牌色-1 12% 透明度（需要新建 token），边框 1px 品牌色-1 显示提示，参考 assets\image\image.png。
> 文件夹卡片只能与文件夹卡片之间排序，素材卡片只能与素材卡片之间互相排序，不能混排。

## 关联方式
- ctrl + 拖拽 + （Ctrl+拖拽、Ctrl+C+Ctrl+V 建链接，可自定义显示名）
出现弹窗询问，参考样式草图：assets\image\f9292aec63ac69b082bc2391cd27d8da.png，整体和冲突窗口差不多，新文件名输入框默认填充源素材的文件名全选态，方便用户不想改名字，可以快速点击关联或者副本按钮，也可以快速删除自定义。

- （Ctrl+Shift+V 粘贴为副本，物理复制新 ID），不弹窗，用户选择了副本的专属粘贴，直接执行，名称和源名称保持一致。

## 重命名
- F2 重命名，右键菜单重命名。
- 重命名不采用模态窗口，而是直接将标题变成输入框，文件树 item 也是如此。assets\image\Pasted image 20260720012332.png 参考。

## 新建文件夹
- 文件夹的副标题处的添加按钮，默认是添加同级兄弟文件夹。
- 右键菜单里弹出的是新建同级文件夹，新建子文件夹，新建文件夹时也不用弹出模态框输入名称，直接新建并且名称输入框状态。右键菜单如果是对着item触发的，创建的新文件夹默认插入为目标item的兄弟文件夹放在item的下一行，如果是空白处则创建至最底部。
