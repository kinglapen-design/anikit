## 3. 文件

![[Pasted image 20260804034037.png]]

在 UI 界面，能显示的数据：

-  颜色：分析颜色。
- 名称
- 链接：浏览器扩展抓取图片时，自动填充网站信息，也可以用户手动填写，可以填写内部链接 .anikit // item // ID，来实现两个文件之间的跳转。
- 基础信息：尺寸 / 文件大小 / 格式 / 添加日期 / 创建日期 / 修改日期，其中尺寸只对可获取到尺寸的文件有效。
- 链接区块：显示当前文件同时存在在哪个区块的哪个文件夹里，显示名称是什么。最多显示三个路径：区块 / 根目录父级 / 所在目录。

![[Pasted image 20260804033412.png]]

- 归属档案：当前文件同时存在在哪些档案里，显示名称是什么。

![[Pasted image 20260804030858.png]]

- 提示词：当没有提示词是，可以点击 `分析提示词` 的按钮，也可以点击 `指定文本` 的按钮。指定文本是用户指定已导入的 MD 文本，然后显示在输入框里。分析提示词，我们不主动额外创建文档。提供三个按钮，一是创建为 MD 文本，将分析提示词的文本创建为 MD 文档作为新的文件导入至 UI，自动放到和源文件一个目录里；二是打开编辑器，输入框在详情栏太小了，不方便输入，我们后面内置 Markdown 编辑器，可以打开编辑，分析的提示词必须先保存为 MD 才能使用编辑器；三是复制按钮，一键复制提示词。

![[Pasted image 20260804032335.png]]

![[Pasted image 20260804032348.png]]

- 关系：可以选择一个文件或档案，来建立关系，比如雪牧添加关系，选择雪天，输入父亲，则二者建立的关系，且是双向显示，在雪牧里显示雪天是父亲，在雪天里，显示雪牧是儿女，如果要更准确，可以手动将儿女改成儿子。

![[Pasted image 20260804032736.png]]

> 关于建立关系的操作逻辑要如何做，右键文件或档案，在菜单里选择添加关系，然后弹出一个窗口显示所有文件吗？会不会很难找？还是有什么直观的其他方式？

- 音色：和关系一样，双向显示，文件用的音频是哪个，音频在哪些文件里使用过。

![[Pasted image 20260804034208.png]]

> 和关系一样，怎么去准确的从一个文件选择到另外一个文件，需要一个操作逻辑。

## 4. 档案

大部分都和文件的数据一致，这里只填写差异项。

 可手动直接编辑的基础信息：

![[Pasted image 20260804035043.png]]

- 头像：hover 到头像上时，显示相机图片，点击后进入头像编辑。可在取景框内用移动图片，调整位置，伴生缩略图也可以作为头像使用，PSD 等文件也可以作为头像文件。

![[Pasted image 20260804035609.png]]

> 还是怎么去准确的去选择另外一个文件的问题，需要一个操作逻辑。

- 徽标：在这里设置的徽标，会在档案卡片左上角显示，可以不设置徽标。
- 基础信息：用通用语义来显示，短文本加长文本，短文本为男 / 16岁之类的信息，短文本之间自动添加 |，长文本则是标题加内容的组合，长文本的文字超过多少行时，显示展开和收起按钮来显示和截断长文本，在编辑界面可以添加。

> 短文本的语义可以用属性，长文本用描述吗？还是其他更通用的语义。
