## 1. 区块

允许用户自定义新增删除区块，为区块命名，设置区块文件夹的默认图标。

![[Pasted image 20260803235620.png]]

点击菜单栏的区块管理图标，进入区块管理界面进行设置：

- 允许上下排序，且允许在侧边栏视图里进行拖拽排序。
- 允许自定区块名称。
- 允许自定义区块默认图标，影响新建文件夹时，item 的默认图标，后续用户可对单个文件夹进行图标更改。
- 默认区块为：目录，不允许删除，当用户停留在档案、全部、未分类等无法导入文件夹的视图时，选择了导入文件夹并且保留层级后，目录就是自动存放这个导入文件夹的地方。
- 删除区块时，如果区块内有文件夹和文件则弹出警告窗口，告诉用户文件去到未分类。

![[Pasted image 20260804041721.png]]

当用户导出资源库到本地时，他们会发现，不同的区块其实就是平行的兄弟文件夹：

## 2. 目录树

区块根目录下的父级文件夹用底色来区分，用户没有自定义设置颜色的情况下，默认使用灰色，如图里的文本 item。

当文件夹从其他层级拖至区块根目录下时，自动变为带灰色底色的默认 item。

当父级被设置颜色后，它的子项全部变为父级颜色的 10% 作为底色。

当设置父级的 item 图标时，允许勾选影响范围至全部子级，统一换图标。

## 4. 档案文件夹

对文件夹右键可以将文件夹转换为档案，也可以直接新建档案，档案享有和文件一样的数据配置，档案文件夹的徽标可以自定义设置，或者隐藏。

档案文件夹内不允许出现子级文件夹，如果右键转换时文件夹内有子级，则提醒用户剔除层级导入。

![[Pasted image 20260804010211.png]]

档案的 item 可以在目录树内出现，但没有展开箭头，下面没有子级，且图标强制切换为档案专属图标，和品牌紫色的圆圈装饰。

![[Pasted image 20260804010511.png]]

当用户在目录树拖拽文件夹时，档案不允许作为父级并入，仅支持排序。

单纯的文件，且多选时不包含文件夹，才允许作为父级拖入。

中间面板展示分为文件夹 / 档案 / 文件，三个区域。

![[Pasted image 20260804005106.png]]

将档案删除移动至回收站时，不可当常规文件夹处理，常规文件夹是剔除层级后出现在未分类和回收站里，但是档案文件夹要保持档案状态出现在回收站里，允许一键恢复。

若删除移动至回收站的文件夹内包含档案，则档案也要保持封装状态，总之可以把档案当单个文件来看待。

档案文件夹采用固定长宽比，缩略图默认索引子项第一张图片，来网格填充铺满，用户可在档案里设置头像，头像既档案的封面，二则同步。

> 注：序列帧其实在移动至回收站时也应该保持封装打包状态。

进入档案后，在中间面板和左侧边栏中间插入一个二级侧边栏，这里显示档案的数据；右侧则是正常的显示文件。

档案文件夹允许设置分组，如图中的文档分组，功能来源参考至 window 资源管理器里的分组功能，不过我们更高级，允许自定义，工具栏有分组图标，点击后进入分组设置。

新拖入的文件默认放入未分组，除非设置了自动分组，进来的文件才会自动判断进分组里，比如开启了文件扩展名分组，那么 fla 文件进来就默认进 FLA 分组里。

![[Pasted image 20260804011935.png]]

window 分组样式：

![[Pasted image 20260804012226.png]]

自定义分组：扩展名 / 类型 / 名称。

- 扩展名：检测档案内所有扩展名，供用户多选。
- 类型：将文件分为文本、图片、文档、视频，供用户多选。
- 名称：输入分词，分词逻辑是 and，自动将包含分词的文件归类到一个组里，当不同的组拥有相同的分词时，文件优先进入条件判定更多的组，比如雪牧_走路.fla，优先进入分词拥有雪牧 / 走路的组里，而不是进入分词只有雪牧的组里。
- 添加日期：按导入的时间进行分组，日期之间互斥。
- 修改日期：按修改的时间进行分组，日期之间互斥。

> 1. 当两个组用了一模一样的规则和范围时，弹出报错，禁止保存。
> 2. 当两个组都只有一个规则时，多个组之间的扩展名、类型、日期等要互斥，比如组一选了 fla，组二再选 fla 时，组一的 fla 就会自动取消选择，不然很难判定应该去哪个组。
> 3. 多规则组合式判断时，允许多个组之间的扩展名、类型、日期同时出现，比如组一是规则 fla，组二是规则 fla 加上名称雪牧，则包含雪牧的 fla 则去往组二。

当规则设置好之后，点击确认，软件自动将文件按规则分类至各个组里，没有被规则包含的，保留在未分组里。
