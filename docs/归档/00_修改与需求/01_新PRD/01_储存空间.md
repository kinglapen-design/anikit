## 1. 概述

AniKit 分为库式资产管理和索引式工作空间，这两个模式之间会涉及频发的互相导入，且在动画的制作和后期合成中，涉及很多的素材链接问题，路径的稳定性优先级很高，素材能不做实质的物理迁移就不要做，数据的变更才是核心管理模式，包括多素材库也要尽可能的遵守这种理念，将所有的素材都封存在 assets 里，多素材库用不同的 json 文件来记录和区分。

---

## 2. 数据结构

大概的结构就是将 assets 和不同的资源库还有工作空间都统一放在 AniKit 储存空间下，整体搬迁时，所有的相对路径都维持着 .Anikit // 的稳定状态。  

``` text
AniKit
	- assets
	- 资源库-1
	- 资源库-2
	- ...
	- workspace
```

### 3.2 资源库管理

后续可在切换资源库的二级菜单中，选择新建资源库和切换资源库。

![[Pasted image 20260804000833.png]]

储存空间可以创建多个，但不同储存空间内的资源不可互通和共享，完全独立，后期我们可以通过导出自己的素材包文件 .anikit 来导入合并其他人发来的资源。

每个储存空间内建立允许建立多个资源库，多个资源库允许合并成一个。

工作空间默认只有一个 workspace 的文件夹，里面用户可以根据自己的习惯和项目自己建立层级，可在设置里将工作空间作为符号链接至其他路径，供用户在资源管理器内操作。

### 3.3 扩展 / 插件

后续可在汉堡菜单里选择设置，在设置里安装新的浏览器插件。

动画软件桥接插件，后续可以汉堡菜单里选择设置，或者在工具栏的插件面板里安装和卸载。
