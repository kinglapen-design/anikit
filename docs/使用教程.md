# AniKit 使用教程

AniKit 是面向动画师的本地素材管理软件。它既能用封闭式素材库集中收管文件，也能用索引式工作空间查看和整理磁盘上的现有目录。

当前公开版本为 **0.1.0 早期版本**。主要链路已经可用，但界面细节、格式覆盖和长期稳定性仍在完善；重要项目请保留自己的备份。

## 1. 首次启动

Windows 免安装包解压后，运行目录中的 `anikit.exe`。请完整解压，不要只把程序单独拖出目录；缩略图、语义分析和插件依赖随包附带。

第一次启动会出现设置向导：

1. 选择或创建一个储存空间。储存空间是 AniKit 保存素材池、资源库、工作空间和缓存的根目录。
2. 创建或打开资源库。一个储存空间可以有多个资源库，库之间共享空间内的素材池。
3. 进入主窗口后，从左侧「资源库」浏览文件夹，从「工作空间」浏览磁盘目录。

关闭主窗口会按当前设置保留到系统托盘；从托盘图标可以重新打开或退出。菜单中的「退出」会直接结束应用。

## 2. 导入与整理素材

### 导入文件

在普通文件夹或「未分类」视口中，可以用以下方式导入：

- 菜单「文件」中的导入文件或导入文件夹；
- 把资源管理器中的文件拖进中间列表或左侧目标文件夹；
- 复制外部文件或图片后按 `Ctrl+V`。

导入时选择「复制」会保留源文件；选择「剪切」会在成功入库后移走源文件。剪切导入前应确认源位置没有未完成写入。快速访问中的「全部」「最近使用」「缩略图」等虚拟视图不是实际落点，因此不允许直接导入。

### 文件夹与档案

文件夹用于组织层级；档案用于把一组素材当作一个作品、角色或主题来管理。档案可以有封面、属性、描述和独立的内容视图。

常用整理动作都可以在右键菜单找到：重命名、移动、创建副本、属性、描述、链接和导出。多选时支持批量操作；`F2` 可重命名，多选时会进入批量重命名。

### 回收站

素材库的「丢到回收站」只改变数据层位置，原文件仍留在素材池中，之后可以还原。只有「彻底删除」或「清空回收站」才会永久移除文件，操作前请核对提示。

工作空间直接操作磁盘，删除走 Windows 系统回收站，与素材库回收站不是同一个位置。

## 3. 搜索、筛选与预览

按 `Ctrl+F` 聚焦搜索框。默认搜索当前视口范围；菜单中的「全局搜索」会预填全局范围标记。分词搜索会先返回名称、属性、描述等文本命中，语义结果随后追加。

搜索框旁的筛选按钮可以组合格式、属性、文件夹、比例、日期、颜色、时长、大小和链接状态。维度内部是多选，不同维度之间取交集。

双击素材默认进入应用内预览，可在「偏好设置 → 通用」改为用默认应用打开。常用按键包括：

- `Enter` 打开预览，`Shift+Enter` 用默认应用打开；
- `Ctrl+Enter` 在新标签页打开；
- 预览中用方向键切换素材，视频与动图可逐帧查看；
- 空格按当前设置进行悬停或选中项预览；
- `Esc` 退出当前浮层或预览。

Markdown 支持阅读、编辑和分屏预览，工具栏可切换大纲。工作空间中的文档预览目前为只读。

## 4. 语义分析与中文搜索

「偏好设置 → 语义分析」分为本地画面分析和外部详细分析两组。

本地分析不需要 API Key。选择素材后，在右键「AI 工具集 → 分析文件向量」启动任务；视频、动图、序列帧以及常见静态图片可以参与基础分析。完成后可尝试「走路的角色」「夜晚的城市」这类自然语言查询。静态图片只提供整图语义命中，不提供时间段、详细事件或片段截取。

CPU 是默认设备；DirectML 可选，但不可用时可能回退到 CPU。模型目录和实际运行后端可在设置页检测。首次分析或大批量分析会占用较多时间和计算资源，任务可以暂停、继续或重试。

外部详细分析是可选项。配置 OpenAI 兼容服务或 Ollama 后，服务会收到带时间戳的采样帧；返回的描述与事件仍由本地模型编码，之后可离线检索。API Key 只写入 Windows 钥匙串，不会回显或写入普通配置文件。

对带时间轴的语义命中，可以定位到对应片段，或创建虚拟片段、物理截取文件。虚拟片段引用原素材的时间范围；物理截取会生成独立文件。

## 5. 工作空间

工作空间适合不搬动原目录的整理方式。它显示储存空间内 `workspace` 目录的真实文件，并能通过链接目录接入外部文件夹。

在文件夹或空白处右键，可以添加链接文件夹、重新定位断链或删除链接。删除链接只删除入口，不删除目标文件夹内容。工作空间与资源库之间可以通过右键菜单或拖拽复制、导入。

安装并运行 Everything 后，工作空间搜索速度更快；未安装时仍可按 Enter 使用内置遍历搜索。工作空间的改动直接发生在磁盘上，与素材库的黑箱管理边界不同。

## 6. Animate 与编辑器联动

工具栏的插件入口包含 Animate CEP、MCP 连接器和编辑器贴图直链。打开对应详情窗可查看安装状态、使用步骤和路径。

Animate 插件支持把选中元件导出并收入 AniKit，也支持把库内工程发送回 Animate。导出时长、大小和帧率在「偏好设置 → 插件」中调整，并与 CEP 面板共享。

「编辑器贴图直链」用于 Typora 与 Obsidian：粘贴图片时先送入收件箱，再把可渲染、可跳回 AniKit 的链接写回文档。详细配置请直接使用插件详情窗中的复制按钮，不要在多个版本间手抄旧配置。

Markdown 文档中的 AniKit 图片引用可以通过「打包导出 MD」收集为本地图片并改写相对路径。工作空间文档的默认导出位置可在「偏好设置 → 通用」设置。

## 7. MCP 与命令行

MCP 让支持的 AI Agent 查询和操作 AniKit。插件面板中的「MCP 连接器」提供服务开关、接入配置、功能清单与命令行用法。

服务默认只读；「允许写入」需要单独开启。删除类工具只进入库内回收站，永久删除不经过 MCP。写入操作支持撤销的范围以界面和接口文档为准。

免安装目录中的 `anikit-cli.exe` 是命令行瘦客户端。先启动 AniKit 与 MCP 服务，再运行 `anikit-cli.exe --help` 查看命令；`status`、`search`、`path` 等子命令可查询当前库。

## 8. 设置、缓存与问题反馈

按 `Ctrl+,` 打开偏好设置。设置按通用、语义分析、自动导入、缓存、插件和快捷键分类，修改后即时生效。

缓存页显示各类派生文件占用。清理不会删除素材本体，但自定义缩略图在重建后会回退到自动派生图，无法从缓存恢复原图；执行「全部清理」前请阅读确认提示。

遇到异常时，先从「帮助 → 查看软件日志」打开日志目录。反馈问题时请附上版本号、Windows 版本、复现步骤和相关日志；不要上传 API Key、个人素材或其他敏感信息。意见反馈入口位于「帮助 → 意见反馈」。
