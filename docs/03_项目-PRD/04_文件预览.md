## 01. 主窗口视图

主窗口采用左中右三栏式设计：左侧边栏、内容展示区、右侧边栏

1. 左侧边栏可以切换四种视图：
	- 资源库视图：展示我们的资源库。快速访问固定四项：全部（根目录）、未分类、最近使用、回收站（见 [[06_数据]]）；下方为文件夹树。
	- 工作空间视图：展示索引的本地工作目录。快速访问：全部、置顶、常用；下方为真实文件夹树。
	- 标签视图：用来管理标签栏（全部标签 / 未标签文件 / 未分类标签 + 标签群组）——随标签管理功能列为后续版本，MVP 标签仅详情面板打词 + 搜索 / 筛选（2026-07-28 定）。
	- 快捷入口：文件夹，标签，文件都支持右键菜单固定到快捷入口，这里可以快速查看常用素材。
2. 右侧边栏可以切换四种视图：
	- 详情面板：展示素材的详细信息，如颜色、基础信息、标签、关联文件夹、AI提示词等。
	- AI 对话框：用来和 AI 聊天，下达任务等。
	- AI 绘画框。
	- AI 视频框。

- **快捷入口数据归属：** 存于独立的 pins.json，按 ID 引用文件夹 / 标签 / 文件，改名与移动不死链，支持拖拽排序。
- **最近使用等数据归属：** 最近使用存于库内 recent.json（ID + 访问时间，上限 500 条）；工作空间的置顶与常用存于 .anikit/workspace.json。
- **显示子文件夹内容：** 内容区顶部提供开关，开启后递归显示当前文件夹的全部子项（"全部"视图即此模式），是列表性能的重点场景。

## 03. 缩略图与全文件支持

封闭式管理下，所有导入的文件都必须显示在 UI 上，让用户清楚自己导入过什么文件，不存在"看不见的文件"。

1. **自有缩略图：** 图片、动图、视频、序列帧、字体等支持的格式，导入时生成缩略图存入 info 文件夹；音频生成**波形图**作为卡片预览（不使用系统通用图标），波形数据随 info 一并缓存（工作空间则缓存于 .anikit）。
	- **格式扩展纪律（2026-07-25 定）：** 内置解码走适配器注册表——新格式 = `services/thumb_formats/` 新增一个适配器文件 + 注册表一行，不改分发逻辑；远期目标对齐 Eagle 按需安装格式扩展：sidecar 外部解码器扩展包（exe + manifest 声明扩展名，子进程喂路径收像素，插件崩溃不拖垮主程序），ffmpeg sidecar（5.1）为第一个外部解码器，届时封装统一扩展接口。
	- 实现定案（2026-07-22，4.2）：PSD 走 psd crate 解内嵌合成图、SVG 走 resvg 渲染——**无 Adobe 依赖**，不走 shell；PSB 走自研轻量合成图解析（psd crate 不支持 PSB；Raw / RLE PackBits，8/16 位 RGB / 灰度 / CMYK 近似，像素上限 64M 防爆内存）；未存合成图（保存时关"最大兼容性"）回退格式图标。**AI 本轮先保底**（走系统格式图标，内容缩略图后置单独评估：pdfium sidecar / hayro）。
2. **系统缩略图：** 暂不支持的格式，调用系统接口获取缩略图——Windows 使用 Shell 接口（IShellItemImageFactory），macOS 使用 Quick Look（QLThumbnailGenerator）。
	- 实现定案（2026-07-22，4.2）：shell 只取**格式图标**（SIIGBF_ICONONLY），作非素材文件（zip 等）与无伴生图工程文件（fla / aep 等）的保底。
3. **系统缩略图缓存：** 系统缩略图按**格式**缓存而非按文件——如 01.zip、02.zip 共用同一份压缩软件图标，每个扩展名只缓存一份，用于加速卡片加载。
	- 实现定案（2026-07-22，4.2）：缓存于 `cache/thumbs/{ext}.webp`，**不进 info**——info 内放 shell 图会污染（后期补伴生缩略图后两份并存），且占空间。
4. **办公文档：** Word 等办公文档依赖外部组件渲染缩略图（Windows 可调用系统 Office COM 或 LibreOffice headless，macOS 走 Quick Look），软件不内置文档渲染器。

## 04. 文件预览

双击素材，中间内容展示区默认切换至预览模式，可查看图片，视频，字体，动图、序列帧、音频、文本等信息。

不同格式的素材，对应的工具栏不同。

1. 图片
	- 基础：原始尺寸，适应屏幕，旋转，翻转，上一文件，下一文件。
	- 高级：滑块放大缩小，滚轮放大缩小，左键拖动，标注，AI抠图、超清、扩图，裁剪等。
	- 实现定案（2026-07-25，4.3）：滚轮缩放瞄点跟随鼠标位置、滑块缩放瞄点在视图中心；放大超出可视范围时右下角出现视图导航器（Eagle 式：拖视口框移动画面、点击跳转，还原适应后自动消失）。
2. 字体
	- 基础：上一文件，下一文件。
	- 查看字体演示，详情，安装/卸载字体。
3. 动图
	- 基础：原始尺寸，适应屏幕，旋转，翻转，上一文件，下一文件。
	- 高级：滑块放大缩小，滚轮放大缩小，左键拖动，标注，逐帧查看，倍数查看，设置某一帧为预览图（重新生成缩略图并记录封面帧）。
	- 支持素材卡片阶段悬停播放，和自动播放，可在查看二级窗口里设置（后续会写UI布局）。
	- 播放条定案（2026-07-25，5.2 实现）：播放/暂停、当前帧/总帧数、进度条、倍率、笔记、当前帧设为预览图、显示器全屏；下方常驻帧条——上/下帧按钮 + 逐帧预览块（预生成全部帧小图缓存于 cache/，不进 info；会话级，打开库时清空，2026-07-25 用户定），切换帧时高亮块先移至可见区两端，顶头后帧列表按需滑动。
	- 播放帧持久化定案（2026-07-26 用户，推翻 2026-07-25"帧数据 cache 会话级"定案）：逐帧播放需要高清帧图配合，既然要解码就持久化——动图导入后后台异步解包到 `info/frames/`（与序列帧同构同归一命名 `{标题}-{序号}.webp`，动图 = 自动打包的序列帧），逐帧时长存 `info/frames.json`（单一写点，备份收录）；一次解码永久可用，重开库不重解。未解包完成时预览用原生 `<img>` 播源文件兜底，解包完成无缝切帧驱动。导入探测（GIF）走字节级扫描（只跳块数帧、累加 delay，不解码像素），导入零等待。
4. 序列帧
	- 基础：原始尺寸，适应屏幕，旋转，翻转，上一文件，下一文件。
	- 高级：滑块放大缩小，滚轮放大缩小，左键拖动，标注，逐帧查看，倍数查看，设置某一帧为预览图。
	- 播放条定案（2026-07-25）：完全复用动图播放条与帧条（数据源为 frames/ 目录帧图），4.3 随序列帧逐帧预览先行落地；**进入预览即自动播放**（2026-07-25 用户定）。
> 序列帧导入时，软件按常见命名格式检测（检测与入库归一规则见 [[01_资源与数据]] 数据格式第 5 条），打包成一个素材卡片展示（一个序列帧包 = 一个资源 = 一个 ID），自动播放，用户可以右键选择进入序列帧包里，查看单独的每一张。
5. 音频
	- 基础：播放 / 暂停，进度条，音量调整，上一文件，下一文件。
	- 高级：倍速播放，循环播放，波形图显示。
	- 支持素材卡片阶段悬停播放，移动鼠标快进快退。
	- 播放条定案（2026-07-25，5.2 实现）：播放/暂停、音量、当前时间/总时长、波形进度条（波形铺满整条，已播放部分高亮 + 播放头竖线）、倍率、循环；无笔记、无全屏。
6. 文本
	- 基础：上一文件，下一文件。
	- word 等文件渲染成缩略图显示（见 03 的办公文档说明），软件内部不内置编辑器，不然太重了。
	- txt 等支持简单的输入和保存，不需要斜体，粗体等高级功能，大概率就是写点提示词。
	- Markdown 支持查看与编辑：源码编辑（纯文本输入）+ markdown-it 渲染预览，不引入所见即所得编辑器，体积可控。
7. 视频
	- 基础：原始尺寸，适应屏幕，旋转，翻转，上一文件，下一文件，标注。
	- 高级：播放进度条，倍率播放，逐帧播放，音量调整，快进，快退，循环播放，选取当前帧为预览图。
	- 可支持在素材卡片阶段，悬停播放，移动鼠标可快进快退。
	- 播放条定案（2026-07-25，5.2 实现）：播放/暂停、快退/快进、音量、当前时间/总时长、进度条、倍率、循环、笔记、当前帧设为预览图、显示器全屏；逐帧走快捷键（或后续补图标）。
	- **帧显示优先定案（2026-07-28 用户）：** 动画师的思维单位是帧——视频播放条与卡片悬停胶囊以帧号显示（当前帧 / 总帧数，按素材自身帧率，metadata 需补 fps 探测），查看方式菜单提供"帧数 / 时间码"全局开关（默认帧数）；逐帧步进按 1/fps；视频笔记标识显示帧号（底层 key 仍为 `t:{秒}` 不变，防 fps 变动）。音频无帧概念，保持时间显示。**播放条时间文本悬停可就地切换帧数 / 时间码（2026-07-28 用户复验定）**——竖排弹窗样式与倍率弹窗同规格，与查看方式菜单"时间显示"同一设置双向联动。

- **卡片悬停行为分发定案（2026-07-27 用户定案，5.3 实现；参考 Eagle 截图三张；同日用户修订：悬停播放 = 完整视频，10 秒范围是自动播放用的；序列帧归动图范围）**——悬停按钮按需出，不再是全部"发送 + 放大镜"：
	1. 视频：无按钮，**悬停 = 完整播放整段**（循环），跟随鼠标横向移动快进快退（video seek，rAF 合帧 + 门控节流；预生成帧图方案 2026-07-28 用户决策废弃——CPU / 磁盘 / 载入成本不可接受）；右下胶囊 = 当前帧（可切时间码，见 7 视频帧显示优先定案）+ 音量钮（默认静音，点击切换）；底部 3px 进度条显示全片进度。
	2. 音频：无按钮，悬停即有声播放；卡片波形图上叠加已播放品牌紫高亮 + 1px 品牌紫播放头竖线，点击/拖动波形 seek；右下胶囊 = 当前时间 + 播放/暂停钮。
	3. 动图（GIF / WEBP 动图）与**序列帧**（归动图范围：打包就是为了看动画效果）：悬停即播放——动图 300ms 后 `<img>` 播源文件原生循环（零等待），序列帧按 fps（缺省 24）轮播 info/frames/ 帧图（从封面帧起播）；移出还原静态封面；**另有放大镜按钮——悬停到图标上出大图浮层，浮层内同样播放**（动图源文件原生循环，序列帧按 fps 轮播帧图，2026-07-28 用户定）。
	4. 静态图片：放大镜按钮——**悬停到图标上 150ms 出大图浮层**（2026-07-28 用户定：悬停触发不点击；浮层 pointer-events: none 鼠标穿透，移出图标 / 滚出 / Esc 即关）。
	5. 图片工程（PSD / PSB / SVG / AI 有内容缩略图时）：默认应用打开 + 放大镜（浮层先缩略图后换全尺寸解码图）。
	6. 动画工程（fla / aep）有内容缩略图时（8.2 伴生图后）：发送 + 默认应用打开 + 放大镜。
	7. 格式图标（shell 图标，无内容缩略图）：仅默认应用打开。
	- 悬停进入延迟 300ms（防划过触发加载/转码）；主窗口隐藏到托盘时暂停全部悬停播放；列表模式不做悬停播放。
	- **自动播放（查看方式菜单开关，"自动播放动图"含序列帧 / "自动播放视频"，默认关）**：开启后网格内全部该类卡片免悬停自动播放，方便快速定位素材。**视频自动播放范围 = 封面帧（thumbFrame `t:{秒}`，未设 = 0）起 10 秒**封顶时长循环（"设置当前画面为预览图"后自动播放范围自动跟随该帧，无需新设置 UI），无控件恒静音；悬停接管 = 同组件切完整播放出控件，移出切回范围循环并强制静音。动图 / 序列帧自动播放与悬停同行为。**性能口径（2.3，2026-08-12）**：① 开关驱动的自动播放受数量闸限制（同时播放 ≤16，满员排队 FIFO 唤醒；悬停播放直通不受限）——小卡片高密度时窗口内数百张卡片同时解码会致全局卡顿，上限与卡片密度解耦；② 动图卡片播放源 = info 内短边 320 小动画缓存（`{名}_anim.webp`，导入后异步生成，替代原尺寸 GIF 逐帧解码；缺失回退源文件并由后端懒生成）。
	- **悬停放大浮层**：**悬停到卡片放大镜图标上 150ms 出居中大图浮层**（max 80vw×80vh，图 3；2026-07-28 用户定：悬停图标触发不点击；浮层 pointer-events: none 鼠标穿透，移出图标 / 滚出 / Esc 即关），直渲格式显源图、PSD/PSB 先缩略图后换全尺寸解码图（复用预览解析队列）；**动图 / 序列帧浮层内播放**（动图源文件原生循环，序列帧按 fps 轮播帧图从封面帧起），其余静态展示。

- **播放条布局（2026-07-25 用户定案）：** 预览模式下搜索栏隐藏，播放条放在搜索栏位置，样式参考搜索框（C3 底色、1px border-1、圆角 8px）。
- **笔记（2026-07-25 用户定案）：** 视频 / 动图 / 序列帧支持逐帧文字笔记——与批注不同：批注是整体画面上框选标注（MVP 后置），笔记是逐帧文字记录。数据存 info 内独立 json（单一写点，不动 metadata 主体结构）。实现定案（2026-07-26，5.2）：文件定名 `notes.json`（`{ version, notes: [{ key, text, updatedAt }] }`，key = 帧名（序列帧 / 动图）或 `t:{秒}`（视频），空文本 = 删除；备份清单已收录）；UI 为播放条上方浮层编辑器（用户定案：当前帧输入框 + 全部笔记列表跳帧 + 帧条笔记圆点标记），样式见 02_样式与布局 13_预览窗口 09 节。音频无笔记。

## 05. 详情面板

展示图片的各类信息：颜色信息、基础信息、标签、关联文件夹、AI 提示词等。

1. 颜色信息：缩略图 + 颜色提取色块，最多支持显示十个颜色，悬停展示色号，单击二级菜单，显示更详细的 HSL，RGB，HSV等，一键复制信息，一键搜索相同颜色。
2. 基础信息：标题输入框（可直接修改文件名，遵循 [[02_文件整理]] 的重命名规则：改当前 Placement 显示名，原始文件才异步改 originName），注释出入口（功能 MVP 后置），链接输入框，其他基础信息，如尺寸，大小，创建时间等。（评分模块随评分移出 MVP，2026-07-28 定）
3. 标签：可添加删除标签。
4. 关联文件夹：展示当前素材同时存在在哪些文件夹里，显示名称是什么。
5. AI 提示词：展示 AI 提示词，没有时，可以点击按钮分析提示词。

- **模块化设计：** 详情面板按模块封装，颜色、基础信息、标签、关联文件夹、AI 提示词等各为独立模块，预留统一接口，后续可随时增删模块（如直方图一类需求）。

## 06. 排列

支持多种排列方式：标题、大小、格式、时长、修改时间、创建时间、导入时间，增还是递减等等常见的排列方式，默认采用自定义。（评分排列随评分移出 MVP，2026-07-28 定）

- **3.5 落地定案（2026-08-19）：** 排序方式 = 28 稿查看方式菜单行点亮（下拉 + 升/降切换按钮组），**全局统一**（应用级 settings.ui，一处设置全库生效）；**键 8 项**：自定义 / 名称 / 文件大小 / 时长 / 扩展名 / 创建时间 / 修改时间 / 导入时间。
	- **自定义 = 存储序**（Placement.order），自定义时升降切换禁用（无升降语义）；**名称 = 自然排序**——阿拉伯数字串按数值（文件2 < 文件10）、中文数字按数值（一~万常见写法：十一/一百零五）、天干（甲乙丙…）按序列（2026-08-19 用户补充：中文序列不处理会按字符码乱序）；空值（无时长 / 存量无创建时间）**恒排尾**不随升降反转；平局恒按名称自然排序 + assetId 兜底（不反转）。
	- **显示层排序，不动存储序**；作用范围 = **素材区全视图生效**（含快速访问；文件夹 / 档案卡片不参与，恒存储序）。
	- **物化（02 整理 02 节口径素材侧落地）：** 显示排序下素材拖拽排序 = 该层可见序（含新增区）物化为存储序、拖拽组按落点并入整层重写（reorder_placements 全层序列 + 段尾锚点），并自动切回自定义——否则 refresh 后排序键盖回，拖拽等于没执行。
	- **新增区（2026-08-19 用户定）：** 排序状态下新增 / 导入 / 粘贴 / 副本的项**不按排序键分散，集中置顶**（区内先来在前）——用户要能找到新建文件、确认导入数量是否完全；**切视图再回来即归位**（并入排序流），切库 / 物化同清。
	- **时间键语义：** 创建时间 = 源文件磁盘创建时间（导入时记 metadata.created_at；剪贴板 / 新建文档 = 建档时刻；副本 / 克隆继承源资产；存量数据无值排尾）；修改时间 = 库内数据最后变更时刻（现有 modified_at，非源文件 mtime）；导入时间 = imported_at。
	- 索引式工作空间无 Placement 数据，不支持自定义排列，自动回落到名称 / 时间排列。

## 07. 分组显示

跟 window 的分组依据类似，可通过首字母分组，格式分组，递增还是递减等，还支持高级分组，分组后的文件，在内容展示区创建一个副标题分割素材。

高级分组：用户可创建分组，用户可以自定义规则，如名称里包含什么，格式是什么等等，无需纳入分词搜索范围，仅用于单文件夹文件太多，扁平化管理时用的归类方式，点击副标题，可弹出下拉框，展示所有分组，快速跳转，滚动条联动。

- **数据归属：** 分组规则存于 folders.json 的文件夹节点上，按文件夹各自生效。
- **3.5 二轮落地口径（2026-08-19，以 [[02_文件整理]] 04 节为准）：** 规则清单 = 扩展名 / 类型（8 类）/ 名称 / 导入日期 / 修改日期（**首字母分组不做**——本节旧表述废除）；副标题 = SectionHeader group 变体（30 高 / 标题档 + 数量 + 折叠箭头 + group-menu 钮）；**点 group-menu 钮出 12 稿菜单**（跳转▸ = 全组列表滚动跳转，与滚动条联动）；分组标题 **sticky 置顶**（transform 虚拟滚动体系内为悬浮层实现）。
