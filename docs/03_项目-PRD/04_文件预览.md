## 01. 主窗口视图

主窗口采用左中右三栏式设计：左侧边栏、内容展示区、右侧边栏

1. 左侧边栏可以切换四种视图：
	- 资源库视图：展示我们的资源库。快速访问固定四项：全部（根目录）、未分类、最近使用、回收站（见 [[06_数据]]）；下方为文件夹树。
	- 工作空间视图：展示索引的本地工作目录。快速访问：全部、置顶、常用；下方为真实文件夹树。
	- 标签视图：用来管理标签栏。快速访问：全部标签、未标签文件、未分类标签；下方为标签群组。
	- 快捷入口：文件夹，标签，文件都支持右键菜单固定到快捷入口，这里可以快速查看常用素材。
2. 右侧边栏可以切换四种视图：
	- 详情面板：展示素材的详细信息，如颜色、基础信息、标签、关联文件夹、AI提示词等。
	- AI 对话框：用来和 AI 聊天，下达任务等。
	- AI 绘画框。
	- AI 视频框。

- **快捷入口数据归属：** 存于独立的 pins.json，按 ID 引用文件夹 / 标签 / 文件，改名与移动不死链，支持拖拽排序。
- **最近使用等数据归属：** 最近使用存于库内 recent.json（ID + 访问时间，上限 500 条）；工作空间的置顶与常用存于 .anikit/workspace.json。
- **显示子文件夹内容：** 内容区顶部提供开关，开启后递归显示当前文件夹的全部子项（"全部"视图即此模式），是列表性能的重点场景。

## 02. 卡片布局

整体采用响应式布局，显示方式分为四种：

- 自适应：等高不等宽（默认）。
- 瀑布式：等宽不等高。
- 网格式：固定正方形。
- 列表式

## 03. 缩略图与全文件支持

封闭式管理下，所有导入的文件都必须显示在 UI 上，让用户清楚自己导入过什么文件，不存在"看不见的文件"。

1. **自有缩略图：** 图片、动图、视频、序列帧、字体等支持的格式，导入时生成缩略图存入 info 文件夹；音频生成**波形图**作为卡片预览（不使用系统通用图标），波形数据随 info 一并缓存（工作空间则缓存于 .anikit）。
	- 实现定案（2026-07-22，4.2）：PSD 走 psd crate 解内嵌合成图、SVG 走 resvg 渲染——**无 Adobe 依赖**，不走 shell；PSD 未存合成图（保存时关"最大兼容性"）回退格式图标。**AI 本轮先保底**（走系统格式图标，内容缩略图后置单独评估：pdfium sidecar / hayro）。
2. **系统缩略图：** 暂不支持的格式，调用系统接口获取缩略图——Windows 使用 Shell 接口（IShellItemImageFactory），macOS 使用 Quick Look（QLThumbnailGenerator）。
	- 实现定案（2026-07-22，4.2）：shell 只取**格式图标**（SIIGBF_ICONONLY），作非素材文件（zip 等）与无伴生图工程文件（fla / aep 等）的保底。
3. **系统缩略图缓存：** 系统缩略图按**格式**缓存而非按文件——如 01.zip、02.zip 共用同一份压缩软件图标，每个扩展名只缓存一份，用于加速卡片加载。
	- 实现定案（2026-07-22，4.2）：缓存于 `cache/thumbs/{ext}.webp`，**不进 info**——info 内放 shell 图会污染（后期补伴生缩略图后两份并存），且占空间。
4. **办公文档：** Word 等办公文档依赖外部组件渲染缩略图（Windows 可调用系统 Office COM 或 LibreOffice headless，macOS 走 Quick Look），软件不内置文档渲染器。

## 04. 文件预览

双击素材，中间内容展示区默认切换至预览模式，可查看图片，视频，字体，动图、序列帧、音频、文本等信息。

不同格式的素材，对应的工具栏不同。

1. 图片
	- 基础：原始尺寸，适应屏幕，旋转，翻转，上一文件，下一文件。
	- 高级：滑块放大缩小，滚轮放大缩小，左键拖动，标注，AI抠图、超清、扩图，裁剪等。
2. 字体
	- 基础：上一文件，下一文件。
	- 查看字体演示，详情，安装/卸载字体。
3. 动图
	- 基础：原始尺寸，适应屏幕，旋转，翻转，上一文件，下一文件。
	- 高级：滑块放大缩小，滚轮放大缩小，左键拖动，标注，逐帧查看，倍数查看，设置某一帧为预览图（重新生成缩略图并记录封面帧）。
	- 支持素材卡片阶段悬停播放，和自动播放，可在查看二级窗口里设置（后续会写UI布局）。
4. 序列帧
	- 基础：原始尺寸，适应屏幕，旋转，翻转，上一文件，下一文件。
	- 高级：滑块放大缩小，滚轮放大缩小，左键拖动，标注，逐帧查看，倍数查看，设置某一帧为预览图。
> 序列帧导入时，软件按常见命名格式检测（检测与入库归一规则见 [[01_资源与数据]] 数据格式第 5 条），打包成一个素材卡片展示（一个序列帧包 = 一个资源 = 一个 ID），自动播放，用户可以右键选择进入序列帧包里，查看单独的每一张。
5. 音频
	- 基础：播放 / 暂停，进度条，音量调整，上一文件，下一文件。
	- 高级：倍速播放，循环播放，波形图显示。
	- 支持素材卡片阶段悬停播放，移动鼠标快进快退。
6. 文本
	- 基础：上一文件，下一文件。
	- word 等文件渲染成缩略图显示（见 03 的办公文档说明），软件内部不内置编辑器，不然太重了。
	- txt 等支持简单的输入和保存，不需要斜体，粗体等高级功能，大概率就是写点提示词。
	- Markdown 支持查看与编辑：源码编辑（纯文本输入）+ markdown-it 渲染预览，不引入所见即所得编辑器，体积可控。
7. 视频
	- 基础：原始尺寸，适应屏幕，旋转，翻转，上一文件，下一文件，标注。
	- 高级：播放进度条，倍率播放，逐帧播放，音量调整，快进，快退，循环播放，选取当前帧为预览图。
	- 可支持在素材卡片阶段，悬停播放，移动鼠标可快进快退。

## 05. 详情面板

展示图片的各类信息：颜色信息、基础信息、标签、关联文件夹、AI 提示词等。

1. 颜色信息：缩略图 + 颜色提取色块，最多支持显示十个颜色，悬停展示色号，单击二级菜单，显示更详细的 HSL，RGB，HSV等，一键复制信息，一键搜索相同颜色。
2. 基础信息：标题输入框（可直接修改文件名，遵循 [[02_文件整理]] 的重命名规则：改当前 Placement 显示名，原始文件才异步改 originName），注释出入口，链接输入框，其他基础信息，如评分，尺寸，大小，创建时间等。
3. 标签：可添加删除标签。
4. 关联文件夹：展示当前素材同时存在在哪些文件夹里，显示名称是什么。
5. AI 提示词：展示 AI 提示词，没有时，可以点击按钮分析提示词。

- **模块化设计：** 详情面板按模块封装，颜色、基础信息、标签、关联文件夹、AI 提示词等各为独立模块，预留统一接口，后续可随时增删模块（如直方图一类需求）。

## 06. 排列

支持多种排列方式：标题、大小、格式、时长、评分、修改时间、创建时间、导入时间，增还是递减等等常见的排列方式，默认采用自定义。

- 索引式工作空间无 Placement 数据，不支持自定义排列，自动回落到名称 / 时间排列。

## 07. 分组显示

跟 window 的分组依据类似，可通过首字母分组，格式分组，递增还是递减等，还支持高级分组，分组后的文件，在内容展示区创建一个副标题分割素材。

高级分组：用户可创建分组，用户可以自定义规则，如名称里包含什么，格式是什么等等，无需纳入分词搜索范围，仅用于单文件夹文件太多，扁平化管理时用的归类方式，点击副标题，可弹出下拉框，展示所有分组，快速跳转，滚动条联动。

- **数据归属：** 分组规则存于 folders.json 的文件夹节点上，按文件夹各自生效。

## 08. 全局与布局

卡片布局与排列支持全部设置，和当前目录设置。
