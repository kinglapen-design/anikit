## 01. 文件树整理

通过修改数据文件实现文件的层级和信息管理等，而非频繁的真实移动文件。

- **自定义排序：** 支持拖拽排序文件夹与文件，顺序写入 folders.json 的 order 字段，仅改数据不动磁盘，保证响应流畅。
- **自定义图标颜色：** 文件夹可自定义图标颜色用于分类识别，一处改色多处生效——文件树的图标、缩进线、右侧详情面板的关联文件夹列表；颜色值存于 folders.json 对应节点。标签自定义颜色随标签管理功能后置（见 02）。
- **封闭式专属：** 文件树整理、标签、标注、多文件夹关联均为封闭式资源库专属功能（注释 / 描述降级后置见 03，评分移出 MVP 见 05）；索引式工作空间仅按真实磁盘结构显示，不支持自定义排序，磁盘与 UI 双向热刷新。

## 02. 标签管理

> 2026-07-28 用户定案：标签对动画师的价值是**跨维度归类**（动作 / 技法等横跨项目文件夹的维度，命名与文件夹都只占一个维度），但 Eagle 式重型体系不适用——MVP 收缩为最小骨架；标签视图、群组、合并、自定义颜色等管理功能列为后续版本（AI 搜索就位后再评估）。

- **最小骨架（MVP）：** 扁平标签，仅添加 / 删除（详情面板逐个 + 多选批量）；分词搜索与筛选命中标签。
- **数据归属：** 标签定义存于独立的 tags.json（单一写点）；资源侧 metadata.json 只存标签名列表。
- **后续版本：** 标签视图（全部标签 / 未标签文件 / 未分类标签 + 群组树，群组仅归类展示不影响搜索筛选）、重命名（所有资源联动更新）、合并、自定义颜色（标签树图标 / 缩进线 / 详情面板三处同步，色值存 tags.json）。

## 03. 注释与描述

> 2026-07-28 用户定案：文件级注释 / 描述对命名规范的动画师素材价值低，降级为 MVP 后置；逐帧文字笔记（notes.json，见 [[04_文件预览]]）已覆盖动画场景的主要记录需求。

用户可对文件夹添加描述，可对文件进行注释。

- **数据归属：** 文件夹描述存 folders.json 的 note 字段，文件注释存 metadata.json 的 note 字段；功能就位后纳入分词搜索范围。
- **版本规划：** MVP 后置。

## 04. 标注

这是一个对于动画师来说比较重要的功能，让用户可以在图片、动图、视频上创建多个画框来进行标注。

示例1：用户在一张打篮球的图片上，创建画框框选住篮球，然后为画框取名为篮球。
示例2：用户在动图或者视频上创建画框，逐帧绘制视频内运动对象的轨迹和压缩与拉伸的状态，来观察动画，方便动画师参考和创作，允许用户额外保存一份记录了标注的副本，导入至动画软件进行绘制参考。

- **数据归属：** 标注存于资源 info 文件夹内独立的 annotation.json，每条标注 = 帧号/时间戳 + 画框坐标 + 名称，随资源一并删除与备份。
- **搜索：** 标注名称纳入分词搜索范围，搜"篮球"可命中对应图片。
- **版本规划：** 静态图片的单帧标注进入 MVP；动图、视频的逐帧标注（轨迹、压缩与拉伸的关键帧绘制）列为后续版本。

## 05. 评分

> 2026-07-28 用户定案：评分服务于"从大量相似素材中筛精品"（摄影选片 / 设计师筛图），动画师素材目的性强、命名规范，用不上 0-5 星粒度——整串移出 MVP（排序 / 筛选 / 分组 / 详情模块同步移除）；metadata.rating 字段保留不做 UI，避免迁移，后续版本再评估。

一个简单的评分系统，让用户在 0 - 5 颗星内进行选择。（后续版本再评估）

## 06. 链接

可为素材添加链接，点击链接可打开浏览器跳转，允许添加 ID 路径：`anikit://item/{ID}`，来进行点击后软件内跳转。

ID 寻址还允许添加给外部软件使用，如给 Obsidian 等软件作为图片附件，点击后打开 AniKit 跳转至图片界面。

- **数据归属：** 链接列表存于 metadata.json 的 links 数组，纳入分词搜索范围。
- **技术前提：** `anikit://` 需在安装时向系统注册协议处理（Windows 注册表 / macOS Info.plist）；软件未启动时点击协议链接，先启动再跳转至对应资源。

## 07. 多文件夹关联

允许同一文件以不同名称出现在多个文件夹，提供两种选项：

- **链接：** 同一资源 ID 出现在多个文件夹，各文件夹内可自定义显示名称，零磁盘开销，改标签、重新生成缩略图等操作处处生效。
- **副本：** 物理复制为全新资源（新 ID），从此完全独立，互不影响。
- **导入查重：** 导入与已有资源 hash 相同的文件时，弹窗询问"建立链接 / 仍导入副本"。

数据规则（改名作用域、删除语义、反查关联、链接寻址、搜索命中）详见 [[01_资源与数据]]。

## 08. AI 智能分类

允许用户配置规则或者直接与大模型对话，让大模型进行资产分类，这项功能的前提是，将 AniKit 的功能，包括基础操作都抽象成接口，让 AI 能从底层操控软件。还需要向量库的帮助，让 AI 可以搭配向量数据，进行文件分类，减少 token 消耗。

## 09. 选择

> 交互细节 2026-07-28 用户逐条确认（依据 `docs/00_修改与需求/04_选择态需求.md`）。

- **单选：** 鼠标单击。
- **加选：** Ctrl + 单击逐个追加。
- **范围选：** Shift + 单击，选中两次点击之间的连续范围。
- **框选：** 在内容区空白处按住左键拖拽框选，仅选中素材卡片。
- **全选：** Ctrl + A，仅选中素材卡片——**文件夹卡片不参与全选与框选**。
- **清空选择：** Esc 或点击空白处。
- 多选状态下，基础操作自动转为批量编辑（见 11）。

## 10. 基础操作

#### 封闭式资源库（仅改数据，不动磁盘）

- **撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z）：** 一切写操作可逆——会话级双栈（上限 50 步，切库清空，不持久化），每步记录受影响数据文件的操作前快照与磁盘逆操作，逐步撤销逐步重做（机制见 [[05_项目进度]] 阶段 6.0）。
- **拖拽排序：** 拖拽调整顺序，写入 Placement 的 order 字段。落点视觉统一为品牌色-1（2026-07-28 定）：文件树 item 高度三等分——上下 1/3 判定为排序（显示插入线 + item hover 背景），中间 1/3 判定为并入（item 底 = 品牌色-1 12% 填充 + 1px 边框）；卡片排序落点 = 品牌色-1 12% 填充 + 1px 边框的**圆角竖向矩形色块填满卡片间距**，拖到文件夹卡片上 = 并入（刚好覆盖缩略图区域的方形覆盖，同配色）。**文件夹卡片与素材卡片排序不混排。**
- **拖拽移动 / 剪切（Ctrl+X）+ 粘贴（Ctrl+V）：** 移动 Placement 至目标文件夹；剪贴板移动仅素材，文件夹仅靠文件树内拖拽（排序 / 并入）。快速访问项是数据自动分类视图，**不可作为拖拽落点与粘贴目标**。
- **Ctrl + 拖拽 / 复制（Ctrl+C）+ 粘贴（Ctrl+V）：** 弹「关联文件夹」清单弹窗（2026-07-28 草图定案）——每行一个素材：源（缩略图 + 所在文件夹 + 文件名）→ 目标（目标文件夹 + 文件名输入框，默认填源文件名全选态，便于直接确认或删改）；行尾「关联 / 副本」互斥单选（默认关联）+ ×（把该行单独踢出本次任务）；确认 = 所有行一次执行，取消 = 全部放弃。单选即一行，多选不逐个弹窗。
- **粘贴为副本（Ctrl+Shift+V）：** 物理复制生成新 ID，不弹窗直接执行，名称与源一致。右键菜单同时露出"粘贴"与"粘贴为副本"两个选项。
- **新建文件夹（2026-07-28 定）：** 侧栏「文件夹」副标题添加按钮 = 新建当前选中文件夹的兄弟（插到其下一行；侧栏恒有选中项，选中快速访问项时插到根级最底部）；右键菜单「新建同级文件夹 / 新建子文件夹」——均不用模态框，直接创建并进入名称输入态；对 item 触发插到其下一行，空白处触发建到最底部。
- **重命名（F2 / 右键菜单）：** 非模态——标题就地变为输入框（卡片与文件树 item 同）；重命名**原始 Placement** 时，同步将磁盘上的 originName（含词干缩略图等伴生文件）一并改名，失败中文报错并整体回滚（2026-07-28 修订为同步语义——配合撤销机制天然可逆；原"先改显示名、后台空闲时异步执行 + 启动自愈"队列方案降级留待，日后遇 Animate 占用致改名失败场景再评估）；重命名**链接 Placement** 仅改显示名（数据规则详见 [[01_资源与数据]]）。
- **克隆文件夹：** 弹窗提供两个选项——**链接克隆：** 仅克隆文件夹节点与全部 Placement（链接指向原资源），零磁盘开销；**复制克隆：** 同时物理复制全部资源（各自生成新 ID）。均命名为"xx 副本"。
- **创建副本：** 即多文件夹关联中的副本选项，生成新 ID，完全独立。
- **删除（Del）：** 删除当前 Placement；最后一条 Placement 被删除时直接移入回收站（不询问，2026-07-29 用户修订，详见 [[01_资源与数据]]）。

#### 索引式工作空间（真实磁盘操作）

- 复制、剪切、粘贴、重命名直接操作磁盘文件，配合双向热刷新。
- 不支持拖拽排序、克隆文件夹、建立链接（无 Placement 数据）。

## 11. 批量编辑

多选后，基础操作自动转为批量执行，是快速移动整理文件的手段：

- **批量复制 / 剪切 / 粘贴：** 对多个 Placement 批量执行，语义同 10（粘贴可选链接或副本）。
- **批量创建副本：** 批量物理复制，各自生成新 ID。
- **批量克隆文件夹：** 多选文件夹时可用，同样提供"链接克隆 / 复制克隆"选项。
- **批量重命名：** 统一标题 + 自动序号（如 人物-1、人物-2）；查找替换等高级规则列为后续版本。
- **批量标签：** 批量追加 / 移除标签。
- **批量删除：** 删除语义同 07。
