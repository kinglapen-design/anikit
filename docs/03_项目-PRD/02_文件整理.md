## 01. 区块

允许用户自定义新增、删除区块，为区块命名，设置区块文件夹的默认图标。点击菜单栏的区块管理图标进入区块管理界面：

- 允许上下排序，且允许在侧边栏视图里拖拽排序。
- 允许自定义区块名称。
- 允许自定义区块默认图标——影响新建文件夹时 item 的默认图标，后续用户可对单个文件夹更改图标。
- **默认区块为「目录」，不允许删除（名称 / 图标 / 排序均放开——锚定常量 id "dir" 而非名称，改名无影响，2026-08-14 用户定）**：它是各兜底落点——承接被删区块移出的文件夹、停留在快速访问等无法导入文件夹的视图时新建文件夹与导入文件夹（保留层级）的存放处。
- 删除区块时，若区块内有文件夹则弹出警告窗口（26 稿 alert warning）；**确认后区块内顶级文件夹带子树移入「目录」区块根级（2026-08-14 用户定）**——不摧毁用户层级；原"文件去到未分类"文案作废。
- **数据口径（2026-08-14 落地）**：区块表存 folders.json `blocks`（`{id, name, icon, order}`，默认区块 id = "dir"）；顶级文件夹以 `Folder.block` 归属区块（None = 「目录」），`Folder.icon` 记新建时继承的区块默认图标（单文件夹改图标 / 颜色随 3.3）；未分类（Placement 根级）语义上属「目录」区块根级，无数据变化。区块管理弹窗（30 稿）= 草稿式一次提交（`apply_block_changes`，一步撤销）；侧栏区块标题可拖拽排序（`reorder_blocks`）、文件夹拖到区块标题 = 移入该区块根级。

导出资源库到本地时，不同区块物化为平行的兄弟文件夹：

``` text
- 项目
	- 吃鸡天赋树
- 档案
	- 角色
		- 男主角
		- ...
	- 场景
	- ...
- 目录
	- 男人
	- ...
```

## 02. 文件树整理

通过修改数据文件实现文件的层级和信息管理等，而非频繁的真实移动文件。

- **自定义排序：** 支持拖拽排序文件夹与文件，顺序写入 folders.json 的 order 字段，仅改数据不动磁盘，保证响应流畅。**排序依据含"自定义"首项（2026-08-14 用户定）**：可随时切回存储序；**名称排序显示下的手动结构操作（拖拽排序 / 新建文件夹）= 先物化该层可见顺序为存储序并自动切回"自定义"**——拖拽落点按可见序计算、新建落点回到选中项下一行；否则 refresh 后名称排序盖回，操作等于没执行（2026-08-14 用户实机"显示排序成功但实际没变"修复）。物化不单独弹 toast（顺序变化是主操作附带，撤销快照仍在）。**2026-08-19（3.5）素材侧落地同款**：显示排序下素材拖拽排序 = 该层可见序（含新增区置顶段）物化 + 整层重写 + 切回自定义；粘贴 / 新建文档不物化——无相对落点语义，由新增区承接（见 [[04_文件预览]] 06 节）；**副本落点 = 紧随原件**（2026-08-20 用户定：同文件夹副本恒插源后第一位，新副本贴原件、旧副本顺后移；跨文件夹副本粘贴 = 段首前插同导入语义——原"段首前插 + 新增区置顶"会把副本顶到第一行第一列，克隆完还要回顶部找）。**新建文件夹后清理（2026-08-14 用户定）**：清其他选中单选新文件夹 + 跳转其视图 + 进命名态——防旧选中域与新项双高亮混淆。
- **区块根目录视觉（2026-08-04 定；2026-08-18 修订）：** 区块根目录下的父级文件夹用底色区分，未自定义颜色时默认灰色；文件夹从其他层级拖至区块根目录下时，自动变为带灰色底色的默认 item；父级被设置颜色后，其子项全部变为父级颜色的**底色版本**（`--custom-{色}-bg`，2026-08-18 用户澄清——非透明度 10%，每个自定义色自带一对前景/底色档）。
- **树行为口径（2026-08-20 用户定，阶段五前 BUG 修复轮）：** ① **数量标签**：折叠 = 递归总数（含全部子文件夹）；**展开 = 直接子项文件数**（子文件夹已各自成行，父级数量只算自己的文件；为 0 不显示——替换原"展开即隐藏"：用户实机"父级 80 个素材直接在父级下、展开后数量消失，误以为显示异常"）。② **移动 / 新建后默认展开父级**：移动文件夹并入子项（拖拽 / 剪切粘贴 / 移动面板）、新建子文件夹 / 子档案后，目标父级保持展开——让用户直接看到操作结果，而不是折叠起来无从确认。③ **导航树定位**：树外入口进入文件夹视口（双击文件夹卡片 / 菜单打开 / 面包屑等）时，树自动展开祖先链与所在区块并滚动定位到该节点——原仅高亮，父级折叠时当前文件夹在树上看不见（视觉焦点丢失）；自身节点不展开（定位 = 看到它）。
- **自定义图标颜色（2026-08-18，3.3 落地；2026-09-01 修订）：** 文件夹可自定义图标颜色用于分类识别；图标与颜色值存于 folders.json 对应节点（`Folder.icon` / `Folder.color`，None 不写字段）。入口 = 树节点右键「更改图标 / 更改颜色」（7.1 二十四轮起 = 图标网格 flyout + 颜色内嵌色块行，组件/上下文菜单稿）。**同步语义（2026-08-18 用户定，图标颜色同口径）**：父级改动默认影响子级——后代中与本节点旧链路值**一致的跟随调整**（图标含默认图标 None == None，未区分子级首次统一即靠此；颜色无色后代不写数据、视觉自动跟随底色版本但链路穿透），**不一致的（用户单独区分过）不动且不再下钻**；后代改回与父级一致后恢复跟随。**「默认」色块 = 显式默认（2026-09-01 用户定）**：落盘存 `"default"` 哨兵断开父级链路强制常态灰——子级选默认若清 None 会被父级色视觉盖回、永退不回灰；哨兵按普通链路值参与同步。**多选批量（同日）**：触发项在多选域内 → 整个选中集一并换色（`set_folder_colors` 单命令单撤销步）。**档案右键菜单接入更改颜色（同日）**：档案 = Folder kind 标记，色值同表，生效于树档案节点圆点/图标（与徽标色 archives 表无关）。图标侧档案后代恒跳过（图标强制 archive，见 03 节）；**archive 图标不可选（同日）**——档案专属，移出更改图标网格与区块默认图标清单（存量 Folder/Block.icon = archive 经开库自检回退 None）。生效范围 = 文件树的 item 底色与图标（缩进线不变色——半透明线叠底色自然呈色，2026-08-18 用户定；7.1 十八轮起缩进线随节点色改该色-2 的 50% 档）、右侧详情面板的关联文件夹列表（随 6.2 区块落地）。
- **封闭式专属：** 文件树整理、区块、档案、分组、标注、多文件夹关联均为封闭式资源库专属功能（注释 / 描述降级后置见 06，评分移出 MVP 见 08）；索引式工作空间仅按真实磁盘结构显示，不支持自定义排序，磁盘与 UI 双向热刷新。

## 03. 档案文件夹

档案 = 文件夹 + 详细数据（数据项见 [[03_数据链接]]），是复盘"节点式管理"的落地形态。对文件夹右键可转换为档案，也可直接新建档案；档案享有和文件一样的数据配置；档案徽标可自定义设置或隐藏。

- **层级约束：** 档案文件夹内不允许出现子级文件夹；右键转换时若文件夹内有子级，提醒用户剔除层级导入。
- **树内形态：** 档案 item 可在目录树内出现，但无展开箭头、下无子级，图标强制切换为档案专属图标 + 品牌紫色圆圈装饰。
- **拖拽规则：** 目录树拖拽文件夹时，档案不允许作为父级并入，仅支持排序；仅纯文件（多选时不包含文件夹）才允许拖入档案。
- **中间面板：** 展示分为文件夹 / 档案 / 文件三个区域。
- **回收站语义（档案当单个文件看待）：** 档案删除移入回收站时保持档案状态（剔除层级是对常规文件夹的处理），允许一键恢复；被删除的文件夹内包含档案时，档案同样保持封装状态。注：序列帧移入回收站时同样保持封装打包状态（既有实现天然满足）。
- **卡片：** 固定长宽比，缩略图默认索引子项第一张图片网格填充铺满；用户可在档案里设置头像——头像即档案封面，二者同步（见 [[03_数据链接]] 03）。
- **档案内视图（2026-08-30 用户定删除）：** ~~进入档案后，在中间面板与左侧边栏之间插入二级侧边栏显示档案数据；右侧正常显示文件~~——面板与右侧详情面板内容完全重复（选中档案卡片右栏即显示同一套档案详情），冗余撤除：ArchiveSidePanel 组件 / per-folder 开关状态 / 收展动画 / 工具栏展开钮一并删除；档案数据查看口径 = 选中档案看右栏。
- **数据口径（2026-08-15 落地，3.2 一轮骨架）**：档案 = folders.json 里 `Folder.kind = "archive"` 标记（serde default + None 不写字段，不升 DATA_VERSION）；头像 / 徽标 / 属性 / 描述存库级 `archives.json`（单一写点 save_archives，记录懒建，开库自检剔除失效记录，结构见 [[03_数据链接]] 06）。**转换两段式**：文件夹转档案时若有后代子文件夹先回 need_confirm 不动数据（26 稿同款两段式，25 稿 alert warning 确认弹窗，主钮「剔除转换」）；确认后剔除层级 = 后代子文件夹 BFS 按 order 逐层解散（各子文件夹 Placement 平移到档案、order 追加在后整体重排连续，子级本身是档案的 archives 记录一并清除），再置 kind。**护栏落地**：create_folder / move_folders 目标父级为档案报错"档案下不允许出现子级文件夹"；树/卡片拖拽档案不作父级并入仅排序，素材拖入档案不受限。**形态落地**：树 item 无展开箭头 + archive-dot 装饰；中间面板 ArchiveStrip 三区（文件夹 / 档案 / 内容，档案区无内容不渲染）；ArchiveCard 260:298 固定长宽比 + 纸底 SVG + 封面默认子项首图 + 左上角徽标芯片 + 底部信息条（名称 / N 个文件 / 链接计数），状态态复用文件夹卡片 ::after 机制。撤销标签：新建档案 / 转换为档案 / 解散档案为文件夹。

## 04. 分组

档案与普通文件夹通用的内容区组织能力（功能来源参考 Windows 资源管理器分组，支持自定义），工具栏分组图标点击进入分组设置。

- **3.5 二轮落地定案（2026-08-19，逐项用户定）：**
	- **数据归属：** 分组规则存 folders.json 文件夹节点 `Folder.groups`（`GroupDef{id, name, rules[]}`，serde default 不升 DATA_VERSION；数组序 = 定义顺序 = 内容区组间序）；**仅文件夹/档案视图生效**（快速访问无分组——无存放节点）；归组计算在前端显示层（lib/grouping.ts），不改任何数据；克隆文件夹分组随迁。
	- **生效范围：** 内容区素材卡片（文件夹/档案卡片不参与）；**仅非递归视图生效——递归显示开启时不分组（纯平铺，排序/新增区照常），分组配置仅对直接子项有意义；工具栏分组管理钮递归态禁用**（2026-08-19 复验定案：递归下为后代素材建的组在非递归视图成幽灵配置，所见/配置不一致；原"递归按当前文件夹规则统一归组"口径废除）。
	- **归组语义：** 组内多规则 **AND 全命中**才归组；多组同时命中归**规则条数更多**者（更具体），平局按定义顺序先建者优先；未命中 = 未分组（**恒在头**，2026-08-19 用户定；**没有任何组命中时未分组段不显示——视觉平铺**，同日复验定案：0 命中组仍在管理窗口可见可编，内容区不挂"未分组"孤标题）；组内顺序 = 排序流相对序（排序方式与新增区在组内自然生效）；**同组内允许拖拽互相排序**（落点限同组段内），**跨分组拖拽禁止出落点**——组归属由规则定，拖入别组不改变归组（2026-08-20 用户定，替换原"分组模式整体禁排"；多选跨组选中时拖拽排序同样无落点）。
	- **类型 8 类**（用户定，替代旧"文本/图片/文档/视频"）：图片 / 动图（GIF·动图·序列帧）/ 视频 / 音频 / 文本 / 文档 / 工程（psd·fla·ai·aep 等）/ 其他；**选项按当前文件夹实际存在动态出**（33 稿注释口径）；首字母分组不做（04_文件预览 07 节旧表述废除）。
	- **日期分档六档互斥**：今天 / 昨天 / 本周早些时候 / 上周 / 本月早些时候 / 更早（本周以周一起）；规则可选多档（OR）；一个文件只落一档。
	- **折叠：** 分组标题折叠 = 仅该组子项折叠（区块标题折叠 = 全部组随折）；会话级不持久化；分组标题 **sticky 置顶**（滚过顶停留、下一组接替顶走，05_区块标题布局规则落地；**贴视口顶**——列表模式让开钉顶列头，2026-08-19 复验定）；**组间距 24**（首组离内容标题恒 12，同日复验定）；**无文件夹/档案区块的视图分组后不出"内容"副标题**（组标题直接顶上，同日定）。
	- **入口与弹窗分工：** 工具栏「分组管理」钮（仅文件夹/档案视口可用）→ 33 稿分组管理弹窗（草稿式一次提交单撤销步，箭头排序 + TransitionGroup，添加分组 / 删除红钮）；分组标题 group-menu 钮 → 12 稿菜单（跳转▸ = 全组列表滚动跳转 / 新建分组 → 34 稿弹窗（单次一个）/ 编辑分组 → 33 稿弹窗 / 展开折叠▸ / 上移 / 下移 / 删除——未分组组简化菜单仅跳转与展开折叠）；23 稿错误（完全相同拦截）= **名称不查重，仅规则集合**（组序/规则序/值序无关）——前端预检弹 23 稿 + 后端同校验兜底。
- **未分组：** 新拖入的文件默认放入未分组；设置自动分组后，进入的文件按规则自动归组（如开启扩展名分组，fla 文件默认进 FLA 组）。
- **自定义规则：** 扩展名（检测全部扩展名供多选）/ 类型（8 类供多选）/ 名称（输入分词，AND 逻辑——空格分隔多词全部命中）/ 导入日期 / 修改日期（日期分档互斥，见上）。
- **规则冲突处理（2026-08-04 定）：**
	1. 两个组规则与范围完全相同时，弹出报错，禁止保存；
	2. 单规则组之间互斥——组二选择已被组一占用的扩展名 / 类型 / 日期时，该项自动从组一转移至组二，并 toast 明确告知（确认前取消则全部恢复）；
	3. 多规则组合允许重叠，文件优先进入命中条件更多的组（如组一 = fla、组二 = fla + 名称"雪牧"，则含"雪牧"的 fla 归组二）；命中数相同的平局按分组定义顺序，先建者优先。
- **AI 写规则：** 后续版本可指派 AI 生成规则，解放手动输入（见 11）。

## 07. 标注

这是一个对于动画师来说比较重要的功能，让用户可以在图片、动图、视频上创建多个画框来进行标注。

示例1：用户在一张打篮球的图片上，创建画框框选住篮球，然后为画框取名为篮球。
示例2：用户在动图或者视频上创建画框，逐帧绘制视频内运动对象的轨迹和压缩与拉伸的状态，来观察动画，方便动画师参考和创作，允许用户额外保存一份记录了标注的副本，导入至动画软件进行绘制参考。

- **数据归属：** 标注存于资源 info 文件夹内独立的 annotation.json，每条标注 = 帧号/时间戳 + 画框坐标 + 名称，随资源一并删除与备份。
- **搜索：** 标注名称纳入分词搜索范围，搜"篮球"可命中对应图片。
- **版本规划：** 静态图片的单帧标注进入 MVP；动图、视频的逐帧标注（轨迹、压缩与拉伸的关键帧绘制）列为后续版本。

## 09. 链接

可为素材添加链接，点击链接可打开浏览器跳转，允许添加 ID 路径：`anikit://item/{ID}`，来进行点击后软件内跳转。

ID 寻址还允许添加给外部软件使用，如给 Obsidian 等软件作为图片附件，点击后打开 AniKit 跳转至图片界面。

- **数据归属：** 链接列表存于 metadata.json 的 links 数组，纳入分词搜索范围（匹配前 URL decode，见 [[03_查找文件]]）。
- **技术前提：** `anikit://` 需在安装时向系统注册协议处理（Windows 注册表 / macOS Info.plist）；软件未启动时点击协议链接，先启动再跳转至对应资源。
- **边界（2026-08-21 用户确认）：** 链接只作跳转，不向外部文档推送图片内容——Markdown `![](anikit://...)` 图片引用无效（渲染器只认 http/file 字节流，不认自定义协议）；剪辑软件素材路径场景用真实文件路径（复制文件路径 / 拖拽），协议链接仅走系统"打开方式"路由，不是文件路径。
- **实现排期（2026-08-21 用户定）：** 协议注册 + 单实例收链接 + 前端跳转解析器随阶段九与硬链接同批；此前仅"复制链接"生产端可用。

## 10. 多文件夹关联

允许同一文件以不同名称出现在多个文件夹，提供两种选项：

- **链接：** 同一资源 ID 出现在多个文件夹，各文件夹内可自定义显示名称，零磁盘开销，重新生成缩略图等操作处处生效。
- **副本：** 物理复制为全新资源（新 ID），从此完全独立，互不影响。
- **导入查重：** 导入与已有资源 hash 相同的文件时，弹窗询问"建立链接 / 仍导入副本"。

数据规则（改名作用域、删除语义、反查关联、链接寻址、搜索命中）详见 [[01_资源与数据]]。被链接引用的源文件在卡片上显示标识（五角星），hover 展示该文件的全部链接位置。

## 11. AI 智能分类

允许用户配置规则或者直接与大模型对话，让大模型进行资产分类，这项功能的前提是，将 AniKit 的功能，包括基础操作都抽象成接口，让 AI 能从底层操控软件。还需要向量库的帮助，让 AI 可以搭配向量数据，进行文件分类，减少 token 消耗。分组规则同样可由 AI 生成（见 04）。

## 13. 基础操作

#### 封闭式资源库（仅改数据，不动磁盘）

- **撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z）：** 一切写操作可逆——会话级双栈（上限 50 步，切库清空，不持久化），每步记录受影响数据文件的操作前快照与磁盘逆操作，逐步撤销逐步重做（机制见 [[05_项目进度]] 阶段 6.0）。
- **拖拽排序：** 拖拽调整顺序，写入 Placement 的 order 字段。落点视觉统一为品牌色-1（2026-07-28 定）：文件树 item 高度三等分——上下 1/3 判定为排序（显示插入线 + item hover 背景），中间 1/3 判定为并入（item 底 = 品牌色-1 12% 填充 + 1px 边框）；卡片排序落点 = 品牌色-1 12% 填充 + 1px 边框的**圆角竖向矩形色块填满卡片间距**，拖到文件夹卡片上 = 并入（刚好覆盖缩略图区域的方形覆盖，同配色）。**文件夹卡片与素材卡片排序不混排。**

- **移动面板（Ctrl+Y / 右键菜单「移动文件 / 移动文件夹 / 移动档案」，29 稿，2026-08-18 落地）：** 弹层文件夹树选落点——item 上中下三段 hover（上/下 1/3 = 移为目标 item 的前/后兄弟，中 1/3 = 并入为子项，落点视觉同树拖拽插入线 / 并入填充），单击弹警告确认（alert 模板，发起名与目标父级名品牌色-常态高亮）；默认全部展开 + 搜索过滤；移动文件夹 / 档案时发起项自身及后代不显示（不能移入自己）；树恒按自定义序渲染（落点所见即所得）；多选批量 = 整个选中集一次移动（单撤销步）。
- **粘贴两键（2026-08-18 定案）：** **Ctrl+V = 作为链接粘贴**（静默执行不弹窗，显示名默认取源名；同文件夹重复链接放开，显示名自动唯一化——2026-08-13 用户定：不替用户做整理决定，原"同资产同文件夹只允许一条链接 + 重复粘贴去重 toast"作废）；**Ctrl+Shift+V = 作为副本粘贴**——物理复制生成新 ID，不弹窗直接执行，名称与源一致。**Ctrl + 拖拽落文件夹 = 直接建链接不弹窗**（与 Ctrl+V 同语义）。右键菜单露出两个粘贴项（**剪贴板为空时粘贴项不出现**；文件夹「粘贴文件夹」同口径——2026-09-05 走查：没有剪切过文件夹就不出现，旧"恒列置灰"废除）。——原 2026-08-04"三键"定案的「作为链接粘贴并重命名（Ctrl+Shift+V 选择性粘贴清单弹窗）」与 Ctrl+Alt+V 键位**废除**（2026-08-18 用户定：导入就是导入，命名导入后手动 F2 / 批量重命名；高频整理弹窗烦人——关联弹窗 / 选择性粘贴弹窗均不再出现）。

## 14. 批量编辑

多选后，基础操作自动转为批量执行，是快速移动整理文件的手段：

- **批量复制 / 剪切 / 粘贴：** 对多个 Placement 批量执行，语义同 13（粘贴可选链接或副本）。
- **批量创建副本：** 批量物理复制，各自生成新 ID。
- **批量克隆文件夹（2026-08-18 落地）：** 多选文件夹右键「克隆」/ Ctrl+D——每个选中文件夹独立克隆一棵（单命令 `clone_folders` 单撤销步），语义同 13（复制克隆，无选项弹窗）。
- **批量重命名（2026-08-18 落地，3.4 / 37 稿）：** 单个「批量重命名」弹窗（多选时右键「重命名」/ Ctrl+R 触发，菜单项多选显示"批量重命名"；单选维持就地重命名）：底部分段选择器切换模式（**序号命名** / **替换命名**，同一时刻只显示当前模式的一行输入）——序号命名 = 名称 + 起始编号，位宽自动按选中数量决定（<100 两位、≥100 三位）；替换命名 = 查找文本 + 替换为（纯文本全处替换，MVP 不做正则）。规则只作用**词干**，扩展名不动。新名称列 = **实时预览**（只读，输入即刷新；替换模式下**原名称匹配段品牌色高亮**——视觉上把高亮部分换成新的）；无变化项不提交（序号名称为空 / 查找为空或无匹配 = 该项保持原名）。撞名不拦截（显示名放开，见 [[01_资源与数据]] 边界规则 7；原始 Placement 磁盘物理约束仍在，撞名失败计入汇总）。执行 = 逐条改名（链接仅改显示名 / 原始同步改磁盘 originName），**失败项（如被动画软件占用）跳过 toast 汇总报告，不整体回滚**；一次执行单撤销步（`rename_placements`）。
- **批量删除：** 删除语义同 13（原写"同 10"系笔误，2026-08-18 修正）。**文件夹批量删除已落地（2026-08-18，3.4）**：文件夹多选域右键「删除文件夹」或 Delete 键 → 一次确认（"已选中的 N 个文件夹…"）→ 后端 `delete_folders` 单趟单撤销步；祖先同批入选的后代去重（删祖先已连带子树），陈旧 id 剔除容错；素材删除原本即批量（Delete / 右键删整个选中集）。
