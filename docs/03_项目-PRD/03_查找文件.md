## 01. 指令式搜索

将筛选、搜索统一至标题栏的顶部搜索框内，通过前缀指令切换搜索方式，移除臃肿的筛选按钮：

``` text
"/"      搜索入口：弹出搜索模式下拉框（分词 / 向量 / AI）
"//"     筛选入口：弹出筛选下拉框
"Tab"    切换搜索范围（当前目录 ↔ 全局），范围 chip 实时更改
"Ctrl+F" 快速聚焦搜索框
```

指令之间可以交叉存在，实现更精确的定位。搜索框左侧提供范围 chip（当前目录 / 全局），显示当前所在范围，点击也可切换，与 Tab 等效。

#### 1. 普通搜索

平时搜索基本不需要按 "/"：直接输入 人物 + 空格 + 走路 时，即可搜索出当前目录的 人物-开心-走路、人物-伤心-走路 等文件。

按 Tab 或点击范围 chip 切换至全局搜索，可搜索出全部素材里的 人物-XX-走路。

分词搜索命中范围：资源名、各 Placement 显示名、扩展名、标签、注释、描述、链接、标注名。

- 索引式工作空间无附加数据（标签、注释等），分词搜索仅命中文件名与路径。

#### 2. 筛选

当用户输入 "//" 弹出下拉筛选菜单：颜色、格式、标签、时长、标注、注释、链接、描述、评分、比例、文件夹、添加日期、修改日期、文件大小等等。

每一个子菜单都弹出一个二级窗口供用户选择，比如选择文件夹，弹出文件树复选框，用户也可以直接在搜索框输入名称搜索文件夹，回车确认后，为选择项创建一个筛选 tag，带删除角标；按一次退格键选中 tag（高亮），再按一次删除，单击 tag 进入编辑，如：

``` text
//颜色：#FFFFFF ✕　//格式：GIF ✕　//标签：走路、男人 ✕ ...
```

交叉定位示例：输入 `//格式：fla` 创建筛选 tag 后，再输入 `/男人` 标记搜索关键字，即定位到名称为男人且格式为 fla 的文件。

#### 3. 搜索模式

当用户输入 "/" 弹出下拉搜索框：分词搜索、向量搜索、AI 搜索。

- **智能路由：** 默认无需手动选择，带空格的关键字走分词搜索，自然语言句子自动走向量 / AI 搜索，下拉仅作为手动覆盖。
- **时间轴定位（向量搜索）：** 视频、动图、序列帧经手动分析（粗略 / 详细两档）后按镜头切分建立分段索引，搜索命中的是"某视频的某段时间"——如搜"马奔跑"，可命中多部动画中的奔跑片段，搜台词同样可定位；结果卡片显示时间点，点击跳转至预览的对应进度。未分析的素材不参与语义搜索，分词搜索不受影响。
- **版本规划：** 分词搜索进入 MVP；向量搜索、AI 搜索列为后续版本。

## 02. 快捷搜索框

按 alt + ` 可在不调出主界面的情况下呼出，快捷搜索框默认全局搜索，复用与主界面相同的前缀指令；Tab 同样可切换范围（当前目录指主界面当前所在的文件夹）。

- **常驻后台：** 该功能要求软件可最小化至托盘常驻后台。
- **热键自定义：** 全局热键允许用户修改，避免与输入法、其他软件的全局快捷键冲突。
