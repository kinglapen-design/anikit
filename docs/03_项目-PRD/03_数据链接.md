## 02. 文件

详情面板可展示与编辑的数据：

- **颜色：** 分析颜色（色块提取，详见 [[04_文件预览]] 详情；**6.1 已落地**：主色存 metadata.colors，透明像素不计入，pinned 颜色 bar 按实际色数渲染前 7）。
- **名称：** 直接改名，走 [[02_文件整理]] 13 的重命名规则。
- **链接：** 浏览器扩展抓取图片时自动填充来源网址，也可用户手动填写；支持内部链接 `anikit://item/{ID}` 实现两个文件之间的跳转（见 [[02_文件整理]] 09）。
- **基础信息：** 尺寸 / 文件大小 / 格式 / 添加日期 / 创建日期 / 修改日期，其中尺寸只对可获取到尺寸的文件有效。
- **属性（2026-08-04 扩展至文件）：** 短文本并列（如 走路 / 跑步 / 拔剑），短文本之间自动添加 `|` 分隔——即"打词"能力，**代替原标签体系**，跨维度归类的载体，分词搜索与筛选命中（见 [[02_文件整理]] 05、[[03_查找文件]]）。**编辑 = 32 稿属性标签弹窗（6.1 已落地）**：搜索框过滤属性池；「输入新属性」回车添加；点池内属性加入拥有（轻微过冲回弹）；池 = 全库聚合（全部文件属性 + 全部档案属性去重），池内 × = 警告二次确认后**全局删除**（所有填写了该属性的文件与档案都失效）。
- **描述（2026-08-04 扩展至文件）：** 长文本，为标题 + 内容的组合；**内容超过 3 行截断、显示"展开 / 收起"按钮**（行数 2026-08-23 用户定）；编辑界面可逐条添加（**31 稿编辑描述弹窗，6.1 已落地**：箭头排序 + 红色删除 + 添加描述，确认一次提交）。
- **链接区块：** 当前文件同时存在于哪个区块的哪个文件夹、显示名称是什么（Placement 反查）；**每条路径只写两段（2026-08-15 用户定：三段太长）——区块名称（常态色）/ 所属目录（标签色）；所属目录为档案时显示「名称.档案」后缀，档案位置一看便知，归属档案信息由此并入本区块**。未分类与回收站资产的显示规则见 [[02_文件整理]] 15。**（2026-08-24 落地，6.2 三轮：添加钮 = 链接管理弹窗（17 稿）——管理本文件的链接分布：左列 = 侧栏文件树照搬（区块分组、文件夹颜色/数量同树）+ 未分类组；右列 = 位置行（名称框就地改显示名 + ★原始/链接徽章 + √ 增删，同文件夹重复链接平铺多行——用户定，后续版本重构 UI 时再重新设计面板逻辑）；草稿式确认一次提交（sync_asset_links 单撤销步），移除 = 直接删记录不进回收站；× = 移除该条链接（同命令单条即时）；**点 item = 跳转定位**（该位置视口 + 选中卡片，面包屑后退返回）+ **当前目录的 item 永远第一行**（2026-08-24 四轮走查②）；文件右键「文件链接管理」Ctrl+J 同入口——工具栏/新增菜单的链接管理钮删除，用户定「针对某个文件，右键菜单和详情面板有入口就行」；档案链接管理随档案多位置立项，见 [[01_资源与数据]] 边界规则待立项）**
- ~~**归属档案：**~~（**2026-08-15 用户定：区块废除**——档案位置经链接区块「名称.档案」后缀表达，不再单设区块。）
- **提示词：** 没有提示词时可点击「分析提示词」或「指定文本」：
	- **指定文本：** 用户指定已导入的 MD 文本，内容显示在输入框；
	- **分析提示词：** 不主动额外创建文档。分析结果提供三个动作——① **创建为 MD 文本**：将分析文本创建为 MD 文档作为新文件导入，自动放到与源文件同一目录；② **打开编辑器**：输入框不便长文输入，内置 Markdown 编辑器（后续版本）打开编辑——分析的提示词必须先保存为 MD 才能使用编辑器；③ **复制**：一键复制提示词文本。
	- **数据落地：** 提示词 = 对 MD 资产的**引用 + 内容快照**——平时显示快照（源 MD 被删除不断链），可跳转源文件。
- **关系：** 选择一个文件或档案建立关系（选择操作见 04，**多选累积**——一次可为同一发起方添加多条）。例：雪牧 添加关系 → 选择 雪天、输入"父亲"——双向显示：雪牧详情显示"雪天是父亲"，雪天详情显示反向称谓"雪牧是儿子"。**（2026-08-23 落地口径，6.2 一轮：反向称谓 = 选择模式备选区右框手动填写、可留空回退同词——"自动显示儿女"的推导不做，无词典。2026-08-24 二轮：详情关系 item 点文件卡 = 跳转定位到对方（面包屑后退返回）；"点文件进选择模式换绑"废除——要换就删了重新添加；改称谓保留 = 点称谓框 C2 输入框；× 删除。）**
- **音色：** 关系的预定义类型，双向显示——文件详情显示"使用的音频是哪个"，音频详情显示"在哪些文件里使用过"。**（2026-08-24 方案 1 定案：voice 恒单向 使用者→音频——音频不能作使用方（"音频的音频"递归起来没完没了），音频侧区块 = 标题「使用者」+ 只展示/跳转、无添加钮；要挂音频跳到使用方上加，后端校验同。）**
- **详情面板区块体系（2026-08-15 落地，3.2 一轮；同日下午用户四轮定案修订）：** 文件与档案共用**pinned 缩略图区块 + 固定 7 排序区块**——缩略图区块（缩略图 / 颜色 bar / 名称输入框 / 链接输入框，四件 gap 12）**永远置顶、不可隐藏、不参与排序、不进 22 稿面板**；排序区块 = 自定义数据（带区块标题：属性 / 描述 / 编辑描述）/ 基础信息 / 副本 / 链接区块 / 关系 / 音频 / 提示词（归属档案区块同日废除并入链接区块）；**无内容区块显示空数据不隐藏**（标题照常 + 空内容 + disabled 添加钮）；排序 + 显隐两个入口——**详情面板内直接拖区块标题行重排**（侧栏区块 blockDrag 同款让位动画）与「编辑数据区块」面板（22 稿），配置持久化 `settings.ui`（应用级 ui.detailSections，注册表 mergeDetailSections 兜底——配置里已删/未知 id 忽略，新增区块按注册表相对序补位默认可见）；**文件与档案各一套独立配置（2026-08-23 用户定）**——`ui.detailSections`（文件套，存量配置无缝保留）+ `ui.detailSectionsArchive`（档案套），原共用一份互串废除；渲染按当前目标形态分流，22 稿面板编辑目标 = 右栏入口跟随当前选中（选中档案卡片 = 档案套，否则文件套；档案侧栏入口 2026-08-30 随面板删除撤除）。

## 03. 档案

档案享有与文件一致的数据配置（[[02_文件整理]] 03，含属性与描述），此处仅列差异项。基础信息可手动直接编辑。**（2026-08-15 落地口径：档案与文件共用同一套区块体系，见 02 区块体系条；档案仅多出头像 + 徽标两项——一轮暂无前端编辑入口，徽标编辑归二轮、头像归三轮。）**

- **头像：** hover 头像显示相机图标，点击进入头像编辑——取景框内移动图片调整位置；伴生缩略图、PSD 等文件均可作为头像来源（走既有缩略图管线）。头像即档案卡片封面，二者同步。
	- **数据落地（2026-08-23 改定，6.1 用户定案）：** 头像 = **库根 covers/ 内独立存的烘培封面文件 + 取景框参数**（`Avatar{ file, crop? }`）——本地选图**不入库**为资产；时间戳命名不覆盖写（撤销回滚即恢复旧封面）；「从资源库中选择」的资产引用变体随主窗口选择模式（04）落地时再扩。**编辑入口 = 43 稿封面设置面板**（详情 pinned 区块点击封面展开：取景滑块缩放 + 拖动位移 / 更换封面 / 徽标 / 颜色，确认一次提交）。
- **徽标：** 在档案数据里设置的徽标显示于档案卡片左上角，可不设置；编辑在 43 稿封面设置面板（徽标输入框留空清除 + 颜色 9 色板，--custom-{色} 主档色值入 `Badge.color`）。

## 05. 主窗口多标签页（2026-08-08 定案，随 1.2 落地）

中间面板标题栏 = 标签栏（figma-css 15_标签栏 / 39_右键菜单-标签页）。标签页可拖拽重排、可拖出拆分停靠（左右 / 上下分屏），布局持久化（重启恢复）。

- **标签页 = 一个文件视口**（快速访问项或文件夹）；全部标签页共用同一份库数据与选择状态，各自只记自己的视口位置。
- **侧边栏导航：** 当前标签页未锁定 → 替换其视口；已锁定 → 新开标签页（Eagle 式）。
- **「新标签页打开」（文件夹 / 档案右键菜单，2026-08-20 接入）：** 恒新开标签页，与当前页锁定态无关（原实现误用侧边栏导航语义——未锁定页只替换视口，等于没开新页）。
- **面包屑后退 / 前进（工具栏，2026-08-20 接入）：** per-panel 导航历史（会话级）——侧边栏导航替换视口时旧视口入后退栈、清前进栈；后退 / 前进直接替换本页视口（不走"锁定页新开"语义——历史是本页自己走过的路径）；新开页 / 布局恢复 = 空历史。
- **锁定：** 锁定标签页无关闭按钮（显示锁定图标）、右键"关闭标签页"禁用；不禁止拖拽排序与分屏。
- **右键菜单：** 关闭标签页 / 锁定 / 新窗口打开 / 左右分屏 / 上下分屏。"新窗口打开"仅预览视图可用（预览子窗口），文件视口下该项禁用色。

## 06. 数据落地规划

- **关系 / 音色统一为 relation 模型：** `{ from, to, kind, label, reverseLabel? }`（kind：free 自由关系 / voice 音色），双向显示为同一条记录的两个视角；存**空间级** relations.json（关系可跨库——库 A 的角色配库 B 的音频），单一写点、携带 version。**（2026-08-23 已落地，6.2 一轮：from/to = `RelationRef{ lib, kind: "asset"|"archive", id, name }`——携库名 + 显示名快照（跨库目标未打开 / 失效时兜底显示）；label = to 对 from 的称谓，reverseLabel = from 对 to 的称谓（手填可空，空 = 反向回退同词）；开库自检剔除本库失效端点的关系。本轮 kind 恒 free；voice 随链接音频轮。）** **（2026-08-24 落地，6.2 三轮：kind = voice 接入——无称谓（label 恒空串、reverseLabel 恒 None），to 必须音频 asset（mp3/wav/wma），from 可 asset / archive；详情「音频」区块点亮：使用方详情 = 音频 item（绿圆播放钮 + 名称 + 波形小图，点击播放/暂停切换，03_数据 item §5 稿），音频详情 = 使用方文件卡；点名称/卡 = 跳转定位（同关系 item），× 删除，添加 = 选择模式过滤音频——**2026-08-24 方案 1 修订：voice 恒单向 使用者→音频，音频侧标题「使用者」+ 无添加钮只展示/跳转，from 不得音频 asset（后端校验防递归）**）**
- **属性 / 描述（文件）：** 属性 = metadata 内字符串数组（复用原 `tags` 字段，标签体系取消后语义转为属性词，免迁移）；描述 = metadata 内 `[{ title, content }]` 数组（`descriptions` 字段，6.1 已落地，serde default 不升 DATA_VERSION），随 metadata 单一写点。
- **档案数据（2026-08-15 已实现，3.2 一轮）：** 档案节点在 folders.json 标记形态（`Folder.kind = "archive"`，serde default + None 不写字段，不升 DATA_VERSION）；档案数据存库级 **archives.json**（单一写点 core::library::save_archives，携带 version；记录懒建——新建/转换不落记录，开库自检 fix_archives 剔除指向失效文件夹的记录）：`ArchivesFile = { version, archives: ArchiveData[] }`；`ArchiveData = { folderId, badge?: { text, color }, avatar?: { file, crop?: { x, y, scale } }, props: string[], descriptions: [{ title, content }] }`（badge / avatar / crop 为 None 时不写字段；**avatar.file = 库根 covers/ 内烘培封面图，2026-08-23 独立存定案，6.1**）。
- **提示词**（引用 + 快照）与**头像**（源资产 + 取景参数）的数据落地见上文各自条目。
- **内部链接**统一使用 `anikit://item/{ID}` ID 寻址，改名不死链（[[02_文件整理]] 09）。
