## 1. 资源库

> [[01_资源与数据]]

### 1.1 储存空间（封闭式资源库）

类似 Eagle、Lightroom Classic 的封闭式管理模式的升级：所有资源库的素材封存于统一 assets 池，多资源库以数据文件区分，路径稳定性优先、数据变更为核心管理模式，详见 [[01_储存空间]]。

### 1.2 索引式工作空间

储存空间内唯一 workspace 文件夹，按真实磁盘结构显示、磁盘与 UI 双向热刷新；可经目录联接映射至其他路径，见 [[01_储存空间]] 3.2。

## 2. 文件整理

> [[02_文件整理]]

### 2.1 文件树

1. 封闭式管理：管理文件树层级和排序时，仅改变数据文件，而非真正频繁的移动文件，从而实现流畅的响应。

2. 索引式管理：根据本地实际的文件夹结构显示，不支持自定义排序，仅支持层级嵌套管理，实现磁盘和 UI 双向热刷新。

3. 区块与档案（2026-08-04 新体系）：区块为顶层自定义分区（默认区块「目录」），档案 = 文件夹 + 详细数据的叶子节点；详见 [[02_文件整理]] 01 / 03。

### 2.2 标签（已取消）

标签体系整体取消（2026-08-04 用户定，取代 2026-07-28 最小骨架方案）：打词下沉为文件与档案的属性（见 [[03_数据链接]]），跨维度归类由多文件夹关联与关系承担；不建独立标签数据。

### 2.3 注释与描述

仅支持封闭式管理，用户可对文件夹和文件进行自定义描述和注释。MVP 后置（2026-07-28 用户定：命名规范的动画师素材价值低，逐帧笔记已覆盖主要记录需求）。

### 2.4 标注

仅支持封闭式管理，可在图片和视频上自由绘制标注，支持导出带标注的副本供动画软件参考。

### 2.5 评分

已移出 MVP（2026-07-28 用户定：评分服务于从大量相似素材中筛精品，动画师素材目的性强、命名规范，用不上）；metadata 字段保留不做 UI，后续版本再评估。

### 2.6 链接

仅支持封闭式管理，可为文件添加链接，支持 `anikit://` ID 寻址，供软件内与外部软件跳转。

### 2.7 多文件夹关联

仅支持封闭式管理，允许一个文件同时以不同的名称出现在多个文件夹内，采用副本或者链接两种选项。

### 2.8 AI 智能分类

允许用户自定义规则和提示词，允许 AI 执行自动化归类。

### 2.9 基础操作

单选、多选、范围选、选框、全选等选择方式；拖拽排序、复制、剪切、粘贴、克隆文件夹、创建副本、重命名等操作；多选后自动转为批量编辑（批量复制、移动、副本、重命名、删除等）；一切写操作支持撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z，会话级，2026-07-28 定）。

### 2.10 数据链接

文件与档案的节点式数据（2026-08-04 新体系）：档案 = 文件夹 + 详细数据；属性与描述、提示词、关系与音色双向链接，详见 [[03_数据链接]]。

## 3. 查找文件

> [[03_查找文件]]

### 3.1 指令式搜索

筛选与搜索统一至标题栏搜索框："/" 搜索入口、"//" 筛选入口，指令可交叉组合；Tab 切换全局 / 当前目录（范围 chip 实时更改），Ctrl+F 快速聚焦搜索框。

### 3.2 筛选

按颜色、格式、标签、时长、链接、比例、文件夹、日期、文件大小等条件筛选，条件以 tag 形式呈现，可交叉组合（标注 / 注释 / 描述随功能就位后补齐，评分已移出 MVP，2026-07-28 定）。

### 3.3 搜索模式

分词搜索（MVP）：关键字加空格分词，命中名称、扩展名、标签、链接、标注名等（注释 / 描述随功能后置就位后纳入）；向量语义搜索与 AI 搜索列为后续版本，支持按输入内容智能路由；向量搜索支持视频分段定位（画面内容与台词），命中具体到某段视频的时间轴位置。

### 3.4 快捷搜索框

软件常驻后台，支持可自定义的全局热键呼出快捷搜索框，默认全局搜索，复用同一套前缀指令。

## 4. 文件预览

> [[04_文件预览]]

### 4.1 导航视图

导航栏支持视图的切换：资源库、本地索引、快捷入口；标签视图随标签管理功能列为后续版本（2026-07-28 定）。

### 4.2 布局显示

支持自适应布局（等高不等宽），瀑布流布局（等宽不等高），网格布局，列表布局。

### 4.3 文件预览

支持软件内预览图片、动图、序列帧、音频、字体、文本、视频等。

### 4.4 详情展示

展示文件的颜色信息、基础信息、属性、已关联的文件夹与档案、提示词、关系、音色等（见 [[03_数据链接]]）。

### 4.5 多种排列

除了自定义排序，还有通用的名称、修改时间、创建时间、导入时间、拓展名、文件大小。（评分排列随评分移出 MVP，2026-07-28 定）

### 4.6 分组显示

为内容展示区实现分组显示：名称、大小、时间、扩展名。（标签 / 评分分组随标签最小骨架与评分砍除同步移除，2026-07-28 定）

## 5. 导入与导出

> [[05_导入与导出]]

### 5.1 导入素材

允许用户导入文件和文件夹，支持复制 / 剪切两种来源方式及剪贴板直接导入；文件夹支持递归导入（剔除层级）、保持文件夹结构导入。

### 5.2 打开素材

支持默认应用打开，支持跨窗口拖拽至其他软件窗口打开。

### 5.3 导出素材

支持导出素材，导出文件夹（根据数据文件结构），导出整个素材库（根据数据文件结构）

## 6. 数据

> [[06_数据]]

### 6.1 存放目录

1. 封闭管理：数据文件、缓存文件均保留在储存空间内（统一素材池 assets 与各资源库目录），重装软件和系统时不丢失（见 [[01_储存空间]]）。
2. 本地索引：工作空间为储存空间内唯一 workspace 文件夹，缓存随空间存放。
3. 全局配置：在系统配置目录存放储存空间、资源库列表与全局设置（便携模式则随软件所在目录）。

### 6.2 数据结构

为导入至资源库的文件单独创建 info 文件夹，并生成 JSON 数据和缩略图；所有数据文件采用 JSON 格式并携带版本号，支持逐级迁移。

### 6.3 备份与恢复

定时与大批量写操作前自动备份数据文件（滚动保留 10 份），菜单内提供版本回滚，数据损坏时可一键恢复至最近备份。

### 6.4 回收站

删除的资源仅在数据层移入回收站（info 文件夹原地不动），永久保留、手动清空，清空时才彻底删除文件；工作空间删除走系统回收站。

### 6.5 缓存清理

缩略图、波形等缓存均可重建，设置页提供占用查看与一键清理。

## 7. 动画软件通信

> [[动画软件通信]]

### 7.1 缩略图导出

支持调用对应插件，与动画软件通信，导出 WebP 等缩略图存放至对应的 info 作为伴生图片；如：检测到没有伴生图的 fla 文件时，调用 JSFL 插件，打开 Animate 生成缩略图。

### 7.2 软件插件

为对应的动画软件开发插件，实现双向通信，如：CEP 插件，在 Aniamte 中，选中元件素材，在 CEP 面板可一键为选中元件新建 fla 文件并导出缩略图。

### 7.3 快速发送

可在 UI 界面快速将 fla、aep 等工程文件发送至软件的舞台。

## 8. AI 功能

> [[08_AI 功能]]

### 8.1 内置 AI 创作

通过调用 API 来实现 AI 创作，生成图片和视频。

### 8.2 AI 工具

一键抠图、一键扩图、一键超清等基础 AI 功能。

### 8.3 AI Agent

让 AI 有着全局权限，可允许执行用户各种指令，来自动整理、命名、标签、定期检查、快速搜索等，需要将前后端彻底解耦，将所有的基础指令和业务都封装成 API，后续也可快速接入新的插件，减少维护量。
