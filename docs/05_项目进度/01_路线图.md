# 01_路线图

> 2026-08-06 新阶段划分定稿（用户文档 `docs/00_修改与需求/02_新阶段/01_新阶段.md`，逐轮查漏后确认）。已实现功能随新 UI 重构接入、不重复建设。

**阶段纪律（用户定）：** 每个阶段最后进行一次阶段性项目检查——死代码、多补丁、耦合高、未封装、大文件。

## MVP（阶段一 ~ 八）

- [ ] **阶段一 · 新 UI / 显示文件**——新 token 与可复用组件封装（1.1）；主窗口样式重构（拖拽拆分条 / 多标签页窗口 / 标签页拆分停靠 / 侧边栏收展 / 标签页右键 / 主窗口选择模式 / 设置页面，1.2）；二级面板与右键菜单规划（占位点亮机制，不留无业务接入的按钮，1.3）；查看方式与布局 + 卡片尺寸缩放（1.4）。**1.2/1.3 顺序 2026-08-07 用户调换：先有主窗口才能调出右键菜单。**
- [ ] **阶段二 · 创建资源库 / 导入与导出**——初次打开向导 + 新库结构与数据文件 + 多库切换合并（2.1）；导入文件/文件夹/序列帧 + 基础数据写入 + 音效（2.2）；导入预览性能优化（2.3）；序列帧打包（2.4）；快速访问按实际数据分类（2.5）；自动导入 Inbox（2.6）；重复文件查重（2.7）；导出文件/序列帧/文件夹/档案（2.8）。~~素材引用硬链接（2.9）~~（**2026-08-14 用户定：挪阶段九**——硬链接唯一用途 = 链接落盘到工作空间，无 workspace 无落点；且 NTFS 硬链接不能跨卷，junction 映射异盘时的回退口径随工作空间一并定）。
- [ ] **阶段三 · 基础操作 / 新建 / 整理**——新建区块/文件夹/文档（3.1；**一轮区块子系统 2026-08-14、二轮新建文档 2026-08-15 均已落地**——文档固定七类：Animate/Photoshop/Illustrator/MarkDown/文本/Word/Excel，AE 不建档，二进制类走 assets/templates/ 空白模板）；新建档案与转换档案 + 数据填写 + 头像 + 徽标（3.2）；自定义文件夹图标颜色（3.3）；选择/拖拽/复制粘贴/重命名/批量操作（3.4）；排序与分组（3.5）；分词搜索与筛选 + 快捷搜索栏（3.6）。
- [ ] **阶段四 · 自研解码器**——为缩略图预览做准备：卡片同时自动播放流畅、减少动图导入期解包、节约磁盘与时间。spike 先行：ffmpeg-next 解码线程 + 帧队列推前端，先验证"帧进 webview"链路再铺量。
- [ ] **阶段五 · 缩略图 / 预览卡片**——图片预览（5.1）；动图悬停/自动播放 + 单帧切换 + 序列帧解包导入 + 包内逐帧查看 + 设封面（5.2）；视频悬停完整播放/自动播放 + 单帧 + 笔记 + 封面 + 自动播放范围（5.3）；自定义缩略图设置（5.4）；音频波形缩略图 + 悬停播放 + 波形播放条（5.5）；字体 / Markdown / txt 等纯文本预览补齐（5.6）。
- [ ] **阶段六 · 自定义数据与连接**——属性打标 / 描述 / 更换封面 / 徽标 / 颜色分析（6.1）；链接区块 / 副本 / 工程恢复文件 / 归属档案 / 关系 / 链接音频（6.2）；提示词编辑 / 分析提示词 / 指定 MD 为提示词 / 编辑 / 删除（6.3）筛选（6.4）。
- [ ] **阶段七 · 插件**——无伴生图 Animate 文档自动监测 + 批量导出缩略图（图片进缩略图视图，7.1）；Animate CEP 插件（7.2）；Chrome 浏览器插件（7.3）。
- [ ] **阶段八 · 重构与性能打磨**——10 万资源滚动达标、长期实测、终查。
