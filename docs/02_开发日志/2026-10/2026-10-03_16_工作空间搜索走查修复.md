# 工作空间搜索走查修复（无缩略图 / 双击打不开 / 打开目标文件夹，2026-10-03）

> 用户实机走查 _15 落地轮三报一轮修复 + 一项新交互（「打开目标文件夹」用户当场定）。

## 三报与根因

**① 搜索结果无缩略图**——断点在「缓存新鲜静默跳过」：`resolve_thumb_job` 对缓存新鲜的条目直接不入队、**零事件**（目录列举不受影响是因为 `entry()` 列目录时已就地回填 thumbPath）。搜索结果集不在 ws 目录缓存里、合成时 thumbPath 恒 null，前端可见卡上报后全部在「新鲜」分支静默消失，等回填永远不来。修法 = 后端在 `ws_search` / 爬盘发射前统一回填：`fill_cached_thumb`（list_dir `entry()` 同口径——内容缩略图缓存新鲜 = asset + w/h 读缓存文件头回填恢复真实比例；失败记忆命中 = 按扩展名格式图标已在缓存才给；其余留 null 继续走前端上报 → 队列生成 → thumbs-ready 回填链）。已知极窄边缘：Everything 索引 mtime/size 与实况瞬时不一致时该条缩略图当次不给（下次搜索自愈）。

**② 双击搜索结果打不开**——预览 `current` 只在「属主面板视口列表 + 库全量 placements」里查 key；ws 搜索命中是跨目录合成集，只存于 search store 的 wsEntries，两处都查不到 → `current = null` → `loadAsset` 静默把 assetKey 置空（库搜索无恙 = 命中集是视口同集的过滤子集）。修法 = 预览导航列表收拢唯一入口 `previewList(panelId, viewKey, content)`：ws 视口且搜索态 = 搜索结果集（顺序与网格一致），其余 = 视口 placements——`current / index / total / step` 四处同源（搜索态预览内上/下一个 = 按搜索结果序翻页）。

**③ 新交互「打开目标文件夹」**（用户定：点击跳到文件所属文件夹并关闭搜索）：ws 文件卡菜单仅搜索态出现——`requestReveal` 登记滚到该文件 + 清空草稿关搜索 + `tabs.openView` 进所在目录视口。

## 验证

探针 `cdp-ws-search-probe` 扩 6 项（S8a-c / S9a-b + 搜索态菜单项存在性），**21 项全 PASS**；579 测绿 + clippy 净 + typecheck 0 错。过程小坑：探针翻回 Everything 可用态后须等能力缓存 3s TTL 过期再搜（否则吃缓存 false 空跑一轮）；预览「返回」钮 title 走 v-tip 不落 DOM 属性，探针改按结构选择器点。
