# 库 ↔ 工作空间互通（拖拽双向复制 + 菜单树选择器双入口）（2026-10-03）

> 2026-10-03 · 第三轮。用户定方向：库与工作空间太割裂，硬链接未排期，先做简单复制——库到工作空间 = 复制过去（本质就是现有「导出到磁盘」，文件夹也能导），工作空间到库 = 导入进库；两边右键菜单各加树选择器入口（移动面板样式）。

## 方案（后端零命令新增）

两方向底层能力全现成：**库 → ws** = 现有 `export_assets` / `export_folder`（assetId / folderId + 目的地绝对路径；originName 拷出、序列帧打包、`名_n` 规避、进度条 + 失败重试），目的地填 `ws.absPath(rel)`；**ws → 库** = 现有 `import_paths`，rel 转绝对路径后进既有 `importDraft` 流（导入弹窗确认结构 / 序列帧检测全继承，`classify_paths` 判 kind 同 App.vue onDrop）。全部工作量在前端：拖拽引擎落点分流 + 菜单项 + 目的树选择弹窗。

附带修正一个现存死链：ws 条目拖库落点原会进 `move_placements` 带 `ws:` 合成 id 被后端按陈旧项跳过、误 toast「已移动 0 个项目」——本轮换成了导入流。

## 落地（纯前端九处）

- **拖拽引擎 `dragOperation.ts`**：六落点分支按拖拽项来源分流——ws 树行 / ws 文件夹卡 / ws pane 三处对**库素材**开放 = `dropLibraryAssetsIntoWs`（export_assets 落该目录，assetId 去重）；库树行 / 库文件夹卡 / 库 pane 三处对 **ws 条目**分流 = `dropWsAssetsIntoLibrary`（importDraft 流，替换 move 死链）；回收站 pane 补 ws 排除（快速访问行同口径）。虚拟视图 / 间隙排序 / 分组段对互通拖拽维持不出落点。
- **菜单四项**：素材卡「导出文件 ▸」与虚拟视图拍平级、文件夹卡「导出文件夹 ▸」各加「导出到工作空间」（`exportAssetsToWsFlow` / `exportFolderToWsFlow`）；ws 文件卡「发送至 Animate」后、文件夹卡 / 树行「在外部位置创建链接…」后加「导入到库」（`importWsToLibraryFlow`，批量整组受理）。
- **目的树选择器 `DestTreeDialog.vue`**（新组件，selection.destTreeDraft 驱动，App.vue 挂载）：移动面板壳 / 搜索 / MoveNode 全复用，差异 = 行级 hover 恒并入 + 单击出 ConfirmPrompt 两段确认（移动面板同口径）。数据源二态：库树（blockSections + 首行「未分类」根落点）/ ws 树（合成「工作空间」根行，懒加载随展开 ensureDir，断链目录不渲染）。
- **MoveNode 扩变体 props**（缺省 = 原行为）：`intoOnly` / `expandable` / `countOf`；**壳样式抽共享件 `moveTree.css`**（MovePanel 同 import，items.css 先例）。
- **selection store** 增 `destTreeDraft`（tree / title / sourceName / onPick 闭包，confirmPrompt.onConfirm 存闭包先例）；**menuOps** 三流程编排。
