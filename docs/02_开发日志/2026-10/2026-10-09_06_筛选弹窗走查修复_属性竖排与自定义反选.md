# 筛选弹窗走查修复：属性竖排根治 + 自定义反选（2026-10-09）

用户实机走查四连问一轮修（另答色相疑问）：

## ① 属性弹窗 chips 竖排根治（踩坑 108 新立）

用户截图：属性弹窗里两个属性词竖排一列一个，横排空间富余。定因 = 三轮给 `bars.css` 列表族新立的全局 `.fp-list { flex-direction: column }`（比例 / 日期用）与二轮 FilterTagsPop scoped 的 `.fp-list`（chips 流式区）**同名撞车**——CSS 特异性逐属性竞争，scoped 只赢它声明过的属性，未声明的 flex-direction 被全局 column 渗入；preview 二轮目验时该全局类尚不存在，三轮加类后未复看属性窗，漏网。修法 = 共享类语义化（`.fp-list` = 列表族 column 专用）+ chips 区改名 `.fp-taglist` 显式 row 断根；预防 = 新立全局共享类先 grep 同名存量 + 复看既有同名组件。

## ② 比例 / 日期自定义反选

用户问「自定义怎么反选」——原只有清空输入框一路，不直观。补 = 自定义行对勾做成可点钮 `.fp-uncheck`（复用 `.fp-check` 显隐口径：生效时显形可点、未生效隐形不响应），点击 = 取消自定义并清空输入框，v-tip「取消自定义」；预设与自定义维度内 OR 共存语义不变（取消自定义保留预设勾选）。

## ③ 色相疑问（答用户，待拍板）

颜色稿只有 SV 盘（色相随当前色）无色相条——现状改色相只能经 HEX / RGB / HSL 输入。提议在 SV 盘下补一条 226×12 色相条（通用取色器形态）解决「想换色系无从下手」，**属稿外新元素，待用户拍板后落地**。
