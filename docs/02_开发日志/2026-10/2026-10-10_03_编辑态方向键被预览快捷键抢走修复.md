# 2026-10-10_03 编辑态方向键被预览快捷键抢走修复（contenteditable 让位）

用户实机报：md 进入编辑态后 ←/→ 无法移动输入指针。定因 = `PreviewPanel.vue` 窗级 keydown（←/→ = 上/下一个素材、空格 = 播放暂停、Esc = 关预览）的输入态让位守卫是手写 `tagName === "INPUT" || "TEXTAREA"`，漏 contenteditable——CM6 的 `.cm-content` 不在豁免名单，方向键冒泡到 window 触发切素材（编辑器随切走销毁，视觉上 = 指针动不了）。

修复 = 守卫换共享 `isEditableTarget`（`useGlobalKeys`，含 `isContentEditable`），一处改全键位愈。探针 `cdp-md-editor-probe.py` 新增 Q 段回归（cm-content 派发 ArrowLeft/Right → 光标移动且编辑器存活不切素材），18 段全 PASS；typecheck 0 错。

**口径沉淀**：窗级快捷键的输入态豁免一律 `isEditableTarget`，禁止手写 tagName 清单（本次漏网根源；速查 §69 同步）。
