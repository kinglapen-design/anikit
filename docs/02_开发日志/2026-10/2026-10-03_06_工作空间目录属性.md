# 2026-10-03_06 工作空间目录属性（Windows 属性窗口低成本批）

## 需求

用户问 Windows 文件夹属性窗口的字段哪些可以低成本显示到 ws 文件夹详情。逐项评估后落地低成本批，高成本/低价值项说明不做。

## 逐项结论

- **创建 / 修改时间**：极低——后端 `entry()` 对目录人为抹零（`if is_dir {0}`），Windows 目录两时间 std metadata 本就有效，放开即得；目录 mtime = 直接子项增删时更新，语义正对「修改日期」。
- **包含 + 大小**：低——新命令 `ws_dir_stats` 递归遍历一次（spawn_blocking 不占 tokio worker，Explorer 属性窗口同为现算），文件数 / 子文件夹数 / 字节总和一腾产出。
- **占用空间（簇对齐真值）**：不做——与字节求和信息重复，且压缩 / 稀疏文件准确值要 GetCompressedFileSizeW，近似反而误导。
- **只读 / 隐藏 / 高级属性 / 共享安全等 tab**：不做——目录只读在 Windows 无意义（属性窗口自注「仅应用于文件夹中的文件」），其余高成本低价值。

## 落地

**后端**：`entry()` 目录 ctime/mtime 抹零放开（字段注释与旧断言同步——`list_dir_sorts_hides_cache_and_fills_fields` 旧断言 `(size, mtime)=(0,0)` 改 size=0 + mtime>0）；新 `dir_stats`（services/workspace.rs）+ `ws_dir_stats` 命令——递归穿透 junction（Explorer 同口径：链接门内容是「挂进来的文件夹」），canonicalize 已访问集防回环，`.anikit` 全层跳过，断链门计 1 文件夹子树跳过，读取失败子树静默，目录缺失 / 越界 Err 上抛；响应附根目录自身时间（详情根视口合成条目无 entry 时间取此）。

**前端**：wsOps 封装 `wsDirStats`；WsDetail 文件夹分支从「只出类型行」扩为——类型 / 文件数 / 子文件夹数 / 占用空间（库 FolderDetail 同标签，行序贴 Windows 属性窗口）/ 创建日期 / 修改日期（条目值优先，根视口取 stats）。stats 拉取 watch entry 对象 identity（所在目录重扫换新即重拉，Explorer 快照口径），防错配同 loadDetail 模式，未到位不加行。

## 过程坑（测试抓住）

`DirEntry::file_type()` 对 junction 的 `is_dir()` 恒 false——Rust std 语义 `is_dir = !is_symlink && is_directory`，reparse point 一律算 symlink 不跟随。初版直接 `ft.is_dir()` 判定，junction 门被完全漏掉（穿透失效，新测试 files 2→1 当场抓住）。修法 = list_dir 同口径候选补 `junction::is_reparse_dir`（普通目录零额外 syscall，仅疑似链接候选查一次）。
