# 筛选业务四轮：输入类三维度（颜色 / 时长 / 大小）（2026-10-09）

筛选五步分走之 ④：输入类三维度弹窗落地，至此 **10 个筛选维度弹窗全数点亮**（剩 ⑤ 菜单收尾）。

## 落地件

- **FilterColorPop**（250×339 稿）：单选色条件（colors 数组取首项）。色盘 = SV 盘 canvas 三层渐变自绘（稿位图落地口径：纯色底 + 白水平 + 黑垂直，色相 = 当前色、品牌蓝 204 兜底）+ 选择环定位 + 点击 / 拖动取色（pointer capture）；取色回环 hue 差 <1° 不重绘防抖。HEX 行 = TextInput lg 新扩 **leading slot**（16×16 色块，空态白底斜杠 = 稿 prose）+ 清除；RGB / HSL 三框互切（切换钮面 = 当前模式），非法 / 超界输入不生效。颜色换算（hex↔rgb↔hsv/hsl）组件内私有。
- **FilterRangePop**（时长 / 大小共用）：单位切换器（单位文字并列点击切换 + expand 装饰，稿「单位下拉菜单」形态）+ 最小 / 最大（focusout / Enter 提交）+ 清除。时长 unit 随条件下发（帧 = 后端按素材 fps 换算，一轮引擎已备）；大小条件恒字节，KB/MB/GB 纯显示档（FloatBarHost 换算，sizeUnit 会话级保持）。
- 走查修复一遭：RGB 行三框初版 flex:1 均分，TextInput 根恒 width:100% 把 48 切换钮挤溢出（目验实证）——改 50 宽固定贴稿。
- summaries 补齐时长（≥10 帧 / 10~240 帧）与大小（formatSize 人性化），至此 10 维度摘要仅文件夹未出（需树名称解析，留走查反馈）。
- preview 陈列四 cell（颜色交互 / 颜色空态 / 时长交互 / 大小静态）+ 浏览器目验贴稿。
