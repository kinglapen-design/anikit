# 命中片段与范围播放

## 数据与命令闭环

新增 `create_semantic_segment`，消费当前模型版本、分析版本和源指纹一致的 `assetId + segmentId`，禁止嵌套虚拟片段。应用内右键「AI 工具集」可先创建当前命中，创建前重查面板；MCP 同名工具逐次过写入闸并广播库变更。创建沿用普通入库、Placement 和撤销，ffmpeg、哈希、缩略图不持库锁。

虚拟片段的 metadata 使用既有 `type=segment / source / start / end`，动图与序列帧增加可选 `startFrame / endFrame` 原始索引。info 只保存 metadata 和区间缩略图，不复制媒体实体。视频按真实 PTS 限界，动图 / 序列帧按原始帧索引限界，失效来源或缺索引明确报错，不播放完整源文件。

物理片段是独立普通资产：视频重编码 MP4；GIF / 动态 WebP / APNG 按原始帧及逐帧 delay 导出；序列帧输出 GIF。`source / start / end` 和原始帧索引只保留来源证据，`type` 为空，可脱离源文件播放。GIF 从选中帧生成调色板并关闭抖动，避免把编码色差误判为错帧。

## 播放与写入隔离

`get_media_source`、`list_sequence_frames` 和 `start_anim_stream` 对虚拟片段返回可选 `segment`，普通资产与物理片段不返回。视频在终点停止或循环回起点；动图和序列帧在原始帧范围内播放、seek 与预加载，不重新编号来源帧。单帧物理结果可以是静态图片，不强行标记为动图。

定位时区分目标 info 与来源媒体路径，设置虚拟片段封面只写自己的目标 metadata 和缩略图，不覆盖来源资产。`get_asset_origin_path` 返回真实来源文件，`get_asset_detail` 返回片段来源和原始帧字段，不返回虚拟目录里不存在的实体。

## 实测结果

- 后端真实覆盖：虚拟视频 / GIF 不复制媒体且保留原始索引、来源删除拒绝播放；物理 MP4 时长正确；GIF 与序列帧按原始帧导出；动态 WebP / APNG 逐帧对比通过；封面写入隔离通过。
- 真实界面：右键菜单创建虚拟视频后，再经 MCP 创建虚拟 GIF、虚拟序列帧和物理 GIF。虚拟视频按时间范围播放，虚拟 GIF 按原始帧播放，虚拟序列帧保留完整源清单但只播放命中范围；物理单帧可独立显示。
- 完整 S0–S9 脚本通过，MCP 32 工具实测通过。最终后端全量 703 项通过、0 失败，前端 typecheck / build 通过。

命中时间角标与完整任务控制面板没有定稿，本轮没有自创这些 UI；菜单只复用现有「AI 工具集」结构。
