## 落地范围

**Everything 层（探测到运行中实例即全功能）**：新适配器 `adapters/everything.rs` 手写 1.4 WM_COPYDATA QUERY2 协议（不引 Everything64.dll、不用 es.exe，零分发授权问题）——探测 = FindWindow 任务栏通知窗（1.5a 类名优先回落 1.4）+ WM_USER 版本查询；查询 = 自建 message-only 接收窗 + ChangeWindowMessageFilterEx 放行（UIPI）+ SendMessageTimeout 发出 + 本线程消息泵等回包，超时降级。能力三态（运行中 / 已安装未运行 / 未安装）= 注册表卸载项 + 默认安装路径，ffmpeg sidecar 降级范式。

**搜索编排 `services/ws_search.rs`**：`path:"<abs>" file: 关键字…`（`file:` 仅文件——目录由侧栏树导航不进结果网格；**搜索串原样透传绝不整体加引号**，踩坑 103）；`~` = 全景搜索工作空间根、无 `~` = 当前视口目录子树（Everything `path:` 天然递归，资源管理器同语义）；junction 登记链接按真实目标分别补查、命中映射回词法门 rel（与方向 b 共享 `links` 台账）；`.anikit` 剔除；限流 1000。命令 = `ws_search`（spawn_blocking，同步 IPC 不占 tokio worker）。

**回退爬盘层（无 Everything）**：不冒充即时搜索——输入不动、空态引导「按 Enter 遍历搜索当前目录」，Enter 触发 `ws_search_crawl_start`（栈式遍历 + rayon 批并行 16 目录/批 + canonical 防 junction 回环 + `.anikit` 跳过 + 取消令牌入 `AppState.ws_searches`），进度与命中批次经 `ws-search-crawl` 事件流式推送；**不接 `~`**（用户定：全局慢搜开销大无意义——后端拒收兜底 + 前端通知栏指路：未安装 =「下载 Everything」`open_external_url` 官网（适配器 http/https 白名单），已安装未运行 =「启动 Everything」`launch_everything` 代拉起）。进度条复用导入进度条组件（用户定「参考导入文件的那个进度条」：不定态滑块 +「已扫 N 个文件」+ 关闭 = 取消，已命中部分保留）。

**前端**：`FloatBarSearch` 筛选钮 `filters` 传空整颗不渲染（原恒渲染，ws 磁盘实况无附加数据可筛——用户原话「没有用」），FloatBarHost 按 viewKey `ws:` 传空 + Enter 转发；`stores/search.ts` 按视口分流（ws → ws_search / 爬盘，库原链不动），命中集 wsEntries 经 `wsEntryToPlacement` 合成进网格（键口径与目录缓存合成链一致，标题计数 / 选择 / 拖拽 / 右键菜单白捡）；搜索命中条目缩略图走既有 ws 管线（可见卡上报 + thumbs-ready 回填本 store）；Everything 能力 = 机器级 3s 缓存 + ws_search 回 unavailable 真值翻转。
