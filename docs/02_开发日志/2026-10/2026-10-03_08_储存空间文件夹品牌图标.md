# 2026-10-03_08 储存空间文件夹品牌图标

## 需求

用户供稿 `design/LOGO/image/AniKit-library-folder-clean-v3-1024.png`（蓝色双层文件夹 + AniKit 标）：储存空间文件夹用专属品牌图标，像 Eagle 的 `.library` 文件夹一样增强品牌感与辨识度。

## 落地（Windows 文件夹自定义图标标准机制）

新适配器 `adapters/space_icon.rs`，`activate_space` 调用（创建 / 打开空间同覆盖，现有空间惰性补写）：

- **ICO 离线转制**：1024 PNG → `src-tauri/icons/space-folder.ico`（16/24/32/48/64/256 六尺寸，pillow；换图标 = 重转覆盖同路径），`include_bytes!` 嵌入 exe，运行时写 `{空间根}/AniKit.ico`（隐藏属性；字节一致跳过幂等，不一致覆写回品牌图——专有文件名单一写点）。
- **desktop.ini**：`[.ShellClassInfo] IconResource=AniKit.ico,0` + `InfoTip=AniKit 储存空间`（相对路径 Vista+ 标准写法；**已存在不动**——可能承载用户其它 shell 自定义）。
- **文件夹只读属性位**：desktop.ini 的生效前提（Windows 只认只读 / 系统属性目录的 desktop.ini；目录只读位无写保护语义）。属性一律 GetFileAttributes → 位叠加 → SetFileAttributes（std set_readonly 整体覆盖属性字不可用）。
- 失败静默 log——图标是装饰，不阻塞开空间。

## 验证

568 测绿（+1：三件套落地 / 幂等 ini 不动 / ico 覆写回 / 只读隐藏位）+ clippy 净。实机验证（免安装包冒烟顺带）：启动新 anikit.exe 恢复空间即落 `E:\anikit\AniKit.ico` + `desktop.ini`（均 Hidden），`E:\anikit` = ReadOnly+Directory——资源管理器可见品牌图标（窗口可能需 F5 刷新）。
