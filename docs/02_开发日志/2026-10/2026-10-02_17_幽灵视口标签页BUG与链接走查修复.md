# 幽灵视口标签页 BUG 与链接走查修复（2026-10-02）

工作空间符号链接（_16）实机走查一轮：用户录屏报「添加链接文件夹… 选完目标报 目标目录不存在」，追查中逮到一个潜伏的标签页 BUG（幽灵视口），三件套修复 + 报错文案消歧。同场记录项目文件夹两迁后的构建修复。

## 同场：项目文件夹迁移与构建修复

用户为测试链接功能把项目文件夹从 `E:\anikit\workspace\...` 挪到 `E:\01_projects\...`（后又迁回）——Rust target 目录嵌绝对路径指纹**不可随项目搬迁**：tauri 构建脚本产物记录旧 canonical 路径，迁后首次 dev 即报 `failed to read plugin permissions ... os error 3`。修法 = `cargo clean` 全量重建（首迁清 50.9G 含历年残留，迁回清 6.5G），两遍冷编译均一把过。与用户敲定的后续口径 = 项目不再搬了；若再搬，可选留门法（旧位置 mklink /J 指真身，构建走门路径）或 target-dir 外置（未实施，仅备录）。`tools/.venv` 的 pip 包装脚本同样嵌旧绝对路径，留观察（`python.exe -m pip` 直调可用）。

## 现象与诊断

录屏现象：空工作空间（侧栏仅回收站 + 文件夹/0）里「添加链接文件夹…」选中 `E:\01_projects`（明明存在）→ toast「目标目录不存在」。

先排三遍嫌疑：后端 `add_link` 校验链（落点 resolve → is_dir → check_link_target 防循环）逐行走查合规；前端 `addLinkFlow` → `ws.addLink` 参数无换位；`gridDispatch` 给 `wsBlankSpec` 的 rel = `sidebarSelected.slice(3)` 来源合规。唯一相容解 = **当前视口本身就是一个不存在的 ws 目录**：`resolve_under` 对不存在路径词法放行 → `is_dir()` false → 报错。

用户随后点破：标签页标题「05_分镜」是**标签页 BUG**——从库式切到工作空间，工作空间没有文件夹，视口却停在库式浏览过的 05_分镜。机制链坐实：`ui.lastWsView` 是**全局跨空间**停留视口记忆（App.vue 按 `ws:` 前缀归桶持续记录，2026-09-19 定），`SidebarLeft onModeChange` 切 workspace 时**未校验存活**直接 `openView(ui.lastWsView)` 重放——甲空间浏览过的 ws 目录在乙空间（空工作空间）重放即成幽灵视口。而 `list_workspace_dir` 当时**降级吞错**（列举失败 → `Ok([])`）让「目录没了」与「空目录」不可分，幽灵得以冒充空目录：空视口 + 标题停在幽灵名 + 右键写操作全落幽灵路径；「目标目录不存在」在选目标语境下被自然误读成选中的链接目标。标签恢复、运行期外部删除当前目录同病。

## 修复三件套 + 文案消歧

1. **后端 `list_workspace_dir` 错误口径改**：未开空间 / workspace 根缺失仍 `Ok([])`（启动暂态降级保留）；**目录缺失 / 越界等列举失败 → Err 原样上抛**，不再冒充空目录（`commands/workspace.rs`）。
2. **前端 ws store 置缺失标记**：`loadDir` catch 置 `missing[rel]`、成功清除（`stores/ws.ts` 新 state）。
3. **幽灵视口自愈**：App.vue 新增 watch——当前视口 rel 被置 missing 即 `tabs.openView` 回退父级；父级仍缺失则其 loadDir 继续置位连环回退直至根（根缺失 = workspace 目录没了，`openView` 同视口早退不成环，`root.exists` 空态接管）。回退后 `lastWsView` 随归桶记录自然归正。

覆盖面：跨空间重放 / 标签恢复 / 运行期外部删除三类幽灵同愈。

附赠消歧：`add_link` 落点缺失报错「目标目录不存在」→「**挂载落点目录不存在**：{rel}」——「目标」在选目标流程里必被误读，写明「落点」（`services/workspace.rs`）。
