# 档案三项收尾：导出点亮 + 筛选档案虚拟类别 + 链接占位摘除（2026-10-11，feat/new-ui）

**背景**：当会话先做了一轮档案模块评估（档案 = 文件夹 + 数据，数据面与文件已同构，缺的全是「文件实体性」能力；完整实体化 = 伤筋动骨不建议）。用户拍板只做其中两项小件——「导出档案」点亮与筛选「档案」虚拟类别；同时定案第三条：档案右键菜单与菜单栏里关于链接的占位功能全部摘除，「留着以后给用户反而误导人」。

## 导出档案点亮

档案右键「导出档案」二级原两项全 disabled 占位（2026-09-05 走查遗留）。后端 `export_folder` 本就无 kind 门禁（任意 folder 通用，档案无子级 = 扁平导出），本轮纯前端接线：「导出到本地磁盘」= `pickExportFolder`，「导出到工作空间」= `exportFolderToWsFlow`（树选择器落点），与文件夹菜单同管线同三项。「导出为素材包」维持 disabled（该业务全局未立项，文件 / 文件夹侧同占位）。树档案节点菜单共用 `archiveCardSpec`（folder.ts treeItemSpec 分流），一处改动双入口同愈。

## 筛选「档案」虚拟类别

筛选一轮（2026-10-09）遗留待定「档案虚拟类别」本轮兑现。口径定案：**扩展名维度新增虚拟类别 `archive`（与 `seq` 序列帧同族）**——

- 未勾选：维持旧口径，筛选激活档案区不出（筛选 = 找文件）；
- 勾选后档案区参与筛选，档案按**可判定维度**做跨维度 AND：属性（archives.props 等值）/ 所在文件夹（档案 parent，folderIds 含后代集同资产位置口径）/ 添加日期（created_at）；
- 资产专属维度（颜色 / 时长 / 比例 / 大小 / 链接状态 / 修改日期）任一激活 = 档案出局（档案无这些数据可判）；
- 资产侧 `archive` 词永不命中（档案不是资产），与真实扩展名混选 = 维度内 OR（档案 ∪ 该扩展名资产）；
- 范围口径不变：档案区仅文件夹视图出（直属）/ 全局 = 全库，快速访问不出。

实现 = search.rs 新增 `SearchFilters::archive_pass`（asset_pass / placement_pass 同族第三判定），档案区段由原 `if !filtering` 改 `if !filtering || archive_category`，区段内 filtering 分支逐档案过 archive_pass；`SearchScope` 签名不变（MCP / 旧调用零改动）。前端 = FloatBarHost extItems 首项恒列加「档案」chip + search store EXT_LABELS 补摘要文案 + preview 展区 demoExtItems 同步。

## 链接占位摘除

档案多位置（PRD 01 边界规则 9，2026-08-24 立项）未实施前，其菜单占位对用户是误导，本轮全摘：

- 档案右键（archiveCardSpec，树档案节点共用）：「档案链接管理 Ctrl+J」disabled 占位、「打开档案链接所在位置」恒空二级、「复制档案 Ctrl+C」disabled 占位——三项删除；「添加文件/档案链接 Ctrl+L」保留（档案作落点收文件链接是既有可用业务）；复制数据 ▸ 复制链接（anikit://folder）保留。
- 菜单栏：`linkEntries()` 三件套（文件/档案链接管理 Ctrl+J / 添加文件/档案链接 Ctrl+L / 打开文件/档案链接所在位置）自 文件▸ 与 整理▸ 两处摘除，函数与孤引用 import 一并清——三项名称均承诺档案能力但实际只对单选素材生效。**文件侧功能零损失**：文件右键菜单（文件链接管理 / 链接位置 linkList 面板）与 Ctrl+J / Ctrl+L 快捷键全部保留。
- useGlobalKeys Ctrl+J 注释同步（文件夹域不响应口径不变）。
