## 杂项 · 子窗口白闪修复（先隐后显，2026-10-02）

**起因**：用户实机录屏报——预览子窗口打开「先加载边框和投影，再出内容」（白色圆角矩形 + 阴影先出现 ~0.5s，内容后才到）；云母时代「都是秒开」。

**根因**：不是云母让子窗口秒开，是云母**遮住了加载期**——`set_effects(Mica)` 顺带把 WebView2 初始化期的默认背景变成深色云母材料，白底从未暴露；10-01 弃云母（fx 拆除）后子窗口不再 set_effects，WebView2 默认白底在「窗口创建 → 前端内容就绪」的窗口期暴露成白闪。主窗口不受影响（tauri.conf backgroundColor #1F1F1F 不透明实底，首帧即深色）。

**修法**（`preview.rs open_child_window`）：builder `.visible(false)` + `.on_page_load(Finished → show + set_focus)`——初始化期窗口根本不可见，内容就绪才出场；预览 / 插件子窗口共用此函数同愈，**降级非透明窗的白底初始化期也一并遮盖**。旧「创建即显即聚焦」行为由 show + set_focus 保持。

**验证**：cargo test / clippy 见提交状态（`on_page_load` 为项目首次使用，编译即 API 验证）。**交实机走查：预览子窗口打开 = 内容直接出场无白闪 / 聚焦正常（点开即可操作）/ 插件子窗口同 / 多次开关与单例复用聚焦**。

**文档**：接口 17_预览 10/11 两条同步先隐后显机制。
