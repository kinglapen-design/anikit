# 2026-10-03_12 ws 视口键清理（scrollPositions / viewRowHeights 僵尸剔除）

## 需求

用户盘点工作空间数据落点时发现：`scrollPositions` / `viewRowHeights`（按视口记滚动位置 / 卡片行高，config.json settings.ui）随浏览过的 ws 目录只增不减，目录删除 / 改名后旧键成僵尸。评估 = 小工作量，当前会话直接做。

## 落地

- **后端**：新命令 `ws_dirs_exist(rels) -> bool[]`——逐键 stat（跟随 `is_dir` || `is_reparse_dir` 断链门 = 活；词法校验拒 `..` / 绝对路径），零 read_dir。**不走 resolve_under 越界闸**（测试当场抓住：未登记 junction 按写操作安全语义 = 越界拒绝，而野门在树里照常显示、视口键是活键——存在性判定只回答「目录在不在」）。
- **前端**：ui store 新 action `pruneWsViewKeys()`——两映射的 `ws:` 键并集（根键恒活除外）批量判定，死键剔除（删除触发既有防抖持久化写回）；命令失败保守不清。App.vue 挂 watch `ws.root`（启动 ensureRoot 完成 / 切空间 reseed 后各跑一轮）。
- **范围收窄说明**：`folder:` 键本轮不清（库文件夹 id 稳定僵尸率低，且 folders 树无「加载完成」标记，空树与未加载不可分易误剔）——留观察项。
