## S1 媒体 http 服务端点（server/media.rs，新文件）

与 MCP 同 axum 实例 / 同端口同生共死（mcp/mod.rs 挂路由）：`GET /item/{id}` 图片字节流——图片扩展名（png/jpg/jpeg/webp/gif/bmp/avif，与 import_task WEBVIEW_DIRECT_EXTS 对齐 + avif）→ origin 原图，其余 → webp 缩略图（thumbAssetId 伴生代理同 views 口径）；库未打开 / ID 不存在 / 读盘失败 = 404 纯文本；`Cache-Control: no-cache`（origin 外部编辑自愈，禁启发式缓存）。`GET /open/{kind}/{id}`（kind = item | folder）——存在性前置校验（404 兜底）→ `emit("media-open", {kind, id})` + 主窗口前置（lib.rs `show_main_window` 托盘同口径）→ 回极简深色页「已在 AniKit 中定位，可关闭本页」。前端 `src/lib/anikitLink.ts`（新文件）：`parseAnikitRef` 归一化解析（双形态，trim 全串匹配）+ `jumpToAnikitRef` 跳转（item → origin placement 视口选中滚进视野，relationOps `jumpToAssetPlacement` 复用；folder → 文件夹视口 + clickFolder）+ `initMediaOpenListener`（App.vue 挂载）。
