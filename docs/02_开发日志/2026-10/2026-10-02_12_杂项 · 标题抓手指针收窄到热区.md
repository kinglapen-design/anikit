# 杂项 · 标题抓手指针收窄到热区（2026-10-02）

## 起因

_11 热区收窄后用户走查再报：抓手指针也该只在真正的热区出现，行空白出抓手看起来误导，「还以为能拖拽」。

## 实现

SectionTitle 的 `cursor: grab` 跟随 hotZone：`bar` 档热区 = 整行（侧栏/详情/弹窗不变），`lead` 档 = 仅 `.lead` 文字区；热区外一律普通指针。选择器 = `.st:not(.hot-lead):hover` + `.st.hot-lead .lead:hover`，零新 token 零新样式档。hover 行现展开钮 / 动作组的稿口径不变。

## 验证

`pnpm typecheck` 0 错。内容容器探针 T7c 改写 + 新增 T7d：**行空白 hover = 展开钮现 + 普通指针（cur=default）/ 文字区 hover = 抓手（cur=grab）全 PASS**，T12b/c/d 点击热区断言同绿；剩 T4/T4b/T4b2 三项详情钮业务漂移（预存在，_11 已挂号）。

中间列表容器标题：空白处移动 = 普通箭头，移到文字/展开钮上 = 抓手；侧栏标题整行抓手照旧。
