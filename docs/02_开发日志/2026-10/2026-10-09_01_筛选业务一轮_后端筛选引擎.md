# 筛选业务一轮：后端筛选引擎落地（2026-10-09）

筛选业务（PRD 03_查找文件 §2，2026-08-31 悬浮栏接入轮留白「条件呈现形态与交叉组合口径随筛选轮定」）立项开工。业务体量大，与用户议定五步分走：**① 口径定案 + 后端筛选引擎全量（本轮）→ ② 前端状态模型 + 统一弹窗壳 + 按钮呈现形态 + chip 类三维度（扩展名 / 链接 / 属性）→ ③ 列表类三维度（文件夹树 / 比例 / 日期）→ ④ 输入类三维度（颜色 / 时长 / 大小）→ ⑤ 菜单占位点亮与走查收尾**。本轮 = ①，纯后端零 UI。

## 口径定案（用户拍板）

**维度内多选 = OR，跨维度 = AND，筛选 × 分词搜索 = AND**（Eagle 同口径；维度内 AND 对扩展名 / 比例等维度无意义）。PRD §2 已回补，并明确「标签」按钮落地名 = 属性（标签体系 2026-08-04 已取消）。

## 架构决策：filters 内嵌 SearchScope

`search_assets` 命令签名不变——`SearchScope` 扩 `filters` 字段（`#[serde(default)]` 空 = 不施加筛选），前端旧调用零改动兼容，MCP `search_assets` 不暴露筛选。query 空 + 有效筛选 = 纯筛选搜索；「空壳」条件（范围双端空 / 日期档位与自定义全空）不算激活。**筛选激活时档案区不出**（筛选 = 找文件，档案实体无维度可判定，本轮定）；回收站视口同口径施加（资产级对 meta、位置级对快照 placements）。位置级维度（所在文件夹 / 链接状态 origin·linked）逐 Placement 判定——同一资产可只中部分位置，与命中键 `assetId|folderId` 模型天然契合。

## 十维度实现口径（细节见接口 11_分词搜索）

颜色 = 主色 RGB 距离 ≤ 64 近似（精确等值几乎永不命中提取色板）；时长 = 帧 / 秒 / 分三单位（帧按素材自身 fps 换算）；属性 = 精确等值不区分大小写；扩展名含 `"seq"` 虚拟类别（`frames_dir_if_sequence` 磁盘口径惰性探盘，与导出 / 重命名同一判定）；文件夹 = Placement 直属；比例 = 横 / 方（1/1.05..=1.05）/ 竖三档 + 自定义 `w:h`（1% 容差）；链接状态四态 = origin / linked / thumb（伴生缩略图引用 thumb_asset_id）/ none（仅 1 条活位置）；大小 = 字节范围；日期 = 当天 / 昨天 / 近 7 / 近 30 / 近 365 / 更早六档 + 自定义年月日任意组合。所有「目标值全无法解析」的维度一律视为不参与，防垃圾输入清空结果。

## 遗留待定（随②③④轮逐个问用户）

条件选中后按钮呈现形态（PRD 留白，9 子稿均无 prose）；链接状态「缩略图」语义候选 = thumb_asset_id 工程侧（本轮实现）vs hidden 缩略图资产侧（后者要破例放开 hidden 不命中口径，前端视图层也得跟着改）；文件夹筛选含不含后代；扩展名「档案」虚拟类别（跨实体，未实现）；弹窗水平锚点 / 关闭时机 / 四稿无清除钮的补齐。
