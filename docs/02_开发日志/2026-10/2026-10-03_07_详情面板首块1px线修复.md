# 2026-10-03_07 杂项 · 详情面板首块 1px 线修复

## 需求

用户实机报：ws 文件夹详情（WsDetail 无缩略图形态）输入框区块的 `border-top` 在无缩略图时直接贴面板顶，与窗口控制区衔接多出一条 1px 线。

## 根因与修法

详情区块公共壳的 `border-top` 语义 = 与上一区块的分隔线；FolderDetail 文件夹形态首块是缩略图区块（`.fd-thumb` 稿注「无 border-top——首块」），输入框区块的 border-top 是正确分隔。但两个无缩略图形态里输入框区块成了面板首块，border-top 贴顶即多线：

- **WsDetail**（ws 文件 / 文件夹详情，无缩略图形态恒以 `.wd-inputs` 为首块）：直接删 `.wd-inputs` 的 `border-top`（首块无 border-top，FolderDetail .fd-thumb 同口径）。
- **FolderDetail quick 形态**（快速访问视口回退，同根因同类——`v-if="folder"` 摘掉缩略图块后 `.fd-inputs` 成首块）：同报同修，quick 形态加 `.fd-first` 去 border-top；文件夹形态保留（与缩略图区块的分隔线不动）。

## 验证

`pnpm typecheck` 0 错。纯样式删线，待实机走查：ws 文件 / 文件夹详情顶部衔接、快速访问视口（全部 / 未分类等）回退形态顶部、库文件夹详情分隔线不回归。
