## 二轮修订口径

- **行 / 组卡片化分层**：链进来每门一张行卡、链出去每文件夹一张组卡——g4 底 + 1px g5 描边 + 圆角 8（ni-card 口径升一档：壳 g3 上卡片 g4，「颜色层级包一下」）；行卡 hover g5 底 g6 描边；卡组间 gap 8。断链 = **整卡** dimmed 0.4 置灰 + 名后 warning 徽章（§65 同档）。
- **操作组 = 污染文件 item 同款 hover 滑入**（items.css `ni-hover` / `ni-slide` 推挤式滑入机制直接复用）：常态零宽不占位，hover 从右缘滑入；钮 = 18 盒常态四级 hover 二级（`.act` 同款）。行卡三钮（重新定位 / 显示 / 删除链接）；链出去子行两钮（显示 / 删除入口）；组卡首行「添加入口」滑入（组卡 hover 直达子选择器只出首行钮，不波及子行各自滑入组）。
- **组卡内**：首行 36（文件夹图标 + 名，底 1px g5 与子行分隔）+ 入口子行 30（缩进 26 对齐组首行名，hover g5 底圆角 6 小底 = 嵌套层级）；门没了子行 = 置灰 + warning + 只留「删除记录」钮。
- **添加行整行按钮化**（用户「按钮要有按钮的样子」）：40 高 g4 底圆角 8 整行可点，hover g5 + 文字升一级——取代一轮的裸文字行。
- **两区块功能分界**：父 gap 24 + 区块二顶 1px g5 分隔线 + 线后 24 留白（合计 24+1+24）；区块内 = 标题 → 卡组 → 添加行 gap 8。
- 壳 640 / 无底部按钮行即时生效 / 空态引导文案——一轮口径沿。
