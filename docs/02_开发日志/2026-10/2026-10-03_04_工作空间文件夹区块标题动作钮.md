# 2026-10-03_04 工作空间「文件夹」区块标题动作钮

## 需求

用户截图定案：工作空间侧栏「文件夹 / N」区块标题补上库式区块头同款悬停动作钮——「+」= 新建文件夹，「⋯」菜单 = 添加链接文件夹、工作空间管理面板。

## 落地（纯前端两文件，零新组件零新样式）

**`WorkspaceTree.vue`**：「文件夹」区块的 SectionTitle 摘掉 `:actions="false"`（「常用」区块保持无动作钮不动），接 `@add` / `@more`。+ 钮 = 根目录新建文件夹，走右键菜单同款 `createAndRename("")`（先建后命名：当前视口正是根视口时新卡片进行内命名态）；区块折叠时先 `treeOpen = true` 强制展开让新行可见——LibraryView.onAddFolder 的 `openBlock` 同先例。⋯ 钮 = 指针位弹出上下文菜单（库区块头 onBlockMenu 同口径）。

**`menuSpecs/workspace.ts`**：`createAndRename` 由私有改 export（区块头 + 钮复用同径，rel "" = 根目录）；新增 `wsFolderSectionSpec()` 两项——「添加链接文件夹…」复用已 export 的 `addLinkFlow("")`（挂根，管理工作空间面板添加钮同径），「管理工作空间」复用应用菜单同入口 `ui.wsManageOpen = true`。

动作组样式、hover 现身、热区外扩全部来自 SectionTitle 既有实现（库区块头已验证），未动组件本身；预览页 SectionTitle 展区本就有 actions 演示，无需新增陈列。
