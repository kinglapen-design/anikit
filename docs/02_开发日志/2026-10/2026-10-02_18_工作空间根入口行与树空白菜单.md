# 工作空间根入口行与树空白菜单（2026-10-02）

链接走查二连报：根目录无法「添加链接文件夹…」——侧栏没有代表根的入口行（库有「全部」类根入口），树空白处右键无菜单，中间面板没有一个可主动打开的根视口，根目录右键菜单无处触发。

## 诊断与定案

步骤 3 曾废除根行「工作空间」（合成父级与子级同缩进撞兄弟），彼时快速入口容器还不存在，留下的空白是：根视口只能切分段时被动恢复（`lastWsView`）或历史后退到达，没有任何**主动**入口；`_17` 幽灵修复后根视口更不该靠「事故」到达。用户报的正是这个洞。

解法不动旧坑：**根入口行回籍快速入口容器**——入口行是快捷入口不是树的合成父级，与子级无缩进关系，旧「撞兄弟」问题天然不成立（容器注释本就预留「后续入口行直接加进容器」，回收站是首行，这是第二行）。

## 落地（纯前端 WorkspaceTree.vue 一处）

- **根入口行**：容器首行 = `TreeRowItem quick + workspace 图标 + 「工作空间」`（名称与根标签标题同，`content.viewTitle` 口径），回收站行居次（10-01「回收站最上方」是对常用 / 文件夹区块而言，根入口先之——观感不合一句话可调）。点击 = `openView("ws:")` 根视口；数量 = 根目录直接文件数（pin 行同口径）；选中态 = `sidebarSelected === "ws:"`。
- **根行右键 = 根空白菜单** `wsBlankSpec("")`（新建文件夹 / 添加链接文件夹… / 粘贴 / 在资源管理器中显示 / 系统菜单（目录背景版）/ 刷新——四项尾部动作对空 rel 已逐一核实兼容）。
- **树容器空白右键同出根空白菜单**：根层容器 `@contextmenu`，非 `.tree-item` 落点才触发（行自身 `.stop` 拦截、回收站行落空不出菜单），递归子层不响应。

零后端改动、零新组件、零新 token / 图标（workspace 图标 = 分段控制器同件），口径速查无新增样式可回补。
