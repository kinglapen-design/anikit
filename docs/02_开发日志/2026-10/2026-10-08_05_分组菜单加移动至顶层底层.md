# 分组菜单加「移动至顶层 / 移动至底层」（2026-10-08）

用户提：组很多的时候靠「上移 / 下移」一层层挪到顶层太麻烦，分组标题 ⋯ 菜单要有直达两端的项。

## 改动

`src/lib/menuSpecs/groupHeader.ts` 一处（12 稿分组标题菜单）：

- 排序组扩为四件，按设计工具图层序惯例排——**移动至顶层 / 上移 / 下移 / 移动至底层**；新两项纯文字无尾图标（图标库无对应件，与「新建分组 / 编辑分组 / 删除」同用默认形态，不自创图标）。
- 行为 = 摘出后 unshift 队首 / push 队尾，走同一 `commit`（`set_folder_groups` 单撤销步，与上移下移同口径）；已在顶 / 底时置灰禁用（disabled 守卫 + action 内双闸，照既有项写法）。
- 未分组简化菜单不变（未分组不参与组序）。

## 验证

`pnpm typecheck` 0 错。待实机走查：中间组一键置顶 / 置底、首组「移动至顶层」与末组「移动至底层」置灰、操作后 Ctrl+Z 单步撤销。
