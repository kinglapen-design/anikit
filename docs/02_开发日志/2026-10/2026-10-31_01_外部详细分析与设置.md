# 外部详细分析与设置

## 目标与边界

本轮在本地 CLIP 基础画面检索之外接入外部详细分析。AniKit 只提供 OpenAI 兼容服务与 Ollama 的接口，不安装、不启动、不内置 LLM、Ollama、Python / PyTorch 或 CUDA。外部服务只负责补充描述、动作和候选事件；生成文本仍由本地同一文本塔编码，后续检索离线进行。

基础模型固定为多语文本塔与配套 CLIP ViT-B/32 图像塔，512 维、FP32。CPU 默认，DirectML 可选；初始化失败必须显示真实 CPU 回退，不能伪报 GPU。独立 `semantic-worker.exe` 承担推理，主窗口不加载分析模型。模型采用受管离线包，没有实现公开下载器。

## 外部服务与数据契约

OpenAI 兼容服务走 `/models` 和 `/chat/completions`，Ollama 走 `/api/tags` 和 `/api/chat`。请求使用真实时间戳的稀疏采样帧，最多 24 张、长边不超过 768；不把采样描述包装成完整连续视频理解。endpoint 仅允许 HTTPS，HTTP 只给本机回环地址，禁止重定向。API key 只进入 Windows 钥匙串，配置、日志与回包不回显。

外部返回保存 description、events、provider、model、prompt 版本、source JSON 和证据帧时间。observed 只表示可观察连续事件，hypothesis 只表示不确定候选因果，不能把先后关系写成确定因果。`analysis_tasks.mode` 区分 basic / detailed，恢复与重试保持启动时模式和 provider 配置。详细任务在 HTTP 前检查模型 revision、分析版本、状态和源指纹，媒体总时长优先读取 `AssetMeta.duration`，不能用最后一个采样区间冒充整段时长。

设置面板复用「通用」页，加入设备、模型目录、运行环境、provider、endpoint、模型、超时、密钥和连接测试。素材右键「AI 工具集」同时提供基础分析和外部详细分析，没有新增导航分类或自创面板样式。

## 验证

- 真实 GIF 经基础分析后，进入本机 OpenAI 兼容假服务，生成 observed / hypothesis，保存证据时间，再由本地文本塔完成中文离线检索；基础视觉向量不变，陈旧指纹拒绝调用。
- OpenAI / Ollama 请求格式、`response_format` 明确不支持时只重试一次、鉴权与模型缺失、不兼容接口均有回归测试。dummy Windows 凭据写入、读取、删除通过，未使用真实密钥或外部额度。
- 语义模块 44 项检查中 39 项通过、5 项按需 ignored；全量后端最终 703 项通过、0 失败。Clippy、前端 typecheck、构建和组件台账通过。

本轮没有使用用户真实 provider 做联网验收；公开模型下载入口也仍未定稿，发布形态是受管离线模型包。
