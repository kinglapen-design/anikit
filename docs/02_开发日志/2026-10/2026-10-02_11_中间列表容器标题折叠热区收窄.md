# 中间列表容器标题折叠热区收窄（2026-10-02）

## 起因

用户实机走查报：标题栏折叠热区覆盖整行，在侧边栏还好，但中间列表容器的分组标题（满宽横条、右侧大片空白）特别容易误触折叠——点空白想落点/起手框选就直接把组折了。定案：热区收到文字这一块。

## 定案与实现

SectionTitle 新增 `hotZone: "bar" | "lead"`（默认 `bar`）：根节点点击闸 `hotZone === 'bar'`、`.lead` 点击闸 `hotZone === 'lead'`，展开钮自带 `@click.stop` 两档不重复触发。**中间列表容器全部标题一律 `lead`**：FolderStrip「文件夹」、ArchiveStrip「档案」、InboxDiskSection「工程文件」、AssetGrid「内容/已导入」+ 分组标题（原位 + sticky 两层）；侧栏（LibraryView / WorkspaceTree）、右栏详情（TabLinks）、移动弹窗（MovePanel）维持 `bar` 不变（用户明确侧边栏还好）。

视觉口径不动：hover 行现展开钮/动作组、抓手指针 cursor: grab 维持稿口径（§14）——收窄的只是点击行为；行空白点击 = 落空 no-op，不下发框选/取消选中（不做行为扩张）。

## 验证

`pnpm typecheck` 0 错。内容容器探针跑通：**T12b 点分组标题行空白不折叠（before=True after=True）/ T12c 点文字折叠 / T12d 点展开钮再展开全 PASS**，T7c 抓手指针旧断言仍绿。

探针顺手修了两处控件族换代漂移（同根因一批）：`.app-switch`→`.kit-switch`（SwitchButton）、`.app-seg`→`.seg .seg-item`（SegmentedControl）——修前 T4c/T12 起全链红且 baseline（撤本轮改动）同证红 = 漂移预存在，与本功能无关；修后探针 54 PASS / 3 FAIL（T4/T4b/T4b2 = 详情钮 4→5 钮业务漂移，旧「插件恒禁用/无第五钮」口径已死，超本轮修复预算，头部注释挂号待重推）。

## 交实机走查

分组标题/内容/文件夹/档案/工程文件标题：点右侧空白不折叠、点文字/展开钮折叠；侧栏与详情面板标题整行折叠照旧。

## 文档

口径速查新立 §63（热区收窄定案）+ §14 SectionTitle 条目回补 hotZone 口径；预览页分组标题展区补 hot-zone="lead" 演示格。
