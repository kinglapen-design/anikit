# 管理工作空间面板 · 设计稿提案（preview 陈列）

> 2026-10-02 · 第二十七轮。用户要「管理工作空间」面板（菜单 → 仓库 → 管理工作空间，现为禁用占位）：总览**链接进来的**（方向 b）与**链出去的**（方向 a′）文件夹、一个文件夹链出去了哪些路径、面板内可添加两种链接。用户定「还不知道怎么设计，先在 design system 里做样式看下」——本轮 = 纯 preview 样式稿（mock 数据，不接生产），用户实机看稿后定稿。

## 设计方案（稿 = PreviewModals 展区「管理工作空间」组，正常态 + 空态双陈列）

- **壳**：BaseModal framed **640**（分组管理先例宽——路径长文本需要宽度）；无底部按钮行，**即时生效**（§61 信息查看管理面板同口径——管理操作直发生，删除走 confirmPrompt 警告确认）。
- **结构 = 双区块一屏总览**（不用 tab——两组数据量都不大，用户要的就是一屏看全链接全景）：SectionTitle block「链接进来的文件夹 / N」「链出去的文件夹 / N」+ 区块底添加行（add-small 图标 + 文字，hover 升档 + g4 底）。
- **链进来行**（DetailBlockRow 52 双行族）：链接徽章 18 + 门名（13/18 一级，断链名后 warning-small 14 + 整行 dimmed 0.4 置灰，§65 同档）/ 「← 目标路径」（12/16 三级截断 + title 全显）+ 行尾三操作（重新定位 / 在资源管理器中显示 / 删除链接，IconButton bare sm）。
- **链出去组**（一对多展开）：组首行 40（文件夹图标 18 + 名 + 行尾「添加入口路径…」钮）+ 入口子行 32 缩进 26（对齐组首行名称；链接图标 14 + 入口绝对路径 12/16 二级截断 + 显示 / 删除钮）；**门没了态** = 路径置灰 + warning 徽章 + 操作只留「删除记录」。
- **空态**：区块无行 = 引导文案一行（12/16 三级，指路右键菜单入口），添加行照常。

## 提案待定点（交用户拍板）

1. **链出去要显示 ⇒ 登记口径升级**：本轮「只管创建不管存续不登记」要改为 `workspace.json` 记 `portals` 台账（rel + 外部入口路径，扁平多条）——创建时登记、打开面板时对账（门在不在 / 指向对不对），门没了只标记不剔除可手删；**仍不做自动管理**（不跟踪、不自愈）。
2. 添加链进来 = 挂载到工作空间**根目录**（面板无目录上下文；换位置走后补拖拽移动）。
3. 「链出去新文件夹…」从零发起需两步选择（WS 内选文件夹 + 选落点）——或保持右键「在外部位置创建链接…」发起、面板只管总览与追加路径。
4. 删除语义：删除链接 / 删除入口 = 门进系统回收站（可找回）+ 剔登记，confirmPrompt 警告确认。
