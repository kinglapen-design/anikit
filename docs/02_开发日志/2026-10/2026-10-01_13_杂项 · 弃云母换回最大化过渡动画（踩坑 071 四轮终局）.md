## 杂项 · 弃云母换回最大化过渡动画（踩坑 071 四轮终局，2026-10-01）

**起因**：用户问「把云母删了，最大化的动画过渡是不是就可以回来了」。复盘代码与踩坑 071 全录后定位真凶：动画丢失**不是云母本身**——09-08 当天的记录里「最大化过渡动画里同样闪按钮」证明云母 + 玻璃全在时动画还在；杀动画的是同日三轮终局的「`WM_WINDOWPOSCHANGING` 动画前摘 `WS_CAPTION`」——DWM 对无 caption 窗口不播最大化/还原过渡动画（Electron/VSCode 无边框窗口有动画，靠的正是全程保留 caption）。摘 caption 本来是为杀 DWM 原生按钮，按钮死了，动画成了没被察觉的连带伤亡（当日复验清单只盯按钮）。

**定案（用户）**：动画优先于云母——删云母，把动画加回来。

**机制链（为什么删云母能解开死结）**：DWM 原生按钮 = caption 样式 + 整窗玻璃画布缺一不可（071 一轮实证：最大化态撤玻璃 → 稳态按钮没了；「动画期照闪」是预撤时机够不着动画期绘制依据，不是依附关系否证——三轮「按钮只依附 caption」的定性被二轮混乱实机状态污染，四轮修正）。玻璃的唯一存在理由是云母载体。所以撤云母 → 撤玻璃 → caption 无需再摘 → **动画回来 + 按钮画不出**，兼得。这正是 Electron 无边框的既有组合（保 caption + NCCALCSIZE 归零 + 无玻璃），历轮恰好从未测过。

**改动**：

- `adapters/window_fx.rs` 重写：`apply` 恒 solid（不再 `set_effects(Mica)`，主窗口/子窗口共用调用点不动）；`extend_frame`（整窗玻璃）、`sync_caption_for_state`（摘 caption）、守卫三挂点与 `WM_GETMINMAXINFO` rcWork 约束（079 衍生修复，带 caption 后 Windows 默认最大化矩形本即 rcWork）、`detect_mode` 版本判定全删；守卫只留 `WM_NCACTIVATE` 失焦欺骗（失焦阴影不收小）。
- `lib.rs`：撤 `extend_frame` / `paint_border` 主窗口调用，注释更新。
- `tauri.conf.json`：`backgroundColor` `#00000000` → `#1F1F1F`（不透明实底，不再需 WebView2 透明透云母，首帧即实色）。
- **边框连带收口**：实色单态下 DWM 染色线与前端自绘线并集必错位双层（063 实测四边 3vs2、角弧异径）——`set_main_border_picking` 改 no-op，主窗口边框/品牌框归前端 `::before`/`::after` 自绘独存（25H2 起 DWM 默认边框本就不画，不染 = 干净单画）；子窗口建窗 DWM 染色保留（子窗口前端不自绘）。
- 前端零行为改动：`get_window_fx_mode` 恒 solid → `.window` 基态实色即终态（`fx-mica` CSS 暂留 dead path，实机定案后整层清理）；App.vue / base.css 顶部过时注释顺手更新。

**验证**：`cargo test` 556 绿 / `cargo clippy` 净 / `pnpm typecheck` 0 错。

**交实机复验清单**：① 最大化/还原过渡动画回来（四条路径：自定义按钮 / 双击标题栏 / 拖顶 snap / Win+↑）；② 最大化稳态与动画全程无 DWM 原生按钮穿帮（核心赌注：无玻璃画布）；③ 圆角 / 阴影 / 前端 1px #333 边框如常，无双层框、无白边环、角部无透底；④ 失焦阴影不收小（欺骗仍在）；⑤ 启动即最大化恢复；⑥ 选择模式 picking 品牌框（前端 ::after 独画）；⑦ 预览/插件子窗口打开观感与首帧（无 Mica 后 webview 加载期透明窗是否闪洞）；⑧ 进出全屏、手动拉满屏。若②按钮仍在（071 三轮定性侥幸成立），回退 = git revert 本次改动。
