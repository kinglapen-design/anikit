## 杂项 · 窗口边框回滚 DWM 染色独存（前端自绘双层修复，2026-10-02）

**起因**：用户实机走查——窗口边框看起来像 2px，指出「边框和投影交给 DWM 就行」。

**根因**（我方 10-01 弃云母轮的误判）：当时按 09-29「Win11 25H2 DWM 默认边框停画」的实证把主窗口 DWM 染色全撤、边框改前端 `::before`/`::after` 自绘——但那条实证是在**整窗玻璃 -1 + 云母**场景下做的；10-01 撤玻璃转不透明实底后，DWM **恢复画默认边框**，与前端自绘 1px 叠成 2px 双层。教训 = 窗口效果结论不可跨「有/无玻璃」场景外推。

**修法（用户定案落地）**：边框/品牌框全交 DWM，前端零绘制——

- `settings.rs` `set_main_border_picking` 恢复染色功能（picking 品牌色 #0F89EC ↔ 常态 #333，09-29 版本回还，no-op 撤销）；
- `lib.rs` 启动恢复 `paint_border(hwnd)` 显式染 #333（25H2 默认停画，显式染色全版本一致画线）；
- `App.vue` 前端自绘体系整块删除（`.window::before` 常态 1px、`.window.picking::after` 品牌框及 fx-mica/maximized/picking 联动规则），顶部注释同步——063「DWM 线与 CSS 线并集必双层」与本次实机互为印证，纯 DWM = 唯一均匀解；
- 子窗口不动（建窗 DWM 染色一直在，前端本就不自绘，无双层）。

**验证**：`pnpm typecheck` 0 错；cargo test / clippy 见提交状态。**交实机走查：边框单圈 1px 观感（常态 #333）/ 圆角处贴边 / picking 进出品牌色切换 / 最大化无边框 / 阴影如常**。

**文档**：口径速查 §19 边框口径回滚为「DWM 染色线独存」并记场景外推教训。
