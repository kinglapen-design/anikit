# 杂项 · 列表模式钉顶列头与 sticky 分组标题间漏缝遮盖（2026-10-02）

## 起因

用户实机走查报：列表模式下钉顶列头和停留顶部的分组标题没有紧贴，中间漏出滚动行（截图行从缝间探出）。根因 = 钉顶列头 34 高（占 0–34），sticky 分组标题 top = listExtra = 40，中间 6px 行距缝（列头与列表间距）无任何遮盖。

## 修法

`.sticky-group-header` 补 `box-shadow: 0 -6px 0 var(--n-g1)`（零模糊同色阴影向上延 6px，§7 口径）——遮盖只能挂在 sticky 上：缝在没有 sticky 时是正常内容区（行从钉顶列头下滚向原位组标题，必须可见），恒遮盖会造出一条死空带。阴影随让位 shift 位移同上移，几何核过 shift ∈ [-26,0] 全程 [34,66] 连续覆盖，上移出列头底缘的部分被钉顶列头（同 z5、DOM 序在后）盖住。标题文本站位不动、grid 模式（listExtra=0）阴影出视口被裁无影响。顺手修正模板注释过期值（46+6 → 34+6）。

## 验证

`pnpm typecheck` 0 错；内容容器探针回归同绿（仅预存在 T4 三项）。sticky 在桩环境不激活（f1 内容不足一屏无法滚动），**交实机走查：列表模式 + 分组滚动——钉顶列头与 sticky 分组标题间不再漏行、让位顶走动画过程缝也不漏**。

## 文档

口径速查 §22 骨架条目回补。
