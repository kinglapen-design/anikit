# 2026-10-16_02 扫描文件/档案链接（待办 2026-08-13 兑现）

**背景**：「扫描文件/档案链接」自 2.7 二轮（2026-08-13）起在四处菜单 disabled 占位（菜单栏 查找▸ / 新增菜单 / 快速访问空白 / 回收站空白），35 稿注释与 PRD 03-03 末条早有复用口径，一直「随该业务单独立项」。1.0 收尾期用户盘点扫描族缺口（有扫描重复文件、缺扫描链接文件），本轮立项点亮。

## 口径定案（PRD 03_查找文件 §04 新立）

- **全库单范围**（菜单项无二级，与重复扫描三范围不同）：`folders.items` 纯内存聚合，有 ≥1 条链接 Placement（origin=false）的资产成组；不扫磁盘、不重算任何值。回收站快照不参与；档案多位置未立项（10-11 占位摘除），结果天然只含文件链接，菜单名「文件/档案链接」不动。
- **组行 = 首列原始文件卡 + 其后全部链接卡**（35 稿排列口径）：origin Placement 决定首列显示名与所在文件夹（无活 origin——在回收站——取第一条 Placement 兜底，origin_placement 同口径）；链接卡 = 链接显示名 + 所在文件夹简介行 + 链接徽章（`linked-file-badge`）。
- **复选语义与重复扫描相反**：复选从组头挪到链接卡 = **删除标记**（整卡可点 + 复选框右上 6/6 与格式徽标镜像），选中卡压暗 30%（透明度 §5 同档，语义 = 将被删除），**默认全不选**用户单个选中；原始文件卡恒留不可选（删原始文件走卡片菜单，不在此列）。
- **单屏无确认屏**：删链接是记录级操作——选中链接一次 `delete_placements`（recycle 语义，PlacementRef 携带 name 显示名精确到行，2026-10-11 选择域配套口径），进回收站可还原、undo 一步整体撤销，不需要重复扫描那种合并前确认第二屏。
- 组排序 = 链接数降序（清理视角多链优先），平手按首列显示名再按 assetId（确定性）；组内链接按所在文件夹名 → 显示名。无结果不弹窗，toast「未发现链接文件」（重复扫描同口径）。

## 实现

- 后端 `services/scan.rs` 加 `scan_links`：`LinkGroupView { asset: DupAssetView, links: [LinkPlacementView { folderId, folderName, name }] }`——asset 直接复用重复扫描的 DupAssetView 全字段（首列卡数据源零新结构）；`commands/scan.rs` 同名命令注册（只读不走 undo）。测试 +3：成组与首列 origin / 无活 origin 兜底第一条 + root = 未分类 / 组间链接数降序。
- 前端 `lib/linkScanOps.ts`：模块单例态（groups + busy 闸）+ openLinkScan（空结果 toast）/ removeLinkGroup（行尾红 X 纯前端摘组）/ closeLinkScan / confirmDeleteLinks（收集 checked 链接组 PlacementRef 一次 delete_placements + content.refresh + 成果 toast 带音），口径全对齐 dupScanOps。
- 新组件 `LinkScanDialog.vue`（714 单屏 BaseModal framed，次左主右 取消 / 删除链接文件）+ `LinkScanGroupRow.vue`；`DupScanCard.vue` 扩展可选 props（badge "link" / nameOverride / metaOverride / selectable / selected），重复扫描既有调用零改动。
- **样式抽象**：两弹窗的壳覆盖 / 组行 / 卡片横排 / 底部计数按钮行完全同构，抽 `src/components/scanDialog.css` 共享件（`scd-` 前缀防撞——`.scroll-wrap` 等通用名是各弹窗 scoped 自有件勿全局化；壳覆盖例外走 `.scan-dialog .bm-modal` 全局后代选择器），DupScanDialog / DupScanGroupRow 同步改吃共享件，DupScanDialog scoped 只剩屏 2 双栏特有样式。
- 菜单 `scanEntries()` 一处点亮四处同生效（查找▸ / 新增 / 快速访问空白 / 回收站空白）；App.vue 挂载。
