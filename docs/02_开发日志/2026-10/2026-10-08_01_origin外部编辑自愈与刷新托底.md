# 2026-10-08_01 origin 外部编辑自愈与「刷新缩略图」全格式托底（哈希漂移治理第 2 层）

> 用户实机报：新建空 md → Typora 写内容后回 APP，文本卡缩略图不更新、详情文件大小恒 0 B，右键「刷新缩略图」报「该格式暂不支持刷新缩略图」；用户记得"好像做过外部编辑后更新"——实为 [2026-09-22 哈希漂移治理三层方案](../../03_项目进度/待办细节清单/2026-09-22.md)的第 2 层（读取触点自愈），当时只落了第 1 层（APP 内编辑回写 hash，[日志 2026-09-22_05](../2026-09/2026-09-22_05_writeText回写hash.md)），第 2 层一直在待办。本轮落地第 2 层 + 把「刷新缩略图」扩展为全格式手动托底。

## 根因

文本卡「缩略图」不是静态图，是前端实时渲染的文本预览（TextContent.vue，cardTextFor 懒拉正文，按 modifiedAt 作版本戳缓存）。外部编辑不改库内任何 metadata——size / modifiedAt 停在建档时刻 → 卡片正文缓存不失效、尺寸标签恒 0 B。而「刷新缩略图」后端走 `thumbnail::generate`，只认图片 / PSD / SVG / 视频 / 音频，文本格式返回 None 直接报错。

## 落地

新服务模块 `services/origin_sync.rs`，两条路径：

**自愈（自动）**：读取触点 `get_asset_detail` / `read_text_asset` / `read_docx_asset` 挂 `heal_if_drifted`——stat 检测 origin size 不符或文件 mtime 晚于 modifiedAt（秒级精度：modifiedAt 本就秒级落盘；同秒编辑漏检由手动托底兜住）→ 回写 size / hash / 宽高 + 非音视频重生成内容缩略图 + modifiedAt 刷新（先落盘后同步索引，规范第 7 条；与 ensure_asset_colors 同属"读命令带维护性写副作用"先例，不进撤销、失败记日志不阻断读取）。回写后广播 `asset-origin-healed { assetId, size, modifiedAt }`，前端 content store 监听同步该资产全部 PlacementView——卡片尺寸标签即时正确，文本卡版本戳失效自动重拉。hash 重算有 64MB 上限（读触点同步执行容不下大文件哈希，超出维持旧 hash 记日志）；音视频缩略图自愈不重生成（ffprobe 重活不进读路径），靠手动刷新托底。序列帧（size = 全帧合计）与虚拟片段（origin 无实体）不适用，直接跳过。

**手动托底**：`refresh_thumbnail` 扩展——无条件重算 hash（用户显式触发，真值语义）+ 全格式重跑导入同管线缩略图（含音视频首帧 / 波形）；**文本等无内容缩略图格式不再报"不支持"**：数据照刷、缩略图回退格式图标（meta.thumbnail 置 None，自定义缩略图一并回退清理——与图片格式"刷新回退 origin 默认图"同语义），返回 `{ thumbPath: string | null, size, modifiedAt }`，前端吐司分流「已刷新缩略图 / 已更新文件数据」。序列帧 / 虚拟片段 / origin 缺失仍报「源文件缺失」（旧口径不变）。get_asset_detail 随自愈改 async（文件 IO 走线程池，规范第 2 条；MCP 的 asset_detail / read_text_asset 维持纯读不自愈，同懒回填先例）。

## 验证

origin_sync 新增 8 测（漂移检 size / mtime 两路、无漂移不动、缺失不报警、手动刷新文本回退格式图标 + 清旧缩略图文件、手动无条件重算 hash——模拟自愈漏检场景、图片重生成、缺失报错）；asset_menu 既有刷新测试适配新返回类型。`cargo test` 588 绿（+8）、`pnpm typecheck` 0 错。待实机走查：Typora 回写后卡片 / 详情自动更新、「刷新缩略图」对 md 的吐司文案、图片外部覆盖后自愈重生成缩略图。

## 边界

自愈检测是启发式（size + mtime 秒级）：同秒同长度覆写漏检，手动「刷新缩略图」= 永远正确的最终托底。第 3 层（查重弹窗提示 + 扫重 size 校验）仍在待办未动。接口文档同步：12_档案文件夹（get_asset_detail 自愈 + async 化）、18_音视频播放与逐帧笔记（两读取触点）、16_右键菜单配套/03_缩略图三件套（refresh_thumbnail 新契约）。
