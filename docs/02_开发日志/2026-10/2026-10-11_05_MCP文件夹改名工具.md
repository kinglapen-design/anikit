# 2026-10-11_05 MCP 文件夹改名工具（rename_folders）

## 背景与定案

用户随 04 轮（文件夹批量重命名 APP 侧落地）定：MCP 工具把文件夹改名和批量改名加进去。形态照 `rename_placements` 既有先例——**单工具 `rename_folders`，单个文件夹改名 = 1 项数组**（MCP 工具面不收单条 / 批量双工具，rename_placements 同款口径），PRD 08-06 立为**五批写工具（一个）**，工具面 20 → 21（只读 8 + 写 13）。

## 实现

纯接线零新业务逻辑：04 轮的 `commands::operations::rename_folders` 命令体整段抽出为 `rename_folders_op`（pub(crate)，锁 library → 锁 undo → 单撤销步，与 rename_placements_op 同范式），命令换薄壳转发；MCP 侧 `tools/write.rs` 加工具（与 rename_placements 同文件）——`RenameFolderItemParams { folderId, newName }`（folderId 吃 anikit:// 链接形态，de_ref_id 归一化）+ write_gate 门禁 + 成功广播 `mcp-library-changed` + 回包 `BatchRenameReport { renamed, failed }`。语义与 APP 完全一致：仅改数据不动磁盘、同名不拦截、失败项（非法名 / 陈旧 id）跳过进 failed 不整体回滚、进撤销。

牵连面同步：插件面板 MCP 详情窗功能列表硬编码计数 12 → 13 + 名单加「文件夹改名」；PRD 08-06 五批段 + 阶段表 ⑧（余量批顺移 ⑨）；接口 MCP通道 / 使用指南计数与工具表（含「进撤销 11 个」清单、省 token 20 → 21）。
