待办细节清单 2026-10-01 B 节方向 b 兑现（[2026-10-01_11](2026-10-01_11_工作空间链接方向定案.md) 定案轮拍板「下会话开工」）：外部文件夹以 NTFS junction 挂进工作空间子目录，散落各处的现有文件夹不搬迁即纳入一处视野。定案出处 = PRD `01_资源与数据/02_索引式工作空间.md`「外部文件夹链接纳入」节 + 待办 2026-10-01 B 节方案全文；方向 a′（真 WS 留库内 + 外部入口 junction）保留为推荐用法不变，方向 a 维持砍掉。

## Spike 三结论（安全红线与监听实测）

`src-tauri/src/adapters/junction.rs` 三个 #[ignore] 测试实跑验证（可 `cargo test spike -- --ignored` 复跑）：

1. **红线 a 成立**：SHFileOperationW 回收站删 junction **只删链接本体**，目标内容完好；断链 junction 回收站删除同样成功——「移除链接」敢直接走系统回收站。
2. **红线 b 成立**：`fs::rename` 只动门（改名后仍指向原目标）——重命名 / 移动链接条目无需特殊分支。
3. **RDC 递归监听不穿透 junction**：主监听收不到链接子树任何事件（3 秒窗口 0 条）——每条链接目标必须单独补监听（踩坑 099）。

## 后端

新适配器 `adapters/junction.rs` 四件套：`is_reparse_dir`（纯 std 属性位）/ `create`（DeviceIoControl FSCTL_SET_REPARSE_POINT 手拼 REPARSE_DATA_BUFFER）/ `read_target`（断链也可读回原指向，重指与登记修复的凭据）/ `remove`（RemoveDirectoryW 只删门）；windows crate 补 feature Win32_System_IO + Win32_System_Ioctl。

**登记清单**：`.anikit/workspace.json` ViewState 扩 `links: [{rel, target}]`（target = canonicalize 绝对路径），写点换原子写（write_text_atomic）；读清单 = 路径闸放行与 watcher 补监听的唯一凭据。

**路径闸 `resolve_under` 口径**：词法过滤照旧 → canonicalize 落 root 内照旧 → 越界时命中登记链接（本身或子树）且落在目标内 → 返回**词法**门路径（fs 操作打在 junction 本体而非目标上——重命名 / 移动 / 删除「门」本身才安全）；断链登记链接同样返回词法 Ok（read_dir 自然失败降级空列表）。`is_under` / `rel_of` 词法优先——链接内文件缓存键 = 链接 rel，缓存落空间内 `.anikit`，链接目标保持干净。未登记 junction 仍越界拒绝；嵌套 junction（链接里再有链接指向目标外）拒绝。

**列举与登记**：WsEntry 新增 `isLink`（目录 reparse point，断链也 true）/ `linkOk`（目标可达，非链接恒 false）；`list_dir` 惰性登记——用户 mklink 自建的 junction 首次被列出即纳入登记。缩略图 / 详情 / 预览 / 系统菜单全链路自动放行。

**对账 reconcile**（start_watch 内）：junction 本体没了 → 剔出登记；外部重指 → 更新登记；**断链 = 只标记保留不剔除**（定案口径）。

**watcher**：主监听照旧 + 每条「链接在且目标在」单独补 target 监听，事件路径从 target 前缀翻译回词法门路径，走同一 changed_dirs / 回声消重管道；AppState.workspace 槽位改 Vec。链接拓扑变化后（增 / 删 / 重指 / 改名 / 移动 / 剪切粘贴）命令层恒重建监听（简单口径，不做 watcher 集增量维护）。

**写操作语义**：回收站删链接 = 只删门（红线 a）；重命名 / 移动 = 只动门（fs::rename），登记清单 rel 随 rename / move / delete / 祖先目录改名自动平移 / 剔除；复制 / 副本链接目录 = **深拷内容**（Explorer 同口径）；拖入 / 粘贴进链接目录 = 落真实目标（防爆递归判定天然覆盖）。

**新命令 3 个**（逻辑全在 services 层，命令层只转发 + 重建监听）：`ws_add_link(destRel, targetPath) -> 挂载点 rel`（挂载名 = 目标目录名 `_n` 规避；拒绝：非目录 / 目标在工作空间内 / 目标是工作空间祖先——防循环）；`ws_remove_link(relPath)`（门进回收站，断链可删）；`ws_retarget_link(relPath, newTarget)`（断链送修径）。
