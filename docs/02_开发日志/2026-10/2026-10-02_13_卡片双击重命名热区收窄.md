# 卡片双击重命名热区收窄（2026-10-02）

## 起因

用户实机走查报：双击重命名热区特别容易误触，尤其是文件夹——双击进去时经常变成重命名。根因 = 名称 span 被拉伸成整行宽（FolderCard `.fd-name` flex:1；FileCard/ArchiveCard 名称在 column 罩层里 align stretch），`@dblclick.stop` 覆盖整行，双击进入时稍偏文字右侧就落入重命名分支。定案：收窄至真正的标题文本区域。

## 实现

名称 span 收缩到文本宽，行空白双击回卡片主操作（文件夹/档案 = 进入、文件卡 = 打开预览）：

- **FolderCard**：`.fd-name` flex 1 → `flex: 0 1 auto` + max-width 100%；`.fd-head` 补 `justify-content: space-between`——文件夹图标恒右缘站位不变，视觉零变化（不自创样式、不改稿版式）。
- **FileCard / ArchiveCard**（`.kc-name` cards.css / `.ar-name`）：`align-self: flex-start` + max-width 100%。FileCard 罩层 pointer-events 口径随之精确化：span 外空白穿透可 scrub（09-08「文本行不 scrub」口径再到文本宽）。
- **ListRowCard** `.lr-name` 本就内容宽无 grow，不动，探针登记防回归。
- v-tip 热区同步收窄到文本；右键菜单「重命名」与命名输入框整宽不动。

## 验证

`pnpm typecheck` 0 错。内容容器探针新增 **T6e/T8d/T9e/T14f（elementFromPoint 命中判定：名称行空白不命中名称 span + 文本命中 + 宽度断言）+ T8e（真实双击文件夹卡名称 → 命名输入框现 / Esc 同名 no-op 退出）全 PASS**；real_click/real_dblclick 提上共享 helper；剩 T4/T4b/T4b2 三项详情钮业务漂移（预存在，_11 已挂号）。截图目验文件夹卡图标仍右缘、版式无变化。

## 交实机走查

文件夹卡双击打整行任意处（文字外）= 进入；双击名称文字 = 重命名。文件卡/档案卡同验（= 预览/进入档案）；名称悬停 tip 只在文字上出。

口径速查新立 §64 + §22 文件夹卡/档案卡/文件卡三条目回补；预览页三展区标题补注。
