# 2026-10-15_01 快捷键全量点亮（设置面板遗留项收尾）

> 2026-10-13 设置面板落地轮全量审计坐实的遗留一次清：未绑七键（Enter / Ctrl+Enter / 新建类五键与 "/"）实绑、「转换为档案」双标注统一、回收站两键守卫放行，速查表 30 行全部接入。纯前端零后端，动作全部复用菜单既有流程，无新命令。

## 打开类：Enter / Ctrl+Enter

新文件 `lib/useGlobalKeysOpen.ts`，与右键菜单动作同径：

- **Enter = 打开**：素材 = `previewSession(panelId).open`（回收站同——recycle 菜单该项本就可点）；文件夹 / 档案 = `tabs.openView(folder:)`，与双击卡片同径（folder/archiveCard「打开」菜单项 09-23 删除时注明 Enter 快捷键本体不受影响，本轮兑现）；ws 文件夹 = `openView(ws:)`（断链拦截走 openView 内建守卫），ws 文件 = 预览。
- **Ctrl+Enter = 新标签页打开**：素材 = `openPreviewInNewTab`；文件夹 / 档案 / ws 文件夹 = `openInNewTab` 同视口新页。

单选才响应（右键菜单恒单选语境同口径），多选不响应；Shift+Enter 仍归 onOperationKeys（默认应用打开），本处理器排除 shift/alt 组合。选择模式与 Shift+Enter 同口径全禁。

## 新建类与 "/"：useGlobalKeysCreate.ts

- **Ctrl+Shift+N = 新建文件夹**：文件夹视口建到当前文件夹，其余位置视图 = 默认区块根级（appMenu 同径）；快速访问六视口禁（isQuickView）。ws = 当前目录 `createAndRename`。
- **Ctrl+Shift+Alt+N = 新建子文件夹**：当前文件夹（folderId null 禁）；ws 同 = 当前目录（库文件夹视口内两键同效口径的 ws 映射）。
- **Shift+N = 新建档案**：默认区块根级（openBlock + createArchiveAndName）；快速访问禁；ws 无语义不响应。
- **Alt+N = 转换为档案**：当前文件夹且非档案（convertToArchiveFlow 两段式确认同菜单）。
- **"/" = 展开/收起所有文件夹**：库树有展开即全收、否则全展（folder 树节点菜单同径）；查看类——选择模式放行（picker 菜单本有该项），ws 树无此菜单不响应。

## 回收站两键守卫放行

Shift+Enter（默认应用打开）与 Ctrl+E（发送至 Animate）原带 `!isRecycleView` 守卫，回收站菜单却可点——**菜单可点而键无效的口径不一瑕疵**（待办 2026-09-25 挂号，PRD 07-04 入口节亦记）。定「快捷键放开回收站」：回收站入口属已定功能（发送查看确认 / 打开六件），非只读写操作，两处守卫摘除即与菜单一致，无其他改动。

## 速查表与标注对齐

SettingsDialog SHORTCUTS 七行 bound 全转 true、「展开或收起所有文件夹」补键 "/"；补全菜单有标注而表漏列的两行 = **从文件夹中移除 Shift+Delete / 退出 Alt+F4**，并重排行序（打开类与新建类归位，不再「未接入殿后」）。未接入尾标机制（bound 字段 + 键位降四级 + 警告橙）保留供后续新键复用。folder.ts「转换为档案」右键标注 **「菜单+N」→「Alt+N」**（appMenu 与速查表同键，双标注不一致消除）。

## 实现拆分（500 行硬上限）

useGlobalKeys.ts 原 494 行近规范硬上限，新键不往里堆：拆 `useGlobalKeysOpen` / `useGlobalKeysCreate` 两个子 composable（同组件实例注册），共享让位判定新立 `lib/globalKeysGuard.ts`（输入框 / 预览子窗口 / 激活 panel 预览中 / 向导态 / 菜单浮层弹窗让位；picker 禁放行由各处理器按编辑类·查看类自判）。`isEditableTarget` 同迁 guard，useGlobalKeys re-export——App / PreviewPanel / useSpaceZoom 既有引用路径不破。
