# 筛选业务二轮：chip 类三维度弹窗与呈现形态（2026-10-09）

筛选五步分走之 ②（① 后端筛选引擎同日一轮已落）：前端状态模型 + 弹窗统一壳 + 按钮呈现形态 + chip 类三维度（扩展名 / 链接 / 属性）端到端打通。一轮遗留的「呈现形态」PRD 留白本轮定稿（auto 模式定、待用户实机确认）；「缩略图」链接态语义、文件夹含不含后代、「档案」虚拟类别三待定项留 ③④ 轮。

## 呈现形态定稿（PRD 03 §2 回补）

**筛选钮 on 态（稿选中态 = 半透明-1 底 + 一级文字）= 该维度有生效条件 或 弹窗打开中**；生效条件摘要 = 按钮 v-tip（链接四态与 `seq` 显示中文文案）。「标签」按钮落地名 = 属性（PRD 既定）。

## 落地件

- **search store**：per-panel `filters` 状态（与后端 SearchFilters camelCase 对齐），`isActive` 扩为「有关键字 || 有生效筛选」——**纯筛选同进搜索态**（结果替换素材区、分组平铺、档案区随后端抑制自然不出），`run` 无条件才清空、scope.filters 随搜下发；新 API = filtersFor / activeFilterDims / filterSummaries / patchFilters / clearAllFilters（菜单「重置所有筛选」第 ⑤ 步点亮同径）。
- **FilterChipsPop**（扩展名 / 链接共用）：`.fb-pop` 壳单行横排，chips = **TagButton solid sm**（选中品牌底 + 立体感-主要按钮，贴稿）；按稿无清除钮，扩展名候选多时限 4 行滚轮。
- **FilterTagsPop**（属性）：350 宽两段式——头行 TextInput sm + 清除 TagButton solid md，1px 分隔线 + chips 流式区滚轮；清除 = 清空全部选中不清搜索输入（稿定）。
- **FloatBarHost 接线**：filterPop 点击制开合（再点同钮 / 点外 / Esc / 切视口 / 切出搜索态关，Esc 分层先关弹窗），定位复用 placePop 管线（触发钮中心对齐 + anchor 内钳制），弹窗根类统一 `.fp-root`；数据源零后端新增——扩展名集 / 属性词集前端自 `content.placements` 算出（有序列帧资产时首项「序列帧」）；FloatBarSearch 的 filter-toggle 携带点击事件供定位、chip 接 v-tip 摘要。
- preview 陈列（PreviewBars 新组：静态 force 态 + 真实交互实例五 cell）+ 浏览器目验贴稿。
