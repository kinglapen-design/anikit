## 阶段七 7.1 二十六轮走查续：左侧边栏树颜色四连修（用户实机四报）

**① 子级选「默认」永远被父级色盖回**——根因 = `Folder.color` 无值（None）的语义是「视觉跟随最近祖先色」（FolderTree `node.color ?? inheritTint`），子级点默认色块写回 None = 无操作，父红则子恒红。修法 = **显式默认哨兵**：「默认」色块落盘存 `"default"`（新 `DEFAULT_COLOR` 常量，customColors.ts）——断开父级链路强制常态灰；展示层 `toNewTint()` 把哨兵映射为无 tint（TreeRowItem / 缩进线 / TreeItem / LinkManageDialog 全部消费端天然兼容，哨兵沿 inheritTint 下传等效"默认色当普通链路值"）。后端 `set_folder_color` 零逻辑改动（色值本就opaque 存储，哨兵按普通链路值参与同步：后代同值为链路一致跟随、改回与父级同色恢复跟随）。

**② 多选树 item 换色不批量**——修法 = 批量分流同剪切/克隆口径（触发项在多选域内 → `selection.orderedSelectedFolderIds()` 整个选中集）；后端新命令 **`set_folder_colors(folderIds, color) -> usize`**（逐 id 走单节点同语义、陈旧 id 跳过、全陈旧报错，单次落盘**单撤销步**），前端 `setFolderColor` 换代为 `setFoldersColor(ids)`。

**③ 档案上下文接入更改颜色**——archiveCardSpec 的 disabled 占位换内嵌色块行（树档案节点 / 档案卡共用 spec；批量分流同 ②；生效于树档案圆点/图标 tint，与 archives 表徽标色无关）。09 待办 2026-08-18 条目 ② 闭环。

**④ 档案图标出更改图标网格**——`archive` 移出 CUSTOM_ICONS（29 个，网格 31→30 格）与后端 `CUSTOM_ICONS_NEW` 白名单（29）——档案图标档案专属不可选（TreeRowItem 按 kind 强制挂载）；存量 Folder/Block.icon = "archive" 经开库自检回退 None。命名对照 02_自定义 archive 行注记。
