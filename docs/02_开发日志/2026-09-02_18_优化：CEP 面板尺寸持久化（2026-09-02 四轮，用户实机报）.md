## 优化：CEP 面板尺寸持久化（2026-09-02 四轮，用户实机报）

面板调好宽度重开 AN 回退默认 300——CEP 宿主不替扩展记忆尺寸。修 = panel.js 加 `panelSizePersist`：启动读 localStorage `cepPanelSize` 恢复（`cs.resizeContent`，下限钳 manifest MinSize 260×380）+ window resize 防抖 300ms 记忆（dock 拖宽/浮动调整都触发）。**docked 下 resizeContent 有效性因宿主而异，待用户实机定**；无效时退路 = manifest 默认 Size 调大 + Animate「窗口→工作区→保存」原生路径。已同步 extensions（面板需重开生效）。

**同日定案（用户）**：面板尺寸场景已由 Animate「保存工作区」原生路径解决（布局含面板宽度随工作区记忆），panelSizePersist 代码保留无害（docked 不生效则静默跳过）不再投入。
