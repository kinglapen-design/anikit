# 5.3 卡片悬停预览（按类型分发）+ 视频自动预览范围（用户定案，参考 Eagle 截图三张）

**5.3 卡片悬停预览（按类型分发）+ 视频自动预览范围（用户定案，参考 Eagle 截图三张）**。① **悬停按钮按需出**（AssetCard kind 分发）：视频 / 音频 / 动图无按钮悬停直接播放；静态图片 / 序列帧 = 放大镜；PSD / PSB / SVG / AI 有内容缩略图 = 放大镜 + 默认应用打开；fla / aep 有内容缩略图（8.2 后）= 发送 + 默认应用打开 + 放大镜（发送仍占位 8.5）；格式图标 = 仅默认应用打开。② **视频悬停播放**（HoverVideoLayer）：范围 = 封面帧（thumbFrame `t:{秒}`，未设 = 0）起 **10 秒**封顶时长循环（用户原话"自动播放最大只支持 10 秒……从这一帧开始往后数 10 秒"）；"设置当前画面为预览图"后悬停范围自动跟随，无需新设置 UI；跟随鼠标横向 scrub 到范围内位置；底部 3px 进度条（轨道 border-2 / fill 品牌紫）+ 右下胶囊（当前时间 + 音量钮，默认静音）。③ **音频悬停播放**（HoverAudioLayer）：有声播放；已播放品牌紫 = div 以同一波形图作 CSS mask + clip-path 裁进度（照 PlayBarAudio，mask-size 与卡片 object-fit 同口径）+ 1px 播放头；点击 / 拖动波形 seek；右下胶囊时间 + 播放暂停钮。④ **动图悬停**：300ms 后 img 换源文件原生循环（零等待），移出还原封面。⑤ **悬停放大浮层**（HoverZoomOverlay，Teleport body z-2000）：居中 max 80vw×80vh（C3 / inset border-1 / 圆角 8 / --shadow-pop）；图源复用 `get_asset_file_path`——直渲给源路径、psd/psb 秒显缩略图后 preview-full-ready 换全尺寸解码图、其余回退缩略图；点击任意处 / Esc 关闭。⑥ **架构**：media 元素各播放层组件自管（与 previewMedia 预览单例隔离可并存）；hoverPreview.ts 注册表 + main-window-hidden 全部暂停；悬停进入统一 300ms 延迟防划过；卡片放大镜语义从"进中栏预览"改为出浮层（双击进预览不变）。⑦ **后端仅一处**：PlacementView 加 `thumbFrame` 透传（views.rs），无新命令（get_media_source / get_asset_file_path / open_with_default_app 全复用）；import.rs 序列化契约用例同步。cargo test 166 过零失败、clippy -D warnings 清零、tsc / build 全绿。PRD 04（卡片悬停行为分发定案）/ 06_卡片 03-1 / 07 接口文档已同步。
