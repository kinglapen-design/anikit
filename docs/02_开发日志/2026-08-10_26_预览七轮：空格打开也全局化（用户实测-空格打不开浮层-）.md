# 预览七轮：空格打开也全局化（2026-08-10 用户实测"空格打不开浮层"）

**预览七轮：空格打开也全局化（2026-08-10 用户实测"空格打不开浮层"）**：根因 = 打开路径仍依赖 viewport 焦点（点侧栏后焦点离开网格，keydown 到不了 viewport）——六轮只全局化了"关闭"，"打开"漏改。修法 = onGridKeydown 改挂 window（AssetGrid mounted 注册 / 卸载摘除，viewport `@keydown` 解绑），并加**激活标签页闸**（多 panel 每实例都挂 window 监听，`panelApi.isActive` 为真才响应）；预览模式 AssetGrid 被 v-else 卸载、监听随摘，不误开。tsc / build 全绿。
