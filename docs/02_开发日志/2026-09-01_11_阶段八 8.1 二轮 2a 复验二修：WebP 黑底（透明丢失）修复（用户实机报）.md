# 阶段八 8.1 二轮 2a 复验二修：WebP 黑底（透明丢失）修复（用户实机报）
## 阶段八 8.1 二轮 2a 复验二修：WebP 黑底（透明丢失）修复（用户实机报）

**现象**：重导的 fla 卡片黑底（应透明透出卡片灰底）。**根因两环**：

1. **组包丢 ALPH**（初版 `extract_vp8_chunk` 只提 VP8/VP8L chunk）——webp crate 有损编码对含 alpha 输入自动产 ALPH 伴随块（libwebp use_argb=1），初版提取把它丢了 → 帧无 alpha 不透明、透明区 RGB(0,0,0) 落成黑底。修法 = `extract_image_chunks` 按序保留 ALPH+VP8/VP8L 全部图像 chunk。webp 0.3.1 自带的 AnimEncoder（官方 libwebp 动画编码封装）评估弃用——它自动差分裁剪帧矩形，与重影根治的"全帧组包"路线冲突。
2. **缩略图管线对动图丢 alpha**（image crate 0.25 的 webp 解码器对 VP8X 动画容器把透明像素落成黑）——`thumbnail::generate` 对 gif/webp 改走 anim 首帧解码（`decode_origin_image` 选路：动图 → anim::decode_frame，静态图 → image crate 魔数解码不变）；静态 webp（非动画容器）image crate 解码 alpha 正常，不受影响。

**验证**：cargo test **422** 全绿（+1：`webp_anim_thumbnail_keeps_alpha` 黑底回归钉——透明底+中心色块组动画 → 缩略图管线 → 角落 alpha≈0 / 中心 alpha≈255）；重影回归钉同步复绿。

**存量**：库里三个黑底 webp 是丢 ALPH 的旧组包，刷新缩略图救不回（原图本身无 alpha）——重导即可。
