# 1.2 走查修复：侧栏收展动画三疾同根同治（用户反馈 + CDP 逐帧复现定位）

**1.2 走查修复：侧栏收展动画三疾同根同治（用户反馈 + CDP 逐帧复现定位）**。现象：① 收展过程中顶栏底色断开露出主窗口 C1；② 锚点失效——收左栏时中间面板右缘应钉死（用户动画师锚点模型），实际整个网格被往左拽再回弹；③ 收展末尾重排闪烁一帧。根因（踩坑 025）：dockview 自动布局回调（RO→rAF 包裹）携带旧尺寸且同帧排在我们回调之后执行，把同帧 `forceLayout` 灌入的当前宽覆盖回上一帧——网格渲染宽恒晚 dock 宿主一帧（实测滞后最多 ~75px）。**修法（治时序非遮色）**：灌宽时机从 rAF 阶段改为 ResizeObserver 阶段——App.vue 新增 `dockResizeObs` 监听 dock 宿主（RO 在当帧 rAF 全部跑完后、绘制之前执行，读到即当帧最终宽），`sidebarAnimFrame` 里旧的同帧 `forceLayout` 移除；窗口拖改尺寸同路径受益。曾试"顶栏垫色带"遮丑方案，用户否决（只遮顶栏治不了滚动条拖拽），已撤。**验证**：CDP 劫持 rAF 逐帧步进复现（Edge 无头 + `__TAURI_INTERNALS__` 桩 + 合成时钟），修复后逐帧 `dockHost == grid == tabs` 精确到 0.1px、收左栏网格右缘恒定钉在窗口右缘、顶栏像素扫描全程 `#181919` 无 C1 条带；tsc / build 全绿。
