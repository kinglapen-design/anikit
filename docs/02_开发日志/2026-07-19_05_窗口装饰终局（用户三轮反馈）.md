# 窗口装饰终局（用户三轮反馈）

**窗口装饰终局（用户三轮反馈）**：window-shadows（1px 直角框）→ tauri 内置 shadow + DWMWA_BORDER_COLOR/DWMWCP_DONOTROUND 抑制（顶边线、圆角外底色块仍有残留）→ **定为 CSS 方案**：`shadow: false` + 全透明窗口，根容器内缩 20px 阴影带，圆角 12px 与 box-shadow 纯 CSS 绘制——跨平台同一套代码，不再碰 DWM（踩坑 007）。窗口原始尺寸调为 1374×1190（可视 1334×1150 + 阴影带 20×2）。阴影参数（0 4px 24px rgba(0,0,0,.5)）暂无 token，待用户验收确认。
