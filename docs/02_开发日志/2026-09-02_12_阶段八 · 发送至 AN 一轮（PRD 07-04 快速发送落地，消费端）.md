## 阶段八 · 发送至 AN 一轮（PRD 07-04 快速发送落地，消费端）

**链路**：fla → 剪贴板载荷转换 → Win32 私有格式写入 → WS 下发 → jsx clipPaste(true) 原位粘贴；兜底 = 打开-复制-粘贴-关闭自动回退。spike 回环（clipboard-probe 解出 Flash 11 Picture = XFL 包）本轮回路闭合。

- **转换器 `services/send_stage.rs`**：fla（XFL zip）→ Flash 11 Picture 载荷。DOMDocument 重写 = folders/media/symbols 等块原样透传 + timelines 收第一场景每层首个 DOMFrame（去 duration、首帧 index≠0 置空帧、elements 直接子元素注入 selected="true"——quick-xml 事件流保属性序，状态机处理多场景丢弃/层内次帧丢弃/自闭合帧归一）；其余 zip entry 原字节原序复制（PublishSettings 全带最保真，依赖闭包裁剪记 09 待办）。全层首帧无内容 → Err 触发兜底。
- **剪贴板适配器 `adapters/clipboard.rs`**：注册格式 "Flash 11 Picture" + OpenClipboard（占用竞争重试 3×50ms）+ GlobalAlloc(GMEM_MOVEABLE) + SetClipboardData（成功句柄所有权移交系统，失败 GlobalFree 防泄漏）；arboard 只支持标准格式，私有格式直调 Win32（规范第 9 条候选表既定路线）。
- **WS 请求-回执模式**（plugin_ws）：S→C `paste{reqId,name}` / `pasteFla{reqId,name,flaPath}`；C→S `pasteResult{reqId,ok,message}`；pending 表 reqId→(clientId, oneshot) + 20s 超时。
- **积压根治三件套**（用户报旧 electron 版痛点：CEP 未连通点发送请求积压不报错，重连激活后积压队列一次性全跑连粘 N 次）：① 无在线客户端立即报错**不排队**（请求不落盘不缓存）；② 全局发送锁（RAII PastePermit，在途期间新发送报「上一次发送尚未完成」）；③ 客户端断开 drain 其 pending 立即失败（不等超时）。
- **jsx**（host.jsx）：`pasteClipboard`（clipPaste(true) + 粘贴后选区非空校验 = 载荷无效排障信号）+ `pasteFlaFile`（兜底：**fl.documents 预判已开护栏**——已开文档用完不 closeDocument 会关掉用户文档，旧脚本 export_lib 实机模式蓝本；用户提供的两份旧 JSFL 实为导出方向，归档 spike/send-to-an-ref/）。panel.js 两消息分支 + replyPaste 回执（readyState 必查同族坑）。
- **前端**：素材卡右键「发送至 Animate」点亮（assetCard 既有占位，仅 fla 单选）+ Ctrl+E 快捷键（onOperationKeys）；placementOps `sendToAnimate` toast 反馈。
- **依赖选型**（规范第 9 条四问过）：`zip = "2.2"`（实际解析 2.4.2，rust 1.77 兼容——XFL 读写标准件）+ `quick-xml = "0.36"`（事件流改写保属性顺序，树库丢序风险）；windows features +Win32_System_DataExchange/Memory。

**验证**：cargo test **433** 全绿（+4 转换器单测：单元件端到端 / 多层多帧收首帧 / 空帧报错 / 缺条目报错）；vue-tsc 0 错 + build 绿；node --check host.jsx / panel.js 过；面板已同步 extensions。**下一步：用户实机回环验收（右键 fla 发送至 Animate → 舞台原位粘贴坐标正确；队列积压三场景复验：断连点发送当场报错 / 发送中连点被拒 / 重连不补跑）**。
