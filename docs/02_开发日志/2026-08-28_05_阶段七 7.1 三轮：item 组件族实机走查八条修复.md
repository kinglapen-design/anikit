# 阶段七 7.1 三轮：item 组件族实机走查八条修复


**用户走查反馈（8 条）与落地**：

1. **快速访问补「缩略图」**（预览页漏排）——thumbnail.svg 转 currentColor（首批 18 个），预览页快速访问组补齐。
2. **关闭/动作钮滑入机制重做**：原 grid 0fr→1fr 宽度过渡视觉上把内容往左挤——改**绝对定位覆盖右缘 + 位移 14px + 透明度**（items.css `.ni-act`，--ni-act-right 按容器传 12/6），五组件（笔记/缩略图/音频/关系/污染）切换；链接文件关闭钮位移 4→14。
3. **SectionTitle 展开钮 hover 提亮 亮色/二级**（与动作钮同口径）。
4. **小图标钮点击热区 `::after` 外扩**（通用问题：缝隙在抓手/指针光标间抖动）——SectionTitle 展开钮 -4/-4/-4/-6（左吃名称间距）、动作钮 block -4 / group -6（钮间距两半各吃）、TreeRowItem 展开钮 -4/-3/-4/-6（吃满上下 padding + 左到 item 缘，旧 TreeItem 同款机制）、ni-close -4。
5. **选择模式 hover 过渡——CDP 探针实证本就统一**（tools/cdp-items-hover-probe.py）：两族 computed transition 一致（background 0.1s），forcePseudoState 强制 hover 采样 rgb(36)→39→41 逐帧插值 YES——用户感知差异源于选择关系内框不变色（仅卡缘变）+ 可能悬到强制态单元格。探针留档。
6. **链接关系名称右对齐** + padding-right 20 预留（关闭钮 14 + 间距 6），覆盖滑入不压不挪。
7. **区块标题 gap 10 = figma 默认自动占位**（用户确认），按 token 档用 8——09 待办①闭环。
8. **标签页肩膀 8px→4px**（= 标签间隙）：8px 肩膀会伸进相邻标签，hover 罩右下间距就不是统一的 4px——改 4 后角部干净（3x 截图实证）。

**顺手修**：链接缩略图 hover 时数量淡出避让（与覆盖式关闭钮同位，不重叠不挤压）。
