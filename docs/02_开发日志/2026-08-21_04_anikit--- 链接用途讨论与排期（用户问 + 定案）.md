# anikit:// 链接用途讨论与排期（用户问 + 定案）


- 用户问 `anikit://item/{ID}` / `anikit://folder/{ID}` 链接可用在哪些地方（md 图片引用 / 剪辑软件素材路径等）。代码核查现状：仅"复制链接"生产端（menuOps.ts 写剪贴板文本），消费端三层全未接——详情面板"打开链接"钮 disabled 占位、前端无解析跳转代码、系统协议未注册（tauri.conf.json / Cargo.toml 无 deep-link）。
- **边界确认（用户）**：链接只作跳转，无法推送图片信息至其他文档——md `![](anikit://...)` 无效（渲染器不认自定义协议）；剪辑软件要真实文件路径（该场景用已实现的复制文件路径 / 拖拽）。
- **排期（用户定）**：协议注册 + 单实例收链接 + 前端跳转解析器记入阶段九，与硬链接同批。PRD 02 §09 补边界与排期两条、01_路线图阶段九条目同步。
