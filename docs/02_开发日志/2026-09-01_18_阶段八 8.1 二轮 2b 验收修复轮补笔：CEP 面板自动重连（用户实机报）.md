# 阶段八 8.1 二轮 2b 验收修复轮补笔：CEP 面板自动重连（用户实机报）
## 阶段八 8.1 二轮 2b 验收修复轮补笔：CEP 面板自动重连（用户实机报）

**现象**：dev 重启（WS 服务重启换端口）后面板停在「连接断开」死状态，不会恢复。**修法**：panel.js 自动重连——onclose/onerror/无端口文件统一 2s 重试（retryTimer 守卫防叠加），端口文件每次重读（AniKit 重启换端口自动跟上）；重连成功 = hello 重握手 → welcome 刷新就绪态与设置。

**至此 8.1 全部闭环**（定案 → hidden 模型 → WS 服务 → 接收入库 → 复验六连修 → 正式面板 + 一键安装 + 设置弹窗 → 验收修复轮七笔）。**下一阶段 = 8.2 APP 内批量导出**（扫描库内无伴生图 fla → 批量导出（jsfl 直启兜底 / CEP 在线通道）→ 可视化进度 + 暂停/取消/失败重试；设置读同一份 settings.cepExport）。
