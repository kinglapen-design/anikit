## 跨窗口拖出修复（走查第一批 · 拖至其他软件打开又失效）

**根因**：spike 任务 2 的 `drag_files` 命令自阶段 1 主窗口重构后零前端调用——演示按钮随重构拆除，产品侧从未接上（用户报"又失效"，实为功能未落地）；`dragOperation.ts` 头部注释"拖出窗口 = 无操作"是 6.1 自实现 pointer 拖拽时的旧语义。

**修法**：

- **前端**（lib/dragOperation.ts onMove）：pointer capture 生效后窗外 pointermove 照常派发且坐标越界（clientX/Y <0 或 ≥ innerWidth/Height）→ 仅素材拖拽（文件夹 = info 目录非用户文件，不拖出）——收集拖拽组 assetId 去重，先 endDrag(true) 取消内部会话（清 ghost/指示/capture）再 invoke `drag_assets`，DoDragDrop 模态循环接管指针至松手。
- **后端**（lib.rs，`drag_files` → `drag_assets`）：入参改 assetIds——路径解析放主线程锁内一次完成（real_origin_file，序列帧 = frames/ 封面帧，失败跳过 + 去重）；手势途中经不起前端往返解析拉长 OLE 接管时机（松手即失窗口期）。同步命令主线程（踩坑 004 口径）；CF_HDROP 天然覆盖拖至任务栏图标"打开方式"链路。

**验证**：cargo test **449** 全绿（+1：resolve_drag_paths 解析/去重/全失败空集）/ vue-tsc 0 错 / build 绿；新探针 `tools/cdp-drag-out-probe.py` **全项 PASS**——S1 越界 invoke 抵达且 assetIds 正确 + 内部会话取消；S2 窗口内并入落点（move_placements）不误触发；S3 文件夹拖出无操作（DOM 合成 PointerEvent——CDP Input 给不了窗口外坐标；桩环境下 DoDragDrop 段覆盖不到）。**下一步：用户实机复验（真 OLE 拖放落目标软件 / 任务栏图标）**。
