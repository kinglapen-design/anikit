## 二十一轮五轮修订（用户实机：列表模式两条）

- **列表模式无法选中**：根因 = 7.1 列表行壳重构类名改 `.list-row-shell`，而 JS 分发三处仍按旧标记类 `.list-row` 命中（dragOperation.gridPointerDown 拖拽/框选分发、useSpaceZoom 空格放大定位、gridDispatch 右键菜单）——pointerdown 落空白回调起框选吞 click，单击/空格放大/行右键全灭。修法 = 壳根补回 `.list-row` 标记类（无样式挂钩，一处改三处全活；样式注释立"勿删"警戒）。
- **列表行格式图标撑太满**：fla 等 shell 图标行缩略图 contain 撑满 80×45——芯 cards/ListRowCard 补 `thumbFit` 两档（contain 默认 / icon = 50% 居中，FileCard icon 档同口径），壳按 `thumbKind === 'formatIcon'` 传档。
- 探针：桩 a2 补 thumbKind=formatIcon + 假 thumbPath；新增 T14d（**Input.dispatchMouseEvent 真实点击**行 → 选中——JS .click() 不过 pointerdown 分发链测不到本 bug）+ T14e（icon 档 50% = 39×21.5，相对内容盒 78×43 非边框盒 80×45）；复跑全 PASS。vue-tsc 绿；速查 §22 列表模式条同步（list-row 标记类 + icon 档）。
