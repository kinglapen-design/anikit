## 阶段七 7.1 二十六轮：复选框 / 单选框 / 开关按钮 / 确认弹窗四组件 + 对勾-极小入库（用户当日写入四稿）

**稿源**：`Design Token/组件/按钮/` 复选框·单选框·开关按钮三稿 + `组件/模态窗口/弹窗.md`（警告与错误）。

**缺口两问当场定**（一次一问）：
- hover-未选中描边稿 prose 写「亮色/六级」——亮色系无此档 → 用户定 **通用/六级**（复选/单选同；与单选框选中外圈描边同档）。
- 弹窗遮罩无 token → 用户定 **黑色-50%**（新 token `--n-mask`；Token.md 1.7 节同步补「黑-50%：窗口遮罩」）。

**落地**：
- `buttons/Checkbox.vue`：框 14×14 圆角 4，g3 底 + g5 内描边（hover 未选中 g6）；选中 brand 底 + l-a1 描边 + check-tiny 对勾（对勾常驻 DOM scale 切换——踩坑 026 口径）；文字 12/16 二级 gap 6。
- `buttons/Radio.vue`：外圈 18×18 g1 底 + g5 内描边 + 内 padding 2（hover 未选中/选中 g6）；选中内圆 14×14 brand + l-a1 描边；文字 13/18 Bold，选中二级 / 未选三级（色过渡 150ms）。
- `buttons/SwitchButton.vue`：30×16 胶囊 padding 2 钮 12×12；关 g4 + g6 内描边钮二级居左，开 brand（无描边）钮一级居右横移 14；disabled 仅不响应点击（稿无禁用视觉）。
- `modals/ConfirmModal.vue`（新目录）：520 宽 padding 24 列 gap 24，g3 底 + 1px g5 真 border + 大阴影 + 圆角 8；遮罩 --n-mask 点击不关闭；标题 18/26 Bold 一级；正文 13/18 三级（默认 slot）；按钮行右对齐 gap 8 次左主右，钮 120×38 圆角 8 按钮文字-大——取消 g5 + 立体感-通用 + 文字二级，确认 kind 色底（warning 警告 / danger 禁止 / brand 品牌）+ 立体感-主要按钮 + 文字一级。
- **动画**：对勾 / 单选圆点 = 弹出 250ms 过冲（cubic-bezier(0.34,1.56,0.64,1) 沿用旧 AppRadio 既定档，token 未收）+ 收回 150ms 缓入快收（2026-08-12 定案沿用）；开关横移 250ms 小位移；底 / 描边 / 文字色 150ms；弹窗弹出 scale 0.96→1 + 淡入 150ms（套旧 modal-pop 先例）。
- **check-tiny.svg 入库**（对勾-极小-icon）：10 viewBox / 矢量 6×3 / 1px 线条 / 垂直居中——用户供源（中文名直放 assets）挪位 docs 底稿 + assets 英文入库转 currentColor（由 .box 亮色/一级档驱动）；命名对照十批登记，01_常用 87→88 个。
- **预览页**：PreviewButtons 加三控件组（真实 v-model 交互 + force-hover 静态列）；新 PreviewModals 展区（三 kind 静态壳复刻窗口口径 + 真实弹出实例验收遮罩与弹出动画）；DesignSystemPreview 注册 nav「组件 模态窗口」。
