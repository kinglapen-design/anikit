# 视频悬停 scrub 改 Eagle 帧图方案（用户录屏对比：video seek 流畅度与 Eagle 差距大）

**视频悬停 scrub 改 Eagle 帧图方案（用户录屏对比：video seek 流畅度与 Eagle 差距大）**。根因：HTML `<video>` currentTime seek 每次都要找关键帧重解码（几十~几百 ms/次），rAF 合帧 + 15fps 门控也救不回来；Eagle 悬停 scrub = 预生成预览帧序列，鼠标移动只切图片零解码延迟。① **后端**：ffmpeg.rs 新 `video_scrub_frames`（fps 滤镜全片均匀抽 40 帧 + scale=-2:480，libwebp 单趟 ~30KB/帧）；新命令 `list_video_scrub_frames`——产物 `cache/scrub/{assetId}/f-NNN.webp`（会话级开库清空，library.rs 名单收录）+ `.stamp` 源戳幂等（大小:mtime，源变化整目录重抽），模块级 OnceLock<Mutex<HashSet>> 防重入（重入返 pending）；MSRV 1.77 无 LazyLock（clippy incompatible_msrv 三连，改 OnceLock 同 preview_queue 先例）；3 新用例（非视频报错 / 缓存命中幂等 / 防重 pending）。② **前端 HoverVideoLayer**：悬停 scrub 帧就绪后 pointermove 经 rAF 合帧切帧图（video 暂停），鼠标停 300ms 后 video 从该位置续播完整视频；帧未就绪 / 生成失败维持 video seek 兜底（rAF 合帧 + 66ms 门控保留）；自动播放模式不请求抽帧（省一次全片扫描）。cargo test 168 过零失败、clippy -D warnings 清零、tsc / build 全绿；07 接口文档已同步。
