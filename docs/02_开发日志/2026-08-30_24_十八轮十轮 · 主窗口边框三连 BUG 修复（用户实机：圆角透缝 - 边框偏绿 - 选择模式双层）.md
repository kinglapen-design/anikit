## 十八轮十轮 · 主窗口边框三连 BUG 修复（用户实机：圆角透缝 / 边框偏绿 / 选择模式双层）

- 三连同源于前一日「云母边框交 DWM」定案：①四角空隙 = CSS radius 8 裁切与 DWM 系统圆角双裁切，AA 路径差透出云母；②边框偏绿 = DWM 染色 #2E332F 系旧体系遗物（现行稿 = 亮色/半透明档，DWM COLORREF 纯色本就贴不了半透明稿）；③选择模式双层 = DWM 1px 暗绿（外）+ picking::after 1.5px 品牌框（内）各画一层。
- 修法（用户定：**边框收回前端自绘，DWM 只管圆角裁切与投影**；描边色试 亮/半透明-3）：lib.rs DWMWA_BORDER_COLOR 改 `DWMWA_COLOR_NONE` 抑制（Win11 22000+，Win10 忽略无差异）；`.window.fx-mica` radius 0 圆角交 DWM 独裁；`.window.fx-mica::before` 恢复自绘 1px `--n-l-a3` + 直角（线四角伸出由 DWM 裁边，外缘贴裁切路径零缝）；picking 时 ::before 让位（border 0），::after 1.5px 品牌框单层（云母 radius 0 同交 DWM）。实色回退模式不变（1px 半透明-1 + 圆角 8 自裁）。
- 探针 cdp-window-shell-probe.py：W2 组改写（mica 自绘 1px 6% 直角 / .window radius 0 / picking 让位 / 品牌框单层）+ W7c 补齐（solid 1px 18% 圆角 8）；W2d 宽度断言带 DPR 量化容差 + W2e 锁 --border-strong 变量档（headless DPR=1 下 1.5px → used value 1px）。全 18 项 PASS；vue-tsc 绿；cargo check 绿。
- 踩坑 063 新立；速查表 §19 .window 壳口径原地改写（圆角分模式 + 边框回前端 + picking 单层）。
- 实机观感（圆角缝隙闭合、半透明-3 描边浓淡、DWM 边框确已抑制）留用户复验——headless 探针截不到 DWM 层。
