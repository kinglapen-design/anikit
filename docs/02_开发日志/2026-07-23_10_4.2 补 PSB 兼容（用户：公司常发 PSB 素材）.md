# 4.2 补 PSB 兼容（用户：公司常发 PSB 素材）

**4.2 补 PSB 兼容（用户：公司常发 PSB 素材）**：psd crate 明确不支持 PSB（8BPB，version=2，部分长度字段 4→8 字节）——自研 `services/psb.rs` 轻量合成图解析：只取文件尾部 Image Data Section（按节长度 seek 跳转，整文件不入内存），Raw / RLE（PackBits 逐行解码）两种压缩，8/16 位（取大端高字节）RGB / 灰度 / CMYK 近似转换（存储反相，不做色彩管理仅供缩略图），像素上限 64M 防爆内存，不支持的模式回退格式图标；probe 头解析 PSD/PSB 同布局统一接受两种签名。5 用例（Raw RGB / RLE / 16 位 / 灰度+CMYK / 不支持与截断拒绝），cargo test 96 过零警告。
