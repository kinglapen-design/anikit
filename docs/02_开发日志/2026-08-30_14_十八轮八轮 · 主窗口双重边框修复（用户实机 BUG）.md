## 十八轮八轮 · 主窗口双重边框修复（用户实机 BUG）

- 现象：主窗口双重边框线。根因 = DWM 边框染色（lib.rs DWMWA_BORDER_COLOR #2E332F）与前端 `.window::before` 1px 自绘描边两层叠画。
- 用户定：**云母模式下边框、投影整体交 DWM**（投影本就 DWM shadow 全管；边框 = DWM 染色），前端描边仅实色回退模式自绘（Win10 DWM 无边框，留兜底）。改动 = App.vue 加 `.window.fx-mica::before { border: 0 }` 一处；lib.rs 不动。
- 速查表 §19（.window 壳口径）同步改定，vue-tsc 绿。实机观感复验待用户。
