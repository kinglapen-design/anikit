# 储存空间方向定案（新 PRD 讨论，用户草稿 `00_修改与需求/01_新PRD/01_储存空间.md`）

**储存空间方向定案（新 PRD 讨论，用户草稿 `00_修改与需求/01_新PRD/01_储存空间.md`）**：AniKit 储存空间唯一（可切换不并存），空间内多资源库 + 唯一 workspace；**统一 assets 池**——所有素材平铺 `空间/assets/{ID}.info`，库降级为纯数据（各自 json），跨库投递零物理迁移，回收站判定升级跨库引用计数；路径稳定锚点 = 空间根，内部一切相对路径；workspace 用 junction 映射出去供用户在磁盘侧直接操作（不考虑散落各处的项目文件夹，用户自行导入或 UI 内创建）；初次打开四步向导（储存空间 → 建库/工作空间 → 浏览器扩展 → 桥接插件），后两步直接下一步即跳过。
