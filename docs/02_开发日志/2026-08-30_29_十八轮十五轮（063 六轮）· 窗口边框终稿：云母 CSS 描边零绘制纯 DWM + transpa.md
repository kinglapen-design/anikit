## 十八轮十五轮（063 六轮）· 窗口边框终稿：云母 CSS 描边零绘制纯 DWM + transparent:false 方案一（用户实机「圆弧变细/四边粗细不一/角部钩形透出下层」）

- 用户诊断方向（1px 抗锯齿）实测细化：新探针 `tools/win-border-measure.py`（mss 物理截屏 + PIL 四边剖线 + 四角 NEAREST 放大 + MoveWindow 相位驱动 + CSS 染色分离实验）。**实测推翻两假设**：Chromium 直边 1px border 自动吸附物理 1px 锐线（无半透列，不糊）；DWM 线 @150% = 2 物理 px（063 旧测 1px 作废）。
- 真凶一（粗细/圆弧缝）：五轮遮罩环与 DWM 线的并集左右不对称——左/上边视口缘贴 DWM 线内缘（并集 3px）、右/下边视口缘伸入 DWM 线区 1px（CSS 被盖，并集 2px）= 四边 3vs2；角部 CSS 弧（10.5 物理）与 DWM 裁切弧（10.3 物理）异径分离露内容色缝。**修法 = `.window.fx-mica::before` 零绘制（border 0 + box-shadow none），边框主权 100% 交 DWM**；picking 前端全零画（DWM 切染品牌线独存）；实色模式自绘不变。复测四边恒 2 物理 px 全实、无半透缝列。
- 真凶二（角部钩形透下层，用户查证）：tao `transparent:true` = blur-behind 空 region hack → 含非客户区整窗按 alpha 合成，「DWM 圆角描边曲线 vs 方形客户区角」的月牙缝 alpha=0 成透底洞；WebView 只填客户区，CSS 垫块够不着（试过了，无效且有色差）；`ExtendFrame(-1)` 在 transparent:true 下单加无效。
- **终版（方案一，用户供）**：tauri.conf `transparent:false + backgroundColor:#00000000`（Mica 由 DWM 在窗口表面底下合成，不需 tao transparent；要透明的只有 WebView2 默认背景）+ lib.rs `DwmExtendFrameIntoClientArea(-1)`（帧/backdrop 填充非客户区缝；Cargo.toml windows +`Win32_UI_Controls`）。实机用户确认：UI 完整、Mica 正常、月牙缝消失。
- 验证：cdp-window-shell-probe W2/W2c/W2d 改零绘制断言 ALL PASS；cargo test 403 / vue-tsc 绿。
- 文档：063 补六轮实录（三层归属预防：客户区/非客户区/窗外）、057 配置终态修订、速查表 §19 双行更新、05 进度二十轮条目。
