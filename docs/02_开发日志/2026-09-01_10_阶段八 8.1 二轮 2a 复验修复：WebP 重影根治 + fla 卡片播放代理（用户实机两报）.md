## 阶段八 8.1 二轮 2a 复验修复：WebP 重影根治 + fla 卡片播放代理（用户实机两报）

**① WebP 播放重影**（缩略图视图 webp 卡播放时多姿势叠加）——根因链：ffmpeg libwebp_anim 合成输出**差分帧**（ANMF 帧矩形 = 内容包围盒裁剪 + blend=none + dispose 混合档，python 逐 chunk 实测坐实）→ **image-webp 0.2 的 read_frame 画布合成缺陷**（矩形外残留早期帧内容；合成逻辑表面无大错、深层待查）。**修法 = 编码端根治**：`cep_export` 改**纯 Rust 全帧组包**（逐帧 webp 单帧编码 → 手写 RIFF 组包 VP8X/ANIM/ANMF，**每帧全画布矩形 + blend=0 源覆盖**——任何解码端不可能叠影），顺带摘掉该链路的 ffmpeg sidecar 依赖（adapters/ffmpeg.rs 的 compose_webp_anim 随加随删）。降级链同步改纯 Rust（质量 → 尺寸（基底内存再缩不重读 PNG）→ 抽帧（隔帧取 + delay×2 时长不变））。**外部存量/未来差分 webp 的解码缺陷记 09 待办**（修法候选：帧流桥换 ffmpeg 单趟全解 / patch image-webp）。**关联**：用户提示的透明 MOV 旧坑同族——ffmpeg 编解自洽的格式无恙，Rust 解码桥是缺口。

**② fla 卡片不播放**（自动播放/悬停皆无）——一轮只代理了静态缩略图四件。补齐**播放代理**：PlacementView 加 `play_asset_id`（serde skip_none），thumb_asset_id 有效时 animated/frame_count/fps/duration/thumb_frame 全代理伴生资产（`source` 统一口径——无代理时 source=自身，表达式零分支）；前端 AnimCanvasLayer 开流目标 = `playAssetId ?? assetId`；预览 store loadAnim 同代理（预览 fla = 播伴生动画，信息/徽章/笔记仍归 fla 自身）。fla 预览态衍生操作（帧条/设封面/笔记抽帧）的代理口径记 09 待办待走查。

**验证**：cargo test **421** 全绿（+2：`webp_anim_full_frames_decode_clean` 重影回归钉（全异色块 4 帧组包 → image-webp 解码逐帧断言一致）+ `compose_fallback_and_halve` 降级链/抽帧 delay 语义）；代理测试补播放字段断言；vue-tsc 0 错 + build 绿；cdp-hidden-thumb-probe 复跑全 PASS。

**文档**：07 接口 §2 入库链路改纯 Rust 组包口径（见下条同步）；09 待办登记四笔；00 状态同步。**下一步：用户实机复验（重新导出 → fla 卡片自动播放/悬停播放 + 缩略图视图播放无重影；存量两个重影 webp 资产重导即换全帧组包文件）**。
