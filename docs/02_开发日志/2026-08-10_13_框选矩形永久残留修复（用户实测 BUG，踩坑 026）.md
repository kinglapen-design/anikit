# 框选矩形永久残留修复（2026-08-10 用户实测 BUG，踩坑 026）

**框选矩形永久残留修复（2026-08-10 用户实测 BUG，踩坑 026）**：现象 = 框选进行中按系统截图、或框选拖到屏幕边缘触发 Win11 snap 预览后，框选矩形永远盖在界面上（UI 不卡死）。根因 = 清除只依赖 viewport 的 pointerup / pointercancel，系统抢指针时两事件双丢。修法 = `useMarquee` 加 lostpointercapture（capture 被剥夺的对症事件）+ window blur 双兜底 forceCancel；拖拽引擎同根加 window blur → endDrag(true) 取消兜底（防 ghost / 落点指示同类残留）。tsc / build 全绿。
