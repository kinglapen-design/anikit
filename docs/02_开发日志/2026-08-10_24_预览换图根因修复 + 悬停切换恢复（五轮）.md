# 预览换图根因修复 + 悬停切换恢复（2026-08-10 五轮）

**预览换图根因修复 + 悬停切换恢复（2026-08-10 五轮）**：用户报"点选目标卡片不会更换"并指明与悬停问题同源——**根因三连误判后定位**：`HoverZoomOverlay` 只在挂载时加载一次图（src 初始化 + onMounted loadFull），`asset` prop 变化无 watch 不重载；浮层 `v-if` 恒 true 组件不重建——切换 / 点选状态早已换成功，图永远是第一张，"按两次先关再开"有效正因销毁重建。二轮误判 hoverCardKey 时序、四轮误删切换功能，根因实在组件不响应 prop 变化。修法 = 浮层 `:key = asset key`（key 变即强制重建重载，一行改动利用既有挂载加载逻辑）；**悬停切换按用户要求恢复**（开着时悬停另一张卡按空格 = 切换、同卡 / 无悬停 = 关闭），点选换图经选择跟随同步生效。tsc / build 全绿。
