# MD 工具栏视图组图标换代（暂代清零）

日期：2026-09-26　分支：feat/new-ui

## 背景

2026-09-25 MD 编辑器二轮走查改版（§60）时，视图组「回预览 / 分屏」两钮无专图标，用户授权先挑库件暂代（眼睛 → view-options、分屏 → collapse-sidebar），待补源后换名。本轮用户补源落地（「分屏编辑预览：Edit_and_preview，预览模式：preview_mode」）。

## 落地

- **图标十七批 2 个（用户直投）**：`edit-and-preview`（分屏编辑预览：方框中竖线分左右）/ `preview-mode`（预览模式：打开的书本）——#141B34 单灰线条转 currentColor；原投文件名 Edit_and_preview.svg / preview_mode.svg 按 kebab-case 纪律改名；设计底稿 分屏编辑预览.svg / 预览模式.svg 补入 docs/06_UI重构/图标/01_常用/；命名对照登记（01_常用 92→94）。
- **FloatBarMarkdown 视图组换代**：编辑态「回预览」= preview-mode（原 view-options 暂代）、「分屏编辑预览」= edit-and-preview（原 collapse-sidebar 暂代）；铅笔（去编辑）不变。collapse-sidebar 本体（左侧边栏收展钮）不受影响。

## 验证
