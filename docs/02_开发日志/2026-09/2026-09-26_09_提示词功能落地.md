# 提示词功能落地（三态菜单 + 详情 tab 接活，2026-09-26）

## 起因

2026-09-05 上下文菜单走查轮立的项（待办 ①）：文件/档案「提示词」一级菜单骨架与详情 TabPrompt 全占位，后端零起点。本轮兑现 PRD 03_数据链接 02「提示词 = 对 MD 资产的引用 + 内容快照」。「分析提示词」数据源原标「口径待定」——本轮定案 = **解析图片内嵌元数据**（AniKit 不做 AI 生产，08-07 工作台转型口径下本地唯一可行解；无内嵌数据明确报错，引导走指定/新建或外部 Agent 经 MCP 写入）。

## 数据模型与断链口径

`PromptBinding { assetId, name, content, updatedAt }` 内嵌 `metadata.prompt`（资产）/ `archives.json`（档案），serde default 不升 DATA_VERSION。三态：未指定（无字段）/ 已指定（assetId 非空）/ 已扫描（纯快照，仅资产侧——档案无「分析」）。展示 = 已指定态实时 `read_text_asset` 读源最新内容、源不可读回落快照；快照在 指定/分析/新建/详情「保存提示词」（= 同步快照）时落盘。断链两条路分得很清：**源文档被彻底删除 = 不断链**（`sync_after_purge` 钩子把引用置空、快照保留降级已扫描态，开库自检 `fix_prompt_refs` / `fix_archive_prompt_refs` 兜底）；**用户主动断开/清空 = 整绑定移除**（快照随解绑清除，不留半态）。
