# 2026-09-23_01 侧栏区块标题「更多」菜单接业务（大纲管理 / 上移 / 下移）

2026-09-23

## 需求

左侧边栏文件夹区块标题的 ···（更多）钮接上下文菜单：大纲管理 / 上移 / 下移。此前该钮「点亮不接业务」（§20，2026-08-30 用户定，区块操作菜单留待后续轮），本轮收口。

## 落地

新增 `src/lib/menuSpecs/blockHeader.ts`（与 groupHeader.ts 同范式的 spec 文件），`LibraryView.vue` 区块标题 SectionTitle 绑 `@more` 弹出。

- **大纲管理** = 侧栏区块管理弹窗（`ui.blockManageOpen = true`，30 稿 BlockManageDialog），与菜单栏「视图 ▸ 大纲管理」同项同径。
- **上移 / 下移** = 即时生效：按 `content.blocks` 全量序交换相邻位后 `reorderBlocks(ids)` 提交（blockOps 封装内含乐观重排 + refresh + toast 带撤销），与区块头拖拽排序同一后端命令同一封装。尾图标与边界禁用（首项禁上移、末项禁下移）随 3.5 分组菜单「上移/下移」口径（chevron-small，下移 rot-180）。
- 三项平铺无分隔线（同分组菜单先例）。

## 口径决策

- **弹出位置 = 指针位**（`openContextMenu(e, …)`），随分组标题菜单 `onGroupMenu` 先例；不走菜单栏文字钮的「按钮下方 + trigger toggle」口径。
- **选择模式整体不弹**：闸在 `onBlockMenu`（`picker.active` return），与区块头拖拽排序闸、添加钮闸同径——排序与管理弹窗均非 §12.1 白名单；菜单无白名单项，不做「开菜单全项 disabled」。
- more 钮不启拖拽由既有 `.act` 排除覆盖（`onBlockHeadPointerDown` 命中动作钮即 return），无需新增守卫。
