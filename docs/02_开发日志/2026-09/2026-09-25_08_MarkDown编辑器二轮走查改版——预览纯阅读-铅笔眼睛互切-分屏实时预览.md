# 2026-09-25_08_MarkDown 编辑器二轮走查改版——预览纯阅读 / 铅笔眼睛互切 Ctrl+E / 分屏实时预览 / 代码块换行

## 任务

用户实机再走查 md 编辑器反馈四条：1) 不要主动进入编辑（只想复制文字，点一下就进编辑很多余）；2) 代码块要根据宽度换行；3) 工具栏加铅笔和眼睛按钮互切（编辑/预览模式），Ctrl+E 没占用就用它；4) 给双屏编辑+预览实时（工具栏加按钮，分割线能左右拖动；库内先挑图标，用户后面画新的；麻烦的话分屏新标签也行）。

## 落地

**预览纯阅读**。onMdClick 撤掉「点击进编辑」分支——预览态点击文字 = 选中复制（复选框 toggle / 代码块复制钮分流不变）；进编辑唯一入口 = 铅笔钮 / Ctrl+E。

**工具栏双态 + 悬浮栏恒显**。FloatBarHost 的 md 判定从「kind text 且 mdEditing」改为「kind text 且 ext md」（`mdActive`）——md 语境悬浮栏恒显，不再编辑态专属。FloatBarMarkdown 加 `editing` prop：预览态 = 仅视图组（铅笔 / 分屏 2 钮），编辑态 = 4 格式组 + 视图组（眼睛 / 分屏）。上轮 chevron-large 返回钮撤下，由眼睛钮取代。

**铅笔/眼睛互切 + Ctrl+E**。铅笔 = pencil.svg（烘焙 #808080 转 currentColor，命名对照十五批）；眼睛图标库没有——用户授权先挑库件，暂用 view-options（语义「查看」最近、已转色），分屏暂用 collapse-sidebar（框内一竖 = 左右分屏，最准），用户后续补专图标换名。Ctrl+E 查证 = 「发送至 Animate」（仅单选 fla 触发）——编辑态 textarea 自拦退出（输入框让位全局）；预览态进编辑在 `useGlobalKeys.onOperationKeys` 开头提前判——**该函数预览态整体 return，第一版追加在 fla 分支后 = 死码，探针 N 段抓出**，提前判后双向零冲突（预览的是 md 时 fla 判定本就不命中）。

**分屏实时预览**（用户参考图定形态，未走「新标签」降级）。左源码右渲染（同 draft 驱动，同步天然免费零成本）；中间分割条 = 5px 命中区 + 1px g3 线，hover / 拖拽 = 品牌色（§22 拖拽线同色系）；`splitRatio` 会话级 clamp 0.25-0.75（§9 ③ 窗口监听拖动）；两侧版心收窄 24（84 为单栏稿值）；ScrollThumb 双轨。预览态点分屏 = 直接进分屏编辑；编辑态点 = 开关；切素材重置。

**代码块换行**。`white-space: pre-wrap` + `overflow-wrap: anywhere`（长串必断），横滚与 kit-scroll-x 注入废除；预览页展区同步。
