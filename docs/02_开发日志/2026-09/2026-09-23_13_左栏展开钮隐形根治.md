# 2026-09-23_13 左栏「展开侧边栏」钮隐形根治（CSS 类名漂移）

2026-09-23

## 需求

用户实机报（新免安装包走查）：**展开侧边栏的按钮怎么没了**——左栏收起后，标签行首的展开钮消失。

## 定位

CDP 复现（`tools/cdp-sidebar-expand-probe.py` 前身 repro）：收起后按钮**在 DOM 里**（`ic-btn plain lg flip-h` 正常挂载）、颜色正常（亮色/三级 + currentColor），但容器 `.dv-pre-actions-container` computed **display:none**、零宽零高。病根 = `dockview-theme.css` 的显隐规则 `:not(:has(.icon-btn))` 引用的是 1.2 时代组件类名——阶段七按钮族封装把 IconButton 根类改 `ic-btn` 后，`:has(.icon-btn)` 永不匹配，容器恒隐藏（踩坑 085：CSS :has 引用组件类名 = 静默断链，DOM 断言测不出，只有几何 / 截图能抓）。

## 落地

- `src/styles/dockview-theme.css`：pre-actions 显隐探测改元素选择器 `:has(button)`（免疫类名再漂移），有钮 margin-right 12 同复；左 actions 区两条 `.icon-btn` 死规则删除（色档已由 IconButton plain 自带）；PreviewTitleBar `:deep(.icon-btn)` 同改 `.ic-btn`。
- 探针新立 `cdp-sidebar-expand-probe.py`：E1 无钮不占位 / E2 收起宽 0 / **E3 展开钮 display:flex + 钮 30×30 + svg 18（几何级可见性断言）** / E4 点钮还原 254，ALL PASS + 截图 `sb-expand-probe.png` 目验钮在标签行首可见。

## 验证

探针 E1-E4 全 PASS（修复前 E2/E3 复现必挂——容器 display:none）；typecheck 不涉及（纯 CSS / 注释改动）。

## 文档

踩坑 085 立档（四段式 + 预防条）；本修复随次轮免安装包重打发出。

## 遗留

无。PreviewTitleBar 为待退役旧件（§23 预览族轮再改），本次仅顺手修选择器漂移。
