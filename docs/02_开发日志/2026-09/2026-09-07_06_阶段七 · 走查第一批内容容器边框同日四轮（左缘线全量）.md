# 阶段七 · 走查第一批内容容器边框 · 同日四轮（左缘线还给每个容器，圆角仍只第一行第一列）

## 任务

三轮拆走拆分条常态线后，用户实机四报：左右分屏里只有左列有左缘线，「这个边框不是跟着容器走的么，我以为是分割后会自带一个 top-left」。

## 定性

「面板本身就自带边框」（条 6 原话）的本意 = **边框是容器的固有属性**：每个内容容器都带自己的左缘线，分割出的新容器自然有；分屏分界就是相邻容器的自带线，不画额外线。而**左上圆角**才是那个只给第一行第一列的限定（用户二轮明确过两次，四轮未推翻）。

一轮~三轮的误读：把「圆角 + 左缘线」捆绑成「第一行第一列限定」，右列容器被剥光了。

## 修法（一行级）

`border-left: 1px solid var(--n-l-a2)` 从「首屏选择器」下放到 `.dv-content-container` 全量规则；圆角选择器只留 `border-radius: 16px 0 0 0`。左栏收起归零覆盖不变（挂在圆角属性上）。

## 验证

`pnpm typecheck` 绿（纯 CSS 移动）。左右 / 上下分屏的容器线观感交用户实机。

## 文档

口径速查 §30 条 6 条目改写（左缘线全量 + 圆角首屏，分界语义写清）。
