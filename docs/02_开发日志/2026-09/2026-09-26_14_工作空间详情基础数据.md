# 工作空间详情基础数据：ws 视口选中文件显示磁盘实况详情（2026-09-26）

## 起因

用户实机报：工作空间视口选中文件后，右侧详情面板是空的。期望对标 Windows 资源管理器「详细信息」窗格——类型 / 大小 / 文件位置 / 修改日期 / 分辨率等。

空面板的根因在 `DetailPanel.vue loadDetail`：ws 条目 assetId 是 `ws:`+relPath 合成假 id（严禁发 assetId 类命令），函数对 `ws:` 前缀直接 return，`detail` 恒 null → `target` 计算属性不命中任何分支 → `DetailSections` 整体不渲染（v-if="target" 落空）。即「前端直接跳过」，不是命令报错。

## 定案

PRD 02 口径：ws 无任何附加数据（无标签 / 注释 / 评分），只有磁盘实况 + 缓存——所以详情只展示磁盘事实，不接库侧属性 / 描述 / 提示词 / 关系任何模块，也**不进 ui.detailBlocks 三 tab 配置体系**（不暴露信息查看管理入口）。形态 = 简化「基础信息」，结构沿既有文件夹详情形态（FolderDetail 同款壳：输入框区块 + BaseDataItem 基本数据卡），零新样式口径——全部复用定稿组件（TextInput 只读框 / BaseDataItem 信息卡）与 token。

多选形态与库侧对齐：库侧多选时详情面板显示选择域首项（`selectedAssetKey` = `selection.first` 转发），ws 侧走同一 `selectedAssetKey` 通道天然同口径——不另做多选聚合形态。

字段口径：

- **名称**（只读输入框）：磁盘文件名，跟随「显示扩展名」（`displayName` 同库侧口径）。
- **位置**（只读输入框）：所在目录绝对路径（`ws.absPath(parentRel)`）。走 TextInput 而非 BaseDataItem 行——信息卡值档 nowrap 数字档放不下长路径，链接输入框同款只读形态天然容纳。
- **尺寸行仅图片显示**：图片条目 w/h = 源像素（后端魔数 probe + thumb_formats psd/svg 适配器探测值）；**视频 / 音频条目 w/h = 缓存缩略图尺寸、字体条目 w/h = 试排样张 SPECIMEN 常量**（thumb_formats font 适配器），皆不可当「分辨率」展示误导用户——非图片不显示该行（不为视频补 ffprobe，性能轮另议）。前端按扩展名白名单判定（png/jpg/jpeg/bmp/webp/gif/psd/psb/svg）。已知边缘：图片扩展名但魔数探测失败且缓存新鲜时，w/h 实为缩略图尺寸，此时尺寸行数值偏小——罕见损坏场景，接受。
- **创建日期 / 修改日期**：ctimeMs / mtimeMs（`formatDetailDate` 两截：日期 + 时间，BaseDataItem 多截值口径；0 = 目录或平台不支持，不加行——无数据不加行旧口径沿）。
- **类型 / 文件大小**：类型 = 扩展名大写 +「文件」（Explorer 口径；无扩展名 =「文件」）；大小 = `formatSize`。

ctime 数据源：`WsEntry` 原缺创建时间——`entry()` 里 `fs::metadata` 已在手，`Metadata::created()` 零额外 syscall，顺手补 `ctime_ms` 字段（Windows NTFS 支持良好；目录 / 平台不支持恒 0）。

## 改动

- 后端 `services/workspace.rs`：`WsEntry` 加 `ctime_ms`；`entry()` 内 `meta` 改按引用取（原 mtime 取值是 move 语义），新增 created() 提取。
- 前端 `lib/wsOps.ts`：`WsEntry` 补 `ctimeMs`。
- 前端 `lib/detailSections.ts`：`DetailTarget` 加 `{ kind: "ws"; entry: WsEntry; dirPath: string | null }`。
- 新建 `components/sections/WsDetail.vue`：名称 + 位置两个只读 TextInput + BaseDataItem 数据卡（尺寸 / 文件大小 / 类型 / 创建日期 / 修改日期）。
- `components/DetailPanel.vue`：新增 `wsTarget` 计算属性——`selectedAssetKey` 为 `ws:` 前缀时按 relPath 从 ws store 目录缓存直达条目（禁发 get_asset_detail）；`target` 分流 ws 分支优先于库 file 分支（假 id 恒不命中库详情，条目不在缓存 = 刚被删 / 目录未加载，留空）。
- `components/DetailSections.vue`：ws 形态与文件夹形态共用滚动壳渲染分支（无分段控制器 / 无 pinned / 无信息查看管理钮）。
- `pnpm inventory` 台账刷新（WsDetail 入库，153 件）。
