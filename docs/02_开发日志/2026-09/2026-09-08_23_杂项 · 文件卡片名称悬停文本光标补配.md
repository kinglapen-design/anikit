# 杂项 · 文件卡片名称悬停文本光标补配
## 杂项 · 文件卡片名称悬停文本光标补配

用户实机报：文件卡片悬停到名称上时没有输入指针提示。

**根因**：卡片组件族惯例 = 名称区悬停 `cursor: text`（注释统一写作「名称区悬停文本光标（双击可改名）」），FolderCard `.fd-name:hover` / ArchiveCard `.ar-name:hover` / ListRowCard `.lr-name` 三处先例均在；7.1 新件 FileCard 的 `.kc-name`（cards.css 共享基座）漏配——双击重命名功能本身在（v-tip / nameEdit 齐全），只差光标提示。

**修法**（`FileCard.vue` scoped，与三处先例同款）：`.kc-name:hover { cursor: text; }`。

**验证**：`pnpm typecheck` 0 错、`pnpm build` 通过。**行为变化交实机走查：悬停文件卡名称出现 I 形文本光标。**
