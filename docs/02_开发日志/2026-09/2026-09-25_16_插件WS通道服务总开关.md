# 2026-09-25_16 插件 WS 通道服务总开关（MCP 同款）

2026-09-25，feat/new-ui。用户问「CEP 有没有开关控制通信？平时不用也在监听吗？」——查实：plugin_ws 恒监听无开关（MCP 有总开关），当场落地同款。

## 后端

- **配置**：`settings.pluginServer.serverEnabled` 缺省开（core::config 单写点；独立子树原因同 MCP——save_ui_settings 整体替换语义会抹掉 ui 子树外挂键）。新增读写 + 测试（缺省开 / 关态往返 / camelCase 键名）。
- **生命周期三函数**（plugin_ws，照 MCP 范式）：`init` 读开关决定本轮是否拉起；`start` 幂等（运行中回端口 / 尸体清理 / 并发弃新保旧）；`stop` = stop 信号收束 accept 循环 + **abort 全部客户端连接**（WS 长连接不随 listener 关闭自然断开，ClientEntry 加连接任务 AbortHandle——channel 与条目建点从 handle_conn 上移到 serve accept 处）+ drain 全部 pending 立即失败 + 删端口文件（残留会误导面板连死端口，MCP 同口径）。
- **命令**：`get_plugin_server_status` / `set_plugin_server_enabled`（新 commands/plugin_server.rs；先启停后持久化，启动失败不记开态；回包 running / port / serverEnabled 同构）。

## 前端

- `lib/plugins.ts` 加 PluginServerStatus 封装（get/set，MCP 同款——get 静默 null、set 成败 toast + 回包校正）。
- AnimatePluginWindow 详情窗加「通信服务」组（居首）：开关行（SwitchButton，动作后以回包校正，与安装/卸载 busy 互斥）+ 运行状态行（圆点 + 字重双指示 + 地址三件套，照 MCP 窗 09-20 定案样式逐项 token 一致）。
- preview 展区 PreviewPlugins 复刻壳同步补组（R1 纪律；壳高 538→640 与 MCP 复刻同高）。
