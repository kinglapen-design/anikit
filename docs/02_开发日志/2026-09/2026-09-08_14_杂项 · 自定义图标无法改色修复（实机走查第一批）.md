## 杂项 · 自定义图标无法改色修复（实机走查第一批）

实机走查第一批：自定义图标无法改色。现象 = 文件夹设了自定义图标（02_自定义 双色集）后，右键「更改颜色」只染默认文件夹图标，自定义图标恒灰不变。

**根因**（`src/components/items/TreeRowItem.vue` 模板 folder 分支）：自定义图标走了 `AppIcon` 原值直出通道——02_自定义 SVG 文件保留 Figma 烘焙原值（亮层 `#BFBFBF` / 暗层 `#666666`，全库 32 件扫描确认仅此二色 + none），CSS color 与 tint 均不吃；而默认的 folder-closed / folder-open 走的是 `TwoToneIcon`（`getTwoToneIcon` 把两个 fill 换成 `--tone-1 / --tone-2` 变量通道，`data-tint` 切九色对），所以只有默认图标跟色。`FolderTree` 侧 `:icon` 与 `:tint` 本就一直同传，纯渲染分支漏接。

**修法**：folder 分支自定义图标改走 `TwoToneIcon` 并传 `:tint`，与默认文件夹图标同一通道；连带清掉因此失效的 `.fico` color 档死规则（原设计想以 color 驱动自定义图标，对硬编码 fill 的双色 SVG 本就无效）。九色对、选中态行为与默认文件夹图标完全同口径（选中不另提亮，tint 保持）。

**波及面核查**：自定义图标消费点全库只有四处——主树 `FolderTree → TreeRowItem`（本次修复）；`FolderPickNode / MoveNode → 旧 TreeItem`（移动/选择弹窗旧体系，tint 视觉语言是行底色而非图标色，随其重构轮贴稿，不动）；`BlockManageRow`（区块默认图标选择器，区块无颜色语义）；`FolderIconGrid`（更改图标选择面板，统一显示默认双色，正常）。文件夹卡片 `FolderCard` 恒用 folder-large 不接 tint（既有定案），不在本条范围。

**验证**：`pnpm typecheck` 0 错；设计系统预览页 `PreviewItems.vue` 树容器 item 区新增「自定义图标 · 常态双色 / + tint 改色联动 / + tint + 选中」三格验收面（dev 预览页可看）。实机走查：文件夹设自定义图标后右键更改颜色，图标双色应随九色联动。归档区 `实机走查.md` 只读，勾选由用户侧处理。
