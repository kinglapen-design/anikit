## 阶段八 CEP 补场景 · 批次 1：导出比例档（用户四点需求之一）

**背景**：用户提出 CEP 四个补场景——① 导出比例（竖版人物导宽屏浪费 APP 布局空间）；② 已有 fla 仅补缩略图（帧范围可选）；③ 一 fla 多素材批量分别导出；④ 缩略图替换机制答疑（换绑靠 `thumb_asset_id` 资产级引用不靠哈希，链接红利天然；旧图处置与入口归后续批次定）。分批落地，本批 = ①。

**定案**：比例基准 = **高度跟随当前文档，宽 = 高 × 比例**（四舍五入取整；用户拍板，弃内容包围盒 / 固定长边两案）；「自动」= 跟随文档原尺寸（现状行为保留）。

**落地**（plugins/animate-cep/，APP 侧与 WS 协议零改动）：

- `index.html`：静/动分段下加比例区分段（自动 | 16:9 | 4:3 | 1:1 | 3:4 | 9:16）+ 自定义比例输入框（placeholder「自定义比例 宽:高（如 2:3）」），样式全复用 seg / input 既有控件。
- `panel.js`：分段与自定义框**互斥**——点分段清自定义框；自定义框输入合法比例（`宽:高`，支持 `:：x×/` 分隔符）即生效、分段去选中；清空自定义框回「自动」；非法输入标红框（`.input.err` → `--n-danger`）沿用上一生效值。选择经 localStorage（key `cepRatio`）记忆，面板重开恢复。导出调用 `exportSelection` 追加 ratioW/ratioH 两参。
- `host.jsx`：`exportSelection(name, outDir, dynamic, maxFrames, ratioW, ratioH)`——比例档生效时 `W = Math.max(1, Math.round(H × ratioW / ratioH))`，高度恒随文档；缺参（旧面板）自动回退跟随文档，向后兼容。内容缩放居中（短边 90%）逻辑不变自动适配。
- `panel.css`：仅加 `.input.err` 一条（token 既有）。

**验证**：node --check panel.js / host.jsx 语法过；四文件已同步 `%APPDATA%\Adobe\CEP\extensions\com.anikit.cep`（install.bat 是 cmd 双击用——Git Bash 下中文注释按 GBK 解析乱码跑挂，手动 cp 等效）。**下一步：用户实机复验（比例档导出 fla 舞台尺寸 / 自定义比例 / 记忆恢复）**。
