# 阶段七 · 自动导入行数量含未导入源文件

## 任务

2026-09-08 用户报：左栏快速访问「自动导入」行的数量只算已导入素材，不识别收件箱里未导入的源文件（"不好做的就算了"——实际现成数据源，低成本可做）。

## 做法

一处改动（`LibraryView.vue` `quickCount`）：`inbox` 分支由 `content.inboxCount`（已导入未摘标）改为 `content.inboxCount + content.inboxDisk.length`。磁盘实况 `content.inboxDisk`（InboxDiskEntry[]，services/inbox.rs 全量重扫）本就是「工程文件」区块数据源，热刷新（inbox-disk-details 事件 + 150ms 防抖）早已接入，直接合计即可——数量与视口「工程文件 + 已导入」两区块内容同口径，与全部/未分类"按视图同口径计数"的既有原则一致。占用条目（occupied）仍是未导入源文件，计入。

## 验证

`pnpm typecheck` 绿。计数实机观感交用户走查。

## 文档

口径注记在 `LibraryView.vue` quickCount 头注（2026-09-08 行）；本日志。
