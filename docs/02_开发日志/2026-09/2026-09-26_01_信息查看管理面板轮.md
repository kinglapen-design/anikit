# 信息查看管理面板轮（三 tab 化重立，旧 22 稿 SectionEditPanel 后继）

日期：2026-09-26　分支：feat/new-ui　稿 = 无（用户当场定案：「重新设计，三 tab 和详情面板三 tab 对应」）

## 背景与定案

旧 22 稿「编辑数据区块」面板（SectionEditPanel，AppMenu 404×440、箭头+标题+眼睛、即时生效）在 2026-08-31 详情面板三 tab 化时随旧区块体系删除，右栏底部「信息查看管理」钮与视图菜单项自此点亮占位（§23「后续轮接」）。本轮把该业务接回——用户定重新设计方向 = 面板内部同样三 tab，与详情面板三 tab（基础信息 / 链接关系 / 提示词）一一对应；显隐图标 = 用户直投 view / view-off（「我放 icon 列」）。

三个无稿自定点（方案确认时一并过）：壳宽 460、显隐用眼睛（不用 SwitchButton）、即时生效无按钮行。

## 落地内容

**弹窗（InfoManageDialog）**：BaseModal framed 460（管理弹窗族先例：区块管理 559 / 分组管理 640）；SegmentedControl text 型三段（g3 壳语境 tone g2，§48）+ 行列表定高 260（5 行×52，切 tab 不跳高）；打开默认落详情当前 tab（ui.detailTab 快照不反写）；tab 切换动画 = 详情面板同款（旧左出/新右入 48px，§23 时序），排序动画 = TransitionGroup 交换 150ms（bm-swap 同款）；即时生效——排序/显隐直写 ui.detailBlocks，settings.ui 防抖 500ms 写回，无确认/取消按钮行。

**行组件（DetailBlockRow）**：52 高（border-box）/ 底线 g5 末行去线 / 下移+上移箭头（chevron-small，首行禁上末行禁下，禁用 30%）+ 标题（隐藏行 = --n-l-disabled——22 稿注「眼睛切换标题要禁用」）+ view/view-off 眼睛（bare lg 新件自带色档）。

**配置（ui.detailBlocks）**：三 tab 各 `{ order, hidden }`——order = 全量序（管理面板行序含隐藏），hidden = 详情渲染过滤。注册表 lib/detailSections.ts（basic = fields/tags/descs/baseData、links 五块、prompt 单块 + DETAIL_TAB_BLOCK_TITLES），mergeDetailBlocks 兜底；**旧 ui.detailLinksOrder 迁移并入 links.order 后废除**（loadSettings 通道，briefMode 先例）。

**详情侧接入**：TabBasic 四区块改 v-for 配置驱动（原写死四个 section）；TabLinks 渲染序 = 全量序过滤 hidden，拖标题行落点改 moveDetailLinkToVisible（可见序落点、hidden 项锚定原位重建全量序——与管理面板箭头排序同一配置双入口）；TabPrompt 单区块 hidden 即整 tab 空白（允许全隐藏，无空态文案）；pinned 恒顶不进面板（旧口径沿）。

**入口**：右栏底部钮 @click + 视图菜单「信息查看管理」disabled 占位点亮 → ui.infoManageOpen（会话级），宿主 App.vue（blockManageOpen 惯例）。

**图标第十六批 2 个**：view / view-off（用户直投，#141B34 单灰线条转 currentColor；设计底稿 查看.svg / 查看-关闭.svg 补入 docs/06_UI重构/图标/01_常用/，命名对照登记）。
