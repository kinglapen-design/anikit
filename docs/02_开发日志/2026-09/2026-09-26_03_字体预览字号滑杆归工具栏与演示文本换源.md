# 字体预览字号滑杆归工具栏与演示文本换源

日期：2026-09-26　分支：feat/new-ui

## 背景

用户实机走查字体预览，两轮共五条：

1. 预览区底部的字号悬浮滑杆（稿未画的现行为件）与顶部工具栏尺寸滑块位重复——稿 预览工具栏 本有「尺寸滑块」位（viewable 媒体作缩放用，font kind 一直未亮）。
2. 演示文本该换——用户备好 `assets/text/荷塘月色_中文.md` + `荷塘月色_英文.md`（中文全文 + 英译全文），替换旧 Eagle 英译选段 + 兰亭集序占位。
3. （二轮）滚动条位置不对——贴着文字预览区右侧，要同 MD 预览贴中间面板右缘。
4. （二轮）md 里的样式要保留：引用（`> *…*`）与下划线（`<u>`）。
5. （二轮）中英不是同屏双段排布，是切换：中文字体只放中文，英文/其他字体放英文。

## 落地

- **字号状态上会话**：`stores/preview.ts` 新增 `fontSize: 15`（per-panel 会话态，默认 15 对齐稿值；标题 ×2）——PreviewTitleBar 与 PreviewFont 经会话共享，不再组件自持。
- **PreviewTitleBar**：滑块组条件 `viewable` 放宽为 `viewable || kind === 'font'`；font 时滑块 = SideSlider 12–72px 直绑 `preview.fontSize`，读值 `{{fontSize}}px`（沿用 zoom-text mono 12/16 三级档）；其余 kind 缩放语义不变。
- **PreviewFont 结构**：底部 `.size-bar` 悬浮滑杆与本地 `fontSize` ref 拆除；`.range` 的横向 72 版心下放到 head / 分段包装 / 滚动容器各子级——**滚动容器通宽，ScrollThumb 贴 `.page` 右缘 = 中间面板右缘**（同 MD 预览口径）；页区 2px g4 顶线改 `.page::before` 收 72 版心，视觉同稿。
- **演示文本换源 + 样式保留**：两 md 经 `?raw` 构建期内联，极简解析（`##` 行 = H1 块、`>` 开头 = 引用块——整段 `*斜体*` 脱壳由 `.demo-quote` 承担：左 2px g3 竖线 + padding 4/0/4/16 + 引用色 + 斜体、其余空行分段 = 正文块；`<u>` 经全文转义后恢复 = UA 默认下划线）；**中英按 `info.hasCjk` 分流切换**（同卡片示例字口径；info 未载完默认中文）——中文 13 块（1 标题 + 11 正文含 1 段下划线 + 1 引用）/ 英文 11 块（1 + 9 + 1）。

## 验证

`pnpm typecheck` 绿、`pnpm build` 绿（?raw 外链资源内联正常）；解析逻辑 Node 复跑核对 = 13/11 块、引用/下划线块命中、无标记残留。滑块联动、引用/下划线观感、中英切换与滚轮贴缘待实机目验。
