# 字体预览字号滑杆归工具栏与演示文本换源

日期：2026-09-26　分支：feat/new-ui

## 背景

用户实机走查字体预览提两条：

1. 预览区底部的字号悬浮滑杆（稿未画的现行为件）与顶部工具栏尺寸滑块位重复——稿 预览工具栏 本有「尺寸滑块」位（viewable 媒体作缩放用，font kind 一直未亮）。
2. 演示文本该换——用户备好 `assets/text/荷塘月色_中文.md` + `荷塘月色_英文.md`（中文全文 + 英译全文），替换旧 Eagle 英译选段 + 兰亭集序占位。

## 落地

- **字号状态上会话**：`stores/preview.ts` 新增 `fontSize: 15`（per-panel 会话态，默认 15 对齐稿值；标题 ×2）——PreviewTitleBar 与 PreviewFont 经会话共享，不再组件自持。
- **PreviewTitleBar**：滑块组条件 `viewable` 放宽为 `viewable || kind === 'font'`；font 时滑块 = SideSlider 12–72px 直绑 `preview.fontSize`，读值 `{{fontSize}}px`（沿用 zoom-text mono 12/16 三级档）；其余 kind 缩放语义不变。
- **PreviewFont**：底部 `.size-bar` 悬浮滑杆与本地 `fontSize` ref 拆除（`.demo` 底部 72 留位 padding 同撤）；演示文本换源——两 md 经 `?raw` 构建期内联，极简解析（`##` 行 = H1 块、空行分段 = 正文块、`>`/`*斜体*`/`<u>` 标记剥离取纯文本），中文 13 块 + 英文 11 块双段排布渲染。

## 验证

`pnpm typecheck` 绿、`pnpm build` 绿（?raw 外链资源内联正常）；解析逻辑 Node 复跑核对两份 md = 13/11 块、无标记残留。字号滑块联动与排版观感待实机目验。
