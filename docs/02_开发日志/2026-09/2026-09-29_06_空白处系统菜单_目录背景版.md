# 空白处系统菜单：目录背景版（2026-09-29 六轮）

用户确认经典菜单内容后要求：「再补一个空白处右键的排序那些」——条目右键没有 新建 / 排序方式 / 查看 是正确行为（那是目录背景菜单的项），本轮把背景版系统菜单补上。

## 实现

- `adapters/shell_menu.rs` 重构出背景形态：条目菜单（GetUIObjectOf 全 PIDL）与背景菜单共享「建窗 → QueryContextMenu 装配 → 光标处模态弹出 → InvokeCommand」管线（`popup_and_invoke` 改收构建闭包）；背景菜单对象 = `SHParseDisplayName` 得目录全 PIDL → 桌面 `BindToObject` 取目录自身 IShellFolder → `CreateViewObject<IContextMenu>`（Explorer 文件夹空白处右键同径）。
- 新命令 `ws_shell_menu_background(absPath)`（validated_ws_path + is_dir 校验，spawn_blocking STA 同条目版）；前端 `wsOps.wsShellMenuBackground` + `wsBlankSpec` 在「在资源管理器中显示」后挂「系统菜单」。

## 内容与边界

弹出的经典背景菜单含：查看 ▸ / 排序方式 ▸ / 刷新 / 新建 ▸ / 属性 等（与 Explorer 该目录 Shift+F10 空白处同一张）。「新建」落盘的文件经 watcher 热刷新回 ws 视图；**查看 / 排序方式子菜单作用于 Explorer 的视图对象，托管菜单里天然无效**（先天边界，非缺陷——同「Win11 新样式 IExplorerCommand 不可托管」一档）。
