# 2026-09-23_11 详情缩略图区块接业务（8.1 伴生缩略图闭环）

2026-09-23

## 需求

用户实机走查：**缩略图链接里没有显示文件调用的缩略图**——fla 详情链接关系 tab 的「缩略图」区块自 7.1 二十三轮起是 UI 占位（§23 记「反查功能未立项」），fla 明明绑着伴生 webp（thumb_asset_id），区块里什么都没有。

## 落地

**后端**（`commands/archive.rs`）：`AssetDetail` 扩两字段——`thumbAsset`（调用侧：本资产 thumb_asset_id 指向的 hidden 伴生资产，`{ assetId, name, users }`，name = 首条 Placement 显示名，users = 它被引用的总数，对应稿「雪牧_自动.webp + 2」；目标非 hidden = null，同 views 代理口径）+ `thumbUsedBy`（被调用侧：本资产是 hidden 缩略图时引用它的资产清单，按显示名排序）。新命令 `unbind_thumb_asset(assetId)`（services/asset_menu.rs）：仅清工程侧 thumb_asset_id，hidden 侧不动（还原走 restore_thumb_asset），幂等、不接撤销（同缩略图三件套口径）。

**前端**（`sections/TabLinks.vue`）：缩略图区块双形态——调用侧卡（LinkThumbItem 名称 + 引用数）/ 被调用侧使用方行。点 item = 跳转定位：伴生资产 hidden 普通视图不可见 → 跳「缩略图」快速访问视图选中（requestReveal + selectOnly）；使用方行走既有 jumpToAssetPlacement。× = `unbindThumbAsset`（placementOps：refresh + bumpDetailRev + toast）。**添加钮点亮 = picker 第五用途 thumb**：仿 cover 单选直回范式（enterThumb → filterImage 过滤同 isThumbCapableExt 口径 → 点图即 set_thumb_asset 绑定/换绑 → 退模式恢复发起文件选中），AssetGrid 点击分发加 thumb 分支。
