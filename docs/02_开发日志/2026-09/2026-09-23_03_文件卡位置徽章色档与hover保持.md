# 2026-09-23_03 文件卡位置徽章：色档升亮色/一级 + hover 徽章保持卡 hover 态

2026-09-23

## 需求

用户实机走查两条：① 卡片右下角链接标识太暗看不清，改成最亮的亮色/一级；② hover 到标识上时卡片丢失 hover 动画移回去、标识却停在原位，视觉脱节——hover 标识时整个卡片要保持 hover 状态。

## 根因（第 ② 条）

徽章 `.card-badges` 渲染在 AssetCard 壳层（FileCard 的兄弟），**不是 `.kc-media` 子树**。hover 徽章时命中链不经过 `.kc-media`，`.kc-media:hover` 丢失 → 卡芯位移/阴影/描边回退；而徽章跟随规则 `.asset-card:hover .card-badges` 仍成立 → 徽章停在 -4px，卡片回去了，脱节。

## 落地

- **色档**：`.card-badges` color `--n-l3` → `--n-l1`（亮色/一级）。
- **结构修复（不复制样式）**：FileCard 加 named slot `badges`（kc-clip 裁剪层外、根内末尾，originBadge 旁），AssetCard 把徽章挪入该槽 → 徽章成 `.kc-media` 后代，hover 徽章即保持 `.kc-media:hover`，位移/阴影/描边/悬停控件全不回退。定位几何不变（FileCard 根 100% 撑满壳）；LinkListPopover 仍挂壳层。
- **同日二轮走查修订（位移双份）**：入槽后徽章随卡芯天然 -4px，壳层补偿规则 `.asset-card:hover .card-badges` 未删 → -8px 比卡片幅度大。已把 `.card-badges` 从壳层附件 transition/transform 组剔除；picked 压暗规则保留（徽章在 clip 外不被卡内压暗覆盖）。

## 范围说明

档案卡右下徽章（§16 二级档）与 FileCard `originBadge` prop（品牌色原值 SVG）不在本次范围，未动。

## 验证

`pnpm typecheck` 绿。探针零改动（cdp-link-manage-probe.py 三处 `.card-badges` 断言均为 `.asset-card` 后代查询，层级加深不影响）。徽章观感与 hover 保持待实机走查。
