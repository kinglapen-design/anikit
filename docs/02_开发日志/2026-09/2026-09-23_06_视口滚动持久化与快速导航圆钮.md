# 2026-09-23_06 视口滚动三件套（持久化 + 跳转定位 + 快速到顶/到底圆钮）

2026-09-23

## 需求

用户实机三条：① 每个视口的滚动条要持久化——大列表翻找到文件，切走再回来又得重新找；② 链接文件跳转后滚动条要定位到目标卡（现状停顶端）；③ 视口右下角补快速到顶/到底圆钮（往下持续滚动出「到底」、往上出「到顶」），样式用搜索框同款变纯圆形 + 箭头。

## 落地

**滚动位置持久化**：content store 会话级 `Map` 废除，迁 `ui.scrollPositions`（viewKey → 像素，PERSIST_KEYS 登记，settings.ui 防抖 500ms 落盘 config.json，`viewRowHeights` 同款应用级口径）——切视口 / 进出预览 / 关标签页 / **重启应用**全恢复。`useGridLayout` 恢复改**保留式**：未到位（异步内容视口高度不足被夹，如工作空间目录加载中）保留待下次重排重试，到位才消费；`useVirtualScroll` 新增用户源滚动回调（wheel/键盘/拖块/点轨道带真实位移上报），用户一滚即放弃悬着的恢复位。序列帧包内视图（原生滚动）同口径接入：`load(restore)` 首载/换包恢复，换包与卸载保存。

**链接跳转定位**：`relationOps` 两个 jump 登记 `content.requestReveal(viewKey, key)`（store 单槽位 `pendingReveal`）；`useGridLayout` 重排末尾消费——目标卡已在视野内不动、否则滚到居中，覆盖恢复/锚点位；同视口跳转（viewKey 不变、items 引用不变，两 watch 都不触发）由新增 `pendingReveal` watch 自驱动一次重排。找不到卡（搜索过滤/折叠组内）= 消费即放弃，静默。

**快速到顶/到底圆钮**：新组件 `src/components/QuickNavButton.vue`（`dir` + click，呈现层），AssetGrid（虚拟滚动 onUserScroll 驱动）与 SequencePackView（原生 scroll 驱动，点击后挂起、wheel 重新武装——scroll 事件不区分用户源/程序源）共用。状态机：同向累计 ≥200px 出现（下滚出「到底」/上滚出「到顶」），停止 1.5s 收起，点击平滑滚动到位即收起，切视口收起清零。按钮 = `IconButton` 新增 **circle 变体**（42×42 纯圆 radius-pill，搜索框壳同款 g-a2 + raised + blur-sm，hover g4 底 + l2 图标）；箭头 chevron-large（源朝左）旋转定向（上 rotate(90deg) / 下 rotate(-90deg)）；定位 bottom 12（与悬浮栏同水平线）/ right 20（让开滚动条命中区）；出入场位移 8 + 透明度 250ms（悬浮栏族动画档 §18 同口径）。平滑滚动 = `useVirtualScroll.smoothScrollTo`（300ms easeInOutCubic，程序源不上报，用户滚动打断）；包内视图用原生 `scrollTo({behavior:"smooth"})`。

## 验证

`pnpm typecheck` 绿（vue-tsc 零错误，覆盖全部 .vue 改动）。预览页 PreviewButtons 补 circle 常态/hover 陈列（旋转演示类在 preview.css——**全局 CSS 禁写 `:deep()`，无效选择器整条规则作废**，`.app-icon` 直接后代选择）。滚动恢复 / 跳转定位 / 圆钮手感待用户实机走查。
