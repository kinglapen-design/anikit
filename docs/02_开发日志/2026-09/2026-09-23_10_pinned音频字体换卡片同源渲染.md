## 需求

用户实机走查（09 轮同日续，两截图）：**右侧边栏的音频和字体还是旧的缩略图**——mp3 详情 pinned 仍是旧静态波形 webp（640×272 图），ttf 仍是旧样张 webp（640×480 图）；卡片层 2026-09-22 已换 R6 新渲染（WaveContent 竖线波形 / FontContent 示例字真渲染），pinned 没跟上。

## 落地

`src/components/sections/SectionPinned.vue` 文件形态 pinned 内容三分流：

- **音频**（isAudioExt）= `WaveContent` 竖线波形，peaks 走 `cardPeaksFor` 懒加载（与卡片同缓存同版本戳）；静态展示 progress 恒 0，无品牌色扫过层、无悬停胶囊（pinned 不接播放交互）。
- **字体**（isFontExt）= `FontContent` 示例字以该字体真渲染，`cardFontFor` 懒加载 + hasCjk 分流（中文四行 / 拉丁三行）；字号随容器宽自缩放（240 容器 ≈ 19.6px，稿基准 220↔18 同比）。
- 其余格式 = 既有 img 缩略图 / 格式图标 50% 居中 / 无图占位不变；FormatBadge 徽标照常。

示例字常量 `FONT_LINES_CJK / FONT_LINES_LATIN` 自 AssetCard 抽至 `lib/cardFonts.ts` 导出共用（卡片 / pinned 两处消费）。

await 切选中防错配、失败静默兜底均同卡片口径；ws 合成项不进本面板（DetailPanel 早退），无需假 id 护栏。
