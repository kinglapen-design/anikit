# 阶段七 · 快速访问入口收窄（视口二分：虚拟视图禁位置级与落点类）

## 任务

2026-09-09 用户发起讨论：快速访问的入口限制（"这里最难搞了"）。四轮对话定案后落地。

讨论链：① 助手提"整理档/找到即用档"框架 → ② 用户四点：查看定位类全留 / 新建文件夹档案一律不留（快速访问无文件夹概念）/ 未分类必须留导入（没想好去哪的素材先导入）/ **重命名全留**（雪牧.fla 改名后 hidden 伴生雪牧.webp 也要跟着改，不然以后对不上；最近使用顺手改名）→ ③ 用户点破核心："**全部自己都不算一个位置**，在全部里移动文件 = 黑箱，用户不知从何移到何；但删除不一样——这东西要不要一眼可辨，不用在乎他在哪" → ④ 拍板"按聊的来，收紧这些入口，后面使用过程测试再调"。

## 定案（PRD 02-15 已同步）

**视口二分**：未分类 / 自动导入 = 位置视口（真实落点，位置级操作全开放；未分类放开导入 / 新建文档 / 粘贴 / 拖入 = 候车区总入口，自动导入维持 09-08 禁手动添加）；全部 / 最近使用 / 缩略图 = 虚拟视图（不是位置）；回收站维持 09-05 口径不动。

**虚拟视图禁**（右键不出现，菜单栏 / 快捷键 / 拖拽源同判定）：移动 / 剪切 / 创建副本 / 粘贴两项 / 导入 / 新建文档 / 从文件夹中移除 / 卡片拖出。**留**（资产级 / 所见即所得）：打开外发全组 / 链接管理与位置导航 / 复制 / 导出 / 重命名 / 标签 / 描述 / 缩略图绑定组 / 设为原始（条件出现照旧）/ **丢到回收站**（删除组自此拆开——「从文件夹中移除」名字即位置语义禁，「丢到回收站」资产判断留，修订 08-18"同口径"）。占位项（新标签页 / 添加资源库 / AI / 提示词 / 置顶）快速访问右键不列。

**连带**：「全部」导入 / 新建封堵（推翻 09-08"全部/未分类允许"半句——全部不是位置，落点必借道）；新建文件夹 / 档案六视口一律禁；空态导入双钮范围 quick:all → quick:uncategorized（库空引导挪候车区）。

## 做法

统一判定入 content store 三 getter（isRecycleView 旁）：

- `isNoImportView` 扩五视口（quick:\* 且 ≠ uncategorized）——原四视口加「全部」；拖拽拒入 / Ctrl+V / 菜单栏导入与新建文档组 / pickImportPaths 兜底自动随扩；
- `isVirtualView` 新（all / recent / thumbnail）——assetCardSpec 分流 `virtualAssetCardSpec` 收窄集（15 项：打开外发 6 + 链接管理 / 设为原始条件 / 链接位置 + 复制文件 / 粘贴标签描述条件 / 重命名 + 缩略图▸六项 + 导出拍平一级「导出到本地磁盘」+ 复制数据▸ + 丢到回收站）；useGlobalKeys 禁 Ctrl+Y / Ctrl+X / Ctrl+D / Shift+Del（F2 / Ctrl+C / Delete 留）；dragOperation 卡片禁拖出（与回收站同守卫，按下不启动手势）；appMenu 整理「移动」与 editMenu 剪切 / 副本 / 移除置灰；
- `isQuickView` 新（quick:\* 六视口）——菜单栏新建文件夹 / 档案整组置灰。

放开面：`pasteTarget` 未分类豁免（落 "root"，toast 文案改「当前视口不支持粘贴」）；editMenu 粘贴两项置灰改挂 pasteTarget 同口径（folder: 或 uncategorized——顺带补上回收站 / seq: 漏判）；空白菜单 gridDispatch 全部降 scanOnlySpec、未分类保持 quickFullSpec；拒入弹窗文案列五视口名 + 引导「文件夹视口或未分类」。
