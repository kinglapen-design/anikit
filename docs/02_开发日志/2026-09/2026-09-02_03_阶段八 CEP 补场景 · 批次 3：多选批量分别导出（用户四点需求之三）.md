## 阶段八 CEP 补场景 · 批次 3：多选批量分别导出（用户四点需求之三）

**场景**：公司素材常多个元件挤一个 fla（截图 3 三个烟雾），需逐个独立成 fla 入库。PRD 07-03「多选：将所选项分别导出 fla」落地（"导出为单一 fla"联合包围盒归 8.3 不做）。

**落地**（纯插件侧，APP/协议零新消息——复用 exported 单条逐发）：

- **jsx**：`beginBatch()` 快照舞台多选（全局 `__batchSel` 跨 evalScript 有效；非元件实例 null 占位，返回 count + names）；`exportBatchItem(i, …)` 校验元素存活 → 设单选 → 复用 `exportSelection`（name 空 = 元件名）；`endBatch()` 清快照。快照期失效（文档切换/删除）该项报错跳过。
- **面板**：导出钮 file 模式先 `beginBatch` 探测——count≤1 走原单选流程（抽 `exportSingle`），>1 走 `exportBatch`：逐单项 evalScript 驱动（**进度实时回传**「(2/3) 烟雾2 已导出…」、可中断），命名 = 各元件名（命名框批量期禁用置灰），比例/静动档各项沿用面板当前档。批量计数（sent/done/ok/fail/jsxDone）：importDone/Error 批量期计数静默、完成汇总「N 项入库，M 项失败」；完成条件 = jsx 循环止且回执全收。**连接中断保护**：onclose/onerror 统一 `onWsDead` 复位 exporting/batch/命名框禁用（单选导出期断连卡死同族坑一并修）。
- 命名冲突入库侧既有 `-2`/`-3` 唯一化兜底。

**验证**：node 语法过；后端零改动（cargo 429 维持）；四文件同步 extensions。**下一步：用户实机复验（三个烟雾多选 → 逐个入库 + 各自缩略图绑定 / 中混非实例跳过 / 断连保护）**。
