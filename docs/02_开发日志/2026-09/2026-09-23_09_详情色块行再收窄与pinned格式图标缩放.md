# 2026-09-23_09 详情色块行再收窄（音频/字体）+ pinned 格式图标 50% 居中

2026-09-23

## 需求

用户实机走查（08 轮同日续，两截图定案）：

1. **音频和字体也没必要了，因为他们的颜色是永远不变的**——mp3 波形缩略图恒一席灰、ttf 字体预览缩略图恒灰白档，色块行显示出来没有信息量，同 docx 一样隐藏；
2. **shell 图标撑太满了，百分比比例缩放下，看卡片缩放的数值是多少**——pinned 缩略图容器里 docx 的 shell 格式图标 100% 撑满 240 方太满，按卡片格式图标的既有缩放数值百分比缩放。

## 落地

均 `src/components/sections/SectionPinned.vue` 一处：

- **色块行显隐追加音频 / 字体排除**：`showSwatches = thumbKind === "asset" 且 !isAudioExt(ext) && !isFontExt(ext)`（复用 `lib/formatBadge.ts` 既有判定：audio = mp3/wav/wma，font = ttf/otf/ttc）。后端取色管线不动（colors 数据仍随缩略图生成落盘，仅供显示层取舍）。
- **格式图标 50% 居中**：pinned 缩略图 img 在 `thumbKind === "formatIcon"` 时挂 `.fit-icon`（absolute left/top 25% + 宽高 50% + contain + 圆角归零）——数值直接对齐卡片 ThumbContent 的 icon 档（「格式图标 50% 居中，Eagle 口径」），这正是用户所问「卡片缩放的数值」= **50%**。
