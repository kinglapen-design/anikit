# 工作空间三类填充卡对接（文本卡 / 音频波形卡 / 字体卡，2026-09-26）

## 起因

库侧 2026-09-22 已落地三种填充卡（R6 三变体：文本卡词干标题+正文滚动预览、音频卡 128 根竖线波形、字体卡 FontFace 示例字真渲染），但 AssetCard 里三个 Active 计算全部带 `&& !isWs` 闸——ws 条目 assetId 是 `"ws:"+relPath` 合成假 id，铁律假 id 不得发给后端命令，ws 卡片因此恒为 general 卡（只有缩略图或格式图标）。本任务把三类填充卡接到工作空间视口，先例是 `get_media_source_by_path` 的按路径命令模式（越界校验 + 服务层本就按路径工作）。

## 方案

四条链路统一范式：后端加按路径命令薄壳（存在性 + `ws::is_under` 越界校验 → 调既有按路径服务层），前端三个卡片加载器（cardText / cardPeaks / cardFonts）按条目是否带 `wsPath` 分流——**假 id 只作前端会话缓存键（纯前端键允许），发后端一律 wsPath 绝对路径**；缓存版本戳沿用 modifiedAt（ws 条目由 mtimeMs 转来，文件改动后自然重拉）。固定比例判定（音频 2:1 / 文本 5:4 / 字体 1:1）在 `useGridLayout` 按扩展名走、与 ws/库无关，接通即自动生效。

## 后端（4 个新命令 + 测试）

- `read_text_by_path` / `read_docx_by_path`（commands/text.rs / docx.rs）：薄壳调 `text::read_text` / `docx::read_docx`，越界 / 非目标格式 / 超上限中文报错（前端卡片 catch 兜底空串）。
- `get_audio_peaks_by_path`（commands/media.rs）：语义同 `get_audio_peaks`（恒定 128 根），**产物磁盘缓存换锚**——库侧 `cache/peaks/{assetId}.json+.stamp`，ws 无资产 id 可挂，仿 ws 缩略图口径存 `workspace/.anikit/peaks/{urlsafe(rel)}-{mtime_ms}-{size}.json`，文件名内嵌实况、按当前 mtime+size 重算期望文件名存在即命中（无 .stamp 旁文件），源变化重算并 `purge_stale` 顺清同 rel 旧缓存。为此把 services/workspace.rs 的 `encode_rel` / `rel_of` / `purge_stale` 升 `pub(crate)` 复用，不重造编码口径。解码走 spawn_blocking（规范第 2 条）。
- `get_font_info_by_path`（commands/font.rs）：返回形状同 `get_font_info`（originPath = ws 源文件绝对路径，前端 FontFace 经 convertFileSrc 加载，asset 协议 scope 与 ws 预览图片同源无需扩）。**安装 / 卸载不开按路径版**——那是 assetId 命令且系统级写入，ws 侧不接线。

四命令注册进 lib.rs 命令表。新增测试 5 个：越界拒绝 / 不存在 / 非目标格式 / 正常读取（text、docx 各一），peaks 缓存命中直给（预置期望名产物，无 ffmpeg 也返回）+ 源变化失鲜重算（假 mp3 解码失败中文错），font 闸门（假字体解析失败等；真字体正路径维持 services/font 层 ANIKIT_TEST_FONT 目检口径不重复）。

## 前端

三个加载器各加 ws 分支（`asset.wsPath` 存在即走 by-path 命令，否则维持 assetId 命令，库侧行为零变化）；字体卡 FontFace 家族名 ws 改 `anikit-card-font-ws-{encodeURIComponent(relPath)}`（假 id 含斜杠 / 非 ASCII 不可直接用，编码单射防冲突），库侧维持 `anikit-card-font-{assetId}`。

AssetCard 三处 Active 闸由 `&& !isWs` 改为 `(!isWs || !!asset.wsPath)`（wsPath 缺失的窗口期仍降级 general，假 id 不出前端）。两处交互件随 ws 收窄：

- **音频悬停胶囊不出**：胶囊 = 时长 + 播放钮，播放走 HoverAudioLayer（assetId 命令，本任务不放开悬停播放），ws 时长也无数据——空壳死钮不出。落地 = AssetCard capsuleText 传空串 + MediaCapsule 根改 `v-if="capsuleText"`（库侧两档胶囊文本恒非空，行为不变）。
- **字体安装钮不出**：cardSpecs 注册表加 `CardContentOverlay.when` 显隐谓词（首例扩展），font spec 挂 `when: (p) => p.installable !== false`，FileCard 按当前 props 过滤 overlays；AssetCard 传 `:installable="!isWs"`。

## 验证

cargo test 535 绿 / 0 败（新增 5 测试）；`cargo clippy --lib` 零告警；`pnpm typecheck` 0 错。实机走查交用户：ws 视口 txt/md/docx 卡正文滚动预览、音频卡波形、字体卡示例字真渲染 + 字重简介行；音频卡悬停无胶囊、字体卡无安装钮；文件改动后重进目录卡片内容刷新。

## 同步与遗留

接口文档 `命令/20_工作空间.md` 登记 4 个新命令 + `.anikit/peaks` 缓存口径。**遗留：ws 音频卡悬停播放层（HoverAudioLayer / 悬停 scrub）与自动播放维持禁用**（播放源 / 状态通道全走 assetId 命令，需另立按路径播放任务）；波形卡与 hover 层无耦合（波形 = 内容件，hover 层 = 独立插槽层），已按预期拆开接。
