# 阶段七 · 收件箱工程文件区块标题与提示行统一（2026-09-08 二轮）

## 起因

同日一轮卡片换代后用户实机走查截图指正：工程文件区块的字体、颜色、图标、「/」数字要检查是否和现在统一。截图里两处显眼残留——标题行还是旧 SectionHeader（「工程文件 - 1」，旧 label 档 + 恒显 tree-expand-arrow 12），提示行「工程文件不支持自动导入，请手动导入」还挂 caption/label 旧 token（偏亮的绿白半透明色，比标题还醒目）。

## 核对与定案

逐项对照现行统一体系（左栏树容器区块标题「目录 / 4」= items/SectionTitle block 为新定稿件）：

标题行：旧 SectionHeader 废除，换 items/SectionTitle block（与 ArchiveStrip / AssetGrid 内容副标题同接法：actions=false、expanded 驱动、@toggle 带 dragView.suppressClick 守卫——§20 口径守卫在调用方）。变化点：计数「- N」改「/ N」三段（标题/斜杠/数字 gap 4）；标题字档 = 次要文字-加粗 12/16 Bold 亮色/四级；展开钮 = expand 14，常态隐藏 hover 现身（hover 提亮二级）。

提示行：notice/error-line 旧 caption/label token 废除，改正文档 13/18——提示 = 亮色/三级，错误 = --error 语义色不变。定档依据 = 空文件夹稿「提示文字」（通用/正文 13/18 常规 亮色/三级），此档同步登记为辅助说明文字通用档（速查 §16 接入登记条），以后无专门稿的说明性文字一律此档。

间距杂项：.disk-block gap 与 .flow 行列距的旧 --space-* 换 --n-space-*（值相同，7.1 重构件统一走新族；ArchiveStrip 同款）。卡片本体（FileCard square）、FLA 角标（FormatBadge）、简介数字档一轮已是新体系，本轮无改动。

## 范围外

旧 SectionHeader 还剩两处调用（DetailNotes 笔记 grip / MovePanel），属详情面板与移动弹窗域，本轮不动。
