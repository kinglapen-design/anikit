## 无规则空组（自由组）

- **数据**：`GroupDef.members?: string[]`（assetId 有序列表，serde default 不升版本）；**rules 为空即自由组**（与规则组不混态）。set_folder_groups 放开空规则、「完全相同」查重只管规则组；**克隆文件夹 members 按克隆资产 id 映射重指新副本**（索引与 vec 双写）。
- **归组优先级 = 手动成员 > 规则**（显式动作胜）；membership 唯一（移动语义 = 先摘除再加入）。新命令 `assign_group(folder, group|null, assetIds)`：移入（目标须自由组）/ 移出（null），单撤销步；+1 单测（唯一归属 / 幂等 / 三类拦截）。
- **弹窗**：草稿加 free 标记（加载 = rules 为空）；自由组块 = 名称行 + 静态说明行（无规则编辑）；「添加空组」钮；预检放开空规则、查重跳自由组。
- **内容区**：空自由组恒渲染（规则空组仍平铺）——展开态占位 64 高提示框「将文件拖入分组」（useGridLayout `FREE_EMPTY_H` 占位 + AssetGrid 提示框）；组标题（自由组 / 未分组段）与提示框挂 `data-group-drop`，**素材拖入 = assign_group**（dragOperation 新 groupZone 分支，落点高亮 = 并入同款品牌/半透明 + 2px 描边；未分组段 = 移出）；2026-08-20「跨组禁落点」对自由组放开（手动归组语义），规则组不变。
- **右键**：文件卡「移动至分组 ▸」（文件夹视口有自由组时出现）= 自由组清单 + 移出分组（选中集在组内才给），多选批量。
