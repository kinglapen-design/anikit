# MCP 条目化进插件面板：服务总开关 + 写入闸挪入 + 使用教程（2026-09-20）

待办细节清单 09-20 立项条兑现：桥接类加「AI 外接通道（MCP）」条目，与 Animate 插件同形态。动机复读一遍——MCP server 内嵌进程、启动成本毫秒级，**省的从来不是启动速度，是入口统一 + 暴露面管理**：不用 Agent 的用户可整个关掉、17701 不白听。

## 落地内容

**面板与详情窗（前端，版式全套既有口径）**：PLUGINS 加第三项（icon 临时 `plugin` 顶替，用户供稿 mcp.svg 后换）；更多菜单 mcp 分支 = 打开 / 启动|停止服务动态项 / 配置快捷键占位；新详情子窗口 `plugins/McpPluginWindow.vue`（544×640，`open_plugin_window` 白名单加 `"mcp"`）四组——**服务**（MCP 服务开关 + 允许写入开关 + 运行状态行，开关行沿退役 SettingsModal 口径）、**使用教程**（Kimi Code / Codex / Claude Code 三种接入配置行 + IconButton copy 复制）、**功能列表**（只读 8 / 写 9 两行汇总）、**路径**（服务地址 + 端口文件）。按钮行仅「关闭」——MCP 无文件可装，「真安装 = 写 Agent 配置」，一键写配置留远期。

**服务总开关（后端，本轮最大的新机制）**：`server/mcp/mod.rs` 从恒起改为可启停——全局 `MCP_HANDLE`（tokio oneshot 停信号 + 实际端口 + serve 任务，不加新依赖）+ `start/stop/status` 三函数（幂等、serve 尸体自清、停服删端口文件让 Agent 发现机制同步下线），`axum::serve` 接 `with_graceful_shutdown`；`init` 读 `settings.mcp.serverEnabled`（缺省开，保持旧行为）决定是否拉起。

**写入闸挪入 + 存储搬家**：配置从 `settings.ui.mcpWriteEnabled` 迁到独立 `settings.mcp` 子树（`serverEnabled` / `writeEnabled`）。搬家原因记一笔：`save_ui_settings` 是 settings.ui **整体替换**语义，键放 ui 子树只有两条死路——store 快照不带它就被抹掉，带它则子窗口与主窗口防抖快照双写竞态。仿 `CepExportSettings` 独立子树 + commands/mcp.rs 三命令（`get_mcp_status` / 两个 set，回包同构 McpStatus 供前端校正）是唯一的干净解；旧键由 `mcp_settings()` 一次性迁移（读到即采用，下次写落新子树）。由此立下铁律：**子窗口面板一律不绑 ui store 持久化字段**（口径速查 §37）。

**偏好设置退役**：弹窗唯一内容就是 MCP 写入开关，挪走后空壳删除（SettingsModal.vue + ui store 两字段 + 预览页展区），菜单栏「偏好设置」项 disabled 占位，后续设置项立项再点亮。
