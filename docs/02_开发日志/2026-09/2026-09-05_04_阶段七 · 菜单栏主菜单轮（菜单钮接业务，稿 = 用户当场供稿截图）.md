## 阶段七 · 菜单栏主菜单轮（菜单钮接业务，稿 = 用户当场供稿截图）

- **范围**：侧边栏细节修复首件——菜单栏「菜单」按钮接应用主菜单（仓库 / 文件 / 查找 / 整理 / 偏好设置 / 帮助 / 关于 AniKit / 退出），全树三级级联；编辑 / 插件 / 视图三钮仍点亮不接业务。新建三级菜单 = 新建文档七项带品牌图标（用户定：用 09-05 入库的 05_文档图标七件，newDocGroupEntries 复用）。
- **机制**：① ContextMenu 单级 flyout 改**多级栈**（flyouts[]；hover 第 k 级 = 截断到 k 层再推新层；key 带层级前缀防撞）；② AppMenu group 改收**数组**（根与各级 flyout 互认组内，点任一级不关）；③ **trigger 触发钮豁免传全级**——深层漏传会把按钮 pointerdown 当组外先关、click 又开，toggle 失效（探针 M7 实证）；④ menuState.trigger + openContextMenu opts.trigger 新通道；⑤ 库列表 = **纯对勾行**（MenuItem checkable + library 动态切换，对勾随 currentLibrary 实时；用户定稿口径）——旧 LibraryMenuItem 抓手排序 / 删除× 不进此菜单，删除走「删除当前资源库」。
- **spec（menuSpecs/appMenu.ts）**：稿项全列、无业务 disabled 占位——接线 = 新建文件夹/子文件夹/新建档案/转换为档案/导入两项/链接管理 Ctrl+J/添加链接 Ctrl+L/linkList 位置/扫描三范围/搜索 Ctrl+F/添加关系/添加音频/缩略图四项/复制标签/粘贴标签/编辑描述/移动 Ctrl+Y/设为原始/新建·删除资源库/切库/退出 exit_app；占位 = 筛选器九项/以图找图五源/帮助三项/偏好设置/关于/清除缓存/管理工作空间/仓库管理/合并资源库/导入链接/导入素材包/导出素材包/CSV/添加至其他资源库/添加缩略图/更换封面两项/添加标签/清空标签/提示词骨架。选中集解析助手 singleAsset / singleArchive / pickerTarget（回收站视口编辑类全 disabled）。
