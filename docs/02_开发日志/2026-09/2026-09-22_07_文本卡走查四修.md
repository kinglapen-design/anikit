# 2026-09-22_07 文本卡实机走查四修（角标让位 / 胶囊可拖 / 滚轮交还 / 字号固定）

> 用户实机走查文本卡（2026-09-22_06 接线后）四条反馈，一轮修齐。速查 §16 txt-md 卡口径已修订。

## 四条

1. **角标遮挡卡内标题** → 文本内容区让位格式角标：起始 top = 角标下缘 + 4（36px，无角标回 12），spec 加 topInset 映射（FileCardProps.badge 非空判定——查看方式关角标时不让位）。
2. **滚动胶囊拖动 100% 被拖拽排序覆盖** → 胶囊本是纯视觉 span（无处理器），补上拖动：`pointerdown` 自停冒泡（不到网格根 = 不起卡片拖拽/框选）+ 位移按比例映射 scrollTop（useSideThumb 同款换算）。
3. **滚轮不滚文字 → 定案：滚轮不介入卡内**——查明成因：网格是自定义 transform 滚动（踩坑 005），viewport wheel 监听 preventDefault 把卡内原生滚动一并取消，所以本就滚不了。用户定「不要滚轮也好，可能影响页面整体滚动；把滚动条做好靠滚动条就行」——内容区改 `overflow: hidden`（卡不再是滚轮目标，滚轮恒滚网格；hidden 仍可由胶囊程序写 scrollTop），双保险。
4. **文字太小** → 字号固定稿值（标题 18/26、正文 13/18、padding 12、gap 8），推翻 2026-09-13「cqw 随卡宽等比缩放」——卡片缩放只影响显示行数；cqw 唯一消费者拆除后 `.fc-root` 的 container-type 同撤。
