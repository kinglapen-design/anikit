# 2026-09-22_08 音频卡接线（R6 卡片三变体 · audio 变体：peaks 竖线波形数据通道落地）

> 用户推进：「重新调整新的音频缩略图样式」——音频卡片内容区从「旧立体声发丝波形 PNG 缩略图」换上新稿竖线波形（稿 = 组件/卡片/文件卡片-音频，WaveContent 组件 R5 已就绪，缺生产数据通道）。本条勾掉待办 2026-09-20「卡片三变体接线」的 audio 项（font 仍待）、2026-08-29 ②「peaks 根数与数据通道」、2026-08-30 ②「peaks 待后端波形数据通道」。

## 根数口径定案（稿 prose 两约束的分工）

稿 prose：「不论是 5 秒音频还是 3 分钟音频都保证根数一致，美观第一位」「走带颜色把进度和波形根数解耦」。落地拆成两个维度：

- **不随时长** = 后端恒定供给：`media::audio_peaks` mono 混音（-ac 1，不分声道——稿「不用分析上下立体声差异」）8kHz PCM 均分 **128 桶**取 max-abs 联合归一。
- **根数随卡宽** = 前端重采样：WaveContent ResizeObserver 按容器宽 ÷ 节距 8（4 线 + 4 距稿值）定根数，超量 max 池化——4px/4gap 恒保稿值、任何卡宽两端铺满（尺寸滑块场景 PNG 方案必糊/拉伸，DOM 竖线天然清晰）。

## 改动

**后端**

- `services/media.rs`：`audio_peaks(path, n)` + `peaks_from_pcm`（分桶 max-abs 归一；全静音出全 0，前端最低高度档兜显细线）+ `CARD_PEAKS = 128`。
- `commands/media.rs`：`get_audio_peaks` 命令——产物 `cache/peaks/{assetId}.json` **跨会话保留**（同 cache/media 口径：全量 PCM 解码与转码同级开销，开库清空会让每次启动首轮滚网格全量重解码；.stamp 记源「大小:mtime秒」防漂移，复用判定先于二进制检查），不在开库清空名单；短锁快照 + spawn_blocking 锁外解码（规范第 2 条）。

**前端**

- `src/lib/cardPeaks.ts`（新）：peaks 懒加载，仿 cardText——会话级缓存附带 modifiedAt 版本戳、inflight 去重、失败回退空数组（空波形 = 纯色底）并缓存。
- `AssetCard.vue`：audio 档（非 ws）→ FileCard `kind="audio"` + peaks / capsuleText（时长）/ playing / progress 接线；ws 合成项降级 general（peaks / 播放源均走 assetId 命令，假 id 禁发）。
- `HoverAudioLayer.vue` 收窄为**透明 seek 交互层**：旧 mask 波形图扫过 div 与自带胶囊双退役（扫过归 WaveContent 品牌色 played 层 clip-path、胶囊归 FileCard overlays MediaCapsule——消除双胶囊）；状态三通道 emit（playing / progress 0..1 / duration）上抛 AssetCard → FileCard；`defineExpose({ togglePlay })` 接胶囊播放钮回转。
- `MediaCapsule.vue`：播放钮 button 化 + `playToggle` emit（click.stop 防卡片选中、pointerdown.stop 防起卡片拖拽 / 穿透 seek 层）；`FileCard.vue`：overlays 透传 `play-toggle`（无此 emit 的附加件监听无害）。
- 预览页：PreviewOverlays 的 HoverAudioLayer 静态复刻展区撤除（层已透明无视觉，波形/扫过/胶囊归 PreviewCards 音频展区验收）；PreviewCards 音频区注释改生产口径。

旧 PNG 波形缩略图（`waveform_image` 640×272 立体声分绘）**保留不动**——消费方余冲突弹窗预览（decode_preview_image）与 ws 工作空间音频卡（general 壳）；预览播放条 / 预览大图走 `get_waveform` sized 版不动。
