# 工作空间右键菜单移植与系统菜单（2026-09-29 五轮）

缘起：用户要求把素材库的右键上下文菜单能移植到工作空间的全移植过去（含快捷键、分组分割线，文件夹与文件都查），并问「Windows 原生右键菜单能不能调（压缩解压、Git 那些）」。答 = 能，本轮一并落地（IContextMenu 经典菜单）。

## 菜单移植（`src/lib/menuSpecs/workspace.ts` 四 spec 重组）

分组 / 分割线 / 快捷键标注全面对齐库菜单稿（纯文字口径，组件同一套，零新样式）：

- **文件卡**：打开预览（Enter）/ 新标签页打开（Ctrl+Enter）/ 在默认应用打开（Shift+Enter）/ 在其他应用打开 / 发送至 Animate（Ctrl+E，仅 fla + 单选）/ 在资源管理器中显示 / **系统菜单** │ 复制（Ctrl+C）/ 剪切（Ctrl+X）/ 粘贴（Ctrl+V，ws 剪贴板非空才出现）/ 重命名（F2，单选）/ 创建副本（Ctrl+D）│ 复制数据 ▸（复制文件路径 / 复制名称 / 复制 base64）│ 删除（Delete）│ 刷新。
- **文件夹卡**：新标签页打开 / 新建文件夹（同级，Ctrl+Shift+N）/ 新建子文件夹（Ctrl+Shift+Alt+N）│ 固定到常用·取消固定（原仅树行有，补齐对齐）│ 剪贴板组（粘贴落点 = 该文件夹内）│ 复制数据 ▸（无 base64）│ 资源管理器 / 系统菜单 │ 删除 │ 刷新。
- **树行**：文件夹主体减「重命名」（ws 树无行内命名态，维持走视口卡片 / 名称双击）。
- **空白**：新建文件夹 / 粘贴 │ 在资源管理器中显示（当前目录）│ 刷新。
- 「打开」冗余项不列（同库 2026-09-23_02 口径：单击卡片 / 树行已导航）；批量分流同库 3.4 口径不变（触发项在多选域内 → 复制 / 剪切 / 副本 / 删除 / 系统菜单作用于整个 ws 选中集，文件与文件夹可混合）。
- 新建文件夹 = 库「先建后命名」移植：默认名创建后当前视口正是父目录时，经 `selection.namingFolderCardId` 进卡片行内命名态（ws store `createFolder` 改返回实际创建名）。
- 顺手修正：ws 新建文件夹本地避让名 `新建文件夹 (n)` 括号式 → `新建文件夹-n`（2026-09-23 序号定案后 ws 侧残留，与库 uniqueFolderName 同形）。

## 快捷键绑定（useGlobalKeys ws 分支新增三键）

Ctrl+D 创建副本（同目录复制）/ Shift+Enter 默认应用打开（单选）/ Ctrl+E 发送至 Animate（单选 fla）；F2 / Delete / Ctrl+C·X·V 已有。Enter / Ctrl+Enter / Ctrl+Shift+N / Ctrl+Shift+Alt+N 仅菜单标注不绑（与库菜单同口径——库侧这几个也仅标注）。

## 新后端命令（`commands/workspace.rs`，注册于 lib.rs）

`open_path_with_default_app` / `open_path_with_dialog`（复用既有 shell_open 适配器）/ `ws_file_base64`（复用库侧 `base64_from_origin`，白名单与 10MB 上限同径）/ `ws_duplicate`（服务层新增 `duplicate_entries` = 同目录复制 + `名_n` 规避，带单测）/ `ws_shell_menu` / `send_path_to_animate`（cep.rs 抽 `pub(crate) send_fla` 共享流程，库素材入口同径不改语义）。统一 `validated_ws_path` 校验（workspace 内 + 存在）。

## Windows 原生系统菜单（`adapters/shell_menu.rs` 新件）

桌面 IShellFolder + 全 PIDL `GetUIObjectOf` 取 IContextMenu（跨目录多选天然成立，Explorer 同径）→ CreatePopupMenu + QueryContextMenu 装配 → 自建 HWND_MESSAGE 消息窗（WndProc 把 WM_INITMENUPOPUP / WM_DRAWITEM / WM_MEASUREITEM / WM_MENUSELECT / WM_MENUCHAR 转发 IContextMenu2/3——不转发则 7-Zip 类扩展子菜单不展开、自绘项空白）→ 光标处 TrackPopupMenuEx（TPM_RETURNCMD，模态循环在 spawn_blocking 线程 STA 内自泵，主线程不冻结）→ 选中项 InvokeCommand（CMINVOKECOMMANDINFOEX + CMIC_MASK_UNICODE）。windows crate 补 `Win32_UI_Shell_Common` + `Win32_System_LibraryLoader` 两特性；`CMIC_MASK_UNICODE` crate 未收按 shellapi.h 原值定义。

边界（已写入 PRD）：只有注册经典 IContextMenu 动词的扩展出现（7-Zip / WinRAR / TortoiseGit 都在）；Win11 新样式菜单的 IExplorerCommand 现代扩展（如部分新版压缩软件的「智能解压」入口）不可托管，不在其中。
