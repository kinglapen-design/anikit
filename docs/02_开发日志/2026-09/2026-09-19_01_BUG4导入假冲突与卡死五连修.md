# BUG 4 导入假冲突与卡死五连修（2026-09-19，feat/new-ui）

用户前一天记录的 BUG 4（四条症状同族），本日聚焦修。用户实机描述：复制导入总提示有冲突，磁盘里实际没有冲突文件，且"已存在"侧连缩略图都没有；冲突选"作为新文件导入"不停报导入失败；自动导入已导入（数量显示 2）但 UI 无卡片，重启后可见；这些状态下托盘退出卡死。同一批文件多次重启后才恢复正常。用户怀疑"json 里有哈希值没跟着删除"——方向正确。

## 根因（五条，全部代码级坐实）

### ① 查重污染 → 假冲突

`dedup_phase` 的 by_hash 取自 `index.assets` 全量，而 `load_assets` 会把空间 assets 池里全部 info/metadata.json 载入索引。于是 hash 比对会命中四类"用户看不见"的资产：回收站引用资产（删除进回收站 info 保留，删了再导必报冲突）；孤儿残留（2026-09-02 删除事故那类半截 info，metadata.hash 还在、无任何引用——"多次重启才恢复"的真身：某次开库自检/处置清掉残留后才不再命中）；hidden 伴生缩略图资产（8.1，用户不可见）；其他库资产（空间共池全量载入，本库无 Placement）。

`conflict_of` 对无本库活 Placement 的资产组装出的冲突项：所在文件夹名空白、显示名回退词干、无内容缩略图格式叠格式图标未缓存 → "连缩略图都没有"。`use_existing` 找不到本库 origin Placement 必失败 → "替换还提示失败"。

### ② 剪贴板临时文件先删后决策 → 连环"文件读取失败"

剪贴板图片 / base64 落 cache/ 根临时文件，`spawn_import` 在 run_import 结束（含冲突挂起）后无条件删除。用户随后点"作为新文件导入"，`copy_new` 回读源文件算 hash → 文件已删 → 报"文件读取失败"；失败弹窗"重试"拿死路径再投 → "路径不存在" → 不停失败。

### ③ 收件箱派发 cancel 恒 false + stop 无限 join → 托盘退出卡死

`dispatch_loop` 调 run_import 传的是 `&AtomicBool::new(false)`；`inbox::stop` 对 dispatcher 线程 `join()` 无限等待。导入长批次或卡死时，RunEvent::Exit 卡在 join → 整个应用退不掉。

### ④ ffmpeg/ffprobe `output()` 无超时 → 管线单元卡死

坏文件 / 异常流可让 sidecar 永不退出，导入单元永不完成：无 Finished → 进度条定格（"数量显示 2"）、无卡片；已完成单元已被 2 秒节流落盘 → "重启后就能看见了"。

### ⑤ resolve_conflicts 全程持全局库锁跑建档重活

sha256、复制、缩略图、ffmpeg 探测全在锁内执行。探测卡死即全 app 命令堵死；收件箱派发等锁，构成退出卡死的另一链。

## 修法（五连）

**查重口径 = 本库"看得见"的资产**：by_hash 只收本库 folders.items 有活 Placement 且非 hidden 的资产（import_task.rs）。回收站 / 孤儿 / 其他库 / hidden 伴生一律不触发冲突，删了再导 = 正常新导入——不依赖清理存量残留，根治。+2 测试（回收站 / 孤儿不冲突 + 活资产回归；hidden 不冲突）。

**剪贴板临时文件冲突保护**：临时文件挪 cache/tmp（会话级，开库整目录清空兜底），`spawn_import` 仅无冲突挂起才删（commands/import.rs）。

**收件箱退出有界**：dispatch_loop 的 cancel 改传 stop 标志——stop 置位即管线当前单元写完中断、Finished 照发（前端 refresh 兜底显示已导入部分）；stop 改 done channel `recv_timeout(5s)` 有界等待，超时放弃 join（开关场景旧线程跑完当前批自退，退出场景随进程终止）。

**ffmpeg 超时**：`run()` 改 spawn + stdout/stderr 双 reader 线程 + try_wait 轮询，90s 超时 kill，按探测失败退化（格式图标保底，导入不失败）。转码 run_status 不动。

**resolve 两阶段出锁**：copy 建档锁外 prepare（sha256 / 实体入库 / 缩略图 / 格式图标）→ 一次短锁 register + 重建索引 + 落盘；库中途关闭 / 落点失效时回收已建 info 壳，不留孤儿。
