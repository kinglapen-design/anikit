# 免安装包重打（含 MCP 三批 trash_placements，2026-09-20）

trash_placements 是 Rust 后端改动，MCP server 编在 exe 里——免安装版不重打就没有新工具（用户问「直接生效吗」引出的本论）。照 09-19_11 既定流程：`pnpm tauri build --no-bundle`（release 全量 54.7s 过）→ 旧 `release/anikit-portable` 与 zip 改名 `.old-20260920`（可逆）→ 组装：app.exe → anikit.exe + av*.dll 七件 + ffmpeg/ffprobe sidecar + `plugins/animate-cep` → 405MB + zip 170MB（python zipfile 代打，Git Bash 无 zip）。

两个过程小坑：① 改名旧目录 Permission denied——早前 dev 验证拉的 `app.exe` 子进程没被 TaskStop 带走（杀 shell 不杀进程树），taskkill 后才改得动；② 冒烟同理，测完 taskkill 落实 + netstat 复核 17701 无 LISTENING 才收工。

冒烟（起新 anikit.exe 直连 17701）：tools/list 正好 17 个、`trash_placements` 在列——打包进去的是新二进制无疑。release/ 本就 gitignore 不入库。
