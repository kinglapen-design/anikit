# 阶段七 · 快速访问「全部」行改资源库行（当前库名 + 切换资源库钮）

## 任务

用户实机提：「创建资源库」只有菜单栏「菜单 → 仓库 → 资源库 → 新建资源库」一个入口，藏得太深。定案 = 快速访问首行（原「全部」行）轻调整：文案不再用「全部」、改为当前资源库名称，名称后加一个常显切换图标（用户供稿 `切换资源库.svg`），与图标/名称同容器等距（gap 6），名称过长截断。用户补充澄清：此行没有树形展开箭头，三件即 库图标 + 名称 + 切换钮。

## 做法

行本体行为不动（点击仍进「全部」视口 quick:all、选中态与数量照旧），只改文案与加钮。切换钮点击弹 **08 稿切换资源库菜单**（`librarySwitchSpec`）根级形态——库列表（当前打勾 / 抓手拖拽排序 / 删除×）+ 新建资源库入口，一次把「切库 / 建库」都提出菜单栏。菜单 toggle、行下方弹出、picker 禁开等口径全对齐菜单栏四文字钮。

组件侧 = `TreeRowItem` 加 `switchable` 变体（props + `switch` emit + `.lib-switch` 样式，色档随 quick 图标族 l3 / hover l2 / 选中 l1，热区伪元素外扩同 .exp），不新建组件。图标 `switch-library.svg` 入库 01_常用（用户直投源图 #808080 三级单灰转 currentColor，命名对照十二批），中文底稿归档 `docs/06_UI重构/图标/01_常用/`。

## 验证

`pnpm typecheck` 绿。观感（库名截断 / 切换钮色档 / 菜单弹出位置）交用户实机走查；预览页 PreviewItems 快速访问展区已换资源库行两例（常态 + 长名截断·选中）可静态验收。
