## 阶段八 CEP 补场景 · 面板分组轮（用户实机走查六点）

**逐条落地**：

1. **自定义比例框/目标文件夹被拉高**——根因 = `.input` 的 `flex:1` 在 .view 纵向容器里变纵向拉伸（自定义框当时是 .view 直接子元素）；修 = `.view > * { flex:none }` 禁收缩/拉伸 + `overflow-y:auto` 超高出滚轮（用户定"高度不够给滚轮"），滚动条悬浮 6px 实色胶囊悬停显隐（速查 §2 口径的 CEP 无 Vue 简化版，status/树区统一）。
2. **按钮挤在一起**——分组加小标题：**导出模式 / 画面 / 入库**（11px l4 小字，params 同档不抢控件）；组间 14 组内 8。
3. **模式/静动分段太像分不清主次**——静/动改**复选框**「动态（WebP 动画）」（用户给的二选一里取勾选；选中 = 品牌底 + 对勾，APP Checkbox 口径简化版；title 注语义）。
4. **比例「自动」语义不清 + 自定义改像素**——「自动」更名「**文档**」+ title「跟随当前文档舞台尺寸」；自定义比例框废除改**像素双框**（宽 px × 高 px，两框都填才生效直定舞台尺寸、优先于比例档——用户原话「直接传入参数建新文档」）；jsx exportSelection 加 sizeW/sizeH（>0 优先，否则比例档，再否则随文档）；记忆 = cepSize（像素，恢复优先）+ cepRatio（旧 custom: 比例值废弃回「文档」）。
5. **仅缩略图起止留空逻辑不明**——模式说明文字（modeDesc，thumb 模式显示）：「不产生新 fla……静态 = 播放头当前帧；动态 = 起止帧范围，留空 = 全部帧（超上限自动截断）。库内 fla 自动绑定缩略图；库外导出到原文件旁边，自行导入。」
6. **批量命名**——命名框批量期不再禁用，改作**前缀**：空 = 各元件名（现状）；非空 = 「前缀-序号」（总数 ≥10 补零对齐排序，jsx exportBatchItem 拼）；placeholder 改「命名（多选 = 前缀+序号）」。APP 侧批量重命名（F2 多选）作后补路径不变。

**验证**：node --check 双文件过；无残留引用（segStatic/segAnim/ratioCustom/disabled 清零）；四文件同步 extensions。**下一步：用户实机复验（分组观感 / 像素直定建文档尺寸 / 勾选动态 / 批量前缀命名）**。
