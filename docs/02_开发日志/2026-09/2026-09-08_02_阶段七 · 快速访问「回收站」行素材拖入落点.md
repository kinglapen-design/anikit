# 阶段七 · 快速访问「回收站」行素材拖入落点

## 任务

2026-09-08 用户定：**拖拽素材到左栏快速访问「回收站」行 = 直接丢到回收站**，不用每次右键/按 Del，更方便。

## 做法

拖拽引擎（`dragOperation.updateDropTarget`）新增落点类：命中 `[data-quick-drop='recycle']` 且为素材拖拽时出落点，`sess.drop = dropAssetsToRecycle(items)` = `deletePlacements(items)` 默认 action "recycle"——**与 Del 键完全同路径**（可撤销，toast「丢到回收站 N 个项目」自带反馈）。

属性选择有讲究：回收站行挂的是专属性 `data-quick-drop`，**不用 `data-folder-id`**——否则 App.vue `onDrop` 系统拖入导入的 `closest("[data-folder-id]")` 会把回收站行误判成导入目标文件夹（folderId="recycle" 写进 importDraft）。快速访问项本就因无 data-folder-id 天然不作树落点，新增属性不破坏既有判定链。

高亮复用既有件：`dragView` 加 `quickRecycle` 布尔（resetIndicators 一并清），LibraryView 回收站行绑 `:drop-zone="... 'into' : null"`——TreeRowItem 本有并入高亮（品牌/半透明填充 + 2px 品牌描边），组件零改动。

**护栏一条**：LibraryView `onQuickSelect` 补 `dragView.suppressClick` 判定——行此前无落点所以没这道闸，拖完松手的紧随 click 会误导航切到回收站视口（树 item / 区块标题早有同口径闸）。

边界：文件夹拖拽不落回收站行（删除文件夹 = 素材移未分类，语义不同，给落点是误导）；Ctrl 无语义忽略；回收站视口内卡片本禁拖（gridPointerDown 守卫）；选择模式拖拽本禁用。

## 验证

`pnpm typecheck` 绿。实机走查交用户：拖素材至回收站行的并入高亮 / 松手丢入 toast / 不误跳视口。
