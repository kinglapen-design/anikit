# 阶段七 · 资源库菜单换新样式（共享 spec）+ 旧 08 稿库菜单机制拆除

## 任务

用户走查资源库行切换钮弹层：首轮误用了旧 08 稿浮层样式（LibraryMenuItem：抓手 + 删除×），定案 = 直接用菜单栏「菜单 → 仓库 → 资源库」的现行样式搬过来；注意一级菜单最小宽度；**拖拽排序不要了**（资源库不至于多到需要排序）。

## 做法

菜单内容提取为共享 spec `src/lib/menuSpecs/libraryMenu.ts` 的 `libraryMenuEntries(names)`：新建资源库 / 删除当前资源库 / 合并资源库（占位）+ 库列表纯对勾行（MenuItem checkable，checked/disabled 函数化求值——keepOpen 切库期间对勾随 currentLibrary 实时；点击动态判定、当前库跳过）。两个调用方同用：appMenu 仓库▸资源库 二级 + 侧栏资源库行切换钮（一级弹出，min-width 250 由渲染层既有口径自动应用）。

旧机制全拆：`LibraryMenuItem.vue` 删除；ContextMenu 的 libDrag 拖拽排序（抓手/让位动画/落点持久化）、`entry.library` 特判分支、settling 样式移除；`CtxItem.library` 字段删除；前端 `reorderLibraries` 封装删除（后端 `reorder_libraries` 命令保留，前端已无调用方）。随汉堡菜单退役而仅剩名义的 `libraryHamburger.ts`（librarySwitchSpec / hamburgerSpec 均无调用方）整文件删除。

## 验证

`pnpm typecheck` 绿。菜单观感（对勾行 / 一级 250 最小宽 / 切换钮弹出位置）交用户实机走查；PreviewMenus 仓库▸资源库 展区本就是纯对勾行定稿，文案说明已同步。

口径速查 §31 改写（菜单 = 菜单栏同款共享 spec + 无拖拽排序 + 一级 min-width 250）；本日志。
