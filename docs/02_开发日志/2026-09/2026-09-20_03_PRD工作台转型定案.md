# PRD 工作台转型定案：08 节改写 + 07 新建（2026-09-20）

MCP 三批落地后的三轮战略讨论，用户把产品方向定死了，本轮全部落入 PRD。

## 定案内容

**AniKit 不做 agent，做 agent 的工作台**。推理链：纯粹素材管理在 AI 时代意义变薄（找半小时素材不如生成一张）→ 但库的角色不是消失是转换——素材超市变生产中转仓 + 一致性资产库（同一角色两百个镜头必须复用，生成替代不了）→ agent/skill 需要文件夹工作区与库式不矛盾（08-06 已定 cwd 架构：工作空间管生产现场、库管资产归宿、MCP 工具面是传送带）→ 内置 agent 难在安全 / 拦截 / 场景 prompt 这些「判断对错」的责任链，而能工程化的部分（红线 = 工具面白名单、拦截 = 写入闸 + 撤销、场景 prompt = 项目 .agents/ 说明书）已在 MCP 路线先行落地 → 大公司 agent 自带生图 / 终端 / 权限生态，正面打不赢也不必打。

**内置 agent 收窄保留**：排期放很后，只干简单的活——整理、命名、打标签，不参与生产（这三样确定性最高、MCP 工具面已覆盖，排期日 = 内置模型 + 现有工具面 + 现成红线层）。

**废除清单**：01_AI创作 整体废除（对话框生图 / 视频 / 透明通道生成 / 无限画布）；02_AI工具 生成向三条（扩图 / 转角度 / 拆分场景）随废，抠图 / 超分两条应急处理类保留（优先级最低）。
