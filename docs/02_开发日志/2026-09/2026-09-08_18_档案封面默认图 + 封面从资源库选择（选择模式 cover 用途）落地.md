# 档案封面默认图 + 封面从资源库选择（选择模式 cover 用途）落地（2026-09-08）

用户要求两件：① 档案封面的默认图 = `assets/icons/03_装饰图标/档案默认封面.png`，索引（子项首图）没有可用封面时展示；② 封面设置「从资源库中选择」点亮——进主窗口选择模式、排除不能作为封面的文件、选择图片后不进备选区直接显示在封面里。数据语义一问定案：**烘培快照**（PRD 03 原案的「资产引用变体」不做），且 **covers 挪进 cache 归可再生缓存 + 覆盖式**（用户实锤「covers 里面几十个过期封面」——旧时间戳命名不覆盖写废除）。

## 后端：覆盖式烘培 + 撤销暂存 + 开库迁移清理

- `services/archive.rs`：`bake_cover` 重写——文件名恒 `{folderId}.webp`（png 回退同干），写 `cache/covers/` 覆盖旧文件；**旧封面先改名暂存 `cache/covers-trash/{时间戳}-b-{旧名}`** 再烘培，烘培/落盘失败先把旧封面归位再报错（不留半截物理态）。返回 `CoverBakeOutcome`（新文件名 / 新路径 / 时间戳 / 暂存旧文件）交命令层。
- `commands/archive.rs` `set_archive_cover_settings`：按产物成对登记 `DiskOp::Rename`——undo 执行序 = [新封面挪入暂存 a，旧封面自暂存 b 归位]，redo 反之（`apply_disk` 逆序执行，登记序即反向推）；undo 时 archives.json 回滚 + 暂存改名还原双管恢复旧封面，撤销保真不破。暂存目录开库清空（同 seq-trash 口径——undo 栈本为会话级）。
- `core/library.rs` 开库自检：旧版库根 `covers/` 整体迁入 `cache/covers/` + 清理无 archives 记录引用的封面文件（过期封面不再跨会话累积）；`covers-trash` 入会话缓存清空清单。
- **coverVer 版本戳**：`cover_file_path` → `cover_file_info` 返回（绝对路径, mtime 纳秒）；`ArchiveListItem` / `ArchiveDetailView` 加 `coverVer`。覆盖式同路径重写后前端 `?v=` 驱动 img 重载（asset 协议同 URL 启发式缓存，同 AssetCard 缩略图 `?v=modifiedAt` 口径）；undo 改名还原把旧文件连 mtime 一并带回——还原后 URL 恰与旧内容同戳，**缓存命中即正确图**。

## 前端：封面链 + picker 第四用途

- `lib/archiveCover.ts`（新）：封面链一处封装 `archiveCoverUrl(coverPath, coverVer, childThumb)` = 自定义封面（带 ?v=）→ 子项首图 → 默认封面图（PNG `?url` 直引，非 SVG 不经 icons.ts 体系）。三处共用：ArchiveStrip 档案卡 / SectionPinned pinned / CoverSettings 封面框。
- `stores/picker.ts`：purpose 加 `cover` + `filterImage` + `coverDraft`；`enterCover(档案)` / `pickCoverAsset`（解析源图 → 草稿 → exit 恢复档案选中）；横幅「选择图片，为 [名] 设置封面」。**exit() 清 filterImage 但绝不清 coverDraft**（草稿存活到消费）；enter() 清陈旧草稿。
- `AssetGrid.vue`：filterImage 时 displayItems 只渲染 `isThumbCapableExt && !isSequence`（静态图 + gif；序列帧包排除——origin 指向 frames/ 内帧非实体单图，烘培必败）；档案区不渲染（ArchiveStrip v-if 加闸）；单击图片卡 = pickCoverAsset 单选直回（不进备选区）。
- `SectionPinned.vue`：消费 coverDraft（档案 id 匹配一次性消费）→ 自动展开封面设置组并把图源以 `initialSourcePath` 传给 CoverSettings；`CoverSettings.vue`：菜单「从资源库中选择」点亮 enterCover，`initialSourcePath` 非空直接取景态（loadPicked 与本地选图共用读尺寸段）。
