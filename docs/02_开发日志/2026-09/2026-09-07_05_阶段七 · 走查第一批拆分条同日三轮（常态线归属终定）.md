# 阶段七 · 走查第一批拆分条 · 同日三轮（常态线归属终定：拆分条零绘制，面板自带线透出）

## 任务

二轮把拆分条常态线落为「1px g3 实线」后用户实机三报：标签栏高度处多出一条竖线，而「原本的就是中间面板顺着圆角的 left」。

## 定性（cdp-panel-edge-probe.py 像素实证）

探针 E1–E3 三段证据：内容容器自带左缘线（`border-left 1px --n-l-a2` + 圆角 16）**命中且一直在**；但拆分条负 margin 与内容容器左缘有 2px 叠压（拆分条 x=252–256 / 容器左缘 x=254），二轮加的 1px g3 常态线正好压在自带线上——g3 #242424 贴窗口底 #1F1F1F 对比近零（用户看成分屏线消失），同线贯穿全高又在标签栏条（46 高透明区）露成一条多余竖线（用户三报「多加了一条线」）。一条线同时造成「该显的不显 + 不该显的显」两个症状。

## 终定（用户口径）

拆分条常态**零绘制**——「常态线」= 中间面板容器自带左缘线（顺着圆角的那条），拆分条上不加任何常态线；hover / 拖拽维持亮色/四级渐变线（二轮口径不变）。右栏维持零绘制无悬停。

## 验证

探针 E1 仍绿（自带线命中）；拆分条常态像素列复测交用户实机（探针已证 g3 线撤除后 x=254 处透出的是 l-a2 ≈ #3d3d3d 而非 g3 #242424）。`pnpm typecheck` 绿。
