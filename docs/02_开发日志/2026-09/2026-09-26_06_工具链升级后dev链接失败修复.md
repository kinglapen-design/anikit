# 杂项 · 工具链升级后 dev 链接失败修复（2026-09-26）

## 起因

用户 `pnpm tauri dev` 链接 app_lib.dll 失败：24 个 `anon.*.llvm.*` 匿名符号 LNK2019。同代码 cargo test / clippy 全绿。

## 定性

rust 工具链 1.97 → 1.98 升级后 target/debug 增量缓存新旧对象文件混链（anon 符号哈希按编译器版本互相引用）。与当轮代码无关——测试 / 检查走新产物全绿，dev 链接复用旧 .o 才爆。

## 处理

`cargo clean -p app`（清 15.5 GiB）→ `cargo build --no-default-features` 全量重链 1m49s 通过，用户重跑 `pnpm tauri dev` 即可。踩坑 091 已记（预防：工具链升级后先 clean -p app；「测试绿但 dev 链不上」先看产物新旧不先怀疑代码）。
