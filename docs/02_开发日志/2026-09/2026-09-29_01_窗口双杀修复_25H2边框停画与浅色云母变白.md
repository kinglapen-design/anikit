# 2026-09-29_01 窗口双杀修复：25H2 边框停画 + 浅色主题云母变白

用户实机两连报：①主窗口边框线消失；②朋友（同为 Win11 25H2）窗口回退成白色而非保底深灰，且朋友机器 Codex 云母正常。用户自测补刀：本机切浅色主题同样变白。

## 排查（实机探针链）

对运行中 portable 实例 ctypes 直读：窗口样式 0x04CF0000 完好（CAPTION/THICKFRAME 在、非 POPUP）、`SYSTEMBACKDROP_TYPE=2`（Mica 设上了）、`USE_IMMERSIVE_DARK_MODE=1`——属性全正常但边框没有、浅色主题下变白。决定性实验：`DwmSetWindowAttribute(BORDER_COLOR, 红)` → 立即画出 2 物理 px 红线 → **DWM 画框机制完好，25H2 的默认边框（COLOR_NONE）不画了**。变白则与 Mica 无关成败——是窗口主题跟随系统，浅色主题下 dark mode 置 0，Mica 浅色变体经全透明 `.window` 透出成白底（保底 `--n-g-a1-solid` 只在后端报 solid 时画，这条路径够不着）。

## 修法（两个方向都走「显式、不靠 DWM 默认」）

- **边框显式染 #333**：新 `window_fx::paint_border`（`BORDER_COLOR_NORMAL = 0x00333333` = --n-g6，与实色模式前端自绘同色），主窗口启动染 + 预览/插件子窗口建窗染；`set_main_border_picking` 常态恢复分支 COLOR_NONE → 染回 #333。debug 实例实机剖线验证：顶边 2 物理 px #333 线精确出现、角部沿圆角走。
- **窗口主题锁深色**：主窗口 `tauri.conf theme:"Dark"` + 子窗口 Builder `.theme(Dark)`。tao 0.35.3 源码实证 `update_theme` 对 `preferred_theme.is_some()` 的窗口在 WM_SETTINGCHANGE 直接 return 不跟随——Mica 恒深色变体，DWM 退化实底也恒深色。
