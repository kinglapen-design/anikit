# 阶段七 · 预览悬浮栏接入轮 + 搜索栏挤压修复（用户实机三条）

2026-09-09。用户实机三条：① 搜索栏展开筛选后被左右侧栏挤压时按钮跑到底色外、收起钮被裁走无法收起；② 聚焦搜索后点筛选不展开、只取消聚焦收回；③ 预览界面播放条全部换成多功能浮动栏。

## 搜索栏两修复

**修复②（根因有意思）**：聚焦态点筛选钮，mousedown 先触发 input blur → 壳宽 450→250 收缩动画启动 → 筛选钮随壳右缘左移 → 300ms 动画内按钮移出静止指针下方 → mouseup 落空、click 不成立。修法 = 栏内按钮（筛选 / 收起 / chip）一律 `@mousedown.prevent` 阻止失焦，顺带保持聚焦可继续敲字。回归钉 S19 必须走真鼠标链路（js `.click()` 不经过失焦路径，复现不了）。

**修复①**：壳 `.fb-shell` 加 `max-width: 100%` 硬钳制（内容永不跑底色外）；筛选组 `.fbs-filters` 作展开态唯一可缩件（overflow-x auto + 隐藏滚动条），输入区与收起钮 flex:none 钉住两端；滚轮 `@wheel` 转 scrollLeft 横滚，无需横滚时穿透给下层列表。回归钉 S20（窄容器 500 下壳钳制 / 收起钮在壳内 / 溢出可滚 / wheel 生效全绿）。

## 预览播放条换悬浮栏（旧 §11 通栏口径作废）

旧九件组件（PreviewPlayBar / PlayBarVideo / PlayBarAudio / PlayBarFrames / PreviewFrameStrip / PreviewNotes / VolumeControl / RateControl / TimeDisplayControl）全删，新业务壳 `PreviewFloatBar.vue` 接 ContentArea / PreviewWindow 两处（全屏两态同位）。口径全量在口径速查 §36，要点：show 组按 kind 删减（video 全量 / audio 留播放+音量+倍率+循环 / sequence·anim 去传输步进音量循环）；帧条 5 格分页页随当前帧、与播放条同宽 777；倍率 / 音量 / 时间显示悬停弹层（120ms 桥、选中即关、时间显示复用 RatePop 装「帧数/时间码」）；笔记确认制；转码态 disabled + 进度区「转码中…」；音频进度换 WaveProgress（音乐预览稿 prose 波形只在播放条上，旧波形 token 化映射）。

## 两个坑（已入踩坑记录）

- **072**：FloatBar 探针（父 max-content 实测）把进度条 327 稿值丢光——Blink 下 `flex-basis` 定值 + shrink>0 的项 max-content 贡献只报内容固有尺寸（BarSlider 内容宽 0）；`width: 327px` 定值才有贡献。一次性实验 `tools/cdp-flex-contrib-exp.py` 定案。
- **073**：dockview 布局不吃 Emulation 视口收窄（panel 宽 dock split 钉死），探针模拟侧栏挤压要直接钉 `.content-area` inline 宽，白跑两轮才转向。
