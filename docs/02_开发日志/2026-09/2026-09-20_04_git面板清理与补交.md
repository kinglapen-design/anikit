# git 面板清理：gitignore 排除三类 + 前序工作补交（2026-09-20）

用户被 VSCode git 面板的 10000+ 未提交更改骚扰（每次打开都提醒），查清构成后分类处置。

## 构成与处置

- **design/（18249 文件 213M，untracked）**：设计素材区——03_图标 199M（图标库 ai/fig/png 原始素材）+ LOGO 14M + 样式 / PRD 小文档。用户拍板**整个忽略**：素材区不进代码库，本地原样保留。
- **tools/test-assets/（35M 32 张截图）**：探针验证临时产物，忽略。其中 screen-now.png 早前被误跟踪过，gitignore 对 tracked 文件无效，`git rm --cached` 摘出。
- **docs/.obsidian/（4 文件已删）**：Obsidian 个人配置（窗口状态），本不该入库——忽略 + 删除入账。
- **不能忽略的**：09-19_04「库/工作空间切换视口记忆 + 详情 tab 全局记忆」会话干完没提交——src 四文件改动与日志口径逐条核实吻合 + typecheck 过，收尾补交（含量径速查两份同步、当前状态条目）；归档实机走查.md +184 行等为用户 Obsidian 编辑，同批入账。

四笔提交：`chore(gitignore)` → `feat(持久化) 09-19_04 收尾` → `docs(归档)` → `chore screen-now 摘出`。处置后 `git status` 全净，面板圆点消失。

## 教训

会话收尾要把「提交」当收尾动作的一部分（09-19_04 日志写了、代码改了、提交忘了）；探针截图类产物从一开始就该在 gitignore 里，screen-now.png 的 tracked 残留证明「先提交后排除」要付 `rm --cached` 的额外代价。
