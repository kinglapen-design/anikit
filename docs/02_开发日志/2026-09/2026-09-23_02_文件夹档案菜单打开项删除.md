# 2026-09-23_02 文件夹 / 档案菜单「打开」项删除

2026-09-23

## 需求

用户实机走查：树右键菜单的「打开文件夹」可以删掉——左键选中就打开了，几乎不会用到；「打开档案」同。

## 落地

四处同删（菜单 spec 层，无组件改动）：

- `folder.ts folderMenuEntries` 首项「打开文件夹 Enter」——树节点与文件夹卡片共用主体，同步生效；
- `folder.ts pickerFolderEntries` 选择模式精简集「打开文件夹」——选择模式点击即导航，同冗余；
- `archiveCard.ts archiveCardSpec` 主菜单首项「打开档案 Enter」（档案卡片 + 树档案节点共用）；
- `archiveCardSpec` 选择模式分支「打开档案」。

删后两侧菜单首项均为「新标签页打开 Ctrl+Enter」。Enter / Shift+Enter 快捷键本体不动（useGlobalKeys 独立实现，与菜单项无耦合）。

## 同扫（§20 教训：改已定稿行为时同文件探针断言一并扫）

- `cdp-context-menu-probe.py`：A11 容器宽断言锚点「打开文件夹」→「重命名」（保"短项右件贴右缘"语义）；B6 前 hover 回移锚点 →「新标签页打开」。A3 分组数断言不受影响（删的是组内项，组数不变）。
- 预览页：PreviewMenus 整菜单形态组删该项演示行、快捷键示例 label 换「重命名 F2」；PreviewOverlays 桩 spec 删首项。
