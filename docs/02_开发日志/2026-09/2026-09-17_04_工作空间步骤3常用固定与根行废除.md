# 2026-09-17_04_工作空间 · 步骤 3 常用固定落地 + 根行废除（用户三条意见定案）

## 要做什么

步骤 2 复验后用户给步骤 3 三条意见：① 搜索先不接——「没有 everything 快就不接，以后能内置 everything 么」；② 常用固定有必要——「像资源管理器一样，固定某个常用文件夹到一个常用或者也叫快速访问的区块」；③ 「工作空间」根行是假父级，与子级同缩进视觉上撞兄弟，不用包一层总父级。

## 定案

**搜索搁置**：Everything 快在 USN + MFT 常驻索引，自研遍历追不平；可行路径 = Everything SDK / es.exe 向用户机器上的常驻实例查询，需用户装着 Everything——记 PRD 搁置，另行立项。PRD 步骤 3 行改为「搜索搁置 + 常用固定本次落地 + junction 维持原判」。

**常用固定**：视图状态 = `workspace/.anikit/workspace.json` 的 `{ pinned: [rel,...] }`（serde 缺省宽容，字段后补）。后端读取即校验：resolve 越界 / 不存在 / 非目录（含 `.anikit`）的条目**静默剔除并回写**——改名 / 移动 / 删除的失效 pin 自动清理，无需前端通知。命令三枚：`ws_list_pinned`（未开空间返 []）、`ws_pin`（须已存在目录，重复幂等）、`ws_unpin`，均返回最新清单。前端清单以后端返回覆写（stores/ws.ts `pinned` + `loadPinned/pin/unpin`；`ensureRoot` 拉到 root 与 `refreshAround` 写操作后各重取一次）。

**固定区块形态**：**无区块标题、直接 item 列表**——沿用库快速访问先例（LibraryView 注释「稿：无区块标题，直接 item 列表」）。行 = TreeRowItem kind="folder" depth 0 无展开钮（`expandable=false`），点击进视口，数量 = 该目录直接文件数（根实例 onMounted 补 `loadDir(pin)`）。pin 行与树行共用 `wsTreeRowSpec` 右键菜单（最小集：打开 / 固定到常用·取消固定按清单状态切换 / 在资源管理器中显示 / 刷新）——spec 集中放 menuSpecs/workspace.ts，行包装 div 挂 `@contextmenu.prevent.stop`（FolderTree.vue:150 同款）。

**根行废除**：磁盘上 `workspace/` 只有 `03_资产` 与 `.anikit`，「工作空间」根行是合成假父级，整个删掉、不做区块头替代。根视口可达性 = 切 workspace 分段自动 `openView("ws:")`（SidebarLeft 已有）+ 历史后退。连带：子行缩进归正（根实例 = depth 0，不再有「根行 depth 0、子行 depth 0 但视觉撞兄弟」的错位）；根行的树内拖拽落点（dropZone('')）随根行一并移除。
