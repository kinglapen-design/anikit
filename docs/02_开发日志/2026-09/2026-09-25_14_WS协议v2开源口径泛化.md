## v2 定案与落地

**消息两层**：通用层无前缀（hello / welcome / getTree / tree / saveSettings / settings / settingsError / error——任何软件接入即用）；软件业务消息走 `<app>.<name>` 命名空间（前缀须与 hello 登记身份一致，不符回 error）。接第二个软件 = 新命名空间 + 同模式 handler，通用层零改动。

- **hello 消费化**：登记 app / version / panelVersion 进连接条目（clients 表升级）；业务消息未握手 / 命名空间不符回协议 error（第三方调试友好）。
- **welcome 泛化**：`cepOutDir` → `exportDir`（中转目录通用概念，animate = temp/cep-out）；加 `protocol: 2`；settings 按身份下发该 app 子树（无设置族 = null）。
- **版本握手**（09-02 待办②兑现）：welcome 回 `bundledPanelVersion`（= cep_install::BUNDLED_VERSION 0.4.0，manifest 同步测试护航）；面板自报 panelVersion，不等 → 状态区持久横幅提示重开/一键升级——面板无热更旧码静默丢消息的根治。
- **saveSettings 按身份路由**：载荷不带 app，服务端按登记分发设置族（animate → cepExport 子树校验落盘）；新软件一族 = config 子树 + settings_for/save_settings_for 各加一支。广播带 app 字段，客户端只收自己命名空间。
- **回包字段通用口径**：`flaAssetId/webpAssetId` → `sourceAssetId/thumbAssetId`（工程源文件/缩略图资产；ThumbOutcome 透传结构体同改）。
