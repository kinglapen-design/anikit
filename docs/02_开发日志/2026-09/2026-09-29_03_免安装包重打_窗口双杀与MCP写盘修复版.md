## 翻车实录（踩坑 096）

一轮打包图省事直跑 `cargo build --release` → 换正后用户实机打开 = 整窗 Edge 内核错误页「127.0.0.1 拒绝连接」。根因：tauri 2 的 dev/prod 判断不看 PROFILE，`tauri/build.rs` 里 `dev = !has_feature("custom-protocol")`——`custom-protocol` 由 **tauri CLI 在 build 时注入**，Cargo.toml 自身不带；直跑 cargo = dev 模式 exe = 不嵌 dist、运行时导航 devUrl。一轮冒烟「进程起 + MCP 握手通」全绿却没发现——后端服务与前端加载无关，**没看窗口 UI 是盲点**。

## 终版链路

`pnpm tauri build --no-bundle`（CLI 注入 custom-protocol + 跑 beforeBuildCommand；1m03s，exe 27.6→32.5MB = dist 真嵌入）→ 换正 portable（`app.exe` 改名 `anikit.exe`，9 件 dll/exe + plugins/animate-cep）→ 冒烟三件：MCP initialize 握手通 + config.json `writeEnabled:true` 保留 + **PrintWindow 抓窗口真 UI 目验正常**（深色网格界面全渲染；普通截屏会被遮挡窗干扰，PrintWindow 直抓窗口位图不受遮挡）→ zip 重打。
