# 杂项 · 预览模式导航不退出修复（切文件夹/快速访问无感知）
## 杂项 · 预览模式导航不退出修复（切文件夹/快速访问无感知）

用户实机报：预览模式下点侧栏切换文件夹或快速访问，预览不退出，自己都不知道文件夹已经切了。

**根因**：预览 = 全局单例（`preview.assetKey` 非空即预览模式），ContentArea 按 `preview.assetKey && active` 把激活标签页整栏切成预览画面；而侧栏导航（文件夹树 / 快速访问 / 档案条 / 文件夹卡片 / 菜单跳转）统一走 `tabs.openView` 只改 `sidebarSelected` 与 panel 的 viewKey，从不碰 preview store。视口在预览画面底下悄悄换掉，中栏画面不动，用户无感知。同族暗伤两处：预览模式下右键「新标签页打开」（`openInNewTab` → `addTab`）新页激活后直接进预览而非显示目标文件夹；面包屑后退 / 前进（`goHistory`）同理只换视口不退预览。

**修法**（`src/stores/tabs.ts` 一处收口）：命令层加 `exitPreview()`——`assetKey` 非空时调 `preview.close()`（幂等，含停帧引擎 / 帧流 / 媒体释放 / 全屏退出）；`openView`（替换视口与锁定新开两分支）、`openInNewTab`、`goHistory` 真正发生视口切换前各调一次。**同视口点击（openView 早退分支）不算导航，预览保持**。直接点标签页切换激活（`activateTab`）不动——预览跟随激活 panel 是 4.3 既有设计（非激活 panel 保持原视口），不属于「切换文件夹」。

**验证**：`pnpm typecheck` 0 错、`pnpm build` 通过。全量导航入口已盘点汇聚（FolderTree / LibraryView / ArchiveStrip / FolderStrip / menuOps / relationOps / 各菜单 spec 全走 tabs 命令层，侧栏无绕过直写 `sidebarSelected` 的路径）；全局快捷键在预览模式下被 `preview.assetKey` 拦截，无键盘导航漏口。**行为变化交实机走查：预览中点任意文件夹 / 快速访问 / 新标签页打开，立即退出预览落在目标视口。**
