# 2026-09-25_05 预览播放走带 rAF 丝滑化（previewMedia store 级）

2026-09-25

## 需求

用户实机：播放条竖条波形已正常，但播放走带 fps 低（一段段跳），提示「最开始卡片悬停播放也有这个问题」——即 09-22_11 音频卡 timeupdate 4Hz 段跳的同款毛病，这次在预览播放条。

## 定位与落地

预览播放链路 `FloatBarHost progressModel → spec.progressGet() → media.currentTime`，而 `previewMedia.currentTime` 由 `<video>` 元素 timeupdate 事件驱动（仅约 4Hz）→ 走带段跳。修法照卡片同款但收到 store 级（一处修全链路受益）：`previewMedia.getEl()` 的 play / pause / ended 事件挂 rAF 循环——播放中逐帧读元素 currentTime 写 store（60fps），pause / ended / release 停循环；scrubbing 期间不回写（同 timeupdate 既有口径）；timeupdate 监听保留作暂停 / seek 后低速兜底。消费方 = barSpecs 进度条与时间码（音频 / 视频两族走带同时丝滑），无重活消费方，开销安全。
