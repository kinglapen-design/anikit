# 杂项 · 视频多选/排序卡死根治 + 拖拽提示线出盒修复与边缘自动滚动（2026-09-13，实机走查三条严重项）

来源 = 实机走查（`docs/归档/00_修改与需求/实机走查.md` 整理节）三条严重项：**多选视频界面直接卡死**、**排序视频卡死**、**拖拽排序时滚动条不跟着移动且插入提示线跑到列表盒子外面**。

## 卡死两条同根：media.rs 持全局锁跑 ffprobe/ffmpeg（踩坑 074）

`get_media_source` 是 async 命令却全程持全局 library std Mutex 同步执行 ffprobe 探测甚至数十秒级 ffmpeg 转码；而 `get_asset_detail` / `list_placements` 等读类命令是同步命令，Tauri v2 安排在**主线程**执行——多选触发的详情拉取、排序落点后的 `refresh()` 全堵在锁上，GUI 事件循环停摆 → 未响应。只有音视频走播放源解析（悬停 >300ms 即触发），所以只有视频卡。

修法 = 锁外化三段式：短锁快照（info_dir / origin / meta / lib.root 克隆即放锁）→ `spawn_blocking` 锁外探测与转码（新内部函数 `media_source_heavy`）→ fps 自愈回写保持「先落盘 metadata.json 再短锁同步内存索引 + 广播 video-fps-healed」。同资产并发去重 = per-asset tokio Mutex 串行化（后者 stamp 命中直接复用产物）。`get_waveform` 同病同改。前端 `mediaOps.getMediaSource` 补 in-flight Map，并发请求共享同一趟解析（settle 即删，不长期缓存防换源后吃旧路径）。

## 提示线出盒：多 panel 实例 × 全局单例串扰

dockview 非激活标签页不卸载仅 `display:none`，多 AssetGrid 实例共存；`dragView.gap` 是全局响应式单例，每个实例都渲染 Teleport 到 body 的 `.drop-gap`，隐藏实例的层 rect 全零 → 提示线按 layer 原始坐标画到窗口左上盒子外。修法 = 全链路按激活 panel 归口：`gapClient` 非激活不渲染；resolver 注册改为激活才注册、`unregisterGridResolver` 谁注册谁清；`FolderStrip.gapBar` 查询限定组件根内（原 `document.querySelector` 全局首匹配同病）；ghost 锚点查询收窄到拖拽源所在网格。顺手把 `pos` 纳入 `gapClient` 响应式依赖，滚动瞬间提示线不再滞留旧位置。

## 拖拽边缘自动滚动（新能力）

此前从未实现。素材拖拽指针压网格视口上 / 下 56px 热区时 rAF 持续 `scrollTo`（指针驻留边缘无 pointermove，必须 rAF 驱动），速度随深入 4→24px/帧；每帧滚动后按最后指针坐标重算落点，提示线随滚动跟随。滚动接口随 resolver 注册注入（`registerGridResolver` 第三参），`updateDropTarget` 入参从 PointerEvent 收窄为坐标结构供 rAF 回放。

## 验证与文档

cargo test 448 全绿（media 组 4 项断言语义不变，适配新内部签名）、pnpm typecheck / build 绿。接口文档 18（get_media_source / get_waveform 锁外化口径）、口径速查 07（Teleport 落点指示 panelActive 门控 + 边缘自动滚动参数）同步。实机复验点：视频文件夹多选 / 框选不卡、拖拽排序不卡、拖至上下边缘自动滚动且提示线始终在网格盒内、双标签页 / 分屏提示线不串扰。
