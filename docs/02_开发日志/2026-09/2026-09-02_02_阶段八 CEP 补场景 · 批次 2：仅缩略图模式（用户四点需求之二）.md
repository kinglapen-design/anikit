## 阶段八 CEP 补场景 · 批次 2：仅缩略图模式（用户四点需求之二）

**定案**（用户答）：绑定目标 = 文档路径自动匹配——工程在库内 → 正常导入缩略图到库并链接；不在库 → WebP 导出到原工程文件旁边，用户自己导入。

**落地**：

- **面板**：模式分段「新文件 | 仅缩略图」（localStorage `cepMode` 记忆）；仅缩略图模式隐藏比例/命名/目标文件夹三行（不裁舞台、不改名、绑定按路径匹配），静/动仍生效——静态 = 播放头帧单帧，动态 = 帧范围行（起/止输入框，1-based 含端点，留空 = 全部；超 maxSecs 上限截断并状态区提示，PRD"全帧卡顿风险"口径落地）。导出钮文案随模式切换。
- **jsx**：`getDocInfo()`（文档平台路径/帧数/fps/播放头帧，未保存报空）；`exportThumbFrames(outDir, name, dynamic, start, end)`——不动文档内容直接导画面（不复制元件、不缩放对齐，PRD 手动兜底口径），动态逐帧导主时间轴范围后还原播放头；`toJson` 补反斜杠转义（路径入 JSON 必需）；`cleanSeqDir` 清序列目录残留 png（同名重导混帧坑，元件导出同族一并修）。
- **后端**：cep_export 加 ThumbPayload/thumb_prepare/thumb_compose/thumb_commit（compose 提取 `compose_webp` 共用核心零重复）；`match_fla_asset` = 文档路径 ↔ 池内实体路径（`assets/{ID}.info/{originName}`）精确比对（正斜杠+小写规范化）。命中 = WebP 入库 root + set_thumb_asset 绑定（**已有绑定 = 换绑，旧 hidden 不动**——PRD 口径，批次 4 替换场景由此天然兑现）；未命中 = WebP rename 到原 fla 旁边（重名 `-2` 唯一化）不入库。WS 加 `thumbOnly` → `thumbDone`（serde tag mode=bound/beside）/`thumbError`，bound 时 emit cep-imported 前端对齐。
- **面板回执**：bound =「已绑定缩略图到「资产名」」；beside =「不在库内，已导出到原文件旁边：路径（自行导入）」。

**验证**：cargo test **429** 全绿（+3：路径匹配规范化 / 命中换绑旧 hidden 不动 / 池外兜底 + 重名唯一化）；node 语法过；四文件同步 extensions。**下一步：用户实机复验（库内工程补缩略图绑对资产 / 池外工程落旁边 / 动态帧范围截断）；其后批次 3 = 一 fla 多素材批量分别导出**。
