`pnpm tauri build --no-bundle`（release 1m02s 过）→ 组装 `release/anikit-portable.out/`（406M：app.exe → anikit.exe + av\*/sw\* 七件 dll + ffmpeg/ffprobe + plugins/animate-cep）→ 冒烟：起新包 17701 LISTENING（MCP 拉起 = 新二进制无疑）→ taskkill /F /T 收尸 + netstat 复核无 LISTENING → python zipfile 覆盖 `anikit-portable.zip`（178M，条目根 `anikit-portable/`，18 条目 testzip 无坏文件）→ 旧目录改名受阻（见坑）改 **robocopy /MIR 同步换正**：`anikit-portable.out` 全量镜像进 `anikit-portable/`，diff -r 零差异后删 .out。

## 过程坑两处

**① 旧目录改名 Permission denied（09-23_12 瞬态锁同款复发但非瞬态）**：`anikit-portable`（昨日详情面板四连版）与 `anikit-portable.new`（昨日展开钮修复版，09-23_14 留的待换正尾巴）两目录的 **plugins 子目录句柄被占**——逐文件试改名（09-23_12 手法）顶层文件全可动、独 plugins 锁；无 Animate/CEPHtmlEngine 进程在跑（Get-Process 只余 AdobeIPCBroker 后台服务），疑似资源管理器 / 索引服务持句柄。等数分钟重试三次均败。**处置升级：不改名，robocopy /MIR 把新包直接镜像进旧目录**——目录句柄锁不挡文件级读写，.new 残留（内容已被全面取代、zip 已留档）待用户侧锁释放后手动删/归档。

**② taskkill 按 bash `$!` 收尸找不到进程**：Git Bash 启动的 `$!` 是 shell 包装 pid 非 Windows PID——按 netstat 17701 行的 PID 收尸才对（本轮 23104）。
