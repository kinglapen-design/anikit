# 2026-09-25_11_预览 per-panel 会话化——分屏双预览对比落地

## 任务

当日 _10 的 ownerPanelId 绑定（踩坑 089）只解决「预览不跟激活面板飘」，全局单例本质不变：分屏后想左右各预览一张图对比，B 面板双击 = 预览从 A 跳到 B（用户再报「分屏左右乱跳」）。落地待办细节清单 2026-09-25 已立项的「双预览 per-panel 实例化」。

## 方案（工厂会话 + 注册表 + 注入换源）

- **三 store 工厂化**：preview / previewMedia / previewNotes（会话态）各包 `build*(panelId)` 工厂 + 注册表缓存（`previewSession` / `previewMediaSession` / `previewNotesSession`，store id `preview#{panelId}` 等）。原模块级单例——动图帧流 streamSession/seekTarget、序列帧 rAF 三变量、全屏 savedView、media 的 `<video>` el/重试标记/走带 raf——全部收进工厂闭包 = 每会话一份（这是比 UI 更硬的改造点）。
- **previewNotes 拆分**：全局店只留共享命令层（version / loadNotes / saveNote / getNoteThumb，DetailPanel 无预览态也消费）；open / notes / currentKey / toggle / jump 等会话态入 per-panel 店，写操作回调全局 saveNote 保 version 热刷新链路。
- **组件层注入换源**：ContentArea / PreviewWindow `provide(PREVIEW_SESSION_KEY, 会话)`，预览族 11 组件 + WaveProgress + FloatBarHost `inject` 取本 panel 会话，局部变量名沿用 `preview`，模板零改动；barSpecs 工厂改收 `{ preview, media }` ctx（FloatBarHost 透传）。`usePreviewStore` / `usePreviewMediaStore` 导出废除，typecheck 兜住 24 个消费文件全换源。
- **键盘按激活 panel 路由**：PreviewPanel 的 window 级 keydown 加闸 `tabs.activeTabId !== session.panelId` 即 return（分屏双预览并存双响应根治；子窗口 activeTabId 恒 "" 自然放行）；useGlobalKeys 四处闸门 + Ctrl+E 改取 `activePreviewSession()`——激活 panel 预览中才让位，激活 panel 是列表时全局键照常（即使别的 panel 在预览）。
- **tabs 定向化**：`exitPreview(panelId?)` 只退目标 panel 会话（导航不再误伤其他 panel）；`openView(viewKey, panelId?)` 支持定向（锁定判定/历史栈/updateParameters 全按目标，sidebarSelected 仅目标是激活 panel 时回写——SequencePackView 包内帧预览在非激活 panel 触发不再导航错 panel）；`syncMirror` 遍历注册表精准回收死 panel 会话（限 "tab-" 前缀，设计稿页 "__design__" 占位会话不误伤）。
- **预览列表源换轨**：`current/index/total/step` 从全局 `visiblePlacements`（跟激活视口）→ `content.placementsFor(tabs.viewKeyOf(panelId))`（本 panel 视口）——上/下一个按属主面板口径。
- **菜单 panelId 穿线**：AssetGrid 注入会话 → gridDispatch 加参透传 → assetCard / recycle / workspace 三 spec 的「打开预览」——顺带根治 089 遗留的「非激活 panel 右键绑错属主」隐患。
- **独立预览子窗口** = `WINDOW_PANEL_ID` 单会话（各 webview 独立 pinia 天然隔离）；**Tauri 事件监听**（preview-full-ready / preview-strips-ready / main-window-hidden）升注册表 `initPreviewListeners()` 扇出全部已建会话。
- 设计稿预览页（DesignSystemPreview）根部 provide `previewSession("__design__")` 占位会话——展区真实实例 FloatBarHost / WaveProgress 注入必需（assetKey 恒 null，只供取数不崩）。

## 行为口径（取代 _10 定案）

- B 面板双击 = B 开自己的预览、A 原样保留（双预览对比落地；_10 的「明确归 B」废除）。
- 导航（侧栏/面包屑/新标签打开）只退出发生导航的 panel 的预览。
- 属主 panel 关闭只回收该会话（syncMirror 精准回收 + pinia state 键删除）。
