# 3.3 二轮（用户实机走查三修订）

**3.3 二轮（用户实机走查三修订）**：
  - **缩进线不变色**：--guide-color 机制撤销（FolderTree 回退）——原半透明 var(--line-hover) 线叠在带色 item 上自然叠出略带颜色的线条，无需显式变色（用户定）。
  - **同步语义替代复选框**（图标「应用至子级」复选框取消，颜色本就不加；用户先给复杂判断的退路"颜色也加复选框手动影响"，评估后实际改动不大按原口径做）：父级改动**默认影响子级**——后端 `sync_follow_targets` DFS：后代与本节点旧链路值**一致的跟随调整**（图标含 None == None——未区分子级首次统一靠此；颜色旧链路上溯祖先链最近色、**无色后代不写数据但链路穿透**——视觉自动跟随底色版本），**不一致的（用户单独区分过）不动且不再下钻**。修复用户场景：子级单独区分后改回与父级一致，父级再改时子级重新跟随。图标侧档案后代恒跳过；set_folder_icon 去 applyToChildren 参数。分支顺序坑：颜色 None 穿透须先判（否则 P 从无色设色会把全部无色后代写入数据）。
  - **验证**：cargo test 329（4 用例重写：首次统一/区分阻断/改回一致重跟随/祖先链路上溯）；CDP 探针重写 S1-S8 + 新增 S3b（图标不跟随）/ S6b（颜色用户场景）64 项全 PASS；typecheck / build 全绿。
  - 文档同步：PRD 02-45/46（同步语义）/ 07 接口文档 / 02 组件目录（去复选框描述）/ 进度。
