# 2026-11-02_07 详细分析事件容错：不合规事件丢弃不整单失败

2026-11-02，feat/new-ui。用户实机用 DeepSeek 跑详细语义分析，toast「1 个素材失败」且 DeepSeek 后台未见 token 消耗。MCP 任务快照取到真实错误：`事件 7 的时间区间未覆盖任何证据帧时间戳`——请求实际已成功往返 DeepSeek（用量页延迟造成"没扣费"错觉），是本地防幻觉校验把整单拒了。用户重试即成功，确认是模型输出随机性的概率问题。

## 定案

模型对单个事件编出落空时间区间属随机失误，**不该整段素材判失败白扔一次调用额度**。改为**不合规事件逐个丢弃（log::warn 记录原因），description 与其余合规事件保留入库**；防幻觉口径不变——不合规事件永不入库。主干校验不动：description 缺失/为空、证据帧数不匹配仍整单失败。

改动 = `provider_schema.rs` parse_response 事件循环（Result collect → 逐个 match 丢弃）；测试 `rejects_bad_time_certainty_and_uncovered_evidence` 重写为 `drops_bad_events_but_keeps_description_and_good_ones`（好坏混合只留好的 / 全坏事件清空但成功 / 主干失败口径不变）。
