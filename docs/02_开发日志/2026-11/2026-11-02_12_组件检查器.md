# 2026-11-02 组件检查器（opendesign 式选组件调参）

用户看 Token 调参面板后反馈「看不懂怎么用，我以为是选择一个组件，弹出一个面板调整，然后我看实时效果的那种」——全局 token 列表不是他要的形态。本轮在调参面板加「组件」页（默认页，Token 页保留），把交互改成他描述的样子。

## 交互

「调参」浮动钮 → 组件页 → **选择组件**：进入 pick 模式，悬停高亮 + 标签跟随，点击页面里任何组件即选中（拦截原交互，Esc 退出）。选中后面板显示：

- **面包屑**（`span.pv-ws-subpath › div.pv-ws-gcard › … › div.pv-move-shell.w640`，点击上钻父级——点到文本节点也能一键回到卡片容器）；
- **选择器行**（自动生成的 CSS 选择器，可复制）；
- **属性编辑器**：宽高 / padding 四向 / margin 四向 / gap / 圆角（滑杆 + 数字），display / flex 方向 / 主轴 / 交叉轴（下拉），字号 / 行高 / 字重 / 文字色，背景 / 描边 / 阴影（文本）。

改动 = **inline style 覆盖，实时生效**；覆盖行品牌色高亮 + 计数；单项 ↺ 重置 / 重置此组件 / 全部重置 / 重新应用。覆盖集按选择器存 localStorage（刷新后重应用）。**「复制覆盖 CSS」导出选择器分块**（`/* selector */ selector { padding-top: 12px; }`）与 JSON，贴回组件样式或发 AI 定稿；剪贴板被拦时与 Token 页同兜底展示原文手动复制。

## 目验

内置浏览器全流程：选择组件 → 点中「管理工作空间」弹窗 02_创作 名称行（span.pv-ws-subpath）→ padding-top 改 12 → 行立即撑开、行品牌色高亮、计数 1、选择器与面包屑就位；重置此组件复原清零。typecheck 0 错。测试覆盖已全数重置，不留污染。

文件：`src/preview/devInspector.ts`（pick / 选择器 / 计算样式 / 覆盖与导出）、`DevInspectorPanel.vue`（组件页）、`DevTokenPanel.vue`（双页 tab）、`preview.css`（dt 共享小件抽出两页共用）。零后端零新依赖零生产进入。
