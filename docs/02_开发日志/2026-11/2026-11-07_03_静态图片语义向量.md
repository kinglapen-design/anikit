# 静态图片语义向量

2026-11-07，用户要求把常见静态图片接入既有向量能力。范围为 PNG / JPG / JPEG / WebP / BMP 的基础画面分析与中文语义搜索，不带详细事件、时间定位或片段截取。

## 链路修正与实现

旧链路有两道限制：候选判定允许 PNG，启动前却又把非 APNG 的 PNG 过滤；执行层最终也只接受视频、动图和序列帧。本轮移除旧过滤，新增 `MediaKind::Image` 与单图分析入口，直接读取原图并调用既有 `embed_image`。

每张静态图只生成一个 `visual` 向量，起止时间为 0、帧索引为空。SQLite schema、模型和 `analysis_version = 1` 均不变，既有视频 / 动图 / 序列帧索引继续有效，搜索与分通道融合无需分叉。

前端用 `hasSemanticTimeline` 统一时间轴能力判定。静态图命中后保留原缩略图、不出时间徽标；详细语义分析、创建虚拟片段和物理截取在菜单中禁用，双击仍正常打开预览。片段后端也有明确拒绝分支，不只靠界面门禁。

`analysis.rs` 原有测试移至 `analysis/tests.rs`，新增五种格式候选测试并扩展真实模型回归。新增独立探针 `tools/cdp-semantic-static-live-probe.py` 覆盖静态 PNG 的实际界面链路。

## 验证

全量 `cargo test` 为 734 项通过、0 失败；生产 Clippy、`pnpm build`、`pnpm typecheck` 通过。真实模型回归完成五种格式分析，每张图均只有一个无帧索引向量，并全部进入中文搜索结果。

隔离 Tauri 探针完成静态 PNG 导入、分析、搜索、卡片无时间徽标与双击预览。菜单门禁通过生产 `assetCardSpec` 实调验证；右键菜单的 CDP 时序不作为本轮验收依据。实例已关闭，本轮未重打免安装包。
