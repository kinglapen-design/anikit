# 2026-11-02 CLI 外接入口（1.0 收尾第 8 项）

用户定 1.0 收尾从第 8 项 CLI 开始。PRD 08-06 既有口径 = CLI 与 MCP 并存、瘦客户端连运行中的 AniKit、复用同一业务与红线、紧凑 JSON、先只读后写。本轮定案并落地，路线图第 8 项已勾销。

## 定案：MCP JSON-RPC 瘦客户端，后端零改动

两条路线里选了**纯客户端**：`anikit-cli.exe`（src/bin 第三 bin）POST `127.0.0.1:{port}/mcp`，每次运行一次握手（initialize → initialized 通知 → tools/call），SSE 与 JSON 两种响应形态都接。另一路「后端加 REST 薄端点直路由工具」被否——要在 rmcp 宏路由外再造一层分发，违背「不另造业务管线」。选定方案下工具面、写入闸、撤销、热刷新广播全部走 MCP 既有实现，AniKit 侧没有任何 CLI 专属业务代码，旧 release 包（20261101）无需重打即可被新 CLI 直接驱动。

端口发现复用 anikit-paste 同款 `mcp-server.port` 端口文件（缺省回退 17701，`--port` 覆盖）；reqwest blocking 是既有依赖，零新增 crate；不引 clap，手写 argv 解析（全局 flag 任意位置、等号形态同吃）。

## 命令面与输出

首版 = **只读 13 工具全量子命令**：status / search / tree / placements / detail / path / read / archives / archive / links / semantic / task / tasks，另 `tools`（tools/list 瘦身 = 名称 + 描述 + readOnly，不带 inputSchema）与 `--help`。id 参数与 MCP 同口径吃 anikit:// / http 链接整段透传。

输出 = 紧凑 JSON（`--pretty` 缩进，解析失败保原文）；退出码三态 = 0 成功 / 1 工具级错误（stdout `{"error":...}`，如「请先打开素材库」）/ 2 连接·协议·用法错误（stderr 中文）。分发 = `tools/pack-portable.py` 缺产物检查与组装各加一行 `anikit-cli.exe` 带件。

## 验证

`cargo test --bin anikit-cli` 4 测绿（参数映射全命令 / 错误与帮助 / SSE 切分 / 回包提取与瘦身）；clippy 净。真实验证直连**正在运行的免安装包实例**（Lapen 空间 / 动画资产库，3991 资产）：status 回真实库态、search「杰森」回真实命中、tools 回 40 工具瘦身清单、path 回真实磁盘路径、`detail anikit://item/...` 链接透传正常、`--pretty` 缩进正常；不存在 id 回 `{"error":"资源不存在，可能已被删除"}` + 退出码 1，错端口回中文连接失败 + 退出码 2。
