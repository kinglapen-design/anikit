# 2026-11-02_03 语义搜索体验两件：进度条显示修复 + 卡片命中徽标

2026-11-02，feat/new-ui。用户实机用语义搜索连报三个体验问题：分析时看不到进度、不知道跑没跑完；搜索能定位到视频但看不到时间戳。排查 = 一个真 bug + 一个体验缺口，当日全落地。

## 进度条显示修复（真 bug）

语义分析的进度条**本来就该复用导入进度条**——10-25 落地时 `ImportProgressBar.vue` 内 semantic 分支的接线全做（标签「正在语义分析 (x/y)」、模型准备期「正在准备语义模型…」不定态、关闭钮 = cancelActive、优先级 导入/导出 > 语义 > 爬盘），唯独根元素 `v-if="p || crawling"` **漏了 semantic 条件**，纯语义任务时进度条根本不渲染。后果链：用户看不到进度 → 重复点「分析文件向量」→ 撞单任务锁弹「已有语义分析任务未结束」→ 又找不到取消入口（取消按钮就在不渲染的进度条上）。

修复 = v-if 补 `|| semantic`（`src/components/ImportProgressBar.vue:77`）。卡死自救口径：**重启即解锁**——任务锁在内存（AppState.semantic_tasks），开库时 `recover_interrupted` 自动标记残留任务，已分析素材经检查点续跑不白费。

## 卡片语义命中徽标（体验缺口）

用户实测「枪指着头」「啤酒放在桌子上」能命中正确视频，但**卡片上看不到命中时间**，误以为没有时间戳能力。经 MCP `semantic_search` 实证：数据层分段精细（best 段 20250–20750ms，正好覆盖用户指认的 489 帧@24fps ≈ 20.4s），双击预览的 seekToSegment 跳转链路（preview.ts:221 → previewMedia.seek）一直在工作（用户截图停在 486 帧整 = 20.25s 整，正是命中段起点）。缺的是**结果卡片不直显时间戳**。

落地：语义搜索结果态网格卡新增**语义命中徽标**——`.kc-float` 铬右上各 12（FormatBadge 左上镜像位），内容 = best 段起点 mm:ss（formatDuration）+ 多段 "+N"（segments 含 best，N = len-1）；mono 数字档 12/16 bold 二级（同笔记数量档），随卡 hover 位移 -4px、选择模式压暗 30% 档、pointer-events none 纯展示。数据 = search store `semanticHitFor(panelId, assetId)`，AssetGrid 经 preview session 透传 panelId（`preview.panelId`，preview.ts:110 state 既有）。仅视频/动图/序列帧出徽标（音频/字体不在分析范围，右上无胶囊/安装钮冲突）。

改动：`src/components/AssetGrid.vue`（传 panel-id）+ `src/components/AssetCard.vue`（prop + computed + 模板 + 样式，笔记徽章同族写法）。

typecheck 通过。徽标效果待用户实机走查（语义搜索后卡片右上出时间徽标）。遗留待办：**列表行（ListRowCard）未接命中显示**（列结构牵 ListHeader 表头）；**暂停/恢复/重试**后端与 MCP 均有、APP 内无 UI 入口（10-25 状态文档「前端真实交互探针」余量）；进度条修复随本轮，状态文档 `2026-10/2026-10-25_04` 已补注。
