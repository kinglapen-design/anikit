# 2026-11-02_08 语义命中定位窄段 + 卡片命中帧图与起播点

2026-11-02，feat/new-ui。用户实机两报：① 详细分析后命中徽标永远 `00:00 +7`，时间戳失效；② 搜索结果卡片从头自动播放，"还得一个个点进去才知道要哪个"——建议卡片直接停在/起播命中帧。当日全落地。

## 定位窄段（根因修复）

description 段（详细分析的整体描述）覆盖近全片（startMs≈0），且整段文本关键词密度高、相似度常最高 → best 被它占住 → 徽标 00:00、双击跳转回开头。定案口径：**best 不动**（最高相似度 = 相关度排序语义，影响 asset 排序与 MCP 回包），**一切「定位」消费统一取窄段**——`pickLocateSegment`（lib/semantic）：segments（后端已按分数降序）首个 kind ≠ description 段，窗口内全宽段才回退 best。接入点：AssetCard 徽标、preview.open 跳转（seekToSegment）、stores/semantic create 创建片段。

## 卡片命中帧图与起播点（用户定案）

- **静态缩略图 = 命中段首帧**（「没开自动播放就停在命中的那一帧」）：视频 `t:{秒}` / 动图 `f:{帧索引}` / 序列帧帧名，复用 get_note_thumb 幂等缓存（命中帧图 = 派生数据，语义域薄封装 getSemanticHitThumb）；抽帧失败/取不到保持原封面不打扰。
- **起播点**（「开了自动播放就从命中的往后放」）：HoverVideoLayer 新增 `startAt`——auto 模式范围起点 = 命中点（10s 封顶循环，替代封面帧），悬停模式初始落点 = 命中帧、范围仍全片（scrub/循环不受影响）；HoverSequenceLayer 新增 `startFrame` 起播索引优先命中帧。AssetCard `semanticHoverProps` 按 kind 透传（video=startAt 秒 / sequence=startFrame）。
- 边界：动图 AnimImgLayer 原生 img 无起播帧控制（记待办）；序列帧帧名经 listSequenceFrames 按 startFrame 索引取（多一次 invoke，watch 内防切选中竞态）。
