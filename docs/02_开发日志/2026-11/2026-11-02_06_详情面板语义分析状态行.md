# 2026-11-02_06 详情面板语义分析状态行

2026-11-02，feat/new-ui。用户实机问「怎么知道哪个素材已经有向量、哪个还没有？详情面板需要挂什么信息吗」——确认是功能缺口：分析状态只在 SQLite 派生索引里，UI 无任何可见入口。当日落地。

## 方案与落地

状态行挂**基础信息 tab 基本数据区块末位**（TabBasic dataRows，尺寸/大小/格式/日期之后），仅可分析类型（视频/动图/序列帧）出行，静态图无此行。文案三档：`未分析` / `基础 N 段` / `基础 N 段 + 详细 M 条`（N = 当前模型版本有效分段数，M = description/event 详细文档数）。

- 后端：新命令 `get_semantic_asset_status`（commands/semantic.rs → services/semantic/analysis.rs `asset_status`）——`analyzable` 与分析目标 supported 同口径（排除 hidden 与虚拟片段）；`segmentCount` 走既有 `segment_count_for_model`（模型版本 + analysis_version 隔离口径）；`detailedCount` 走 `provider_document_count`（**摘除其 `#[cfg(test)]` 门控转正**）。全容错：模型目录未配置或索引不可读时两计数按 0 返回，面板不被打断。
- 前端：`lib/semantic.ts` 类型 + 命令封装；TabBasic watch（选中 assetId + `semanticTasks.last` 任务完成快照）拉取——分析跑完状态行自动刷新，无需手动重开面板。await 期间切选中按 id 失配丢弃。

## 验证与边界

cargo check / clippy 净，语义专项 41 项过（5 ignored 系既有），pnpm typecheck 过。实际显示效果待用户实机走查。边界口径：模型未配置的新用户显示「未分析」（容错归零，不报错）；虚拟片段（type=segment）不出行（supported 排除）；档案形态不挂（分析是文件级概念）。
