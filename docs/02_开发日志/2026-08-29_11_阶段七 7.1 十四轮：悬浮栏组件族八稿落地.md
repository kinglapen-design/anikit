## 阶段七 7.1 十四轮：悬浮栏组件族八稿落地

**稿源**：`组件/悬浮栏/多功能悬浮栏/` 八稿（搜索框 / 搜索栏展开成筛选 / MarkDown 工具栏 / 播放条 / 帧条 / 倍率 / 音量 / 笔记）→ `src/components/bars/` 9 件 + 共享 `bars.css` + 预览页「组件 · 悬浮栏」展区。

**用户定案一笔**：切换动画参数——稿只写「宽度平滑伸缩，功能按钮 Y 轴出场入场」未给数值，用户定 **250ms 小位移 + Y 位移 4px**（缓入缓出）。

**落地要点**：

- **FloatBar 四模式同一容器**（搜索 / MarkDown / 播放切换，稿 prose）：壳 = `.fb-shell`（通用/半透明-2 + 立体感-背景模糊 + 圆角 21 稿值字面量——同波形 99px 先例非新造 token + 高 42 + overflow hidden）；padding 12/16 由模式根 `.fb-mode` 自带（四稿同值）。**宽度动画 = DropButton 同款 JS 实测 + 显式 width 过渡**（内容自适应宽 CSS 无法过渡，踩坑 055）：内容槽恒 max-content 可测（离场内容 absolute 不占宽），模式切换 / 搜索展开收起 / 聚焦失焦 / fonts.ready 触发重测，ready 类 rAF 后开过渡防首帧闪；`width` prop 显式覆盖（帧条同宽组合场景）；`visible=false` = 宽度 0 + 透明度 0 退场（稿 prose）。模式内容 props/事件经 `$attrs` 透传（inheritAttrs: false）。
- **FloatBarSearch**：常态 250 / 聚焦 450 / 展开 max-content（稿值）；搜索 icon 三级、筛选 icon 与收起钮 半透明-2（烘焙值已转 currentColor 由 CSS 给档），hover 均升二级；占位符 半透明-2、已输入文字 二级（稿无已填态，随输入框族）；收起钮 = expand 旋转 90° 朝左；筛选钮 24 高 半透明-3 底 + 立体感-通用 + 次要文字-加粗 二级，hover 底升半透明-2、选中 半透明-1 + 一级。
- **FloatBarMarkdown**：段落 / 列表 / 插入 / 格式四组，组间 1px 半透明-3 border-left 分隔（稿方案）；图标全 **IconButton bare 复用**（18 实寸三级 hover 二级）。
- **FloatBarPlay**：稿为全量陈列 → `show` prop 按组删减（transport/step/volume/rate/loop/note/cover/fullscreen）；**播放/暂停、声音/静音 = 单钮按态切换**（playing/muted prop，两态并列是全量画法）；时间码 数字-大（当前/分隔 二级、总计 三级）；进度条 = BarSlider 宽 327 稿值、**无填充段**（稿未画，进度靠拖钮位置——旧体系品牌填充不沿用）；**循环/笔记开启态稿未画 → 不改视觉记 09 待办**。图标朝向：seek 原样 ◀◀ 快退 / flip-h ▶▶ 快进；step-frame 原样 |◀ 上一帧 / flip-h ▶| 下一帧（与旧口径同终稿，探针截图实证）。
- **BarSlider 两稿合一**（进度条 / 音量滑块）：轨道 6px 圆头 99px（稿 height 0 + border 3 等效渲染）、拖钮 10px 圆形 二级 + 1px 描边；tone light = 半透明-3 档（播放条）/ dark = 通用/四级档（音量）；pointerdown 跳值 + window pointermove 拖动（速查表 §9 ③ 同款）。
- **四弹层 = `.fb-pop`**（通用/半透明-1 + 立体感-背景模糊-大阴影 + 圆角 8）：RatePop（11 档降序，选中品牌底 + 立体感-主要按钮 + 一级，hover 六级）/ VolumePop（124 稿值）/ FrameStrip（与播放条同宽 + 间距 12 归父容器；上/下帧 = 尖括号 angle-bracket 下一帧 flip-h；帧图 129×76 二级底 + 1px 三级描边；**当前帧高亮稿未画记 09**）/ NotesPop（533×378 稿值；打开即聚焦输入稿 prose；取消/确认复用 ActionButton lg solid/primary flex 均分——提权覆盖 flex:none 按速查表 §6）。
- **图标四批 29 个转 currentColor**（search / filter / heading-1~6 / body-text / quote / 三列表 / table / code-block / code-inline / insert-link / divider / bold / italic / strikethrough / seek / step-frame / volume / mute / loop / note / fullscreen / angle-bracket），命名对照登记。
