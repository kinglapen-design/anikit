# 修复：最近使用不热刷新（用户实测：要重启软件才更新）

**修复：最近使用不热刷新（用户实测：要重启软件才更新）**。根因 = `open_with_default_app` 前端直接 invoke、后端 `touch_recent` 后无任何通知，前端 recentAssets 仅全量 refresh 才拉。修法 = 记录成功广播 `recent-changed` 事件（commands/preview.rs 加 AppHandle），前端 content store 新增 initRecentListener 重拉 refreshRecent（App.vue 注册）；未来哈希变更 / 发送 / 拖出三入口挂钩时同发此事件即可。cargo test 217 过、clippy 清零、tsc / build 全绿。
