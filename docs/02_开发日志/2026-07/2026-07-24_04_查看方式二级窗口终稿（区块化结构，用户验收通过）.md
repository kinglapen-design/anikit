# 查看方式二级窗口终稿（区块化结构，用户验收通过）

**查看方式二级窗口终稿（区块化结构，用户验收通过）**：级联菜单 → 设置面板式二级窗口（宽 296）——窗口 padding 0 gap 0，三区块各自 padding 16 / gap 8（下拉行组 / 自动播放开关组 / 显示开关组），组间 inset 0 1px 顶部分割线（border-2，与详情面板区块同配方），衔接处 16+16=32 自然成区块感。**经验定案：1px 分割线用 inset box-shadow 顶线 + 整数 padding 位置最稳定**——MenuDivider 的 ::before 细线（圆头 / margin / 嵌套 gap 构成）在缩放动画或亚像素偏移下会渲染成粗细不一（排查三轮：通栏 → 去圆头 → 区块化，区块化后用户确认解决）；MenuDivider 组件保留仅用于菜单内部。配套：浮层 padding 三档规则（标准菜单 8 / 工具栏弹出的二级设置窗口 16 / UI 中间模态·非模态 32）、AppSwitch（标准 50×28 / 小号 40×24 滑动动画）、AppMenu pad/gap props + 弹出缩放动画、picker 下拉独立组 + trigger 指向当前按钮（再点 toggle、选中即关）、弹窗遮罩恢复 C1-80。
