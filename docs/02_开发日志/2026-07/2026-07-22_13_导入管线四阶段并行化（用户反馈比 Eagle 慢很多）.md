# 导入管线四阶段并行化（用户反馈比 Eagle 慢很多）

**导入管线四阶段并行化（用户反馈比 Eagle 慢很多）**：原单线程串行、每文件读盘 2~3 遍。引入 rayon（四问：Rust 官方生态核心库、rayon-core 1.13 发布于 2025-08、MIT/Apache、纯 Rust 无 C 依赖、无现有替代）——阶段 1 并行 sha256（IO 密集）→ 阶段 2 一次短锁全量查重（hash→meta 预建 HashMap，O(A+N)）+ keep 层级先行 → 阶段 3 并行 复制/移动+缩略图+metadata → 阶段 4 mpsc 消费者串行注册（Placement+索引+节流落盘）。**基准实测（#[ignore] 留存）：100×2MB 随机图，串行 21.32s → 并行 1.42s，15.06x**（32 核）。语义不变：started/folders/asset/finished 不变式有断言，cancel 保持"当前文件写完后停"，同批次重复（twin）待注册后组装冲突项（existingThumbPath 才可用）。进一步空间（未做）：copy 与 hash 单遍合并、缩略图剥离后台队列（先入席后补妆，Eagle 感知快的真正来源）——瓶颈已转移到磁盘 IO，需要再上。
