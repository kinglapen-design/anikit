# inbox 语义重定（用户讨论定案，先改 PRD 不写码）

**inbox 语义重定（用户讨论定案，先改 PRD 不写码）**：推翻"任何文件另存为到 inbox 即自动过境"——Inbox 改定位**工作中素材/模板快速入口**，不是工程收纳器；素材模板也可能是工程文件（一段表演单独存盘），不能按"完整动画才配叫工程"窄化。硬伤两条：工程占用期物理移不动；后台移动会改动画软件"最近打开"路径语义（RECOVER/.blend1 也要求原位）。新规则：自动入库收窄为**白名单可视素材格式**（当前 = 4.2 可出缩略图口径 + 视频：png/jpg/jpeg/bmp/webp/gif/psd/psb/svg/ai/mp4/mov/avi/mpeg4/m4v，音频待 5.1 波形/元数据就位再扩），仍 Move 过境；**不反向枚举工程格式**（用户指正：枚举不完），白名单以外一律不自动导入，仅磁盘实况展示。快速访问 Inbox 两区块：**工程文件**（扫描磁盘实况，热刷新必须准确、不丢实际文件防黑箱；不建档不写库不建持久状态；提醒文案写死"工程文件不支持自动导入，请手动导入"；右键只给打开/重命名/删除与手动导入；**手动导入 = 移走入库（剪切语义，入口明示"源文件将从收件箱移走"）**，不做复制入口——复制会让磁盘实况与库内资产在 UI 上并存两份（用户指正）；导入后工程区块消失、已导入区块出现，后续整理归用户）+ **已导入**（写库数据：媒体自动 + 工程手动）。伴生判定同时收窄：**工程未入库不参与**，媒体入库查库内已入库工程、工程手动入库再查库内已入库媒体。被占用从"等放手自动入库"改为工程实况状态；放手后不自动入库。伴生缩略图定原则：不做同名扫描过滤（会误伤真正同名工程+图片），走**双向候选提示**（图片查工程、工程查图片，同一条候选，先后无关），候选只提示不过滤、不建持久状态，确认"设为预览图"才把媒体收进工程 info 作 cover/sidecar 并撤独立 Placement，"两者都要"保持两独立资产；实现归 8.2 前置底座。PRD 01 / 05 / 06 与 05 进度已同步；hash 自动合并收窄为只服务自动入库媒体（RECOVER 场景随工程不自动入库消解，工程手动导入撞 hash 走正常重复提示）。
