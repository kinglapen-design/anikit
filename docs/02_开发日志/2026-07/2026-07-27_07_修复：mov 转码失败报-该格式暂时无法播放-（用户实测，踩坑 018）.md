# 修复：mov 转码失败报"该格式暂时无法播放"（用户实测，踩坑 018）

**修复：mov 转码失败报"该格式暂时无法播放"（用户实测，踩坑 018）**。根因：sidecar 是 LGPL 构建，**没有 libx264**（x264 为 GPL 许可），而 5.2 转码参数按惯性写了 `-c:v libx264`——ffmpeg 编码器缺失非零退出，转码兜底静默失败。改用 LGPL 构建内可用的 `libopenh264`（Cisco BSD，无传染；不支持 crf/preset，改 `-b:v 3M` 码率控制）。先用 `-encoders` 核实构建清单（libvpx-vp9 太慢、h264_mf/nvenc/qsv 依赖机器，均不作首选），再用用户真 mov（魔马跑，无音频流）手动转码验证 0.58s 成功 + `ffmpeg_transcode_smoke`（ANIKIT_TEST_VIDEO=该 mov）通过。cargo test 166 过零失败、clippy 清零；07 接口文档转码参数同步。
