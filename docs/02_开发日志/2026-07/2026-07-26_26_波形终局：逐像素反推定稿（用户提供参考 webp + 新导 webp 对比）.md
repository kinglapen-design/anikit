# 波形终局：逐像素反推定稿（用户提供参考 webp + 新导 webp 对比）

**波形终局：逐像素反推定稿（用户提供参考 webp + 新导 webp 对比）**：双层渐变恢复版对短音频整体发淡（alpha 统计：近满色仅 0.5%——短文件每窗口仅 ~2 样本，纵线短且不重叠，梯度机制天然发淡，我此前用 8s 噪声样本目检被误导）。取参考版音频本体跑候选算法逐像素比对（`tools/waveform-match.py`）：满色 1px 纵线系三变体均 95%+ 匹配、无柔化略优——参考版即**满色 1px + 竖向柔化**（c639e35）。最终渲染 = c639e35 原样恢复，再用参考音频本体渲染比对 95.3% 逐像素一致（残差为编码误差）。**教训：波形类目检必须用用户真实音频（短文件），合成样本会掩盖口径缺陷。**cargo test 132 过零警告、clippy 清零。
