# 5.2 后端第一块：动图帧解码管线 + 设封面帧扩展（后端落地，前端未接）

**5.2 后端第一块：动图帧解码管线 + 设封面帧扩展（后端落地，前端未接）**。① **动图流式解码**：`services/anim.rs` 加 `decode_frames(path, on_frame)` 单趟逐帧回调（帧序号/RGBA/delayMs，回调 false 中止）——GIF 走 image 0.25 的 GifFrameIterator（**内部已按 disposal 合成完整画布帧**，与 collect_frames 语义一致，无需自写合成器），WEBP 走 image-webp read_frame；decode_frame 改为基于它的薄封装，消除每帧全量重解码 O(n²)；坏帧跳过 warn 但占号（帧名与 frameCount 占位清单一一对应）。② **cache 约定**：播放帧 `cache/anim/{assetId}/frame-NNNNN.webp`（长边 ≤4096 等比，libwebp q80 同既有管线，thumbnail::save_anim_frame），帧条 `cache/frames/{assetId}/` 与序列帧同构（generate_frame_strip 复用，从刚落盘的播放帧读）；cache/anim 进 library.rs open() 会话级清空名单。③ **PreviewTask::AnimFrames 进预览解析队列**：worker 逐帧落盘 + 每 8 帧一批发 `preview-anim-frames-ready { assetId, done, items }`，收尾发 done=true 最终批（items 可空）；逐帧查代际可中断（回调 false 停解码）。④ **命令**：`list_anim_frames`（新，commands/anim.rs，占位清单立即返回 + 缓存命中直给 + 未缓存入队）；`set_thumb_frame` 扩动图分支（cache/anim 取帧，未就绪报"帧尚未解码完成，请稍后重试"）；`set_video_thumb`（新，ffmpeg 截帧 → cache/tmp 临时 PNG → 同管线缩略图，thumbFrame 记 `t:{秒}`）。**单文件 500 行红线触发拆分**：commands/preview.rs 的封面帧逻辑迁 commands/thumb_frame.rs（locate_asset 升 pub(crate) 共用）；全局队列测试互斥锁上提 preview_queue::TEST_LOCK 跨模块共用（preview/anim 两组测试并行会互顶任务）。cargo test 142 过零警告、clippy --all-targets -D warnings 清零。
