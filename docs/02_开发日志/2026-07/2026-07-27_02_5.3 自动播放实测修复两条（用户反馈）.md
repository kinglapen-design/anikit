# 5.3 自动播放实测修复两条（用户反馈）

**5.3 自动播放实测修复两条（用户反馈）**。① **动图（GIF/WEBP）滚出视口再回来 / 视口外滚入不播**：根因 = 动图播放靠 `watch(animPlaying)` 触发但无 `immediate`——虚拟滚动销毁重建后 animPlaying 挂载即 true 无"变化"不触发（序列帧/视频走组件 onMounted 启动故不受影响），watch 加 immediate。② **序列帧播放与静态封面双重影像**：序列帧播放层叠在卡片缩略图上、帧图透明底透出底层封面，层加 C1 底（与卡片图同口径）盖住。tsc / build 全绿。
