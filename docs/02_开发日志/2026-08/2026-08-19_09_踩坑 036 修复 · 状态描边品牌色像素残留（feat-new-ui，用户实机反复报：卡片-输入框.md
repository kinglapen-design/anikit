**踩坑 036 修复 · 状态描边品牌色像素残留（feat/new-ui，用户实机反复报：卡片/输入框 聚焦·选中·右键选中取消后圆角处残留品牌色像素）**：
  - **根因**：`border-color` / `box-shadow` transition 是**重绘型动画**——圆角 + 1.5px 分数像素下，过渡结束时 GPU 合成器损伤区偶发漏覆盖，上一态品牌色像素留屏。headless 软渲染探针 30 轮复现不了（合成路径不同）。
  - **修法（全库统一）**：状态描边改**双层结构 = 常态层（无过渡）+ 状态层（1.5px 品牌框 opacity 0↔1 过渡，合成器属性无光栅损伤）**——AssetCard（::after 常态 + ::before 状态）/ FolderCard / ArchiveCard / InboxDiskSection（同双层）/ PreviewFrameStrip（.frame.active 元素 border 改 ::after）/ AppInput **统一壳化**（"非 clearable 裸 input"分支废除——input 无伪元素；聚焦 = 壳 ::after opacity；CreateLibraryModal `$el.focus()` 改 expose `focus()`；BlockManageRow / 分组三组件的底色覆盖选择器随壳化适配）/ AppSearchBar（壳 ::after 聚焦层）。
  - **验证**：typecheck / build 全绿；残留探针 tools/cdp-border-residue-probe.py（基线 diff 法 + `--window` 非 headless GPU 路径）。
  - 文档：踩坑 036 四段式 + 速查表 §7 补口径（状态描边一律 opacity 过渡，禁颜色过渡）。
