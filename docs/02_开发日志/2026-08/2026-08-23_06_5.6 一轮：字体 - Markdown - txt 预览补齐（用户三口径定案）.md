# 5.6 一轮：字体 / Markdown / txt 预览补齐（用户三口径定案）


- **口径（用户逐项定）**：① 字体预览 = Eagle 四页签先「预览 + 其它」两页（大小 / 字形后置 09 待办）；② **安装 / 卸载字体本轮做，且必须系统级**——用户痛点："Eagle 装的字体其他软件老是识别不到，每次导出来自己装一遍"（Eagle 仅注册进自有体系）；③ txt = APP 内编辑 + **防抖 1s 自动保存**；md 本轮只读渲染（编辑归 6.2 提示词编辑）。
- **字体后端**：`services/font.rs`（ttf-parser 元数据：名称 = PostScript 名 / 全名 / 系列 / 样式 / 版本 / 字数 num_glyphs，en-US 优先；fontdue 样张渲染——cmap 含中文 '永' → 四行「永和九年 / 歲在癸丑 / AaBbCcDd / 01234567」，否则三行拉丁，Eagle 同款口径；640×480 透明底、常态色 7 折 alpha）+ thumb_formats/font.rs 适配器注册（probe 记样张尺寸入 width/height，音频波形同手法）。**安装 = 用户级系统安装**：复制 → `%LOCALAPPDATA%\Microsoft\Windows\Fonts`（撞名且字节不同加 -anikit 后缀）→ HKCU 注册表 Fonts 项写 "{全名} (TrueType)"（ttc 逐 face）→ AddFontResourceW → WM_FONTCHANGE 广播——**其他软件立即可见，免管理员**；卸载反向（占用文件保留并提示）；只认 HKCU 口径，HKLM 系统级不动。命令 3 个（get_font_info / install_font / uninstall_font；锁内定位锁外系统 IO）。
- **文本后端**：`services/text.rs`（读 = UTF-8 BOM 剥离优先、GBK 回退——Windows 中文 txt 常态 ANSI；写 = 恒 UTF-8 无 BOM；2MB 上限）+ 命令 2 个（read_text_asset / write_text_asset——origin 文本新写点，保存同步 metadata.size / modifiedAt 落盘 + 索引；**编辑不进 undo**）。
- **前端**：preview kind 加 `font` / `text`（formatBadge isFontExt / isTextExt 分流）；**PreviewFont.vue**（页签 AppSegmented：预览 = 演示文本《荷塘月色》英译选段 + 兰亭集序一段（FontFace API 加载 origin，webview 原生排版，family 按 assetId 命名防冲突，切素材 fonts.delete 清理）+ 底部字号滑杆 SideSlider；其它 = 斑马纹元数据 7 行（含系统状态）+ AppButton 安装/卸载）；**PreviewText.vue**（md = markdown-it 只读渲染——html:false、图片引用渲染占位文本 / 链接 pointer-events none 两笔 09 待办；txt = textarea 编辑防抖 1s 自动保存 + 右下保存状态字，**保存绑定加载时 assetId** 防切素材旧草稿错存新资产，切走 / 卸载前 flush 在途编辑，placements size / modifiedAt 同刷）；标题栏 font/text 加默认应用打开。
- **依赖**：后端 fontdue 0.9 + ttf-parser 0.25 + encoding_rs 0.8 + windows Win32_System_Registry feature；前端 markdown-it（PRD 04-04 条 6 既定选型）。
- **踩坑两枚**：① PreviewText `let timer` 声明在 immediate watch 之后 → TDZ ReferenceError（load 同步链访问），声明前移；② cargo 测试 `modified_at` 秒级精度同秒撞车——assert_ne 改不倒退断言。windows crate 0.62 注册表 API 实证：无 RegGetValueExW（用 RegOpenKeyExW + RegQueryValueExW）、HWND 在 Foundation 且构造收裸指针。
- **验证**：cargo test **377** 绿（+12：font 服务 4 / text 服务 4 / 命令层 4）/ typecheck / build 全绿；新探针 `tools/cdp-font-text-probe.py` **全项 PASS**（字体页签 / 演示文本结构 / 元数据 7 行 / 安装按钮流转 install_font 桩断言 / md 渲染结构 + 链接不可点 / txt 防抖保存桩断言）+ 截图 4 张目验。
- **同步**：PRD 04-04 条 2 字体 / 条 6 文本实现定案 / 07 接口（字体与文本 4 命令组）/ 09 待办四笔（大小·字形页 / woff / md 链接 / md 图片引用）。
- **待用户实机走查**：字体卡片缩略图样张观感（中 / 拉丁两家族）、预览页滑杆与演示文本排版、安装 / 卸载后 Animate 等软件可见性（核心诉求）、txt 编辑保存手感、md 渲染排版。
