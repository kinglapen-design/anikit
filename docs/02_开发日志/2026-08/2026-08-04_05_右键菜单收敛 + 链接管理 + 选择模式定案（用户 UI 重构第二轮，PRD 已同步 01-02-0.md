# 右键菜单收敛 + 链接管理 + 选择模式定案（用户 UI 重构第二轮，PRD 已同步 01/02/03、05 待办补 ⑧⑨⑩）

**右键菜单收敛 + 链接管理 + 选择模式定案（用户 UI 重构第二轮，PRD 已同步 01/02/03、05 待办补 ⑧⑨⑩）**：
	- **菜单合并（25 项 → 常驻约 15）**：默认应用打开+在其他应用打开 →「打开方式 >」；分析文件向量 → 并入「AI 工具集 >」；三个粘贴 →「粘贴 >」二级（快捷键不动）；添加至其他资源库+导出文件 →「导出 >」；叠加条件显隐（粘贴族随剪贴板 / 链接位置仅链接显示 / 删除按 Placement 分流 / 发送至 Animate 随插件）。
	- **链接管理面板（Ctrl+J，文件→位置视角）**：勾选 = 位置存在状态，**允许反选原始 Placement**——origin 自动转给剩余顺序最前一条（PRD 01 边界规则 8，闭合"原始滞留未分类"的清理通道）；反选到一条不剩 = 丢回收站需提示。
	- **位置→文件方向**：主路径 = 复制粘贴 / 拖拽（粘贴三键已覆盖），散源收集 = 资产选择器第四用途（前三个：关系/音色/头像）。
	- **资产选择器 = 主窗口选择模式**（弹窗方案否决——mockup 证明弹窗只是重造阉割版主界面）：四重模式标识（整圈品牌色边框 / 目的横幅带 Esc / 右侧备选区 / 已选卡片压暗大勾）+ 单击入备选、双击预览保持、编辑类禁用、树仅导航；单选（选新换旧）/ 多选（行=输入框改显示名，批量查找替换确认后走批量重命名）；确认带数量。
	- **文件与档案数据同步**：文件也有属性/描述——属性 = 打词代替标签（分词搜索命中，metadata 复用 tags 字段免迁移），描述 = {title, content} 数组；档案数据存库级 archives.json；关系/音色空间级 relations.json。
