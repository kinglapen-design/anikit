## 十八轮十一轮 · 主窗口边框三轮定稿（用户实机复验：二轮方案仍双层 + 圆角处断线）

- 二轮方案（COLOR_NONE 抑制 + 前端直角线自绘）实机两败：①直角 1px 线四角三角区被 DWM 角弧（内陷 ≈2.3px > 线宽）整段吞掉 → 描边断开；②DWM 线与 CSS inset 0 线系统性 ~0.5px 错位，双层依旧（选择模式同）。**几何结论：沿窗口圆角的线只能由 DWM 画（或按同 radius 路径画）——裁切交 DWM、画线也交 DWM。**
- 三轮定稿（用户定：边框色 = 通用/六级实心 #333）：**云母边框 DWM 染画**（lib.rs #333333）+ 前端 ::before 云母不画（实色模式照旧自绘 --n-g6）；**选择模式 IPC 联动**——新命令 `set_main_border_picking`（commands/settings.rs），picker store enter/exit 切染 DWM 品牌色 #3DDDD2 ↔ 常态 #333，前端 ::after 1.5px 品牌框 radius 8 同色重叠单层（同色容错）；::after 圆角回 8（直角必断）。.window.fx-mica radius 0 保持（圆角 DWM 独裁不变）。
- 探针 cdp-window-shell-probe.py：W2 组三改（mica 前端不画 / picking 品牌框 radius 8 沿路径）+ W7c 色档改 rgb(51,51,51)，全 18 项 PASS；vue-tsc / cargo check 绿。
- 踩坑 063 改写三轮全录；速查表 §19 .window 壳口径三改。DWM 染色/切色实机观感留用户复验（headless 截不到 DWM 层）。
