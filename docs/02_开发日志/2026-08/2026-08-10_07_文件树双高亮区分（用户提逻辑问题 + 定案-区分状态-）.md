# 文件树双高亮区分（2026-08-10 用户提逻辑问题 + 定案"区分状态"）

**文件树双高亮区分（2026-08-10 用户提逻辑问题 + 定案"区分状态"）**：问题 = 文件夹卡片选中经共享文件夹选择域联动树 item，树上"当前目录"与"被联动选中项"同一样式（`FolderTree` 原把 `sidebarSelected` 与 `isFolderSelected` 绑进同一 `selected`），用户分不清停留在哪个目录。"不联动"被否（卡片 / 树共享选择域是多选与拖拽排序基础，拆不干净）。定案：**TreeItem 新增 `domainSelected` 变体**——选择域成员（卡片联动 / 树多选）= 1.5px `--brand-border` 描边不叠罩层（与文件夹卡片选中边框同色呼应）；`selected` 实心高亮只表当前目录（sidebarSelected，"你在这里"）；FolderTree 绑定拆分且互斥、当前目录优先。其他 TreeItem 使用处（FolderPicker / LibraryView 等）不受影响。tsc / build 全绿。
