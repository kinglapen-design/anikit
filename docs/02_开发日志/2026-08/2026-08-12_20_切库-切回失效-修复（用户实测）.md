# 切库"切回失效"修复（2026-08-12 用户实测）

**切库"切回失效"修复（2026-08-12 用户实测）**：根因 = 菜单 entries 是打开时静态快照——切库项 action 按开菜单时 currentName 生成（当前库 undefined），keepOpen 期间切到另一库后原库的 action 仍是 undefined 永远点不动。修 = 库条目点击改 ContextMenu 动态判定（当前库跳过，其余按名 switchLibrary），spec 不再配 action；勾选此前已动态绑定不受影响。CDP 探针实证三轮互切全生效（断言改用桩内真实状态，此前 GBK 乱码致同名长度库名误判通过——教训：断言不用控制台乱码文本）。**盘符"资料"正解**：subst 映射盘显示名继承目标卷卷标（用户 E 盘卷标 = "资料"），非目标目录名、非失效映射；免管理员无法按映射改名（DriveIcons 需写 HKLM），inbox 目录正名"自动导入"保留（空间根目录名与挂载目标语义一致，应用内托盘显示"收件箱盘符（A:）"）。
