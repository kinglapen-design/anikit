# 6.2 二轮：选择模式四修订（用户走查一轮后定案）

# 2026-08-24


**背景**：6.2 一轮（昨日，选择模式框架 + 关系闭环）落地后用户走查，提四修订：① 详情关系 item 点文件要能跳转（"光显示在那是没用的"）；② 发起文件自身在选择模式下要视觉排除（剪切档半透明禁选）；③ 模式权限收窄成白名单（"其他和选文件无关的都不让干"，筛选将来接入进白名单）；④ 关系选择逻辑改多选累积（"选一个文件是切换了文件而不是新增了一条关系——我想同时添加父亲、儿子、母亲、专武"）。

**口径（两问定案）**：换绑整个废除（用户原话"没有啥换绑的，要换就重新再添加，你已经给了改关系名的入口就够了"）；返回设施 = 面包屑后退（既有，openView 入历史即零成本）；多选样式 = "整组竖排，把整个 item 复制就行了"；跨库挑选 = **禁切库，以后再说**（选择模式下汉堡整体禁用）。

**后端**：`add_relation` → **`add_relations` 批量**（`NewRelationInput{ toKind, toId, label, reverseLabel? }` 数组，任一校验失败全不写 = 批量原子；撤销标签 1 条"添加关系" / 多条"添加 N 条关系"）；`update_relation` 收窄只改称谓（newTo/newFrom 换绑参数随换绑废除删除）；服务 `update` 同步收窄（不再需 lib 参）。测试 5 用例改写全绿（批量往返 / 批量原子校验 / 称谓编辑）。

**前端**：
- `picker.ts`：picked 改 `PickedRelation[]`（每组 = target + 双框称谓）；togglePick 多选累积（点新追加 / 点已选移除）；purpose / retargetSide / editingRelationId 随换绑废除删除；confirm 走 add_relations 批量 + toast 计数；canConfirm = 每组左框称谓非空。
- `PickerPanel`：关系模板**整组竖排复制**（选中文件 item + 双称谓框 + 发起文件 item 同显 + 红删删整组）；空态 = 占位组（双框 disabled）；确认带数量「确认 (N)」。
- `SectionRelations`：点文件卡改**跳转定位**（asset → origin Placement 所在文件夹视口 + 选中卡片 / archive → 档案视口 + 选中档案卡；nextTick 入域让过 sidebarSelected watch；跨库目标 toast"在另一个资源库"、回收站目标提示不可达）；retarget 删除。
- 自身禁选视觉：AssetCard / ArchiveCard 加 `picker-self` 态（opacity --opacity-cut 0.5 + cursor not-allowed）。
- **白名单收窄新增**：汉堡禁（按钮 disabled + toggleHamburger 守卫，含切库）；ArchiveSidePanel 选择模式下不渲染（档案数据编辑入口隔离）；InboxDiskSection 条目选中 / 菜单禁；SequencePackView 帧选择 / 帧菜单仅留打开预览 / 空白重排 / Delete 帧禁。此前已有：三 spec 精简、拖拽双守卫、树仅导航、编辑快捷键全禁、新增 / Ctrl+N / 区块管理禁、回收站不可选。

**探针**：`cdp-relation-picker-probe.py` 重写适配——S2 多选累积 / 自身 picker-self（opacity 0.5 + not-allowed computed 断言）、S3 add_relations 批量全参数 + 2 item、S4 称谓修改参数收窄、S5 跳转档案视口出详情、S6 双向显示 + 跳回文件、S7 删除 2→1、S8 Esc 零写入、S9 右键精简 + 汉堡 / 新增钮 disabled；**全项 PASS** + 截图 2 张（picker-mode-multi / relation-jump）目验贴稿。坑：探针选择器两处——IconButton 的 title 是 v-tip 指令不落 DOM title 属性（按结构位置取钮）；占位组占位文字与发起文件同 `.name` 类（过滤 :not(.placeholder)）。

**验证**：cargo test 397 全绿（5 用例改写）/ typecheck / build 绿。

**同步**：PRD 03（04 节二轮修订五点 + 02 关系条跳转口径）/ 07 接口（add_relations 批量签名 / update 收窄 / 选择模式机制条白名单全清单）/ 速查表 §12.1（二轮修订节）/ 09 待办（跨库挑选 / 筛选进白名单 / 预览内编辑未滤）/ 05 进度。
