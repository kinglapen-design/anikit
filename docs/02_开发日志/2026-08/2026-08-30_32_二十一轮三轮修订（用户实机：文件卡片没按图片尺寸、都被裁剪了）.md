## 二十一轮三轮修订（用户实机：文件卡片没按图片尺寸、都被裁剪了）

- **根因**：7.1 满铺卡（FileCard 图满铺整卡 + 渐变罩名称/简介叠图内）落地后，布局层仍按旧"图 + 下文字区"排版给每张卡追加简介区高度（CARD_CAPTION_H 57 / 紧凑 36）——盒高比图高恒多一截 → 盒比例 ≠ 图比例，cover 满铺必然裁切（超宽图裁左右，行高越小裁越狠）。
- **修法（layouts.ts / useGridLayout.ts）**：四布局算法（justified / waterfall / grid / list）删除 captionHeight 参数，**盒高 = 纯图高**（justified 盒宽 = (w/h)×行高，盒比例恒 = 图比例 → cover 数学零裁）；CARD_CAPTION_H / CARD_CAPTION_COMPACT_H 常量删除；useGridLayout 不再随「显示简介」开关重排（showBrief 只切 AssetCard info prop = 渐变罩内简介行显隐）。
- **口径变化（用户汇报同步）**：显示简介「关」= **仅隐简介行不缩卡**（2026-08-19"缩短卡片 57→36"旧口径随满铺废除——满铺卡缩卡必错位裁图，二者不可兼得）。
- **探针**：cdp-content-container-probe 复跑 ALL PASS（断言不涉卡高公式，零适配）；cdp-brief-probe 适配 7.1 新口径后全部通过——选择器换代（.meta→.kc-info / 工具栏钮 .ic-btn 组第 4 / 徽章断言删：桩 linkCount=1 本不显示且非本探针主题），S2a 断言换为修复核心回归「盒比例 = 图比例 16:9」（实证 334×188 = 1.7766）、S3a 换「卡高不变 188→188」；截图 brief-on/off 目验（开 = 名称+简介行，关 = 仅名称，卡尺寸不变）。
- vue-tsc 绿；文档同步：速查 §22 文件卡条（盒高 = 纯图高口径）、PRD 04-02 显示简介条文（关 = 仅隐简介行）、进度 00 二十一轮条目补三轮 + 8-19 旧条修订指针。
