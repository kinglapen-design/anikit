# 名称排序显示下拖拽排序失效修复（用户实机"显示排序成功但实际没有执行"）

**名称排序显示下拖拽排序失效修复（用户实机"显示排序成功但实际没有执行"）**。根因：`ui.treeSort` 非 custom 时 FolderTree 按名称 localeCompare 重排显示，拖拽落点 `dropFolderBeside` 只对**存储序** reorder——refresh 后名称排序盖回去，拖拽等于没执行。修法（dropFolderBeside 同级分支）：该层显示非 custom 时**物化可见顺序**——取目标层全部可见兄弟（DOM 序）剔除移动组、按落点插回，整层序列 `reorder_folders(seq, parentId, null)` 整体重写，并切回"自定义"（treeSortAnchor 置 null）；跨父/跨区块移动不受影响（移动结果在名称排序下照样可见）。CDP 探针实证（tools/cdp-tree-sort-drag-probe.py 全 PASS：排序菜单切换 / 物化序列 folderIds=["f3","f2","f1"] / refresh 后显示序保持 / custom 基线路径不破 + tree-sort-drag.png）；顺手修 cdp-drag-zombie-probe 的 list_folder_tree 旧桩（区块化 breaking 漏网）重跑全 PASS。PRD 02 §02 同步。**探针附注**：树"标题 A→Z"= localeCompare(zh) 拼音序（甲乙丙 拼音序为 丙<甲<乙），若预期是自然序/笔画序另开需求（探针桩命名一丙/二甲/三乙规避）。
