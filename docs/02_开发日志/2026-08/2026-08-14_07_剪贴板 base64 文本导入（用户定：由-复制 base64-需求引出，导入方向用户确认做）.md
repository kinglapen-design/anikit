# 剪贴板 base64 文本导入（用户定：由"复制 base64"需求引出，导入方向用户确认做）

**剪贴板 base64 文本导入（用户定：由"复制 base64"需求引出，导入方向用户确认做）**。`import_clipboard` 原只认剪贴板位图 + CF_HDROP 文件列表，base64 文本静默跳过。**落地第三分支**：位图 → 文件列表 → `get_text` base64——data URI（去 `data:...;base64,` 头）与裸 base64 都认、容忍空白换行、STANDARD 与 NO_PAD 双引擎；解码后 `sniff_ext` 按魔数定扩展名（psd 8BPS / psb 8BPB / png / jpg / gif / bmp / webp / wav / mp3 / ftyp→qt 品牌 mov 其余 mp4 / svg 文本头），**魔数不在表内一律不认**（普通文本可能是合法 base64 字符集，魔数兜底防误判入库）；单文件上限 512MB（超出提示先存成文件再导入）；落 cache/ 临时文件（`clipboard_png_name` 正名 `clipboard_temp_name` 带扩展名参数）走正常导入管线，导入后清理。有文本但不可导入报"剪贴板里没有可导入的内容"（原无内容报错不变）。新测试 5 用例（psd 魔数 / data URI + 换行 / 普通文本拒 / 未知魔数拒 / 魔数表覆盖 + 改名用例扩展名透传）。cargo test 293 全绿。PRD 05 §01 与 07 接口文档同步。
