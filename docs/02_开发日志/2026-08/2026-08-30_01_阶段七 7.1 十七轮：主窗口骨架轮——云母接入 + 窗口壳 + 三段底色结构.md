## 阶段七 7.1 十七轮：主窗口骨架轮——云母接入 + 窗口壳 + 三段底色结构

**范围（开工两问用户定案）**：① 轮次切分 = **骨架轮先行**——云母/背景模糊 + 窗口壳 + 三段底色结构；面板内部样式与三栏宽度（254/264）归后续面板轮。② 云母不可用（Win10 及更低）兜底 = **实色回退 #1F1F1F 无透明度、新增 token**（不做 Acrylic）。

**落地**：

1. **Token**：`Token.md` 1.2 通用节新增「实色-1：0、0、12」（= 半透明-1 去透明度）；tokens.css 加 `--n-g-a1-solid: hsl(0, 0%, 12%)`。
2. **云母接入**：tauri.conf `transparent: false→true`（删 backgroundColor，transparent 下无效）；新 `adapters/window_fx.rs`——注册表 `HKLM\...\CurrentVersion\CurrentBuildNumber` ≥ 22621（Win11 22H2）判 mica，`set_effects(Effect::Mica)`；读取失败 / 非 Windows / set_effects 失败恒 solid 安全回退；`apply_main` 存主模式 OnceLock，命令 `get_window_fx_mode` 挂 commands/settings.rs；预览子窗口（open_preview_window）builder 加 transparent + 同 apply。lib.rs 在 show() 前 apply_main（首帧即正确观感）。
3. **窗口壳（App.vue）**：`fxMode` ref 启动查询——**基态样式即 solid 实色**（防首帧半透明闪），返回 mica 单向切 `.fx-mica`；`.window` 底 = 基态 `--n-g-a1-solid` / fx-mica `--n-g-a1`；圆角迁 `--n-radius-8`；**1px 亮-半透明-1 描边自绘 `::before`**（z-54，picking 外框 55 之下，最大化隐藏）；DWM 边框染色（#2E332F）保留，实机叠粗则云母模式去染色（记验证点）。
4. **三段底色结构（稿核心视觉）**：左栏三壳块（bar-title / rail / side-content）与标签栏（--dv-tabs-and-actions-container）**透明透窗口底**；**内容容器 = g1 实底卡片 + 左上 16px 圆角 + 左缘 1px `--n-l-a2`**；右栏 = `--n-g1` + 左缘 1px `--n-g3` 通栏（panel-toolbar / side-content 原各自 border-left 收编容器统一）；标签栏下边框线废除（内容容器顶边即分界）。
5. **图标旧版回退层（第三问用户定）**：排查发现主窗口 legacy UI 引用旧版图标大面积缺失（menu / nav-history / window-close / help 等均在旧版归档未迁移），主窗口启动即渲染崩（十六轮已载「预期过渡态」）——骨架轮要验云母必先让主窗口能跑。`icons.ts` 加回退层：新库查无 → 落旧版同名 + console.warn 打标（一次/名）；面板轮逐件按稿接线、回退命中清零后整层删除退役（速查表 §19 明记：新写组件禁依赖回退层）。

**坑（探针两败实证）**：dockview-vue 的壳层比 dockview-core 深——主题类 `.anikit-dock-theme` 挂在 `.dv-shell`，其下还有 `dv-shell-middle-column` 和两层 split-view-container 才到 `.dv-grid-view.dv-dockview`；且 split-view-container 的**首子恒为 `.dv-sash-container`**（不是 view-container），`:first-child` 定位首个 group 恒不匹配。正解 = `.dv-grid-view > .dv-branch-node > .dv-split-view-container > .dv-sash-container + .dv-view-container`（紧邻兄弟定位，不依赖易碎序号）。

**验证**：vue-tsc 绿；cargo test **403**（+2：mode_for_build 边界 / detect_mode 有效值）；新探针 `tools/cdp-window-shell-probe.py` **全项 13 项 PASS**（fx 双态切换 / 描边 / 三段底色，两轮换桩各跑）+ `tools/style-preview/r17-window-shell.png` 目验（左栏透底浅一档、内容区/右栏 g1 深一档、左上 16px 圆角可见——headless 无真云母，层级结构贴稿）；search-probe 复跑全 PASS（回退层无回归，主窗口探针恢复可跑）。
