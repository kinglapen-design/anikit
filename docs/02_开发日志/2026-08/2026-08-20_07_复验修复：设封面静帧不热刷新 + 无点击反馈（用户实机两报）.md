# 复验修复：设封面静帧不热刷新 + 无点击反馈（用户实机两报）


用户实机：点「当前画面设为预览图」后磁盘缩略图已变（后端成功），但卡片静帧仍显示旧图，要重启软件才换；且点击无任何反馈。

- **根因**：asset 协议同 URL 启发式缓存——`thumbPath` 路径恒定（词干同名覆盖），置空再还原只能让 img 重新请求**同一 URL**，WebView2 拿缓存旧图（5.2 起即存在，序列帧同缺陷未暴露）。
- **修复（URL 版本戳）**：`SetThumbResult` 加 `modifiedAt` 返回（persist 已算好）；前端 setAsThumb / setVideoThumb 同步 `target.modifiedAt`；AssetCard / ListRowCard 的 thumbUrl 拼 `?v={modifiedAt}`——URL 变 → img 必然重新加载新 URL（query 不影响 asset 协议路径解析）。视图外资产（回收站等）兜底全量 refresh。
- **反馈**：成功 / 失败均 toast（「已设为预览图」/ 后端中文错误文案，失败带音）——set_thumb_frame 与 set_video_thumb（视频侧同缺陷）统一接入。
- **验证**：cargo test 346 绿（webp 抽帧分支补用例——原只覆盖 gif）；typecheck / build 绿；预览探针补断言全 PASS（toast 文本 / 设封面前后版本戳 `?v=` 空 → `?v=2026-08-20T18:30`）。
