# 3.4 二轮 · 粘贴定案落地（feat/new-ui，用户当日定案：废弹窗）

**3.4 二轮 · 粘贴定案落地（feat/new-ui，用户当日定案：废弹窗）**：粘贴收敛为**两键**——Ctrl+V 链接 / Ctrl+Shift+V 副本；「作为链接粘贴并重命名」（选择性粘贴清单弹窗）与 Ctrl+Alt+V 键位**废除**（用户：导入就是导入，命名导入后手动 F2 / 批量重命名，高频整理不弹窗）。
  - **静默化**：`pasteClipboard` copy 分支不再弹 LinkDialog（linkDraft 系 6.1 残留路径）改直接 `linkPlacements`；**Ctrl+拖拽落文件夹同改直接链接**（dragOperation linkDraft 分支废除）——PRD 02-13"静默执行 / 直接建链接"条文（2026-08-04 定）至此真落地。LinkDialog 本体保留给"添加至文件夹"显式入口（pickFolderForLink）。
  - **菜单清理**：addMenu / assetCard 删「作为链接粘贴并重命名」项、副本粘贴键位标正为 Ctrl+Shift+V；archiveCard 同删 + 档案「克隆」占位项删除（用户定：文件夹没有链接语义，档案的链接走文件同款链接管理、不是克隆——克隆只剩文件夹复制克隆，归 3.4 四轮）。
  - **快捷键补绑**：Ctrl+D = 创建副本（`duplicateSelected` 自 assetCard spec 提 placementOps 共用，菜单早已点亮键盘缺失）；Alt+V 不响应。
  - 验证：typecheck / build 全绿（纯前端轮，无后端改动）。PRD 02 §13 粘贴段重写为两键。
