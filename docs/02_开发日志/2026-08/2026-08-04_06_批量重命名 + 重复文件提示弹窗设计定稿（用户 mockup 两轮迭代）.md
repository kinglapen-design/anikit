# 批量重命名 + 重复文件提示弹窗设计定稿（用户 mockup 两轮迭代）

**批量重命名 + 重复文件提示弹窗设计定稿（用户 mockup 两轮迭代）**：
	- 批量重命名：toggle 开关否决（开/关语义不适合 A/B 切换）→ **分段选择器**（序号命名 | 替换命名），同一时刻只显示当前模式一行输入（用户确认双行同显仅为示意）；删"命名"按钮改**实时预览只读**（输入即刷新，逐行手改不做——规则引擎与手改混列必乱）；位宽自动按数量（<100 两位）；词干规则（扩展名不动）；逐条容错失败汇总不整体回滚。
	- 重复文件提示：三选项 radio 化（mockup 初版误用 checkbox）；⊖ 删除按钮改**导入/跳过开关**（用户定：跳过可反悔，删除按钮语义不可逆）；「同步到全部」开关默认开（优于"全部应用"按钮——持续状态可关后逐行精调）；取消 = 全部跳过；底部内嵌批量重命名同组件（改名不影响 hash 判定）。
	- **显示名放开（用户定，推翻 PRD 01 原规则 7"显示名唯一"）**：唯一名规则是贴 Windows 习惯的保守决策，库内显示名为纯数据、物理唯一性由 originName 单点承载——同文件夹允许同显示名，不拦截不强制追加序号；同资产链接去重与副本新 ID 分别覆盖"引用一份就够"与"实体多份"需求；自动生成默认名仍给序号（新建文件夹-2）仅作区分便利。
