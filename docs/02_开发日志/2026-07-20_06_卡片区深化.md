# 卡片区深化

**卡片区深化**：header 与卡片层分离（header grid 自然流不缩放、卡片层 translateY 实时头高 + scale，拉伸不再重叠拉远）；间距 32 构成（文件夹底 8 + 总容器 gap 16 + 素材顶 8，无硬编码 32）；文件夹卡片选中态 + 与素材互斥；缩放阈值 12%→4%（拖窗口为更多列非放大卡片）；行高 clamp 不回写滑块值（窗口收窄再拉出不再卡最小尺寸）；副文本规则（无子文件夹仅显 X 个文件）；搜索框五条（padding 4 / 左箭头朝上 / 搜索方式入口去 hover 底色 / 清除 C4-40→70 / 右箭头 16×16）+ 28×28 图标容器；右栏五条（置顶图标调换 / 星星警告色线条+填充 / 详情表值右对齐 / 删除改 clear 图标 C4-40→70 / 标签间距 8）。
