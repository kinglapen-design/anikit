# 2. 动画软件通信通道（WebSocket）


- 服务：`server/plugin_ws.rs`（8.1 落地），`ws://127.0.0.1:{动态端口}`，lib.rs setup 拉起；端口文件 = 全局配置目录 `AniKit/plugin-server.port`（每次启动覆写——spike 验证的发现机制：插件 node fs 读文件直连，无需固定端口）。帧格式 = JSON 文本帧（camelCase）。
- 协议（8.1；演进 = 同通道加 type）：
	- C→S `{ "type": "hello", "app": "animate", "version": "2024" }` → S→C `welcome`：`{ type, libReady, libRoot, cepOutDir, settings: { maxSecs, maxBytes, fps } }`——未开库 libReady=false（面板禁导出）；settings 默认档 10 秒 / 2M / fps 0=跟随文档（2026-09-06 重构删 maxEdge）
	- C→S `{ "type": "getTree" }` → S→C `{ "type": "tree", "data": FolderTreeView | null }`（面板目标文件夹选择器数据源）
	- C→S `{ "type": "saveSettings", "settings": { maxSecs, maxBytes, fps } }`（2026-09-06：CEP 面板设置可编辑回写）→ `CepExportSettings::validate()` 护栏 → config 单写点落盘 → 广播 `settings`（**含发件者**回显确认）；校验/解析失败回发件者 `{ "type": "settingsError", message }`（面板回滚输入框为当前生效值）。面板侧 localStorage（cepSettings）缓存最后生效值兜底——重开面板不回硬编码默认（PRD「插件本地缓存最后值兜底」口径兑现）
	- C→S `{ "type": "exported", "payload": { name, folderId | null, dynamic, flaPath, seqDir | null, pngPath | null, fps } }` → 接收入库（services/cep_export 三段式：prepare 短锁 / compose **锁外**（ffmpeg 秒级慢 IO 不冻结命令层）/ commit 锁内）→ S→C `importProgress{stage:"compose"}` → `importDone{ flaAssetId, webpAssetId, overLimit, webpBytes }` / `importError{ message }`
	- C→S `{ "type": "thumbOnly", "payload": { docPath, dynamic, seqDir | null, pngPath | null, fps } }`（**批次 2 仅缩略图**，2026-09-02：不导新 fla，当前文档画面补缩略图）→ 同三段式（thumb_prepare/compose/commit，compose 与 exported 共用 compose_webp 核心）→ `thumbDone`（serde tag mode：**`bound`**{ assetId, webpAssetId, name, overLimit, webpBytes } = 命中库内 fla 资产、WebP 入库 root + set_thumb_asset 绑定（已有绑定 = 换绑，旧 hidden 不动），emit cep-imported；**`beside`**{ outPath, webpBytes } = 未命中不入库、WebP 挪原 fla 旁边重名 -序号唯一化（用户自行导入））/ `thumbError{ message }`。**匹配 = 文档磁盘路径 ↔ 池内实体路径（assets/{ID}.info/{originName}）精确比对**（正斜杠 + 小写 + 去尾斜杠规范化；双口径 2026-09-02 用户定）
- 入库链路（cep_export）：产物校验（temp/cep-out 落点，库根）→ 动态 = **纯 Rust 全帧组包**（2026-09-01 复验三连修订：逐帧 webp 单帧编码 + 手写 RIFF 组包 VP8X/ANIM/ANMF，**全画布矩形 + flags bit1=1（do not blend，源像素含透明区直接替换画布）**——ffmpeg libwebp_anim 差分帧经 image-webp 画布合成出重影，而 bit1=0（alpha 混合）透明区不覆盖画布出移动残影，两坑合并根治；ALPH 伴随块按序保留（初版丢失致黑底）；并摘掉 sidecar 依赖。降级链 = 质量 80→60→40 → 抽帧隔帧取 delay×2 时长不变（**2026-09-06 去尺寸档**——maxEdge 废除，帧图不再按长边缩放），软上限 2M 压不进保留产出 overLimit=true；静态 = image crate 原尺寸直转 WebP。**合成性能（2026-09-02 用户实机报「8M 导出卡 10 秒」= 降级链逐档全量重编码 240 帧）**：逐帧编码 rayon 并行保序组包 + libwebp method 4→2（动画缩略图快档，体积降级链兜底）+ 大小判断改内存过了才写盘（旧版每档写盘覆盖 = temp 里文件早现≠完成）+ 首档超上限 >5 倍直奔抽帧档）→ build_asset 两资产（Source::Move 同盘剪切；webp 经动图探测自动 animated）→ placement 落目标文件夹（失效 id 回退 root）→ set_thumb_asset hidden 绑定 → operations::finish → 清场（seq 目录 / 静图 PNG）→ 前端 `cep-imported` 事件全量 refresh + 成功提示音（2026-09-02 用户定：导出时视口停留 Animate 窗口，听觉兜底；500ms 节流批量只响一声）。**播放代理**：thumb_asset_id 有效时 PlacementView 的 animated/frameCount/fps/duration/thumbFrame 全代理伴生资产 + `playAssetId`（播放源解析目标；前端卡片 AnimImgLayer 与预览 loadAnim 均 `playAssetId ?? assetId`——fla 卡片/预览直接播伴生动画）；**静态伴生预览**（2026-09-02 修：原落 kind=other 无 viewable 滚轮缩放失效）= playAssetId 存在且非 animated 时预览按图片加载伴生本体（kind=image 全功能）。**缩略图管线**：gif/webp 动图改走 anim 首帧解码（`decode_origin_image` 选路——image crate 对 VP8X 动画容器解码丢 alpha 落黑底）
	- **发送至 AN（8.3 提前落地，PRD 07-04；请求-回执 id 对模式落地）**：
		- S→C `{ "type": "paste", "reqId": n, "name": "素材名" }` —— 主方案：后端已把 fla 转成 Flash 11 Picture 写进系统剪贴板；面板 jsx `pasteClipboard()` = 当前文档 `clipPaste(true)` 原位粘贴 + 粘贴后选区非空校验（空 = 剪贴板数据无效的排障信号）
		- S→C `{ "type": "pasteFla", "reqId": n, "name", "flaPath": "平台路径" }` —— 兜底（转换失败自动回退）：jsx `pasteFlaFile()` = 打开-主时间轴第一帧全选复制-关闭-原位粘贴；**已打开护栏**（`fl.documents` 预判：已开文档用完不 closeDocument——会关掉用户开着的文档；旧 electron 版脚本实证坑）
		- C→S `{ "type": "pasteResult", "reqId": n, "ok": bool, "message": "中文原因" }` —— 回执；面板侧发送前查 readyState（失败无害：后端 20s 超时自动报错）；后端 `request_paste` = 首个在线客户端单播 + pending 表（reqId → 客户端 id+oneshot）+ 20s 超时 + 断连 drain
		- 载荷转换口径（services/send_stage）：fla（XFL zip）→ folders/media/symbols 等块**原样透传** + timelines 重写（第一个 DOMTimeline 每层收首个 DOMFrame——去 duration 等属性、首帧 index≠0 置空帧占位、多场景丢弃、elements 直接子元素注入 `selected="true"`，quick-xml 事件流保属性序）+ 其余 zip entry（LIBRARY/bin/PublishSettings 等）原字节原序复制（spike/clipboard-probe 实证剪贴板 XFL 包同构）；全层首帧无内容 → Err 触发兜底。剪贴板写入 = adapters/clipboard `write_flash_picture`（Win32 注册格式 "Flash 11 Picture" + GMEM_MOVEABLE 堆句柄移交，OpenClipboard 竞争重试 3×50ms；spike probe-write.py 同 API 路径）
	- 旧占位（请求/响应 id 对 + sendToStage/exportThumbnail/getState 动作集）——sendToStage 已由 8.3 paste 系列兑现（本条上行）；exportThumbnail / getState 随 8.2 / 8.3 修订。
