# 扫描重复文件（2.7 二轮，2026-08-13 落地，PRD 03_查找文件-03）：

**扫描重复文件（2.7 二轮，2026-08-13 落地，PRD 03_查找文件-03）：** 只读命令不走 undo；扫描口径 = 存量 metadata.hash 分组 ≥2 个不同资产成组、按资产去重（同一资产多 Placement 不重复列）、视图取 origin Placement（缺则第一条兜底，无 Placement 资产不作候选也不作锚点）；**范围 = 锚点过滤**（组内任一资产命中范围，整组返回）；合并执行前端复用 `delete_placements` "recycle" 一次调用（落选资产含全部 Placement 移回收站，undo 一步）
	- `scan_duplicates(scope: ScanScope) -> DupGroupView[]` —— `ScanScope = { kind: "all" } | { kind: "folder", folderId } | { kind: "assets", assetIds }`（folder 锚 = origin Placement 所在文件夹）；组内 importedAt 升序（**assets[0] = 导入最早 = 合并前确认默认保留者**，平手 assetId 字典序），组间可节约空间 (n-1)×size 降序；`DupGroupView = { hash, size, assets: [{ assetId, name, folderId, folderName（root → "未分类"）, w, h, ext, size, thumbPath, thumbKind, placements: [{ folderId, origin }] }] }`（placements = 该资产全部 Placement 含链接，供前端组装 PlacementRef）
