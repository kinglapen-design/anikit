# 预览（阶段 4.3 落地）：

**预览（阶段 4.3 落地）：**
	- `get_asset_file_path(assetId: string) -> { path: string | null, pending: boolean, animPreview: string | null }` —— 预览显示路径解析：webview 可直渲格式（png/jpg/jpeg/bmp/gif/webp/svg）返回源文件绝对路径；psd/psb 缓存命中返回全尺寸缓存路径，**未命中则提交预览解析队列并返回 `pending: true`**（前端先显缩略图，事件 `preview-full-ready { assetId, path }` 到达后替换高清）；其余格式 path=null + pending=false（前端用格式图标大图兜底）。**animPreview 字段（2.3 落地，2026-09-02 恢复）**：动图小动画播放缓存（info/{stem}_anim.webp 短边 320 animated webp，**纯 Rust 转码**——decode_frames 完整画布帧 → shrink_to_edge → encode_webp_anim 全帧组包 blend=0；ffmpeg sidecar 链 2026-09-02 八轮退役：libwebp 差分编码产物带残影，踩坑 068；**存量 ffmpeg 产物由 is_fresh 全帧组包结构判定自动翻新**）——命中给绝对路径（卡片播放优先于 path），未命中提交 anim_preview_queue 懒生成后给 null（前端回退 path 播原文件，生成完成经 `preview-anim-ready { assetId, path }` 事件热切换）；非动图恒 null。生成挂钩 = import_task 注册完成（动图判定）+ CEP 伴生 webp 入库两入口；队列单 worker 无代际作废、同资产去重、库切换清空；存量 anim.webp 文件新鲜度判定（mtime ≥ origin）直接复用
		- **帧流（services/frame_stream + adapters/decoder，阶段四·自研解码器，2026-08-20；5.3 曾全面接入视频，2026-08-22 晚实机否决退役，收窄纯动图；2026-09-02 卡片层回滚原生 `<img>`，帧流收窄预览专用）**：**预览窗口**动图播放源（~~动图卡 + 预览窗口~~——卡片层实机性能否决：N 卡 = N 个解码线程全尺寸循环重解 origin + RGBA 裸帧 WS + 前端主线程 putImageData，十几张 1080p 即 ~18% CPU；卡片 2026-09-02 回归原生 `<img>` 播放（Eagle 同机制；播放源 = info/{stem}_anim.webp 短边 320 小动画缓存，恢复 2.3，未生成回退 origin））——会话 = 解码线程（循环播 origin 源文件）+ 帧槽（恒持最新帧）；WS server（127.0.0.1 动态端口，lib.rs setup 初始化；init 时 timeBeginPeriod(1) 提升 Windows 定时粒度，踩坑 040 收口）按会话推流。**协议**：二进制帧 `[0][w u32le][h u32le][idx u32le][pts_ms f64le][seq u64le][rgba]`（29 字节头；**idx = 源帧索引** 0 起循环回绕——预览播放条帧号/进度用；pts_ms = 趟内累计 delay 毫秒，前端动图忽略；seq = 单调推送序号）；文本消息 = 控制：`flush`（seek 重推前发——WS 有序，flush 前到达的帧必为旧帧）/ `error`（会话线程死亡——解码错误等；前端降级静态封面，防静默冻结，2026-08-22 实机返修）。**通道语义**：帧走 watch（latest-only，卡顿时丢帧是正确语义）；控制走 broadcast（容量 256；**广播 Lag 时合成 flush 下发**——控制消息丢失会让前端 seek 等待态永久卡死，2026-08-22 实机冻结案；前端另有 1.5s 看门狗自清双保险）。**节奏 = 累计 deadline**（next_due += delay/rate，sleep 差值；落后不追赶防爆发）。出帧尺寸 = **显示短边**（真短边等比不足不放大 = thumbnail::shrink_to_edge 口径；clamp [16,4096]：卡片前端自 clamp 1024，预览按 视口短边×zoom×DPR 传——4K/150% 屏欠采样修复），会话级 AtomicU32 **热更新**（尺寸变化不重启解码、不回第一帧）。**路由**：gif → ffmpeg-next 库级解码（src-tauri/vendor/ffmpeg，BtbN lgpl dev 库 + patches/ffmpeg-next EXIF cfg 补丁，编译前置 tools/libclang，踩坑 038）；webp → services/anim（image-webp 纯 Rust——lgpl 构建无 libwebp decoder，踩坑 039）。会话上限 80（泄漏兜底；卡片回滚原生 `<img>` 后正常仅预览单实例）；库切换 stop_all。**播放控制（预览对接）**：暂停 = publish 后阻塞轮询（stop/恢复/seek 唤醒）；倍速 = delay/rate；**seek = 帧索引**（GIF/WEBP 无索引只能顺序解码：目标在当前之后 = 快进不推帧不睡眠纯解码，已过 = 中止本趟重开从头快进；暂停 + seek±1 = 逐帧步进）。**视频不走此通道**——`<video>` + convertFileSrc 直读（见 get_media_source 条）；自研解码器 VideoDecoder（adapters/decoder 持久会话：就地 seek / 相邻续解 / 拉取模型）保留为单帧抽取工具
		- `start_anim_stream(assetId: string, shortEdge: number) -> { session: number, port: number }` —— 开启动图会话（前端连接 `ws://127.0.0.1:{port}/{session}` 收帧，StreamSession 封装，lib/streamClient.ts）；shortEdge = 显示短边（预览 = 视口短边×zoom×DPR，后端 clamp）；非动图 / metadata 缺失 / origin 不存在 / 会话超上限返回中文错误（前端回退静态封面 / 原生 img，不报错打扰）
		- `stop_anim_stream(session: number)` —— 停止会话（幂等：已停止/不存在静默成功）；解码线程随停止标记退出，WS 连接断开（按 session id 操作；下三命令同）
		- `set_anim_stream_size(session: number, shortEdge: number)` —— 热更新出帧短边（幂等同 stop；卡片 ResizeObserver 防抖 150ms 调用 / 预览视口×zoom 变化调用，解码循环下一帧起按新尺寸出帧）
		- `set_anim_stream_playing(session: number, playing: boolean)` —— 播放 / 暂停（预览播放条/空格；暂停 = 推完当前帧阻塞，恢复无缝续播）
		- `set_anim_stream_rate(session: number, rate: number)` —— 倍速（预览 RateControl；非法值 ≤0/NaN/无穷 忽略）
		- `seek_anim_stream(session: number, frameIndex: number)` —— 动图定位到目标帧（预览播放条拖动 / 逐帧步进）
	- `list_sequence_frames(assetId: string) -> { fps: number | null, thumbFrame, frames: [{ name, fullPath, stripPath }] }` —— **序列帧帧清单**（预览窗口播放条），**立即返回（帧原图立即可播）**：扫 `{ID}.info/frames/` 按文件名排序（帧可缺号，不推导）；fps 缺省 24（前端按 1000/fps 预填帧时长）。**动图不走此命令（2026-08-20 解包废除）**——播放 / 帧条 / 设封面全部对 origin 运行时解码，调用报"是动图资源，无序列帧清单"。stripPath 为帧条小图路径——已缓存直接填，未缓存为 null 并提交预览解析队列后台生成，每 8 帧（或收尾）发事件 `preview-strips-ready { assetId, items: [{ name, stripPath }] }` 渐进填充（2026-07-25 用户定：播放不被帧加载卡住）
	- `prepare_anim_strips(assetId: string) -> { items: [{ name, stripPath }] }` —— **动图帧条**（2026-08-20 解包废除新增）：立即返回已缓存清单（`cache/frames/{assetId}/f-{索引5位}.webp`，name = `f:{索引0起}`），同时提交预览解析队列 AnimStrips 任务——origin 单趟流式解码逐帧缩 128 落盘（已缓存跳过幂等），批次经同一 `preview-strips-ready` 事件渐进推送（items 同构）。非动图报中文错误
	- **序列帧包操作（commands/sequence + services/operations/sequence，2026-08-21，5.2 包内视图）：**
		- `dissolve_sequence(assetId: string) -> number`（返回解散出的素材数）——**解散序列帧包导入**（素材卡片右键，前置 alert warning 弹窗明示）：每帧**移动**出库建档为独立素材（新 ID + 独立 info + 逐帧 sha256 + 缩略图，复用导入单文件管线），落点 = 原包 origin Placement 所在文件夹（无 origin 取首条 Placement、无 Placement 兜底未分类），段首前插保持帧序、显示名唯一化；全部帧建档成功后删除原包全部 Placement、物理删除原包 info（逐帧笔记随之删除）并清 `cache/frames` 与 `cache/seq-trash` 内该资产缓存。**危险操作不进 undo（不可撤销）**；任一帧失败整体回滚（已移帧移回 + 已建 info 清除），落盘失败命令层内存重载对齐
		- `delete_sequence_frames(assetId: string, frameNames: string[]) -> number`（返回实际删除数）——**删除帧（抽帧）**：帧移 `cache/seq-trash/{assetId}/` 暂存（会话级，开库清空名单已收录 = 会话结束真删），**可撤销**（磁盘移动对登记 DiskOp::Rename 双向——暂存区与 frames/ 互斥恒不撞名；metadata.json 与 notes.json 快照）；封面帧 / originName 指向帧被删 → 改指剩余首帧并重建缩略图；被删帧笔记 key 清除 + noteCount 冗余同步；frameCount / modifiedAt 更新；帧条小图缓存逐帧清。**至少保留 1 帧**（删空中文报错）；陈旧帧名跳过容错；0 删除不登记空事务
		- `renumber_sequence_frames(assetId: string) -> number`（返回实际改名数，0 = 已连续无操作）——**重排序号**：剩余帧按当前文件名顺序重排连续序号（`词干-001..N`，词干 = meta.name，位宽 = max(现位宽, N 位数) 只增不减）；**两段改名防撞**（先 `~anikit-renumber-` 临时名再目标名），**可撤销**（服务层按 apply_disk 逆序语义折算 undo/redo 两组磁盘序列，段内目标位恒腾空——0 起序号等 old_i < new_i 场景单向序列会撞名，测试钉死）；帧笔记 key 随旧 → 新映射迁移（replace_all 保原文本时间）；封面帧 / originName 跟随；帧条缓存整清
	- **预览解析队列（services/preview_queue，2026-07-25 用户定）**：单 worker 线程 + 代际号——**提交新任务即清空 pending 并代际 +1**（预览只服务当前停留素材，过期任务作废）；PSD 单文件解码不可中断（完成落盘无害，已切走不发事件），帧条（序列帧 FrameStrips / 动图 AnimStrips）逐帧查代际可中断；lib.rs setup 初始化（AppHandle 发事件，cfg(test) 空实现，见踩坑 014）
	- ~~动图解包（services/anim_unpack + unpack_queue）~~ **已废除（2026-08-20 用户定案）**：导入不再解包（info 不再产生 frames/ 与 frames.json），两模块与 `anim-unpacked` / `anim-unpack-failed` 事件随删；播放 = 帧流、设封面 / 笔记帧画面 = origin 抽帧、帧条 = origin 按需解码
	- `set_thumb_frame(assetId: string, frameName: string) -> { thumbPath, modifiedAt }` —— 当前帧设为预览图（2026-07-25 用户定：重新生成缩略图 + 记封面帧）：重跑缩略图管线（词干同名直接覆盖），更新 metadata 的 thumbFrame/thumbnail/modifiedAt 并同步内存索引；返回新缩略图绝对路径（前端即时换卡片图）+ **modifiedAt（前端同步进 PlacementView 作缩略图 URL 版本戳 `?v=`——asset 协议同 URL 启发式缓存致静帧不热刷新，2026-08-20 用户实机报；成功 / 失败前端 toast「已设为预览图」/错误文案）**。**frameName 分两路**：序列帧 = frames/ 内帧文件名；**动图 = `f:{帧索引0起}`**（如 f:41——origin 运行时解码抽帧经 cache/tmp 临时 png 走同管线，thumbFrame 同格式记录；2026-08-20 解包废除后无磁盘帧图；非法格式 / 越界索引 / 抽帧失败中文报错）
	- `set_video_thumb(assetId: string, atSecs: number) -> { thumbPath, modifiedAt }` —— 视频任意时间点设封面（5.2）：ffmpeg 截帧（快速 seek）→ PNG 落 cache/tmp 临时文件 → 同管线重生成缩略图 → thumbFrame 记 `t:{秒}`（如 "t:12.500"，与序列帧/动图帧名区分）→ 落盘 + 同步索引；非视频报"「名」不是视频资源"，截帧失败报"无法截取该时间点的画面，请换个时间点重试"。modifiedAt 与 toast / URL 版本戳口径同 set_thumb_frame（2026-08-20 同修复）；返回含 **thumbFrame**（`t:{秒:.3}`，前端同步进 PlacementView——自动播放范围起点即时跟随新封面帧，2026-08-23 用户实机"设封面后范围要重启才生效"修复；set_thumb_frame 同结构同字段）；两命令返回另含 **thumbWidth/thumbHeight**（5.4：前端局部同步 PlacementView，布局比例即时跟随新缩略图）
	- `open_with_default_app(assetId: string)` —— 系统默认程序打开源文件（Windows ShellExecuteW "open"，adapters/shell_open；非 Windows 暂不支持）
