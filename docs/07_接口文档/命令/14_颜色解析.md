# 颜色解析（6.1 三轮，2026-08-23 落地，PRD 04_文件预览 05-1）：

**颜色解析（6.1 三轮，2026-08-23 落地，PRD 04_文件预览 05-1）：** 服务层 `services/color.rs`——`extract` 从缩略图提主色（4-4-4 桶直方图 + 桶内均值，占比降序贪心选，RGB 距离² < 56² 同色合并，上限 10 个 #RRGGBB；**alpha < 16 透明像素不计**，用户定）；提取随缩略图管线（`ThumbOut.colors`，导入 / 序列帧打包 / 删帧重建 / 设封面帧 / 剪贴板·自定义缩略图五处生成点全接，重生成即刷新）；存 `metadata.colors`（serde default 不升 DATA_VERSION）；存量懒回填 `ensure_asset_colors`（不刷 modifiedAt 防排序键漂移、不进撤销——系统补数非用户写操作）；无独立命令，出口 = `get_asset_detail` 的 colors 字段（见"内容浏览"组）
