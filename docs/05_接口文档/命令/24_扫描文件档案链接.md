# 24_扫描文件档案链接

> 扫描文件/档案链接（2026-10-16 立项落地，待办 2026-08-13 兑现，PRD 03_查找文件-04）：全库单范围列出「有链接的资产」组，链接卡复选标记后批量删除（记录进回收站，undo 一步）。实现 = services/scan.rs `scan_links` + commands/scan.rs（与扫描重复文件同文件）；前端 lib/linkScanOps.ts + LinkScanDialog / LinkScanGroupRow（复用 DupScanCard 扩展）。

- `scan_links() -> LinkGroupView[]` —— 只读纯内存（folders.items 聚合，不扫磁盘、不重算任何值），不走 undo；有 ≥1 条链接 Placement（origin=false）的资产成组，回收站快照不参与。
  - `LinkGroupView { asset: DupAssetView, links: LinkPlacementView[] }`（camelCase）——asset = 首列原始文件卡数据，复用扫描重复文件 `DupAssetView` 全字段（见 [10_扫描重复文件](10_扫描重复文件.md)；origin Placement 决定显示名与所在文件夹，无活 origin——origin 在回收站——取第一条 Placement 兜底）。
  - `LinkPlacementView { folderId, folderName, name }`：folderName 对 root / 未知 id 回「未分类」（与扫描重复文件同口径）；name = 链接显示名。
  - 排序：组内链接按所在文件夹名 → 显示名；组间链接数降序（清理视角多链优先），平手按首列显示名再按 assetId（确定性输出）。
- 删除执行零新命令——前端复用 `delete_placements`（lastAction `"recycle"`，见 [08_选择态与基础操作](08_选择态与基础操作.md)）：选中链接组装 PlacementRef（`origin: false` + **携带 name 显示名**——同文件夹同资产重复链接按名精确到行，2026-10-11 选择域配套口径），一次调用进回收站，undo 一步整体撤销；资产本体与其余位置不动。
- 档案侧：档案多位置未立项（2026-10-11 占位摘除），扫描结果当前天然只含文件链接；菜单名「文件/档案链接」不动，档案链接随其多位置立项并入。
