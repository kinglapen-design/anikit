# 24_扫描文件档案链接

> 扫描文件/档案链接（2026-10-16 立项落地，待办 2026-08-13 兑现，PRD 03_查找文件-04；同日两段式改版）：全库单范围列出「有链接的资产」组，屏 1 选组 → 屏 2 每组 radio 选一个位置**保留当原始文件**，其余位置全部清除进回收站。实现 = services/scan.rs `scan_links` + services/operations/placement.rs `consolidate_asset_links`；前端 lib/linkScanOps.ts + LinkScanDialog（与 DupScanDialog 同构两段式）/ LinkScanGroupRow（复用 DupScanCard 扩展）。

- `scan_links() -> LinkGroupView[]` —— 只读纯内存（folders.items 聚合，不扫磁盘、不重算任何值），不走 undo；有 ≥1 条链接 Placement（origin=false）的资产成组，回收站快照不参与。
  - `LinkGroupView { asset: DupAssetView, origin: Option<LinkPlacementView>, links: LinkPlacementView[] }`（camelCase）——asset = 首列原始文件卡数据，复用扫描重复文件 `DupAssetView` 全字段（见 [10_扫描重复文件](10_扫描重复文件.md)；origin Placement 决定显示名与所在文件夹，无活 origin 取第一条 Placement 兜底）；origin = 活 origin 位置（屏 2 默认保留者，None = origin 在回收站）；`LinkPlacementView { folderId, folderName, name }`，folderName 对 root / 未知 id 回「未分类」。
  - 排序：组内链接按所在文件夹名 → 显示名；组间链接数降序（清理视角多链优先），平手按首列显示名再按 assetId（确定性输出）。
- `consolidate_asset_links(keepers: PlacementRef[]) -> usize` —— 屏 2 确认执行（进撤销，标签「归并 N 组链接」，记录 folders.json + recycle.json 两文件快照，整批一次 undo 步）：每个保留者位置**成为/保持唯一 origin**，该资产其余全部位置（链接 + 被替换的旧 origin）移入回收站——资产只剩保留者一个位置，物理不动。
  - 实现 = 既有原语编排：先 `delete_placements`（recycle 语义，PlacementRef **name 恒携带**按行精确——同文件夹重复链接不错伤）清余位，再 `set_placement_origin` 提升保留者（幂等——已是 origin 无操作；仅标记转移不动磁盘，originName 不随链接显示名改）。
  - 保留者定位先按传入 origin、落空换另一态再找（同 set_placement_origin 口径），陈旧跳过不计；返回清除的位置总数（0 = 不进撤销栈）。
- 档案侧：档案多位置未立项（2026-10-11 占位摘除），扫描结果当前天然只含文件链接；菜单名「文件/档案链接」不动，档案链接随其多位置立项并入。逐条增删链接归链接管理（`sync_asset_links`，见 [08_选择态与基础操作](08_选择态与基础操作.md)），本功能只做整组归并。
