# 系统（1.3 落地）：

**系统（1.3 落地）：**
	- `exit_app() -> ()` —— 退出应用（14 汉堡菜单"退出"点亮，2026-08-11 用户定：完全结束进程 = app.exit(0)，菜单快捷键标注 alt+F4）
	- `create_document(kind, targetFolder: string | null) -> PlacementView` —— 新建文档入库（3.1 二轮通用化，2026-08-15 用户定：放弃 shell 检测模式 detect_doc_apps 废除，固定七类恒显）：kind ∈ md / txt / fla / psd / ai / docx / xlsx——md/txt 空内容建档，二进制五类以 assets/templates/ 空白模板为内容（编译期内嵌 include_bytes!）；不走导入管线——info 目录 + 模板内容（唯一显示名"新建文档[_N].{ext}"，library::unique_name 同导入口径）+ metadata.json（size/hash = 模板内容实测）+ 前插 origin Placement + 格式图标保底（cache/thumbs/{ext}.webp）；撤销 = info 目录移入 cache/tmp 备份、重做 = 移回（DiskOp::Rename 成对）。AE 不建档（工程素材为链接路径、需打包工程，属工作空间而非资源库，2026-08-15 用户定）
	- `drag_assets(assetIds: string[]) -> { dropped: boolean, x: number, y: number, ctrl: boolean }` —— 跨窗口拖出（2026-11-04 快速松手竞态修复，PRD 05_导入与导出）：文件卡形成拖拽（移动超过 6px）即移交系统级拖放，不再等指针越界（Windows CF_HDROP，拖至任务栏图标走系统"打开方式"同链路）；锁内 real_origin_file 解析真实实体路径（序列帧 = frames/ 封面帧；不存在/失败跳过 + 去重，空集报错）；**同步命令主线程发起 DoDragDrop**（踩坑 004：OLE 拖拽放线程池无声失败）。返回真实落窗结果、窗口客户区物理坐标与 Ctrl 实态，前端换算 CSS 像素后决定执行应用内落点或结束拖出；本窗 enter / over 续接原落点引擎，曾出窗再返回取消且不回导。最近使用"跨窗口拖出"挂钩仍待 8.5（口径见"快速访问"组）
	- `ws_drag_paths(relPaths: string[]) -> { dropped: boolean, x: number, y: number, ctrl: boolean }` —— 工作空间拖出（PRD 02-13）：ws 文件卡片与库文件卡共用提前系统接管机制（原生层 CF_HDROP，Options::default = DragMode::Copy 宣告复制效果、源文件不动；落资源管理器 = 复制）；入参 = rel 清单，逐条 `validated_ws_rel` 校验转绝对路径（越界 / 不存在跳过 + 去重保序；**文件夹不拖出**——同库「文件夹不拖出」口径，拖出集只收文件），空集报错；与 drag_assets 共用私有 `start_files_drag` 主体，同步命令主线程 DoDragDrop（踩坑 004），返回值与窗内落点收口口径同上
	- `get_clipboard_seq() -> number` —— 系统剪贴板序号（2026-09-17 粘贴仲裁；09-17 落地时本文件漏登记，2026-10-01 补）：Win32 GetClipboardSequenceNumber——任何程序每次写剪贴板它都递增；前端记录「APP 内复制时刻」的值（库 selection.clipboardSeq / ws clipSeq，均「先写系统剪贴板后记序号」防竞态），Ctrl+V 时比对：序号未变 = 内部粘贴（库链接 / 移动；ws 磁盘复制 / 移动），变了 = 外部已覆盖 → 让位系统剪贴板导入（库 import_clipboard；ws ws_paste_system，见 `20_工作空间.md`）
	- `show_logs_in_explorer() -> ()` —— 日志目录在资源管理器中定位（2026-10-13 设置面板接生产：「关于 · 查看软件日志」与主菜单「帮助 ▸ 查看软件日志」同一动作）：目录 = app_log_dir（%LOCALAPPDATA%\com.anikit.dev\logs，tauri_plugin_log，超 5MB 轮转保留 2 份）；定位最新一份 .log（按修改时间选，文件名不硬编码），目录里没有 .log 则直接打开目录兜底；目录不存在 = 尚未产生日志（中文报错）。Shell 调用走线程池（COM 纪律，同 reveal_in_explorer）
