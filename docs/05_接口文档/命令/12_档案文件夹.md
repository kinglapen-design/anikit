# 档案文件夹（3.2 一轮，2026-08-15 落地，PRD 02_文件整理-03 / 03_数据链接-06）：

**档案文件夹（3.2 一轮，2026-08-15 落地，PRD 02_文件整理-03 / 03_数据链接-06）：** 档案 = folders.json `Folder.kind = "archive"` + 库级 archives.json 单一写点（save_archives；`ArchivesFile = { version, archives: ArchiveData[] }`，`ArchiveData = { folderId, badge?: Badge{ text, color }, avatar?: Avatar{ file, crop?: Crop{ x, y, scale } }, props: string[], descriptions: DescItem[]{ title, content }, links: string[], createdAt?: string }`——links/createdAt 2026-08-15 六轮补（档案详情对齐文件：链接输入框 + 基础信息创建日期；create/convert 当次建档写 RFC3339，幂等不覆盖）；**avatar 2026-08-23 改独立存（6.1 用户定），2026-09-08 再改定**：file = **cache/covers/** 内烘培封面文件名（选图不入库为资产；**覆盖式命名恒 {folderId}，一档案一文件不累积**——旧时间戳命名废除，旧封面改名暂存 cache/covers-trash/ 支撑 undo/redo（同 seq-trash 口径开库清空），开库自检迁移旧版库根 covers/ 并清理无引用文件；「从资源库中选择」随选择模式 cover 用途落地 = 单选直回，资产引用变体不做），badge/avatar/crop/createdAt 为空不写字段；新建 / 转换当次建档，其他编辑路径可懒建空记录，开库自检 fix_archives 剔除指向失效文件夹的记录）；写命令走撤销三步（锁序 library → undo，folders.json + archives.json 按需双 record_file）。2026-10-31 起 APP 与 MCP 共用 `commands/archive_ops.rs`；删除文件夹 / 档案当场清除对应 archives.json 记录，撤销同时恢复节点与档案数据。
	- `create_archive(parentId: string | null, name: string, afterFolderId: string | null, blockId?: string | null) -> Folder` —— 新建档案：复用 create_folder 全链路（命名校验 / 锚点插入 / 区块继承）后补 kind 标记；parentId = null/"root" 为顶层，afterFolderId / blockId 口径同 create_folder。撤销标签"新建档案"
	- `convert_to_archive(folderId: string, confirmed: boolean) -> "done" | "need_confirm"` —— 文件夹转换为档案（两段式）：已是档案幂等 "done"；有后代子文件夹且 confirmed = false → "need_confirm" 不动任何数据（询问段丢弃事务，不进撤销栈）；confirmed = true → **剔除层级**（后代子文件夹 BFS 按 order 逐层解散：各子文件夹 Placement 平移到该档案、order 追加在后整体重排连续，子文件夹节点删除，子级本身是档案的 archives 记录一并清除）后置 kind。撤销标签"转换为档案"
	- `convert_to_folder(folderId: string) -> void` —— 档案解散为普通文件夹：摘 kind 标记 + 清 archives.json 中该档案的记录（无记录 = 无操作；Placement 不动）。撤销标签"解散档案为文件夹"
	- `list_archives() -> ArchiveListItem[]` —— 全部档案数据（量小；前端 content store 启动装配 archives map）；`ArchiveListItem = ArchiveData 全字段 + { totalSize: number, coverPath: string | null, coverVer: string | null }`（totalSize = 档案容量（字节，2026-08-30 用户定案）：档案内 Placement 引用资产 size 去重合计，同 get_archive_data 口径；coverPath 6.1：封面图绝对路径 = **cache/covers/** 内烘培文件（2026-09-08 覆盖式挪 cache），无自定义封面 / 文件缺失 = null，前端回退子项首图 / 默认封面图；**coverVer（2026-09-08）= 封面文件 mtime 纳秒版本戳——覆盖式同路径重写后前端 ?v= 驱动 img 重载，undo 还原旧文件连 mtime 一并回（缓存命中恰为旧内容）**）
	- `get_archive_data(folderId: string) -> ArchiveDetailView` —— 单个档案详情（只读；2026-08-15 六轮扩展）：`ArchiveDetailView = ArchiveData 全字段 + { fileCount: number（档案内 Placement 数，链接逐条计）, totalSize: number（资产去重 size 合计 = 占用空间）, coverPath: string | null（6.1）, coverVer: string | null（2026-09-08，同 list_archives） }`；无记录返回默认空记录 + 计数（档案刚转换、尚未配置数据）
	- `get_asset_detail(assetId: string) -> AssetDetail` —— 资产详情（资产不存在报中文错）：`AssetDetail = { assetId, originName, ext, size, width?, height?, duration?, importedAt, modifiedAt, tags, descriptions, colors, links, note, placements: PlacementLink[], archives: ArchiveRef[], thumbAsset: ThumbLinkItem | null, thumbUsedBy: ThumbLinkItem[] }`（tags = 属性词，复用原 tags 字段；descriptions = 描述标题+内容数组，6.1 补输出；colors = 主色 #RRGGBB 数组按占比降序，6.1 颜色解析——**返回前对存量资产懒回填**：colors 空且有缩略图时解码缩略图提取落盘（取色源含伴生缩略图代理：fla 等工程资产取 thumb_asset_id 指向的 hidden 伴生 WebP 的缩略图，2026-09-23 用户定），不刷 modifiedAt、不进撤销，读命令维护性写副作用先例；**thumbAsset / thumbUsedBy = 缩略图区块**（8.1 伴生缩略图，2026-09-23 接业务）：调用侧 = 本资产 thumb_asset_id 指向的 hidden 伴生资产（`ThumbLinkItem = { assetId, name（首条 Placement 显示名，无则 originName）, users }`，users = 它被引用的总数），目标非 hidden（还原途中）= null；被调用侧 = 本资产是 hidden 缩略图时引用它的资产清单（按显示名排序，users 恒 null））；`PlacementLink = { folderId: string | null（未分类 root Placement = null）, blockName（未分类 / 无区块归属 = 默认区块「目录」）, path: string[]（最多三段：根目录 / 父级 / 所在目录，超出三段取首段 + 末两段；未分类 = ["未分类"]）, name, origin }`——链接区块反查；`ArchiveRef = { folderId, name }`——归属档案反查：Placement 所在 folder 父链上 kind = archive 者按首次出现序去重。**origin 外部编辑自愈触点（2026-10-08，哈希漂移治理第 2 层）**：懒回填同例读命令维护性写——返回前 stat 检测 origin size / mtime 漂移 → 回写 size / hash（>64MB 跳过重算记日志，真值交手动 refresh_thumbnail 托底）/ 宽高 + 非音视频重生成内容缩略图 + modifiedAt 刷新，广播 `asset-origin-healed { assetId, size, modifiedAt }`（前端同步全部 PlacementView，文本卡版本戳失效自动重拉）；序列帧 / 虚拟片段不适用，origin 缺失不算漂移不报错；命令本体随自愈改 async（文件 IO 走线程池，规范第 2 条）
