- `export_md_bundle(assetId: string, destDir: string) -> BundleReport` —— MD 打包导出（2026-10-08 S6，PRD 02-09——AE 收集打包的 MD 版）：扫描文档内 anikit 资产引用（`anikit://item/{id}` 与 `http(s)://127.0.0.1:{port}/item/{id}` 双形态，`services/md_bundle.rs` scan_refs；open/ 回链与 folder 引用不收集、原文保留）→ 图源同媒体服务 `/item/{id}` 口径（图片 = origin 原图 / 非图片 = webp 缩略图含 thumbAssetId 伴生代理）导出 `destDir/{资产名}-打包/assets/`（文件名 = origin 文件名 / {资产名}.webp，重名 _n；重复打包目录名 -2… 规避不覆盖既有产物）+ 引用 URL 改写相对路径写 md 副本；仅 md 资产（非 md 报「仅支持 md 文档打包」）；跳过项（资产不存在 / 无可用图片 / 复制失败）进 `skipped` 报告不阻断；**不改库数据不进撤销**（同 export_assets 口径）。回包 `BundleReport { outDir, images, docFile, skipped[] }`。菜单入口 = 素材卡「导出文件 ▸ 打包导出 MD…」（仅 md 出现）
- `ws_export_md_bundle(absPath: string, destDir?: string | null) -> BundleReport` —— 工作空间 MD 打包（2026-10-24 默认目录轮）：`absPath` 经 `validated_ws_path` 校验，仅 md；`destDir` 有值时校验其为已存在目录并作为落点，空串 / null / 缺省回退文档父目录。两种落点均经 `fresh_bundle_dir` 生成 `{文档名}-打包/`（重名 -2），后续引用收集与 `export_md_bundle` 共用 `export_bundle`。默认目录失效时提示「请在偏好设置中重新选择」，不静默回退。菜单 = WS 文件卡「打包导出 MD…」（仅 md 单选）；前端从 `ui.mdBundleExportDir` 取默认目录，原文档不动。
