# 库管理（2.1 空间化重写，2026-08-12；PRD 01_储存空间）：

**库管理（2.1 空间化重写，2026-08-12；PRD 01_储存空间）：**
	- `create_space(parent_path: string, name: string, auto_import: bool) -> SpaceInfo` —— 在父目录下创建储存空间（`<name>/` 内建 space.json + assets/ + workspace/ + inbox/）；已是合法空间视为打开（幂等）；非空非空间目录返回中文错误；打开时按空间 autoImport 启停收件箱（盘符 + 监听）
	- `open_space(path: string) -> SpaceInfo` —— 校验空间结构（space.json 可解析，assets/ 与 inbox/ 缺失自愈补建）后打开并记 config spaces 最近列表；非空间结构报"该文件夹不是 AniKit 储存空间"
	- `get_current_space() -> SpaceInfo | null` —— 当前打开的储存空间
	- `list_space_libraries() -> string[]` —— 当前空间内库名列表（扫空间根一级子目录中含 folders.json 者，排序；无当前空间返回空）
	- `create_library(name: string) -> LibraryInfo` —— 当前空间内创建资源库（库目录 = 5 数据文件 + backup/cache/vectors，素材实体统一入空间 assets/ 池；自动导入为空间级设置，建库不带）
	- `open_library(name: string) -> LibraryInfo` —— 当前空间内按名打开；校验 + 版本迁移检查（迁移前自动备份）+ 24h 定时备份；旧版库结构（库根自含 asstes/）报"旧版库结构，请新建资源库"不迁移。**开库自检无主 info（2026-09-02 资产污染修复）**：空壳（无 metadata.json）自动物理清理；孤儿（metadata 在但 folders ∪ 回收站无引用）不自动删，非空时 emit `library-orphan-infos`（create_library / open_library 统一经 activate 出口推送）
	- 事件 `library-orphan-infos` → `OrphanNotice[]`（`{ id, name, path }`，path = info 目录完整路径）——前端 OrphanInfosAlert 警告弹窗列清单（简单版只读；打开资源管理器 / 删除按钮待用户补稿）
	- `get_current_library() -> LibraryInfo | null` —— 当前打开的库；前端启动据此决定是否走向导
	- `list_recent_libraries() -> LibraryEntry[]` —— 全局配置 config.json 的资源库最近列表（最近在前）；启动自动重开（reopenLastSession）与打开空间后选库使用
	- `set_auto_import(enabled: bool) -> SpaceInfo` —— 自动导入开关（**空间级**，space.json 单写点；inbox 空间级共用，2026-08-12 用户定）：开 = 启动收件箱（盘符挂载 + 监听，目标 = 当前打开的库），关 = 停止收件箱（卸载盘符）；空间打开 / 切换时按该设置启停
	- `reorder_libraries(order: string[]) -> string[]` —— 库列表拖动排序持久化（08 稿抓手拖动，space.json `libraryOrder` 单写点）；order 与实扫库名集合不一致报中文错；list_space_libraries 返回即按此序（外来目录排尾字典序，create_library 自动入尾）
	- `delete_library(name: string, deleteOrphans: bool) -> string[]`（剩余库名列表）—— 删除资源库：删当前打开的库先清 state/undo 再删目录（库内数据不可恢复；确认弹窗在前端）；order 移除；删当前库后的切换由前端据返回列表驱动（切剩余第一个 / 无剩余回向导第二步）。**deleteOrphans（2026-08-12 孤儿清理定案）**：先算孤儿集再删库——孤儿 = 该库引用集（folders ∪ recycle）与其余各库引用集并集的差集，true 时这些 info 实体从 assets 池递归删除（共享素材保留；按 ID 删，不枚举 assets/）
	- `count_library_orphans(name: string) -> u64` —— 统计该库孤儿素材数（删库确认弹窗的复选框文案用）
	- `list_merge_candidates() -> MergeCandidate[]` —— 合并资源库弹窗列表（2026-09-26 功能轮）：当前空间内除当前打开库外的全部库（libraryOrder 序）+ 各库容量（引用资产集 folders ∪ recycle 的 metadata.size 求和；读取失败按 0 计不阻塞列表）
	- `merge_libraries(names: string[]) -> LibraryInfo` —— 合并资源库（2026-09-26 功能轮，PRD 01_储存空间 3.2）：勾选的其余库（可多选）并入当前打开库，源库目录删除。编排 = 校验（空选择 / 并入自己 / 源库不存在报中文错）→ 目标库强制备份（失败即取消）→ core::merge 纯数据并入（folders/recycle/recent/pins/archives 五文件，tags 不并）+ 档案封面跨库拷贝（撞名唯一化回写 avatar.file）→ 单写点落盘（失败 reload 对齐盘面后报错）→ 内存索引重建 → relations.json 端点改写（lib 名 + 档案 id 重映射）→ 删源目录 + libraryOrder 更新（删除失败容忍记日志，残留可再删）→ 清撤销栈。合并口径（id 撞车重映射 / 同名不去重 / origin 恒 ≤ 1 降级 / 精确去重 / 回收站同资产并条）见 core/merge.rs 模块头与 PRD；返回目标库最新 LibraryInfo
	- 路径纪律：ID → info 路径推导唯一出口 `core/paths.rs`（assets 池访问纪律，PRD 01_储存空间），业务侧禁止自行拼 assets 路径
	- **UI 设置与窗口几何持久化（2026-07-28 用户复验定："用户设置要持久化，包括窗口大小，位置"）**：落全局 config.json 的 settings 子树（core/config.rs 单一写点，应用级不随库）
		- `get_ui_settings() -> Record<string, unknown>` —— settings.ui 子树原样返回（从未保存 = 空对象，前端按默认值补齐并做类型对照校验）；前端启动时调用覆盖 ui store（多预览窗口各自独立 Pinia 各自加载，不做跨窗口同步）
		- `save_ui_settings(settings: Record<string, unknown>)` —— 前端 ui store 变更 $subscribe 防抖 500ms 整体写回（单点覆盖 settings.ui）
		- `save_window_state(state: { x, y, width, height, maximized })` —— 主窗口 resize/move 防抖 500ms 提交（预览子窗口不记录）；**最大化时后端只刷标志位、几何保留上次还原尺寸**（退出最大化不丢位置）；启动恢复在 Rust setup（tauri.conf `visible: false` 先隐后显防跳变；显示器拔除致坐标落空时只恢复尺寸不恢复位置；saved maximized 则先设尺寸再 maximize）
	- 类型：`LibraryInfo = { name, path, assetCount, folderCount }`；`LibraryEntry = { name, path, lastOpenedAt }`；`SpaceInfo = { name, path, autoImport }`；`MergeCandidate = { name, sizeBytes }`（2026-09-26）
