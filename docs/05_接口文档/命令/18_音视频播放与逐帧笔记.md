# 音视频播放与逐帧笔记（5.2；视频 5.3 终版回归 `<video>` 直读，本组 get_media_source 恢复全量路由）：

**音视频播放与逐帧笔记（5.2；视频 5.3 终版回归 `<video>` 直读，本组 get_media_source 恢复全量路由）：**
		- `get_media_source(assetId: string) -> { path: string, transcoded: boolean, fps: number | null }` —— **音视频播放源解析（5.2；5.3 曾收窄音频专用，2026-08-22 晚视频回归 `<video>` 直读后恢复全量）**：`get_media_source(assetId, forceTranscode?)` **直读优先 + 播放错误回退（2026-09-13 定案，废除 ffprobe 探测分流——探测白名单把本可直解的 HEVC 也送进软编码转码，踩坑 075）**：一律先直给源文件绝对路径（`transcoded: false`，零探测零等待；HEVC 等编码 WebView2 经 Windows Media Foundation 直解，与 Eagle 同机制——Eagle 能播的本机即无需转码；asset protocol Range 实测完好：1080p25 seek 5-40ms、scrub 全跟手，见踩坑 049）；前端 `<video>`/`<audio>` 播放 error 后带 `forceTranscode: true` 重调 → ffmpeg 转码兜底（`transcoded: true`）→ `cache/media/media-{assetId}.mp4|.wav`（libopenh264+aac / pcm_s16le；**跨会话保留**——原 cache/tmp 开库清空导致每会话首次播放都重转、CPU 长时间满载，用户实机定持久化）。前端四个播放点（HoverVideoLayer / HoverAudioLayer / previewMedia / TabLinks）均接 error 回退，每素材只回退一次。**转码幂等**：产物旁 .stamp 记源文件 "大小:mtime秒"，一致直接复用不重复转码，源变化重转；复用判定先于二进制检查。非音视频资源报"「名」不是音视频资源"；ffmpeg 缺失报"音视频组件缺失，无法播放该格式"；转码失败报"该格式暂时无法播放"。**fps 字段**（视频，无 fps 时 null）：存量视频 metadata 无 fps 首次播放补探测写回（先落盘 metadata.json 再同步内存索引，规范第 7 条；成功广播 `video-fps-healed { assetId, fps }`，content store 监听同步全部 Placement 的 fps）——播放条帧号 / 逐帧步进立即正确；探测失败静默跳过不阻塞播放。**锁外化（2026-09-13 视频多选 / 排序卡死根治，踩坑 074）**：探测 / 转码全程不占全局库锁（短锁快照 info_dir/origin/meta/root → spawn_blocking 锁外重活 → fps 自愈先落盘 metadata.json 再短锁同步内存索引并广播）；同资产并发调用经 per-asset tokio Mutex 串行化去重（后者 stamp 命中直接复用产物），前端 mediaOps.getMediaSource 另有 in-flight Map 共享同一趟解析
		- `get_waveform(assetId: string, width: number, height: number) -> { path: string }` —— 波形图按需重采样（2026-07-26 波形清晰度修复，对齐 Eagle）：前端按播放条 / 预览大图实际显示像素（CSS px × devicePixelRatio，防抖 250ms）请求，后端按该尺寸重渲 PCM 波形（渲染口径同 5.1 定稿：每像素 1 列 min/max 满色纵线 + 仅竖向 1px 柔化 + 上半左下半右声道分绘 + 静音细中线；**柱 alpha 恒 100%**——前端 CSS mask 调色取图 alpha，60% 会稀释品牌紫，2026-07-26 用户定；`waveform_image` 卡片缩略图 640×272 保持 60% alpha 签名不变），任意宽度 1px 级清晰。宽高钳制 32~7680 / 8~1080（防前端异常值）；产物缓存 `cache/waveforms/{assetId}_{宽}x{高}.webp`（**会话级，开库清空名单已收录**），已存在直给不重渲。非音频资源报"「名」不是音频资源"；ffmpeg 缺失报"音视频组件缺失，无法生成波形图"；提取失败报"波形提取失败，请检查音频文件"——前端失败回退 info 波形缩略图拉伸旧行为。前端播放条配色同步改版（2026-07-26 用户定，Eagle 蓝/灰对比的紫/灰版）：两层 div 以波形图作 CSS mask（alpha 通道，mask-size 100% 100%），底层 wave-pending 实色 = 未播放（font-icon-3 60% 与 C3 混合的实际色号，新增 token）、上层 brand-1 clip-path 裁到进度 = 已播放，播放头 1px brand-1 不变。锁外化（2026-09-13 同 get_media_source，踩坑 074）：重采样与产物落盘不占全局库锁
		- `get_audio_peaks(assetId: string) -> number[]` —— **音频卡片波形 peaks（2026-09-22 R6 卡片三变体接线 · audio 变体，稿 = 组件/卡片/文件卡片-音频 竖线波形数据通道）**：mono 混音 PCM（8kHz，-ac 1 不分声道——稿 prose「不用分析上下立体声差异」）均分 **恒定 128 桶**取 max-abs 联合归一（0..1；**根数不随时长**——稿 prose「5 秒与 3 分钟根数一致、美观第一位」；前端 WaveContent 按卡宽 ÷ 节距 8 max 池化重采样）。产物 `cache/peaks/{assetId}.json` **跨会话保留**（同 cache/media 口径——全量 PCM 解码与转码同级开销，开库清空会让每次启动首轮滚网格全量重解码；.stamp 记源 "大小:mtime秒" 防漂移，复用判定先于二进制检查），不在开库清空名单。短锁快照后解码走锁外线程池（规范第 2 条）。非音频报"「名」不是音频资源"；ffmpeg 缺失报"音视频组件缺失，无法生成波形"；解码失败报"波形提取失败，请检查音频文件"——前端 cardPeaksFor 失败回退空数组（空波形 = 纯色底）并缓存，modifiedAt 变化自然重试

	- **字体与文本（5.6，2026-08-23）：**
		- `get_font_info(assetId: string) -> { originPath, name, fullName, family, style, version, glyphCount, installed }` —— 字体预览数据源：name 表元数据（名称 = PostScript 名 / 全名 / 系列 / 样式 / 版本，英文 en-US 优先回退第一条；字数 = num_glyphs）+ origin 绝对路径（前端 FontFace API 加载预览字体，webview 原生排版，后端不重渲染）+ 系统安装状态（HKCU 注册表 Fonts 项查值名）。格式 = ttf / otf / ttc（woff 系后置）。非字体报"「名」不是字体资源"，解析失败报"字体文件解析失败"。解析 = ttf-parser（纯 Rust）；缩略图 = fontdue 样张渲染走 thumb_formats 适配器（cmap 含中文 '永' → 四行「永和九年 / 歲在癸丑 / AaBbCcDd / 01234567」，否则三行「ABCDEFG / abcdefg / 0123456」，Eagle 同款口径；样张 640×480 透明底、字色 = 常态色实色部 7 折 alpha）
		- `install_font(assetId: string) / uninstall_font(assetId: string) -> { installed }` —— **系统级安装 / 卸载（用户级，免管理员；2026-08-23 用户痛点定案：Eagle 装字体其他软件识别不到，AniKit 必须装到系统级）**：安装 = 复制 origin → `%LOCALAPPDATA%\Microsoft\Windows\Fonts`（撞名且字节不同加 -anikit 后缀避让）→ HKCU\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Fonts 写 "{全名} (TrueType)" = 绝对路径（ttc 逐 face 一项）→ AddFontResourceW 会话内立即可用 → 广播 WM_FONTCHANGE（其他软件立即可见）；注册表写失败回滚文件。卸载 = RemoveFontResourceW → 删注册表值 → 删文件（被占用时注册表已清、文件保留并中文提示）。只认本应用安装口径（HKCU），系统级（HKLM）字体不动。锁内定位取路径与全名清单、锁外系统 IO（不占库锁）；不改库数据
		- `read_text_asset(assetId: string) -> { content }` —— txt / md 全文读取：**编码 = UTF-8（BOM 剥离）优先、失败 GBK 回退**（Windows 中文用户 txt 常态 ANSI）；内容上限 2MB（超出报"文件超过 2MB，暂不支持预览编辑"）。非文本报"「名」不是文本资源"
		- `write_text_asset(assetId: string, content: string) -> { size, modifiedAt }` —— txt APP 内编辑保存（预览内防抖 1s 自动落盘，2026-08-23 用户定；**编辑不进 undo**）：覆写 origin（**恒 UTF-8 无 BOM**——GBK 源编辑保存后编码转换属预期口径）→ metadata.size / modifiedAt 落盘 → 同步内存索引（规范第 7 条）；返回字段前端同步全部 PlacementView（简介"文件大小"档 / 排序"修改时间"键即时正确）。内容超 2MB 拒绝；非文本同上报错
		- `read_docx_asset(assetId: string) -> { paragraphs: [{ heading, list, runs: [{ text, bold, italic }] }], truncated }` —— **docx 只读预览内容提取（2026-09-22 R6 新功能验证首例，PRD 04-04 条 6）**：zip 取 `word/document.xml`，quick-xml 流式解析段落结构——`heading` = 0 正文 / 1-6 标题级（pStyle = Heading1-9 / 中文 Word 纯数字样式 id / Title 按 1 级，clamp 1-6）；`list` = 列表项标记（w:numPr，统一一级，前端加项目符号）；run 级粗 / 斜标记（w:b / w:i，`w:val="false"/"0"/"off"/"none"` 关闭态识别）；w:br → `\n`、w:tab → `\t`；表格内容按段落平铺（无框线），图片 / 分栏 / 页眉页脚不还原（非版式级渲染，「不内置文档渲染器」口径不变）。空段落（无 run）保留 = 空行。上限：document.xml 解压后 32MB（按实读字节截流防解压炸弹，超出报"文档过大，暂不支持预览"）、文本总量 2MB（对齐文本口径）截断置 `truncated: true`。只读无写命令（编辑走默认应用打开）。非 docx 报"「名」不是 docx 资源"；损坏 zip 报"docx 解包失败"；缺 document.xml 报"非标准 Word 文档"。doc（OLE2 二进制）/ xlsx / pptx 后置另立
	- `get_notes(assetId: string) -> NoteEntry[]` / `set_note(assetId: string, key: string, text: string) -> NoteEntry[]` —— 逐帧笔记；两条命令统一返回全量列表（按 key 排序），前端直接替换。set_note 的 text 去空白后为空 = 删除该条，否则新增 / 覆盖（同 key 刷新 updatedAt）；key 校验非空、≤64 字符（中文报错）。`NoteEntry = { key, text, updatedAt }`。**key 语义：序列帧 = 帧名，动图 = `f:{帧索引0起}`（2026-08-20 解包废除后不再依赖帧文件名——get_notes 对动图资产附带旧帧名 key（`{标题}-00042.webp`）一次性迁移为 `f:{索引}`，冲突保留 updatedAt 较新者），视频 = `t:{秒}`**。**set_note 同步维护 metadata.noteCount 冗余**（5.2 展示层：卡片角标 / 详情区块免读 notes.json）：写完 notes.json 后按当前条数更新（0 记 null 不写字段），先落盘 metadata.json 再同步内存索引，条数未变不重复落盘；PlacementView 携带 `noteCount: number | null`，前端卡片角标据此显隐，预览 / 详情删改笔记后按 set_note 返回全量算条数调 content store `setNoteCount` 刷新
	- `get_note_thumb(assetId: string, key: string) -> { path: string | null }` —— 详情面板笔记悬停帧画面（5.2 展示层）：序列帧 key = 帧名，直给 `info/frames/{key}` 绝对路径（不存在返回 null）；**动图 key = `f:{索引}`，origin 解码抽帧** → 缩到短边 320 存 `cache/note-thumbs/{assetId}_f-{索引5位}.webp`（幂等，会话级缓存开库清空）；视频 key = `t:{秒}`，ffmpeg 截帧（快速 seek）→ 同规格存 `cache/note-thumbs/{assetId}_{安全化key}.webp`（安全化 = `:` 与 `.` 换 `_`）。抽帧 / 截帧失败或 key 与资产类型不符返回 null 不报错（前端 C4 占位，悬停预览是辅助展示不打扰）；key 拒路径穿越（空 / 含分隔符 / `..` 中文报错）
	- **notes.json 格式**（info 内单资源数据文件，单一写点 core::notes；备份对象，INFO_DATA_FILES 已收录）：`{ "version": 1, "notes": [{ "key": "标题-001.png" | "t:12.500", "text": "…", "updatedAt": "RFC3339" }] }`；key 语义约定：序列帧 / 动图 = 帧名（frames/ 内归一名），视频 = `t:{秒:.3}`（与 thumbFrame 的视频记法一致）；单条 text 上限 2000 字符超出截断；文件不存在 = 空列表不算错误
