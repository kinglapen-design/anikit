# 工作空间（2026-09-17 步骤 1 只读底座 + 步骤 2 基础整理 + 步骤 3 常用固定落地，插队提前自阶段十二；PRD `01_资源与数据/02_索引式工作空间`）

索引式工作空间（空间内唯一 `workspace/` 目录，磁盘实况语义）的浏览 + 基础整理接口。未开空间读接口一律返回空（null / []）不报错，写接口报「请先打开储存空间」；relPath 拒绝 `..` 与绝对路径组件，越界报中文错。

## 命令

- `workspace_root() -> { rootPath, exists } | null`：workspace/ 目录绝对路径（前端 `convertFileSrc` 直读其下文件）+ 目录是否存在。
- `list_workspace_dir(relPath) -> WsEntry[]`：relPath 空串 = 根。`WsEntry = { name, relPath, isDir, hasSubDir, size, mtimeMs, ctimeMs, w, h, ext, thumbPath, thumbKind }`——目录在前、同名不区分大小写排序；`.anikit` 隐藏不出现在结果里；`hasSubDir` = 目录是否含可见子目录（2026-09-26 侧栏树展开箭头真实化：列目录时顺带单次 read_dir 提前退出扫描，任一非 `.anikit` 子目录即 true，与列举同口径只滤缓存目录，读取失败 false；文件恒 false；废除前端「未加载乐观出箭头、展开后才消」）；`ctimeMs` = 文件创建时间 Unix 毫秒（2026-09-26 详情面板基础数据补，复用同一份 metadata 零额外开销；目录 / 平台不支持恒 0）；`w/h` = 布局比例来源（卡片按真实比例自适应）：图片 = 源像素宽高（魔数探测），非图片（视频/音频/字体等）内容缩略图缓存新鲜时 = 缩略图尺寸（与源同比例，仅读缓存文件头 `image::image_dimensions` 不全解码，2026-09-26 视频卡方盒裁切修复），均无 = null 回退方盒；`thumbPath` 仅缩略图缓存新鲜时给绝对路径，否则 null；`thumbKind` = `asset | formatIcon | null`（非可解码类型回退系统格式图标——exe 按文件缓存，其余按扩展名缓存，见「缓存口径」；**2026-09-26 起失败记忆命中的条目同落回 formatIcon**，见「缩略图生成管线」）。命令本体 async + spawn_blocking（2026-09-26 性能优化 B：大目录同步 IO 与 exe 图标 COM 提取不占 tokio worker）。
- `request_workspace_thumbs(absPaths, priority?) -> void`：立即返回，任务进**进程级缩略图 worker 池**（`services/ws_thumb_queue`，2026-09-26 性能优化：N = 可用并行度一半钳 1..=4 固定并发，取代每 invoke 裸 spawn 串行线程）；**跨请求去重**（键 = rel+mtime+size 缓存键茎，队列中/进行中跳过）+ **失败记忆**（解码失败键进程级记录，命中不再重试，mtime/size 变自然失效）；`priority=true` 整批插队队首（前端视口内缺失项），缺省 false 排尾部；完成批次 emit `workspace-thumbs-ready`。命令本体 async + spawn_blocking（逐条 stat / 新鲜度判定不占 tokio worker）。
- `get_media_source_by_path(absPath, forceTranscode?) -> MediaSource | null`：按真实路径取音视频播放源（形状与按 assetId 版一致：`{ path, transcoded, fps }`）；默认直读优先（踩坑 075 口径），前端播放 error 后带 `forceTranscode=true` 重调走转码兜底；转码产物落 `workspace/.anikit/media/`。图片 / 动图 / 文本不经此命令（前端直 `convertFileSrc` 源路径）。文件须在空间 workspace 内，否则 null。
- `reveal_path(absPath) -> void`：在文件管理器中打开并选中（explorer /select，含空格路径经 ShellExecuteW 原样传参）；约束在当前空间 workspace 内，越界 / 不存在报中文错。

## 打开外发与系统菜单（2026-09-29 库右键菜单移植轮）

下列命令与 `reveal_path` 共用同一校验（`validated_ws_path`：当前空间 workspace 内 + 存在，否则中文报错）。

- `open_path_with_default_app(absPath) -> void`：用系统默认程序打开（库「在默认应用打开」按路径版；ShellExecuteW "open"）。
- `open_path_with_dialog(absPath) -> void`：系统「打开方式」对话框（openas 动词；缺失时 rundll32 `OpenAs_RunDLL` 兜底——同库侧适配器既有口径）。
- `ws_file_base64(absPath) -> string`：复制 base64 按路径版，复用库侧 `services/asset_menu::base64_from_origin`——静态图（png/jpg/jpeg/bmp/webp/gif）读原字节 ≤10MB，psd/psb/svg 解码合成图 → 长边 ≤4096 PNG ≤10MB，其余格式 / 文件夹中文报错。
- `send_path_to_animate(absPath) -> string`：发送至 Animate 按路径版（仅 fla）；解析与校验后共享 `commands/cep.rs send_fla` 流程（剪贴板载荷转换 → 失败回退兜底 → WS 下发；发送锁在途拒绝），返回素材名。
- `ws_shell_menu(absPaths) -> void`：**Windows 原生右键菜单**（「系统菜单」项）——多路径整组一次弹出。实现 = `adapters/shell_menu.rs`：桌面 IShellFolder + 全 PIDL `GetUIObjectOf` 取 IContextMenu（跨目录多选同 Explorer 口径），`CreatePopupMenu` + `QueryContextMenu` 装配，`TrackPopupMenuEx`（`TPM_RETURNCMD`）在光标处模态弹出，选中项 `InvokeCommand`（`CMINVOKECOMMANDINFOEX` + `CMIC_MASK_UNICODE`）执行；7-Zip 等扩展的子菜单与自绘项靠自建消息窗把 `WM_INITMENUPOPUP / WM_DRAWITEM / WM_MEASUREITEM / WM_MENUSELECT / WM_MENUCHAR` 转发 IContextMenu2/3（`HandleMenuMsg(2)`）。模态循环在 spawn_blocking 线程的 STA 内自泵消息，主线程不冻结；命令返回 = 菜单已关且命令已执行，用户取消 = Ok。**边界**：只出经典 IContextMenu 扩展（压缩解压 / TortoiseGit 等）；Win11 新样式菜单的 IExplorerCommand 现代扩展不可托管，不在其中；动词自身行为（删除 / 重命名等）由 shell 扩展自理。

## 填充卡按路径命令（2026-09-26 三类填充卡对接）

ws 条目 `assetId` = `ws:${relPath}` 合成假 id，**严禁发 assetId 类命令**——卡片填充内容（文本正文 / 音频波形 / 字体信息）一律走下列按路径命令（前端以 `wsPath` 绝对路径调用，假 id 仅作前端缓存键）。统一口径：未开空间报「请先打开储存空间」；越界 / 不存在 / 非目标格式中文报错（前端卡片 catch 兜底空内容）；越界校验与 `get_media_source_by_path` 同为 `ws::is_under`。

- `read_text_by_path(absPath) -> { content }`：txt/md 全文（UTF-8 优先 GBK 回退，2MB 上限），形状同 `read_text_asset`。
- `read_docx_by_path(absPath) -> DocxContent`：docx 段落结构提取（只读），形状同 `read_docx_asset`。
- `get_audio_peaks_by_path(absPath) -> number[]`：音频卡片波形 peaks（恒定 128 根不随时长，同 `get_audio_peaks`）。**产物缓存换锚** `workspace/.anikit/peaks/{job_key}.json`——job_key 同缩略图缓存键（见「缓存口径」），文件名内嵌 mtime+size，按当前实况重算期望文件名存在即命中（无 .stamp 旁文件，与库侧 `cache/peaks/{assetId}.json+.stamp` 不同锚）；源变化重算并顺清同 relPath 旧缓存（purge_stale，同 ws 缩略图口径）。
- `get_font_info_by_path(absPath) -> FontInfo`：字体元数据 + 安装状态，形状同 `get_font_info`（`originPath` = ws 源文件绝对路径，前端 FontFace 经 `convertFileSrc` 加载）。**安装 / 卸载无按路径版**（系统级写入只认库资产），ws 卡片不出安装钮。

## 写操作（步骤 2，2026-09-17 同日落）

命令返回即磁盘生效；**前端命令返回后直接局部重扫 UI，本进程写操作的 watcher 事件按「已知操作」消重**（3s 窗口内登记路径之下的事件不上报；窗口外 / 混合事件照常推送，不用延时忽略）。写操作一律拒绝 `.anikit` 缓存目录内路径。

- `ws_create_folder(relDir, name) -> void`：relDir 下新建文件夹；重名 / 非法名（空、`.` `..`、`\ / : * ? " < > |`、控制字符、结尾点或空格）报中文错（新建须显式命名，不自动规避）。
- `ws_rename(relPath, newName) -> void`：relPath 最后一段改名（文件与文件夹同径）；目标重名报错；名字不变不动。
- `ws_delete(relPaths) -> void`：多路径一次删除到**系统回收站**（SHFileOperationW，FOF_ALLOWUNDO 语义；PRD 06 不进库内回收站）；失败（如被占用）整批中文错。
- `ws_move(relPaths, destRel) -> void`：移入 destRel（同卷 rename；目录禁移入自身子树）；重名自动 `名_n` 规避（n 从 2 递增，2026-09-23 序号格式统一定案），不覆盖。
- `ws_paste(relPaths, destRel, cut) -> void`：复制（cut=false，目录递归）或移动（cut=true）进 destRel；剪切成功后由前端清剪贴板。重名自动规避同 ws_move。
- `ws_duplicate(relPaths) -> void`：创建副本（2026-09-29 库「创建副本」Ctrl+D 移植）——逐项复制进**自身所在目录**（copy_entries 的固定同目录形态），重名自动 `名_n` 规避不覆盖；文件与文件夹混合整批受理，目录递归。

## 视图状态（步骤 3，2026-09-17 同日落）

视图状态 = `workspace/.anikit/workspace.json` 的 `{ pinned: string[] }`（字段后补，serde 缺省宽容读取）。**读取即校验**：resolve 越界 / 不存在 / 非目录的条目静默剔除，去重保序，有变化即回写（改名 / 移动 / 删除的失效 pin 由此自动清理，无需前端通知）。未开空间 / 目录缺失一律返回 `[]` 不报错。

- `ws_list_pinned() -> string[]`：当前固定清单（rel 路径，固定顺序）。
- `ws_pin(relPath) -> string[]`：固定目录（须为空间内已存在目录，resolve_under 校验、拒绝 `.anikit`；重复固定幂等）；返回最新清单。
- `ws_unpin(relPath) -> string[]`：取消固定；返回最新清单（残留失效条目由 list 顺带清理）。

树行右键由 `menuSpecs/workspace.ts wsTreeRowSpec` 出菜单（2026-09-29 移植轮起 = 文件夹卡片菜单同主体减「重命名」——ws 树无行内命名态；批量分流同 wsFolderSpec 口径：触发行在选择域内且多选 → 复制 / 剪切 / 删除 N 项作用于整批（文件与文件夹可混合）；未选中行右键先单选入域，FolderStrip ws 卡片同口径）。固定区块在 WorkspaceTree 顶部「常用 / N」区块（SectionTitle block 标题分割 + hover 折叠，2026-09-17_05 用户截图定——早期「无标题直接列表」口径已废），行 = 目录快捷入口（纯导航不入选择域，库快速访问行同口径；复用 wsTreeRowSpec 时分流天然不命中，退化为对 pin 目录自身的单项操作）。写操作局部重扫后前端重取清单对齐（`stores/ws.ts refreshAround` 末尾 `loadPinned`）。

## 事件

- `workspace-fs-changed`（负载 `()`）：workspace 递归监听（notify，参照收件箱 inbox_watch 同适配器）任何路径变化即推，**`.anikit` 组件内事件已后端过滤**（防缩略图 / 转码产物写回自激）+ **本进程已知写操作的回声已消重**（3s 窗口，见上）；前端 300ms 去抖后重扫已加载目录。
- `workspace-thumbs-ready`（负载 `[{ absPath, thumbPath, w, h, thumbKind }]`）：worker 池批量回吐——**凑满 16 条或队列完全排空时 emit 一帧**（2026-09-26 起；旧「每 invoke 一事件、无生成也 emit 空数组」口径废除，全部重复/已新鲜/已失败时不发事件）。`thumbKind` = `asset`（内容缩略图；`w/h` = 缩略图实际像素宽高，前端 patchThumbs 随 thumbPath 一并回填条目 w/h，非图片卡片由 300 方盒恢复真实比例）| `formatIcon`（**解码失败条目的系统格式图标落回**——thumbPath = 按扩展名缓存图标，w/h 为图标边长前端忽略；前端回填后 thumbPath 非 null 天然不再请求）。

## 缩略图生成管线（2026-09-26 性能优化）

生成走 `services/ws_thumb_queue` 进程级常驻 worker 池：固定并发 N = 可用并行度一半钳 1..=4（解码/重采样/编码 CPU 密集，留一半核给 UI；音视频 ffmpeg 子进程随之至多 4 并发）；**跨请求去重**——键 =（workspace 根, `job_key` 缓存键茎，见「缓存口径」），队列中/进行中同键跳过，worker 执行前再重查缓存新鲜度；**失败记忆**——解码/编码/落盘失败记入进程级失败键集合（workspace.rs；不落盘，重启后至多再试一趟；源 mtime/size 变键自然失效重试；成功路径防御性清除），入队解析命中即跳过，且列举时 `entry()` 把失败条目视同不可解码落回按扩展名格式图标（exe 特例同既有分支）；**优先级**——priority 批整插队首保批内顺序（前端视口内缺失项 120ms 合批上报：AssetCard IntersectionObserver 可见性 / ListRowCard 挂载），目录全量补发排尾部；切空间（start_watch）清 pending。前端对接：`stores/ws.ts requestMissingThumbs`（全量排尾）/ `requestVisibleThumbs`（视口合批插队）/ `patchThumbs`（按 thumbKind 回填，仅 asset 补 w/h）。

## 缓存口径

缓存键茎 `job_key = {截断≤80的 url-safe(relPath) 前缀}-{fnv64hex(relPath)}-{mtime_ms}-{size}`（**2026-09-26 有界命名修复**：旧版整条 url-safe 编码路径做文件名，中文每字符 9 倍膨胀，深中文 rel 超 NTFS 255 单组件上限写盘必败——踩坑 092；前缀只截在完整 %XX 转义边界、只供人读，唯一性由 FNV-1a 64bit 散列段兜底，mtime+size 仍内嵌判新鲜，全长 ≤160 字符）。缩略图缓存 = `workspace/.anikit/thumbs/{job_key}.webp|png`：整名重算比对判新鲜，无 sidecar 索引；webp / png 双扩展名均认（libwebp 退 PNG 产物同样视为新鲜）。同 relPath 旧缓存顺清（purge_stale）**按 hash 段 `-{fnv64hex(rel)}-` 匹配**。可整体删除重建。卡片波形 peaks 缓存（2026-09-26）= `workspace/.anikit/peaks/{job_key}.json`，同口径判新鲜、同源 purge_stale 顺清。

**存量迁移（2026-09-26）**：旧命名缓存全部失效成孤儿——`.anikit/cache_v2` 标志文件记一次性清理，开空间（activate_space）时标志不存在则清空 thumbs/ 与 peaks/ 后落标志（纯缓存重建零代价；`.anikit` 其余内容不动；失败记忆进程级无需迁移）。

**exe 图标走文件级缓存**（2026-09-17 用户定，改按扩展名初判）：`{job_key}.icon.webp`——同扩展名各程序图标不同，按扩展名缓存会把首个 exe 的图标串给所有 exe；现场 shell 提取该文件自身图标，源变化（mtime+size）即失效重提并顺清同 relPath 旧缓存（purge_stale 同源）；`thumbKind` 仍 = `formatIcon`。**其余不可解码类型维持按扩展名缓存** `.anikit/thumbs/{ext}.webp`（txt/zip/fla 等，库 `cache/thumbs` 同口径换锚）。
