# 工作空间（2026-09-17 步骤 1 只读底座 + 步骤 2 基础整理 + 步骤 3 常用固定落地，插队提前自阶段十二；PRD `01_资源与数据/02_索引式工作空间`）

索引式工作空间（空间内唯一 `workspace/` 目录，磁盘实况语义）的浏览 + 基础整理接口。未开空间读接口一律返回空（null / []）不报错，写接口报「请先打开储存空间」；relPath 拒绝 `..` 与绝对路径组件，越界报中文错。

## 命令

- `workspace_root() -> { rootPath, exists } | null`：workspace/ 目录绝对路径（前端 `convertFileSrc` 直读其下文件）+ 目录是否存在。
- `list_workspace_dir(relPath) -> WsEntry[]`：relPath 空串 = 根。`WsEntry = { name, relPath, isDir, size, mtimeMs, w, h, ext, thumbPath, thumbKind }`——目录在前、同名不区分大小写排序；`.anikit` 隐藏不出现在结果里；`w/h` = 图片像素宽高（魔数探测，卡片按真实比例自适应）；`thumbPath` 仅缩略图缓存新鲜时给绝对路径，否则 null；`thumbKind` = `asset | formatIcon | null`（非可解码类型回退系统格式图标——exe 按文件缓存，其余按扩展名缓存，见「缓存口径」）。
- `request_workspace_thumbs(absPaths) -> void`：立即返回；后台线程逐一生成缺失 / 过期缓存（解码失败条目跳过，源变化时顺手清理同 relPath 旧缓存），完成 emit `workspace-thumbs-ready`。
- `get_media_source_by_path(absPath, forceTranscode?) -> MediaSource | null`：按真实路径取音视频播放源（形状与按 assetId 版一致：`{ path, transcoded, fps }`）；默认直读优先（踩坑 075 口径），前端播放 error 后带 `forceTranscode=true` 重调走转码兜底；转码产物落 `workspace/.anikit/media/`。图片 / 动图 / 文本不经此命令（前端直 `convertFileSrc` 源路径）。文件须在空间 workspace 内，否则 null。
- `reveal_path(absPath) -> void`：在文件管理器中打开并选中（explorer /select，含空格路径经 ShellExecuteW 原样传参）；约束在当前空间 workspace 内，越界 / 不存在报中文错。

## 写操作（步骤 2，2026-09-17 同日落）

命令返回即磁盘生效；**前端命令返回后直接局部重扫 UI，本进程写操作的 watcher 事件按「已知操作」消重**（3s 窗口内登记路径之下的事件不上报；窗口外 / 混合事件照常推送，不用延时忽略）。写操作一律拒绝 `.anikit` 缓存目录内路径。

- `ws_create_folder(relDir, name) -> void`：relDir 下新建文件夹；重名 / 非法名（空、`.` `..`、`\ / : * ? " < > |`、控制字符、结尾点或空格）报中文错（新建须显式命名，不自动规避）。
- `ws_rename(relPath, newName) -> void`：relPath 最后一段改名（文件与文件夹同径）；目标重名报错；名字不变不动。
- `ws_delete(relPaths) -> void`：多路径一次删除到**系统回收站**（SHFileOperationW，FOF_ALLOWUNDO 语义；PRD 06 不进库内回收站）；失败（如被占用）整批中文错。
- `ws_move(relPaths, destRel) -> void`：移入 destRel（同卷 rename；目录禁移入自身子树）；重名自动 `名_n` 规避（n 从 2 递增，2026-09-23 序号格式统一定案），不覆盖。
- `ws_paste(relPaths, destRel, cut) -> void`：复制（cut=false，目录递归）或移动（cut=true）进 destRel；剪切成功后由前端清剪贴板。重名自动规避同 ws_move。

## 视图状态（步骤 3，2026-09-17 同日落）

视图状态 = `workspace/.anikit/workspace.json` 的 `{ pinned: string[] }`（字段后补，serde 缺省宽容读取）。**读取即校验**：resolve 越界 / 不存在 / 非目录的条目静默剔除，去重保序，有变化即回写（改名 / 移动 / 删除的失效 pin 由此自动清理，无需前端通知）。未开空间 / 目录缺失一律返回 `[]` 不报错。

- `ws_list_pinned() -> string[]`：当前固定清单（rel 路径，固定顺序）。
- `ws_pin(relPath) -> string[]`：固定目录（须为空间内已存在目录，resolve_under 校验、拒绝 `.anikit`；重复固定幂等）；返回最新清单。
- `ws_unpin(relPath) -> string[]`：取消固定；返回最新清单（残留失效条目由 list 顺带清理）。

树行右键（最小集：打开 / 固定到常用·取消固定 / 在资源管理器中显示 / 刷新）由 `menuSpecs/workspace.ts wsTreeRowSpec` 出菜单；固定区块在 WorkspaceTree 顶部（**无区块标题直接列表**，库快速访问同先例），行 = 目录快捷入口。写操作局部重扫后前端重取清单对齐（`stores/ws.ts refreshAround` 末尾 `loadPinned`）。

## 事件

- `workspace-fs-changed`（负载 `()`）：workspace 递归监听（notify，参照收件箱 inbox_watch 同适配器）任何路径变化即推，**`.anikit` 组件内事件已后端过滤**（防缩略图 / 转码产物写回自激）+ **本进程已知写操作的回声已消重**（3s 窗口，见上）；前端 300ms 去抖后重扫已加载目录。
- `workspace-thumbs-ready`（负载 `[{ absPath, thumbPath }]`）：缩略图后台生成完成，**总是 emit**（无生成 = 空数组），只含本趟实际生成成功的条目。

## 缓存口径

缩略图缓存 = `workspace/.anikit/thumbs/{url-safe(relPath)}-{mtime_ms}-{size}.webp|png`：文件名内嵌 mtime+size，整名重算比对判新鲜，无 sidecar 索引；webp / png 双扩展名均认（libwebp 退 PNG 产物同样视为新鲜）。可整体删除重建。

**exe 图标走文件级缓存**（2026-09-17 用户定，改按扩展名初判）：`{url-safe(relPath)}-{mtime_ms}-{size}.icon.webp`——同扩展名各程序图标不同，按扩展名缓存会把首个 exe 的图标串给所有 exe；现场 shell 提取该文件自身图标，源变化（mtime+size）即失效重提并顺清同 relPath 旧缓存（purge_stale 同源）；`thumbKind` 仍 = `formatIcon`。**其余不可解码类型维持按扩展名缓存** `.anikit/thumbs/{ext}.webp`（txt/zip/fla 等，库 `cache/thumbs` 同口径换锚）。

## 前端对接

`src/lib/wsOps.ts`（命令封装 + 事件监听）、`src/stores/ws.ts`（目录缓存 / 合成 PlacementView / 剪贴板与写操作局部重扫，`assetId` = `ws:${relPath}` 合成假 id，**严禁发 assetId 类命令**）。视口 viewKey 前缀 `ws:`（根 = `ws:`）。
