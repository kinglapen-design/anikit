# 工作空间（2026-09-17 步骤 1 只读底座 + 步骤 2 基础整理 + 步骤 3 常用固定落地 + 2026-10-02 链接目录（junction 方向 b），插队提前自阶段十二；PRD `01_资源与数据/02_索引式工作空间`）

索引式工作空间（空间内唯一 `workspace/` 目录，磁盘实况语义）的浏览 + 基础整理接口。未开空间读接口一律返回空（null / []）不报错，写接口报「请先打开储存空间」；relPath 拒绝 `..` 与绝对路径组件，越界报中文错。

## 命令

- `workspace_root() -> { rootPath, exists } | null`：workspace/ 目录绝对路径（前端 `convertFileSrc` 直读其下文件）+ 目录是否存在。
- `list_workspace_dir(relPath) -> WsEntry[]`：relPath 空串 = 根。`WsEntry = { name, relPath, isDir, hasSubDir, isLink, linkOk, size, mtimeMs, ctimeMs, w, h, ext, thumbPath, thumbKind }`——目录在前、同名不区分大小写排序；`.anikit` 隐藏不出现在结果里；`hasSubDir` = 目录是否含可见子目录（2026-09-26 侧栏树展开箭头真实化：列目录时顺带单次 read_dir 提前退出扫描，任一非 `.anikit` 子目录即 true，与列举同口径只滤缓存目录，读取失败 false；文件恒 false；废除前端「未加载乐观出箭头、展开后才消」；**reparse 目录（含断链 junction）计入子目录**——跟随式 is_dir 对断链得 false，曾误判只含断链门的父目录无子级丢箭头，2026-10-02 实机报修复）；`isLink` = 目录链接（2026-10-02 junction 方向 b「门」：目录 reparse point 即 true，**断链也 true**——门没了目标仍是门；文件恒 false；断链链接仍列作目录条目，`hasSubDir` 随 read_dir 失败自然 false）；`linkOk` = 链接目标当前可达（跟随式 metadata 探测成功；断链 false；**非链接恒 false**）——前端据此出角标 / 断链置灰、「重新定位… / 删除链接」菜单项与断链修复弹窗（见「链接目录」节）；`ctimeMs` = 创建时间 Unix 毫秒（2026-09-26 详情面板基础数据补，复用同一份 metadata 零额外开销；**目录同样取值**——Windows 目录时间有效，`mtimeMs` 同取 = 直接子项增删时更新，2026-10-03 目录属性落地放开，原「目录恒 0」人为抹零废除；平台不支持恒 0）；`w/h` = 布局比例来源（卡片按真实比例自适应）：图片 = 源像素宽高（魔数探测），非图片（视频/音频/字体等）内容缩略图缓存新鲜时 = 缩略图尺寸（与源同比例，仅读缓存文件头 `image::image_dimensions` 不全解码，2026-09-26 视频卡方盒裁切修复），均无 = null 回退方盒；`thumbPath` 仅缩略图缓存新鲜时给绝对路径，否则 null；`thumbKind` = `asset | formatIcon | null`（非可解码类型回退系统格式图标——exe 按文件缓存，其余按扩展名缓存，见「缓存口径」；**2026-09-26 起失败记忆命中的条目同落回 formatIcon**，见「缩略图生成管线」）。命令本体 async + spawn_blocking（2026-09-26 性能优化 B：大目录同步 IO 与 exe 图标 COM 提取不占 tokio worker）。**错误口径（2026-10-02 幽灵视口修复改）**：未开空间 / workspace 根缺失 → `Ok([])`（启动暂态降级）；**目录缺失 / 越界等列举失败 → Err 原样上抛**——不再降级冒充空目录，前端据 Err 置 missing 标记并把当前幽灵视口回退到最近存活祖先（见「幽灵视口自愈」节）。
- `ws_dir_stats(relPath) -> WsDirStats`（2026-10-03 详情面板目录属性，Windows 属性窗口「包含 / 大小」口径）：`WsDirStats = { files, dirs, totalSize, ctimeMs, mtimeMs }`——递归子树的文件总数 / 子文件夹总数（不含根自身）/ 文件字节总和（前端「占用空间」行 = 字节求和，库 FolderDetail 同口径，非簇对齐）；`ctimeMs/mtimeMs` = 根目录自身时间（详情根视口的合成条目无 entry 时间取此；子目录前端优先用条目值）。**穿透 junction**（Explorer 属性窗口同口径——方向 b 链接门的内容是「挂进来的文件夹」），canonicalize 已访问集防回环（外部自建 junction 指回空间内不重复统计；断链门本身计 1 个文件夹、子树不可达自然跳过）；`.anikit` 全层跳过（list_dir 同口径）；读取失败子树静默跳过。命令本体 async + spawn_blocking（大子树遍历不占 tokio worker）；未开空间 / 目录缺失 / 越界 Err 上抛（前端只对现存目录发起，失败静默不加行）。
- `ws_dirs_exist(rels) -> bool[]`（2026-10-03_12 前端 ws 视口键清理）：目录存在性批量判定——逐键 stat（跟随 `is_dir` || reparse 断链门 = 活；词法校验拒 `..` / 绝对路径组件），零 read_dir；**不走 resolve_under 越界闸**（写操作安全语义不适用——未登记野门在树里照常显示、视口键是活键）。未开空间全 false（前端只在 root 就绪后调）。
- `request_workspace_thumbs(absPaths, priority?) -> void`：立即返回，任务进**进程级缩略图 worker 池**（`services/ws_thumb_queue`，2026-09-26 性能优化：N = 可用并行度一半钳 1..=8 固定并发——上限 2026-10-01 由 4 提至 8，取代每 invoke 裸 spawn 串行线程）；**跨请求去重**（键 = rel+mtime+size 缓存键茎，队列中/进行中跳过）+ **失败记忆**（解码失败键进程级记录，命中不再重试，mtime/size 变自然失效）；`priority=true` 整批插队队首（前端视口内缺失项），缺省 false 排尾部；完成批次 emit `workspace-thumbs-ready`。命令本体 async + spawn_blocking（逐条 stat / 新鲜度判定不占 tokio worker）。
- `get_media_source_by_path(absPath, forceTranscode?) -> MediaSource | null`：按真实路径取音视频播放源（形状与按 assetId 版一致：`{ path, transcoded, fps }`）；默认直读优先（踩坑 075 口径），前端播放 error 后带 `forceTranscode=true` 重调走转码兜底；转码产物落 `workspace/.anikit/media/`。图片 / 动图 / 文本不经此命令（前端直 `convertFileSrc` 源路径）。文件须在空间 workspace 内，否则 null。
- `reveal_path(absPath) -> void`：在文件管理器中打开并选中（explorer /select，含空格路径经 ShellExecuteW 原样传参）；约束在当前空间 workspace 内，越界 / 不存在报中文错。

## 打开外发与系统菜单（2026-10-01 库右键菜单移植轮）

下列命令与 `reveal_path` 共用同一校验（`validated_ws_path`：当前空间 workspace 内 + 存在，否则中文报错）。

- `open_path_with_default_app(absPath) -> void`：用系统默认程序打开（库「在默认应用打开」按路径版；ShellExecuteW "open"）。
- `open_path_with_dialog(absPath) -> void`：系统「打开方式」对话框（openas 动词；缺失时 rundll32 `OpenAs_RunDLL` 兜底——同库侧适配器既有口径）。
- `ws_file_base64(absPath) -> string`：复制 base64 按路径版，复用库侧 `services/asset_menu::base64_from_origin`——静态图（png/jpg/jpeg/bmp/webp/gif）读原字节 ≤10MB，psd/psb/svg 解码合成图 → 长边 ≤4096 PNG ≤10MB，其余格式 / 文件夹中文报错。
- `send_path_to_animate(absPath) -> string`：发送至 Animate 按路径版（仅 fla）；解析与校验后共享 `commands/cep.rs send_fla` 流程（剪贴板载荷转换 → 失败回退兜底 → WS 下发；发送锁在途拒绝），返回素材名。
- `ws_export_md_bundle(absPath) -> BundleReport`：MD 打包导出工作空间版（2026-10-08 S6，PRD 02-09——库侧 `export_md_bundle` 同服务 services/md_bundle.rs）：落点固定 = 文档旁 `{文档名}-打包/`（重名 -2… 规避）；abs_path 经 validated_ws_path 校验、仅 .md；引用的库资产解析需库已打开。菜单入口 = ws 文件卡右键「打包导出 MD…」（仅 md 单选出现）。
- `ws_shell_menu(absPaths) -> void`：**Windows 原生右键菜单**（「系统菜单」项）——多路径整组一次弹出。实现 = `adapters/shell_menu.rs`：桌面 IShellFolder + 全 PIDL `GetUIObjectOf` 取 IContextMenu（跨目录多选同 Explorer 口径），`CreatePopupMenu` + `QueryContextMenu` 装配，`TrackPopupMenuEx`（`TPM_RETURNCMD`）在光标处模态弹出，选中项 `InvokeCommand`（`CMINVOKECOMMANDINFOEX` + `CMIC_MASK_UNICODE`）执行；7-Zip 等扩展的子菜单与自绘项靠自建消息窗把 `WM_INITMENUPOPUP / WM_DRAWITEM / WM_MEASUREITEM / WM_MENUSELECT / WM_MENUCHAR` 转发 IContextMenu2/3（`HandleMenuMsg(2)`）。模态循环在 spawn_blocking 线程的 STA 内自泵消息，主线程不冻结；命令返回 = 菜单已关且命令已执行，用户取消 = Ok。**边界**：只出经典 IContextMenu 扩展（压缩解压 / TortoiseGit 等）；Win11 新样式菜单的 IExplorerCommand 现代扩展不可托管，不在其中；动词自身行为（删除 / 重命名等）由 shell 扩展自理。
- `ws_shell_menu_background(absPath) -> void`：**目录背景版系统菜单**（空白处右键「系统菜单」，2026-10-01 补）——`BindToObject` 取目录自身 IShellFolder → `CreateViewObject` 取背景 IContextMenu：经典版 **新建 ▸ / 排序方式 ▸ / 查看 ▸** / 刷新 / 属性 等在其中（新建落盘经 watcher 热刷新回视图；查看/排序方式子菜单作用于 Explorer 视图对象，在托管菜单里天然无效——先天边界非缺陷）。目标须为目录，其余同 `ws_shell_menu`。
- `open_system_recycle_bin() -> void`：资源管理器打开系统回收站（`explorer shell:RecycleBinFolder`，ShellExecuteW 原样传参同 reveal 口径）——工作空间侧栏「回收站」行点击入口（2026-10-01，行 = 库快速访问回收站同款 TreeRowItem quick + trash 图标，无数量：磁盘实况不跟踪系统回收站内容）。

## 填充卡按路径命令（2026-09-26 三类填充卡对接）

ws 条目 `assetId` = `ws:${relPath}` 合成假 id，**严禁发 assetId 类命令**——卡片填充内容（文本正文 / 音频波形 / 字体信息）一律走下列按路径命令（前端以 `wsPath` 绝对路径调用，假 id 仅作前端缓存键）。统一口径：未开空间报「请先打开储存空间」；越界 / 不存在 / 非目标格式中文报错（前端卡片 catch 兜底空内容）；越界校验与 `get_media_source_by_path` 同为 `ws::is_under`。

- `read_text_by_path(absPath) -> { content }`：txt/md 全文（UTF-8 优先 GBK 回退，2MB 上限），形状同 `read_text_asset`。
- `read_docx_by_path(absPath) -> DocxContent`：docx 段落结构提取（只读），形状同 `read_docx_asset`。
- `get_audio_peaks_by_path(absPath) -> number[]`：音频卡片波形 peaks（恒定 128 根不随时长，同 `get_audio_peaks`）。**产物缓存换锚** `workspace/.anikit/peaks/{job_key}.json`——job_key 同缩略图缓存键（见「缓存口径」），文件名内嵌 mtime+size，按当前实况重算期望文件名存在即命中（无 .stamp 旁文件，与库侧 `cache/peaks/{assetId}.json+.stamp` 不同锚）；源变化重算并顺清同 relPath 旧缓存（purge_stale，同 ws 缩略图口径）。
- `get_font_info_by_path(absPath) -> FontInfo`：字体元数据 + 安装状态，形状同 `get_font_info`（`originPath` = ws 源文件绝对路径，前端 FontFace 经 `convertFileSrc` 加载）。**安装 / 卸载无按路径版**（系统级写入只认库资产），ws 卡片不出安装钮。

## 预览按路径命令（2026-10-23 工作空间文档预览放行）

ws 预览面板放行 txt / md / docx / 字体（PRD 02 技术口径「文档预览」条）：组件按 `wsPath` 分流——`read_text_by_path` / `get_font_info_by_path` 直接复用上节命令，docx 预览原始字节新增下列命令；**md / txt 只读**（编辑链路另立）。预览「默认应用打开 / 其他应用打开」出口 = `open_path_with_default_app` / `open_path_with_dialog` 既有命令（preview store 内按 isWsPlacement 分流）。

- `read_docx_binary_by_path(absPath) -> 原始字节（IPC 二进制响应，前端收 ArrayBuffer）`：预览 mammoth 链路按路径版，形状同 `read_docx_binary`。越界 / 不存在 / 非 docx 中文报错（`check_ws_docx` 与 `read_docx_by_path` 共用校验），64MB 容量闸在 `services::docx::read_docx_bytes`；无 origin 自愈触点（ws 无 metadata）。

## 写操作（步骤 2，2026-09-17 同日落）

命令返回即磁盘生效；**前端命令返回后直接局部重扫 UI，本进程写操作的 watcher 事件按「已知操作」消重**（3s 窗口内登记路径之下的事件不上报；窗口外 / 混合事件照常推送，不用延时忽略）。写操作一律拒绝 `.anikit` 缓存目录内路径。

- `ws_create_folder(relDir, name) -> void`：relDir 下新建文件夹；重名 / 非法名（空、`.` `..`、`\ / : * ? " < > |`、控制字符、结尾点或空格）报中文错（新建须显式命名，不自动规避）。
- `ws_rename(relPath, newName) -> void`：relPath 最后一段改名（文件与文件夹同径）；目标重名报错；名字不变不动。
- `ws_delete(relPaths) -> void`：多路径一次删除到**系统回收站**（SHFileOperationW，FOF_ALLOWUNDO 语义；PRD 06 不进库内回收站）；失败（如被占用）整批中文错。
- `ws_move(relPaths, destRel) -> void`：移入 destRel（同卷 rename；目录禁移入自身子树）；重名自动 `名_n` 规避（n 从 2 递增，2026-09-23 序号格式统一定案），不覆盖。
- `ws_paste(relPaths, destRel, cut) -> void`：复制（cut=false，目录递归）或移动（cut=true）进 destRel；剪切成功后由前端清剪贴板。重名自动规避同 ws_move。
- `ws_duplicate(relPaths) -> void`：创建副本（2026-10-01 库「创建副本」Ctrl+D 移植）——逐项复制进**自身所在目录**（copy_entries 的固定同目录形态），重名自动 `名_n` 规避不覆盖；文件与文件夹混合整批受理，目录递归。

## ws ↔ Explorer 互通（2026-10-01，PRD 02-13 定案五条）

双向拖拽 + 剪贴板复制 / 剪切 / 粘贴互通。拖入一律复制（非破坏口径）；拖出 = 复制语义（`ws_drag_paths`，登记见 `02_系统.md`）；复制 / 剪切同步写系统剪贴板；粘贴按剪贴板序号仲裁（前端 ws store，机制同库 2026-09-17）。剪贴板读写属 COM/IO，命令一律 async + spawn_blocking。

- `ws_write_clipboard(relPaths, cut) -> void`：写系统剪贴板——CF_HDROP 文件列表 + 单张静态图 ≤20MB 附位图（PNG + CF_DIBV5，库 2026-09-17 同口径，`services/asset_menu::clipboard_bitmap` 复用）+ **剪切附 Preferred DropEffect=MOVE**（资源管理器粘贴即移动，源由系统自删；复制按惯例不写）。rel 逐条校验（越界 / 不存在跳过 + 去重保序），空集报错。
- `ws_clipboard_files() -> { paths: string[], cut: boolean }`：读系统剪贴板文件清单（CF_HDROP 逐个 DragQueryFileW + DropEffect）——右键菜单「粘贴」出现条件（内部剪贴板非空 || 系统剪贴板含文件）查询用；仲裁读取在 `ws_paste_system` 内不经本命令。
- `ws_paste_system(destRel) -> { pasted: string[], moved: boolean, hadFiles: boolean }`：系统剪贴板粘贴（仲裁外部分支）——复制来源恒复制 / **剪切来源（DropEffect=MOVE）= 移动**（同盘 rename、异盘复制后删源）；源已不存在项跳过，全失效 = pasted 空（前端 toast「剪贴板中的文件已不存在」）；hadFiles=false = 剪贴板无文件（前端静默）；图片 / 文本等无文件内容不导入（库导入专属）。
- `ws_import_paths(absPaths, destRel) -> string[]`：Explorer 拖入（恒 copy）——源 = 外部绝对路径（不做 root 约束，不存在项跳过），dest 走 ws 校验（越界 / 非目录 / `.anikit` 内中文报错）；目录递归、重名 `名_n` 规避；返回 created rel 集（前端局部重扫锚）。服务层 `import_external_entries` 共用护栏：目标落源子树内跳过（防爆递归）、剪切粘贴到自身所在目录 = 无操作。

## 链接目录（junction 方向 b，2026-10-02 落地，PRD 02 定案节）

外部文件夹以 NTFS junction 挂进空间子目录（不搬迁即纳入视野）。**登记清单** = `workspace/.anikit/workspace.json` 的 `links: [{ rel, target }]`（target = canonicalize 绝对路径；与 pinned 同文件，写点 `write_text_atomic` 原子写）——**读清单 = 路径闸放行与 watcher 补监听的唯一凭据**；`list_dir` 惰性登记（用户 `mklink /J` 自建 junction 首次被列出即纳入登记）。**路径闸 `resolve_under`**：词法过滤照旧 → canonicalize 落 root 内照旧 → 越界时命中登记链接（本身或子树）且落在目标内 → 返回**词法**门路径（fs 操作打在 junction 本体而非目标上——重命名 / 移动 / 删除「门」本身才安全）；断链登记链接同样返回词法 Ok（read_dir 自然失败降级空列表）；未登记 / 嵌套 junction（链接里再有链接指向目标外）仍越界拒绝。链接内文件缓存键 = 链接 rel——缓存落空间内 `.anikit`，链接目标保持干净。**watcher**：主监听（RDC 递归）**不穿透 junction**（spike 实测 3 秒窗口 0 事件，踩坑 099），每条「链接在且目标在」单独补 target 监听，事件路径从 target 前缀翻译回词法门路径，走同一 `changed_dirs` / 回声消重管道（`workspace-fs-changed` 口径不变，前端零感知）；链接拓扑变化（增 / 删 / 重指 / 改名 / 移动 / 剪切粘贴）后命令层恒整体重建监听（简单口径）。**对账 reconcile**（start_watch 内）：门没了 → 剔出登记；外部重指 → 更新登记；**断链 = 只标记保留不剔除**（定案）。**写操作语义**：回收站删链接 = 只删门（spike 红线实证，目标内容不动）；重命名 / 移动 = 只动门（`fs::rename`，登记 rel 随 rename / move / delete / 祖先目录改名自动平移 / 剔除）；复制 / 副本链接目录 = **深拷内容**（Explorer 同口径）；拖入 / 粘贴进链接目录 = 落真实目标。适配器 = `adapters/junction.rs`（`is_reparse_dir` 纯 std 属性位 / `create` = DeviceIoControl FSCTL_SET_REPARSE_POINT 手拼 REPARSE_DATA_BUFFER / `read_target` 断链可读回原指向 / `remove` = RemoveDirectoryW 只删门）。

- `ws_add_link(destRel, targetPath) -> string`：targetPath（外部目录绝对路径）以 junction 挂进 destRel 下，挂载名 = 目标目录名（重名自动 `名_n` 规避）；返回挂载点 rel。拒绝：destRel 落点缺失（「挂载落点目录不存在：{destRel}」——写明「落点」防误读成选中的目标，2026-10-02 实机教训）/ target 非目录 / **在储存空间整树内**（空间根 / 素材池 / 自动导入 / 库数据 = APP 自留地，素材池挂进来会绕过库封闭语义直接改库文件，同日用户问后补）/ 在工作空间内（含等于）/ 是工作空间祖先（防循环）——中文报错。
- `ws_remove_link(relPath) -> void`：链接本体进系统回收站（只删门不动外部目标）+ 剔出登记清单；断链链接同样可移除；rel 不是链接中文报错。
- `ws_retarget_link(relPath, newTarget) -> void`：链接重指向 newTarget（校验同挂载：目录 / 不在空间内 / 非祖先）——断链链接的送修径。

三命令逻辑全在 services 层，命令层只转发并在成功后重建监听。前端封装 = `lib/wsOps.ts` 的 `addWsLink` / `removeWsLink` / `retargetWsLink` + ws store 三 action 与 `linkState(rel)` getter；菜单「添加链接文件夹…」（空白 / 文件夹新建组，系统目录选择器）与「重新定位…」「删除链接」（仅链接门条件出现，断链同列，多选只作用被右键项；ws 菜单无图标惯例）；**断链修复弹窗**（2026-10-02 二轮用户定：选中断链即弹——主钮 重新定位… / 次钮 删除链接 / 取消；三触发源 = 单选 / `tabs.openView` ws 守卫导航拦截 / 幽灵回退，状态 `selection.brokenLinkPrompt`，宿主 App.vue；目标被删零 watcher 事件场景由回退路径 `refreshAround` 重扫父级翻正徽章）；角标与断链置灰口径见 口径速查 §65。

## 缓存口径

缓存键茎 `job_key = {截断≤80的 url-safe(relPath) 前缀}-{fnv64hex(relPath)}-{mtime_ms}-{size}`（**2026-09-26 有界命名修复**：旧版整条 url-safe 编码路径做文件名，中文每字符 9 倍膨胀，深中文 rel 超 NTFS 255 单组件上限写盘必败——踩坑 092；前缀只截在完整 %XX 转义边界、只供人读，唯一性由 FNV-1a 64bit 散列段兜底，mtime+size 仍内嵌判新鲜，全长 ≤160 字符）。缩略图缓存 = `workspace/.anikit/thumbs/{job_key}.webp|png`：整名重算比对判新鲜，无 sidecar 索引；webp / png 双扩展名均认（libwebp 退 PNG 产物同样视为新鲜）。同 relPath 旧缓存顺清（purge_stale）**按 hash 段 `-{fnv64hex(rel)}-` 匹配**。可整体删除重建。卡片波形 peaks 缓存（2026-09-26）= `workspace/.anikit/peaks/{job_key}.json`，同口径判新鲜、同源 purge_stale 顺清。

**存量迁移（2026-09-26）**：旧命名缓存全部失效成孤儿——`.anikit/cache_v2` 标志文件记一次性清理，开空间（activate_space）时标志不存在则清空 thumbs/ 与 peaks/ 后落标志（纯缓存重建零代价；`.anikit` 其余内容不动；失败记忆进程级无需迁移）。

**魔数探测缓存（2026-10-01 性能优化②）**= `workspace/.anikit/probe.json`：`{ job_key: [w,h] | null }`——图片源尺寸魔数探测结果按键持久缓存（**含非图片 / 探测失败负缓存**，否则非图片条目每次列举都重开文件头实探），源变化（mtime+size）键自然失效无需主动清；list_dir 趟初一次读入、趟末有新增才回写（进程级锁内重读合并防并发趟互覆 + `write_text_atomic` 原子写，条目超 5 万按本趟触及键白名单重建防无界膨胀）；纯缓存可删可重建。**同轮瘦身**：list_dir 的内容缩略图 / exe 图标 / 格式图标命中判定改趟初对 thumbs 目录一次 `read_dir` 取文件名快照集合匹配（原逐文件 is_file 探测——webp/png 双扩展名 + exe 图标 + 格式图标——全消，万级目录每次列举数万次 syscall 的大头）。

**exe 图标走文件级缓存**（2026-09-17 用户定，改按扩展名初判）：`{job_key}.icon.webp`——同扩展名各程序图标不同，按扩展名缓存会把首个 exe 的图标串给所有 exe；现场 shell 提取该文件自身图标，源变化（mtime+size）即失效重提并顺清同 relPath 旧缓存（purge_stale 同源）；`thumbKind` 仍 = `formatIcon`。**其余不可解码类型维持按扩展名缓存** `.anikit/thumbs/{ext}.webp`（txt/zip/fla 等，库 `cache/thumbs` 同口径换锚）。
