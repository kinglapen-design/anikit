# 自定义数据（6.1 一轮，2026-08-23 落地，PRD 03_数据链接 02/03/06 + 32/31/43 稿）：

**自定义数据（6.1 一轮，2026-08-23 落地，PRD 03_数据链接 02/03/06 + 32/31/43 稿）：** 文件与档案的属性（打词）/ 描述（标题+内容）/ 档案封面与徽标编辑；服务层 `services/custom_data.rs`（属性/描述写 + 属性池 + 全局删除）+ `services/archive.rs`（封面设置与烘培）；写命令撤销三步、服务无改动返回 false 时取消事务不进撤销栈；属性规整 = trim 去空去重保序，描述规整 = 标题/内容 trim 双空条目丢弃
	- `set_asset_props(assetId: string, props: string[]) -> void` —— 编辑文件属性（metadata.tags 语义 = 属性词；metadata 单写点落盘 + 索引同步 + modified_at 刷新）。撤销标签"编辑属性"
	- `set_asset_descriptions(assetId: string, descriptions: DescItem[]) -> void` —— 编辑文件描述（metadata.descriptions，6.1 新字段 serde default 不升 DATA_VERSION）。撤销标签"编辑描述"
	- `list_prop_pool() -> string[]` —— 属性池（只读；32 稿「已有属性标签：」）：全库聚合（全部资产 tags + 全部档案 props）去重，按码点序
	- `delete_props_globally(words: string[]) -> number` —— 全局删除属性（32 稿池内 ×，前端警告二次确认后调用）：全部命中资产 tags / 档案 props 移除该批词并落盘，单撤销步（record 各 metadata + archives.json），返回影响处数（资产 + 档案按 id 去重）。撤销标签"删除属性"
	- `set_archive_props(folderId: string, props: string[]) -> void` / `set_archive_descriptions(folderId: string, descriptions: DescItem[]) -> void` —— 编辑档案属性 / 描述（archives.json 单写点，记录懒建不写 created_at；目标非档案报错）。撤销标签"编辑属性" / "编辑描述"
	- `set_archive_cover_settings(folderId: string, badge?: Badge | null, cover?: { sourcePath, crop }) -> void` —— 档案封面设置（43 稿确认；badge 三角：缺省 = 不动 / null = 清除 / 对象 = 设置；cover 给了 = 本地选图按取景参数烘培新封面——按内容魔数解码（假扩展名防护）、cover 铺满 × scale + 中心偏移裁切、输出恒 416×416 方形（7.1 新稿取景框 240×240 同比例；旧 43 稿框 218:168 的 416×320 口径 2026-09-01 废除——输出比≠框比导致确认后"二次裁剪"）webp 存库根 covers/）。撤销标签"设置档案封面"
	- 护栏（operations::folder，2026-08-15）：create_folder / move_folders 目标父级为档案报错"档案下不允许出现子级文件夹"；`list_folder_tree` 的 FolderNode 全层级带 `kind?`（见"内容浏览"组）
