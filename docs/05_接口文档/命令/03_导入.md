# 导入（阶段 3.1 落地，后台任务 + Channel 流式；4.1 序列帧打包）：

**导入（阶段 3.1 落地，后台任务 + Channel 流式；4.1 序列帧打包）：**
	- `classify_paths(paths: string[]) -> { kind: "files" | "folder" | "mixed", fileCount }` —— 拖拽 / 菜单共用预判；fileCount 为递归展开后文件总数
	- `detect_sequences(paths: string[]) -> SequenceGroupInfo[]` —— 序列帧检测（后端为唯一事实来源，4.1）：递归展开后按"同目录 + 基础名 + 扩展名 + 序号位宽"分组（`标题001` / `标题 (1)` / `标题_001` / `标题-001`），序号连续（缺帧 ≤ max(2, 跨度/10)、同组同号不判）且 ≥3 且为图片格式（png/jpg/jpeg/gif/webp/bmp）才判定；`SequenceGroupInfo = { name, ext, frameCount }`（name = 基础名即资产标题）。09 导入弹窗确认后调用，命中则追加弹 12_序列帧弹窗
	- `import_paths(paths: string[], structure: "flatten" | "keep", source: "copy" | "move", targetFolder: string | null, sequenceMode: "pack" | "scatter", onEvent: Channel<ImportEvent>) -> taskId` —— **立即返回 taskId，导入在后台线程执行**（分段短锁：扫描 / hash / 复制 / 缩略图在锁外，索引与 folders 写盘在锁内毫秒级，UI 不阻塞）；keep 按原结构建文件夹节点（同级同名复用）并先发 folders 事件；move 跨盘回退 copy+删；**hash 查重只对本库"看得见"的资产生效**（2026-09-19 BUG 4 假冲突根治：本库 folders.items 有活 Placement 且非 hidden 伴生才参与比对——回收站引用 / 孤儿残留 / 其他库资产 / hidden 伴生一律不触发冲突，原全量比对产出无文件夹名 + 无缩略图的"幽灵冲突"且 useExisting 必失败）；hash 命中挂起待 resolve_conflicts 决策；单文件失败不阻塞整批。**sequenceMode = "pack"（4.1）：检测到的序列帧整组打包为一个 Asset**——`{ID}.info/frames/` 归一重命名 `标题_序号.扩展名`（序号补齐位宽），metadata 记 fps（默认 24）/ frameCount / thumbFrame（首帧文件名），缩略图复用图片管线取 thumbFrame；组 hash = 各帧 sha256 按序号升序串联后再 sha256；Placement 显示名 = `标题.扩展名`；复制/剪切对整组生效（剪切整组帧移走）；"scatter" = 逐文件导入（现状；剪贴板 / 收件箱恒 scatter）。started.total 按单元计（散文件数 + 组数）
	- `import_clipboard(targetFolder: string | null, onEvent: Channel<ImportEvent>) -> taskId` —— 剪贴板导入（2026-07-27 扩）：先读图片（截图 → PNG 落 cache/tmp/，命名 剪贴板-yyyyMMdd-HHmm 重名 _序号，**无冲突挂起才即删、有冲突保留供 resolve copy 回读**，开库整目录清空兜底——2026-09-19 BUG 4：原落 cache/ 根且导入结束即删，冲突"作为新文件导入"读不到源连环失败），无图再读文件列表（资源管理器 Ctrl+C 的文件 / 文件夹，CF_HDROP），再读 **base64 文本（2026-08-14 用户定）**：data URI / 裸 base64 容忍空白，解码按魔数定扩展名（psd/psb/png/jpg/gif/bmp/webp/wav/mp3/mp4/mov/svg），魔数不在表内不认，上限 512MB，落 cache/tmp/ 临时文件同命名同清理口径；**来源恒 Copy**（剪贴板复制的文件绝不 Move 走用户原文件）+ flatten + scatter；三者皆无报中文错"剪贴板里没有图片或文件"（有文本但不可导入报"剪贴板里没有可导入的内容"）；**内容级重试（2026-10-08，踩坑 107）**：三路皆空不立即报错，50ms × 10 ≈ 最长 500ms 内重读等内容到达——外部程序常异步提交剪贴板（截图工具先走 UI 动画、浏览器复制大图先编码），单次读在内容到达前必空；任何一路有内容（含不可导入纯文本）即停（有内容 = 写入方已提交完毕）
	- `cancel_import(taskId: number)` —— 置位取消标志，管线在当前单元写完后中断（已导入部分保留）
	- `resolve_conflicts(items: ConflictResolution[], source: "copy" | "move") -> { resolved, failed }` —— 冲突决策（导入完成后统一处理）；**copy 建档重活在锁外执行**（2026-09-19 BUG 4：sha256 / 实体入库 / 缩略图 / ffmpeg 探测不再占全局库锁——原全程持锁，坏文件探测卡死即全 app 命令堵死；锁内只做校验 + Placement 登记 + 落盘）；`ConflictResolution = { sourcePath, existingAssetId, targetFolder, action: "useExisting" | "copy" | "link" | "skip", sequence?, sourceThumbPath?, importedFrom? }`；useExisting 把已有资源 origin Placement 移至 targetFolder（目标处链接去重），copy 继承 source 建档（**序列帧冲突按回传的 sequence 组信息重新打包**，4.1；新资产继承 importedFrom 批次渠道标记——自动导入冲突"保留两个"进"已导入"视图，2026-08-13；**copy 显示名 = 源文件原名不唯一化**——2026-08-14 用户定：库允许同名，自动加序号废除），link 建链接 Placement（显示名 = 源文件原名），skip 不动（源文件保留）；~~newName~~（**2026-08-13 用户定：弹窗内嵌批量重命名过度设计废除**，字段同步删除——命名导入后走独立批量重命名弹窗）；**sourceThumbPath 原样回传——决策成功（含 skip）即删除该预览缓存，且 cache/tmp 为会话级临时、打开库时整目录清空（4.2，2026-07-23 用户定）**；**决策落点不设限（2026-08-13 用户定案"不替用户做整理决定"）：useExisting / link 的 targetFolder 允许 root（未分类）——原"候车区护栏后端兜底拒绝"废除**
	- 事件流 `ImportEvent`（tag="type" camelCase）：`{type:"started",total}` → keep 模式 `{type:"folders"}`（层级已建，前端重拉文件树）→ 逐单元 `{type:"asset",placement:PlacementView}`（到一个显示一个）→ `{type:"finished",imported,conflicts:ConflictItem[],failed:{path,reason}[]}`
	- 冲突挂起项 `ConflictItem`（携双侧显示数据，供 10_重复添加提示）：`{ sourcePath, sourceName, sourceSize, sourceW, sourceH, sourceThumbPath, targetFolder, targetFolderName, existingAssetId, existingName, existingW, existingH, existingSize, existingExt, existingThumbPath, existingFolderName, sequence? }`——**sourceThumbPath（4.2 补）**：webview 直渲不了的格式（PSD/PSB/SVG 等）后端经解码管线生成的预览缓存绝对路径（cache/tmp/{路径+大小散列}.webp，幂等）；图片格式为 null，前端直读源文件。**不复用已有侧缩略图**：将来支持剪贴板自定义缩略图后 hash 相同缩略图也可能不同（2026-07-23 用户定）；**序列帧冲突（4.1）**：sourceName = `标题.扩展名`、sourcePath = 首帧路径（弹窗预览首帧）、sequence = `{ name, ext, width, frames: [{path, number}] }`（帧按序号升序，前端原样回传给 resolve_conflicts）
	- **根目录约定：Placement.folder 用保留 ID `"root"` 表示，Folder 列表不放 root 节点**
	- **新导入前插（2026-07-25 用户定）：新 Placement 插到目标文件夹段首（add_placement 锚点保批内到达序，新批次排旧批次前），显示顺序 = items 数组顺序；order 向负生长（仅相对键，7.1 排序落地时统一重排）；前端流式导入同语义前插（started 锚点清零，finished 后 refresh 全量对齐）**
