- `resolve_asset_by_origin_name(name: string) -> string | null` —— **by-name 解析**（2026-10-23 编辑器贴图直链，PRD 02-09「by-name 形态」条）：按 originName 等值（两端小写归一）解析**最新一笔**非回收站、非 hidden 伴生资产，回 assetId；查无 = null。实现 = `core/index.rs LibraryIndex::latest_by_origin_name`（纯 core 可单测）；消费方 = 前端 `jumpToAnikitRef` 的 item-by-name 分支（深链 / 内部 MD 点击 by-name 链接），媒体服务 `GET /item/by-name/{name}` 同源（见 [anikit协议](../../anikit协议.md)）。
- `get_paste_link_info() -> { command, toolPath, inboxDir | null }` —— 插件面板「编辑器贴图直链」详情窗数据源（commands/paste_link.rs）：`command` = Typora 自定义上传命令文本（anikit-paste.exe 绝对路径含引号，exe 位置 = 当前进程同目录）；`inboxDir` = 收件箱真实目录（空间根 + `自动导入`；未打开储存空间 = null）。
- `install_obsidian_plugin(vaultPath: string) -> string` —— 把 Obsidian 贴图插件写入 `{vault}/.obsidian/plugins/anikit-paste/`（main.js / manifest.json **include_bytes 嵌在 exe 里**，portable / dev 无路径解析问题），返回插件目录；vault 路径不存在 / 非目录 / 写失败中文报错。装完需重启 Obsidian 启用（toast 在插件面板封装内）。

**anikit-paste.exe（Typora 自定义上传命令，src/bin/anikit-paste.rs）**：argv = 图片路径列表 → 逐图拷入收件箱（`%APPDATA%\AniKit\config.json` 的 spaces[0].path + `自动导入`，目录缺失自建）→ stdout 每图一行 `http://127.0.0.1:{port}/item/by-name/{percent编码名}`（端口读 `mcp-server.port`，缺省 17701）。唯一名 `贴图-yyyyMMdd-HHmmss-fff.{ext}`；控制台子系统（Typora 读 stdout），错误走 stderr + 非零退出。随 pack-portable 进免安装包根目录。
