# 分词搜索（3.6 一轮，2026-08-19 落地；2026-08-31 前端 tag 化 chips 废除、换多功能悬浮栏单行输入，PRD 03_查找文件-01）：

**分词搜索（3.6 一轮，2026-08-19 落地；2026-08-31 前端 tag 化 chips 废除、换多功能悬浮栏单行输入，PRD 03_查找文件-01）：** 只读命令不走 undo；空格分词 AND、逐关键字子串包含不区分大小写、链接字段匹配前 URL decode（`+` 转空格）；命中范围 = 素材（资产名 / 各 Placement 显示名 / 扩展名 / 链接 / 所在路径链（区块 / 各级文件夹 / 档案名））+ 档案（档案名 / 徽标文本 / 属性 / 描述 / 链接）；范围口径（用户定）：当前目录跟随递归显示开关、快速访问 = 当前视图即范围（回收站里搜回收站，recycle 范围命中键 folderId 恒 "recycle"）、全局（`~` 前缀）= 全库不含回收站；档案命中仅文件夹视图出档案区（快速访问视图不出），非全局仅直属口径（同 stripArchivesFor，递归开关不影响档案区）、全局 = 全库命中档案
	- `search_assets(query: string, scope: SearchScope) -> SearchHits` —— `SearchScope = { viewKey, recursive, global, filters? }`（viewKey 同前端视口键：`folder:{id}` / `quick:all` 等六项）；query 前缀解析在后端：`//` 剥除（显式分词与直接输入等效）、`~` 本条强制全局（覆盖 scope.global，与 `//` 可交叉顺序不限）、`/` 按普通文本搜（筛选走悬浮栏按钮组另轮，不拦截）；`SearchHits = { placements: [{ assetId, folderId }]（与前端选择键 assetId|folderId 同口径，排序输出）, archives: string[]（命中档案 folderId，排序输出） }`

**筛选（2026-10-09 筛选业务一轮，PRD 03_查找文件-02）：** `scope.filters` 内嵌（serde default 空 = 不施加，旧调用零改动；query 空 + 有效筛选 = 纯筛选搜索）。**口径 = 维度内多选 OR、跨维度 AND、与分词搜索 AND（用户定案）**；「空壳」条件（范围双端空 / 日期档位与自定义全空）不算激活；筛选激活时档案区不出（筛选 = 找文件，档案无维度可判定）。回收站视口同口径施加（资产级对 meta、位置级对快照 placements，「无链接」按快照条数）；MCP `search_assets` 不暴露筛选。`SearchFilters` 逐维度实现口径：
	- `colors: string[]` —— 主色近似：`#RRGGBB` 多选，资产任一主色与任一目标色 RGB 欧氏距离 ≤ 64 即中；资产无色板不中；目标全无法解析 = 维度不参与（防垃圾输入清空结果）
	- `duration: { unit, min?, max? }` —— 时长范围：unit = `frames`（按素材自身 fps 换算总帧数，无 fps / duration 不中）/ `seconds` / `minutes`，单端可空
	- `tags: string[]` —— 属性词精确等值，不区分大小写
	- `exts: string[]` —— 扩展名小写（容忍 `.` 前缀）；虚拟类别 `"seq"` = 序列帧（`frames_dir_if_sequence` 磁盘口径，与导出 / 重命名同一判定，仅在该词出现时惰性探盘）
	- `folderIds: string[]` —— 所在文件夹（**自身或后代**——树形复选圈整棵子树，2026-10-09 三轮用户侧定案；`root` = 未分类；后端预展开后代集，位置级逐 Placement 判定）
	- `ratios: string[]` —— `landscape` / `square` / `portrait`（方图 = 宽高比 ∈ 1/1.05..=1.05）或自定义 `"w:h"`（相对偏差 ≤ 1%）；无宽高资产不中；词全无效 = 维度不参与
	- `linkStates: string[]` —— 链接状态四态：`origin` / `linked`（位置级 = 该卡是否原始放置）/ `thumb`（资产有伴生缩略图引用 thumb_asset_id）/ `none`（资产仅 1 条活位置）；位置级维度逐 Placement 判定（同资产可只中部分位置）
	- `size: { min?, max? }` —— 文件大小字节范围，单端可空
	- `imported / modified: { buckets: string[], custom?: { year?, month?, day? } }` —— 添加 / 修改日期：档位 = `today` / `yesterday` / `week`（近 7 天）/ `month`（近 30 天）/ `year`（近 365 天）/ `earlier`（≥365 天前，档位间 OR 允许重叠）；自定义年月日任意组合（填写项全等即中，只填年 = 该年全部）；modified = 库内数据变更时刻（非源文件 mtime）

**ws 视口不走本命令**（2026-10-03 工作空间搜索落地）：viewKey `ws:` 前缀时前端分流到 `ws_search` / `ws_search_crawl_*` 命令族（Everything IPC + 爬盘回退双层，见 20_工作空间「搜索」节）；`~` 前缀在 ws = 全景搜索工作空间（整个空间根），无 `~` = 当前视口目录子树递归。
