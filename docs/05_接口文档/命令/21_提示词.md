# 提示词（2026-09-26 提示词轮落地，PRD 03_数据链接 02「提示词」+ 走查菜单三态）：

**提示词（2026-09-26 提示词轮落地，PRD 03_数据链接 02_文件「提示词」+ 实机走查菜单三态）：** 提示词 = 对库内 md/txt 文本资产的「引用 + 内容快照」——`PromptBinding { assetId: string | null, name: string, content: string, updatedAt: string }` 内嵌 metadata.json（资产）/ archives.json（档案），serde default 不升 DATA_VERSION；三态 = 未指定（无字段）/ 已指定（assetId 非空）/ 已扫描（assetId null 纯快照，仅资产侧——档案无「分析」）。源文档被彻底删除不断链：`sync_after_purge` 钩子把引用置空、快照保留降级已扫描态，开库自检 `fix_prompt_refs` / `fix_archive_prompt_refs` 同口径兜底；「断开/清空」则整绑定移除（快照随解绑清除，不留半态）。服务层 `services/prompt.rs`（业务）+ `services/prompt_scan.rs`（内嵌元数据解析：PNG tEXt/zTXt/iTXt/eXIf 手写 chunk walk、JPEG/WEBP 经 image `exif_metadata` + 手写 TIFF 取 UserComment/ImageDescription、ComfyUI `prompt` chunk 抽 CLIPTextEncode 文本去重拼接、失败回落原 JSON；门禁 png/jpg/jpeg/webp）。写命令全走撤销三步（无改动取消事务）；assign / clear 两族抽 `_op` 供 MCP 写工具 assign_prompt / clear_prompt 复用。菜单三态数据通道：`PlacementView.promptState`（"none"/"scanned"/"linked"）+ `AssetDetail` / `ArchiveDetailView` / `ArchiveListItem` 带 `prompt` 全字段。搜索命中范围含 prompt.name + prompt.content
	- `analyze_asset_prompt(assetId: string) -> PromptBinding` —— 分析提示词（仅资产）：解析图片内嵌元数据落已扫描态快照（name = "扫描结果"）并返回绑定；非支持格式报「该格式无内嵌提示词可分析」、解析不到报「未检测到内嵌提示词」。撤销标签"分析提示词"
	- `assign_asset_prompt(assetId: string, promptAssetId: string) -> void` / `assign_archive_prompt(folderId: string, promptAssetId: string) -> void` —— 指定提示词：校验目标是库内文本资产（txt/md）、禁自指；读源内容落绑定 + 快照（name = 源显示名快照）。撤销标签"指定提示词"
	- `clear_asset_prompt(assetId: string, label?: string) -> void` / `clear_archive_prompt(folderId: string, label?: string) -> void` —— 清除提示词：菜单「断开提示词文档链接」与「清空提示词」共用，整绑定移除；label = 撤销标签由调用方按语义传（"断开提示词"/"清空提示词"），缺省"移除提示词"
	- `refresh_asset_prompt_snapshot(assetId: string) -> void` / `refresh_archive_prompt_snapshot(folderId: string) -> void` —— 同步快照：重读源内容更新快照 content + updatedAt（一轮详情「保存提示词」钮用；2026-09-26 二轮两态三钮改版后面板无入口，命令保留 API 层）。撤销标签"保存提示词"
	- `new_asset_prompt_document(assetId: string, folderId?: string, kind: "md" | "txt") -> PlacementView` —— 新建提示词文档（资产侧）：菜单「新建 .md/.txt 提示词文档」（未指定）与「保存提示词为 .md/.txt 文档」（已扫描）共用——文档名 = 资产显示名词干（撞名走 unique_name `_序号` 既有口径）、已扫描态内容 = 快照、folderId 落点（缺省根目录）；建文档 + 写内容 + 绑定单撤销步"新建提示词文档"，回新文档 PlacementView
	- `new_archive_prompt_document(folderId: string, kind: "md" | "txt") -> PlacementView` —— 新建提示词文档（档案侧）：落点 = 档案自身，名 = 档案名，恒空内容（档案无已扫描态），其余同资产侧
	- `delete_asset_prompt_document(assetId: string) -> void` / `delete_archive_prompt_document(folderId: string) -> void` —— 删除提示词文档：源文档全部活 Placement 丢回收站（可逆）+ 清除绑定，单撤销步"删除提示词文档"；未指定报「未指定提示词」、已扫描态报「扫描结果无提示词文档可删除」
