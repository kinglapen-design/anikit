# 2. 动画软件通信通道（WebSocket）

- 服务：`server/plugin_ws.rs`（8.1 落地），`ws://127.0.0.1:{动态端口}`，lib.rs setup 拉起；端口文件 = 全局配置目录 `AniKit/plugin-server.port`（每次启动覆写——spike 验证的发现机制：插件 node fs 读文件直连，无需固定端口）。帧格式 = JSON 文本帧（camelCase）。
- **服务总开关（2026-09-25，MCP 同款）**：`settings.pluginServer.serverEnabled` 缺省开——init 读配置决定本轮是否启动；插件面板 Animate 详情窗可随时启停（不用插件的用户关后不白听端口）。stop = graceful 收束 accept 循环 + abort 全部客户端连接（WS 长连接不随 listener 关闭自然断开）+ drain pending 立即失败 + 删端口文件（残留会误导面板连死端口）；面板侧走既有「连不上即未连接」语义。命令 = `get_plugin_server_status` / `set_plugin_server_enabled`（先启停后持久化，启动失败不记开态）。
- **协议 v2（2026-09-25 T1 开源口径泛化）**：消息分两层——**通用层无前缀**（任何软件插件接入即用）；**软件业务消息走 `<app>.<name>` 命名空间**（前缀须与 hello 登记的 app 一致，不符回 `error`；接第二个软件如 Blender = 新命名空间 + 同模式 handler，通用层零改动）。库数据变更前端事件 = `plugin-imported`（原 cep-imported 改名）。**v1（裸消息名 + cepOutDir + flaAssetId/webpAssetId）同日废除，CEP 面板 0.4.0 同步切换**。
- 通用层协议：
	- C→S `{ "type": "hello", "app": "animate", "version": "2024", "panelVersion": "0.4.0" }` → 登记连接身份（app / version / panelVersion，日志备查 + 能力分级演进位，PRD 07-01）→ S→C `welcome`：`{ type, protocol: 2, libReady, libRoot, exportDir, settings, bundledPanelVersion? }`——未开库 libReady=false（面板禁导出）；**exportDir = 该软件导出中转目录**（库根 temp/ 下，animate = `temp/cep-out`；通用概念，第二软件另开子目录）；settings = 该 app 设置子树（animate = cepExport：maxSecs 默认 10 秒 / maxBytes 2M / fps 0=跟随文档；无设置族的软件 = null）；**bundledPanelVersion 仅 animate 下发 = 版本握手**（面板无热更：与面板自报 panelVersion 不等 → 面板提示「重开 / 一键升级」，2026-09-02 待办②兑现）
	- C→S `{ "type": "getTree" }` → S→C `{ "type": "tree", "data": FolderTreeView | null }`（面板目标文件夹选择器数据源；组装 = `services/folder_tree`，命令层 list_folder_tree 与 MCP list_folder_tree 同函数，2026-09-25 自 commands 下迁）
	- C→S `{ "type": "saveSettings", "settings": {...} }`——载荷不带 app，**服务端按 hello 登记身份路由**到对应设置族（animate → `CepExportSettings::validate()` 护栏 → config 单写点落盘 settings.cepExport 子树）→ 广播 `{ "type": "settings", "app", "settings" }`（**全员含发件者**回显确认；客户端只收自己命名空间的）；校验/解析失败回发件者 `{ "type": "settingsError", message }`（面板回滚输入框为当前生效值）；未 hello 先发 = error 回包。面板侧 localStorage（cepSettings）缓存最后生效值兜底——重开面板不回硬编码默认（PRD「插件本地缓存最后值兜底」口径兑现）。新软件一族设置 = config 子树 + plugin_ws `settings_for` / `save_settings_for` 各加一支
	- S→C `{ "type": "error", "message" }` = 协议错误回包（未知消息类型 / 未 hello 先发业务消息 / 命名空间与登记身份不符——第三方调试友好）
- animate 命名空间协议：
	- C→S `{ "type": "animate.exported", "payload": { name, folderId | null, dynamic, flaPath, seqDir | null, pngPath | null, fps } }` → 接收入库（services/cep_export 三段式：prepare 短锁 / compose **锁外**（ffmpeg 秒级慢 IO 不冻结命令层）/ commit 锁内）→ S→C `animate.importProgress{stage:"compose"}` → `animate.importDone{ sourceAssetId, thumbAssetId, overLimit, webpBytes }` / `animate.importError{ message }`（**sourceAssetId = 工程源文件资产 / thumbAssetId = 缩略图资产**——通用口径，Animate 即 fla/webp）
	- C→S `{ "type": "animate.thumbOnly", "payload": { docPath, dynamic, seqDir | null, pngPath | null, fps } }`（**批次 2 仅缩略图**，2026-09-02：不导新 fla，当前文档画面补缩略图）→ 同三段式（thumb_prepare/compose/commit，compose 与 exported 共用 compose_webp 核心）→ `animate.thumbDone`（serde tag mode：**`bound`**{ sourceAssetId, thumbAssetId, name, overLimit, webpBytes } = 命中库内 fla 资产、WebP 入库 root + set_thumb_asset 绑定（已有绑定 = 换绑，旧 hidden 不动），emit plugin-imported；**`beside`**{ outPath, webpBytes } = 未命中不入库、WebP 挪原 fla 旁边重名 _序号唯一化（用户自行导入））/ `animate.thumbError{ message }`。**匹配 = 文档磁盘路径 ↔ 池内实体路径（assets/{ID}.info/{originName}）精确比对**（正斜杠 + 小写 + 去尾斜杠规范化；双口径 2026-09-02 用户定）
	- **发送至 AN（8.3 提前落地，PRD 07-04；请求-回执 id 对模式）**：
		- S→C `{ "type": "animate.paste", "reqId": n, "name": "素材名" }` —— 主方案：后端已把 fla 转成 Flash 11 Picture 写进系统剪贴板；面板 jsx `pasteClipboard()` = 当前文档 `clipPaste(true)` 原位粘贴 + 粘贴后选区非空校验（空 = 剪贴板数据无效的排障信号）
		- S→C `{ "type": "animate.pasteFla", "reqId": n, "name", "flaPath": "平台路径" }` —— 兜底（转换失败自动回退）：jsx `pasteFlaFile()` = 打开-主时间轴第一帧全选复制-关闭-原位粘贴；**已打开护栏**（`fl.documents` 预判：已开文档用完不 closeDocument——会关掉用户开着的文档；旧 electron 版脚本实证坑）
		- C→S `{ "type": "animate.pasteResult", "reqId": n, "ok": bool, "message": "中文原因" }` —— 回执；面板侧发送前查 readyState（失败无害：后端 20s 超时自动报错）；后端 `request_paste` = **按 app=animate 选在线客户端单播**（v2 起——多软件并存不串台；v1 文档写「首个」实为 HashMap 任意一个，2026-09-25 对账修正）+ pending 表（reqId → 客户端 id+oneshot）+ 20s 超时 + 断连 drain + 全局发送锁（不在线立即报错不排队 / 在途拒绝新发送）
		- 载荷转换口径（services/send_stage）：fla（XFL zip）→ folders/media/symbols 等块**原样透传** + timelines 重写（第一个 DOMTimeline 每层收首个 DOMFrame——去 duration 等属性、首帧 index≠0 置空帧占位、多场景丢弃、elements 直接子元素注入 `selected="true"`，quick-xml 事件流保属性序）+ 其余 zip entry（LIBRARY/bin/PublishSettings 等）原字节原序复制（spike/clipboard-probe 实证剪贴板 XFL 包同构）；全层首帧无内容 → Err 触发兜底。剪贴板写入 = adapters/clipboard `write_flash_picture`（Win32 注册格式 "Flash 11 Picture" + GMEM_MOVEABLE 堆句柄移交，OpenClipboard 竞争重试 3×50ms；spike probe-write.py 同 API 路径）。前端入口 = 素材卡右键 / 回收站右键「发送至 Animate」/ Ctrl+E（回收站视口快捷键拦截而菜单可点 = 口径不一瑕疵，记待办）；**点击即最小化主窗口**（2026-09-08 走查第 20 条：APP 不挡 AN 弹窗）
	- 入库链路（cep_export）：产物校验（temp/cep-out 落点，库根）→ 动态 = **纯 Rust 全帧组包**（2026-09-01 复验三连修订：逐帧 webp 单帧编码 + 手写 RIFF 组包 VP8X/ANIM/ANMF，**全画布矩形 + flags bit1=1（do not blend，源像素含透明区直接替换画布）**——ffmpeg libwebp_anim 差分帧经 image-webp 画布合成出重影，而 bit1=0（alpha 混合）透明区不覆盖画布出移动残影，两坑合并根治；ALPH 伴随块按序保留（初版丢失致黑底）；并摘掉 sidecar 依赖。降级链 = 质量 80→60→40 → 抽帧隔帧取 delay×2 时长不变（**2026-09-06 去尺寸档**——maxEdge 废除，帧图不再按长边缩放），软上限 2M 压不进保留产出 overLimit=true；静态 = image crate 原尺寸直转 WebP。**合成性能（2026-09-02 用户实机报「8M 导出卡 10 秒」= 降级链逐档全量重编码 240 帧）**：逐帧编码 rayon 并行保序组包 + libwebp method 4→2（动画缩略图快档，体积降级链兜底）+ 大小判断改内存过了才写盘（旧版每档写盘覆盖 = temp 里文件早现≠完成）+ 首档超上限 >5 倍直奔抽帧档）→ build_asset 两资产（Source::Move 同盘剪切；webp 经动图探测自动 animated）→ placement 落目标文件夹（失效 id 回退 root）→ set_thumb_asset hidden 绑定 → operations::finish → 清场（seq 目录 / 静图 PNG）→ 前端 `plugin-imported` 事件全量 refresh + 成功提示音（2026-09-02 用户定：导出时视口停留 Animate 窗口，听觉兜底；500ms 节流批量只响一声）。**播放代理**：thumb_asset_id 有效时 PlacementView 的 animated/frameCount/fps/duration/thumbFrame 全代理伴生资产 + `playAssetId`（播放源解析目标；前端卡片 AnimImgLayer 与预览 loadAnim 均 `playAssetId ?? assetId`——fla 卡片/预览直接播伴生动画）；**静态伴生预览**（2026-09-02 修：原落 kind=other 无 viewable 滚轮缩放失效）= playAssetId 存在且非 animated 时预览按图片加载伴生本体（kind=image 全功能）。**缩略图管线**：gif/webp 动图改走 anim 首帧解码（`decode_origin_image` 选路——image crate 对 VP8X 动画容器解码丢 alpha 落黑底）
	- 旧占位（请求/响应 id 对 + sendToStage/exportThumbnail/getState 动作集）——sendToStage 已由 8.3 paste 系列兑现（本条上行）；exportThumbnail 随 8.2 批量导出于 2026-10-24 撤销，不再补做；getState 未接入且暂无消费方，不列为 1.0 收尾项。
