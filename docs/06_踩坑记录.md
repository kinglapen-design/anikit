## 001 PySide6 快速滚动卡顿（历史项目）

- **现象：** 虚拟缓存、懒加载都上了，快速拉动滚动条仍卡顿。
- **原因：** 疑为 QWidget 体系 CPU 光栅 + Python 侧绘制委托 + 滚动时同步解码/IO，并非单纯"没走 GPU"。
- **解法：** 本项目改用 Web 技术栈（浏览器合成器 GPU 加速，createImageBitmap 离线程解码）。
- **预防：** 已写入 01_开发规范 第 7 条——列表虚拟化、异步解码、布局预计算（用 metadata 宽高）、滚动降级（主色占位）。验收线：10 万资源快拖不掉帧。
