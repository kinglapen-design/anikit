> 本轮无新设计稿——版式全部套 §29 已定口径（插件面板 + Animate 详情窗）与退役 SettingsModal 开关行定案；业务 = PRD 08-06 MCP 条目化（待办细节清单 2026-09-20 立项）。

- **桥接类新条目「AI 外接通道（MCP）」**：`lib/plugins.ts` PLUGINS 加项（icon = `mcp`——用户直投官方插头对接 logo，清理 iconfont 冗余 + 转 currentColor，命名对照十三批登记，实寸 22 同 animate-plugin 盒口径）。数据源写死内置三项的形态不变。
- **更多菜单 mcp 分支**：打开 / **启动服务|停止服务**（开菜单时 `getMcpStatus` 拉 `running` 动态文案，对应 Animate 的安装/卸载位——MCP 无文件可装，「启停」即其安装位语义）/ 配置快捷键（占位禁用，同其他条目）。
- **MCP 详情子窗口（`plugins/McpPluginWindow.vue`，544×640）**：链路全沿 §29（open_plugin_window 白名单加 `"mcp"` / `?plugin=mcp` 分发 / 单例聚焦 / 通栏 62px 拖拽带容器+h1 双挂 / ScrollThumb 负 margin 贴右缘 / Esc=关窗）。高度 640 = 四组内容实量估值（Animate 窗 578 容三组），实机走查校。
- **四组内容版式**：① **服务** = 两开关同一行；② **使用教程** = pw-lines bullet 行组 + **配置块**（见下）；③ **功能列表** = 只读 8 / 写入 9 两行汇总（17 工具不逐条列，防组区过长）；④ **路径** = 服务地址（动态端口）+ 端口文件。按钮行 = **左件运行状态 + 右件「关闭」**（cancel）——无安装/卸载钮（「真安装动作 = 写 Agent 配置」，本轮展示+复制，一键写配置属远期项）。
- **开关行口径（同日用户调整轮定：两开关同一行，省纵向空间）**：行内两开关组 gap 12；单开关组内 = SwitchButton 左 + 标签右 gap 8（沿退役 SettingsModal 定案），标签 13/18 二级。「允许写入」在「MCP 服务」关时禁用（SwitchButton disabled 仅去交互无视觉差，§24 稿未画禁用态）。
- **运行状态 = 按钮行左件（同日用户调整轮定，挪左下角）**：圆点 8×8 实心（形态参 组件/卡片/文件卡片-字体 安装按钮圆角 99；尺寸 = 按钮行 38 配 13/18 文字的指示点档）——**联通 = `--n-success` 状态/成功色，断开/读取中 = `--n-l4` 四级灰**（用户定色档）；状态文字 13/18 三级（运行中 · url / 已停止）。按钮行因此 = space-between（纯按钮稿的右对齐口径在本窗让位）。
