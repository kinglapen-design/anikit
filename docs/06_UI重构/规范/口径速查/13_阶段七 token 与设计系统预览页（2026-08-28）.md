# 13. 阶段七 token 与设计系统预览页（2026-08-28）



- **新 token 一律 `--n-` 前缀**（--n-brand / --n-g1~6 / --n-l1~4 / --n-space-* / --n-radius-* / --n-dur-* …），唯一源头 = `docs/06_UI重构/Design Token/Token.md`；旧体系变量（--c1~5 / --text-* / --brand 等）为 legacy 块**禁新增引用**——新组件只许吃 --n- token，`Token.md` 没有的数值先补 token（问用户），不自创。
- **换算口径**：背景模糊 = figma 值减半（80→40 / 250→125，主窗口稿导出实证）；投影 / 内阴影照 figma-css 导出原值不转换；渐变角度稿未注明暂按 180deg。
- **设计系统预览页**（`src/preview/`，验收面）：DEV + `#design-system` 哈希进入（动态 import 不进生产）；组件新增 / 扩展 / 改样式同次进预览页（ui-refactor 第 7 条）。
- **`--n-font-mono` 中文回退 = 雅黑**（2026-08-29 走查）：链 = `"Fira Mono", Consolas, "Microsoft YaHei UI", "Microsoft YaHei", sans-serif`——原链末位裸 `monospace` 在 Windows 落宋体，数字档行里的中文（「个文件」等）变宋体是错误信号。
