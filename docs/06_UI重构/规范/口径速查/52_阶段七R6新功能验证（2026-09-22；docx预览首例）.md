# 52 阶段七 R6 新功能验证（2026-09-22；docx 预览首例）

> R5 注册表化（§43）的验收轮：以「新增 docx 预览」实测扩展性，验收标准 = 新 kind 只动自己文件夹 + 一行注册不动主线；动了即回头补架构。本节目的：① 记录验证结论与本轮消除的两个摩擦点；② 给下一种预览格式（xlsx / pptx / 3D / 插件格式）一份接入清单。

## 验证结论（首例 docx）

- **注册表范式成立**：`src/lib/previewSpecs/docx.ts`（spec 文件）+ index.ts 一行注册 + `src/components/PreviewDocx.vue`（渲染组件）——宿主 PreviewPanel 分发零改动，行为与 R5 承诺一致。
- **发现并消除两个排除式主线摩擦点**（若不改，每个新 kind 都要回宿主登记 = 隐性主线改动）：
  1. **PreviewPanel `showImg` 否定式排除清单**（`kind !== "video" && kind !== "audio" && …`）→ 改白名单 `["image", "sequence", "anim"]`（宿主基建三分支）。错误信号：新 kind 漏加排除时 `loadAsset` 预置的 thumbPath 会让格式图标缩略图盖在组件上（img 与组件同屏）。
  2. **PreviewTitleBar「默认应用打开」kind 列举**（`isSource || kind === 'other' || …`）→ 改判定式 `(!viewable && kind !== 'audio') || isSource || playAssetId`。语义：查看器媒体与 audio（APP 内播放完备）以外的 kind 恒有外部打开入口，新 kind 默认获得。
- **剩余必动主线（认定可接受，非摩擦）**：`preview.ts` 的 `PreviewKind` 联合加成员 + `loadAsset` 分派链加一支（数据分派涉及 ws 降级 / 序列帧 / 动图 / 伴生代理优先级，属业务路由不属渲染分发）；`formatBadge.ts` 扩展名表 + 判定函数一组。下一种格式仍按此清单走。

## 新预览 kind 接入清单（docx 实测路径）

1. **PRD 先改**（硬性边界）：04_文件预览.md 对应格式条补实现定案（kind 名 / 渲染口径 / 只读或可编辑 / 缩略图口径 / ws 降级口径）。
2. 后端（如需内容提取）：`services/{fmt}.rs`（解析 + 单测，输出结构 derive Serialize camelCase）→ `commands/{fmt}.rs`（命令 = `locate_asset` + 格式门，模板 `commands/text.rs`）→ services/commands `mod.rs` 各一行 → `lib.rs` `generate_handler!` 一行。自定义命令无 capabilities 登记（ACL 只管插件命令）。
3. 前端：`formatBadge.ts` 扩展名表 + `isXxxExt()` → `preview.ts` kind 联合 + loadAsset 分支（ws 合成项默认降级 other，与 font/text 同口径）→ `lib/{fmt}Ops.ts` invoke 封装 → `components/Preview{Xxx}.vue`（无 props 自管数据，loadedId 守卫竞态，排版复用既有口径）→ `previewSpecs/{fmt}.ts` + index.ts 一行注册。
4. 免查项（判定式已覆盖，新 kind 自动正确）：showImg 白名单（不渲染 img）、viewable / hasPlayBar（无缩放组 / 播放条）、标题栏「默认应用打开」（自动出现）。barSpecs 未注册 = 无播放条；cardSpecs 未注册 = general 卡片 + 无悬停层。
5. 验证：cargo test（解析单测）+ pnpm typecheck + CDP 探针（模板 `tools/cdp-docx-preview-probe.py`：结构断言 / showImg 白名单 / 打开按钮接线 / 既有 kind 回归）。

## docx 本轮口径（UI 部分）

- 排版复用 md 渲染态档（padding 24/32、字号 fs-md-body、行高 1.8、h1 1.7em / h2 1.4em / h3 1.15em、字色 l2）；run 粗斜 = span .b/.i（font-weight 700 / italic）；列表项 = bullet "•"（l3 色）+ 1.6em 悬挂缩进；空行 = 无 run 段落 nbsp 占位；截断 / 空文档提示 = 说明文字档 l3；读取失败 = error-text 居中底部（同 PreviewPanel 口径）。
- 只读不编辑，无可保存态；user-select: text（stage 全局 none 覆盖回，同文本预览）。
- 设计陈列室「此文件不支持预览」展区样例格式由 docx 改 zip（docx 已支持预览，展区语义保鲜）。
