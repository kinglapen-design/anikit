# 63. 标题 item 折叠热区收窄（2026-10-02 用户实机定；中间列表容器收文字区 + 抓手随热区）

## 定案

SectionTitle 新增 `hotZone: "bar" | "lead"`（默认 `bar`）：

- **bar（默认）** = 整行点击折叠——左侧边栏（LibraryView / WorkspaceTree）、右侧详情（TabLinks）、移动弹窗（MovePanel）等窄容器维持不变，用户明确「侧边栏还好」。
- **lead** = 折叠热区收到文字区（标题 / 数量 / 展开钮）——**中间列表容器全部标题一律此档**：FolderStrip「文件夹」、ArchiveStrip「档案」、InboxDiskSection「工程文件」、AssetGrid「内容/已导入」、AssetGrid 分组标题（原位 + sticky 两层）。

## 缘由（错误信号）

中间列表容器的分组标题是满宽横条、右侧大片空白，热区覆盖整行时点空白（想在卡片区落点 / 框选起手）直接折叠分组，误触频发；侧栏标题行短、空白少，无此问题。

## 实现口径

- 组件内根节点点击闸 `hotZone === 'bar'`、`.lead` 点击闸 `hotZone === 'lead'`；展开钮自带 `@click.stop` 两档不重复触发。行空白点击 = 落空 no-op（不下发框选 / 取消选中，本次不做行为扩张）。
- **抓手指针收窄到热区**（同日二轮用户定）：`cursor: grab` 只在真正热区出现——bar 档 = 整行、lead 档 = 仅 `.lead` 文字区；热区外一律普通指针（行空白出抓手误导「以为能拖拽」）。hover 行现展开钮 / 动作组维持稿口径不变。
- 展开钮热区外扩（`::after` 左 -6 余 -4）不变，文字区点击实际覆盖 = 标题文字 + 数量 + 展开钮外扩带。
- 探针：`cdp-content-container-probe.py` T7c/d（空白普通指针 / 文字区抓手）+ T12b/c/d 真实鼠标点击断言（JS `.click()` 不走命中测试，测不到热区收窄——必须 Input.dispatchMouseEvent）。
