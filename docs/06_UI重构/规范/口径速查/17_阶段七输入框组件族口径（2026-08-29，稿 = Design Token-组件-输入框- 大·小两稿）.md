# 17. 阶段七输入框组件族口径（2026-08-29，稿 = Design Token/组件/输入框/ 大·小两稿）


- **组件位置 = `src/components/inputs/`**：TextInput 两稿合一（size：lg / sm）；与旧 AppInput 并存，业务接入随面板重构轮替换。
- **lg = 高 34 / padding 8/12 / 常态描边 通用三级；sm = 高 26 / padding 4/12 / 常态描边 亮色/半透明-3**。**文字一律左对齐**（2026-09-21 用户定「所有输入全部左对齐」——sm 稿 justify-content center 年/月/日小框语境特化废，§46）。底色通用二级 + 圆角 8，宽度 100% 随父容器（稿值 240/55 = figma 实例语境）。
- **文字 = 正文档 13/18 亮色/二级；占位符 = 亮色/四级（2026-08-29 用户定，稿未写）**。
- **聚焦 = 亮色/半透明-1 描边，双层伪元素 inset 0（同卡片线条方案，§16）**：`::after` 常态层瞬时、`::before` 聚焦层 opacity 过渡 150ms（聚焦不做颜色过渡，踩坑 036）；壳 + 内嵌透明 input 结构（`focus-within` 驱动，expose focus/select 转发）。
- **hover 稿无 → 不做；禁用态稿未画 → 属性透传不改视觉**（同按钮族口径，记 09 待办不自创）。
- **`focusable=false` = 聚焦描边不显（2026-08-31 用户定）**：仅快速访问固定入口名称框用——亮聚焦边误导人以为能输入；**文件夹/文件名称框保留聚焦态**（改名语义上可输入，勿按「readonly 一律禁聚焦边」全局收口——同日被用户纠正）；readonly 本身行为不变（仍可聚焦选中）。
