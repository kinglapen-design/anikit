# 2. 滚轮（滚动条）


- **纵向 = `ScrollThumb` 悬浮件**（悬停显隐）：滚动容器挂 `.kit-scroll` + relative 包裹层 + `<ScrollThumb :body="ref" />`。**禁止**：原生恒显 / `scrollbar-gutter` 占位 / 容器 border 占位 / **"padding + gutter 凑边距"**（6+6=12、10+6=16 这种凑法就是错误信号——主窗口边距就是纯 padding 16）。
- **横向 = `.kit-scroll-x`** 原生 6px 实色胶囊（C4/C5），容器 `padding-bottom: 6` 容纳。
- 悬浮滚轮贴边不压弹窗框的前提 = 弹窗真 border（见 §1）；**内容区内的分隔线**被滚轮压时，包裹层 `::after` 上层补画（z-index 11、pointer-events none）。
- 滚轮 thumb ~~用**实色** C4/C5~~（透明色与线条交叉叠色，2026-08-10 定案作废）→ **色档改定 = 通用/四级常态、通用/六级 hover**（2026-09-06 用户定，实机走查第一批末项：旧 C4/C5（#212323/#282a2a）在 g3 底上几乎不可见；ScrollThumb 组件层已落地，全局使用方同生效）。
- **实机走查第一批末项全量口径（2026-09-06 用户引用；色档已落地，布局整改未完成挂走查项）**：所有滚动条**紧贴窗口右边、不挤压内容**（包裹层负 margin 扩到窗口边 + 滚动容器补回 padding 的手法，首例 = 插件详情子窗口 `.pw-scroll-wrap`）/ **hover 到对应窗口时才出现**（ScrollThumb 悬停显隐本即此语义）/ 应用至所有（卡片 / 二级面板 / 模态窗口——全场景排查整改未做，归实机走查该条目）。
- **拖拽滚轮期间禁窗口拉伸（2026-09-06 五轮，useSideThumb 组件层）**：onThumbDown `setResizable(false)` / onUp 恢复 + pointercancel / blur / 组件卸载三路兜底（防永禁）；capabilities 须含 `core:window:allow-set-resizable`；invoke 失败静默不阻断。缘由 = 滚轮贴窗口右缘后与系统边缘拉伸热区重叠（§29 五轮②）。
- **贴右缘全场景落地（2026-09-13 实机走查整改轮）**：**通用规则 = thumb 贴宿主面板/弹窗右缘的 padding 区，不压内容**——包裹层右缘与宿主右缘有距离 P 时挂「负 margin -P + 滚动容器 padding-right +P」对子（模板 = AnimatePluginWindow `.pw-scroll-wrap`），且**包裹层与宿主缘之间不能有 overflow 裁剪祖先**（有就把对子上移到裁剪祖先一层）。落地账：① **AppModal 全局对子**（`.content` −24/+24，一次覆盖全部旧弹窗；壳 padding 被弹窗改 0 的在该弹窗 `:deep(.content)` 归零 margin-right，`padding: 0 24` 内缩型弹窗（Duplicate/BlockManage/GroupManage）改为对子下沉到内层包裹一层）+ `.content` 兜底滚轮补 ScrollThumb（`.app-modal` relative 锚，此前无指示）；② **AppMenu 超高菜单补滚轮 = 锚点包裹层 `.app-menu-anchor`**（fixed/z-index 上移本层 shrink-wrap，滚轮与滚动容器**平级**——放容器内会随内容滚动漂移；组外判定改用包裹层，**flyout 的滚轮也不算组外**（按其锚点是否包住组内元素判定，防拖 flyout 滚轮误关整组）；PluginListPanel 壳覆盖随之改 `:deep` 口径）；③ alert 变体弹窗（FailedList/OrphanInfos）不在 `.content` 内，各自 `.scroll-wrap` 对子；④ **漏网容器补滚轮**：PropsDialog 属性池（包裹 = `.pd-body` relative）、NotesPop 左列表（贴列表自身右缘，右侧是编辑区不贴弹层缘）；⑤ **色档扫尾**：AssetGrid `.grid-thumb` 旧 C4/C5 与 FileCard 文本卡 `.fc-text-thumb` g3/g5 统一 **g4/g6**（稿「hover-滚动条」档被全局定案覆盖）；⑥ 八宿主（SidebarLeft 树 / DetailSections / PickerPanel / MovePanel / SequencePack / PreviewFont / PreviewText / PluginListPanel）核实「padding 自承于滚动容器 = thumb 本已贴缘」不动。
