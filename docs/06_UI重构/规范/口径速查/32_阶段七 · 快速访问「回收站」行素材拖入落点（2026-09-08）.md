# 32. 阶段七 · 快速访问「回收站」行素材拖入落点（2026-09-08）

2026-09-08 用户定：**素材卡片拖到左栏快速访问「回收站」行 = 丢到回收站**，免每次右键/ Del——回收站行自此成为拖拽引擎落点。

- **落点判定（dragOperation.updateDropTarget）**：回收站行带专属性 `data-quick-drop="recycle"`（LibraryView TreeRowItem 模板直挂）——**不用 `data-folder-id`**，防 App.vue `onDrop` 系统拖入导入的 `closest("[data-folder-id]")` 误判导入目标。仅素材拖拽（kind=asset）出落点；**文件夹拖拽不落**（删除文件夹 = 素材移未分类，语义不同，给落点是误导）；Ctrl 无语义忽略。
- **落点动作**：`dropAssetsToRecycle` = `deletePlacements(items)` 默认 action "recycle"——与 Del 键同路径（可撤销，toast「丢到回收站 N 个项目」自带反馈）。
- **高亮**：`dragView.quickRecycle` 布尔（resetIndicators 一并清），LibraryView 回收站行 `:drop-zone="'into'"`——TreeRowItem 既有并入高亮（品牌/半透明填充 + 2px 品牌描边），组件零改动。
- **suppressClick 闸**：LibraryView `onQuickSelect` 补 `dragView.suppressClick` 判定（此前没有——行本无落点，拖完松手的紧随 click 会误导航切到回收站视口；与树 item / 区块标题同口径）。
- **不冲突面**：回收站视口内卡片本禁拖（gridPointerDown 守卫）；选择模式（picker.active）拖拽本禁用。
