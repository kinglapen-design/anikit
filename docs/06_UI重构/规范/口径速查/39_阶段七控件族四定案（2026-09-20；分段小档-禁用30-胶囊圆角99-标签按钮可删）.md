# 39 阶段七控件族四定案（2026-09-20；分段小档 / 禁用 30% / 胶囊圆角 99 / 标签按钮可删）

> 2026-09-20 R2 第一刀遗留四问的用户定案，控件族通用，后续新件照此。

## ① SegmentedControl small 档（28 高）

稿 = `Design Token/布局/工具栏展开窗口/查看方式/02_布局方式.md`（03_排序方式 / 04_时间码同）。`size="sm"`（仅 text 型）：容器 28 高 / padding 2 / gap 4 / g2 底 / 圆角 8；段 24 高 / padding 4/8 / 圆角 6 / **次要文字-加粗 12/16**；选中 = 亮色/半透明-1 + 立体感-通用 + 文字升一级。滑块 thumb 定位随档（padding md 4 / sm 2）。落地：ViewOptionsMenu 三段全接 sm（268/134/134 稿宽），行高回 53 稿值。

## ② 禁用态 = 30% 透明度（控件族通用）

用户原话「禁用态给 30% 透明度」——与 §5 既有「跳过/取消勾选压暗 30%」同档，不新造。已落地：SwitchButton / IconButton / SegmentedControl（`:disabled` / `.disabled` → `opacity: 0.3` + 不响应）。此前「禁用稿未给仅去交互」的注释口径作废。Checkbox / Radio / ActionButton 暂无 disabled 需求，接入时照此档。

## ③ 胶囊圆角 = `--n-radius-pill: 99px`

用户原话「能直接用 99 吗？不能就根据实际高度/2」——CSS border-radius 超半高自动截半，99px 即胶囊。Token.md 4_圆角 已补档；tokens.css 新块入档，legacy `--radius-pill`（999px）定义已删。消费方全换：ScrollThumb / AssetGrid / SetupWizard / SwitchButton（原 999px 字面量）。

## ④ TagButton 扩 removable（烧 AppTag）

用户原话「扩充点击和删除」——`removable` + `@remove`：hover 删除钮（clear 12）右至左滑入（宽 0→12 + 左距 6，150ms，沿旧 AppTag 既定交互）；removable 时根元素换 span（button 不可嵌 button）。PropsDialog 两处（拥有 chips / 属性池 chips）已迁，AppTag 已烧删。旧 AppTag 的 readonly 展示态不再单立——纯陈列就不挂 removable。

## ⑤ 附：ViewOptionsMenu 面板换代（同日，稿 = 布局/工具栏展开窗口/查看方式 01~06）

面板本体全量换 `--n-`：404 宽 / padding 24 / 大阴影覆盖（AppMenu 默认小阴影，`:deep(.app-menu)` 覆盖为 `--n-shadow-lg`）；行标题 16/22 按钮文字-大**亮色/三级**（稿值 #808080——2026-08-11「标题用常态色」是旧稿口径，随新稿作废）；行序与行高按稿：布局 40（padding-bottom 12）/ 排序·时间码 52（顶 1px g5 线）/ 显示开关组 gap 12 行 22 / 自动播放组 gap 8 行 28；**picker 下拉框 = 86×28 / g6 底 / 1px 亮色-半透明-3 真 border / 圆角 6 / 次要文字-加粗 12/16 亮色/二级 / 箭头 14 三级**，hover 档稿未给 = 就近描边升半透明-2（待实机走查）。「显示自定义数据」禁用行 = 文字 30% + 开关自带禁用档。已进 preview（浮层展区真实实例——ui store 在预览环境纯内存不写回）。
