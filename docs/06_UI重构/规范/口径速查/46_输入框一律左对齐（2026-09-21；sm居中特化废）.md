# 46 输入框一律左对齐（2026-09-21；sm 居中特化废）

> 用户实机指 preview 展区（编辑描述 / 属性标签 / 添加分组等）「所有的输入全部改成左对齐。现在很多居中」。§40 挂账的「TextInput sm 文字居中观感差」就此定案。

## 定案与落地

**所有输入框文字一律左对齐**，无例外（含日期筛选年/月/日小框——sm 稿 justify-content center 的原始语境也一并改）。

- 基件一处改：`TextInput.vue` 删 `.ti-root.sm .ti-inner { text-align: center }`，§17 的 sm 居中特化废。影响面 = 全部 sm 消费方自动转正：DescEditDialog 标题/内容框、GroupEditDialog / GroupManageDialog / BlockManageRow 行内名称框、筛选栏日期小框等。
- 冗余覆写清理：GroupManageDialog 名称框 `:deep(.ti-inner) text-align: left`（§42 衍生覆盖）删——左对齐归基件统一口径，该件只留 30 高 / g4 底 / 文字一级 三处稿值提权。
- preview 同步：PreviewInputs sm 展区标题与占位文案「居中」改「左对齐」。

## 边界（不动的居中）

非输入的居中一律不动：字体预览 H1（§42 稿值）、向导步骤标题、空态提示文字、拖拽幽灵、卡片/悬浮栏布局居中。TermChipsInput 手写 input 本就无居中样式（chips 容器内联自适应观感非居中）；GroupRulesEditor 下拉钮 `.val` 的 text-align:left 是对抗 button 默认居中，保留。
