## 链接扫描 = 两段式（与重复扫描同构，2026-10-16 改版定案）

- **屏 1 选组**：组级复选「N 个链接文件」默认全选（用户单个取消，选中 = 本组进归并）+ 行尾红 X 纯前端摘组；卡片横排**只看不动**（首列原始文件卡 + 链接卡 = 链接显示名 + 所在文件夹 + 链接徽章）。底部「已选择 N 个文件 · 将清除 M 个位置」（M = Σ(组内位置数 - 1)，保留者恒存 1）。
- **屏 2 选保留者**（970，合并前确认）：左组列表 + 右保留者 radio 单选——候选行 = origin 行在前（★ original-file-badge）+ 全部链接（linked-file-badge，14 亮色/一级，`.kbadge`），行 = 缩略图 + 显示名 + 所在文件夹 chip；**默认选中 = 当前 origin**（无活 origin 退首条链接）。
- **归并 = 每组保留者成为/保持唯一 origin，其余位置（链接 + 被替换的旧 origin）全部进回收站**——资产只剩一个位置；`consolidate_asset_links` 单命令（原语编排：delete_placements recycle 清余位 + set_placement_origin 幂等提升，name 恒携带精确到行），整批一次 undo 步，物理不动。
- **逐条删链接归链接管理**（Ctrl+J / 详情链接区块），本弹窗只做整组归并（用户原话定界）。
- 无结果不弹窗 toast「未发现链接文件」（重复扫描同口径）。
