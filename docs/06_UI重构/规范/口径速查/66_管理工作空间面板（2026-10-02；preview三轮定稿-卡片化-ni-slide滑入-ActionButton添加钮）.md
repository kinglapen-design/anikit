# 66. 管理工作空间面板（2026-10-02 落地；preview 三轮走查定稿——卡片化 + ni-slide 滑入操作组 + ActionButton 添加钮）

> 「管理工作空间」面板（菜单「仓库 ▸ 管理工作空间」）的形态与操作口径。数据源 = 链接双向台账（方向 b `links` + 方向 a′ `portals`，接口 20）；业务语义见 PRD 02「管理工作空间面板」节。设计稿 = PreviewModals「管理工作空间」组（静态复刻壳 + mock 真实弹出），本体 = `components/WsManageDialog.vue`。

## 定案

- **壳**：BaseModal framed **640**（分组管理先例——路径长文本需要宽度）；**无底部按钮行，即时生效**（§61 信息查看管理面板同口径——管理操作直发生，删除走 confirmPrompt 警告确认）。
- **结构 = 双区块一屏总览**（不用 tab——链接全景一屏看全）：SectionTitle block「链接进来的文件夹 / N」「链出去的文件夹 / N」+ 区块底添加钮；**两区块分界 = 父 gap 24 + 1px g5 顶线 + 线后 24 留白**（一轮贴排被用户否「分不清什么是什么」）。
- **卡片化分层**（二轮用户定「用颜色层级包一下」）：链进来每门一张行卡、链出去每文件夹一张组卡——**g4 底 + 1px g5 描边 + 圆角 8**（ni-card 升一档：壳 g3 上卡片 g4）；行卡 hover g5 底 g6 描边；卡组间 gap 8。
- **操作组 = 污染文件 item 同款 hover 滑入**（items.css `ni-hover` / `ni-slide` 推挤式直接复用）：常态零宽不占位，hover 从右缘滑入；钮 = 18 盒常态四级 hover 二级（`.act` 同款）。链进来行卡三钮 = 重新定位 / 在资源管理器中显示 / 删除链接；链出去子行两钮 = 显示 / 删除入口；组卡首行「添加入口」滑入（组卡 hover 直达子选择器只出首行钮，**不波及子行各自滑入组**——组卡不挂 ni-hover 类的原因）。
- **添加钮 = ActionButton solid md 真件**（三轮用户定「按钮用这种按钮的样式」，指展区 ActionButton 排）+ 前置图标 add-small；宽 100% 整行（lg/md 档自带）；说明文字挪 title。
- **组卡内**：首行 36（文件夹图标 18 + 名 13/18 一级，底 1px g5 与子行分隔）+ 入口子行 30（缩进 26 对齐组首行名；hover g5 底圆角 6 嵌套小底）。
- **断链 / 门没了**：链进来断链 = **整卡** dimmed 0.4 置灰 + 名后 warning-small 14（§65 同档）；链出去门没了 = 子行路径置灰 + warning 徽章 + 操作只留「删除记录」（显示钮摘除）；文件夹本体没了（relOk=false）= 组首行置灰。
- **空态**：区块无行 = 引导文案一行（次要文字 12/16 三级，指路右键菜单入口），添加钮照常。

## 实现口径

- 行族 / 卡组样式随组件沉淀（WsManageDialog scoped，wm- 前缀 = preview pv-ws- 稿搬入）；preview 静态复刻壳留作常态陈列（口径变更与组件同步）。
- 链出去「添加」「从零发起」的交互流（目录选择器 title / 两步选择 / 挂根）见 PRD 02 与接口 20；面板操作后重拉 `ws_link_overview`（台账对账 = 后端现场探测，无前端缓存态）。
- preview 真实弹出 = mock props 注入（`mock?: WsLinkOverview`）——mock 态操作钮点击不动作（组件内 isMock 早退），只演示 hover 滑入。
