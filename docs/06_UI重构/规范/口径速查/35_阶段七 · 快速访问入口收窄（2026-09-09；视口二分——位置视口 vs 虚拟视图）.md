# 35. 阶段七 · 快速访问入口收窄（2026-09-09；视口二分——位置视口 vs 虚拟视图）

2026-09-09 用户讨论定案（四轮对话），PRD 已同步 [02_文件整理/15_快速访问视图](../../../01_项目-PRD/02_文件整理/15_快速访问视图.md) 与 [02-13 基础操作](../../../01_项目-PRD/02_文件整理/13_基础操作.md)（删除组拆开、未分类粘贴豁免）。

**核心定案：快速访问六视口不是一类东西**——「全部」自己都不算一个位置，在里面移动文件 = 黑箱（用户不知从何移到何）；但删除不一样（"这东西要不要"一眼可辨，不用在乎在哪）。由此二分：

- **位置视口 = 未分类 / 自动导入**（真实落点）：位置级操作全开放。未分类 = **候车区总入口**（导入 / 新建文档 / 粘贴 / 拖入全放开，落点 root 所见即所得）；自动导入维持 09-08 禁手动添加（走自动通道），移出归位保留。
- **虚拟视图 = 全部 / 最近使用 / 缩略图**（不是位置）：**位置级与落点类全禁**——移动 / 剪切 / 创建副本 / 粘贴两项 / 导入 / 新建文档 / 从文件夹中移除 / **卡片禁拖出**（拖出 = 黑箱移动同病）。**留资产级与所见即所得**：打开外发全组 / 链接管理与位置导航 / 复制（文件·数据·缩略图）/ 导出 / **重命名**（用户定：卡片上所见即所得——缩略图视口改 hidden 伴生图名配工程名、最近使用顺手改名）/ 标签 / 描述 / 缩略图绑定组 / 设为原始（条件出现照旧）。
- **删除组自此拆开**（修订 08-18"同口径"）：「丢到回收站」全留（资产判断，多位置条目右键哪条丢哪条）；「从文件夹中移除」虚拟视图不出现（名字即位置语义）。
- **占位项不列**（业务未立项：新标签页 / 添加资源库 / AI 工具集 / 提示词 / 置顶 / Animate 生成缩略图）——快速访问右键收窄就是为了菜单变短；菜单栏维持"入口汇总恒列置灰"口径不动。
- **新建文件夹 / 档案六视口一律禁**（快速访问无文件夹概念，建到根级也看不见）；**「全部」导入 / 新建封堵**（推翻 09-08"全部/未分类允许"半句：全部不是位置，落点必借道）。
- **回收站**维持 §25 定案（全列 + 四项写能力占位禁用），不在本轮变动。

## 实现（同一判定多处共用）

- **`content.isNoImportView` 扩五视口**：quick:\* 且 ≠ uncategorized（全部 / 最近使用 / 自动导入 / 缩略图 / 回收站）——右键收窄 / 拖拽拒入 / 菜单栏导入+新建文档组 / Ctrl+V 系统剪贴板 / `pickImportPaths` 兜底，五处同判定。未分类豁免。
- **`content.isVirtualView` 新**：quick:all / recent / thumbnail——右键卡收窄（`assetCardSpec` 分流 `virtualAssetCardSpec`）/ 快捷键（Ctrl+Y·X·D·Shift+Del 禁）/ 拖拽源（`dragOperation` 卡片禁拖出，与回收站同守卫）/ 菜单栏整理「移动」/ 编辑菜单（剪切·副本·移除置灰）。
- **`content.isQuickView` 新**：quick:\* 六视口——菜单栏新建文件夹 / 档案整组置灰。
- **粘贴落点 `pasteTarget`**：folder: → 当前文件夹；**quick:uncategorized → "root"（放开）**；其余 toast「当前视口不支持粘贴」。编辑菜单粘贴两项置灰挂 isNoImportView（顺带补上回收站漏判）。
- **空白菜单分流**（gridDispatch）：全部降 `scanOnlySpec`（只扫描两项）；未分类保持 `quickFullSpec`（去新建两项，留导入 / 新建文档 / 粘贴 / 添加链接 / 扫描）。
- **空态导入双钮**（AssetGrid `folderEmpty`）范围：folder: + **quick:uncategorized**（原 quick:all——全部禁导入，库空引导挪未分类）。
- **拒入弹窗**文案列五视口名 + 引导「文件夹视口或未分类」。
- 文件卡收窄集导出**拍平一级**「导出到本地磁盘」（素材包占位不列，不留空壳二级）。
