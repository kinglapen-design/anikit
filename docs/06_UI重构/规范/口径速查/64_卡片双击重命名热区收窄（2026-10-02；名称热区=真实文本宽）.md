# 64. 卡片双击重命名热区收窄（2026-10-02 用户实机定；名称热区 = 真实文本宽）

## 定案

卡片「双击名称 = 重命名」的热区一律收窄到**真实标题文本区域**（名称 span 收缩到文本宽），不再覆盖名称行整宽：

- **FolderCard**（`.fd-name`）：`flex: 1` → `flex: 0 1 auto` + `max-width: 100%`；`.fd-head` 补 `justify-content: space-between`——**图标恒右缘的站位不变，视觉零变化**。
- **FileCard**（`.kc-name`，cards.css）：column 罩层默认 stretch 撑满 → `align-self: flex-start` + `max-width: 100%`。
- **ArchiveCard**（`.ar-name`）：同上。
- **ListRowCard**（`.lr-name`）：本就内容宽（flex item 无 grow），无需改动，探针登记防回归。

## 缘由（错误信号）

名称 span 被拉伸成整行宽：双击文件夹卡进入时稍偏文字右侧就落入 `.fd-name` 的 `@dblclick.stop` → 进入变重命名，文件夹卡最高频（「双击进去」是主操作）。

## 实现口径

- 收窄后行空白双击 = 冒泡到卡片根走既有主操作（文件夹/档案 = 进入、文件卡 = 打开预览）；v-tip 热区同步收窄到文本。
- FileCard 罩层 `pointer-events: none` 口径随之精确化：名称 span 外空白穿透可 scrub（旧「文本行不 scrub」口径 2026-09-08 精确化到文本行、本轮再到文本宽）。
- 长名截断不受影响：`min-width: 0` / `max-width: 100%` 保 ellipsis。
- 重命名其它入口不动：右键菜单「重命名」、命名输入框仍整宽。
- 探针：`cdp-content-container-probe.py` T6e/T8d/T9e/T14f（elementFromPoint 命中判定：行空白不命中名称 span + 文本命中 + 宽度断言）+ T8e（真实双击文本 → 命名输入框现 / Esc 退出）。
