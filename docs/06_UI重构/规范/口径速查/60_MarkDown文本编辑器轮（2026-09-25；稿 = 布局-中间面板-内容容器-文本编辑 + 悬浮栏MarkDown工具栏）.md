- **范围**：md 预览态排版按稿定稿 + md 编辑器落地（PRD 04-04 条 6「源码编辑 + 渲染预览」兑现，5.6「md 只读」阶段状态作废）+ 悬浮栏 MarkDown 工具栏业务接入（§18 遗留「随预览族轮」本轮闭环）。探针 = `tools/cdp-md-editor-probe.py`（8 场景 A-H 全绿：贴稿 computed / toggle 回写 / 复制 / 编辑态切换 / 工具栏动作 / Esc 退出 / png 回归 / Checkbox 抽象回归）。

- **编辑器形态 = 预览态 ↔ 编辑态双态**（不引入所见即所得，PRD 口径）：预览态点击正文（复制钮 / 复选框分流外）进编辑态 = 全文源码 textarea（Fira Mono + 版心同渲染 84 + **底 66 让位悬浮栏**——§18 遮挡补偿口径 12+42+12）；Esc / Ctrl+Enter 退出（先 flush 落盘）。**渲染源 = draft 非 source**（toggle / 编辑实时反映；source 仍保存基准）。保存管线与 txt 同：防抖 1s / loadedId 竞态守卫 / 不进 undo。

- **19 动作 = `lib/mdEdit.ts` 纯函数**（UI 零业务逻辑）：行首类（h1-h6 toggle / body 剥全部前缀 / quote·ul·ol·task toggle）逐行作用于选区覆盖行；包裹类（bold `**` / italic `*` / strike `~~` / code-inline `` ` `` / link）再点剥除；插入类（table / code-block / divider）模板 + 光标预置。工具栏「正文」钮 = 剥行首全部块标记。
- **探针坑**：同 URL 换 hash 不触发重载（main.ts bootstrap 仅启动时判 `#design-system` 一次）——预览页场景验证须先 navigate about:blank 再进目标 hash；**vite dev watcher 静默丢变更**（探针 FAIL 数据 = 旧样式，curl `/src/styles/markdown.css` 实证 dev 照发旧版）——探针前 curl 对版本，不对杀 dev 进程重启（2026-08-30 九轮「残留 dev 跑旧样式」同族）；**探针自启 dev 跑后必须收尸**（当日实证：探针前重启的 `pnpm dev` 留在 5373 没杀，用户随后 `pnpm tauri dev` 的 beforeDevCommand 撞端口起不来——重启 dev 探针收尾时 taskkill 归还端口）。
- **走查修订（2026-09-25 用户实机四条）**：① **编辑撤销 = `lib/mdHistory` 自实现快照栈**（textarea 原生撤销遇程序化修改——工具栏动作 / 复选框 toggle / v-model 同步——即断栈，用户报「没有接入撤销」）：组件会话级，编辑态 Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 驱动（preventDefault 禁原生栈；全局 Ctrl+Z 本对输入框让位不冲突）；记录三点 = `@input` 键入（800ms 窗连续合并一步）/ 工具栏动作（独立步）/ 复选框 toggle（独立步，编辑态可回撤）；与库撤销无关（「编辑不进 undo」口径不变）。② **任务列表对齐**：任务 li 不再额外缩进（与无序/有序同 content 左缘），复选框外挂 **marker 列**（`left: -20px` = 框 14 + 文距 6 组件 gap 档）——三列表文本列齐、标记列齐（用户「三个列表要对齐」）。③ **「返回预览」钮**：工具栏第五组单钮 = chevron-large 原样朝左（与预览工具栏返回钮同图标同语义，§22），`action "preview"` = exitEdit——编辑态回预览的可见出口（用户「怎么切换到预览」）；实时预览（分屏左码右渲）技术可行（rendered 本基于 draft 实时算）但 880 版心劈半太挤、分屏版式无稿，所见即所得 PRD 口径不做——先给可见出口，分屏若要另轮定版式。④ **19+1 钮全配悬停 tip**（IconButton title prop 走 v-tip，内容容器轮同口径）。**顺手**：chevron-large 烘焙 #808080 转 currentColor（命名对照十四批——2026-08-30 入库漏转，PreviewTitleBar 返回钮 / QuickNavButton 的 hover 升档一并治好）。
