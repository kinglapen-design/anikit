## 组件台账（烧减验收面，此后「哪里没改」看台账不看肉眼）

- 生成器 `tools/gen-component-inventory.mjs`（`pnpm inventory`）重扫 `src/components/` 全部组件，输出 `src/preview/inventory.generated.ts`（生成文件勿手改）；预览页首屏展区 `PreviewInventory.vue` 渲染。
- 状态四档徽标：**旧件待烧 legacy**（12 件，脚本内 LEGACY 表登记替代件，烧一件删一行）/ **零消费休眠 dead**（消费方 0 自动判）/ **业务件 business**（换代目标 = 组件内 legacy token 归零）/ **新体系 new**（新族八目录 + 脚本内 NEW_AT_ROOT 白名单）。
- 计数口径：消费方 = src/ 内 import 文件数（排除 src/preview）；legacy token = `var(--c1~5 / --text-* / --brand)` 引用数。底数 2026-09-20：旧件消费方共 93 处、组件内 legacy token 473 处（全 src 485）。
- 每烧一轮重跑 `pnpm inventory` 刷新台账；消费方清零才准删旧件。
- 进度快照（2026-09-20 R2 第一刀后）：144 件 = 新 66 / 业务 70 / 旧件 6（AppButton/IconButton/AppModal/AppInput/AppSearchBar/AppTag）/ 休眠 2；AppCheckbox/AppRadio/AppSegmented/AppSwitch 已烧删，AppMenu/ScrollThumb 查实已新体系归白名单。

## preview 全覆盖三新展区（R1）

- **业务弹窗 PreviewDialogs**：12 件全收。纯 props 不碰 store 的（FailedListDialog / PathErrorDialog）真实弹出；依赖 store 或挂载即 invoke 的一律 `pv-*-shell` 静态复刻，壳内嵌真实子件（DuplicateRow / DupScanGroupRow / GroupRulesEditor 等纯前端可交互的直接嵌真）。危险动作（RecycleConfirm 彻底删除）只静态陈列绝不真弹。
- **浮层与滚动 PreviewOverlays**：ContextMenu / AppMenu 真实实例（展区自带 ContextMenu 宿主 + 桩 spec 触发，action 全空操作）；HoverZoomOverlay 真实实例用 `ws:` 假 id + `wsPath=null` 桩资产天然豁免后端；HoverVideoLayer / HoverAudioLayer / HoverSequenceLayer 挂载即 invoke → 静态复刻控件铬（胶囊 / 播放条 / 波形高亮），媒体本体不演；ScrollThumb / FloatBarHost 真实实例（FloatBarHost 不传 panelId/viewKey = 搜索侧 store 全禁）。
- **独立窗口 PreviewWindows**：PreviewWindow / SetupWizard / PickerPanel 统一 pv-*-shell 静态复刻（沿 PreviewPlugins 惯例），壳内纯 props 驱动的子件嵌真实组件（向导三步骤件 / Pick 两 item 本地态可操作）。
