# 71. md 大纲栏（2026-10-15 定稿落地；用户看稿一轮定 = 一级标题加大加粗，其余照初案）

> 用户反馈 md 缺大纲、长文档查找困难（PRD 04_文件预览「md 大纲栏」）。交互参照 = 飞书文档大纲（左侧标题层级列表 / 点击跳转 / 当前节高亮）。样式无设计稿——preview 陈列稿一轮定稿（2026-10-15 用户看稿：**一级标题字号加大加粗，其他的没什么**），同日接生产。组件 = `components/MdOutline.vue`（纯展示件：清单 / 当前节喂入，点击抛 jump）；提取 = `lib/mdOutline.ts`（复用 markdown-it parse tokens——heading_open 自带层级 tag 与源码行号 map，与 kitLineMap 的 data-line-start 同口径；PreviewText 渲染与大纲共用同一次 parse 双消费）。

## 定稿口径

- **布局**：md 预览面板内左侧可开关栏——悬浮栏 MarkDown 工具栏**视图组「大纲」钮**切换（预览 / 编辑 / 分屏三态同支持）；**图标 collapse-sidebar 暂代占位**（2026-10-15 用户定「先随便找一个占位，最近几个业务图标都是占位的，到时候一起换」，待补源后换名）。开关态 = preview store `mdOutline`（会话级：切素材保持，关预览复位；FloatBarMarkdown 经 `requestMdAction("outline")` 翻转）。宽 **168**（设置面板左导航同宽，§70）；右缘 **1px g3 竖线**（md 分屏分割条同档；滚轮 hover 压线一小段 = 2026-08-13 主窗口统一口径，不补画）。壳 = PreviewText `.md-row > MdOutline + .md-col`（原列语境下移，ScrollThumb 锚 / 底部 66 补偿选择器随之下移）。
- **item**：26 高 / 圆角 6 / padding 4 8 / 正文 13/18 `--n-l2`（菜单 item 同档，§3）；**缩进 12/级**（8 + (level-1)×12 左 padding）；单行省略；**一级标题加大加粗** = `--n-fs-md-body` 15 + `--n-fw-bold`（定稿唯一条，行高行宽不变）。
- **状态**：hover 底 `--n-l-a3`（菜单 item hover 同档）；当前节 cur = 底 `--n-l-a2` + 文字 `--n-l1`（设置面板导航选中同口径）；选中态行不叠 hover（§3）。
- **空态**：「本文档没有标题」次要档 l3。
- **滚动**：kit-scroll + ScrollThumb（§2）；底 **66** 悬浮栏遮挡补偿（§18 同口径）；当前节自动滚进视野。
- **动画**：进场 150ms 缓出 + 8px 滑移（稿无数值就近套档，`mo-in` keyframes；v-if 关闭瞬时——出向无可过渡挂载点）。
- **跳转三态**：预览 = 渲染块按 `data-line-start="{line}"` 定位（行号同源唯一——每块起始行独占）滚顶 12 呼吸；编辑 = CM 光标落行首 + `EditorView.scrollIntoView(y:"start", yMargin 12)` + focus；分屏 = 右栏精确定位 + 左栏 CM 同步（**linkLock 墙钟锁 100ms** 防两侧互拽，typewriter 同口径）。点击先置当前节，反馈不等滚动事件。
- **当前节跟踪**：渲染体（预览 / 分屏右栏）= 最后一个「块顶 ≤ 滚动顶 + 24」的标题（阈值 = 版心上 padding 12 + 呼吸 12）；编辑态单栏 = CM 可视顶行（`lineBlockAtHeight`）同口径换算；**分屏只跟右栏**——左栏滚动经 linkScroll 带动右栏，事件链自然覆盖。形态切换 / 开关后 nextTick 重锚（v-show 归零恢复同拍）。
