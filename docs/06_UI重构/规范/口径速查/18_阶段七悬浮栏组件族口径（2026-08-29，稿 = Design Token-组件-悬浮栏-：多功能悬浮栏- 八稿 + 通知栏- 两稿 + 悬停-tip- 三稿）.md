- **宽度机制 = 壳宽唯一动画源（2026-08-29 十五轮走查定稿）**：模式根恒 `width: 100%` 随壳，内容右端件（筛选图标等）随壳边逐帧平滑移动——**原方案「模式根自持 250/450/max-content 宽度类 + 壳跟随」作废勿回退**：根类瞬时切换、只有壳在动画，聚焦/失焦时筛选按钮一帧瞬跳（用户实机实锤；错误信号：内容位移与壳宽不同步）。测量 = 模式根 inline `max-content` 探针同帧读 offsetWidth（设→读→还原不闪；切换交叉期跳过 `.fb-leave-active` 旧根测新根）；**搜索栏定值档 250 常态 / 450 聚焦不经探针（稿值）**，展开与其余模式探针实测；触发点 = 模式切换 / 搜索 expanded-change·focused-change（forceState / initialExpanded 挂载即上报镜像）/ fonts.ready；ready 类挂载 rAF 后开过渡防首帧闪；`width` prop 显式覆盖跳实测（帧条同宽组合）。模式内容 props/事件经 `$attrs` 透传（inheritAttrs: false）。**中心向两侧扩张 = 父容器居中即自动成立**（布局稿口径 = 中间面板底部居中：壳只动画 width，逐帧重排使左右缘对称外扩；探针实证聚焦/失焦全程壳中心 cx 恒定 ±0）——组件不做定位，定位归父容器。
- **切换动画参数 = 300ms 形态切换 + Y 位移 4px（2026-08-29 用户两轮定：先定 250 小位移，走查改 300 缓入缓出）**：稿只写「宽度平滑伸缩，功能按钮 Y 轴出场入场」未给数值；入场自下 +4→0 / 出场向上 0→-4 渐隐（Transition 同帧双挂载，离场 absolute 宽 100% 随壳）。**退场 = visible=false → width 0 + opacity 0**（稿 prose「宽度和透明度退场」）。
