# 19. 阶段七主窗口壳口径（7.1 十七轮骨架轮，2026-08-30；稿 = 布局/主窗口/）


- **窗口背景效果（2026-10-01 终局转向：弃云母保最大化动画，踩坑 071 四轮）**：主窗口 `transparent:false + backgroundColor:#1F1F1F`（不透明实底）+ `shadow:true`——**无云母、无整窗玻璃、WS_CAPTION 全程保留**。历史链：7.1 十七轮接云母（063 六轮：`ExtendFrame(-1)` 玻璃载体 + `set_effects(Mica)` + WebView2 背景透明）→ 玻璃 + tao 保留的 caption 让 DWM 把原生按钮画进窗内（最大化稳态/动画期/常态顶边三态穿帮）→ 09-08 三轮「动画前摘 caption」杀按钮，连带杀掉最大化/还原过渡动画（动画依附 caption）并衍生 079 → 四轮弃云母：按钮画布 = 玻璃（一轮实证撤玻璃按钮没了；Electron/VSCode 无边框 = 保 caption + 无玻璃 = 有动画无按钮），撤玻璃后 caption 全程保留，动画与无按钮兼得，079 的 rcWork 约束随摘 caption 体系一并撤除。**窗口主题锁深色保留**（2026-09-29：tao `update_theme` 对 preferred_theme 窗口不跟随系统，DWM 退化实底恒深色）。前端 = `get_window_fx_mode` 恒 solid，`.window` 基态实色 `--n-g-a1-solid` 即终态（fx-mica 类与其 CSS 暂留 dead path，实机定案后清理）。预览/插件子窗口同恒 solid（`window_fx::apply` = no-op；子窗口 transparent layered 保留作圆角载体，前端实色底盖住；`&fx=solid` 降级路径天然一致）。主窗口守卫只留 WM_NCACTIVATE 失焦欺骗（阴影不收小）。
- **.window 壳**：底 = `--n-g-a1-solid` 单态（2026-10-01 弃云母；fx-mica 暂留 dead path）；大阴影 = DWM shadow（shadow:true，丢失再议 workaround）；圆角 = 前端自裁 `--n-radius-8` 单态（最大化归零）——不透明实底下与 DWM 系统圆角同径，无 063 双裁透缝问题；**窗口边框 = 前端自绘单态（2026-10-01 收口）**：常态 `::before` 1px `--n-g6` radius 8（最大化隐藏）、picking `::after` 1px `--n-brand` 自绘 + `::before` 让位单层——主窗口 DWM 染色全撤（lib.rs paint_border 调用撤、set_main_border_picking no-op 化）：DWM 线与 CSS 线并集必错位双层（063 实测：四边 3vs2、角弧异径出缝），且 25H2 起 DWM 默认边框本就不画，不染 = 前端单画干净解；子窗口边框仍 = 建窗 DWM 染 #333（子窗口前端不自绘边框）。**沿窗口圆角画线必须按同 radius 圆角路径**——直角线四角被 DWM 角弧（内陷 ≈2.3px > 线宽）整段吞断（063）。
