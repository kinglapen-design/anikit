## 搜索栏两修复（FloatBarSearch / bars.css）

- **栏内按钮一律 `@mousedown.prevent`**（筛选 / 收起 / chip 全挂）：阻止 input 失焦——否则聚焦态点筛选时 blur 抢先触发壳宽 450→250 收缩动画，按钮随壳边移出指针下方、mouseup 落空 click 不成立（用户实机报「聚焦后点筛选不展开只收回」）。顺带保持输入聚焦，点筛选 / 收起后可继续敲字。回归钉 = 搜索探针 S19（必须真鼠标链路 mousedown→mouseup→click，js `.click()` 不经过失焦路径复现不了）。
- **挤压裁剪口径**（用户实机报「按钮被裁且跑到底色外」）：壳 `.fb-shell` 加 `max-width: 100%` 硬钳制（配合 flex 收缩双保险），内容永不跑底色外；**筛选组 `.fbs-filters` = 展开态唯一可缩件**（`flex: 0 1 auto; min-width: 0; overflow-x: auto` + 隐藏滚动条——同旧帧条 .frames 口径），输入区 174 稿值与收起钮 flex:none 钉住两端不被裁走；**滚轮横滚** = `@wheel` 转 scrollLeft，无需横滚（scrollWidth ≤ clientWidth）时不拦默认行为（穿透给下层列表纵向滚动）。回归钉 = S20（dockview 不吃视口收窄，挤压用 content-area inline 宽模拟——踩坑 073）。

- **定位 = 底部居中距底 12**（同搜索悬浮栏 .sf-anchor 口径），pointer-events 穿透空隙；**帧条浮于播放条上方、同宽、间距 12**（播放条-帧条稿 prose）：宽度链 = 帧条 5 格自然宽 777 + 播放条 `:width` 跟随，容器窄时双双钳制壳内裁剪。
- **show 组按上下文删减**（稿 prose「根据上下文，选择保留哪些按钮」）：video 全量；audio 去 transport/step/note/cover/fullscreen（留 播放/音量/倍率/循环）；sequence/anim 去 transport/step/volume/loop（上/下帧归帧条两端尖括号钮 = stepFrame ∓1 旧帧条语义）。

- **弹层（倍率 / 音量 / 时间显示）= 悬停开 + 120ms 延迟关桥**（LinkListPopover 同款），定位 = 播放条上方居中（bottom = 栏高 42 + 间距 12），显隐动画 = 透明度 + scale 0.98 / 150ms（稿无弹层动效 prose，套旧 menu-pop 语义 + token 档）；倍率钮点击也可开合，**选中即关**（旧弹窗口径）；音量钮点击 = 切静音（旧主行为不变，悬停弹层滑块静音时显 0、setVolume>0 自动解静音）；**时间显示切换复用 RatePop**（项样式定稿件，「帧数/时间码」↔ ui.timeDisplay，与查看方式菜单同值联动）。
- **笔记弹层 = 确认制**（稿 取消/确认 按钮）：confirm = 保存当前帧笔记（空文本 = 删除 store 语义）不关弹层；cancel = 关闭；切帧 / 切列表项草稿直接回填（确认制 = 未确认即丢弃，无旧 dirty 防误删需求）；帧号列格式化沿用旧 itemLabel 口径（t: → 帧 N / mm:ss，f: / 帧名 → 帧 N）。

- **音频进度 = WaveProgress**（bars/ 新件，FloatBarPlay `#progress` 插槽替换 BarSlider；FloatBar 同轮补插槽透传）：音乐预览稿 prose「只在播放条上放波形图」；波形配色 token 化映射 = 未播放 亮色/三级实色（旧 wave-pending「标签档不透明版」语义档）/ 已播放与播放头 品牌（--n-brand）。
- **BarSlider 补 `drag-start` / `drag-end`**（窗口 pointermove 链路两端 emit）：视频 scrub 挂 `media.setScrubbing` 的进出口（拖动期 timeupdate 不回写）。
- **全屏态**：浮动栏随 anchor 浮于画面底部居中距底 12（旧「footer absolute 贴底」作废，画面铺满挡住就挡住口径不变）。

## 同日二轮（2026-09-09，用户实机四条 + 扩展性定案）

- **两侧 12 呼吸**：悬浮栏 anchor 改 `left/right: 12px`（`.fbh-anchor`），壳被挤压后两侧也保 12——搜索与播放两态同口径。
- **播放条横向填满（fill）**：FloatBar 加 `fill` prop——壳 `width: 100%` 随 anchor 跳过实测（指定值恒定，父容器 resize 不触发过渡 = 即时跟随；退场 gone 宽 0 仍 300ms 过渡）；FloatBarPlay 透传 fill，进度条改 `flex-grow: 1; width: auto` 吃余量（fill 不走 max-content 探针，避开踩坑 072 丢宽）。
- **弹层对齐触发件上方居中**（旧通栏口径回接，原「栏体居中」作废）：FloatBarPlay 的 hover / open 事件带触发事件对象（`emit('volume-hover', true, $event)`），宿主 `placePop` 取 `currentTarget` rect 算 anchor 内 x + `translateX(-50%)`，水平钳制 anchor 内；**弹层读宽要按当前弹层类选择 + `:not(.fbh-pop-leave-active)` 排除离场残留**（150ms 离场动画内上一弹层仍在 DOM，querySelector 误中会把钳制算偏——探针实证）。
- **形态切换动画落工程（稿 prose「同一容器」兑现）**：搜索侧 SearchFloatBar 与播放侧 PreviewFloatBar 合并为 **`FloatBarHost.vue` 根部单例**（ContentArea 两分支外，预览进出不卸载）——mode = `search` ↔ `play` 走 FloatBar 既有 Transition morph（宽伸缩 + Y 出入 300ms）；查不到 spec 的预览 kind = `visible=false` 宽度+透明度退场。ContentArea 显隐口径不变（showSearchBar 关时 Ctrl+F 唤出 / Esc 收回走 sf-reveal）。
- **扩展性定案 = barSpecs 注册表**（`src/lib/barSpecs/`，用户定方向「以后 3D / 第三方格式支持不动宿主」）：`PlayBarSpec` 接口 = show 组 + 时间码 / 进度 / 播放控制全函数取值（宿主 computed 内调用，store 响应式追踪照常）+ 可选 `frames`（帧条）/ `waveFallback`（音频波形）；`registerPlayBarSpec(kind, factory)` 开放注册。内建 video / audio / sequence·anim 四 kind 三工厂。**宿主只查表分发**，新格式 = 一个 spec 文件 + 注册一行；新控件种类才动 FloatBarPlay 的 PlayGroup。
- 探针：playbar 探针 +fill 断言（壳 = anchor = 面板 - 24、进度条 grow 1 伸展 ≥327）+ 弹层对齐断言（pop cx = 触发件 cx ±2）+ **morph 回程断言**（关预览切回搜索形态 250）；搜索探针 S20a 加两侧 12 呼吸数值。
