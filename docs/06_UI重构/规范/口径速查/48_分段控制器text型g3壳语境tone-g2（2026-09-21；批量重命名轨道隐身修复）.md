# 48 分段控制器 text 型 g3 壳语境 = tone g2（2026-09-21；批量重命名轨道隐身修复）

> 用户实机报批量重命名弹窗底部分段控制器「少了底色」——未选段与轨道底全消失，只剩选中滑块。

## 根因与定案

与 §47 同族病灶：SegmentedControl text 型默认轨道底 = 通用/三级（字体预览稿语境），批量重命名壳 = BaseModal g3——**g3 轨道贴 g3 壳同底隐身**。

**语境规则：text 型分段控制器落在 g3 壳上一律 `tone="g2"`**（通用/二级轨道在 g3 壳上显形；组件 2026-09-06 插件面板轮已具 tone 能力，本规则写入 SegmentedControl 头注释）。修复 = BatchRenameDialog 与 preview 复刻格各加 `tone="g2"`，组件零改动。

## 语境排查（同病灶全清）

variant="text" 消费方逐核宿主底色：字体预览（中间面板内容区非 g3，g3 轨道显形，不动）/ 插件面板与查看方式（已是 tone g2）/ 右侧边栏与左侧边栏（icon 型 a3 轨道，无此病灶）/ preview 展区（PreviewButtons 演示格底非 g3，显形；PreviewDialogs 批量重命名复刻格同修）。

## 同族口径归并

g 系同底隐身已有两例：§47（规则行 g3 块贴 g3 壳 → 组块卡片化垫 g6）与本节（分段轨道 g3 贴 g3 壳 → tone g2）。**往上叠容器时底色必须错档**——g3 壳上的内容容器用 g2/g4~g6，不用 g3。
