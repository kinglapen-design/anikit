# 50 链接管理名称列贴行右缘（2026-09-21；232 固定宽废）

> 用户实机指链接管理树行「旁边空出来的好像才是打勾的位置」——对勾应贴行右缘，现状名称框右端与行右缘之间空一截。

## 根因与定案

行内两列宽度体系不一致：表头 = 两列 flex 1 均分（各 270），行内 = 文件夹格 270 固定 + 名称框 **232 稿值固定**——270+12+232 = 514 < 552 内容宽，右缺口 38px（figma 实例宽在稿 552 内容宽下的拉伸语境，被当成定宽落地）。

**定案：名称框列 232 固定废，改 flex 1 与表头均分列对齐**——folder-cell 270 + gap 12 + link-cell 270（弹性），正好等于表头两列均分；对勾（名称框内右端 / 空行 flex-end）贴行右缘。子级行文件夹格随缩进变窄时名称框相应变长，对勾右缘恒定。
