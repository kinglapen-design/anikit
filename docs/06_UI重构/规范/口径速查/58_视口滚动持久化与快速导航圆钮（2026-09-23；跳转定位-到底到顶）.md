# 58. 视口滚动持久化 + 链接跳转定位 + 快速到顶/到底圆钮（2026-09-23；滚动三件套一轮）

2026-09-23

- **视口滚动位置改落盘持久化（用户定）**：原 content store 会话级 `Map`（重启即丢）废除，迁 **ui store `scrollPositions`**（viewKey → 像素，PERSIST_KEYS 登记随 settings.ui 防抖 500ms 写回，`viewRowHeights` 同款口径——应用级不随库）。切视口 / 进出预览 / 关闭标签页 / **重启应用**后都恢复。序列帧包内视图（原生滚动）同口径接入（`seq:{assetId}` 键，load 完成恢复 / 换包与卸载保存）。
- **恢复加固 = 保留式恢复**：`useGridLayout` 重排恢复后校验到位——未到位（异步内容视口高度不足被夹，如工作空间目录加载中）**保留待下次重排重试**，到位才消费；**用户一旦主动滚动即放弃**（useVirtualScroll 新增用户源回调清 null，不再拽回用户手下）。
- **链接跳转定位（用户定：跳转不再停顶端）**：`relationOps` 两个 jump 登记 `content.requestReveal(viewKey, key)`（store 单槽位 `pendingReveal`）；目标网格重排时消费——**目标卡已在视野内不动，否则滚到居中**；同视口跳转（viewKey 不变）由 `pendingReveal` watch 自驱动一次重排。找不到卡（搜索过滤 / 折叠组内）= 消费即放弃，静默。
- **快速到顶/到底圆钮（用户定）**：新组件 `QuickNavButton`（`dir: top|bottom|null` + click，AssetGrid 与 SequencePackView 共用），右下角定位 **bottom 12（与多功能悬浮栏同水平线）/ right 20（让开滚动条命中区 12 + 间隙 8）**。显隐状态机：用户源滚动**同向累计 ≥200px 出现**（下滚出「滚到底」/ 上滚出「回到顶」），停止滚动 1.5s 收起，点击平滑滚动到位即收起；切视口收起清零。按钮样式 = **IconButton 新增 `circle` 变体**：42×42 纯圆（--n-radius-pill）+ 搜索框壳同款（通用/半透明-2 + 立体感-通用 + 背景模糊-小），hover 底升 通用/四级 + 图标升 亮色/二级。箭头 = `chevron-large`（源朝左）旋转定向：上 rotate(90deg) / 下 rotate(-90deg)（悬浮栏收起钮先例）。出入场 = 位移 8 + 透明度 250ms 缓入缓出（悬浮栏族动画档 §18 同口径）。
- **平滑滚动**：`useVirtualScroll.smoothScrollTo`——300ms easeInOutCubic（分段滑块 300ms 动画档），程序源不上报用户回调；任何用户滚动（wheel/键盘/拖块/点轨道）经 scrollTo 打断动画。原生滚动侧（包内视图）用 `scrollTo({behavior:"smooth"})`，点击后挂起显隐、用户 wheel 重新武装（scroll 事件不区分用户源与程序源）。
- 预览页 PreviewButtons 补 circle 常态/hover 陈列（上下两向旋转演示类在 preview.css，`.app-icon` 直接后代选择——**全局 CSS 禁写 `:deep()`，无效选择器会整条规则作废**）。

**同日修复轮（用户实机两报「没有持久化 / 跳转定位不准」）**：根因 = `useGridLayout` 的 `watch(opts.viewKey)` 与 `watch(opts.items)` 实际触发顺序**与注册序相反**（items 先跑——props patch 顺序决定，踩坑 084）——items 的 relayout 先把 pos 夹到新视口，viewKey 随后保存被污染值、restorePos 迟到（本轮恢复失效且悬着把 reveal 定位也拉回）。**定案：viewKey watch 必须 `flush:"sync"`**（props patch 瞬间同步执行，先于一切排队 relayout）——凡两个 watch 有先后依赖，禁止靠注册序假设顺序。回归探针 `tools/cdp-scroll-restore-probe.py`（S1-S5：保存未污染 / 切回恢复 / 同视口 reveal / 跨视口 reveal 覆盖恢复位 / 各视口按 key 保存）。
