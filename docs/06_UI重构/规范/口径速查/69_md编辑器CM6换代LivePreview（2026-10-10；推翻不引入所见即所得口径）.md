# 69. md 编辑器 CM6 换代 · Live Preview（2026-10-10；推翻 §60「不引入所见即所得」口径，PRD 04-04 条 6 同步翻转）

- **动因与定案**：用户评估 Obsidian 式所见所得可行后定案——可读性优先。编辑态内核由 textarea 换 **CodeMirror 6**：光标外行内联渲染（标题字号 / 加粗斜体删除线隐标记 / 引用竖线 / 代码块卡片 / 任务复选框 / anikit 图片真图），光标行回落纯源码。**文档源仍是 md 字符串**——防抖 1s 自动保存、loadedId 竞态守卫、「编辑不进 undo」、19 个工具栏动作作用源码选区、anikit 粘贴补全，全部沿用不变。预览态（markdown-it 渲染纯阅读）与分屏（左编辑右渲染）形态不变。富文本路线（Milkdown/Tiptap）因 markdown 往返有损（存盘重排用户文件格式）+ 双解析引擎分叉被否。
- **落点**：`lib/cmMd.ts` = 唯一装配入口（createMdEditor 工厂；内核 + Live Preview 装饰层 ViewPlugin + 探针钩子 `__cmView`）；排版 = **`styles/cm-md.css` 全局类**（与 markdown.css 同 token 双写——选择器语境不同，稿值唯一源头仍是文本编辑稿）；PreviewText md 编辑态换挂载点 `.cm-host`，txt 路径不动。**`lib/mdHistory.ts` 自实现快照栈退役删除**——撤销 = CM6 原生事务栈：键入按 500ms 新组窗合并；工具栏动作 dispatch 带 `userEvent: md.toolbar.{seq}`（每次点击恒独立步）、任务框 toggle = `md.task`、粘贴 = `input.paste`、外部回灌 = `md.external`。
- **装饰层口径**：行级样式（标题 / 引用 / 代码块行）**恒挂**——光标在内排版不塌；隐标记（`#` `**` `*` `~~` `` ` `` `[]()` URL `>`）与 widget 替换（图片 / 分割线）**仅光标外行**生效，active 判定 = 装饰区间与任一选区相交（光标贴边算在内）；任务框 / 图片 widget 恒渲染（框点击按行回写 toggle——位置随编辑漂移以行重扫为准，同 toggleTaskLine 口径；图点击内部跳转，光标进图区间回落源码便于改 alt/url）。装饰构建只扫 `visibleRanges`。**表格 / Setext 标题本轮不装饰**（保源码态，待另轮）；编辑器块距 = md 空行自然撑开（非渲染态 flex gap 12）。
- **嵌套标记下探**：标题 / 强调族节点 `iterate` 时必须 `return true` 继续下探（`return false` 会漏藏 `# **粗**` 的内层 `**`）；隐藏装饰用 Set 按区间去重（`***粗斜***` 内外层同名 mark 重复藏会让 CM6 replace 重叠报错）。
- **退出键上浮截停**：CM6 键图不 stopPropagation——Esc / Ctrl+Enter 在 contentDOM 处理退出后冒泡到 `.cm-host` 时拦停（`@keydown` guard），否则 Esc 连带触发面板级 / 全局监听关掉整个预览（探针 F 实锤：编辑器退了、预览也没了）。Ctrl+E 不拦（全局 isEditableTarget 对 contenteditable 本就让位）。
- **探针适配口径**（`tools/cdp-md-editor-probe.py`，17 段）：CM6 实例经宿主钩子 `.cm-host.__cmView` 拿（CDP 语境 import 不到 EditorView 类）；选区 / 键入 = `view.dispatch`（updateListener 自动同步 draft）；快捷键 = 合成 keydown 派发 `.cm-content`；滚动联动断言对 `.cm-scroller`。新增 P 段 = Live Preview 装饰层验收（光标外 H1 隐标记 / 光标行回落 / 任务框与代码块行装饰）。
- **分屏 / 保活平移**：typewriter 光标行 = `view.state.doc.lineAt(selection.main.head).number - 1`（同 data-line-start 0 起口径）；滚动保活「editor」键取元改 cmScrollEl（md）/ editorRef（txt）分流；分屏右栏复选框 toggle 经 `watch(draft) → mdEditor.setDoc` 回灌（整文替换 + 光标钳位，setDoc 自守恒等不循环）。
- **typewriter 合一计时器化（2026-10-10 踩坑 109）**：headless Chromium 按需出帧模式下，空视觉损伤窗口期 **rAF 回调会整段停摆**——旧 rAF 合一守卫 id 永锁、typewriter 死滚动（探针 O 段实锤，新调度也饿死）；合一改 `setTimeout` 16ms（取消-重排保「连续键入后者赢」）。**linkLock 进一步改墙钟截止时刻**（`performance.now() + 100`）——计数 + 定时器解锁在节流环境同样冻死（解锁回调迟到数秒，联动长锁全瘫），墙钟到点自然失效零回调依赖。**教训：凡「等一帧再算 / 过会儿解锁」的工具代码，探针语境一律定时器 / 墙钟，不用 rAF / 回调解锁。**
- **走查修订（2026-10-10 用户实机两报）**：① **文末抬高余量**——编辑态 `.cm-content` 底 padding 66 → `calc(66px + 50vh)`（悬浮栏补偿 + 半屏滚动余量，末行可抬至视口中部，Obsidian typewriter 同思路；预览态不动）；② **字体必须打在 `.cm-content`**——CM6 base theme 对 `.cm-content` 直属设 `font-family: monospace`，打 `.cm-editor` 会被截断继承、中文落宋体；`.cm-editor .cm-content`（0,2,0）压（0,1,0）。
- **窗级快捷键豁免一律 `isEditableTarget`**（2026-10-10 用户实机报「编辑态 ←/→ 动不了指针」）：PreviewPanel 窗级 ←/→ 切素材守卫手写 tagName INPUT/TEXTAREA 漏 contenteditable，CM6 `.cm-content` 不豁免被切素材；换共享判定（含 isContentEditable）。**禁止手写 tagName 豁免清单**——下一个富文本内核（或任何 contenteditable 岛屿）还会再漏。
- **待办 / 另轮**：颜色档微调（用户：现色淡、可读性不够，可能需新 token——另轮讨论）；表格 Live Preview 渲染；Setext 标题；代码块复制钮在编辑态不挂（源码可直接选中复制，预览态有钮）；引用块首末行 4px 纵向 padding 未做（稿 4/0/4/16，行装饰逐行供给不了纵向呼吸，待评估）。
