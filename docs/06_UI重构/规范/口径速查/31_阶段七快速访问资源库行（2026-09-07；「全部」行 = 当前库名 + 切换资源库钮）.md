# §31 阶段七快速访问资源库行（2026-09-07；「全部」行 = 当前库名 + 切换资源库钮）

2026-09-07 用户定案，同日二轮修订。动机：「创建资源库」此前只有菜单栏「菜单 → 仓库 → 资源库 → 新建资源库」一个入口，藏得太深。定案 = 在快速访问首行（原「全部」行）上轻调整，把资源库菜单提到行内，版面结构不改。

## 布局口径

行壳不动（TreeRowItem quick：26 高 / padding 4 6 / 圆角 6）。库图标（library 18）+ 名称 + 切换钮三件同处 `.lead` 容器，**等距 = 容器既有 gap 6**，不加额外间距。名称 = 当前资源库名（`currentLibrary.name`，空回退「全部」），过长截断（.nm 既有省略档），切换钮 flex none 不被挤压。行右数量（全部 Placement 数）保留不变。

## 行为口径

行本体点击不变 = 进「全部」视口（quick:all），选中态照旧。切换钮点击弹**资源库菜单 = 菜单栏「菜单 → 仓库 → 资源库」同款内容**（共享 spec `menuSpecs/libraryMenu.ts` 的 `libraryMenuEntries`，二轮定：首轮误用旧 08 稿浮层已纠正）——新建资源库 / 删除当前资源库 / 合并资源库（占位）+ 库列表**纯对勾行**（MenuItem checkable，对勾与禁用函数化求值，keepOpen 切库期间实时）。

**库列表无拖拽排序**（二轮用户定：资源库不至于多到需要排序）——08 稿 LibraryMenuItem（抓手排序 + 删除×）全库废除，组件与 ContextMenu libDrag 机制、CtxItem.library 字段、前端 reorderLibraries 一并拆除；删除走菜单项「删除当前资源库」。后端 `reorder_libraries` 命令保留但前端已无调用方。

菜单作为一级菜单弹出，**min-width 250**（2026-09-05 一级条目菜单定档，渲染层自动应用）；位置 = 行下方 4px、左缘对齐行左缘；同钮再点 = 关闭（菜单栏四文字钮同款 toggle，trigger 豁免）。选择模式（picker）下禁开——切库非 §12.1 白名单，视觉不改（同菜单栏钮口径，稿无禁用态）。

## 样式口径

切换钮 = 18×18 盒**常显**（不随 hover 现身——它是本行主入口，与 SectionTitle 动作组 hover 现身口径相反）；图标 `switch-library` 18（01_常用，入库十二批转 currentColor）。色档随 quick 图标族：常态 亮色/三级，hover 提亮 亮色/二级，选中行随名称 亮色/一级；color 过渡 `--n-dur-100`。点击热区伪元素外扩（.exp 同款）：上下 -4 吃满 item padding、左右 -3 各吃间距一半。
