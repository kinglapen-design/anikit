# 15. 阶段七按钮组件族口径（2026-08-29，稿 = Design Token/组件/按钮/ 17 稿）


- **组件位置 = `src/components/buttons/`**（6 件）：ActionButton / IconButton / TagButton / SegmentedControl / FontInstallButton / DropButton；与旧根目录按钮件（AppButton / IconButton / AppSegmented / AppTag 等）并存，业务接入随面板重构轮逐件替换、旧件退役。
- **ActionButton**（主按钮-大/小 + 文字按钮-大/小-立体 + 文字按钮 + 图标+文字-立体 五稿合一）：variant = primary（品牌/常态底 + 立体感-主要按钮，文字一级；hover 品牌/提亮）/ solid（通用/四级 + 立体感-通用，文字二级；hover 通用/六级）/ ghost（菜单钮无填充，文字三级；hover 半透明-3 底 + 文字升二级）；size = lg 高 38（按钮文字-大）/ md 高 34（正文-加粗）/ sm 高 28（按钮文字，稿仅 ghost）；**lg/md = 填充式宽 100%**（figma padding-x 0 + flex-grow 的拉伸语境，宽度由父容器定），sm 自适应内容；前置图标 = 18 实寸 亮色/三级、hover 不变色（图标+文字稿）。
- **IconButton**（通用/大/小/立体/立体-半透明 五稿合一）：plain = 30×30 padding 6 圆角 6（hover 半透明-3 底 + 图标升二级）/ bare = 裸图标无容器（lg 18 / sm 14，hover 仅图标升二级）/ solid = 通用/四级 + 立体感-通用 高 34 填充式（图标恒二级，hover 通用/六级）/ float = 通用/半透明-2 + 立体感-通用 30×30 浮于内容上（图标恒三级，hover 通用/四级底）；图标尺寸 = 稿 icon 容器实寸 18（bare sm 14）——**图标一律按导出实寸渲染勿缩放**（2026-08-29 走查，用户："我都是按实际尺寸导的"）。
- **TagButton**（标签按钮-大/小-立体 + 立体-半透明 三稿）：圆角 6 均带立体感-通用；solid md = 通用/四级 高 28 padding 6/12 次要文字-加粗（hover 通用/六级）；solid sm = 通用/五级 高 24 padding 4/8 次要文字（选中 = 品牌底 + 文字一级 + 立体感-主要按钮）；ghost sm = 半透明-3 高 24 padding 4/8 次要文字-加粗（hover 半透明-2；选中 = 半透明-1 + 文字一级）。
- **SegmentedControl**（分段控制器-图标/文字 两稿）：容器 padding/gap 4 圆角 8——icon = 半透明-3 底高 38（右侧边栏 详情/链接）/ text = 通用/三级底高 40（字体预览）；选中 = 半透明-1 + 立体感-通用的**滑块 thumb 位移**（300ms 形态切换 + 缓入缓出 token），内容升一级；未选三级，hover 段底半透明-3；段均分 flex 1 + min-width 0（防 nowrap 撑溢出错位，沿旧 AppSegmented 踩坑口径）。
- **FontInstallButton**：18px 圆钮 通用/四级底 + 通用/六级 1px 内描边；**hover = 描边升 亮色/四级**（2026-08-29 用户定，稿原无 hover）；选中 = 品牌/常态底 + **亮色/半透明-3 描边**（用户改定，稿 prose 原写半透明-1）。
- **DropButton**（拉下按钮-横向）：通用/六级底 + 亮色/半透明-3 内描边，高 28 padding 6/6/6/12 圆角 6，**宽度自适应内容**；项 = 次要文字-加粗（选中一级 / 未选三级，**hover 项文字升二级**——2026-08-29 走查）；常态只显示选中项 + 箭头朝右，点箭头 **inline 横向展开**全部项、点项选中并收起；**展开/收起宽度动画 250ms 小位移 = JS 实测各项内容宽 + wrap 显式 width 过渡**（grid 0fr→1fr 推挤**只适用外部定宽容器**——item 卡片定宽 240 有效；本组件内容自适应下 0fr 轨道仍把 max-content 计入容器宽，收起态隐藏项占位撑宽间距错乱，2026-08-29 十轮实锤作废，踩坑 055；间距模型 = 容器 padding 6 + 各项内层左 padding 6，首项视觉前距 12 = 稿值，缝恒由后项提供）；**箭头 = 标题同款 expand**（∨ 旋转 ∓90° 得朝右/朝左，非 chevron-small——走查改正），hover 升二级。
- **全族动画时长（稿「给了动画的补毫秒」2026-08-29 用户要求标注）**：hover / 颜色过渡 = **150ms**（--n-dur-150 通用 + 缓入缓出）；拉下按钮展开/收起与箭头旋转 = **250ms**（--n-dur-250 小位移）；分段控制器滑块位移 = **300ms**（--n-dur-300 形态切换）；色块 hover 放大 = 150ms（item 族）。**禁用 / 按下（active）态 17 稿均未画**——不做不自创，需要时找用户补稿（09 待办）。
