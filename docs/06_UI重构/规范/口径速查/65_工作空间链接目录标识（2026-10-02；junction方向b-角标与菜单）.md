# 65. 工作空间链接目录标识（2026-10-02；junction 方向 b——角标与菜单）

> 方向 b（外部文件夹 junction 挂进 WS 子目录，2026-10-02 落地）的视觉标识与菜单口径。链接目录 = 「门」：删除 / 重命名只动门，复制深拷内容，断链只标记不剔除——视觉与菜单都服务这套语义。

## 定案

- **角标 = `badge` prop**：`TreeRowItem` / `FolderCard` 新增可选 `badge` prop——文件夹图标**右下角 10px 徽章，右下 0 偏移**。**无稿零件最小方案，待用户实机走查定稿**；走查前其它场景不得自作主张复用这个徽章位。
- **徽章取用（零新 token 零新图标）**：挂链 = `linked-file-badge` 图标（亮 l3 档；树行选中态升 l1——同 §55/§57 链接徽章「亮色/一级」色档口径）；断链 = `warning-small` 图标 + 整条目复用既有 `dimmed` 0.4 透明度档置灰（§5：用既有档禁新造）。
- **菜单三项**：「添加链接文件夹…」入**空白菜单与文件夹菜单的新建组**（系统目录选择器选目标 → 挂载到当前目录 / 本文件夹）；「重新指向…」「移除链接」入**文件夹菜单固定组、条件出现**——仅链接门条目出现（**断链同列**：断链可重指可移除）；树行 / pin 行经共享 builder 自动获得；**多选时只作用被右键项**（不整批分流）。
- **「移除链接」确认弹窗** = warning 黄钮，文案明示「只移除链接本身（进系统回收站可找回），目标文件夹内容不受影响」。
- **ws 菜单全文件无图标惯例**：新项一律不带图标（`menuSpecs/workspace.ts` 既有口径，与库菜单带图标不同族）。

## 实现口径

- 前端对链接条目**零特殊分支**：删除 / 重命名 / 拖拽 / 副本不判 `isLink`（语义由后端保证——删与改名只动门、复制深拷内容、拖入落真实目标）；断链门双击进入 = 空列表（后端 read_dir 自然失败降级），不报错不弹窗。
- 角标数据来自 `WsEntry.isLink` / `linkOk`（接口 20 组）；pin 行徽章与链接菜单项依赖**父目录已加载**——未加载按非链接降级，预期行为非缺陷。
- preview 页 TreeRowItem / FolderCard 展区已加 badge 陈列（挂链 / 断链两态），改徽章方案先对陈列。
