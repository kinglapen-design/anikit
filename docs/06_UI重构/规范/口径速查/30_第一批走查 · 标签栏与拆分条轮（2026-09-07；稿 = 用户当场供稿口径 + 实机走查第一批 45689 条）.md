# 30. 第一批走查 · 标签栏与拆分条轮（2026-09-07；稿 = 用户当场供稿口径 + 实机走查第一批 4/5/6/8/9 条，含同日二轮正态）



- **左栏拆分条（SplitBar left）**：**常态 = 以前的 1px 分割线样**（右栏左缘同档 `1px --n-g3`）；**hover / 拖拽 = 亮色/四级渐变线**（沿条长 `linear-gradient` 两头 0%、中间 50%，`color-mix(in srgb, var(--n-l4) 50%, transparent)` 派生），线宽 1px 升 2px + 150ms 过渡（条 4 二轮用户正态：渐变是 hover 样式，不是常态）。**右栏拆分条 = 无悬停**，常态线由右栏自身左缘通栏线承担，仅 `cursor: col-resize`。
- **标签页分屏 sash hover 同渐变语言**（条 5 二轮用户定）：dockview sash 悬停 / 拖拽指示线 = 同款亮色/四级渐变（两头 0% 中间 50%），**方向沿 sash 长轴**——横向容器（左右分屏，竖 sash）垂直渐变、纵向容器（上下分屏，横 sash）水平渐变；线宽维持 1.5px。
- **分屏静态分割线废除**（条 6）：dockview 分屏组间不画常态线（原 `.dv-view:not(:first-child)::before` 整套删除），`--dv-separator-border: transparent`。
- **内容容器左上圆角 = 只有第一行第一列**（条 6 二轮用户正态）：选择器 = `.dv-grid-view > .dv-branch-node > .dv-split-view-container > .dv-sash-container + .dv-view-container > .dv-view:first-child .dv-content-container`——`> .dv-view:first-child` 锁首个分屏；**末端必须后代 `.dv-content-container`**：dockview 7 是「单 sash-container + 单 view-container 裹全部 .dv-view」（splitview.js 实证），且**上下分屏时原组被重定向包进嵌套分支**，直达子链会漏匹配（一轮回归根因：上下分屏首排圆角消失 + 左右分屏两列都有圆角）。**左栏收起时左上圆角归零**（同日补充用户定，`.dock-host.left-collapsed` 覆盖 `border-top-left-radius: 0`，与右缘直角统一）。
- **标签拖拽插入提示 = 框选同款**（条 8）：`--dv-drag-over-background-color: var(--n-brand-50)` + `--dv-drag-over-border: 1px solid var(--n-brand)`（+ `--dv-drag-over-border-color: var(--n-brand)` 小边缘档），与 AssetGrid `.marquee` 同色系同粗细。
- **单标签拖拽分屏 no-op 修复**（条 9）：dockview 对「单 panel 组拖自己内容区边缘」走「单 tab = 移组」优化——源/目标同分支时 `moveChild` 自身 = no-op（core `moveTo` 源码实证），分屏永不成功。修法 = **拦组级 `model.onWillDrop`**（可 `preventDefault`；组件级 `@will-drop` 在无 advancedDnD 模块时不转发组级事件，必须逐组订阅）。拦截条件：`kind === 'content'` + 位置为四边缘 + 落点组 === 源组 + **源组只剩 1 panel**；拦下后走 `splitTab` 同语义（同视口复制到新组，与右键菜单一致——单标签拖走 = 源组销毁布局回弹，复制是该场景唯一有效结果）。position 词汇（left/right/top/bottom）→ direction 词汇（left/right/above/below）需映射。新建组经 `api.onDidAddGroup` 补挂（Set 幂等防移组重挂）。
