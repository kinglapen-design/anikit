# 30. 第一批走查 · 标签栏与拆分条轮（2026-09-07；稿 = 用户当场供稿口径 + 实机走查.md 第一批 4/5/6/8/9 条）



- **左栏拆分条（SplitBar left）= 亮色/四级渐变线**（条 4 用户供稿）：沿条长方向（竖条 = 垂直向）`linear-gradient(to bottom, transparent 0%, color-mix(in srgb, var(--n-l4) 50%, transparent) 50%, transparent 100%)`，2px 宽圆角 1。**常态即显示**（不再常态透明）、**无悬停 / 拖拽变色**（用户未供 hover 态，勿自创）；右栏拆分条（条 5）= **零绘制**——不渲染线、无悬停效果，仅 `cursor: col-resize` 提示。旧 `--brand-border` 悬停高亮整套作废。
- **分屏静态分割线废除**（条 6）：dockview 分屏组间不再画 1.5px 常态线（原 `.dv-view:not(:first-child)::before` 整套删除），面板自带边框、中间零线；sash 悬停 / 拖拽指示线保留（1.5px 居中，`--brand-border` 青绿 → `--n-brand` 新品牌蓝，行为不变）。`--dv-separator-border: transparent`。
- **内容容器左上圆角只给第一列**（条 6）：选择器末端必须走**直达子链** `> .dv-view > .dv-groupview > .dv-content-container`——原**后代选择器**会把第一列内嵌套分屏的内层容器一并圆角化 + 挂左缘线（用户报「其他列左上角圆角非常丑」的根因）。链路依据：splitview 每组包 `.dv-view`（core addView 实证）、组元素挂 `.dv-groupview`（model 构造 toggleClass 实证）、内容容器为其直接子（container.append 实证）。
- **标签拖拽插入提示 = 框选同款**（条 8）：`--dv-drag-over-background-color: var(--n-brand-50)` + `--dv-drag-over-border: 1px solid var(--n-brand)`（+ `--dv-drag-over-border-color: var(--n-brand)` 小边缘档），与 AssetGrid `.marquee`（50% 品牌填充 + 1px 品牌描边）完全同色系同粗细。
- **单标签拖拽分屏 no-op 修复**（条 9）：dockview 对「单 panel 组拖自己内容区边缘」走「单 tab = 移组」优化——源/目标同分支时 `moveChild` 自身 = no-op（core `moveTo` 源码实证），分屏永不成功。修法 = **拦组级 `model.onWillDrop`**（可 `preventDefault`，dockview 随即放弃默认处理；组件级 `@will-drop` 在无 advancedDnD 模块时不转发组级事件，必须逐组订阅）。拦截条件：`kind === 'content'` + 位置为四边缘 + 落点组 === 源组 + **源组只剩 1 panel**；拦下后走 `splitTab` 同语义（同视口复制到新组，与右键菜单一致——单标签拖走 = 源组销毁布局回弹，复制是该场景唯一有效结果）。position 词汇（left/right/top/bottom）→ direction 词汇（left/right/above/below）需映射。新建组经 `api.onDidAddGroup` 补挂（Set 幂等防移组重挂）。
