# 70. 设置面板轮（2026-10-13；1.0 收尾第 1 项——Eagle 式左右布局六轮定稿）

> 「偏好设置」面板（菜单栏「菜单 ▸ 偏好设置」/ Ctrl+,）的形态与口径。1.2 时代无稿无定义，本轮 preview 先行六轮定稿。本体 = `components/SettingsDialog.vue`（mock prop 陈列态早退，WsManageDialog 先例），数据层 = `lib/settingsData.ts` composable 收口；设计稿 = PreviewModals「设置面板」组（真实弹出 mock）。

## 定案

- **壳（2026-11-08 发布走查修订）**：BaseModal framed **880×640**，以视口四周 72 留白封顶；右栏内部滚动，不再使用 720×480 固定小壳。无底部按钮行**即时生效**；遮罩点击不关闭、Esc/X 关闭。
- **左右布局**（用户供 Eagle 截图定，竖排长页一轮被否）：左导航列 **168** 壳色 g3 无独立色块（**左浅**），导航行树行口径 32 高 / 圆角 6 / hover a3 / 选中 a2 + l1，**行首 18px 图标占位空盒**（6 分类图标待用户补）；右内容区 **g1 深色全出血填满**（**右深**）——顶贴标题横线、贴壳三缘，由内 padding 24 承视觉呼吸。
- **分割线**：导航列右缘 1px g5 竖线通 body 区高；标题横线 / 竖线 / 两块底色 **T 形相连零间距**（用户两轮截图纠偏终态：色块与分割线之间不留壳色缝，不做内嵌卡片）。实现 = 实例级压壳 `:deep(.bm-modal.framed) { gap: 0; padding: 0; overflow: hidden }`（见下方坑条）。
- **切分类动画** = 详情面板 tab 切换同款（150ms 缓出 + 250ms 缓入 delay 100ms 位移 48px，§23/§61 配方搬入），切换时内容区回滚到顶；快捷键区块内容区内部滚动（kit-scroll + ScrollThumb 不出区），不换壳高。
- **六分类（2026-11-08 修订）**：通用 / 语义分析 / 自动导入 / 缓存 / 插件 / 快捷键。关于从设置中移出，主菜单根级「关于 AniKit」打开独立窗口。
- **分组与防截断**：各页用 `sd-section`（g2 底 + g3 内描边 + 圆角 8 + padding 16）拆功能组；标题在设置语境升至 l1/l2。行高改最小高，长路径与说明 `overflow-wrap:anywhere`，按钮组允许换行；数字框用 `.sd-input-side > .ti-root.sd-num` 固定 96，分段控件用 `.sd-row .sd-seg.seg` 恢复内容宽，避免被子组件根样式抢满行。设置内 `ActionButton sm` 恢复 4/8 padding，不吃 BaseModal 底栏按钮的 48 档。
- **缓存与插件**：缓存 = 资源库 / 工作空间两卡 + 合计行；插件 = Animate 导出三输入行。快捷键行最小高 28，动作名在左、等宽键位在右。
- **快捷键状态色区分**：已接入行常态；未接入行键位降 l4 + 警告橙尾标，不整行置灰。2026-10-15 起 30 行全部实绑，`bound` 机制保留给后续新键。
- **MD 默认导出目录**：通用「文档导出」组提供选择目录与恢复默认；空值回当前文档旁，持久化键 = `ui.mdBundleExportDir`。

## 语义分析设置（2026-11-08 独立分类）

语义配置位于独立「语义分析」页，组件 = `components/settings/SemanticSettings.vue`，数据层 = `lib/semanticSettings.ts`。本地与外部详细分析分成两张 `sd-section`；本地部分为 CPU / DirectML、模型目录与运行环境，外部部分为 OpenAI 兼容 / Ollama、服务地址、视觉模型、超时、密钥与连接测试。GPU 回退必须显示实际 CPU 后端；API Key 只写 Windows 钥匙串且不回显。预览走 mock，禁止发命令。

共享行、分组与输入样式归 `styles/settings.css`，主设置与子组件都能命中；长路径允许换行，密钥输入与操作钮允许折行，不以裁切消化内容。

「帮助 ▸ 使用教程」= `HelpDialog`，BaseModal framed 840×640 视口封顶，正文直接渲染 `docs/使用教程.md`，kit-scroll + ScrollThumb 自滚。关于 = `AboutDialog`，framed 520，72 LOGO + 名称 + `0.1.0` / 早期版本 + 教程 / 仓库 / 反馈 / 日志入口。版本与外链命令收口 `lib/aboutData.ts`。

## 压壳样式的坑（2026-10-13 四轮空发教训）

- **组件 fallthrough class 落在 BaseModal 的遮罩 `.bm-mask` 上，不在弹窗本体**——`class="settings-dialog"` 类名叠加压壳全打在遮罩空发（gap/padding 从未生效，「圆角通过」一度是误判）。
- 正解 = **`:deep(.bm-modal.framed)` 实例级覆盖**（优先级 (0,4,0) 稳压共享件，与样式表加载序无关）；BaseModal 共享件零改动。WsManageDialog 的 `class="ws-manage"` 同样落遮罩（目前无样式消费无害）——后续面板压壳样式别再走类名叠加。
