# 70. 设置面板轮（2026-10-13；1.0 收尾第 1 项——Eagle 式左右布局六轮定稿）

> 「偏好设置」面板（菜单栏「菜单 ▸ 偏好设置」/ Ctrl+,）的形态与口径。1.2 时代无稿无定义，本轮 preview 先行六轮定稿。本体 = `components/SettingsDialog.vue`（mock prop 陈列态早退，WsManageDialog 先例），数据层 = `lib/settingsData.ts` composable 收口；设计稿 = PreviewModals「设置面板」组（真实弹出 mock）。

## 定案

- **壳**：BaseModal framed **720×480 定高**；无底部按钮行**即时生效**（§61/§66 同口径——设置直写直存，无确认/取消）；遮罩点击不关闭、Esc/X 关闭。
- **左右布局**（用户供 Eagle 截图定，竖排长页一轮被否）：左导航列 **168** 壳色 g3 无独立色块（**左浅**），导航行树行口径 32 高 / 圆角 6 / hover a3 / 选中 a2 + l1，**行首 18px 图标占位空盒**（6 分类图标待用户补）；右内容区 **g1 深色全出血填满**（**右深**）——顶贴标题横线、贴壳三缘，由内 padding 24 承视觉呼吸。
- **分割线**：导航列右缘 1px g5 竖线通 body 区高；标题横线 / 竖线 / 两块底色 **T 形相连零间距**（用户两轮截图纠偏终态：色块与分割线之间不留壳色缝，不做内嵌卡片）。实现 = 实例级压壳 `:deep(.bm-modal.framed) { gap: 0; padding: 0; overflow: hidden }`（见下方坑条）。
- **切分类动画** = 详情面板 tab 切换同款（150ms 缓出 + 250ms 缓入 delay 100ms 位移 48px，§23/§61 配方搬入），切换时内容区回滚到顶；快捷键区块内容区内部滚动（kit-scroll + ScrollThumb 不出区），不换壳高。
- **六分类**：通用 / 自动导入 / 缓存 / 插件 / 快捷键 / 关于。通用行 = label 左 + 控件右（分段 sm tone g2——g1 上错档成立）；缓存 = 双子组（资源库 / 工作空间）行（名称 + 副说明 12/16 l3 + 占用 + 清理 ghost 钮）+ 合计行（总字节数 + 全部清理）；插件 = Animate 导出三输入行（TextInput 小档定宽 96 + 单位文字）；快捷键 = 22 高紧凑行（动作名 l2 左 + 键位 l3 右）；关于 = logo 44 + 名称/简介/版本三行 + 右侧 ghost 钮。
- **快捷键状态色区分**（用户定「用颜色区分」）：已接入行常态；**未接入行不整行置灰**——键位降四级 l4 + 尾标「未接入」**`--n-warning` 警告橙**（颜色即状态区分）。自定义快捷键随后续版本。**2026-10-15 全量点亮**：原未接入七行（Enter / Ctrl+Enter / 新建类五键与 "/"）全数实绑（`useGlobalKeysOpen` / `useGlobalKeysCreate` 两新文件 + `globalKeysGuard` 共享让位判定，useGlobalKeys 近 500 行硬上限拆分），回收站 Shift+Enter / Ctrl+E 守卫放行，速查表补全 Shift+Delete / Alt+F4 两行、「展开或收起所有文件夹」补键 "/"——现 30 行全部已接入，未接入尾标机制（bound 字段 + 样式）保留供后续新键复用。
- **区块标题** SectionTitle block 传 `:actions="false"` 消死添加钮（WsManageDialog 漏传同轮补）；hover 折叠箭头/grab 光标为共享件既定行为不改。
- **MD 默认导出目录（2026-10-24 用户定）**：通用区复合行 = label 左 + 右侧两枚 `ActionButton ghost sm`（选择目录… / 恢复默认）+ 下方 `sd-note` 显示路径或「未设置：导出到当前文档旁」；复用 `sd-field / sd-row / sd-input-side`，零新 CSS / token / 图标。空值禁用恢复钮；mock 可演示选择与恢复两态。持久化 = `ui.mdBundleExportDir`（`settings.ui` 全局），WS 打包用该目录，空值回文档旁。

## 压壳样式的坑（2026-10-13 四轮空发教训）

- **组件 fallthrough class 落在 BaseModal 的遮罩 `.bm-mask` 上，不在弹窗本体**——`class="settings-dialog"` 类名叠加压壳全打在遮罩空发（gap/padding 从未生效，「圆角通过」一度是误判）。
- 正解 = **`:deep(.bm-modal.framed)` 实例级覆盖**（优先级 (0,4,0) 稳压共享件，与样式表加载序无关）；BaseModal 共享件零改动。WsManageDialog 的 `class="ws-manage"` 同样落遮罩（目前无样式消费无害）——后续面板压壳样式别再走类名叠加。
