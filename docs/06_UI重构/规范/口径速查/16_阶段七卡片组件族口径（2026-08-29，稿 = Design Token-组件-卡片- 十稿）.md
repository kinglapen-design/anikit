- **组件位置 = `src/components/cards/`**（6 件 + 共享 `cards.css`）：FileCard（通用 / 视频 / 音频 / 字体 / txt-md 五稿合一，kind prop）/ FolderCard / ArchiveCard / ListRowCard / ListHeader / FormatBadge；与旧根目录同名卡片件并存，业务接入随列表容器重构轮替换。
- **媒体卡壳 `.kc-media`**（文件卡 / 档案卡）：g2 底 + 圆角 8；hover = 位移 Y -4px + 小阴影（250ms 小位移）。**线条 = 旧统一方案双层伪元素 inset 0**（2026-08-29 走查改回——首版「真 1px border + 选中环 inset -1px」在分数物理像素下渗线、粗细不均，文件夹卡无真 border 反而正常）：常态 1px = `.kc-bordered::after`（**2026-08-30 定案 = 半透明环**：常态 l-a4 / 媒体卡 hover l-a2，深底 ≈ g3/g6 等效亮度，与图片混合压锯齿，§7；列表行 hover 仍 g5 实色；瞬时换色不做过渡，踩坑 036）、选中 2px 品牌 = `.kc-sel::before` opacity 过渡；**禁真 border、禁负 inset**；内容圆角裁切走 `.kc-clip` 内层。**圆角平滑三件套（2026-08-30，§7 同款口径）**：壳不挂 overflow:hidden（单层裁剪）、铺满缩略图/封面自带 radius 8（`.fc-thumb` cover/contain、`.ar-cover`）、选中/命名态常态环 transparent 让位（cards.css `.kc-sel.selected::after` + FileCard/ArchiveCard/ListRowCard naming scoped）。
- **悬停控件 hover 才现（2026-08-29 用户定）**：视频/音频右上胶囊（`.kc-float`：半透明-2 + 立体感-通用 + 背景模糊-小 + 圆角 4；视频 = 帧数 + 播放/暂停 + 音量/静音，音频 = 时长 + 播放/暂停；图标二级、自身 hover 升一级）+ 视频底部 4px 播放条（轨道 亮色/半透明-2、填充 亮色/一级，贴底 4、左右 12）；**音频波形进度 = 品牌色同构波形层 clip-path 扫过**（与根数解耦，稿 prose；颜色 2026-08-29 用户定品牌色），hover / 播放中才显。波形竖线 4px gap 4 五级，圆头 99px 为稿值（Token.md 圆角无此档，非新造 token）。**根数口径（2026-09-22 R6 audio 接线修订，原「根数恒定由业务保证」精确化）**：稿 prose「根数一致」= **不随时长**（后端 `get_audio_peaks` 恒定供 128 根，mono 混音分桶 max-abs 归一、不分声道）；**根数随卡宽**——WaveContent 按容器宽 ÷ 节距 8 定根数、超量 max 池化重采样（4px/4gap 恒保稿值、任何卡宽两端铺满）。生产接线：AssetCard audio 档 → FileCard kind="audio"，胶囊播放钮经 FileCard `playToggle` → HoverAudioLayer（收窄为透明 seek 层）`togglePlay`；**ws 合成项 2026-09-26 起接通波形填充卡**（peaks 走 `get_audio_peaks_by_path`，产物缓存换锚 `workspace/.anikit/peaks/{url-safe(rel)}-{mtime_ms}-{size}.json`，文件名内嵌实况判新鲜）——**悬停播放层 / 悬停胶囊 ws 不出**（播放走 assetId 命令未开按路径版、ws 无时长数据：capsuleText 空串 = MediaCapsule 整体不渲染，空壳死钮不出）；**走带进度 = rAF 逐帧读 currentTime**（2026-09-22 实机修订——timeupdate 仅约 4Hz，扫过一段段跳；播放中起循环、暂停/结束/卸载停）；预览播放条 / 冲突弹窗仍用 PNG 波形（get_waveform / decode_preview_image 不动）。
