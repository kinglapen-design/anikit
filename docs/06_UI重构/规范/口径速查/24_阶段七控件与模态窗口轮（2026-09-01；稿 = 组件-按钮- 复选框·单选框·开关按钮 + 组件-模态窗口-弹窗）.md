# 24. 阶段七控件与模态窗口轮（2026-09-01；稿 = 组件/按钮/ 复选框·单选框·开关按钮 + 组件/模态窗口/弹窗）


- **新组件 4 件**：`buttons/Checkbox.vue` / `buttons/Radio.vue` / `buttons/SwitchButton.vue` / `modals/ConfirmModal.vue`（新目录）；前三个接口与旧 AppCheckbox / AppRadio / AppSwitch 对齐（v-model + label / value + label / disabled），业务接入随轮替换，旧件与 AppModal / AppConfirm 随迁移退役。
- **Checkbox**（复选框）：框 14×14 圆角 4 = 通用/三级底 + 通用/五级 1px 内描边；**hover 未选中描边 通用/六级**（稿 prose 误写「亮色/六级」——亮色系无此档，2026-09-01 用户定为通用/六级）；选中 = 品牌/常态底 + 亮色/半透明-1 描边 + **对勾-极小 check-tiny**（本轮入库，10px / 矢量 6×3 / 1px 线条，currentColor 由 .box 亮色/一级档驱动）；文字 = 次要文字 12/16 二级，gap 6。
- **Radio**（单选框）：外圈 18×18 圆 = 通用/一级底 + 通用/五级 1px 内描边 + 内 padding 2（hover 未选中描边 通用/六级，与选中外圈同档）；选中 = 内圆 14×14 品牌/常态底 + 亮色/半透明-1 描边；文字 = 正文-加粗 13/18，选中二级 / 未选三级（色过渡 150ms）。
- **SwitchButton**（开关按钮）：轨道 30×16 胶囊圆角 padding 2，圆钮 12×12；关 = 通用/四级底 + 通用/六级内描边 + 钮二级居左，开 = 品牌/常态底（无描边）+ 钮一级居右（横移 14px，右开左关）。
- **控件动画档**：对勾 / 单选圆点 = 弹出 **250ms 过冲**（cubic-bezier(0.34,1.56,0.64,1)，沿用旧 AppRadio 既定档——token 未收过冲缓动）+ 收回 **150ms 缓入快收不回弹**（2026-08-12 用户定案沿用）；开关横移 = **250ms 小位移**；底 / 描边 / 文字色过渡 = **150ms**。
- **ConfirmModal**（警告与错误弹窗）：窗口 **520 宽 padding 24 列 gap 24**，通用/三级底 + **1px 通用/五级真 border**（弹窗真 border 口径不变，新稿由 1.5 亮-选中改 1px 五级）+ 大阴影 + 圆角 8；**遮罩 = 黑色-50%**（新 token `--n-mask`，2026-09-01 用户定），点击不关闭；标题 = **18/26 Bold 亮色/一级**（新稿口径，旧「标题常态色 16px」随旧 AppModal 退役）；正文 13/18 三级；按钮行右对齐 gap 8（次左主右不变），**按钮 120×38**（新稿定宽，废 88×38）圆角 8 按钮文字-大——取消 = 通用/五级底 + 立体感-通用 + 文字二级，确认 = kind 色底（warning 状态/警告 / danger 状态/禁止 / brand 品牌/常态——稿：不危险的提示换品牌色）+ 立体感-主要按钮 + 文字一级；弹出动画 = 缩放 0.96→1 + 淡入 **150ms**。
- **稿未画状态清单（待用户补稿，不做不自创）**：复选框 / 单选框的选中态 hover 与禁用态；开关 hover 与禁用视觉（disabled 现仅不响应点击）；弹窗按钮 hover。
