# 59. 音频音乐预览落地与播放条波形塌陷修复（2026-09-25）

2026-09-25

- **音乐预览稿落地**：预览视口音频分支换代 = `PreviewAudio.vue` 居中立姿——唱片-icon 200（`vinyl` 装饰图标，渐变底 + 转盘 + 指针、opacity 0.6 与小阴影烘焙在 svg，AppIcon 引用）+ 文件名（标题档 18/26 Bold 二级，含扩展名）；块 = column 居中 gap 24 + padding-bottom 24（稿「图标+提示」200×274，与 PreviewUnsupported 同族立姿口径）。**预览界面无波形**——稿 prose「只在播放条上放波形图即可，预览界面无需波形图」；R5 的 PreviewAudioWave 波形大图与 previewSpecs/audioWave.ts 一并废除，spec 换代 = previewSpecs/audio.ts（注册表一行，宿主零改动，R5 范式第三次兑现）。播放条侧波形不变（FloatBarPlay #progress 的 WaveProgress，§36）。
- **WaveProgress 高度塌陷坑（错误信号定案）**：症状 = 播放条音频波形整体不可见，但 DOM 三层（base / played / head）齐全——探针 DOM 存在性断言（layers 2 + head）全绿测不出。根因 = `.fbp-progress` 无显式高度：`.fb-mode` align-items center 下盒子高度由内容撑，BarSlider 自带轨道高不塌（视频条一直正常），WaveProgress 根 `height: 100%` 在父高 auto 时百分比解析失败塌成 0（overflow hidden 连播放头一起裁没）。修复 = `.fbp-progress { align-self: stretch; }` 拉满内容盒 18（42 - padding 12×2）供百分比子高解析。回归起点 = 2026-09-09 播放条换悬浮栏轮（fb59785c）。**教训入档：高度 / 尺寸类塌陷必须截图或实尺寸断言目验，DOM 存在性断言无效**——本轮靠 stash 基线截图对照（塌陷版 vs 修复版播放头竖线）坐实修复。
- **preview 页同步**：PreviewStates 加音乐预览复刻壳（嵌真实 AppIcon vinyl；居中立姿族壳由 pv-us-* 抽象改名 pv-stand-stage/body/title，不支持预览与音乐预览两展区共用）；PreviewBars 音频语境格进度区换真实 WaveProgress + data-uri 演示波形（preview 页纯前端口径，不调后端 get_waveform；mask 只取 alpha）。
- **探针环境病留档**：cdp-playbar-probe 4 条 FAIL（动图预览未打开 / 全屏悬浮栏未浮窗级 / 音频 anchor 1346≠panel-24 / 回程未 morph 回搜索）经 stash 基线对照全同 = 探针桩数据（WaveContent 缺字段抛异常）与全屏时序漂移，非本轮回归，按探针纪律停手未修，留待探针专项轮清理。

## 同日二轮：高清波形「加载完就空」= 后端小高度振幅被留白吃光（踩坑 087）

- 前端塌陷修好后实机再走查浮出同族第二条：播放条波形**加载完反而空**（只剩播放头），加载前的「旧波形图」= info 缩略图回退。根因在后端 `render_waveform`：上下留白恒 10px（5.1 为 272 高大图定的常量），18px 播放条请求 `max_half = 9-10 = 0` → 全图只剩 1px 中线。修复 = 留白等比收缩 `WAVEFORM_MARGIN.min(h / 27)`（272 及以上恒 10 不变，18px margin 0 满幅）；回归钉 `render_waveform_small_height_keeps_amplitude`。教训 = **渲染函数参数化后，函数内一切 px 常量必须过「随尺寸缩放还是恒定」**；「回退图正常、高清图反而坏」= 两条产物链尺寸档差异先查。
