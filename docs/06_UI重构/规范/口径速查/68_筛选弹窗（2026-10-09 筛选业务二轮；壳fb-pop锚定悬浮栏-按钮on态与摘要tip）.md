# §68 筛选弹窗（2026-10-09 筛选业务二轮；壳 .fb-pop 锚定悬浮栏 / 按钮 on 态与摘要 tip）

稿 = 布局/主窗口/中间面板/中间面板-多功能悬浮栏-筛选/ 九子稿；组件稿 = 组件/悬浮栏/多功能悬浮栏/搜索栏展开成筛选。本轮落地 chip 类三维度（扩展名 / 链接 / 属性），其余维度随对应轮接入时回补本节。

## 壳与定位

- 壳 = `.fb-pop`（bars.css 既有：通用/半透明-1 + 立体感-模糊-大阴影 + blur + 圆角 8），弹窗根类统一 `.fp-root`（placePop 选择器）。
- 定位 = 底边锚定悬浮栏顶上方 12（`.fbh-pop` bottom: calc(42px + 12)，RatePop 族同径）；水平 = 触发钮中心对齐弹窗中心，钳制在 anchor 内（`placePop(ev, "filter")` 同一管线）。
- 显隐动画 = fbh-pop（透明度 + 轻微缩放 150ms，旧 menu-pop 语义 + token 档）。

## 开合（点击制）

点筛选钮开 / 再点同钮关 / 点外关 / Esc 关 / 切视口或切出搜索态（预览、md 工具栏）随语境收。点外判定 = document pointerdown 捕获期，落点在 `.fp-root`（弹窗）或 `.fbs-chip`（筛选钮）内不关；Esc 分层 = 弹窗开着先关弹窗，否则维持「清空并失焦」旧口径。筛选钮 mousedown.prevent 阻失焦（§36 口径）不变。

## 按钮呈现形态（2026-10-09 定稿，PRD 03 §2）

- on 态（半透明-1 底 + 一级文字，稿选中态）= **该维度有生效条件 或 弹窗打开中**（activeFilters = activeFilterDims ∪ filterPop）。
- 生效条件摘要 = 按钮 v-tip（search store `filterSummaries`；空串不出 tip，链接态四态与 `seq` 序列帧显示中文文案）。
- 「标签」按钮落地名 = **属性**（PRD 03 §2，标签体系 2026-08-04 已取消）。

## chips 弹窗（扩展名 / 链接，FilterChipsPop）

- chips = **TagButton solid sm**（未选 通用/五级 + 立体感-通用；选中 品牌/常态 + 立体感-主要按钮 + 一级文字，稿 prose「可以多选」）。
- 单行横排 padding 12 gap 8，max-w 380（稿 379 上限），超出换行限 4 行滚轮（max-h 144，标签稿「列表太长加滚轮」同口径）。
- **两稿无清除钮**——取消靠再点 chip，条件清零维度即失效（2026-10-09 按稿定，不擅自补）。

## 属性弹窗（FilterTagsPop）

- 宽 350 壳 padding 0 两段式：头行 44 高（padding 8/8/8/12 gap 8）= 搜索框 **TextInput sm + leading search**（稿 28 高，sm 26 稿差标注）+ 清除钮 **TagButton solid md**（48×28 通用/四级）；1px 亮色/半透明-3 分隔线（border-top，非独立元素）；chips 流式区 padding 12 gap 8、max-h 306 滚轮。
- 搜索过滤 = 子串包含不区分大小写（组件内纯视图计算）；被过滤掉的选中项仍生效。
- **清除 = 清空全部选中，不清搜索输入**（稿定）。

## 数据源（零后端新增）

扩展名候选 = 库内实有扩展名集（首项恒列「序列帧」seq 虚拟类别——frameCount 序列帧 / 动图 / 视频同字段不可据以判定，选中零结果属正常筛选语义）；属性候选 = 全库属性词集；均前端自 `content.placements` 算出。条件 per-panel 存 search store，随 `search_assets` scope.filters 下发（接口 11）。

## 列表族三弹窗（2026-10-09 三轮：文件夹 / 比例 / 日期）

- **共享件（bars.css 列表族）**：`.fp-list`（纵向 padding 12 gap 4 滚轮）+ `.fp-item`（26 高 padding 4/6/4/8 圆角 6，正文-加粗 13px；选中 = 一级文字 + `.fp-check` 对勾 18 显，未选 = 三级文字 + 对勾隐，hover 半透明-3 底）+ `.fp-custom`（自定义尾行 34 高）。
- **文件夹（FilterFoldersPop，350×468 稿）**：头行同属性弹窗（搜索 + 清除，清除 = 清空全部选中不清搜索输入）；树区 max-h 424 滚轮——首项「未分类」（uncategorized 图标 + root 直属数）+ 库文件夹树**扁平化渲染 + TransitionGroup + expandAnim 150ms**（行缩进 18/层，展开箭头 expand 旋转 90°，folder-open/-closed 双色调 TwoToneIcon 通道：未选 l2·l3 → 选中 l1·l2 升亮，稿 #666/#CCC → #CCC/#F2F2F2 的 token 近似）；数量 = FolderNode.count 递归总数（Fira Mono 12 三级）；选中行 = 半透明-2 底 + 立体感-通用（稿 prose）。**勾选 = folderIds 含后代**（勾父圈整棵子树，三轮定案；后端预展开后代集）。
- **比例（FilterRatioPop，164×148 稿）**：预设三档（横图 / 方形 / 竖图）+ 尾行自定义「宽:高」（TextInput sm 40 宽两框 + 生效对勾）；focusout / Enter 提交（两框齐全正数生效、全空撤销、半成品不提交）。
- **日期（FilterDatePop，207×238 稿，添加 / 修改共用）**：预设六档（当天 / 昨天 / 最近一周 / 最近一月 / 最近一年 / 更早）+ 尾行年月日三框（年 55 / 月日 40，placeholder = 年 / 月 / 日，任意组合生效、非法值不提交）；两者按稿**无清除钮**（预设再点取消、自定义清空撤销）。
- 摘要 v-tip 同轮补齐：比例（横图 / 16:9）、两日期（当天 / 2026-10-3）；文件夹维度需树名称解析暂不出摘要。

## 输入类三弹窗（2026-10-09 四轮：颜色 / 时长 / 大小）

- **颜色（FilterColorPop，250×339 稿）**：单选色条件（colors 取首项）。色盘 226×223 = **SV 盘 canvas 三层渐变自绘**（纯色底 hsl(hue,100%,50%) + 白水平 + 黑垂直；色相 = 当前色色相、品牌蓝 204 兜底，取色回环 hue 差 <1° 不重绘防抖）+ 选择环（14 空心白环）+ 点击 / 拖动取色（pointer capture）；HEX 行 = TextInput lg **leading slot**（16×16 色块圆角 4；空态白底斜杠 = 渐变细线，稿 prose）+ 清除 TagButton md；RGB 行 = 三框 50 宽固定（**不定 flex:1**——TextInput 根恒 width:100% 均分会把 48 钮挤溢出，走查实证）+ RGB/HSL 切换钮（钮面 = 当前模式）。颜色换算（hex↔rgb↔hsv/hsl）组件内私有。
- **范围（FilterRangePop，时长 328 / 大小 348 稿共用）**：单位切换器（通用/六级底 + 圆角 6 + 28 高；单位文字并列点击切换，当前一级 / 其余三级 hover 升二级，expand 14 旋转 90° 朝左纯装饰）+ 最小 / 最大 TextInput lg 69 宽（focusout / Enter 提交，非法 / 负值不生效）+ 清除 TagButton md。时长 unit ↔ frames/seconds/minutes 随条件下发；大小条件恒字节，KB/MB/GB 纯显示档（FloatBarHost 换算进出，sizeUnit 会话级保持）。
- **TextInput 扩 leading slot**（与 leadingIcon 同位互斥、slot 优先，gap 复用 has-lead）——颜色色块首例消费。

## 菜单入口（2026-10-09 五轮）

菜单栏「查找 ▸ 筛选器」子菜单点亮（appMenu findEntries）：维度项与按钮组 10 项同序同名，点击 = search store `requestFilterPop`（focusSeq 同模式三 ref）→ FloatBarHost watch → `openFilters()`（FloatBarSearch → FloatBar 透传 expose）展开筛选组 + filterPop 开对应弹窗（placePop 无事件 = anchor 中心定位）；「重置所有筛选」= `clearAllFilters`（无生效筛选 disabled）；ws 视口整组 disabled（与筛选钮不渲染同口径）。
