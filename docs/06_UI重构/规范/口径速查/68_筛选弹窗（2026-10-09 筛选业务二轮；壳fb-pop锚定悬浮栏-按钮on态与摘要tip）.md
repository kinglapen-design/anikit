# §68 筛选弹窗（2026-10-09 筛选业务二轮；壳 .fb-pop 锚定悬浮栏 / 按钮 on 态与摘要 tip）

稿 = 布局/主窗口/中间面板/中间面板-多功能悬浮栏-筛选/ 九子稿；组件稿 = 组件/悬浮栏/多功能悬浮栏/搜索栏展开成筛选。本轮落地 chip 类三维度（扩展名 / 链接 / 属性），其余维度随对应轮接入时回补本节。

## 壳与定位

- 壳 = `.fb-pop`（bars.css 既有：通用/半透明-1 + 立体感-模糊-大阴影 + blur + 圆角 8），弹窗根类统一 `.fp-root`（placePop 选择器）。
- 定位 = 底边锚定悬浮栏顶上方 12（`.fbh-pop` bottom: calc(42px + 12)，RatePop 族同径）；水平 = 触发钮中心对齐弹窗中心，钳制在 anchor 内（`placePop(ev, "filter")` 同一管线）。
- 显隐动画 = fbh-pop（透明度 + 轻微缩放 150ms，旧 menu-pop 语义 + token 档）。

## 开合（点击制）

点筛选钮开 / 再点同钮关 / 点外关 / Esc 关 / 切视口或切出搜索态（预览、md 工具栏）随语境收。点外判定 = document pointerdown 捕获期，落点在 `.fp-root`（弹窗）或 `.fbs-chip`（筛选钮）内不关；Esc 分层 = 弹窗开着先关弹窗，否则维持「清空并失焦」旧口径。筛选钮 mousedown.prevent 阻失焦（§36 口径）不变。

## 按钮呈现形态（2026-10-09 定稿，PRD 03 §2）

- on 态（半透明-1 底 + 一级文字，稿选中态）= **该维度有生效条件 或 弹窗打开中**（activeFilters = activeFilterDims ∪ filterPop）。
- 生效条件摘要 = 按钮 v-tip（search store `filterSummaries`；空串不出 tip，链接态四态与 `seq` 序列帧显示中文文案）。
- 「标签」按钮落地名 = **属性**（PRD 03 §2，标签体系 2026-08-04 已取消）。

## chips 弹窗（扩展名 / 链接，FilterChipsPop）

- chips = **TagButton solid sm**（未选 通用/五级 + 立体感-通用；选中 品牌/常态 + 立体感-主要按钮 + 一级文字，稿 prose「可以多选」）。
- 单行横排 padding 12 gap 8，max-w 380（稿 379 上限），超出换行限 4 行滚轮（max-h 144，标签稿「列表太长加滚轮」同口径）。
- **两稿无清除钮**——取消靠再点 chip，条件清零维度即失效（2026-10-09 按稿定，不擅自补）。

## 属性弹窗（FilterTagsPop）

- 宽 350 壳 padding 0 两段式：头行 44 高（padding 8/8/8/12 gap 8）= 搜索框 **TextInput sm + leading search**（稿 28 高，sm 26 稿差标注）+ 清除钮 **TagButton solid md**（48×28 通用/四级）；1px 亮色/半透明-3 分隔线（border-top，非独立元素）；chips 流式区 padding 12 gap 8、max-h 306 滚轮。
- 搜索过滤 = 子串包含不区分大小写（组件内纯视图计算）；被过滤掉的选中项仍生效。
- **清除 = 清空全部选中，不清搜索输入**（稿定）。

## 数据源（零后端新增）

扩展名候选 = 库内实有扩展名集（有序列帧资产时首项「序列帧」seq 虚拟类别）；属性候选 = 全库属性词集；均前端自 `content.placements` 算出。条件 per-panel 存 search store，随 `search_assets` scope.filters 下发（接口 11）。
