# 61. 信息查看管理面板轮（2026-09-26；三 tab 化重立，旧 22 稿 SectionEditPanel 后继）

稿 = 无（用户当场定案：「重新设计，三 tab 和详情面板三 tab 对应」）；样式全部复用定稿族件——壳 = BaseModal framed 460（管理弹窗族：区块管理 559 / 分组管理 640 先例），行 = DetailBlockRow（BlockManageRow 范式），显隐图标 = view / view-off（用户直投入库，第十六批）。三个无稿自定点经用户方案确认：壳宽 460、显隐用眼睛（不用 SwitchButton）、即时生效无按钮行。

- **业务定位**：旧 22 稿「编辑数据区块」面板（AppMenu 404×440，2026-08-31 三 tab 化随旧区块体系删除）的后继——详情面板三 tab 区块的**排序 + 显隐**管理。入口双路同置位：右栏底部「信息查看管理」钮 + 菜单栏「视图 → 信息查看管理」（原 disabled 占位点亮）→ `ui.infoManageOpen`（会话级），宿主 App.vue（blockManageOpen 惯例）。

- **结构（InfoManageDialog）**：framed 标题栏 54 → SegmentedControl **text 型三段**（基础信息 / 链接关系 / 提示词，与详情面板三 tab 一一对应；g3 壳语境 **tone g2**，§48）→ 行列表**定高 260**（5 行×52，切 tab 弹窗不跳高；超出 kit-scroll + ScrollThumb）。**打开默认落详情当前 tab**（ui.detailTab 快照，面板内切换不反写）。framed 内容段自承 padding 0 24，底部 24。

- **行（DetailBlockRow）**：高 52（border-box 含 padding）/ padding 12 0 / gap 8 / 底线 g5 **末行去线**——下移+上移箭头（IconButton bare sm chevron-small，源图形朝上：下移 rot-180；首行禁上 / 末行禁下，禁用 = 新件自带 30% 透明度；可用态 l1 提权照 bm-row 写法）+ 区块标题（13/18 l2；**隐藏行标题 = --n-l-disabled 禁用色**——22 稿注「眼睛切换标题要禁用」）+ 眼睛（bare lg：可见 view / 隐藏 view-off；常态 l3 hover l2 新件自带档）。

- **即时生效无按钮行**（旧 22 稿口径 + 用户定）：排序/显隐直写 `ui.detailBlocks`，settings.ui 防抖 500ms 写回，详情面板实时跟随；无确认/取消（区块管理草稿式不适用——纯视图配置无后端事务）。

- **配置 = ui.detailBlocks（三 tab 各 { order, hidden }）**：order = 全量序（含隐藏项，管理面板行序）；hidden = 隐藏清单（详情渲染过滤）。注册表 = lib/detailSections.ts（DETAIL_BASIC_BLOCKS = fields/tags/descs/baseData + DETAIL_LINK_BLOCKS + DETAIL_PROMPT_BLOCKS + DETAIL_TAB_BLOCK_TITLES），mergeDetailBlocks 兜底（未知 id 忽略 / 缺 id 注册表稿序补位 / hidden 过滤已知 id）。**旧 ui.detailLinksOrder 迁移并入 links.order 后废除**（loadSettings 迁移通道，briefMode 先例）；文件/档案共用一套（三 tab 化后口径，旧双套不复活）。

- **排序双入口同一配置**：管理面板箭头 = 全量序移动（moveDetailBlock）；链接 tab 面板内拖标题行 = **可见序落点**（moveDetailLinkToVisible——hidden 项锚定原位，可见项按新序回填重建全量序）。排序动画 = TransitionGroup 交换 150ms（bm-swap 同款）；tab 切换动画 = 详情面板同款（旧左出 / 新右入 48px，§23 时序四调）。

- **隐藏口径**：hidden 区块整块不渲染（含链接 tab 标题行——§23「标题行恒渲染」是对空数据而言，用户主动隐藏不在其列）；**允许全隐藏**（tab 空 = 空白，无空态文案）；提示词单区块排序箭头自然全禁、仅显隐；pinned 恒顶不进面板（旧口径沿）。基础信息四区块行标题按子稿命名 = 名称与链接 / 标签 / 详情 / 基本数据（详情侧无标题行，面板行标题属管理语境）。
