## 01. 搜索

搜索与筛选分离（2026-08-31 用户定案，随阶段七多功能悬浮栏落地）：搜索 = 底部多功能悬浮栏单行输入（中间面板居中、距底 12），输入即自动实时搜索，空格分词 AND；筛选 = 悬浮栏筛选按钮组 + 弹窗（见 2 节）。

``` text
"~"      本条搜索强制全局（手敲前缀，无范围按钮；全局 = 全库，回收站除外）
"Ctrl+F" 快速聚焦搜索框
"Esc"    清空搜索并失焦
```

> 2026-08-31 废除：tag 化 chips（`~` / `//` / `/` 前缀 tag、空格成 chip、右侧 kbd 提示组）与 `/`、`//` 前缀指令——原「筛选搜索统一搜索框 + 前缀指令切换」口径（2026-08-19 定）随悬浮栏「筛选与搜索分离」定案作废；`~` 前缀保留（后端解析，手敲生效）。

#### 1. 普通搜索

直接输入 人物 + 空格 + 走路 时，即可搜索出当前目录的 人物-开心-走路、人物-伤心-走路 等文件。

输入 `~` 前缀切换至全局搜索，可搜索出全部素材里的 人物-XX-走路（全局 = 全库，回收站除外）。

**搜索态展示（3.6 一轮落地，2026-08-19 用户逐项定案）**：结果替换素材区（清空搜索框即恢复原视图）；命中素材 + 命中档案（ArchiveCard）显示，文件夹区块隐藏；排序按当前排序设置生效，分组失效平铺；当前目录范围跟随递归显示开关；快速访问视图 = 当前视图即当前范围（回收站里搜回收站）；无结果 = 中央「无搜索结果」文案。档案命中范围 = 档案名 / 徽标文本 / 属性 / 描述 / 链接（档案数据已就位）；档案区仅文件夹视图出（快速访问视图同既有口径不出），非全局仅直属口径、全局 = 全库命中档案。

分词搜索命中范围（2026-08-04 扩展，见 [[03_数据链接]]；**MVP 落地子集** 2026-08-19）：资源名、各 Placement 显示名、扩展名、链接、所在路径（区块 / 文件夹 / 档案名）、徽标文本（档案徽标已就位）、档案属性与档案描述（已就位）；**资产侧属性与描述 6.1 已纳入（2026-08-23）**，提示词、关系与音色的对象名及关系名随对应功能就位后纳入（阶段六）；标注名、注释随对应功能就位后纳入（注释 / 描述 MVP 后置，见 [[02_文件整理]] 06 节）。颜色、尺寸 / 比例、文件大小、时长、各日期为筛选维度，不纳入分词搜索。

匹配规则：空格分词 AND；逐关键字**子串包含**匹配，不区分大小写；链接字段匹配前先做 **URL decode**（抓取链接中编码的关键词可命中，如 `q=%E6%A1%A3%E6%A1%88` → 输"档案"可命中）。

- 索引式工作空间无附加数据，分词搜索仅命中文件名与路径（已落地 2026-10-03 = Everything 手写 IPC + 自研爬盘回退双层，`~` 全景 / 无 `~` 当前目录子树、回退不接 `~` 走通知栏指路；口径与触点见 [[01_资源与数据]] 02 索引式工作空间「搜索」节）。

#### 2. 筛选

悬浮栏搜索框右侧筛选图标，点击横向展开筛选按钮组：颜色、时长、标签、扩展名、文件夹、比例、链接、大小、添加日期、修改日期（阶段七设计稿：布局/主窗口/中间面板-多功能悬浮栏 + 中间面板-多功能悬浮栏-筛选 9 子稿）；标注、注释、描述随对应功能就位后补齐，评分已移出 MVP（2026-07-28 定），标签随体系取消改为属性（2026-08-04 定）。

每个按钮弹出对应筛选弹窗（与悬浮栏保持 12 间距）供选择条件，如文件夹弹窗 = 文件树复选框、可输入名称搜索文件夹；支持多选。**条件选中后的呈现形态与交叉组合口径已定案（见下两段）**（2026-08-31 悬浮栏接入轮：按钮组点亮不接业务——点击仅切换选中态，筛选弹窗与后端筛选条件随筛选轮点亮；旧「输入 `/` 弹下拉菜单、选择项创建筛选 tag 带删除角标」口径随 tag 化一并废除）。

**交叉组合口径（2026-10-09 用户定案，筛选业务一轮）**：维度内多选 = OR（如扩展名同时选 fla / psd = 命中任一），跨维度 = AND，筛选 × 分词搜索 = AND（即下方交叉定位示例）。筛选激活时档案区默认不出（筛选 = 找文件；例外见下「档案」虚拟类别）。「标签」按钮落地名 = **属性**（标签体系 2026-08-04 已取消）。各维度语义要点：颜色 = 主色近似匹配（色盘取任意色，非精确等值）；时长单位帧 = 按素材自身 fps 换算；比例 = 横图 / 方形 / 竖图三档 + 自定义比；日期 = 当天 / 昨天 / 最近一周 / 最近一月 / 最近一年 / 更早六档 + 自定义年月日（添加 / 修改两按钮共用弹窗）；链接状态 = 原始 / 链接 / 缩略图 / 无链接四态；扩展名含「序列帧」「档案」两虚拟类别——**「档案」类别（2026-10-11 用户定）** = 档案区参与筛选的入场券：勾选后档案按可判定维度参与（属性 / 所在文件夹 / 添加日期），资产专属维度（颜色 / 时长 / 比例 / 大小 / 链接状态 / 修改日期）激活即出局；未勾选时筛选激活档案区不出（筛选 = 找文件）。实现口径（容差数值等）见接口文档 11_分词搜索。

**呈现形态与弹窗交互（2026-10-09 筛选业务二轮落地，auto 模式定稿、待用户实机确认）**：筛选钮 on 态（半透明-1 底 + 一级文字，稿选中态）= 该维度有生效条件 或 弹窗打开中；生效条件摘要 = 按钮悬停 tip（如「fla、psd」）。弹窗 = 点击制开合：点筛选钮开、再点同钮关、点外关、Esc 关（Esc 分层：弹窗开着先关弹窗，否则维持清空并失焦旧口径）、切视口 / 切出搜索态（预览等）随语境收；条件变更即时生效无确认（稿无确认/取消钮）；属性弹窗清除 = 清空全部选中（不清搜索输入，稿定）；扩展名 / 链接弹窗按稿无清除钮（再点 chip 取消，条件清零维度即失效）。弹窗数据源零后端新增：扩展名候选 = 库内实有扩展名集（首项恒列「序列帧」「档案」两虚拟类别，后者 2026-10-11 接入），属性候选 = 全库属性词集（均前端自 placements 算出）。

**列表类三维度（2026-10-09 筛选业务三轮落地）**：文件夹 = 树形复选（搜索 + 递归数量 + 未分类首项，双色文件夹图标随选中升亮），**勾选 = 自身或后代**（勾父圈整棵子树，树形复选通用心智，三轮定案）；比例 / 日期 = 预设档位多选 + 尾行自定义行（比例「宽:高」两框、日期年/月/日三框任意组合，自定义行对勾 = 自定义条件生效态），focusout / Enter 提交、半成品不生效；两者按稿无清除钮（预设再点取消；**自定义反选 = 对勾可点取消自定义并清框**，两框 / 三框清空同效，2026-10-09 走查修订）。

**输入类三维度（2026-10-09 筛选业务四轮落地）**：颜色 = **单选色条件**（后端 colors 数组取首项）——SV 色盘自绘（水平饱和 / 垂直明度 / 色相随当前色，稿位图落地口径，点击 / 拖动取色）+ **色相条**（226×12 彩虹渐变 + 指示环，点击 / 拖动换色相；稿无此件、稿内换色相只能输数值，2026-10-09 用户拍板补，弹窗高 339 → 363）+ HEX 输入（前置色块，空态白底斜杠）+ RGB / HSL 三框互切（切换钮面 = 当前模式）+ 清除（稿 prose 全套）；时长 / 大小 = 单位切换（帧/秒/分、KB/MB/GB：单位文字并列点击切换，稿「单位下拉菜单」形态）+ 最小 / 最大 + 清除。时长单位随条件下发（帧 = 后端按素材自身 fps 换算）；大小条件恒字节，KB/MB/GB 为纯显示档（数值按当前单位换算进出）。**定宽弹窗稿宽下限防守**（2026-10-09 走查修订：颜色 / 属性 / 文件夹弹窗 min-width = 稿宽）——悬浮栏弹层 `max-width: 100%` 在窄 anchor 下会压缩弹窗、定宽内容（色盘 / 树）与行内右端件（清除钮）被挤溢出；恒稿宽时超窄 anchor 由 placePop 钳制管位置，不压坏内容；弹窗内输入框一律 `min-width: 0` 放开收缩（防 shrink 卡死顶出右端件）。

**菜单入口（2026-10-09 筛选业务五轮落地）**：菜单栏「查找 ▸ 筛选器」子菜单点亮——维度项与悬浮栏按钮组 10 项同序同名，点击 = 当前 panel 悬浮栏展开筛选组并打开对应弹窗（ws 视口无筛选能力整组禁用，与筛选钮不渲染同口径）；「重置所有筛选」= 清空全部筛选条件（无生效筛选时禁用）。

交叉定位示例：筛选按钮组选「扩展名：fla」+ 搜索框输「男人」，即定位到名称为男人且格式为 fla 的文件。

#### 3. 搜索模式

分词搜索 = 默认模式（悬浮栏直接输入）；向量搜索、AI 搜索列为后续版本——入口 = 悬浮栏搜索图标点击展开选项（设计稿 prose，随对应版本点亮）。

- **智能路由：** 默认无需手动选择，带空格的关键字走分词搜索，自然语言句子自动走向量 / AI 搜索，搜索图标选项仅作为手动覆盖。
- **时间轴定位（向量搜索）：** 视频、动图、序列帧经手动分析（粗略 / 详细两档）后按镜头切分建立分段索引，搜索命中的是"某视频的某段时间"——如搜"马奔跑"，可命中多部动画中的奔跑片段，搜台词同样可定位；结果卡片显示时间点，点击跳转至预览的对应进度。未分析的素材不参与语义搜索，分词搜索不受影响。
- **版本规划：** 分词搜索进入 MVP（3.6 一轮已落地，2026-08-19）；向量搜索、AI 搜索列为后续版本。

## 02. 快捷搜索框

按 alt + ` 可在不调出主界面的情况下呼出，快捷搜索框默认全局搜索，复用主窗口搜索交互（悬浮栏单行分词 + `~` 全局前缀；当前目录指主界面当前所在的文件夹）。

- **常驻后台：** 该功能要求软件可最小化至托盘常驻后台。
- **热键自定义：** 全局热键允许用户修改，避免与输入法、其他软件的全局快捷键冲突。

## 03. 扫描重复文件

> 2026-08-13 用户定案（35_扫描重复文件 稿 + Eagle 式合并前确认两轮讨论）。入口：菜单栏「菜单 ▸ 查找 ▸ 扫描重复文件 ▸ 全部」（= 全部范围；2026-09-05 主菜单轮自旧汉堡入口迁入）；新增菜单「扫描重复文件 ▸」二级三范围——当前目录 / 全部 / 所选文件（无当前文件夹 / 无选中素材时对应项禁用）。

#### 1. 扫描口径

- 按存量 `metadata.hash` 把当前库资产分组，同 hash ≥ 2 个不同资产 = 重复组；**按资产去重**——同一资产的多条链接共享一份实体文件，不重复列出；卡片信息一律取 origin Placement（只扫描原始文件，链接状态徽章恒为原始文件徽章）。
- 扫描范围为**锚点过滤**：组内任一资产命中范围，整组返回（当前目录有一份、别处有相同文件也能扫到）——全部 = 无条件；当前目录 = 组内任一资产的 origin Placement 位于当前文件夹；所选文件 = 组内任一资产属于当前选中集合。
- 扫描不重算 hash（用导入期存量值）；无结果时不弹窗，toast「未发现重复文件」。

#### 2. 结果列表（屏 1，35 稿）

- 每组一行：组级复选框「N 个相同文件」**默认全选**（用户单个取消）+ 行尾红色 ⊖ = **从列表移除该组**（纯前端操作，文件不做任何处理）；卡片横排（327 卡片：缩略图 / 名称 / 宽×高 / 格式徽标 / 原始文件徽章），超过两个出横向滚动条。
- 底部：「已选择 N 个文件」= 选中组资产总数；「可节约 X 储存空间」= 选中组 Σ(组内 n-1) × 文件大小；按钮 = 合并（主，无选中组禁用）/ 取消。

#### 3. 合并前确认（屏 2，Eagle 式两步，2026-08-13 用户定）

- 点「合并」进入确认屏：左列 = 选中组列表（缩略图 + 名称 + N 个文件，当前组高亮，可切换）；右列 = 当前组资产横条列表（缩略图 + 名称 + 大小 + 所在文件夹标签），**radio 单选保留哪一个**，用户可逐组改选。
- **默认选中 = 导入最早的那一个**（`imported_at` 升序第一个，同刻平手按 assetId 字典序；不按文件时间、不按数据量）。
- 不做 Eagle 的字段级合并（文件名 / 链接 / 文件夹 / 标签 / 注释逐项勾选不要）——保留者整体保留，其余整体处理。

#### 4. 合并执行

- 每组保留用户选中的 1 个资产，**其余资产连同其全部 Placement（原始 + 链接）移入回收站**（复用 `delete_placements` 回收站语义：recycle.json 记录、info 原地不动、一次 undo 可整体撤销；物理空间在清空回收站后才真正释放）。
- 保留者的元数据不合并（落选者的笔记 / 链接等随资产进回收站，不做迁移）。
- 「扫描文件/档案链接」复用本样式（原始文件列前、链接列后、复选 = 删除链接、选中压暗 30%、默认全不选），随该业务单独立项。
