## 01. 批量收藏

与 Eagle 浏览器扩展同类：在网页上一键抓取图片，批量导入资源库。

- **抓取：** 收集当前页面全部图片，列表展示（缩略图 + 尺寸），支持按尺寸过滤、全选 / 多选。
- **拖拽保存：** 支持从网页直接拖拽图片到 AniKit 窗口入库。
- **保存位置：** 保存时选择目标文件夹，或默认进入"未分类"。
- **导入流程：** 复用 [[05_导入与导出]] 的建档流程（生成 ID、metadata、hash 查重、缩略图）。

## 02. 技术形态

- **扩展：** Chrome / Edge 扩展（Manifest V3）。
- **通信：** 扩展通过本地 WebSocket（127.0.0.1，与 [[07_动画软件通信]] 同一条通道）把选中的图片地址交给 AniKit，由 AniKit 下载入库；软件未启动时提示先启动。
- **职责划分：** 图片下载、hash 查重、建档均在 AniKit 侧完成，扩展只做收集与转发，保持极薄。
