## 07. 工作台转型（2026-09-20 三轮讨论定案）

MCP 外接通道落地（[[06_AI外接通道MCP]]）后，用户重新定位了产品方向：纯粹素材管理在 AI 时代意义变薄——找半小时素材不如直接生成一张。**AniKit 转型工作台：不做 agent，做 agent 的工作台**。

### 定位：为什么不做 agent

大公司的成熟 agent 产品（Kimi Code / Claude Code / Codex 等）自带生图能力、有更大权限、能调用终端，正面做 agent 打不过也没必要。内置 agent 的难点还不在代码：安全、拦截、红线、为每个场景写 system prompt，本质是「判断对错」的责任链，而判断对错的活终点永远是人（03 节 L4 定案本来就承认这一点）。

但这些产品**进不了 AniKit 的库**——封闭 assets 池、Placement、链接归组、回收站、撤销体系是它们的盲区。AniKit 的不可替代位不在「生成」，在「归宿与整理」。

### 库的角色转换：素材超市 → 生产中转仓

「找素材」需求被生成替代，「管产物」需求被生成放大：一次漫剧生产几百张图、几十个镜头版本，没有查重、链接、分组、回收站，文件夹三周乱成垃圾场。角色设定图、风格参照这类**一致性资产**更是生成替代不了的——同一角色两百个镜头必须复用，不能每次重生。库从「素材的入口」变成「产物的归宿 + 一致性资产库」。

### 双载体分工：文件夹管生产，库管归宿

agent 与 skill 需要真实文件夹作工作区，库式管理没有实际文件夹——这不是冲突，是分工，PRD 08-06 的工作目录架构已定：agent 的 cwd = 项目文件夹（落在索引式工作空间内，真实磁盘结构、磁盘与 UI 双向热刷新），库只当资产归宿，一切进出走 MCP 工具。工作空间管生产现场，库管资产归宿，MCP 工具面是两者之间的传送带。

### 红线工程化：安全不靠 prompt 靠结构

MCP 路线把内置 agent 最难的三件事提前解决了，且答案都是工程而非提示词：

- **红线 = 工具面白名单**：「不许彻底删除」不靠 prompt 约束，靠 recycle.rs / purge.rs 根本不注册成工具——没有调用路径的错误不可能发生（trash_placements 落地即范例：允许丢回收站 = 开一个工具，不许彻底删除 = 另一批工具永不开）。
- **拦截 = 写入闸 + 撤销**：全局开关逐次检查、Ctrl+Z 兜底、大批量删前自动备份，库层既有能力，与 agent 内置外接无关。
- **场景 prompt = instructions + 项目说明书**：握手 instructions 是通用口径，每个项目 `.agents/` 里的工作流说明书就是场景 prompt——用户可改、随项目演进的活文档。

### skill 内置三层落地

skill 的本质是文件夹里的 md 说明书，载体已有（08-06 约定 `.agents/` 放工作流说明书、`06_AI_temp/` 当生成候车区）。AniKit 按投入从小到大做三层：

1. **项目骨架模板**：新建项目文件夹一键生成骨架——`.agents/` 工作流说明书（拆剧本 → 生成 → 入库 → 改名 → 链接进场次的定稿流程）+ 目录约定 + mcp 配置说明。`assets/templates/` 模板机制扩一类「项目骨架」，最佳工作流沉淀成模板，每个新项目自带。
2. **硬链接出库**：库 → 工作区现在是 `get_asset_origin_path` 拿路径 agent 自行复制，能跑但糙；硬链接出库不占双份磁盘、库封闭性不破，随阶段九 2.9 硬链接合并考虑。
3. **工作空间补完**：阶段十二剩余步骤做完，agent 的生产现场才算完整。

### 内置 agent 定案（收窄保留，排很后）

内置 agent 不做但也不砍死：**排期放很后，职责收窄为只干简单的活——整理、命名、打标签，不参与生产**。这三样是确定性最高、几乎不需要判断对错的杂活，且 MCP 工具面已覆盖（rename / move / link，打标签对应余量批 `set_asset_props`）；真到排期日，内置 agent = 内置模型 + 现有工具面 + 现成红线层，与外部 agent 各吃一段（外部的管生产流水线，内置的干碎片整理）。详见 [[03_AIAgent]]。

### 废除清单（2026-09-20 用户定）

- **01_AI创作 整体废除**：对话框生图 / 视频生成 / 透明通道生成 / 无限画布（远期）全部算了——生产交给外部工具与 agent。
- **02_AI工具 收窄**：扩图（生成式 outpainting）/ 转角度（图生图）/ 拆分场景（分割 + 补全）三条生成向的随 01 一并废除；一键抠图 / 超分两条素材应急处理类保留，优先级降至最低，随需要再评。
