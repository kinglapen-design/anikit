## 01. AI 创作

简化版是对话框形式，通过上传参考图，或者将素材库里的图片素材右键固定到对话框作为参考图，然后输入提示词生成。

- **参考图一键固定：** 凡 info 文件夹内有伴生图的素材——图片、动图封面帧、PSD / AI / fla 的缩略图——都可右键一键固定到对话框作为参考图，无需用户手动导出图片；无伴生图的（系统图标类）不支持。
- **提示词模板：** 支持用户保存提示词模板。
- **透明通道生成：** 动画道具大多需要透明通道，两条路线——
	1. 可靠路线（默认）：生成后自动过一遍抠图模型（BiRefNet / RMBG-2.0，开源，可本地可 API）后处理，输出透明通道 PNG，与 02 的一键抠图复用同一能力；
	2. 原生透明生成（可选增强）：如 gpt-image-1 的透明背景输出、SD 生态的 LayerDiffuse。
- **无限画布（远期里程碑）：** 终极目标是将中间的内容展示面板变成无限画布。自研成本高，可行路径是基于现成画布库（tldraw 等）集成"素材引用 + AI 生成节点"，不进 MVP。

## 02. AI 工具

- 一键抠图（透明通道生成的替代，平时可以应急用；BiRefNet / RMBG-2.0）
- 超分（Real-ESRGAN / SUPIR）
- 扩图（生成式 outpainting）
- 转角度（图生图 + 视角提示词，效果不稳定，属"尽力而为"档）
- 拆分场景或者人物（SAM 类分割 + 背景补全）

> 这些功能大概率需要提示词和模板的搭配，可以给出参考，内置常用模板。

执行方式：优先走 API（用户配置密钥），本地开源模型作为可选方案（需要 GPU）。

## 03. AI Agent

Agent 在素材管理软件中具体能起到什么作用，是值得探讨的。前提是全部基础操作 API 化（前后端解耦），Agent 按**分级授权**调用：

- **L1 只读（搜索、分析、体检报告）：** 自由执行。
- **L2 低风险可逆（标签、评分、注释、描述）：** 可配置为自动执行；AI 生成的内容统一打标记，可一键清除；后台任务队列批量运行，不打扰前台。
- **L3 结构性（移动、新建文件夹、批量重命名）：** AI 先出方案（变更预览），用户确认后才执行。
- **L4 删除：** 永远需要人工确认，回收站兜底。

典型场景：

1. 整理素材（L3，先出方案再执行）。
2. 自动标签、描述、注释（L2，后台批量跑）。
3. 监测到无缩略图的动画工程文件，自动调出插件执行（此类定时任务由规则引擎直接做即可，不必经过大模型）。
4. 定期体检：重复文件、死链、未分类资源、缺失伴生图。
5. 自然语言指令："把上周导入的走路素材移到 人物/走路 并打上标签"。
6. 联网搜索素材：列为后续探讨。

Token 控制：向量检索预筛候选集，再交给大模型处理（见 [[02_文件整理]] 08）。

## 04. 关于 AI 搜索的补充

CLIP 类向量只记录静态画面（"是什么"，不含运动信息）。我们垂直是动画师，动态语义需要补充两条路线，推荐组合使用：

1. **抽帧静态向量：** 动图、视频、序列帧抽取关键帧分别提取 CLIP 向量，聚合入库，覆盖画面内容。
2. **运动描述文本化：** 用视频理解模型为动态素材生成运动描述文本（如"火焰从中心向外扩散"），作为文本入向量库——用户搜"爆炸特效"时命中的正是运动描述。
3. 时空向量模型（InternVideo / X-CLIP 等）确实存在，但模型重、需要本地 GPU，列为技术观察，不进主线。

#### 分段语义索引（时间轴定位）

- **覆盖范围：** 视频、动图（GIF / APNG / 动态 WEBP）、序列帧包。
- **手动触发：** 用户选中素材或文件夹后点击"分析"，分析过的素材才纳入语义搜索（未分析素材的分词搜索不受影响）。
- **两档分析：**
	1. 粗略分析（快）：镜头切分（场景检测，动图与序列帧可按帧段细分）+ 抽帧提取 CLIP 向量，本地完成、无大模型调用，画面内容可搜。
	2. 详细分析（慢）：在粗略基础上，每段送视频理解模型生成动作与内容描述，并进行台词提取。可 API 或本地模型，后台队列、断点续跑。
- **台词定位：** 优先解析字幕——外挂字幕（srt / ass）直接读取，内封字幕轨用 ffmpeg 提取，零成本最可靠；无字幕时走 ASR 语音识别（whisper / faster-whisper，本地可跑、自带时间戳）；烧进画面的硬字幕不做 OCR（成本高、准确率低）。台词按"起止时间 + 文本"入索引，搜台词即可定位时间轴。
- **索引结构：** 分段索引条目 = 素材 ID + 起止时间 + 类型（画面 / 台词）+ 向量 / 文本，属派生数据、可重建。
- 命中的优秀片段可一键沉淀为新素材：**虚拟片段**（metadata 记录来源 ID 与起止时间，零磁盘开销，见 [[01_资源与数据]] 数据格式第 6 条）或 ffmpeg 物理截取为普通新资源，完成"找到 → 定位 → 剪下 → 归档"的参考库闭环。

## 05. 关于预览的补充

预览能力同样走适配器 / 插件接口（与 [[07_动画软件通信]] 同一套模块化体系），后续可对接更多格式的预览，比如 3D 工程文件（glTF 类可直接渲染，blend 等专有格式需转换）。反正我们的软件基本都要封装成可复用接口，就算没人做插件，我们自己做新的功能时，对接起来也方便。
