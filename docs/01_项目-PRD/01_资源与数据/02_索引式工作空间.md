## 02. 索引式工作空间

在工作中，我们需要频繁切换操作系统自带的资源管理器来管理项目，素材软件来查找素材，我们需要做一个简易的本地索引，来实现软件内即可完成工作。

用户首次打开软件弹出窗口：**创建工作空间**， **打开工作空间**， **稍后**。

工作空间无标签，自定义排序，评分，注释，描述，批注等等附加数据，只缓存缩略图便于快速加载浏览，保证双向热刷新。

#### 1. 资源库结构

与本地磁盘双向同步，UI 热刷新，在工作空间根目录创建 .anikit 文件夹，保存缩略图缓存。

## 手动刷新兜底（2026-09-17 用户定）

热刷新是承诺但不是保险——工作空间视图右键菜单提供**「刷新」**项，手动触发该目录全量重新扫描重建视图，作为热刷新失手（漏事件、监听断连、网络盘抖动）的兜底入口。

## 右键菜单（2026-10-01 库菜单移植轮）

工作空间文件卡 / 文件夹卡 / 树行 / 空白四组右键菜单全面对齐库菜单的分组、分割线与快捷键标注（纯文字口径，组件同一套）。文件 = 打开外发组（打开预览 / 新标签页打开 / 在默认应用打开 / 在其他应用打开 / 发送至 Animate 按路径版（仅 fla）/ 在资源管理器中显示 / 系统菜单）│ 剪贴板组（复制 / 剪切 / 粘贴（剪贴板非空才出现）/ 重命名（单选）/ 创建副本——同目录复制、重名 `名_n` 规避）│ 复制数据 ▸（复制文件路径 / 复制名称 / 复制 base64，格式白名单与 10MB 上限同库）│ 删除（系统回收站）│ 刷新；文件夹 = 新标签页打开 / 新建文件夹（同级）/ 新建子文件夹 │ 固定·取消固定 │ 剪贴板组 │ 复制数据 ▸（无 base64）│ 资源管理器 / 系统菜单 │ 删除 │ 刷新；树行 = 文件夹主体减「重命名」（ws 树无行内命名态）；空白 = 新建文件夹 / 粘贴 │ 在资源管理器中显示 / 系统菜单（目录背景版）│ 刷新。新建文件夹 = 库「先建后命名」移植（默认名创建后当前视口正是父目录时进行内命名态）。「打开」冗余项不列（同库 2026-09-23 口径：单击已导航）。快捷键绑定 = F2 / Delete / Ctrl+C·X·V·D / Shift+Enter / Ctrl+E（useGlobalKeys ws 分支）；Enter / Ctrl+Enter / 新建两键仅标注（同库口径）。

**「系统菜单」= Windows 原生右键菜单**（IContextMenu 经典菜单，多选整组弹出）：7-Zip / WinRAR 压缩解压、TortoiseGit 等注册经典动词的 shell 扩展全量出现；**Win11 新样式菜单的 IExplorerCommand 现代扩展不可托管，不在其中**。动词自身行为（如删除 / 重命名）由 shell 扩展自理。空白处的「系统菜单」为**目录背景版**（`CreateViewObject` 取目录背景菜单）：经典版 新建 ▸ / 排序方式 ▸ / 查看 ▸ / 刷新 / 属性 在其中——新建落盘经 watcher 热刷新回视图；查看 / 排序方式子菜单作用于 Explorer 视图对象，托管菜单里天然无效（先天边界非缺陷）。

## 与资源管理器联动（2026-10-01 定案）

工作空间 ↔ 资源管理器双向打通：资源管理器文件 / 文件夹拖入 ws 视口 = **一律复制**进落点目录；ws 文件卡拖出窗口 = 库拖出同机制的系统级复制拖拽；Ctrl+C·X 同步写系统剪贴板（剪切附 DropEffect=MOVE，资源管理器可接力移出）；Ctrl+V 按剪贴板序号仲裁内部粘贴 / 系统剪贴板粘贴（外部剪切来源 = 移动入）。完整语义见 [[13_基础操作]]「索引式工作空间」节。库 ↔ ws 之间的复制粘贴与互拖仍属「明确不做」，另行立项。

**落点高亮口径（2026-10-01 走查定，应用内拖拽与 OS 拖入同一套视觉槽）：** 树行 / 文件夹卡片 = 并入高亮，视口空白 = pane 级整片高亮（命中区 = 整个视口，OS 拖入经 `onDragDropEvent` enter / over 实时解析）；**同目录、虚拟视图、回收站视口不出高亮**——高亮只回答「松手会不会落到这」。

## 外部文件夹链接纳入（junction，2026-10-01 定案，已落地 2026-10-02）

与用户两轮讨论后三向拍板：**方向 a**（junction 在库内 WS 路径、内容外置）= **砍掉**（破空间自包含：备份 / 迁移空间不带工作区内容）；**方向 a′**（真 WS 留库内 + 外部便利入口 junction）= **保留为推荐用法**（零代码——库内 WS 是普通真实目录，APP 对外面 junction 无感，用户 `mklink /J` 自建即用：拖进入口 = 落库内 WS，不用翻找真目录；断链只断门、内容零风险）；**方向 b**（外部文件夹 junction 挂进 WS 子目录）= **已落地（2026-10-02）**（不逼用户搬迁，直接把散落各处的现有文件夹纳入一处视野）。

**断链口径：** **只标记不自动剔除**——目标根被挪 / 改名 / 删除后链接目录显示「链接失效」态（不弹窗），右键给「重新指向… / 移除链接」；不做按卷扫描猜新位置的自愈。junction 语义 = 门不是房间（透明转发、名下无内容）：目标内部移动不影响，只有目标根本身被动才断链；断链不伤已落盘文件；删除链接本身只删链接（安全红线，spike 已验证）。

**与硬链接的交汇**（随阶段九批次定）：工作空间 = 真实磁盘结构统一呈现层——目录级 = junction 纳入（b），文件级 = 硬链接落盘（§04 库素材出库）。库素材硬链接落进链接目录 = 落真实目标，同卷成 / 异卷败（跨卷回退 = 复制 or 拒绝提示随阶段九）；库侧链接记录建议存 canonicalize 后真实路径。方案全文、技术清单与 junction 语义备忘见 待办细节清单 2026-10-01 B 节。

**方向 b 落地口径（2026-10-02）：** 创建入口 = 右键「添加链接文件夹…」（空白菜单与文件夹菜单，系统目录选择器选目标；挂载名 = 目标目录名，重名 `名_n` 规避；拒绝非目录 / **储存空间整树**（空间根 / 素材池 / 自动导入 / 库数据 = APP 自留地，素材池挂进工作空间会绕过库封闭语义直接改库文件，2026-10-02 用户问后补）/ 目标在工作空间内 / 目标是工作空间祖先——防循环）。标识 = 链接目录角标（挂链 = 链接徽章；断链 = 警告徽章 + 置灰）；断链只标记保留不剔除，**选中断链即弹修复窗**（主钮 重新定位… / 次钮 删除链接 / 取消——双击零提示会以为 UI 卡住，对 MKLINK 无概念的用户必须给结论，同日二轮用户定；导航拦截与幽灵回退同弹一窗）+ 右键「重新定位… / 删除链接」。删除链接 = 只删门；重命名 / 移动 = 只动门；复制 / 副本链接目录 = 深拷内容（Explorer 同口径）；拖入 / 粘贴进链接目录 = 落真实目标。登记清单 = `.anikit/workspace.json` 的 `links`（rel + canonicalize 目标路径——路径闸放行与 watcher 补监听的唯一凭据；用户 `mklink` 自建 junction 首次被列出即惰性纳入登记）；watcher = 主监听不穿透 junction，每条链接目标单独补监听、事件翻译回门路径，链接拓扑变化恒重建。方向 a′ 保留方案不变。

## 搜索（2026-10-02 定案，待落地）

## 技术口径

- **缩略图缓存键** = 文件路径 + mtime + 大小（无资产 ID 可挂）；缓存目录为工作空间根 `.anikit/`，可随时整体删除重建。
- **删除走系统回收站**：调用 Windows Shell API（`SHFileOperationW` FOF_ALLOWUNDO 语义，2026-09-17 步骤 2 落地；`SHFileOperationW` 不支持 `\\?\` 逐字路径，统一经 `shell_path` 剥前缀——踩坑 078），不进库内回收站（PRD 06 已定）。
- **写操作冲突口径**（步骤 2 定）：新建 / 重命名重名即报错（须显式命名）；移动 / 复制粘贴重名自动 `名_n` 规避（n 从 2 递增；**2026-09-23 序号格式统一定案**，原 `名 (n)` 括号式废除），不覆盖；目录禁移入自身子树。
- **watcher 回声消重**（PRD 步骤 2 口径）：命令返回即直接更新 UI，本进程写操作的 watcher 事件按「已知操作」登记簿消重（3s 窗口，全部路径落在登记路径下才丢弃；不用延时忽略，避免误吃窗口期外真实外部改动）。
- **搜索**只命中文件名与路径（PRD 03 已定）；实现 = 2026-10-02 定案双层方案，见「搜索」节。
- **监听范围** = workspace 根递归；`.anikit` 自身变更不触发刷新（避免缓存写回引起自激），写操作亦禁入 `.anikit`。
- **视图状态**（步骤 3 常用固定）= `.anikit/workspace.json`（与缩略图缓存同目录，可删可重建）：`{ "pinned": [relPath, ...] }`。读取时静默剔除已不存在 / 已改名的条目并回写；改名 / 移动 / 删除操作后前端重取。
- **常用固定交互**（2026-09-17 用户定，资源管理器快速访问式）：树文件夹行右键「固定到常用」→ 侧栏「常用」区块；固定行右键「取消固定」。**区块标题分割**（2026-09-17 用户截图定，改「无区块标题」初判）：「常用 / N」与「文件夹 / N」两个 SectionTitle block 区块，hover 出展开钮可折叠（FolderStrip / ArchiveStrip 同先例）。**根不设合成父级行**——树从根子文件夹直接铺（工作空间整段即根，假父级行与子级同缩进视觉撞兄弟），根视口 = 切分段自动开 + 历史后退可达。**快速入口容器与回收站行**（2026-10-01 用户定）：树根层最上方（常用 / 文件夹区块之上）设库快速访问同口径的**无标题总容器**（行 gap 2；后续入口行直接加进容器，不动区块嵌套）；首行 = 「回收站」（库快速访问回收站同款 TreeRowItem quick + trash 图标，无数量——磁盘实况不跟踪系统回收站内容），点击 = 资源管理器打开系统回收站（`shell:RecycleBinFolder`）。**根入口行（2026-10-02 用户实机报后定）**：容器首行 = 「工作空间」（TreeRowItem quick + workspace 图标，回收站行居次）——点击 = 根视口（`openView("ws:")`），右键 = 根空白菜单（新建文件夹 / 添加链接文件夹… / 粘贴 / 在资源管理器中显示 / 系统菜单 / 刷新），数量 = 根目录直接文件数（pin 行同口径）；**入口行 ≠ 上文废除的合成父级行**（只是快捷入口，不做树的父级、不与子级同缩进撞兄弟），「根视口仅切分段 / 历史后退可达、根菜单无处触发」的空白由此补上。树容器空白（非行落点）右键同出根空白菜单。
- **exe 图标走文件级缓存**（2026-09-17 用户定：「exe 可以单独走文件缓存，其他的还是按格式缓存」）：exe 的图标不按扩展名缓存（同扩展名各程序图标不同，按扩展名会把首个 exe 的图标串给所有 exe），命名 = 内容缩略图键 + `.icon` 中缀（`{url-safe(rel)}-{mtime}-{size}.icon.webp`，源变化即失效重提顺清旧缓存）；其余不可解码类型维持按扩展名缓存 `.anikit/thumbs/{ext}.webp`。
