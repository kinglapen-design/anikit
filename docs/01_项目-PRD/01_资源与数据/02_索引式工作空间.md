## 02. 索引式工作空间

在工作中，我们需要频繁切换操作系统自带的资源管理器来管理项目，素材软件来查找素材，我们需要做一个简易的本地索引，来实现软件内即可完成工作。

用户首次打开软件弹出窗口：**创建工作空间**， **打开工作空间**， **稍后**。

工作空间无标签，自定义排序，评分，注释，描述，批注等等附加数据，只缓存缩略图便于快速加载浏览，保证双向热刷新。

与本地磁盘双向同步，UI 热刷新，在工作空间根目录创建 .anikit 文件夹，保存缩略图缓存。

## 右键菜单（2026-10-01 库菜单移植轮）

工作空间文件卡 / 文件夹卡 / 树行 / 空白四组右键菜单全面对齐库菜单的分组、分割线与快捷键标注（纯文字口径，组件同一套）。文件 = 打开外发组（打开预览 / 新标签页打开 / 在默认应用打开 / 在其他应用打开 / 发送至 Animate 按路径版（仅 fla）/ 在资源管理器中显示 / 系统菜单）│ 剪贴板组（复制 / 剪切 / 粘贴（剪贴板非空才出现）/ 重命名（单选）/ 创建副本——同目录复制、重名 `名_n` 规避）│ 复制数据 ▸（复制文件路径 / 复制名称 / 复制 base64，格式白名单与 10MB 上限同库）│ 删除（系统回收站）│ 刷新；文件夹 = 新标签页打开 / 新建文件夹（同级）/ 新建子文件夹 │ 固定·取消固定 │ 剪贴板组 │ 复制数据 ▸（无 base64）│ 资源管理器 / 系统菜单 │ 删除 │ 刷新；树行 = 文件夹主体减「重命名」（ws 树无行内命名态）；空白 = 新建文件夹 / 粘贴 │ 在资源管理器中显示 / 系统菜单（目录背景版）│ 刷新。新建文件夹 = 库「先建后命名」移植（默认名创建后当前视口正是父目录时进行内命名态）。「打开」冗余项不列（同库 2026-09-23 口径：单击已导航）。快捷键绑定 = F2 / Delete / Ctrl+C·X·V·D / Shift+Enter / Ctrl+E（useGlobalKeys ws 分支）；Enter / Ctrl+Enter / 新建两键仅标注（同库口径）。

**「系统菜单」= Windows 原生右键菜单**（IContextMenu 经典菜单，多选整组弹出）：7-Zip / WinRAR 压缩解压、TortoiseGit 等注册经典动词的 shell 扩展全量出现；**Win11 新样式菜单的 IExplorerCommand 现代扩展不可托管，不在其中**。动词自身行为（如删除 / 重命名）由 shell 扩展自理。空白处的「系统菜单」为**目录背景版**（`CreateViewObject` 取目录背景菜单）：经典版 新建 ▸ / 排序方式 ▸ / 查看 ▸ / 刷新 / 属性 在其中——新建落盘经 watcher 热刷新回视图；查看 / 排序方式子菜单作用于 Explorer 视图对象，托管菜单里天然无效（先天边界非缺陷）。

## 与资源管理器联动（2026-10-01 定案）

工作空间 ↔ 资源管理器双向打通：资源管理器文件 / 文件夹拖入 ws 视口 = **一律复制**进落点目录；ws 文件卡拖出窗口 = 库拖出同机制的系统级复制拖拽；Ctrl+C·X 同步写系统剪贴板（剪切附 DropEffect=MOVE，资源管理器可接力移出）；Ctrl+V 按剪贴板序号仲裁内部粘贴 / 系统剪贴板粘贴（外部剪切来源 = 移动入）。完整语义见 [[13_基础操作]]「索引式工作空间」节。库 ↔ ws 的互拖与菜单互通 2026-10-03 立项落地（见「与资源库互通」节）；库 ↔ ws 之间的剪贴板复制粘贴仍属「明确不做」。

**落点高亮口径（2026-10-01 走查定，应用内拖拽与 OS 拖入同一套视觉槽）：** 树行 / 文件夹卡片 = 并入高亮，视口空白 = pane 级整片高亮（命中区 = 整个视口，OS 拖入经 `onDragDropEvent` enter / over 实时解析）；**同目录、虚拟视图、回收站视口不出高亮**——高亮只回答「松手会不会落到这」。**应用内拖拽移动（2026-10-02 文件夹起拖补全）：** 文件与文件夹均可从树行 / 文件夹卡片起拖（多选整组同拖），落点 = 树行 / 文件夹卡片 / 视口空白（= 移动进目标目录，重名 `名_n` 规避）；**拖到自身、自身子孙目录或同目录同样不出高亮、松手无操作**——后端 ws_move「不能移动到自身 / 自己的子目录」护栏的前端前置，不弹报错。

## 与资源库互通（2026-10-03 定案，复制双向）

库与工作空间不再割裂：**双向一律复制**，不搬动源（硬链接落盘属阶段九批次，本互通先做简单复制）。

- **库 → 工作空间 = 导出管线**：库素材卡 / 文件夹卡拖到 ws 树行 / ws 文件夹卡 / ws 视口空白 = 复制进落点目录——复用「导出到本地磁盘」同一管线（`export_assets` / `export_folder`：originName 拷出、序列帧打包成文件夹、`名_n` 重名规避、进度条 + 失败重试弹窗），目的地 = 落点目录绝对路径；watcher 回声驱动树 / 视口刷新。文件夹整棵导出同「导出到本地磁盘」语义（层级 + 显示名重建）。
- **工作空间 → 库 = 导入管线**：ws 文件卡 / 文件夹卡（含树行）拖到库树行 / 库文件夹卡 / 库文件夹视口空白 = 导入进库——rel 转绝对路径后进既有 `importDraft` 流（导入弹窗确认结构扁平 / 保留、序列帧打包检测全继承），落点文件夹 = 目标；未分类视口空白 = 根。**替换旧死链**：原 ws 项拖库落点会进 `move_placements` 被后端按陈旧跳过、误 toast「已移动 0 个项目」。
- **菜单双入口（树选择器，移动面板样式）：** 库素材卡 / 文件夹卡「导出 ▸ 导出到工作空间」→ 工作空间目录树选择器（根 = 「工作空间」行，懒加载逐级展开，断链目录不作落点）；ws 文件卡 / 文件夹卡 / 树行「导入到库」→ 库文件夹树选择器（含「未分类」行 = 根）。单击落点出确认弹窗（同移动面板两段确认），确认即执行。

## 外部文件夹链接纳入（junction，2026-10-01 定案，已落地 2026-10-02）

与用户两轮讨论后三向拍板：**方向 a**（junction 在库内 WS 路径、内容外置）= **砍掉**（破空间自包含：备份 / 迁移空间不带工作区内容）；**方向 a′**（真 WS 留库内 + 外部便利入口 junction）= **已产品化落地（2026-10-02，「链出去」）**（原零代码推荐用法的正式化——库内 WS 是普通真实目录，APP 对外面 junction 无感：拖进入口 = 落库内 WS，不用翻找真目录；断链只断门、内容零风险）；**方向 b**（外部文件夹 junction 挂进 WS 子目录）= **已落地（2026-10-02）**（不逼用户搬迁，直接把散落各处的现有文件夹纳入一处视野）。

**断链口径：** **只标记不自动剔除**——目标根被挪 / 改名 / 删除后链接目录显示「链接失效」态（不弹窗），右键给「重新指向… / 移除链接」；不做按卷扫描猜新位置的自愈。junction 语义 = 门不是房间（透明转发、名下无内容）：目标内部移动不影响，只有目标根本身被动才断链；断链不伤已落盘文件；删除链接本身只删链接（安全红线，spike 已验证）。

**与硬链接的交汇**（随阶段九批次定）：工作空间 = 真实磁盘结构统一呈现层——目录级 = junction 纳入（b），文件级 = 硬链接落盘（§04 库素材出库）。库素材硬链接落进链接目录 = 落真实目标，同卷成 / 异卷败（跨卷回退 = 复制 or 拒绝提示随阶段九）；库侧链接记录建议存 canonicalize 后真实路径。方案全文、技术清单与 junction 语义备忘见 待办细节清单 2026-10-01 B 节。

**方向 b 落地口径（2026-10-02）：** 创建入口 = 右键「添加链接文件夹…」（空白菜单与文件夹菜单，系统目录选择器选目标；挂载名 = 目标目录名，重名 `名_n` 规避；拒绝非目录 / **储存空间整树**（空间根 / 素材池 / 自动导入 / 库数据 = APP 自留地，素材池挂进工作空间会绕过库封闭语义直接改库文件，2026-10-02 用户问后补）/ 目标在工作空间内 / 目标是工作空间祖先——防循环）。标识 = 链接目录角标（挂链 = 链接徽章；断链 = 警告徽章 + 置灰）；断链只标记保留不剔除，**选中断链即弹修复窗**（主钮 重新定位… / 次钮 删除链接 / 取消——双击零提示会以为 UI 卡住，对 MKLINK 无概念的用户必须给结论，同日二轮用户定；导航拦截与幽灵回退同弹一窗）+ 右键「重新定位… / 删除链接」。删除链接 = 只删门；重命名 / 移动 = 只动门；复制 / 副本链接目录 = 深拷内容（Explorer 同口径）；拖入 / 粘贴进链接目录 = 落真实目标。登记清单 = `.anikit/workspace.json` 的 `links`（rel + canonicalize 目标路径——路径闸放行与 watcher 补监听的唯一凭据；用户 `mklink` 自建 junction 首次被列出即惰性纳入登记）；watcher = 主监听不穿透 junction，每条链接目标单独补监听、事件翻译回门路径，链接拓扑变化恒重建。

**方向 a′「链出去」落地口径（2026-10-02）：** 创建入口 = 文件夹卡 / 树行右键「在外部位置创建链接…」（系统目录选择器选**入口摆放位置**，选择器带标题防与方向 b 选「目标」混淆）→ 落点下建 junction 指向本文件夹（入口名 = 文件夹名，重名 `名_n` 规避），成功 toast 入口绝对路径。**只管创建不管存续**——入口在 WS 外：不补监听、无徽章、无断链标记（方向 b 的标记体系只管 WS 内的门；内容本体在 WS 内已被 watcher 全覆盖，外部门被删不伤分毫，十秒重建）。落点校验 = 拒储存空间整树（同方向 b 闸——workspace 内摆入口 = 同一内容两个词法身份）；落点是源的祖先无害（入口指向子孙不构成环）。源是方向 b 的门时入口直指最终目标（创建时 canonicalize 展平，内容仍只有一份——嵌套兼容性结论见 待办 2026-10-02）。断链的链接门不可链出（提示先重新定位）。**登记台账**（2026-10-02 面板轮升级——总览要显示就得登记）：`workspace.json` 扩 `portals: [{ rel, portal }]`（扁平多条，一文件夹可多个入口），创建时登记；改名 / 移动 / 删除随 links 台账同径词法平移 / 剔除；仍不做自动管理（断了只标记可手删）。

## 搜索（2026-10-02 定案，2026-10-03 落地）

步骤 3「搜索搁置」解冻并落地：**双层架构**——**Everything 手写 IPC 层**（探测到运行中的 Everything 即全功能，`adapters/everything.rs` 手写 1.4 WM_COPYDATA QUERY2 协议：不引 DLL / es.exe，零分发授权问题）+ **自研爬盘回退层**（无 Everything 时 Enter 显式触发）。**不依赖 Windows Search**（索引默认不覆盖任意路径工作空间）。

**行为口径（2026-10-03 用户定）**：搜索框输入即搜（仅命中文件名与路径，PRD 03）；**`~` 前缀 = 全景搜索整个工作空间**，无 `~` = 当前视口目录子树（Everything `path:` 天然递归，资源管理器同语义）；命中仅文件（`file:`——目录由侧栏树导航不进结果网格）；结果限流 1000 条；junction 链接目录按真实目标分别补查、命中映射回词法 rel（与方向 b 共享 `links` 台账）；`.anikit` 剔除；Everything 原生查询语法原样透传（`ext:` 等修饰符可用——**搜索串绝不整体加引号**，引号 = 短语字面搜索，修饰符全失效）。ws 视口搜索框**筛选钮整颗隐藏**（磁盘实况无附加数据可筛，2026-10-03 用户定「没有用」——filters 传空组件不渲染）。

**回退层口径（2026-10-03 用户定）**：无 Everything 时不冒充即时搜索——输入不动，空态引导「按 Enter 遍历搜索当前目录」，Enter 触发爬盘（栈式遍历 + rayon 批并行 + 可取消，进度条复用导入进度条组件 = 不定态「已扫 N 个文件」，命中流式进网格）；**回退不接 `~`**（全局慢搜开销大无意义）——`~` 输入即通知栏指路：未安装 =「下载 Everything」（官网 voidtools.com），已安装未运行 =「启动 Everything」（代拉起，启动用户自己的软件无授权问题）。

**能力探测三态**（ffmpeg 降级范式）：运行中（FindWindow 任务栏通知窗 + 版本查询，QUERY2 需 1.4.1+）/ 已安装未运行（注册表卸载项 + 默认安装路径）/ 未安装。

**未落地（后续轮）**：文件夹数量标记（一次性全量查询聚合 + 监听窄查询修正，树行 / 文件夹卡直接 / 递归文件数——探测与查询基建已就位）；首启引导页推荐安装；Everything 1.5 SDK3 命名管道增强（二期）。

- junction 链接目标落在异盘时的跨卷写问题（库素材硬链接落盘的交汇回退口径，随阶段九硬链接批次一并定；junction 纳入本身已落地 2026-10-02，见「外部文件夹链接纳入」节）。

## 技术口径

- **缩略图缓存键** = 文件路径 + mtime + 大小（无资产 ID 可挂）；缓存目录为工作空间根 `.anikit/`，可随时整体删除重建。
- **删除走系统回收站**：调用 Windows Shell API（`SHFileOperationW` FOF_ALLOWUNDO 语义，2026-09-17 步骤 2 落地；`SHFileOperationW` 不支持 `\\?\` 逐字路径，统一经 `shell_path` 剥前缀——踩坑 078），不进库内回收站（PRD 06 已定）。
- **写操作冲突口径**（步骤 2 定）：新建 / 重命名重名即报错（须显式命名）；移动 / 复制粘贴重名自动 `名_n` 规避（n 从 2 递增；**2026-09-23 序号格式统一定案**，原 `名 (n)` 括号式废除），不覆盖；目录禁移入自身子树。
- **watcher 回声消重**（PRD 步骤 2 口径）：命令返回即直接更新 UI，本进程写操作的 watcher 事件按「已知操作」登记簿消重（3s 窗口，全部路径落在登记路径下才丢弃；不用延时忽略，避免误吃窗口期外真实外部改动）。
- **搜索**只命中文件名与路径（PRD 03 已定）；实现 = 2026-10-02 定案双层方案，见「搜索」节。
- **监听范围** = workspace 根递归；`.anikit` 自身变更不触发刷新（避免缓存写回引起自激），写操作亦禁入 `.anikit`。
- **视图状态**（步骤 3 常用固定）= `.anikit/workspace.json`（与缩略图缓存同目录，可删可重建）：`{ "pinned": [relPath, ...] }`。读取时静默剔除已不存在 / 已改名的条目并回写；改名 / 移动 / 删除操作后前端重取。
- **常用固定交互**（2026-09-17 用户定，资源管理器快速访问式）：树文件夹行右键「固定到常用」→ 侧栏「常用」区块；固定行右键「取消固定」。**区块标题分割**（2026-09-17 用户截图定，改「无区块标题」初判）：「常用 / N」与「文件夹 / N」两个 SectionTitle block 区块，hover 出展开钮可折叠（FolderStrip / ArchiveStrip 同先例）。**「文件夹」区块标题动作钮**（2026-10-03 用户定，库区块头悬停动作钮同口径）：「+」= 根目录新建文件夹（先建后命名同右键菜单径，区块折叠时先强制展开）；「⋯」= 添加链接文件夹…（挂根，管理工作空间面板添加钮同径）/ 管理工作空间面板（应用菜单同入口）。**根不设合成父级行**——树从根子文件夹直接铺（工作空间整段即根，假父级行与子级同缩进视觉撞兄弟），根视口 = 切分段自动开 + 历史后退可达。**快速入口容器与回收站行**（2026-10-01 用户定）：树根层最上方（常用 / 文件夹区块之上）设库快速访问同口径的**无标题总容器**（行 gap 2；后续入口行直接加进容器，不动区块嵌套）；首行 = 「回收站」（库快速访问回收站同款 TreeRowItem quick + trash 图标，无数量——磁盘实况不跟踪系统回收站内容），点击 = 资源管理器打开系统回收站（`shell:RecycleBinFolder`）。**根入口行（2026-10-02 用户实机报后定）**：容器首行 = 「工作空间」（TreeRowItem quick + workspace 图标，回收站行居次）——点击 = 根视口（`openView("ws:")`），右键 = 根空白菜单（新建文件夹 / 添加链接文件夹… / 粘贴 / 在资源管理器中显示 / 系统菜单 / 刷新），数量 = 根目录直接文件数（pin 行同口径）；**入口行 ≠ 上文废除的合成父级行**（只是快捷入口，不做树的父级、不与子级同缩进撞兄弟），「根视口仅切分段 / 历史后退可达、根菜单无处触发」的空白由此补上。树容器空白（非行落点）右键同出根空白菜单。
- **树展开态记忆（2026-10-12 用户报「视口记住上次停留文件夹、树展开每次要重新展开」补落）**：「文件夹」区块树的目录展开态按空间持久化——存全局 `settings.ui` 的 `wsTreeExpanded`（键 = 空间 rootPath、值 = 展开目录 relPath 清单，ui store 防抖 500ms 写回同其他界面设置，后端零新增；**按空间分键不共享**——路径类记忆跨空间重放出幽灵态，踩坑 100 教训），空间 root 就绪即恢复，恢复时顺带剔除已删除 / 改名目录的残留键（`wsDirsExist` 批量判定，`pruneWsViewKeys` 同口径，判定失败保守不清）。区块标题折叠态与库树展开态维持会话级不持久化。
- **exe 图标走文件级缓存**（2026-09-17 用户定：「exe 可以单独走文件缓存，其他的还是按格式缓存」）：exe 的图标不按扩展名缓存（同扩展名各程序图标不同，按扩展名会把首个 exe 的图标串给所有 exe），命名 = 内容缩略图键 + `.icon` 中缀（`{url-safe(rel)}-{mtime}-{size}.icon.webp`，源变化即失效重提顺清旧缓存）；其余不可解码类型维持按扩展名缓存 `.anikit/thumbs/{ext}.webp`。
