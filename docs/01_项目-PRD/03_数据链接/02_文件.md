## 02. 文件

详情面板可展示与编辑的数据：

- **颜色：** 分析颜色（色块提取，详见 [[04_文件预览]] 详情；**6.1 已落地**：主色存 metadata.colors，透明像素不计入，pinned 颜色 bar 按实际色数渲染前 7）。
- **名称：** 直接改名，走 [[02_文件整理]] 13 的重命名规则。
- **链接：** 浏览器扩展抓取图片时自动填充来源网址，也可用户手动填写；支持内部链接 `anikit://item/{ID}` 实现两个文件之间的跳转（见 [[02_文件整理]] 09）。
- **基础信息：** 尺寸 / 文件大小 / 格式 / 添加日期 / 创建日期 / 修改日期，其中尺寸只对可获取到尺寸的文件有效。
- **属性（2026-08-04 扩展至文件）：** 短文本并列（如 走路 / 跑步 / 拔剑），短文本之间自动添加 `|` 分隔——即"打词"能力，**代替原标签体系**，跨维度归类的载体，分词搜索与筛选命中（见 [[02_文件整理]] 05、[[03_查找文件]]）。**编辑 = 32 稿属性标签弹窗（6.1 已落地）**：搜索框过滤属性池；「输入新属性」回车添加；点池内属性加入拥有（轻微过冲回弹）；池 = 全库聚合（全部文件属性 + 全部档案属性去重），池内 × = 警告二次确认后**全局删除**（所有填写了该属性的文件与档案都失效）。
- **描述（2026-08-04 扩展至文件）：** 长文本，为标题 + 内容的组合；**内容超过 3 行截断、显示"展开 / 收起"按钮**（行数 2026-08-23 用户定）；**标题行折叠钮收起 = 留一排截断正文而非整段隐藏**（2026-08-31 右栏轮用户实机定——只留标题看不出内容，无法判断是否展开）；编辑界面可逐条添加（**31 稿编辑描述弹窗，6.1 已落地**：箭头排序 + 红色删除 + 添加描述，确认一次提交）。
- **链接区块：** 当前文件同时存在于哪个区块的哪个文件夹、显示名称是什么（Placement 反查）；**每条路径只写两段（2026-08-15 用户定：三段太长）——区块名称（常态色）/ 所属目录（标签色）；所属目录为档案时显示「名称.档案」后缀，档案位置一看便知，归属档案信息由此并入本区块**。未分类与回收站资产的显示规则见 [[02_文件整理]] 15。**（2026-08-24 落地，6.2 三轮：添加钮 = 链接管理弹窗（17 稿）——管理本文件的链接分布：左列 = 侧栏文件树照搬（区块分组、文件夹颜色/数量同树）+ 未分类组；右列 = 位置行（名称框就地改显示名 + ★原始/链接徽章 + √ 增删，同文件夹重复链接平铺多行——用户定，后续版本重构 UI 时再重新设计面板逻辑）；草稿式确认一次提交（sync_asset_links 单撤销步），移除 = 直接删记录不进回收站；× = 移除该条链接（同命令单条即时）；**点 item = 跳转定位**（该位置视口 + 选中卡片，面包屑后退返回）+ **当前目录的 item 永远第一行**（2026-08-24 四轮走查②）；文件右键「文件链接管理」Ctrl+J 同入口——工具栏/新增菜单的链接管理钮删除，用户定「针对某个文件，右键菜单和详情面板有入口就行」；档案链接管理随档案多位置立项，见 [[01_资源与数据]] 边界规则待立项）**
- ~~**归属档案：**~~（**2026-08-15 用户定：区块废除**——档案位置经链接区块「名称.档案」后缀表达，不再单设区块。）
- **提示词：** 没有提示词时可点击「分析提示词」或「指定文本」：
	- **指定文本：** 用户指定已导入的 MD 文本，内容显示在输入框；
	- **分析提示词：** 不主动额外创建文档。分析结果提供三个动作——① **创建为 MD 文本**：将分析文本创建为 MD 文档作为新文件导入，自动放到与源文件同一目录；② **打开编辑器**：输入框不便长文输入，内置 Markdown 编辑器（后续版本）打开编辑——分析的提示词必须先保存为 MD 才能使用编辑器；③ **复制**：一键复制提示词文本。
	- **数据落地：** 提示词 = 对 MD 资产的**引用 + 内容快照**——平时显示快照（源 MD 被删除不断链），可跳转源文件。
	- **实现定案（2026-09-26 提示词轮落地）：** 绑定存 `metadata.prompt` / `archives.json` 同构字段 `{ assetId, name, content, updatedAt }`（引用 + 快照内嵌，serde default 不升版）；三态 = 未指定 / 已指定 / 已扫描（仅文件——档案不是文件无「分析」），文件/档案右键一级「提示词」二级按态切换（未指定 = 分析/指定/新建 md/txt；已指定 = 打开编辑器/复制/断开/删除文档；已扫描 = 保存为 md/txt/复制/重新分析/清空）。**「分析提示词」数据源 = 解析图片内嵌元数据**（SD/NovelAI 系 PNG `parameters`/`Comment`、ComfyUI 节点图抽 CLIPTextEncode 文本、JPEG/WEBP EXIF UserComment 等；门禁 png/jpg/jpeg/webp，无内嵌数据明确报错）——非 AI 生成（AniKit 不做生产，见 [[08_AI 功能]] 07）。展示 = 已指定态实时读源最新内容、源被彻底删除回落快照（`sync_after_purge` 降级 + 开库自检兜底）；快照在 指定/分析/新建 时落盘（`refresh_*_prompt_snapshot` 同步快照命令保留 API 层——详情二轮改版后面板无入口）。「新建/保存为文档」= 建库内文本资产并绑定（名 = 资产显示名，撞名 `_序号`），「删除提示词文档」= 源文档丢回收站 + 解绑单撤销步；内容编辑走内置编辑器不进撤销。MCP 同步加 `assign_prompt` / `clear_prompt` 两写工具（见 [[08_AI 功能]] 06）。**（2026-09-26 二轮用户修订：提示词不独占 tab——详情第三 tab 改「自定义组件」占位容器，提示词挪基础信息 tab 末位区块；区块按钮 = 两态三钮，无提示词 = 扫描/新建（弹二级 .md/.txt）/指定、有提示词 = 编辑（已扫描先存为 .md 再开编辑器）/断开提示词链接/删除提示词文档；右键菜单三态不变。）**
- **关系：** 选择一个文件或档案建立关系（选择操作见 04，**多选累积**——一次可为同一发起方添加多条）。例：雪牧 添加关系 → 选择 雪天、输入"父亲"——双向显示：雪牧详情显示"雪天是父亲"，雪天详情显示反向称谓"雪牧是儿子"。**（2026-08-23 落地口径，6.2 一轮：反向称谓 = 选择模式备选区右框手动填写、可留空回退同词——"自动显示儿女"的推导不做，无词典。2026-08-24 二轮：详情关系 item 点文件卡 = 跳转定位到对方（面包屑后退返回）；"点文件进选择模式换绑"废除——要换就删了重新添加；改称谓保留 = 点称谓框 C2 输入框；× 删除。）**
- **音色：** 关系的预定义类型，双向显示——文件详情显示"使用的音频是哪个"，音频详情显示"在哪些文件里使用过"。**（2026-08-24 方案 1 定案：voice 恒单向 使用者→音频——音频不能作使用方（"音频的音频"递归起来没完没了），音频侧区块 = 标题「使用者」+ 只展示/跳转、无添加钮；要挂音频跳到使用方上加，后端校验同。）**
