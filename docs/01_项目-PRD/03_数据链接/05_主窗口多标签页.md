## 05. 主窗口多标签页（2026-08-08 定案，随 1.2 落地）

中间面板标题栏 = 标签栏（figma-css 15_标签栏 / 39_右键菜单-标签页）。标签页可拖拽重排、可拖出拆分停靠（左右 / 上下分屏），布局持久化（重启恢复）。

- **标签页 = 一个文件视口**（快速访问项或文件夹）；全部标签页共用同一份库数据与选择状态，各自只记自己的视口位置。
- **侧边栏导航：** 当前标签页未锁定 → 替换其视口；已锁定 → 新开标签页（Eagle 式）。
- **「新标签页打开」（文件夹 / 档案右键菜单，2026-08-20 接入）：** 恒新开标签页，与当前页锁定态无关（原实现误用侧边栏导航语义——未锁定页只替换视口，等于没开新页）。
- **资产「新标签页打开」（素材卡右键菜单，2026-09-25 接入，per-panel 预览会话化配套）：** 新开同源视口的标签页并直接进该资产预览（预览 = 每标签页各自会话，互不抢）；预览中的标签页标题 = 资产名，退出预览自动回视口名。快速访问（虚拟视图）与回收站菜单同口径点亮。
- **面包屑后退 / 前进（工具栏，2026-08-20 接入）：** per-panel 导航历史（会话级）——侧边栏导航替换视口时旧视口入后退栈、清前进栈；后退 / 前进直接替换本页视口（不走"锁定页新开"语义——历史是本页自己走过的路径）；新开页 / 布局恢复 = 空历史。
- **锁定：** 锁定标签页无关闭按钮（显示锁定图标）、右键"关闭标签页"禁用；不禁止拖拽排序与分屏。
- **右键菜单：** 关闭标签页 / 锁定 / 新窗口打开 / 左右分屏 / 上下分屏。"新窗口打开"仅预览视图可用（预览子窗口），文件视口下该项禁用色。
- **跨分屏拖拽（2026-09-17 实机走查定案）：** 分屏的收益 = 高效整理——一边开着目标目录，另一边找文件拖过去。**素材卡片可跨分屏落点**：目标文件夹与当前不同 = **并入移动**（目标 pane 级高亮 = 并入同款品牌/半透明 + 2px 品牌描边；Ctrl = 建链接，与文件夹卡片落点同语义）；同文件夹（含同视口两分屏）= 间隙排序（组约束同单 pane 语义，提示线只渲染在归属网格）。落点分流：文件夹视口 → 移入该文件夹；未分类 → 移入 root；回收站视口 → 丢到回收站；工作空间视口 → ws 素材按路径移动（库素材不落）；虚拟视图（全部 / 最近使用 / 缩略图）不出落点（位置级不成立）。工程实现：网格 resolver 由「激活 panel 单例」改「全可见网格注册表」，命中按层 rect 包含判定（dockview 隐藏标签页 rect 全零天然不中），提示线/边缘滚动按归属网格 token 渲染与驱动。
