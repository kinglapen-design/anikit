## 06. 数据落地规划

- **关系 / 音色统一为 relation 模型：** `{ from, to, kind, label, reverseLabel? }`（kind：free 自由关系 / voice 音色），双向显示为同一条记录的两个视角；存**空间级** relations.json（关系可跨库——库 A 的角色配库 B 的音频），单一写点、携带 version。**（2026-08-23 已落地，6.2 一轮：from/to = `RelationRef{ lib, kind: "asset"|"archive", id, name }`——携库名 + 显示名快照（跨库目标未打开 / 失效时兜底显示）；label = to 对 from 的称谓，reverseLabel = from 对 to 的称谓（手填可空，空 = 反向回退同词）；开库自检剔除本库失效端点的关系。本轮 kind 恒 free；voice 随链接音频轮。）** **（2026-08-24 落地，6.2 三轮：kind = voice 接入——无称谓（label 恒空串、reverseLabel 恒 None），to 必须音频 asset（mp3/wav/wma），from 可 asset / archive；详情「音频」区块点亮：使用方详情 = 音频 item（绿圆播放钮 + 名称 + 波形小图，点击播放/暂停切换，03_数据 item §5 稿），音频详情 = 使用方文件卡；点名称/卡 = 跳转定位（同关系 item），× 删除，添加 = 选择模式过滤音频——**2026-08-24 方案 1 修订：voice 恒单向 使用者→音频，音频侧标题「使用者」+ 无添加钮只展示/跳转，from 不得音频 asset（后端校验防递归）**）**
- **属性 / 描述（文件）：** 属性 = metadata 内字符串数组（复用原 `tags` 字段，标签体系取消后语义转为属性词，免迁移）；描述 = metadata 内 `[{ title, content }]` 数组（`descriptions` 字段，6.1 已落地，serde default 不升 DATA_VERSION），随 metadata 单一写点。
- **档案数据（2026-08-15 已实现，3.2 一轮）：** 档案节点在 folders.json 标记形态（`Folder.kind = "archive"`，serde default + None 不写字段，不升 DATA_VERSION）；档案数据存库级 **archives.json**（单一写点 core::library::save_archives，携带 version；记录懒建——新建/转换不落记录，开库自检 fix_archives 剔除指向失效文件夹的记录）：`ArchivesFile = { version, archives: ArchiveData[] }`；`ArchiveData = { folderId, badge?: { text, color }, avatar?: { file, crop?: { x, y, scale } }, props: string[], descriptions: [{ title, content }] }`（badge / avatar / crop 为 None 时不写字段；**avatar.file = 库根 covers/ 内烘培封面图，2026-08-23 独立存定案，6.1**）。
- **提示词**（引用 + 快照）与**头像**（源资产 + 取景参数）的数据落地见上文各自条目。
- **内部链接**统一使用 `anikit://item/{ID}` ID 寻址，改名不死链（[[02_文件整理]] 09）。
