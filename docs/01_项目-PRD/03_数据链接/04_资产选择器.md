## 04. 资产选择器 = 主窗口选择模式（2026-08-04 定案）

**（2026-08-23 落地，6.2 一轮 = 框架 + 关系闭环；2026-08-24 二轮修订（用户定）：① 关系模式 = 多选累积——选一个 = 追加一条而非切换（一次为发起方加父亲/儿子/母亲/专武多条），备选区整组（选中文件 item + 双称谓框 + 发起文件 item + 红删）竖排复制，确认批量写入单撤销步、按钮带数量；② 详情关系 item 点文件卡 = 跳转定位（面包屑后退返回），稿注"进选择模式换绑"废除——要换就删了重新添加，改称谓保留；③ 发起文件自身卡片 = 剪切档半透明 + 禁选光标（视觉排除）；④ 白名单收窄——模式内只放行：树 / 快速访问导航、搜索、查看方式（含滑块 / 递归显示）、挑选文件（点选 + 双击预览）、面包屑后退前进；其余全禁（编辑类操作 / 新增 / 区块管理 / 汉堡含切库——跨库挑选以后再说 / 收件箱条目与菜单 / 包内帧编辑）；⑤ 后续筛选（悬浮栏筛选按钮组）接入时进白名单。）**

建立关系、指定音色、选择头像来源、添加文件链接等"从一个文件选到另一个/一批文件"的场景，不弹窗——**主窗口就地进入选择模式**，浏览能力（搜索 / 筛选 / 树导航 / 悬停预览 / 排序）全部就地复用：

- **模式标识（四重）：** 窗口整圈品牌色外边框 + 顶部目的横幅（"选择文件：为 雪牧 添加关系"，标注 Esc = 取消）+ 右侧详情栏临时替换为**备选区** + 已选卡片压暗显示品牌色大勾。
- **交互变化：** 单击卡片 = 加入 / 移出备选（不再是选中）；双击仍可预览（返回后模式保持）；右键仅留查看类操作，编辑类禁用；拖拽禁用；左侧树仅导航（新建 / 重命名 / 排序禁用）。
- **两种规格：** ~~**单选模式**（关系 / 音色 / 头像——备选区恒一条，选新换旧，行 = 纯显示 + ×）~~（**2026-08-24 改定：关系 = 多选累积**，见上文修订①；单选规格留给音色 / 头像用途落地时再定）；**多选模式**（添加文件链接——累积，**行 = 输入框可改显示名**，确认时按行写入；批量查找替换改名不在此做，确认后走 14 批量重命名）。**（2026-08-24 落地，6.2 三轮：文件模板行 = 名称输入框——用户定「稿的名称框本身就是输入框」，默认源名可改 + 链接徽章 + 红删；用途两接——link 添加文件链接：文件夹/档案右键「添加文件/档案链接」Ctrl+L 与工具栏钮进入，落点 = 目标文件夹/当前文件夹视口，确认 link_placements 单撤销步，旧文件夹选择弹窗 + 关联弹窗废弃；voice 链接音频：详情音频区块添加钮进入，**过滤非音频**——网格只渲染音频卡片、档案区不渲染（02 稿「过滤掉非音频文件，去掉噪音」），多选累积，确认 add_relations kind=voice）**
- **确认 / 取消：** 确认按钮带数量（确认 (3)）——退出模式、回到触发处、按用途执行；取消 / Esc = 全部放弃。
- **拖拽为主不变：** 两文件同屏时，直接拖卡片到详情面板目标区块（关系 / 音色）仍是首选路径，无需进入模式。
- **落地补充（6.2 一轮）：** 备选区两模板 = 关系模式（选中文件 item + 关系输入框×2 + 发起文件 item + 红删）/ 文件选择模式（名称 + 链接状态徽章 + 红删，多选累积——文件选择用途入口随后续轮接入）；回收站文件不可加入备选；关系模式发起文件自身不可选；确认 / 取消退出后恢复发起目标选中（回到触发处 = 详情面板恢复显示发起文件）；右栏收起态进入时强制展开；备选区空态 = 「点击卡片选择」占位 + 确认禁用（稿未画，实现定）。**（2026-08-31 贴新稿重构，7.1 二十三轮：** 备选区 item 组件化（items/PickRelationItem 组卡 / PickFileItem 行卡），旧 54 标题栏「备选区」与 15px 缩略图左标 / 链接状态徽章 / 红删 IconButton 废除（关闭钮 = close-small）；**按钮序改 取消左 / 确认右——全局定案「确认放右边更顺手」，存量弹窗按钮序随轮翻转**（速查表 §1）。）

- **cover 档案封面用途（2026-09-08 落地，用户定）：** 封面设置组「更换封面 - 从资源库中选择」进入；**单选直回规格首次落地——单击图片卡片即定，不进备选区**（备选区仅作模式标识 + 取消入口，确认钮恒不可用）；**过滤非封面图**——网格只渲染可作封面的图片卡片（静态图 png/jpg/jpeg/bmp/webp + gif 动图，与烘培可解码格式同口径；序列帧包排除）、档案区不渲染；横幅「选择图片，为 [名] 设置封面」；选定即退模式回触发处，封面设置组自动展开取景态，确认后烘培（cache/covers/ 覆盖式一档案一文件，见 03 头像条）。
