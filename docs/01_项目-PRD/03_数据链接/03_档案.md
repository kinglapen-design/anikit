## 03. 档案

档案享有与文件一致的数据配置（[[02_文件整理]] 03，含属性与描述），此处仅列差异项。基础信息可手动直接编辑。**（2026-08-15 落地口径：档案与文件共用同一套区块体系，见 02 区块体系条；档案仅多出头像 + 徽标两项——一轮暂无前端编辑入口，徽标编辑归二轮、头像归三轮。）**

- **头像：** hover 头像显示相机图标，点击进入头像编辑——取景框内移动图片调整位置；伴生缩略图、PSD 等文件均可作为头像来源（走既有缩略图管线）。头像即档案卡片封面，二者同步。
	- **数据落地（2026-08-23 改定，6.1 用户定案）：** 头像 = **库根 covers/ 内独立存的烘培封面文件 + 取景框参数**（`Avatar{ file, crop? }`）——本地选图**不入库**为资产；时间戳命名不覆盖写（撤销回滚即恢复旧封面）；「从资源库中选择」的资产引用变体随主窗口选择模式（04）落地时再扩。**编辑入口 = 43 稿封面设置面板**（详情 pinned 区块点击封面展开：取景滑块缩放 + 拖动位移 / 更换封面 / 徽标 / 颜色，确认一次提交）。
- **徽标：** 在档案数据里设置的徽标显示于档案卡片左上角，可不设置；编辑在 43 稿封面设置面板（徽标输入框留空清除 + 颜色 9 色板，--custom-{色} 主档色值入 `Badge.color`）。
