## 03. 档案

档案享有与文件一致的数据配置（[[02_文件整理]] 03，含属性与描述），此处仅列差异项。基础信息可手动直接编辑。**（2026-08-15 落地口径：档案与文件共用同一套区块体系，见 02 区块体系条；档案仅多出头像 + 徽标两项——一轮暂无前端编辑入口，徽标编辑归二轮、头像归三轮。）**

- **头像：** hover 头像显示相机图标，点击进入头像编辑——取景框内移动图片调整位置；伴生缩略图、PSD 等文件均可作为头像来源（走既有缩略图管线）。头像即档案卡片封面，二者同步。
	- **数据落地（2026-08-23 改定，6.1 用户定案；2026-09-08 再改定）：** 头像 = **cache/covers/ 内独立存的烘培封面文件 + 取景框参数**（`Avatar{ file, crop? }`）——选图**不入库**为资产；**覆盖式文件名恒 {folderId}，一档案一文件不累积历史封面**（用户实锤旧时间戳命名积了几十个过期封面），旧封面改名暂存 cache/covers-trash/ 支撑撤销（开库清空，同序列帧 seq-trash 口径）；封面归**可再生缓存**，开库自检把旧版库根 covers/ 迁入并清理无记录引用的文件。「从资源库中选择」**已落地**（2026-09-08，主窗口选择模式 cover 用途，见 04）：网格过滤非封面图（静态图 + gif，排除序列帧包），单击图片**单选直回不进备选区**，回封面设置组取景态确认后同管线烘培（原「资产引用变体」方案不做——用户定烘培快照）。**默认封面图**：无自定义封面且索引子项无可用首图时显示装饰图 档案默认封面.png（档案卡片 / 详情 pinned / 封面设置框同一链）。**编辑入口 = 43 稿封面设置面板**（详情 pinned 区块点击封面展开：取景滑块缩放 + 拖动位移 / 更换封面 / 徽标 / 颜色，确认一次提交）。
- **徽标：** 在档案数据里设置的徽标显示于档案卡片左上角，可不设置；编辑在 43 稿封面设置面板（徽标输入框留空清除 + 颜色 9 色板，--custom-{色} 主档色值入 `Badge.color`）。
