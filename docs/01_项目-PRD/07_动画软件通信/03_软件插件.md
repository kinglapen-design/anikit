## 03. 软件插件

先做 Animate 的 CEP 插件，通过本地 WebSocket 与 AniKit 通信。

插件功能：
- 全局选项：导出静态缩略图，导出动态缩略图。
- 导出为新的文件，并生成缩略图：
	- 单选：导出为 fla。
	- 多选：导出为单一 fla（归 8.3 联合包围盒）；将所选项分别导出 fla。**（2026-09-02 批次 3 落地 = 多选分别导出：舞台多选实例 → 面板逐单项驱动（jsx `beginBatch` 快照选区 / `exportBatchItem` 逐项复用单选流程 / `endBatch`），进度逐条回传状态区；命名 = 各元件库内名（命名框批量期禁用）；非元件实例项跳过计数；每项产物走既有 exported 单条入库（各自 fla + hidden WebP 绑定，同目标文件夹）；完成条件 = jsx 循环止 + 已发回执全收；连接中断复位导出态防卡死。）**
	- 导出选中帧为新文件：若用户选中的是一串动画帧而非元件，则直接剪切粘贴帧后导出序列，不做缩放对齐舞台中央。
	- 对齐方式：保持坐标、对齐至舞台中央；多选元件或元素时，识别整个多选后的外边框（联合包围盒），先记录各元素坐标，再整体缩放对齐至舞台中央，导出后逐一还原。
- 导出缩略图（即手动兜底，无需自动对齐——用户选择直接导出，大概率是已自行调整好画面，或是为整个项目选小范围帧导出一个预览）：
	- 选择帧范围（当用户输入全部帧时，提示用户可能会卡顿或崩溃）。
	- **（2026-09-02 批次 2 落地 = 面板「仅缩略图」模式：** 不复制元件、不新建 fla，直接导当前文档画面——静态 = 播放头帧，动态 = 主时间轴起止帧范围（1-based 含端点，留空 = 全部；帧数超 maxSecs 上限截断并提示，即"卡顿风险"口径的落地）；比例/命名/目标文件夹三控件该模式隐藏。**绑定目标双口径（用户定）：文档路径精确匹配库内 fla 资产（池内实体路径规范化比对）→ 命中 = WebP 入库 + hidden 绑定（已有绑定 = 换绑，旧 hidden 不动）；未命中 = 不入库、WebP 挪原 fla 旁边用户自行导入。** 主时间轴嵌套 movieclip 不逐帧推进属 Animate 天性（jsx 注释明示），嵌套动画走「新文件」元件导出。模式选择 localStorage 记忆。**）**

无论是 AniKit 缩略图生成，还是 CEP 插件里的导出为新文件，都要保持原坐标导出，模拟手动操作的话就是：复制元件 - 原位粘贴 - 记录坐标 - 缩放移动至舞台中央 - 导出序列帧 - 合成 WEBP - 还原坐标 - 保存文件（AniKit 的缩略图生成，则是直接关闭，不保存，避免修改到文件）。

#### 实施定案（2026-09-01 用户定，一轮 = CEP 选中元件导出先行）

排期调整：用户素材急需整理，阶段八拆分提前到阶段七 7.1（暂停于二十六轮）之前——**8.1 = CEP 插件 + 选中元件导出**（本轮）→ 8.2 = APP 内无伴生图批量导出（02 节内容，jsfl 直启兜底 + CEP 在线通道）→ 8.3 = CEP 完整能力（多选联合包围盒 / 选中帧导出 / 快速发送）→ 8.4 = Chrome 插件。一轮范围只做**单选元件导出对齐舞台中央**，多选 / 选中帧导出不做。

**面板（交互形态 = 面板预设 + 一键导出，样式套 APP 暗色 token 朴素版先跑通，正式稿后补）：**

- 控件清单：连接状态指示（与 AniKit 的 WS 连接，断开时导出钮禁用）/ 静态·动态切换开关 / **命名输入框（默认填充元件名，用户可改——工作中元件名多为"元件1"类默认值，无参考意义，2026-09-01 用户补充）+ 中文输入辅助钮**（CEP 面板 HTML 输入框打不了中文 = CEF IME 顽疾；辅助钮弹 jsx ScriptUI 原生输入框走系统 IME，输完回填命名框——用户旧项目 promptForName 同款，2026-09-01 定） / 目标文件夹树选择器（**默认未分类，不选可直接导出**，同用户补充；树数据由 APP 经 WS 实时下发）/ 导出按钮（选中元件时可用，导出中防重入）/ 状态区（进度 / 成功 / 失败原因）/ 当前生效参数只读展示（帧数 / 大小 / 尺寸上限，来自 APP 设置，面板不可改）。

**导出规格：**

- 命名：输入框内容为准（默认 = 元件库内名称）；与目标位置已有文件冲突自动 `_2`/`_3` 唯一化；WebP 与 fla 同名词干。
- 新 fla 舞台：高度跟随元件所在当前文档；内容等比缩放至舞台短边 90% 后居中（留边不贴边）；导出完成后还原坐标，新 fla 内元件保持居中后的坐标保存。**（2026-09-02 比例档落地：面板加导出比例选择——分段快选 自动 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 + 自定义框「宽:高」输入即生效，两者互斥，localStorage 记忆；基准 = 高度跟随当前文档、宽 = 高 × 比例四舍五入取整（用户定），「自动」= 跟随文档原尺寸）****（2026-09-02 面板分组轮修订：① 自定义比例框废除改**像素双框**（宽 px × 高 px，两框都填直定舞台尺寸、优先于比例档——用户定「比例算起来麻烦，直接传像素建文档」；「自动」更名「文档」+ tip 注明跟随当前文档舞台尺寸）；② 面板控件分组加小标题（导出模式 / 画面 / 入库）；静/动分段与模式分段主次区分 = **模式分段 16px 加粗 + 选中品牌色**（静/动先改复选框后复验改回分段——用户定「有标题分割不乱，切换按钮更直观」）；③ 面板超高出滚轮（控件不压缩，滚动条悬浮 6px 悬停显隐 + 右留 6px 隙）；④ 仅缩略图模式显示说明文字（静态 = 播放头帧 / 动态起止留空 = 全部截断 / 库内绑定库外落旁边）；⑤ 批量命名 = 命名框作**前缀**（空 = 元件名现状；非空 = 前缀-序号，≥10 补零），命名框不再禁用）****（2026-09-02 对齐档落地：面板加对齐分段「保持坐标 | 合适舞台」，localStorage 记忆——保持坐标 = 现状口径（导出后还原坐标再保存，fla 保原坐标，与 04 快速发送原位粘贴联动）；合适舞台 = 缩放居中态直接保存不还原（拥挤 fla 拆素材场景，拆出元件即在舞台中央，用户定）；symbolType/loop 恢复恒做（元件语义与坐标无关）；仅缩略图模式不适用自动隐藏；批量导出各项沿用当前档）**
- 动态 WebP：帧率 = 文档 fps；帧数上限默认 **10 秒**（随 fps 换算）；PNG 序列按舞台尺寸逐帧无损导出，合成前缩放到长边 ≤1024。
- 大小软上限 **2M**：限制只作用于 ffmpeg 合成 WebP 环节（PNG 中间产物合成完即删、与限制无关）；超限自动分级重压——降质量（80→60→40）→ 缩尺寸（1024→768→512）→ 减帧率（减半），一次 PNG 导出可反复尝试合成；极端压不进也保留产出并提示。
- 静态导出：取元件第 1 帧（对齐后单帧画面）。

**入库口径：**

- 产物落**库根 `temp/cep-out/`**（2026-09-01 用户定两级：① 不落 C 盘临时目录——同盘剪切进库快、合成失败残留可手动清理；② **temp 与 cache 分离**——temp = 中转产物临时文件（用完即删），cache = 可重建缓存，今后各功能临时文件在 temp/ 下各有归属子目录），插件经 WS 通知 AniKit（fla 路径 + WebP 路径 + 目标 folderId + 命名）；AniKit 走正常导入管线收进 assets 池，导入完成后清除产物。库根路径由 AniKit 在 WS 连接建立时下发给插件。
- fla 进选定文件夹（默认未分类）；WebP 导入为独立资产后按 [[02_文件整理]] 02-15 打 **hidden 标记并绑定 fla**（thumbAssetId 模型本轮兑现）：普通视图统一过滤、快速访问「缩略图」视图点亮（按资产显示一次并标注绑定的工程）、fla 卡片经 thumbAssetId 直接显示 / 播放该 WebP（动态缩略图复用动图卡片既有播放能力）。

**设置共享：** 导出参数（帧数上限 / 大小上限 / 像素尺寸）存 APP 全局设置文件 `settings.cepExport` 子树（单一写点）；CEP 连接时 APP 下发、变更时实时推送（`settings` 消息广播），插件本地缓存最后值供 APP 未启动时兜底；8.2 APP 内批量导出读同一份设置，天然一致。**APP 设置入口（2026-10-13 定稿）= 偏好设置 ▸「插件」区**（导出三参数：单段时长上限秒 / 导出大小上限 MB / 帧率 0=跟随文档，失焦即存）；09-01 曾以「工具栏插件钮 → CEP 导出设置弹窗」先行兑现，设置面板轮收编进插件区（不单独挂牌——用户定「APP 不能像 AN 专用挂件」）。

**安装：** AniKit 提供 CEP 插件一键安装（复制到 CEP extensions 目录 + 写 PlayerDebugMode 注册表项），免手动配置。

**通信开关（2026-09-25）：** 插件 WS 服务总开关 `settings.pluginServer.serverEnabled` 缺省开，插件面板 Animate 详情窗「通信服务」组随时启停——不用插件时关了不白听 127.0.0.1 端口（MCP 总开关同款形态）；stop = 收束监听 + 断开全部已连面板 + 删端口文件，再开即恢复。
