## 15. 快速访问视图（2026-08-04 定案）

全部 / 未分类 / 最近使用 / 自动导入 / 缩略图 / 回收站统称**快速访问**——数据自动归类的只读视图，不可作为拖拽落点与粘贴目标。

- ~~资产级去重~~（**2026-08-13 用户定案废除**：不替用户做整理决定——快速访问视图按实际 Placement 显示，链接不再隐藏，侧栏计数同口径；原"按资产显示一次只显原始 Placement"作废）。
- **候车区（未分类 / 自动导入）：** 只是临时落点，**不做内容限制**（2026-08-13 用户定案）——链接允许从任意资产发起、允许落在未分类，同文件夹允许重复链接；怎么整理是用户的事。原"只收原始文件 + 发起端/落点双护栏 + 文件夹选择弹窗无未分类项 + 开库剔除 root 链接"整体废除；"移出根目录即摘标"、"快速访问不作拖拽落点与粘贴目标"的交互规则不变。
- **删除文件夹时的位置去向（2026-08-19 修订）：** 删除文件夹时子树全部 Placement（origin 与链接一视同仁）回未分类——原"链接随文件夹直接删除"定案废除（位置级模型：链接当真实文件对待）。物理删除只在彻底删除（回收站 / permanent）路径发生，彼时他处指向被删资产的链接一并清除（本体已死）。
- **缩略图视图（hidden 资产）：** 图片被设为工程 / 档案的缩略图后打 hidden 标记——**不复制、不搬迁、不删链接**：所有视图统一过滤 hidden 资产，其在各文件夹的链接位置自动从视图消失；缩略图视图按资产显示一次并标注绑定的工程；**一个资产可绑定多个工程**（thumbAssetId 引用不受 hidden 影响）；「还原为素材」取消 hidden 后所有链接位置原样恢复。工程更换缩略图后，旧缩略图资产可「解除缩略图」（回未分类）或删除。**生命周期跟随（2026-09-02 资产污染修复）：** 彻底删除工程 / 档案时，其 hidden 伴生缩略图资产**无其他存活资产引用才一并物理删除**（一个 hidden 可绑多工程，引用未归零保留）；「还原为素材」后的资产已是普通资产，不随删。开库自检扫描无主 info：空壳（无 metadata.json 的半截残骸）自动物理清理；孤儿（metadata 在但 folders ∪ 回收站无引用）只记日志清单不自动删，由用户确认后处置。**（2026-09-01 阶段八 8.1 落地：metadata `hidden` / `thumb_asset_id` 字段 + set_thumb_asset / restore_thumb_asset 命令 + 视图过滤与代理，接口见 [05_接口文档](../../05_接口文档/Index.md)；缩略图视图的"标注绑定工程"展示与详情「缩略图」区块反查随后续轮）**
- **链接区块显示规则（详情面板，见 [[03_数据链接]]）：** 未分类显示为「目录 / 未分类」（未分类 = 默认区块「目录」的根级）；回收站条目与库内活位置分列——资产本体在回收站时链接区块追加「回收站（原位置：区块 / 路径）」行（2026-08-19 位置级模型：回收站资产的活链接可以存活，照常反查显示）；「全部」为递归视图不是位置，不进链接区块。
