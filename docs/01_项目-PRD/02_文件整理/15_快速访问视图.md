## 15. 快速访问视图（2026-08-04 定案）

全部 / 未分类 / 最近使用 / 自动导入 / 缩略图 / 回收站统称**快速访问**——数据自动归类的只读视图，不可作为拖拽落点与粘贴目标。

- ~~资产级去重~~（**2026-08-13 用户定案废除**：不替用户做整理决定——快速访问视图按实际 Placement 显示，链接不再隐藏，侧栏计数同口径；原"按资产显示一次只显原始 Placement"作废）。
- **候车区（未分类 / 自动导入）：** 只是临时落点，**不做内容限制**（2026-08-13 用户定案）——链接允许从任意资产发起、允许落在未分类，同文件夹允许重复链接；怎么整理是用户的事。原"只收原始文件 + 发起端/落点双护栏 + 文件夹选择弹窗无未分类项 + 开库剔除 root 链接"整体废除；"移出根目录即摘标"、"快速访问不作拖拽落点与粘贴目标"的交互规则不变。
- **删除文件夹时的位置去向（2026-08-19 修订）：** 删除文件夹时子树全部 Placement（origin 与链接一视同仁）回未分类——原"链接随文件夹直接删除"定案废除（位置级模型：链接当真实文件对待）。物理删除只在彻底删除（回收站 / permanent）路径发生，彼时他处指向被删资产的链接一并清除（本体已死）。
- **缩略图视图（hidden 资产）：** 图片被设为工程 / 档案的缩略图后打 hidden 标记——**不复制、不搬迁、不删链接**：所有视图统一过滤 hidden 资产，其在各文件夹的链接位置自动从视图消失；缩略图视图按资产显示一次并标注绑定的工程；**一个资产可绑定多个工程**（thumbAssetId 引用不受 hidden 影响）；「还原为素材」取消 hidden 后所有链接位置原样恢复。工程更换缩略图后，旧缩略图资产可「解除缩略图」（回未分类）或删除。**生命周期跟随（2026-09-02 资产污染修复）：** 彻底删除工程 / 档案时，其 hidden 伴生缩略图资产**无其他存活资产引用才一并物理删除**（一个 hidden 可绑多工程，引用未归零保留）；「还原为素材」后的资产已是普通资产，不随删。开库自检扫描无主 info：空壳（无 metadata.json 的半截残骸）自动物理清理；孤儿（metadata 在但**全空间各库** folders ∪ 回收站均无引用——assets 池空间级共享，引用判定 2026-09-26 自当前库口径修为空间级并集）只记日志清单不自动删，由用户确认后处置。**（2026-09-01 阶段八 8.1 落地：metadata `hidden` / `thumb_asset_id` 字段 + set_thumb_asset / restore_thumb_asset 命令 + 视图过滤与代理，接口见 [05_接口文档](../../05_接口文档/Index.md)；缩略图视图的"标注绑定工程"展示与详情「缩略图」区块反查随后续轮）**
- **链接区块显示规则（详情面板，见 [[03_数据链接]]）：** 未分类显示为「文件夹 / 未分类」（未分类 = 默认区块「文件夹」的根级；区块名 2026-09-17 由「目录」更名）；回收站条目与库内活位置分列——资产本体在回收站时链接区块追加「回收站（原位置：区块 / 路径）」行（2026-08-19 位置级模型：回收站资产的活链接可以存活，照常反查显示）；「全部」为递归视图不是位置，不进链接区块。
- **入口收窄（2026-09-09 用户讨论定案）——视口二分：** 未分类 / 自动导入 = **位置视口**（真实落点，位置级操作全开放；自动导入维持 09-08 禁手动添加，移出归位保留）；全部 / 最近使用 / 缩略图 = **虚拟视图**（不是位置，位置级与落点类操作在此语义不成立——「全部」里移动文件 = 黑箱，用户不知从何移到何）；回收站维持 2026-09-05 口径（全列 + 写能力占位禁用）。
  - **虚拟视图禁：** 移动 / 剪切 / 创建副本 / 粘贴两项 / 导入 / 新建文档 / 从文件夹中移除——右键不出现，菜单栏与快捷键（Ctrl+Y / Ctrl+X / Ctrl+D / Shift+Del）同判定禁用，**卡片不可拖出**（拖出 = 黑箱移动同病）。**删除组自此拆开**：「丢到回收站」保留（删除 = 资产"要不要"的判断，一眼可辨、无需在乎位置；多位置条目右键哪条丢哪条），「从文件夹中移除」禁（名字即位置语义）——原 08-18"删除组快速访问同口径"修订。
  - **虚拟视图留（资产级 / 所见即所得）：** 打开与外发全组（预览 / 新窗口 / 默认应用 / 其他应用 / 发送至 Animate / 资源管理器）/ 导航（打开链接所在位置）/ 复制（文件 / 数据 / 缩略图）/ 导出 / **重命名**（定案理由：名字显示在卡片上所见即所得——缩略图视口改 hidden 伴生图名配工程名、最近使用顺手改名两案例）/ 标签 / 描述 / 缩略图绑定组 / 设为原始 / 链接管理。业务未立项占位项（新标签页 / 添加资源库 / AI 工具集 / 提示词 / 置顶）快速访问右键不列。
  - **未分类 = 候车区总入口放开：** 导入 / 新建文档 / 粘贴 / 拖入可落（落点 root 所见即所得；原"快速访问一律不作粘贴目标"自此豁免未分类）。**「全部」导入 / 新建封堵**（推翻 09-08"全部/未分类允许"半句：全部不是位置，落点必借道）——禁导入判定扩五视口（全部 / 最近使用 / 自动导入 / 缩略图 / 回收站），拖拽拒入弹窗同口径。
  - **新建文件夹 / 档案六个快速访问视口一律禁**（快速访问无文件夹概念，菜单栏整组置灰）。
