## 04. 分组

档案与普通文件夹通用的内容区组织能力（功能来源参考 Windows 资源管理器分组，支持自定义），工具栏分组图标点击进入分组设置。

- **3.5 二轮落地定案（2026-08-19，逐项用户定）：**
	- **数据归属：** 分组规则存 folders.json 文件夹节点 `Folder.groups`（`GroupDef{id, name, rules[]}`，serde default 不升 DATA_VERSION；数组序 = 定义顺序 = 内容区组间序）；**仅文件夹/档案视图生效**（快速访问无分组——无存放节点）；归组计算在前端显示层（lib/grouping.ts），不改任何数据；克隆文件夹分组随迁。
	- **生效范围：** 内容区素材卡片（文件夹/档案卡片不参与）；**仅非递归视图生效——递归显示开启时不分组（纯平铺，排序/新增区照常），分组配置仅对直接子项有意义；工具栏分组管理钮递归态禁用**（2026-08-19 复验定案：递归下为后代素材建的组在非递归视图成幽灵配置，所见/配置不一致；原"递归按当前文件夹规则统一归组"口径废除）。
	- **归组语义：** 组内多规则 **AND 全命中**才归组；多组同时命中归**命中关键字（值）更多**者（更具体——**2026-09-17 用户实机修订**：旧"规则条数更多者"在规则数相同、名称词数不同时误判——组一 名称{P1}、组二 名称{P1,2K}，「P1_02_2K」命中词 1 vs 2 应归组二；ext/类型/日期等单值域命中计 1、名称按命中词数计），平局按定义顺序先建者优先；未命中 = 未分组（**恒在头**，2026-08-19 用户定；**没有任何组命中时未分组段不显示——视觉平铺**，同日复验定案：0 命中组仍在管理窗口可见可编，内容区不挂"未分组"孤标题）；组内顺序 = 排序流相对序（排序方式与新增区在组内自然生效）；**同组内允许拖拽互相排序**（落点限同组段内），**跨分组拖拽禁止出落点**——组归属由规则定，拖入别组不改变归组（2026-08-20 用户定，替换原"分组模式整体禁排"；多选跨组选中时拖拽排序同样无落点）。
	- **类型 8 类**（用户定，替代旧"文本/图片/文档/视频"）：图片 / 动图（GIF·动图·序列帧）/ 视频 / 音频 / 文本 / 文档 / 工程（psd·fla·ai·aep 等）/ 其他；**选项按当前文件夹实际存在动态出**（33 稿注释口径）；首字母分组不做（04_文件预览 07 节旧表述废除）。
	- **日期分档六档互斥**：今天 / 昨天 / 本周早些时候 / 上周 / 本月早些时候 / 更早（本周以周一起）；规则可选多档（OR）；一个文件只落一档。
	- **折叠：** 分组标题折叠 = 仅该组子项折叠（区块标题折叠 = 全部组随折）；会话级不持久化；分组标题 **sticky 置顶**（滚过顶停留、下一组接替顶走，05_区块标题布局规则落地；**贴视口顶**——列表模式让开钉顶列头，2026-08-19 复验定）；**组间距 24**（首组离内容标题恒 12，同日复验定）；**无文件夹/档案区块的视图分组后不出"内容"副标题**（组标题直接顶上，同日定）。
	- **入口与弹窗分工：** 工具栏「分组管理」钮（仅文件夹/档案视口可用）→ 33 稿分组管理弹窗（草稿式一次提交单撤销步，箭头排序 + TransitionGroup，添加分组 / 删除红钮）；分组标题 group-menu 钮 → 12 稿菜单（跳转▸ = 全组列表滚动跳转 / 新建分组 → 34 稿弹窗（单次一个）/ 编辑分组 → 33 稿弹窗 / 展开折叠▸ / 移动至顶层 / 上移 / 下移 / 移动至底层（2026-10-08 追加，组多时免逐层挪）/ 删除——未分组组简化菜单仅跳转与展开折叠）；23 稿错误（完全相同拦截）= **名称不查重，仅规则集合**（组序/规则序/值序无关）——前端预检弹 23 稿 + 后端同校验兜底。
- **未分组：** 新拖入的文件默认放入未分组；设置自动分组后，进入的文件按规则自动归组（如开启扩展名分组，fla 文件默认进 FLA 组）。
- **自定义规则：** 扩展名（检测全部扩展名供多选）/ 类型（8 类供多选）/ 名称（输入分词，AND 逻辑——空格分隔多词全部命中；**匹配对象为词干，不含扩展名**——2026-09-22 P4⊂mp4 案：匹配全名时 "P4" 撞中 ".mp4" 里的 "mp4" 子串，P5A_01.mp4 误命中 P4 组且与 P5 组权重平局、按定义序误入 P4）/ 导入日期 / 修改日期（日期分档互斥，见上）/ **标签（2026-09-17 实机走查追加）**——按 metadata.tags 归组：输入标签词（chips），**AND 全命中**（多词 = 资产须全带，与名称规则同口径；命中词数计入归组权重）；**单规则组互斥转移同扩展名口径**（一个标签词同时只属于一个单规则标签组，改选即转移 + toast 告知）。卡片数据通道：PlacementView 增 `tags` 字段（后端 views.rs 自 metadata 带出，与排序四字段同径）。**角标不定规则**（同日用户定：档案自定义角标才有归组价值，但档案进分组尚无对应业务，不做）。
- **规则冲突处理（2026-08-04 定）：**
	1. 两个组规则与范围完全相同时，弹出报错，禁止保存；
	2. 单规则组之间互斥——组二选择已被组一占用的扩展名 / 类型 / 日期时，该项自动从组一转移至组二，并 toast 明确告知（确认前取消则全部恢复）；
	3. 多规则组合允许重叠，文件优先进入命中关键字更多的组（如组一 = fla、组二 = fla + 名称"雪牧"，则含"雪牧"的 fla 归组二；组一 名称{P1}、组二 名称{P1,2K}，「P1_02_2K」命中词 1 vs 2 归组二——2026-09-17 修订明确**按命中关键字（值）数**而非规则条数）；命中数相同的平局按分组定义顺序，先建者优先。
- **AI 写规则：** 后续版本可指派 AI 生成规则，解放手动输入（见 11）。
- **无规则空组（自由组，2026-09-17 实机走查定案）：** 仅靠规则无法灵活分组——**创建即为空、完全无规则、手动归组**的组。`GroupDef` 增 `members?: string[]`（assetId 有序列表，serde default 不升 DATA_VERSION）；**rules 为空即自由组**（规则组与自由组不混态：弹窗里规则组不出现 members、自由组不出现规则编辑）。**归组优先级 = 手动成员 > 规则**（显式动作胜）：资产在自由组 members 内即归该组（同在多个自由组按定义顺序先者——实际通过「移动语义」保证唯一：移入即从他组摘除），否则按规则权重归组；自由组成员身份**唯一**（移动至分组 = 从本文件夹其他自由组摘除后加入）。**空自由组恒渲染**（规则空组仍不出——视觉平铺定案不动）：初始给小高度 + 居中一行提示「将文件拖入分组」。**交互**：拖卡片入自由组段（段体 / 标题）= 移入（并入落点高亮，**2026-08-20「跨分组拖拽禁止出落点」定案对自由组放开**——自由组的组归属由手动定，规则组不变）；拖出至未分组段 / 右键「移出分组」= 摘除成员身份（回未分组或按规则重估）；文件卡右键「移动至分组 ▸」= 自由组清单 + 移出分组（多选批量、单撤销步，命令 `assign_group(folder, group|null, assetIds)`）。**「完全相同」查重只管规则组**（自由组无规则可比，按名称区分）；组内排序与规则组同（排序流相对序 + 同组内可拖拽排序）；组间序 = 定义序（自由组与规则组混排）。**克隆文件夹随迁重映射**：规则组原样随迁；自由组 members 按克隆资产 id 映射表重指新副本，无对应新副本的成员剔除。
