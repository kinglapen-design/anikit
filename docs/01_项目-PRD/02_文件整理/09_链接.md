## 09. 链接

可为素材添加链接，点击链接可打开浏览器跳转，允许添加 ID 路径：`anikit://item/{ID}`，来进行点击后软件内跳转。

- **数据归属：** 链接列表存于 metadata.json 的 links 数组，纳入分词搜索范围（匹配前 URL decode，见 [[03_查找文件]]）。
- **双形态分工（2026-10-08 定案）：** `anikit://item/{ID}` = **内部标识符**（复制链接 / links 字段 / 内部 MD 引用语法 / MCP 工具参数），只在 AniKit 内部解析消费（选中 + 跳转定位），ID 寻址改名不死链；`http://127.0.0.1:{port}/item/{ID}` = **对外可点击形态**——本地媒体服务端点 `GET /item/{ID}` 返回图片字节（外部 MD `![]()` 引用渲染）+ `GET /open/item/{ID}` 点击跳转回 AniKit（内部定位 + 主窗口前置），外部编辑器 / AI 客户端零注册零插件通用。
- **系统协议注册废案（2026-10-08 用户定）：** 原 2026-08-21 定案「安装时向系统注册 anikit:// 协议处理（Windows 注册表 / macOS Info.plist）」作废——`/open/item/{ID}` http 端点覆盖全部点击跳转场景，deep-link 唯一增量「少开一个浏览器标签」不值注册表写入与单实例参数转发成本，portable 分发保持零系统副作用。
- **外部文档引用形态（2026-10-08 定案）：** Markdown 图片用 `![名](http://127.0.0.1:{port}/item/{ID})`（渲染器只认 http/file 字节流不认自定义协议的旧边界不变，故对外流通一律 http 形态；右键「复制 MD 图片」菜单两项 = 裸 / 带跳转回链）。**复制文件路径形态废弃**——info 黑箱不可辨认 + 磁盘名随重命名变化即死链 + Obsidian 不渲染 vault 外本地路径。
- **打包导出（2026-10-08 定案）：** 发送场景由 AniKit 侧「打包导出」解决（AE 收集打包的 MD 版）——解析文档内 anikit:// 与 http://127.0.0.1:*/item/{ID} 双形态引用（同一归一化解析器），收集图片导出文档旁 assets/（文件名用资产名）并改写相对路径；工作空间文档右键直通免导入。
- **实现排期（2026-10-08 用户定，自阶段九提前）：** S1 媒体服务端点 → S2 复制 MD 图片菜单 → S3 内部 MD 渲染与粘贴补全 → S4 links 输入框编辑跳转 → S5 MCP URI 增强 → S6 打包导出；步骤卡见待办细节清单 2026-10-08，定案全文见开发日志 2026-10-08_06。**（2026-10-08 当日晚 S1-S6 全部落地，开发日志 2026-10-08_07；内部 MD 图片引用与链接可点两个 09 待办同批勾销。）**
