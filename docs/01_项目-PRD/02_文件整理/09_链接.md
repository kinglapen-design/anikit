## 09. 链接

可为素材添加链接，点击链接可打开浏览器跳转，允许添加 ID 路径：`anikit://item/{ID}`，来进行点击后软件内跳转。

- **数据归属：** 链接列表存于 metadata.json 的 links 数组，纳入分词搜索范围（匹配前 URL decode，见 [[03_查找文件]]）。
- **双形态分工（2026-10-08 定案）：** `anikit://item/{ID}` = **内部标识符**（复制链接 / links 字段 / 内部 MD 引用语法 / MCP 工具参数），只在 AniKit 内部解析消费（选中 + 跳转定位），ID 寻址改名不死链；`http://127.0.0.1:{port}/item/{ID}` = **对外可点击形态**——本地媒体服务端点 `GET /item/{ID}` 返回图片字节（外部 MD `![]()` 引用渲染）+ `GET /open/item/{ID}` 点击跳转回 AniKit（内部定位 + 主窗口前置），外部编辑器 / AI 客户端零注册零插件通用。
- **系统协议注册（2026-10-08 deep-link 复活）：** 外部点击 anikit:// 链接 = 系统拉起 exe 带 URL 参数 → 单实例回调转发运行中实例，**零浏览器标签页**。注册 = 启动时幂等覆写 HKCU\Software\Classes\anikit（免提权、portable 绿色、exe 漂移自愈；冷启动链接参数存 pending 待前端就绪消费）。（沿革：2026-08-21 初版定案注册 → 当日午改定 /open http 端点替代并废案 → 实机后浏览器标签堆积干扰坐实、且单实例回调本就携带命令行参数，废案复活。http /open 端点保留：AI 客户端只认 http 链接 + 未注册环境兜底。）
- **by-name 形态（2026-10-23 编辑器贴图直链定案）：** 粘贴场景写入链接时资产可能尚未入库、拿不到 ID——两种形态各扩一个按名解析变体：`http://127.0.0.1:{port}/item/by-name/{文件名}`（媒体服务按 originName 解析**最新一笔**非回收站、非隐藏伴生资产，等值比较小写归一）与 `anikit://item/by-name/{文件名}`（深链同径，前端经 `resolve_asset_by_origin_name` 解析成 ID 后走既有 item 跳转定位）。文件名由写入方生成唯一时间戳名（`贴图-yyyyMMdd-HHmmss-fff`），确定性 = 唯一名 + 最新优先。媒体端点对导入途中的暂态未命中短暂等待（最多 10 秒），避免外部编辑器缓存破图；超时仍 404，深链点击解析不到仍 toast「尚未导入或已删除」。
- **外部文档引用形态（2026-10-08 定案）：** Markdown 图片用 `![名](http://127.0.0.1:{port}/item/{ID})`（渲染器只认 http/file 字节流不认自定义协议的旧边界不变，故对外流通一律 http 形态；右键「复制 MD 图片」菜单两项 = 裸 / 带跳转回链）。**复制文件路径形态废弃**——info 黑箱不可辨认 + 磁盘名随重命名变化即死链 + Obsidian 不渲染 vault 外本地路径。
- **打包导出（2026-10-08 定案）：** 发送场景由 AniKit 侧「打包导出」解决（AE 收集打包的 MD 版）——解析文档内 anikit:// 与 http://127.0.0.1:*/item/{ID} 双形态引用（同一归一化解析器），收集图片导出 assets/（文件名用资产名）并改写相对路径；工作空间文档右键直通免导入。**WS 落点（2026-10-24 用户定）：** 默认仍在当前文档旁生成 `{文档名}-打包/`；「偏好设置 → 通用 → MD 打包导出目录」可配置全局默认目录，设置后 WS 直接导出到该目录，不逐次弹窗；恢复默认即回文档旁。配置目录失效时明确报错、不静默回退；库内 MD 仍逐次选择导出目录。
- **实现排期（2026-10-08 用户定，自阶段九提前）：** S1 媒体服务端点 → S2 复制 MD 图片菜单 → S3 内部 MD 渲染与粘贴补全 → S4 links 输入框编辑跳转 → S5 MCP URI 增强 → S6 打包导出；步骤卡见待办细节清单 2026-10-08，定案全文见开发日志 2026-10-08_06。**（2026-10-08 当日晚 S1-S6 全部落地，开发日志 2026-10-08_07；内部 MD 图片引用与链接可点两个 09 待办同批勾销。）**
