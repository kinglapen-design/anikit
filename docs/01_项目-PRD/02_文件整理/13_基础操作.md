## 13. 基础操作

#### 封闭式资源库（仅改数据，不动磁盘）

- **撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z）：** 一切写操作可逆——会话级双栈（上限 50 步，切库清空，不持久化），每步记录受影响数据文件的操作前快照与磁盘逆操作，逐步撤销逐步重做（机制见 [03_项目进度](../../03_项目进度/Index.md) 阶段 6.0）。
- **拖拽排序：** 拖拽调整顺序，写入 Placement 的 order 字段。落点视觉统一为品牌色-1（2026-07-28 定）：文件树 item 高度三等分——上下 1/3 判定为排序（显示插入线 + item hover 背景），中间 1/3 判定为并入（item 底 = 品牌色-1 12% 填充 + 1px 边框）；卡片排序落点 = 品牌色-1 12% 填充 + 1px 边框的**圆角竖向矩形色块填满卡片间距**，拖到文件夹卡片上 = 并入（刚好覆盖缩略图区域的方形覆盖，同配色）。**文件夹卡片与素材卡片排序不混排。**
- **拖拽移动 / 剪切（Ctrl+X）+ 粘贴（Ctrl+V）：** 移动 Placement 至目标文件夹；**素材、档案、文件夹均支持剪切粘贴（2026-08-04 修订——剪切 = 移动，三种实体全通；原"剪贴板移动仅素材"作废；2026-08-18 已落地）**，文件夹剪切粘贴复用 move_folders 护栏（禁止移入自身或子文件夹、粘贴时源失效则 toast 提示）；剪切期间源项半透明（--opacity-cut）。快速访问项是数据自动分类视图，**不可作为拖拽落点与粘贴目标**；档案不接收文件夹（无子文件夹约束）。
- **移动面板（Ctrl+Y / 右键菜单「移动文件 / 移动文件夹 / 移动档案」，29 稿，2026-08-18 落地）：** 弹层文件夹树选落点——item 上中下三段 hover（上/下 1/3 = 移为目标 item 的前/后兄弟，中 1/3 = 并入为子项，落点视觉同树拖拽插入线 / 并入填充），单击弹警告确认（alert 模板，发起名与目标父级名品牌色-常态高亮）；默认全部展开 + 搜索过滤；移动文件夹 / 档案时发起项自身及后代不显示（不能移入自己）；树恒按自定义序渲染（落点所见即所得）；多选批量 = 整个选中集一次移动（单撤销步）。
- **粘贴两键（2026-08-18 定案）：** **Ctrl+V = 作为链接粘贴**（静默执行不弹窗，显示名默认取源名；同文件夹重复链接放开，显示名自动唯一化——2026-08-13 用户定：不替用户做整理决定，原"同资产同文件夹只允许一条链接 + 重复粘贴去重 toast"作废）；**Ctrl+Shift+V = 作为副本粘贴**——物理复制生成新 ID，不弹窗直接执行，名称与源一致。**Ctrl + 拖拽落文件夹 = 直接建链接不弹窗**（与 Ctrl+V 同语义）。右键菜单露出两个粘贴项（**剪贴板为空时粘贴项不出现**；文件夹「粘贴文件夹」同口径——2026-09-05 走查：没有剪切过文件夹就不出现，旧"恒列置灰"废除）。——原 2026-08-04"三键"定案的「作为链接粘贴并重命名（Ctrl+Shift+V 选择性粘贴清单弹窗）」与 Ctrl+Alt+V 键位**废除**（2026-08-18 用户定：导入就是导入，命名导入后手动 F2 / 批量重命名；高频整理弹窗烦人——关联弹窗 / 选择性粘贴弹窗均不再出现）。
- **新建文件夹（2026-07-28 定）：** 侧栏「文件夹」副标题添加按钮 = 新建当前选中文件夹的兄弟（插到其下一行；侧栏恒有选中项，选中快速访问项时插到根级最底部）；右键菜单「新建同级文件夹 / 新建子文件夹」——均不用模态框，直接创建并进入名称输入态；对 item 触发插到其下一行，空白处触发建到最底部。
- **新建文档（3.1 二轮落地，2026-08-15 用户定案）：** 新增菜单固定七项恒显（放弃 shell 软件检测动态显隐）——Animate(.fla) / Photoshop(.psd) / Illustrator(.ai) / MarkDown(.md) / 文本(.txt) / Word(.docx) / Excel(.xlsx)；**AE 不建档**（工程文件素材为链接路径、成稿需打包工程，适合工作空间而非封闭式资源库）。菜单图标本地化（svg 入库 + md.webp + txt.png 系统记事本图标一次性提取留存；**2026-09-05 走查：七项图标入 `assets/icons/05_文档图标/`（位图 base64 包壳 svg），菜单项带左图标——「右键菜单-带图标」稿口径：同菜单无图标项左占位对齐**）。二进制五类以 `assets/templates/` 空白模板为内容建档（编译期内嵌）；md/txt 空内容。均不用模态框，落当前视口目录（同导入位置口径），先建后命名进名称输入态，可撤销。
- **重命名（F2 / 右键菜单）：** 非模态——标题就地变为输入框（卡片与文件树 item 同）；重命名**原始 Placement** 时，同步将磁盘上的 originName（含词干缩略图等伴生文件）一并改名，失败中文报错并整体回滚（2026-07-28 修订为同步语义——配合撤销机制天然可逆；原"先改显示名、后台空闲时异步执行 + 启动自愈"队列方案降级留待，日后遇 Animate 占用致改名失败场景再评估）；重命名**链接 Placement** 仅改显示名（数据规则详见 [[01_资源与数据]]）。
- **克隆文件夹（Ctrl+D / 右键菜单「克隆」，2026-08-18 落地，3.4）：** **复制克隆，无弹窗**——递归复制子树：文件夹节点结构（图标 / 颜色 / 区块归属 / 档案记录随迁）+ 子树 origin 资产物理副本（各自新 ID，同资产只复制一次）+ Placement 结构忠实重建（链接指向子树内新副本；指向子树外的链接原样保留，不越界复制别夹本体）。根克隆命名"xx 副本"（同级唯一化）紧随源之后，单撤销步。**没有链接克隆**（2026-08-18 用户定：文件夹没有链接语义，原"链接克隆 / 复制克隆"弹窗设计废除）；~~档案不可克隆~~（**2026-09-05 走查改定：档案可克隆**——档案右键「克隆」同文件夹 clone_folders 单命令，档案记录随迁；档案菜单「作为副本粘贴」删除（走克隆语义）；「复制档案 / 作为链接粘贴」随档案多位置立项（6.2 三轮遗留①）后按条件出现，立项前菜单不列）。
- **创建副本（Ctrl+D）：** 就地创建副本（当前位置生成新 ID），完全独立。
- **复制 base64（右键菜单"复制数据"）：** 静态图片（png / jpg / jpeg / bmp / webp / gif）复制原文件字节 base64（≤10MB）；**psd / psb / svg 复制解码后 PNG 的 base64（2026-08-14 用户定）**——合成图解码 → 长边 ≤4096（复用全尺寸预览口径）→ PNG 编码 ≤10MB，贴给 AI / 网页可用（原字节 PSD 对方不认，且 123MB 级文件编码无意义）；其余格式不支持（toast 提示）。返回纯 base64，不带 data: 前缀。
- **删除（Del / Shift+Del）：** 「丢到回收站」（Del）= 该位置进回收站（recycle.json 按资产聚合记录，物理不动，撤销可找回）；「从文件夹中移除」（Shift+Del）= 该位置挪未分类（不删记录）。**位置级模型（2026-08-19 用户定"护栏拆干净"）：origin / 链接一视同仁**——无"最后一条"判定、无 origin 自动转移（手动转移归阶段六「设为原始文件」）、无链接分流独立项（03 稿"从文件夹中移除文件链接"废除）；菜单删除组恒此两项，快速访问视图同口径支持。撤销标签分流「丢到回收站 N 个项目 / 从文件夹中移除 N 个项目」。**回收站显示名 = 被删位置自身的显示名，不做特殊对待**（2026-08-20 用户定：回收站只是普通视口——叫什么名就显示什么名，链接位置进回收站即显示链接名；同资产多条位置同删聚合成一条时取快照第一条，不做 origin 优先）。**回收站彻底清除：** 条目含 origin 快照 = 资产本体在回收站——彻底删除 = 物理删 info + 库内该资产全部活链接随清（两段式确认窗提示虚拟片段引用数 + "其关联的 N 条链接将一并清除"）；纯位置记录条目彻底删除只删记录、物理不动、无需确认。**回收站右键菜单（2026-09-05 走查扩充）**：文件项 = 还原 / 打开预览 / 新标签页·新窗口·默认应用·其他应用打开 / 发送至 Animate / 资源管理器 / 移动文件 / 设为原始文件 / 打开链接所在位置（= 徽章 hover 弹窗同构双行列表）/ 剪切 / 重命名 / 添加至其他资源库 / 导出 / AI 工具集 / 复制数据 / **彻底删除入菜单**（旧"不入菜单"口径废除）/ 清空回收站；其中移动 / 设为原始 / 剪切 / 重命名四项 = 回收站快照写能力，后端立项前占位禁用；空白处 = 扫描重复文件 / 扫描文件/档案链接 / 还原全部 / 清空。**同时多选档案+文件夹的删除分流（同日走查）**：右键菜单删除组分两项——「删除文件夹」只作用文件夹选中集 /「将档案丢到回收站」只作用档案选中集（档案进回收站的完整语义 = 链接/原始档案独立进站，随档案多位置一轮后端立项；本轮菜单先行、删除行为照旧）。语义总纲见 [[01_资源与数据]] 边界规则 2 / 8。

#### 索引式工作空间（真实磁盘操作）

- 复制、剪切、粘贴、重命名直接操作磁盘文件，配合双向热刷新。
- 不支持拖拽排序、克隆文件夹、建立链接（无 Placement 数据）。
