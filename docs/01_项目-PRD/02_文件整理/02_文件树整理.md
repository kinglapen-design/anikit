## 02. 文件树整理

通过修改数据文件实现文件的层级和信息管理等，而非频繁的真实移动文件。

- **自定义排序：** 支持拖拽排序文件夹与文件，顺序写入 folders.json 的 order 字段，仅改数据不动磁盘，保证响应流畅。**排序依据含"自定义"首项（2026-08-14 用户定）**：可随时切回存储序；**名称排序显示下的手动结构操作（拖拽排序 / 新建文件夹）= 先物化该层可见顺序为存储序并自动切回"自定义"**——拖拽落点按可见序计算、新建落点回到选中项下一行；否则 refresh 后名称排序盖回，操作等于没执行（2026-08-14 用户实机"显示排序成功但实际没变"修复）。物化不单独弹 toast（顺序变化是主操作附带，撤销快照仍在）。**2026-08-19（3.5）素材侧落地同款**：显示排序下素材拖拽排序 = 该层可见序（含新增区置顶段）物化 + 整层重写 + 切回自定义；粘贴 / 新建文档不物化——无相对落点语义，由新增区承接（见 [[04_文件预览]] 06 节）；**副本落点 = 紧随原件**（2026-08-20 用户定：同文件夹副本恒插源后第一位，新副本贴原件、旧副本顺后移；跨文件夹副本粘贴 = 段首前插同导入语义——原"段首前插 + 新增区置顶"会把副本顶到第一行第一列，克隆完还要回顶部找）。**新建文件夹后清理（2026-08-14 用户定）**：清其他选中单选新文件夹 + 跳转其视图 + 进命名态——防旧选中域与新项双高亮混淆。
- **区块根目录视觉（2026-08-04 定；2026-08-18 修订）：** 区块根目录下的父级文件夹用底色区分，未自定义颜色时默认灰色；文件夹从其他层级拖至区块根目录下时，自动变为带灰色底色的默认 item；父级被设置颜色后，其子项全部变为父级颜色的**底色版本**（`--custom-{色}-bg`，2026-08-18 用户澄清——非透明度 10%，每个自定义色自带一对前景/底色档）。
- **树行为口径（2026-08-20 用户定，阶段五前 BUG 修复轮）：** ① **数量标签**：折叠 = 递归总数（含全部子文件夹）；**展开 = 直接子项文件数**（子文件夹已各自成行，父级数量只算自己的文件；为 0 不显示——替换原"展开即隐藏"：用户实机"父级 80 个素材直接在父级下、展开后数量消失，误以为显示异常"）。② **移动 / 新建后默认展开父级**：移动文件夹并入子项（拖拽 / 剪切粘贴 / 移动面板）、新建子文件夹 / 子档案后，目标父级保持展开——让用户直接看到操作结果，而不是折叠起来无从确认。③ **导航树定位**：树外入口进入文件夹视口（双击文件夹卡片 / 菜单打开 / 面包屑等）时，树自动展开祖先链与所在区块并滚动定位到该节点——原仅高亮，父级折叠时当前文件夹在树上看不见（视觉焦点丢失）；自身节点不展开（定位 = 看到它）。
- **自定义图标颜色（2026-08-18，3.3 落地；2026-09-01 修订）：** 文件夹可自定义图标颜色用于分类识别；图标与颜色值存于 folders.json 对应节点（`Folder.icon` / `Folder.color`，None 不写字段）。入口 = 树节点右键「更改图标 / 更改颜色」（7.1 二十四轮起 = 图标网格 flyout + 颜色内嵌色块行，组件/上下文菜单稿）。**同步语义（2026-08-18 用户定，图标颜色同口径）**：父级改动默认影响子级——后代中与本节点旧链路值**一致的跟随调整**（图标含默认图标 None == None，未区分子级首次统一即靠此；颜色无色后代不写数据、视觉自动跟随底色版本但链路穿透），**不一致的（用户单独区分过）不动且不再下钻**；后代改回与父级一致后恢复跟随。**「默认」色块 = 显式默认（2026-09-01 用户定）**：落盘存 `"default"` 哨兵断开父级链路强制常态灰——子级选默认若清 None 会被父级色视觉盖回、永退不回灰；哨兵按普通链路值参与同步。**多选批量（同日）**：触发项在多选域内 → 整个选中集一并换色（`set_folder_colors` 单命令单撤销步）。**档案右键菜单接入更改颜色（同日）**：档案 = Folder kind 标记，色值同表，生效于树档案节点圆点/图标（与徽标色 archives 表无关）。图标侧档案后代恒跳过（图标强制 archive，见 03 节）；**archive 图标不可选（同日）**——档案专属，移出更改图标网格与区块默认图标清单（存量 Folder/Block.icon = archive 经开库自检回退 None）。生效范围 = 文件树的 item 底色与图标（缩进线不变色——半透明线叠底色自然呈色，2026-08-18 用户定；7.1 十八轮起缩进线随节点色改该色-2 的 50% 档）、右侧详情面板的关联文件夹列表（随 6.2 区块落地）。
- **封闭式专属：** 文件树整理、区块、档案、分组、标注、多文件夹关联均为封闭式资源库专属功能（注释 / 描述降级后置见 06，评分移出 MVP 见 08）；索引式工作空间仅按真实磁盘结构显示，不支持自定义排序，磁盘与 UI 双向热刷新。
