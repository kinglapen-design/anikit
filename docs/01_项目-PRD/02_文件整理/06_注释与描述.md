## 06. 注释与描述

> 2026-07-28 用户定案：文件级注释 / 描述对命名规范的动画师素材价值低，降级为 MVP 后置；逐帧文字笔记（notes.json，见 [[04_文件预览]]）已覆盖动画场景的主要记录需求。档案的"描述"为新一轮定案的数据项，见 [[03_数据链接]] 03，与本节文件级注释 / 描述不是同一物。

用户可对文件夹添加描述，可对文件进行注释。

- **数据归属：** 文件夹描述存 folders.json 的 note 字段，文件注释存 metadata.json 的 note 字段；功能就位后纳入分词搜索范围。
- **版本规划：** MVP 后置。
