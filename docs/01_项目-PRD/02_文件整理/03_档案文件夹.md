## 03. 档案文件夹

档案 = 文件夹 + 详细数据（数据项见 [[03_数据链接]]），是复盘"节点式管理"的落地形态。对文件夹右键可转换为档案，也可直接新建档案；档案享有和文件一样的数据配置；档案徽标可自定义设置或隐藏。

- **层级约束：** 档案文件夹内不允许出现子级文件夹；右键转换时若文件夹内有子级，提醒用户剔除层级导入。
- **树内形态：** 档案 item 可在目录树内出现，但无展开箭头、下无子级，图标强制切换为档案专属图标 + 品牌紫色圆圈装饰。
- **拖拽规则：** 目录树拖拽文件夹时，档案不允许作为父级并入，仅支持排序；仅纯文件（多选时不包含文件夹）才允许拖入档案。
- **中间面板：** 展示分为文件夹 / 档案 / 文件三个区域。
- **回收站语义（档案当单个文件看待）：** 档案删除移入回收站时保持档案状态（剔除层级是对常规文件夹的处理），允许一键恢复；被删除的文件夹内包含档案时，档案同样保持封装状态。注：序列帧移入回收站时同样保持封装打包状态（既有实现天然满足）。
- **卡片：** 固定长宽比，缩略图默认索引子项第一张图片网格填充铺满；用户可在档案里设置头像——头像即档案封面，二者同步（见 [[03_数据链接]] 03）。
- **档案内视图（2026-08-30 用户定删除）：** ~~进入档案后，在中间面板与左侧边栏之间插入二级侧边栏显示档案数据；右侧正常显示文件~~——面板与右侧详情面板内容完全重复（选中档案卡片右栏即显示同一套档案详情），冗余撤除：ArchiveSidePanel 组件 / per-folder 开关状态 / 收展动画 / 工具栏展开钮一并删除；档案数据查看口径 = 选中档案看右栏。
- **数据口径（2026-08-15 落地，3.2 一轮骨架）**：档案 = folders.json 里 `Folder.kind = "archive"` 标记（serde default + None 不写字段，不升 DATA_VERSION）；头像 / 徽标 / 属性 / 描述存库级 `archives.json`（单一写点 save_archives，记录懒建，开库自检剔除失效记录，结构见 [[03_数据链接]] 06）。**转换两段式**：文件夹转档案时若有后代子文件夹先回 need_confirm 不动数据（26 稿同款两段式，25 稿 alert warning 确认弹窗，主钮「剔除转换」）；确认后剔除层级 = 后代子文件夹 BFS 按 order 逐层解散（各子文件夹 Placement 平移到档案、order 追加在后整体重排连续，子级本身是档案的 archives 记录一并清除），再置 kind。**护栏落地**：create_folder / move_folders 目标父级为档案报错"档案下不允许出现子级文件夹"；树/卡片拖拽档案不作父级并入仅排序，素材拖入档案不受限。**形态落地**：树 item 无展开箭头 + archive-dot 装饰；中间面板 ArchiveStrip 三区（文件夹 / 档案 / 内容，档案区无内容不渲染）；ArchiveCard 260:298 固定长宽比 + 纸底 SVG + 封面默认子项首图 + 左上角徽标芯片 + 底部信息条（名称 / N 个文件 / 链接计数），状态态复用文件夹卡片 ::after 机制。撤销标签：新建档案 / 转换为档案 / 解散档案为文件夹。
