## 14. 批量编辑

多选后，基础操作自动转为批量执行，是快速移动整理文件的手段：

- **批量复制 / 剪切 / 粘贴：** 对多个 Placement 批量执行，语义同 13（粘贴可选链接或副本）。
- **批量创建副本：** 批量物理复制，各自生成新 ID。
- **批量克隆文件夹（2026-08-18 落地）：** 多选文件夹右键「克隆」/ Ctrl+D——每个选中文件夹独立克隆一棵（单命令 `clone_folders` 单撤销步），语义同 13（复制克隆，无选项弹窗）。
- **批量重命名（2026-08-18 落地，3.4 / 37 稿）：** 单个「批量重命名」弹窗（多选时右键「批量重命名」/ **F2** 触发——F2 多选分流 2026-09-23 接入，原 Ctrl+R 键位同日早已废除；单选维持就地重命名）：底部分段选择器切换模式（**序号命名** / **替换命名**，同一时刻只显示当前模式的一行输入）——序号命名 = `名称_编号`（名称 + `_` + 起始编号，序号格式统一 2026-09-23 定案），位宽自动按选中数量决定（<100 两位、≥100 三位）；替换命名 = 查找文本 + 替换为（纯文本全处替换，MVP 不做正则）。规则只作用**词干**，扩展名不动。新名称列 = **实时预览**（只读，输入即刷新；替换模式下**原名称匹配段品牌色高亮**——视觉上把高亮部分换成新的）；无变化项不提交（序号名称为空 / 查找为空或无匹配 = 该项保持原名）。撞名不拦截（显示名放开，见 [[01_资源与数据]] 边界规则 7；原始 Placement 磁盘物理约束仍在，撞名失败计入汇总）。执行 = 逐条改名（链接仅改显示名 / 原始同步改磁盘 originName），**失败项（如被动画软件占用）跳过 toast 汇总报告，不整体回滚**；一次执行单撤销步（`rename_placements`）。
- **批量删除：** 删除语义同 13（原写"同 10"系笔误，2026-08-18 修正）。**文件夹批量删除已落地（2026-08-18，3.4）**：文件夹多选域右键「删除文件夹」或 Delete 键 → 一次确认（"已选中的 N 个文件夹…"）→ 后端 `delete_folders` 单趟单撤销步；祖先同批入选的后代去重（删祖先已连带子树），陈旧 id 剔除容错；素材删除原本即批量（Delete / 右键删整个选中集）。
