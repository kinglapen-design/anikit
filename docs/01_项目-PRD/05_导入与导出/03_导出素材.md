## 03. 导出素材

右键菜单常驻导出，支持导出文件，文件夹，整个素材库。

- 导出文件夹和整个素材库时，按照 folders.json 记录的层级 + Placement 显示名重建目录结构，千万不可导出我们的实际路径（ID.info 结构）。
- 同一素材以链接形式存在于多个文件夹时，导出后每个位置均为真实副本。
- **序列帧导出为一个文件夹装全部帧**（2026-08-14 用户定）：导出文件时文件夹名 = 资产名，导出文件夹时 = Placement 显示名去扩展名；帧保持库内归一名（标题_序号），重名文件夹追加 _序号。
- **导出进度复用导入进度条**（2026-08-14 用户定）：样式与位置同一组件，导出可取消（当前文件拷完后停）。
- **导出失败提示（2026-08-14 用户定）：** 逐文件拷贝失败不再静默——完成时有失败项弹 alert 错误模板弹窗（同导入失败：文件名竖排间距 8px）；主按钮"重试" = 按首跑记录的 源→目标 原路覆盖重投（成功项不重导），次按钮"退出" = 纯关闭。
- 导出仅为拷出，不改动库内任何数据。
- 索引式工作空间无需导出功能，文件本来就在磁盘上。
