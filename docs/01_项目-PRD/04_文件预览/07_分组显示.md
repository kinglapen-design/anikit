## 07. 分组显示

跟 window 的分组依据类似，可通过首字母分组，格式分组，递增还是递减等，还支持高级分组，分组后的文件，在内容展示区创建一个副标题分割素材。

高级分组：用户可创建分组，用户可以自定义规则，如名称里包含什么，格式是什么等等，无需纳入分词搜索范围，仅用于单文件夹文件太多，扁平化管理时用的归类方式，点击副标题，可弹出下拉框，展示所有分组，快速跳转，滚动条联动。

- **数据归属：** 分组规则存于 folders.json 的文件夹节点上，按文件夹各自生效。
- **3.5 二轮落地口径（2026-08-19，以 [[02_文件整理]] 04 节为准）：** 规则清单 = 扩展名 / 类型（8 类）/ 名称 / 导入日期 / 修改日期（**首字母分组不做**——本节旧表述废除）；副标题 = SectionHeader group 变体（30 高 / 标题档 + 数量 + 折叠箭头 + group-menu 钮）；**点 group-menu 钮出 12 稿菜单**（跳转▸ = 全组列表滚动跳转，与滚动条联动）；分组标题 **sticky 置顶**（transform 虚拟滚动体系内为悬浮层实现）。
