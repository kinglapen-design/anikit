## 02. 卡片布局

整体采用响应式布局，显示方式分为四种：

- 自适应：等高不等宽（默认）。
- 瀑布式：等宽不等高。
- 网格式：固定正方形。
- 列表式

- **显示简介（2026-08-19 接入，28 稿查看方式菜单行）：** 下拉选内容 + 开关两个独立设置（应用级 settings.ui `briefMode` / `showBrief`）。**档 4 项**：尺寸（音视频 = 时长 mm:ss、动图与其他 = w×h）/ 文件大小 / 创建日期 / 修改日期；**档内无数据一律回退文件大小**（文件大小恒有，2026-08-19 用户定——存量创建日期 null、尺寸档无尺寸资源 fla 等即属此列；旧"无尺寸 = 格式角标文案"废除：角标 / 名称 / 简介三处重复同一格式词，信息浪费）；**标签档占位禁用**（卡片数据无 tags，待后端数据通道随 3.2 二轮补）；**「无显示」档废除**（与开关语义重复，2026-08-19 用户定），旧配置残留 none 启动迁移回尺寸档。**关 = 仅隐藏简介行**（7.1 满铺卡口径，2026-08-30 修订）：名称/简介在图内渐变罩上，简介行显隐不占布局高度——卡高恒 = 纯图高（盒比例 = 图比例，cover 零裁），网格不随开关重排；旧"缩短卡片 57→36"口径随满铺定稿废除（盒高多于图高必致盒比例错位、cover 裁图）。原始文件徽章为整卡绝对定位（右下各 12）、不随简介显隐变化。列表模式固定列行高，不参与简介开关。


- **文本卡（2026-09-22 接入，稿 = 文件卡片-txt-md；R6 卡片三变体 text 变体生产接线）：** txt / md / docx 卡片内容区 = 词干标题 + 正文滚动预览（卡内滚轮直接滚动全文，hover 出滚动胶囊）——不再走系统格式图标；docx 复用预览同款段落结构提取拼纯文本。数据 = 卡片懒加载（虚拟滚动渲染即视口内才读文件，会话级缓存按 modifiedAt 版本戳自动失效），正文截断 8000 字符防大文档 DOM 过载；ws 工作空间合成项不挂文本变体（assetId 假 id 禁发命令，维持格式图标）。docx 卡片用 read_docx_asset 全量解析的浪费记待办观察（必要时后端加读头部轻命令）。字体卡 / 音频卡变体接线仍待立项。
	- 文本卡修订（2026-09-22 用户实机走查四条）：**字号固定稿值不随卡宽缩放**（卡片缩放只影响显示行数；推翻 2026-09-13 cqw 等比缩放口径）；**卡内文本让位格式角标**（起始 = 角标下缘 + 4px，无角标回 12）；**滚轮不介入卡内**（滚轮恒滚网格页面，卡内滚动走右缘胶囊拖动——「大部分情况只大概看看，细节点进预览看」）；**滚动胶囊可拖**（修复拖动被拖拽排序抢走）。
