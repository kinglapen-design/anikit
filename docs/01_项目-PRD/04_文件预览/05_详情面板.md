## 05. 详情面板

展示图片的各类信息：颜色信息、基础信息、标签、关联文件夹、AI 提示词等。

1. 颜色信息：缩略图 + 颜色提取色块，最多支持显示十个颜色，悬停展示色号，单击二级菜单，显示更详细的 HSL，RGB，HSV等，一键复制信息，一键搜索相同颜色。**实现口径（2026-08-23，6.1 三轮已落地色块真色）：** 提取随缩略图管线（导入 / 重生成缩略图时从 320px 缩略图统计，直方图分桶 + 同色合并），主色存 `metadata.colors`（#RRGGBB 按占比降序，上限 10；serde default 不升 DATA_VERSION），存量资产打开详情时懒回填；**透明通道颜色不混入**（alpha < 16 的像素不参与统计，半透明按原始 RGB 计入——2026-08-23 用户定）；pinned 颜色 bar 恒显，槽位 7 个（01_主窗口稿）按实际色数渲染、无颜色（非图片 / 无缩略图）出 7 个占位色块；悬停色号 / 单击二级菜单（HSL·RGB·HSV、一键复制、搜同色）**后置**（2026-08-23 用户定本轮只上真色，09 待办）。
2. 基础信息：标题输入框（可直接修改文件名，遵循 [[02_文件整理]] 的重命名规则：改当前 Placement 显示名，原始文件才异步改 originName），注释出入口（功能 MVP 后置），链接输入框，其他基础信息，如尺寸，大小，创建时间等。（评分模块随评分移出 MVP，2026-07-28 定）
3. 标签：可添加删除标签。
4. 关联文件夹：展示当前素材同时存在在哪些文件夹里，显示名称是什么。
5. AI 提示词：展示 AI 提示词，没有时，可以点击按钮分析提示词。

- **模块化设计：** 详情面板按模块封装，颜色、基础信息、标签、关联文件夹、AI 提示词等各为独立模块，预留统一接口，后续可随时增删模块（如直方图一类需求）。**（2026-08-31 三 tab 化 + 文件夹详情形态，7.1 二十三轮：** 模块组织 = pinned 缩略图/颜色区块恒顶 + 分段控制器三 tab（基础信息 / 链接关系 / 提示词），见 [[03_数据链接]] 02 区块体系条；**新增文件夹/快速访问详情形态——选中普通文件夹或视口未选中文件时，右栏显示该文件夹/当前视口信息**（文件夹 = 图标缩略图 + 名称/链接 + 文件数/档案数/子文件夹数/占用空间；快速访问 = 简化版：无缩略图 + 名称固定文案禁改名 + 文件数/占用空间两行）。）**（2026-10-03 工作空间视口同口径回退：** 工作空间视口未选中任何项时，右栏显示当前视口目录信息——形态 = 选中该文件夹同款的简化基础信息（名称 / 位置 / 类型行，磁盘实况无附加数据）；子目录条目取父目录缓存（深层视口父目录未加载时前端幂等触发加载），根视口名称 = 「工作空间」（根入口行 / 根标签标题同口径）、位置 = 根绝对路径。）**（2026-10-03 目录属性落地（Windows 属性窗口低成本批）：** 文件夹详情基本数据 = 类型 / 文件数 / 子文件夹数 / 占用空间（递归统计，字节求和 = 库 FolderDetail 同标签同口径，穿透 junction 防回环、`.anikit` 跳过；异步 `ws_dir_stats` 现算快照，未到位不加行）/ 创建日期 / 修改日期（目录时间后端放开——原人为抹零废除，Windows 目录 mtime = 直接子项增删时更新；根视口合成条目取 stats 根目录值）。不做项：簇对齐「占用空间」真值（与字节求和信息重复、压缩/稀疏不准）、只读 / 隐藏属性与高级属性（目录只读在 Windows 无意义，展示价值低）、共享 / 安全 / 以前的版本 tab（高成本）。）**（2026-10-12 三 tab 语义分界定案 + 逐帧笔记接回：** 基础信息 = 是什么（名称/链接/标签/描述/基本数据）/ 链接关系 = 和谁连着 / 自定义组件 = 绑定选中对象的文件级生产批注扩展（[[07_工作台转型]] 扩展点第 1 条同日修订口径）——提示词自基础信息末位挪回（2026-09-26 二轮口径修订），逐帧笔记接回换代（2026-08-31 摘出的 DetailNotes → sections/NotesSection + items/NoteItem 笔记 item 稿；仅库内文件形态，**有笔记才显示**——同日走查用户定：图片无笔记语义）；提示词卡片包 SectionTitle 标题行（同日走查定）；排序/显隐随信息查看管理面板第三段，7.3 T3 detailTabSpecs 注册表化后新卡片（直方图等）挂同一容器。）
