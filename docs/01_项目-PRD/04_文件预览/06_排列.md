## 06. 排列

支持多种排列方式：标题、大小、格式、时长、修改时间、创建时间、导入时间，增还是递减等等常见的排列方式，默认采用自定义。（评分排列随评分移出 MVP，2026-07-28 定）

- **3.5 落地定案（2026-08-19）：** 排序方式 = 28 稿查看方式菜单行点亮（下拉 + 升/降切换按钮组），**全局统一**（应用级 settings.ui，一处设置全库生效）；**键 8 项**：自定义 / 名称 / 文件大小 / 时长 / 扩展名 / 创建时间 / 修改时间 / 导入时间。
	- **自定义 = 存储序**（Placement.order），自定义时升降切换禁用（无升降语义）；**名称 = 自然排序**——阿拉伯数字串按数值（文件2 < 文件10）、中文数字按数值（一~万常见写法：十一/一百零五）、天干（甲乙丙…）按序列（2026-08-19 用户补充：中文序列不处理会按字符码乱序）；空值（无时长 / 存量无创建时间）**恒排尾**不随升降反转；平局恒按名称自然排序 + assetId 兜底（不反转）。
	- **显示层排序，不动存储序**；作用范围 = **素材区全视图生效**（含快速访问；文件夹 / 档案卡片不参与，恒存储序）。
	- **物化（02 整理 02 节口径素材侧落地）：** 显示排序下素材拖拽排序 = 该层可见序（含新增区）物化为存储序、拖拽组按落点并入整层重写（reorder_placements 全层序列 + 段尾锚点），并自动切回自定义——否则 refresh 后排序键盖回，拖拽等于没执行。**自定义排序下同口径（2026-10-13 修订）：** 目标段可见清单含新增区置顶项时，拖拽排序同样走物化（可见序物化 + 新增区归位）——置顶期间可见序 ≠ 存储序，按存储序插入与所见落点错位（拖置顶项存储侧可能是无操作），refresh 后钉住盖回 = "排序提示成功但没用"（用户实机报，链接与原始文件同夹时两条同钉必现；切目录归位后自愈）。
	- **新增区（2026-08-19 用户定；2026-08-20 修订）：** 新增 / 导入 / 粘贴的项**不按排序键分散，集中置顶**（区内先来在前），**所有排序模式生效含自定义**——用户实机报"全部"视图自定义序下新导入沉底（存储序按文件夹段组织，落点段位置不定）；**切视图再回来即归位**（并入排序流），切库 / 物化同清。**副本不进新增区**（2026-08-20 用户定：副本紧随原件落点，置顶反而拽回第一行第一列）。**存储序前插修订（2026-08-20 复验二轮）：** 导入 / 新建文档写存储序（folders.json items）= **全部视图全局前插**（插入位 = 本批已插总数，异文件夹混批按到达序从头部依次后移）——原按目标文件夹段首定位，段不在头部时"全部"视图归位后沉回段位（用户实机"导入后在中间插入"）；文件夹视图段首前插语义不变。
	- **时间键语义：** 创建时间 = 源文件磁盘创建时间（导入时记 metadata.created_at；剪贴板 / 新建文档 = 建档时刻；副本 / 克隆继承源资产；存量数据无值排尾）；修改时间 = 库内数据最后变更时刻（现有 modified_at，非源文件 mtime）；导入时间 = imported_at。
	- 索引式工作空间无 Placement 数据，不支持自定义排列，自动回落到名称 / 时间排列。
