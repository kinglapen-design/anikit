## 04. 文件预览

双击素材，中间内容展示区默认切换至预览模式，可查看图片，视频，字体，动图、序列帧、音频、文本等信息。

不同格式的素材，对应的工具栏不同。

1. 图片
	- 基础：原始尺寸，适应屏幕，旋转，翻转，上一文件，下一文件。
	- 高级：滑块放大缩小，滚轮放大缩小，左键拖动，标注，AI抠图、超清、扩图，裁剪等。
	- 实现定案（2026-07-25，4.3）：滚轮缩放瞄点跟随鼠标位置、滑块缩放瞄点在视图中心；放大超出可视范围时右下角出现视图导航器（Eagle 式：拖视口框移动画面、点击跳转，还原适应后自动消失）。**显示器全屏 = 临时充满（2026-09-17 实机走查定案，全格式同口径）**：进入全屏恒「适合窗口」充满铺满（抓手/缩放退出过跟随的视图也放大填充），退出全屏还原进入前的工作取景（缩放/平移/跟随态），全屏不污染工作视图。
2. 字体
	- 基础：上一文件，下一文件。
	- 查看字体演示，详情，安装/卸载字体。
	- 实现定案（2026-08-23，5.6）：格式 = ttf / otf / ttc（woff 系后置，09 待办）；解析 = ttf-parser（name 表 / cmap / num_glyphs，纯 Rust 无系统依赖）。**缩略图 = 样张渲染**（fontdue 光栅化，thumb_formats 适配器）：cmap 含中文（'永'）→ 四行「永和九年 / 歲在癸丑 / AaBbCcDd / 01234567」，否则三行「ABCDEFG / abcdefg / 0123456」（Eagle 同款口径，用户供参考图）；width/height 元数据记样张尺寸（音频波形同手法）。**预览** = 页签「预览 / 其它」（Eagle 四页签先两页，大小 / 字形后置）：预览页 = 演示文本（origin 经 FontFace API 前端加载，webview 原生排版，后端不重渲染）+ 底部字号滑杆；其它页 = 名称（PostScript 名）/ 全名 / 系列 / 样式 / 版本 / 字数 + 系统状态。**安装 / 卸载 = 系统级用户安装**（%LOCALAPPDATA%\Microsoft\Windows\Fonts + HKCU 注册表 Fonts 项 + WM_FONTCHANGE 广播，免管理员）——**其他软件立即可见**（2026-08-23 用户痛点定案：Eagle 装字体仅注册进自有体系、其他软件识别不到，AniKit 必须装到系统级）；只认本应用安装口径（HKCU），系统级（HKLM）字体不动。
3. 动图
	- 基础：原始尺寸，适应屏幕，旋转，翻转，上一文件，下一文件。
	- 高级：滑块放大缩小，滚轮放大缩小，左键拖动，标注，逐帧查看，倍数查看，设置某一帧为预览图（重新生成缩略图并记录封面帧）。
	- 支持素材卡片阶段悬停播放，和自动播放，可在查看二级窗口里设置（后续会写UI布局）。
	- 播放条定案（2026-07-25，5.2 实现）：播放/暂停、当前帧/总帧数、进度条、倍率、笔记、当前帧设为预览图、显示器全屏；下方常驻帧条——上/下帧按钮 + 逐帧预览块（小图缓存于 cache/frames 会话级，打开库时清空，2026-07-25 用户定：序列帧从磁盘帧图缩放，**动图 = origin 按需解码**——2026-08-20 解包废除后无磁盘帧图），切换帧时高亮块先移至可见区两端，顶头后帧列表按需滑动。
	- 播放帧定案（2026-08-20 用户，**解包废除**，推翻 2026-07-26"导入期解包持久化"）：动图**不持久化解包**——预览播放 = 自研解码帧流（WS 推帧 canvas 渲染，对 origin 运行时解码，播放/暂停/帧号进度/倍率/拖动定位/逐帧步进全套由会话命令驱动，总帧数 = metadata frameCount）；设封面（set_thumb_frame）与笔记帧画面 = origin 单帧抽解码（`f:{帧索引}`）；帧条小图 = origin 单趟流式解码存 cache/frames 会话级；逐帧笔记 key = `f:{帧索引}`（存量帧名 key 加载时一次性迁移）。导入零解包等待（探测仍走 GIF 字节级扫描，只数帧累加 delay 不解像素）。
4. 序列帧
	- 基础：原始尺寸，适应屏幕，旋转，翻转，上一文件，下一文件。
	- 高级：滑块放大缩小，滚轮放大缩小，左键拖动，标注，逐帧查看，倍数查看，设置某一帧为预览图。
	- 播放条定案（2026-07-25）：完全复用动图播放条与帧条（数据源为 frames/ 目录帧图），4.3 随序列帧逐帧预览先行落地；**进入预览即自动播放**（2026-07-25 用户定）。
> 序列帧导入时，软件按常见命名格式检测（检测与入库归一规则见 [[01_资源与数据]] 数据格式第 5 条），打包成一个素材卡片展示（一个序列帧包 = 一个资源 = 一个 ID），自动播放，用户可以右键选择进入序列帧包里，查看单独的每一张。
	- **包内视图定案（2026-08-20 用户定，5.2 落地）**：素材卡片右键「打开序列帧包」→ 当前视口切换为包内卡片列表（视口 key = `seq:{assetId}`，标签页标题 = 包名，面包屑后退可返回来源视口）。帧卡片 = 素材卡片同款视觉（缩略图取 cache/frames 帧条小图，与预览帧条同一份缓存），恒按帧序平铺（不参与排序/分组/新增区），卡片尺寸滑块生效。**双击帧 / 右键「打开预览」** = 退回包所在文件夹视口并打开预览定位该帧。**右键菜单**：打开预览 / 将当前帧设为预览图（直复用播放条同款 set_thumb_frame 业务，2026-08-21 用户定）/ 重排序号 / 删除此张序列图（多选 = 删除 N 张）；**空白右键**：重排序号；菜单定宽 320（与素材卡片右键菜单同宽——213 下删除项 + 快捷键徽章仍裁切，用户实机两轮定）。**详情面板停留包详情不为空**（2026-08-21 用户定）：包内视图选择域已清空，selectedAssetKey 回退 placements 内该包资产（origin 优先），详情面板据此显示包的详情与逐帧笔记；笔记跳帧在包内可直接开预览定位（preview store current 回退全量 placements 精确匹配）。**删除帧**（抽帧调节奏场景）：物理移出库（会话内暂存 cache/seq-trash 支撑撤销/重做，会话结束真删），封面帧被删则改指剩余首帧并重建缩略图，至少保留 1 帧；**重排序号**：剩余帧按当前顺序重排为连续序号（`词干-001..N`，位宽只增不减），帧笔记 key 随帧名映射迁移，封面帧跟随，磁盘改名成对登记可撤销。**播放与序号断开的口径**：播放按 frames/ 目录文件名排序的清单逐帧等长播放，序号只是帧名字符、不参与连续性推导——抽删帧后序号断开**不影响播放**，帧数变少即节奏加快（正是抽帧目的）；重排序号仅为整洁，非播放前提。
5. 音频
	- 基础：播放 / 暂停，进度条，音量调整，上一文件，下一文件。
	- 高级：倍速播放，循环播放，波形图显示。
	- 支持素材卡片阶段悬停播放，移动鼠标快进快退。
	- 播放条定案（2026-07-25，5.2 实现）：播放/暂停、音量、当前时间/总时长、波形进度条（波形铺满整条，已播放部分高亮 + 播放头竖线）、倍率、循环；无笔记、无全屏。
6. 文本
	- 基础：上一文件，下一文件。
	- word 等文件渲染成缩略图显示（见 03 的办公文档说明），软件内部不内置编辑器，不然太重了。
	- txt 等支持简单的输入和保存，不需要斜体，粗体等高级功能，大概率就是写点提示词。
	- Markdown 支持查看与编辑：Live Preview 所见所得编辑（Obsidian 式——光标外行渲染排版、光标行回落源码；CodeMirror 6 内核，文档源仍是 md 字符串）+ markdown-it 渲染预览；原「不引入所见即所得编辑器」作废（2026-10-10 用户定：可读性优先，样式沿用文本编辑稿）。
	- 实现定案（2026-08-23，5.6）：预览 kind = text（txt / md）。**txt = APP 内编辑**（textarea 即预览，防抖 1s 自动保存；编辑不进 undo；保存后 metadata.size / modifiedAt 同步，PlacementView 同刷）。**编码口径**：读 = UTF-8（BOM 剥离）优先、失败 GBK 回退（Windows 中文用户 txt 常态 ANSI）；写 = 恒 UTF-8 无 BOM；内容上限 2MB。txt / md 缩略图维持格式图标（不入内容缩略图体系）。
	- **md 编辑器落地（2026-09-25 文本编辑稿轮，兑现上条「源码编辑 + 渲染预览」定案）**：预览态 = markdown-it 渲染（排版 = 06_UI重构 中间面板-内容容器-文本编辑稿：版心 84 / 块 gap 12 / H1 带 2px 分割线 / 引用竖线 / 代码块卡片 + 右上复制钮；任务列表 = 复选框组件同款通用类，点击 toggle 直接回写源码）；点击正文进编辑态 = 全文源码编辑（防抖 1s 自动保存与 txt 同管线、同不进 undo；悬浮栏换 MarkDown 工具栏：段落 / 列表 / 插入 / 格式 19 动作作用源码选区），Esc / Ctrl+Enter 退回预览态。md 图片引用 = 库内封闭路径解析不了渲染占位文本、链接本轮不可点，两笔 09 待办不变（2026-10-08 已勾销）。
	- **md 编辑器换代 = Live Preview（2026-10-10 用户定，推翻上条「不引入所见即所得」口径）**：编辑态内核由 textarea 换 CodeMirror 6——光标外行内联渲染（标题字号 / 加粗斜体删除线隐标记 / 引用竖线 / 代码块卡片 / 任务复选框 / anikit 图片真图，排版数值同文本编辑稿与 markdown.css token），光标行回落纯源码；预览态（markdown-it 渲染，纯阅读）与分屏（左编辑右渲染）保留不变。文档源仍是 md 字符串：防抖 1s 自动保存、19 个工具栏动作作用源码选区、任务框点击回写、anikit 粘贴补全全部沿用；撤销换 CM6 原生事务栈（自实现 mdHistory 快照栈退役，「编辑不进 undo」口径不变）。
	- **md 大纲栏（2026-10-15 立项并落地——用户反馈 md 缺大纲、长文档查找困难；交互参照 = 飞书文档大纲）**：md 预览面板内左侧可开关大纲栏（悬浮栏 MarkDown 工具栏视图组「大纲」钮切换，图标暂用库件占位、待补源随批换；开关态会话级——切素材保持，关预览复位）；H1-H6 标题层级缩进列表（一级标题加大加粗），点击跳转对应节（预览 = 渲染块定位 / 编辑 = CM scrollIntoView / 分屏 = 右栏精确 + 左栏 CM），正文滚动联动高亮当前节并自动滚进视野。样式无设计稿——preview 陈列一轮定稿（用户看稿：一级标题加大加粗，其余照初案，口径速查 §71）。
	- **docx 预览（2026-09-22 R6 首例 → 2026-10-10 换 mammoth 引擎）**：预览 kind docx = Word .docx APP 内**只读预览**。渲染 = **mammoth.js 前端 docx→HTML**（用户实机推翻初代 quick-xml 段落提取——「公司反馈文档都是视频截图配文字」，初代表格平铺无框线、无图片在该场景残废）：**表格带框线、图片内嵌显示、标题/列表/粗斜体/对齐基础样式**；浮动布局图片（文字环绕 / 任意拖放 anchor）与文本框降级为顺序内嵌、裁切特效显示原图、形状批注丢失——真撞上再升级 docx-preview（接口层留换引擎位）。上限：文件 64MB（解压由 mammoth/JSZip 自理，前端转换）；非 docx / 损坏中文报错。编辑走「默认应用打开」（「软件内部不内置编辑器」口径不变）；doc（OLE2）/ xlsx / pptx 后置另立；docx 缩略图仍走系统格式图标。~~工作空间磁盘实况下 docx 与字体 / 文本同口径降级 other~~（**2026-10-23 作废**——工作空间文档预览放行，docx / 字体 / 文本在 ws 同进对应预览页，定案见 [[02_索引式工作空间]] 技术口径「文档预览」条；ws 文本卡内容 = 既有按路径文本提取 read_docx_by_path，不随预览换引擎）。
7. 视频
	- 基础：原始尺寸，适应屏幕，旋转，翻转，上一文件，下一文件，标注。
	- 高级：播放进度条，倍率播放，逐帧播放，音量调整，快进，快退，循环播放，选取当前帧为预览图。
	- 可支持在素材卡片阶段，悬停播放，移动鼠标可快进快退。
	- 播放条定案（2026-07-25，5.2 实现）：播放/暂停、快退/快进、音量、当前时间/总时长、进度条、倍率、循环、笔记、当前帧设为预览图、显示器全屏；逐帧走快捷键（或后续补图标）。
	- **播放解码定案（2026-08-22 晚，5.3 终版：`<video>` 直读硬解；推翻同日白天"全面接入自研帧流"定案——实机验证裸帧软解流不达 Eagle 流畅度：4K 裸帧 WS 带宽 235MB/s 级、GOP 软解精确 seek 结构性 1-2s 延迟）：** 视频播放（卡片 + 预览）= `<video>` 元素 + convertFileSrc 直读 origin（asset protocol Range 实测完好：1080p25 单点 seek 5-40ms、66ms 连发 scrub 全跟手、4K120 松手 100ms 到位；Eagle 同一条 Chromium 硬解管线），音画同步 / 音量 / 循环由元素原生承担；不可直播格式转码兜底链（2026-09-13 修订为**直读优先 + 播放错误回退**，用户实机"转码太慢、每次开软件 CPU 长时间满载"）：get_media_source 一律先直给源文件路径（零探测零等待——HEVC 等编码 WebView2 经 Windows Media Foundation 直解，与 Eagle 同机制，Eagle 能播的本机即无需转码，实机验证），前端播放 error 后带 forceTranscode 重调才转码兜底；**error 回退分两级（2026-09-24 补，踩坑 086）**——`<video>`/`<audio>` error 先读 MediaError.code：非 SRC_NOT_SUPPORTED（seek / 硬解管线瞬时错误）先同源直读重试一次（恢复原位置续播，不出「转码中…」），仍 error 才落转码；SRC_NOT_SUPPORTED（真格式不支持）直落转码不白试；转码产物迁 cache/media **跨会话保留**（原 cache/tmp 开库清空 → 每会话重转；stamp 幂等保源变化重转，每资产终身只转一次）。帧号 / 逐帧 = currentTime 帧级控制（步进 ± 1/fps，fps 感知缺省 24；键盘 , . 与播放条按钮同语义）；播放条循环钮 = 元素 loop；笔记 key 仍 `t:{秒}`；设封面仍 set_video_thumb（sidecar 截帧，与播放链无关）。**scrub 跟手口径（同日实测定案，对齐 Eagle"进度条剥离"机制）**：播放条拖动 / 悬停 scrub 期间进度条与帧号以鼠标位置为准立即渲染（seek() 乐观写入；拖动中 timeupdate 不回写防弹回——该事件仅 250ms 粒度，直接驱动 UI 必肉眼滞后），画面由解码异步追。自研解码器（adapters/decoder 持久 VideoDecoder）保留给设封面 / 单帧抽取场景；帧流服务收窄纯动图。
	- **帧显示优先定案（2026-07-28 用户）：** 动画师的思维单位是帧——视频播放条与卡片悬停胶囊以帧号显示（当前帧 / 总帧数，按素材自身帧率，metadata 需补 fps 探测），查看方式菜单提供"帧数 / 时间码"全局开关（默认帧数）；逐帧步进按 1/fps；视频笔记标识显示帧号（底层 key 仍为 `t:{秒}` 不变，防 fps 变动）。音频无帧概念，保持时间显示。**播放条时间文本悬停可就地切换帧数 / 时间码（2026-07-28 用户复验定）**——竖排弹窗样式与倍率弹窗同规格，与查看方式菜单"时间显示"同一设置双向联动。

- **卡片悬停行为分发定案（2026-07-27 用户定案，5.3 实现；参考 Eagle 截图三张；同日用户修订：悬停播放 = 完整视频，10 秒范围是自动播放用的；序列帧归动图范围）**——悬停按钮按需出，不再是全部"发送 + 放大镜"：
	1. 视频：无按钮，**悬停 = 完整播放整段**（循环），跟随鼠标横向移动快进快退（`<video>` seek：pointermove 直接设 currentTime——2026-08-22 实测 5-40ms/次，无需合帧 / 门控；进度条与帧号同步写目标值立即跟手，不走 timeupdate；预生成帧图方案 2026-07-28 用户决策废弃——CPU / 磁盘 / 载入成本不可接受）；右下胶囊 = 当前帧（可切时间码，见 7 视频帧显示优先定案）+ 音量钮（默认静音，点击切换；无音轨不出）；底部 3px 进度条显示全片进度。
	2. 音频：无按钮，悬停即有声播放；卡片波形图上叠加已播放品牌紫高亮 + 1px 品牌紫播放头竖线，点击/拖动波形 seek；右下胶囊 = 当前时间 + 播放/暂停钮。
