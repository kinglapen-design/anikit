## 03. 缩略图与全文件支持

封闭式管理下，所有导入的文件都必须显示在 UI 上，让用户清楚自己导入过什么文件，不存在"看不见的文件"。

1. **自有缩略图：** 图片、动图、视频、序列帧、字体等支持的格式，导入时生成缩略图存入 info 文件夹；音频生成**波形图**作为卡片预览（不使用系统通用图标），波形数据随 info 一并缓存（工作空间则缓存于 .anikit）。
	- **格式扩展纪律（2026-07-25 定）：** 内置解码走适配器注册表——新格式 = `services/thumb_formats/` 新增一个适配器文件 + 注册表一行，不改分发逻辑；远期目标对齐 Eagle 按需安装格式扩展：sidecar 外部解码器扩展包（exe + manifest 声明扩展名，子进程喂路径收像素，插件崩溃不拖垮主程序），ffmpeg sidecar（5.1）为第一个外部解码器，届时封装统一扩展接口。
	- 实现定案（2026-07-22，4.2）：PSD 走 psd crate 解内嵌合成图、SVG 走 resvg 渲染——**无 Adobe 依赖**，不走 shell；PSB 走自研轻量合成图解析（psd crate 不支持 PSB；Raw / RLE PackBits，8/16 位 RGB / 灰度 / CMYK 近似，像素上限 64M 防爆内存）；未存合成图（保存时关"最大兼容性"）回退格式图标。**AI 本轮先保底**（走系统格式图标，内容缩略图后置单独评估：pdfium sidecar / hayro）。
2. **系统缩略图：** 暂不支持的格式，调用系统接口获取缩略图——Windows 使用 Shell 接口（IShellItemImageFactory），macOS 使用 Quick Look（QLThumbnailGenerator）。
	- 实现定案（2026-07-22，4.2）：shell 只取**格式图标**（SIIGBF_ICONONLY），作非素材文件（zip 等）与无伴生图工程文件（fla / aep 等）的保底。
3. **系统缩略图缓存：** 系统缩略图按**格式**缓存而非按文件——如 01.zip、02.zip 共用同一份压缩软件图标，每个扩展名只缓存一份，用于加速卡片加载。
	- 实现定案（2026-07-22，4.2）：缓存于 `cache/thumbs/{ext}.webp`，**不进 info**——info 内放 shell 图会污染（后期补伴生缩略图后两份并存），且占空间。
4. **办公文档：** Word 等办公文档依赖外部组件渲染缩略图（Windows 可调用系统 Office COM 或 LibreOffice headless，macOS 走 Quick Look），软件不内置文档渲染器。
5. **缩略图操作（右键「缩略图」组）：** 刷新缩略图（从 origin 重跑导入同管线）、自定义缩略图（从剪贴板位图 / 选择文件，外来源清空 thumbFrame）、复制缩略图。
	- 实现定案（2026-08-23，5.4）：「复制缩略图」= 把本资产缩略图位图写进系统剪贴板，用途 = 配「自定义缩略图 - 从剪贴板」把缩略图设给其他资产——**全类型统一复制各自缩略图**（静态图 / 视频封面 / 序列帧封面 / 动图首帧 / 音频波形），shell 格式图标也放开（cache/thumbs/{ext}.webp；"想用 shell 图定义其他文件是用户自己的事"，用户定）；纯读不改库数据。同组其余项归属：「打开 Animate 生成缩略图」归阶段七插件；~~「转换为缩略图链接并复制」「将「xx」设置为缩略图」归 8.2 伴生缩略图阶段~~（**2026-09-02 批次 4 提前点亮**：「转换为缩略图链接并复制」= 纯引用复制进会话级 thumbLink（不动库数据，hidden 在实际绑定时打）；「将『xx』设置为缩略图」= 对该资产 set_thumb_asset 绑定（label 动态带链接资产名；自绑禁用；无链接时占位 disabled）；**重复绑定 = 换绑语义（用户定保守路径）：工程改指向新资产，旧 hidden 不动**——旧图手动处置 = 缩略图视图右键「还原为素材」（同轮挂前端入口，restore_thumb_asset：取消 hidden 链接位置恢复 + 清除全部工程侧引用，toast 带清除数）或删除；链接红利 = 一个 hidden 资产可绑多个工程处处生效）
	- 布局口径（2026-08-23 二轮，用户定）：卡片自适应 / 瀑布流布局比例**跟缩略图实际尺寸走**（metadata.thumb_width/height，生成缩略图时写入）——自定义缩略图后布局按新图比例自适应，width/height 恒为源文件尺寸（详情显示与排序语义不动），刷新缩略图从 origin 重生成即回退；存量数据无该字段，前端回退 width/height（比例一致无感知）。
	- 解码口径（2026-08-23 二轮）：缩略图管线探测 / 解码**按内容魔数识别，不认扩展名**（壁纸站等渠道假扩展名常见——.png 实为 JPEG；image crate 按扩展名预设格式会 InvalidSignature，踩坑 052）。
