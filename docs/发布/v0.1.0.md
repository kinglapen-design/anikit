# AniKit v0.1.0

发布日期：2026-11-08

AniKit 的首个公开早期版本，面向动画师的本地素材管理软件。版本号使用 `0.1.0`，不称为 `1.0`：主要链路已经打通，但格式覆盖、细节体验和长期稳定性仍需真实使用与反馈。

## 下载

Windows 10 / 11 x64 免安装包：`anikit-v0.1.0-20261108.zip`。

- 文件大小：911,124,503 字节（约 869 MiB）
- SHA-256：`f1392384e624003ce2f00031a70b247c721ccd83e0ba0330f30fb24a1adb165a`

完整解压后运行 `anikit.exe`。包内包含 FFmpeg、本地语义模型与运行时，请保留目录结构。系统需要 WebView2 Runtime。

## 本版内容

### 素材库与整理

支持封闭式素材池、多资源库、文件夹与档案、导入导出、链接、属性、描述、提示词、分组筛选、批量操作、回收站、备份与恢复。

### 搜索与预览

支持分词与中文语义搜索，以及图片、视频、动图、序列帧、音频、字体和文档预览。Markdown 支持阅读、编辑、分屏、大纲与图片打包导出。

本地 CLIP 提供基础画面分析；可选外部视觉服务补充详细描述与事件。带时间轴的命中可以定位，并创建虚拟片段或物理截取。静态图片支持整图语义检索，但不提供时间段或片段功能。

### 工作空间与联动

索引式工作空间可直接整理现有目录，支持链接外部文件夹、与素材库互通和 Everything 加速搜索。Animate CEP、Typora / Obsidian 贴图直链、MCP 与 `anikit-cli.exe` 已接入。

### 发布入口与界面

偏好设置按通用、语义分析、自动导入、缓存、插件和快捷键分类，长文本与操作区支持换行和内部滚动。主菜单提供应用内使用教程、GitHub 意见反馈、日志和独立关于窗口。

## 早期版本边界

- 当前仅面向 Windows，其他平台没有发布承诺。
- 外部详细分析只有主动配置后才发送采样帧；基础语义分析与检索在本地运行。
- 工作空间操作直接作用于磁盘；素材库永久删除与工作空间系统回收站是不同链路。
- 清理缓存不删除素材本体，但自定义缩略图重建后不能从缓存恢复。
- 插件机制、格式覆盖与部分界面仍会调整，重要项目请保留独立备份。

## 文档与反馈

使用教程见 `docs/使用教程.md`，应用内「帮助 → 使用教程」阅读同一内容。问题反馈请使用 GitHub Issues，并附版本、Windows 版本、复现步骤与相关日志；不要上传 API Key 或个人素材。

本项目尚未选择开源许可证。第三方组件、模型与字体分别遵循其许可证和声明。
